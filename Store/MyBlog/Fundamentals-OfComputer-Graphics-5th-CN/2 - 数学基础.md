# 2 - 数学基础（Miscellaneous Math）

图形学在很大程度上就是把数学直接“翻译”成代码：数学越简洁，最终写出的代码就越清晰。因此，本书会花相当篇幅讨论如何为每个任务挑选最合适的数学工具。本章回顾高中与大学数学中的各种工具，定位更接近参考材料而非教程。乍看之下，本章像各种主题的大杂烩——事实也的确如此；每个主题入选都自有原因：要么它在“标准”数学课程中不那么常见，要么它在图形学中居于核心地位，要么它通常不会被从几何的角度讲授。除了建立全书使用的符号体系，本章还着重强调了一些标准本科课程中偶尔会略过的要点，例如三角形上的重心坐标。本章无意对这些内容作严格的理论处理，而是重在培养直觉理解与几何解释。线性代数的讨论推迟到第6章，紧接着变换矩阵的内容。建议读者先通读本章，熟悉所涉及的主题，待需要时再回头查阅。章末的习题有助于判断哪些主题还需要复习。

## 2.1 集合和映射（Sets and Mappings）

映射（mapping，也称函数 function）是数学和编程的基础。就像程序中的函数一样，数学中的映射接收某种类型的参数，并将其映射（返回）为特定类型的对象。在程序中，我们称之为“类型”；在数学中，我们会明确指定集合。当某个对象属于某个集合时，我们使用符号 $\in$。例如，

$$a \in S$$

可读作“$a$ 是集合 $S$ 的成员”。给定任意两个集合 $A$ 和 $B$，可以通过两者的笛卡尔积（Cartesian product）构造第三个集合，记作 $A \times B$。集合 $A \times B$ 由所有可能的有序对 $(a,b)$ 组成，其中 $a \in A$ 且 $b \in B$。作为简写，我们用 $A^2$ 表示 $A \times A$。笛卡尔积的概念还可以推广：由三个集合构造所有可能的有序三元组，依此类推，可以由任意多个集合构造任意长度的有序元组。

常用的集合包括：

• $\mathbb{R}$ —— 实数集（real numbers）；
• $\mathbb{R}^+$ —— 非负实数集（包括零）；
• $\mathbb{R}^2$ —— 实数平面上的有序对；
• $\mathbb{R}^n$ —— $n$ 维笛卡尔空间中的点；
• $\mathbb{Z}$ —— 整数集（integers）；
• $S^2$ —— 单位球面上的三维点集（$\mathbb{R}^3$ 中的点）。

注意，虽然 $S^2$ 由嵌入三维空间的点组成，但这些点位于可用两个变量参数化的曲面上，因此 $S^2$ 可视为二维集合。

映射的记号使用箭头和冒号，例如：

$$f : \mathbb{R} \to \mathbb{Z}$$

可读作“存在一个名为 $f$ 的函数，它以实数为输入，将其映射为整数”。这里，箭头左侧的集合称为函数的**定义域**（domain），右侧的集合称为**目标集**（codomain）。程序员可能更熟悉如下等价表述：“存在一个名为 $f$ 的函数，它接收一个实数参数并返回一个整数。”换句话说，上述集合记号等价于常见的编程记号：

```text
integer f(real) ← 等价于 → f : ℝ → ℤ
```

因此，冒号-箭头记号完全可以看作一种编程语法。就这么简单。

点 $f(a)$ 称为 $a$ 的**像**（image）；集合 $A$（定义域的子集）的像是目标集的一个子集，包含 $A$ 中所有点的像。整个定义域的像称为函数的**值域**（range）。

### 2.1.1 逆映射（Inverse Mappings）

![Figure2.1](Figure2.1.png)
如果有函数 $f : A \to B$，则可能存在逆函数 $f^{-1}: B \to A$，其定义为 $f^{-1}(b) = a$，其中 $b = f(a)$。这一定义仅在以下条件下成立：$B$ 中每个 $b$ 都是某个点在 $f$ 下的像（即值域等于目标集），并且这样的点唯一（即只有唯一的 $a$ 满足 $f(a) = b$）。这样的映射或函数称为**双射**（bijection）。双射把 $A$ 中每个 $a$ 映射到 $B$ 中唯一的 $b$；反过来，$B$ 中每个 $b$ 都恰好对应一个满足 $f(a) = b$ 的 $a$（图2.1）。骑手与马匹之间的双射意味着每个人恰好骑一匹马、每匹马恰好被一个人骑，对应的两个函数分别是 rider(horse) 和 horse(rider)，二者互为逆函数。不是双射的函数没有逆函数（图2.2）。
![Figure2.2](Figure2.2.png)
双射的一个例子是 $f : \mathbb{R} \to \mathbb{R}$，其中 $f(x) = x^3$，其逆函数为 $f^{-1}(x) = \sqrt[3]{x}$。这个例子说明标准记号可能有些别扭，因为 $x$ 在 $f$ 与 $f^{-1}$ 中都被用作哑变量（dummy variable）。有时换用不同的哑变量更直观，即 $y = f(x)$、$x = f^{-1}(y)$，于是得到更直观的表示：$y = x^3$ 与 $x = \sqrt[3]{y}$。

没有逆函数的例子是 $\text{sqr} : \mathbb{R} \to \mathbb{R}$，其中 $\text{sqr}(x) = x^2$。原因有二：首先 $x^2 = (-x)^2$；其次，定义域中没有任何成员被映射到目标集的负数部分。注意，如果同时把定义域和值域限制为 $\mathbb{R}^+$，就可以定义逆函数——此时 $\sqrt{x}$ 是有效的逆函数。

### 2.1.2 区间（Intervals）

我们经常需要约束函数输入所在的实数范围，区间（interval）就是其中一种方式。例如，零到一之间、不包括零和一的所有实数可记作 $(0,1)$。由于不包含端点，这称为**开区间**（open interval）。相应的**闭区间**（closed interval）包含端点，用方括号表示：$[0, 1]$。这两种记号可以混用，例如 $[0, 1)$ 包含零但不包含一。书写区间 $(a, b)$ 时，我们默认 $a \leq b$。表示区间的三种常见方式如图2.3所示。
![Figure2.3](Figure2.3.png)
区间的笛卡尔积也很常用。例如，要表示三维单位立方体中的点 $x$，可以写 $x \in [0, 1]^3$。

区间与集合运算结合使用尤为有用：交集、并集和差集。例如，两个区间的交集是它们共有点的集合，符号 $\cap$ 表示交集，如 $(3, 5) \cap (4, 6] = [4, 5)$。并集用符号 $\cup$，表示属于任一区间的点，如 $[3, 5) \cup (4, 6] = [3, 6]$。与前两个运算符不同，差运算符的结果取决于参数的顺序。减号表示差运算，它返回左区间中不在右区间中的点，例如 $[3, 5) - [4, 6] = [3, 4)$，而 $[4, 6) - [3, 5) = [5, 6)$。借助区间图可以很直观地观察这些运算（图2.4）。

### 2.1.3 对数（Logarithms）

尽管在计算器普及之后，对数已不如从前那样常用，但在处理含指数项的方程时，对数依然很有用。按定义，每个对数都有一个底数 $a$。“以 $a$ 为底的 $x$ 的对数”写作 $\log_a x$，含义是“$a$ 的多少次幂等于 $x$”，即

$$y = \log_a x \Leftrightarrow a^y = x$$

注意，对数底 $a$ 与把 $a$ 升幂的函数互为逆函数。这一定义有几个直接推论：

$$a^{\log_a x} = x$$

$$\log_a (a^x) = x$$

$$\log_a (xy) = \log_a x + \log_a y$$

$$\log_a (x/y) = \log_a x - \log_a y$$

$$\log_a x = \frac{\log_b x}{\log_b a}$$

当用微积分处理对数时，特殊常数 $e = 2.718\ldots$ 经常出现。以 $e$ 为底的对数称为**自然对数**（natural logarithm），我们采用常见简记 $\ln$：

$$\ln x = \log_e x$$

注意，符号 $\equiv$ 可读作“按定义等价”。与虚数单位 $i$ 一样，特殊常数 $e$ 出现在大量不同语境中。许多领域习惯使用其他特定底数，并在记号中省略底数，直接写 $\log x$。例如，天文学家常用以 10 为底的对数，理论计算机科学家常用以 2 为底的对数。由于计算机图形学借鉴了许多领域的做法，本书将避免这种省略底数的简记。

对数和指数的导数说明了为什么自然对数是“自然的”：

$$\frac{d}{dx} \log_a x = \frac{1}{x \ln a}$$

$$\frac{d}{dx} a^x = a^x \ln a$$

只有当 $a = e$ 时，上述常数乘子才等于 1。

## 2.2 解二次方程（Solving Quadratic Equations）

一元二次方程的形式为

$$Ax^2 + Bx + C = 0,$$

其中 $x$ 是实数未知数，$A$、$B$、$C$ 是已知常数。若画出 $y = Ax^2 + Bx + C$ 的二维 $xy$ 图像，则解就是曲线与 $x$ 轴交点处的 $x$ 值，即“零点”。由于 $y = Ax^2 + Bx + C$ 是抛物线，根据抛物线与 $x$ 轴相离、相切或相交的情况，方程会有零个、一个或两个实数解（图2.5）。
![Figure 2.5](Figure2-5.png)
为了解析地求解二次方程，先两边除以 $A$：

$$x^2 + \frac{B}{A}x + \frac{C}{A} = 0$$

然后利用“配方法”（completing the square）整理各项：

$$\left(x + \frac{B}{2A}\right)^2 = \frac{B^2}{4A^2} - \frac{C}{A}$$

把常数项移到右边并开平方，得到：

$$x + \frac{B}{2A} = \pm\sqrt{\frac{B^2}{4A^2} - \frac{C}{A}}$$

两边同时减去 $\frac{B}{2A}$，并把各项合并到分母 $2A$ 上，就得到熟悉的形式：

$$x = \frac{-B \pm \sqrt{B^2 - 4AC}}{2A} \quad (2.1)$$

这里，$\pm$ 表示两个解，一个取正号，一个取负号。因此，$3 \pm 1$ 等于“2 或 4”。注意，决定实数解个数的项是

$$D = B^2 - 4AC,$$

它称为二次方程的**判别式**（discriminant）。若 $D > 0$，有两个实数解（也称根 root）；若 $D = 0$，有一个实数解（“重根”）；若 $D < 0$，则没有实数解。

例如，$2x^2 + 6x + 4 = 0$ 的根是 $x = -1$ 和 $x = -2$，而方程 $x^2 + x + 1 = 0$ 没有实数解。这两个方程的判别式分别为 $D = 4$ 和 $D = -3$，与预期解的数量相符。

在程序中，通常最好先计算 $D$；若 $D$ 为负，直接返回“无根”，无需开平方。

## 2.3 三角学（Trigonometry）

### 2.3.1 角（Angles）

尽管我们对角已经习以为常，仍有必要回到角的定义，以便把角的概念推广到球面。角由两条半直线（从同一点出发的两条无限射线）或两个方向构成，必须借助某种约定来决定二者之间形成的两个可能角中的哪一个，如图2.6所示。角由其对应的单位圆弧长定义。一种常见约定是取较小的弧长，并以两条半直线的指定顺序决定角的符号。按此约定，所有角都落在 $[-\pi, \pi]$ 范围内。

![Figure2.6](Figure2-6.png)

其中每个角都等于两个方向在单位圆上截取的弧长。由于单位圆周长为 $2\pi$，两个可能角之和为 $2\pi$。弧长的单位是**弧度**（radian）。另一种常用单位是**度**（degree），此时整个圆周为 $360°$。因此，$\pi$ 弧度的角等于 $180°$，通常记作 $180°$。度与弧度之间的换算为：

$$\text{度} = \frac{180}{\pi} \cdot \text{弧度}$$

$$\text{弧度} = \frac{\pi}{180} \cdot \text{度}$$

### 2.3.2 三角函数（Trigonometric Functions）

给定一个直角三角形，边长分别为 $a$、$o$ 和 $h$，其中 $h$ 是最长边（总是与直角相对）的长度，即斜边（hypotenuse），一个重要的关系由**勾股定理**（Pythagorean theorem）描述：

$$a^2 + o^2 = h^2$$

从图2.7可以看出这一结论，其中大正方形的面积为 $(a+o)^2$，四个三角形的总面积为 $2ao$，中心正方形的面积为 $h^2$。由于三角形和内部正方形正好铺满大正方形，有 $2ao + h^2 = (a + o)^2$，整理即可得到上式。
![Figure2-7](Figure2-7.png)
定义角 $\phi$ 的正弦、余弦以及其他基于比值的三角函数：

$$\sin \phi = \frac{o}{h}; \quad \csc \phi = \frac{h}{o};$$

$$\cos \phi = \frac{a}{h}; \quad \sec \phi = \frac{h}{a};$$

$$\tan \phi = \frac{o}{a}; \quad \cot \phi = \frac{a}{o}.$$

这些定义使我们得以建立**极坐标系**（polar coordinates），其中点的位置由到原点的距离和相对于正 $x$ 轴的有符号角度表示（图2.8）。注意约定角度 $\theta \in (-\pi, \pi]$，正角从正 $x$ 轴起逆时针度量。逆时针为正的约定虽带任意性，但在图形学的许多场合都会用到，值得牢记。
![Figure2-8](Figure2-8.png)
三角函数是周期函数，可以接受任意角度作为参数，例如 $\sin(A) = \sin(A + 2\pi)$。这意味着这些函数在定义域 $\mathbb{R}$ 上不可逆。标准做法是限制反函数的值域，几乎所有现代数学库都遵循这一约定（例如 Plauger (1991)）。各反函数的定义域与值域为：

$$\arcsin : [-1, 1] \rightarrow [-\pi/2, \pi/2];$$

$$\arccos : [-1, 1] \rightarrow [0, \pi]; \quad (2.2)$$

$$\arctan : \mathbb{R} \rightarrow (-\pi/2, \pi/2);$$

$$\text{atan2} : \mathbb{R}^2 \rightarrow (-\pi, \pi].$$

最后一个函数 $\text{atan2}(s, c)$ 往往非常有用。它接收一个与 $\sin A$ 成正比的值 $s$，以及一个按相同因子缩放 $\cos A$ 的值 $c$，返回角度 $A$（假设该因子为正）。理解该函数的一种方式是：它返回二维笛卡尔坐标点 $(s, c)$ 在极坐标下的角度（图2.9）。
![Figure2-9](Figure2-9.png)

### 2.3.3 常用的恒等式（Useful Identities）

#### 位移恒等式（Shifting identities）

$$\sin(-A) = -\sin A$$

$$\cos(-A) = \cos A$$

$$\tan(-A) = -\tan A$$

$$\sin(\pi/2 - A) = \cos A$$

$$\cos(\pi/2 - A) = \sin A$$

$$\tan(\pi/2 - A) = \cot A$$

#### 勾股恒等式（Pythagorean identities）

$$\sin^2 A + \cos^2 A = 1$$

$$\sec^2 A - \tan^2 A = 1$$

$$\csc^2 A - \cot^2 A = 1$$

#### 加法和减法恒等式（Addition and subtraction identities）

$$\sin(A + B) = \sin A \cos B + \sin B \cos A$$

$$\sin(A - B) = \sin A \cos B - \sin B \cos A$$

$$\sin(2A) = 2\sin A \cos A$$

$$\cos(A + B) = \cos A \cos B - \sin A \sin B$$

$$\cos(A - B) = \cos A \cos B + \sin A \sin B$$

$$\cos(2A) = \cos^2 A - \sin^2 A$$

$$\tan(A + B) = \frac{\tan A + \tan B}{1 - \tan A \tan B}$$

$$\tan(A - B) = \frac{\tan A - \tan B}{1 + \tan A \tan B}$$

$$\tan(2A) = \frac{2\tan A}{1 - \tan^2 A}$$

#### 半角恒等式（Half-angle identities）

$$\sin^2(A/2) = \frac{1 - \cos A}{2}$$

$$\cos^2(A/2) = \frac{1 + \cos A}{2}$$

#### 任意三角形的定律

以下恒等式适用于边长为 $a$、$b$、$c$，对应角分别为 $A$、$B$、$C$ 的任意三角形（图2.10）：

$$\frac{\sin A}{a} = \frac{\sin B}{b} = \frac{\sin C}{c} \quad \text{（正弦定律）}$$

$$c^2 = a^2 + b^2 - 2ab \cos C \quad \text{（余弦定律）}$$

$$\frac{a + b}{a - b} = \frac{\tan\left(\frac{A+B}{2}\right)}{\tan\left(\frac{A-B}{2}\right)} \quad \text{（正切定律）}$$

#### 三角形面积

三角形的面积也可以用这些边长计算：

$$\text{三角形面积} = \frac{1}{4}\sqrt{(a + b + c)(-a + b + c)(a - b + c)(a + b - c)}$$

### 2.3.4 立体角和球面三角学（Solid Angles and Spherical Trigonometry）

本节之前的传统三角学处理的是平面上的三角形。三角形也可以定义在非平面表面上，其中最常出现（例如在天文学中）的是单位半径球面上的三角形。这些**球面三角形**（spherical triangle）的边是球面上大圆（单位半径圆）的弧段。对它们的研究称为**球面三角学**（spherical trigonometry），在图形学中并不常用，但一旦需要，往往至关重要。这里不讨论其细节，只希望读者知道：当这类问题真正出现时，存在相应的理论，并且有许多有用的规则，如球面余弦定律与球面正弦定律。球面三角学应用的一个例子可参见关于采样三角形光源（投影到球面三角形）的论文（Arvo, 1995b）。

对计算机图形学更为核心的概念是**立体角**（solid angle）。角度让我们能量化“我视野中那两根杆子隔了多远”这类问题，而立体角让我们能量化“那架飞机占了我视野的多少”这类问题。对普通角，我们把杆子投影到单位圆上，测量两者在单位圆上截取的弧长。由于我们太常处理角，许多人可能早已忘记这个定义——如今这一切都显得太直观了。立体角同样简单，却可能更令人困惑，因为我们大多数人成年后才接触到它。

对于立体角，我们把“看到”飞机的那些视线方向投影到单位球面上，然后测量所覆盖的面积。这个面积就是立体角，正如弧长之于角度。角度以**弧度**为单位，总和为 $2\pi$（单位圆的总周长）；立体角以**球面度**（steradian）为单位，总和为 $4\pi$（单位球面的总面积）。

## 2.4 向量（Vectors）

**向量**（vector）描述长度与方向，用箭头表示非常形象。两个向量只要长度和方向相同就相等，即使我们认为它们位于不同的位置（图2.11）。应尽可能把向量看作箭头，而不是坐标或数字。尽管最终必须把向量表示为程序中的数字，但即使在代码里，向量也应作为对象来操作，只有底层的向量运算才需要关心数值表示（DeRose, 1989）。本书中向量用粗体表示，例如 $\mathbf{a}$，其长度记作 $\|\mathbf{a}\|$。**单位向量**（unit vector）是长度为 1 的向量；**零向量**（zero vector）是长度为零的向量，零向量的方向未定义。

向量可以用来表示许多不同的事物。例如，它可以表示**偏移量**（offset），也称**位移**（displacement）。如果我们被告知“宝藏埋在秘密集合点以东两步、以北三步的地方”，那么我们只知道偏移量，却不知道从哪里出发。向量还可以表示**位置**（position），它是“位置”或“点”的另一种说法。位置可以表示为相对另一个位置的位移。通常我们约定一个原点位置，其他所有位置都作为相对该原点的偏移量存储。

需要特别强调的是，**位置并不是向量**。正如我们将要讨论的，两个向量可以相加；但两个位置相加通常没有意义，除非是计算位置加权平均时的中间步骤（Goldman, 1985）。两个偏移量相加确实有意义，这正是偏移量作为向量的原因之一。但这也说明位置不是偏移量：位置是相对特定原点位置的偏移量，而偏移量本身并不是位置。

### 2.4.1 向量操作（Vector Operations）

向量拥有实数算术中我们熟悉的大部分运算。两个向量相等，当且仅当它们长度相同且方向相同。两个向量相加遵循**平行四边形法则**（parallelogram rule）：把第二个向量的起点接到第一个向量的终点，所得向量即两者之和（图2.12）。和向量就是“补全”由这两个向量构成的三角形的向量。无论按哪种顺序相加，得到的都是同一个平行四边形，这正说明向量加法满足**交换律**（commutativity）：

$$\mathbf{a} + \mathbf{b} = \mathbf{b} + \mathbf{a}$$

注意，平行四边形法则不过是对位移直觉的形式化：想象先沿一个向量从尾走到头，再沿另一个向量走，净位移正是平行四边形的对角线。我们还可以定义向量的**一元负号**（unary minus）：$-\mathbf{a}$（图2.13）是与 $\mathbf{a}$ 长度相同、方向相反的向量。由此可以定义减法：

$$\mathbf{b} - \mathbf{a} = -\mathbf{a} + \mathbf{b}$$

减法同样可以用平行四边形直观理解（图2.14），并且有：

$$\mathbf{a} + (\mathbf{b} - \mathbf{a}) = \mathbf{b}$$

向量也可以相乘，而且涉及向量的乘法有若干种。首先，可以用实数 $k$ **缩放**（scale）向量：只改变长度而不改变方向。例如，$3.5\mathbf{a}$ 与 $\mathbf{a}$ 方向相同，但长度为后者的 3.5 倍。本节后面将讨论两种涉及两个向量的乘法——**点积**和**叉积**；第6章还会讨论涉及三个向量的乘积——**行列式**。

![Figure2-12](Figure2-12.png)

### 2.4.2 笛卡尔坐标系下的向量（Vectors and Cartesian Coordinates）

任一二维向量都可以表示为任意两个非零且互不平行的向量的组合。这两个向量的这一性质称为**线性无关**（linearly independent）。两个线性无关的向量构成一个二维**基底**（basis），这两个向量因此称为**基向量**（basis vector）。例如，向量 $\mathbf{c}$ 可以表示为基向量 $\mathbf{a}$、$\mathbf{b}$ 的组合（图2.15）：

$$\mathbf{c} = a_c\mathbf{a} + b_c\mathbf{b}\tag{2.3}$$

![Figure2.16](Figure2-16.png)

注意系数 $a_c$、$b_c$ 是唯一的。如果两个基向量**正交**（orthogonal，即相互垂直），该基底会特别有用；如果它们又都是单位向量，即构成**标准正交基**（orthonormal basis），就更为有用。假设已知两个这样的“特殊”向量 $\mathbf{x}$ 和 $\mathbf{y}$，那么可以在**笛卡尔坐标系**（Cartesian coordinates）中表示所有其他向量，每个向量用两个实数表示。例如，向量 $\mathbf{a}$ 可以表示为：

$$\mathbf{a} = x_a\mathbf{x} + y_a\mathbf{y}$$

其中 $x_a$、$y_a$ 是二维向量 $\mathbf{a}$ 的实数笛卡尔坐标（图2.16）。注意，这与方程(2.3)在概念上并无本质区别，只是那里的基向量并不标准正交。但笛卡尔坐标系有若干优势，例如由**勾股定理**可直接得到 $\mathbf{a}$ 的长度：

$$\|\mathbf{a}\| = \sqrt{x_a^2 + y_a^2}$$

此外，在笛卡尔系中计算点积、叉积和向量坐标都很简单，我们将在后续章节看到。

按照惯例，我们把 $\mathbf{a}$ 的坐标写作有序对 $(x_a, y_a)$ 或列向量形式：

$$\mathbf{a} = \begin{pmatrix} x_a \\ y_a \end{pmatrix}$$

采用哪种形式取决于排版的方便程度。偶尔也会把向量写成行向量，记作 $\mathbf{a}^T$：

$$\mathbf{a}^T = \begin{pmatrix} x_a & y_a \end{pmatrix}$$

笛卡尔坐标同样可以表示三维、四维及更高维向量。三维情形下，我们引入一个既与 $\mathbf{x}$ 正交、又与 $\mathbf{y}$ 正交的基向量 $\mathbf{z}$。

### 2.4.3 点积（The Dot Product）

两个向量之间最简单的乘法是**点积**（dot product）。$\mathbf{a}$ 与 $\mathbf{b}$ 的点积记作 $\mathbf{a} \cdot \mathbf{b}$，也常称为**标量积**（scalar product），因为它返回一个标量。点积的结果与两个向量的长度及其夹角 $\phi$ 有关（图2.17）：

$$\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\| \|\mathbf{b}\| \cos \phi \tag{2.4}$$

在图形程序中，点积最常见的用途是计算两个向量之间夹角的余弦值。

点积还可用来求一个向量在另一个向量上的**投影**（projection）：$a_{\rightarrow b}$ 是 $\mathbf{a}$ 垂直投影到 $\mathbf{b}$ 方向上的长度（图2.18）：

$$a_{\rightarrow b} = \|\mathbf{a}\| \cos \phi = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{b}\|}$$

点积满足实数运算中我们熟悉的交换律和分配律：

$$\begin{align}
\mathbf{a} \cdot \mathbf{b} &= \mathbf{b} \cdot \mathbf{a} \\
\mathbf{a} \cdot (\mathbf{b} + \mathbf{c}) &= \mathbf{a} \cdot \mathbf{b} + \mathbf{a} \cdot \mathbf{c} \\
(k\mathbf{a}) \cdot \mathbf{b} &= \mathbf{a} \cdot (k\mathbf{b}) = k\mathbf{a} \cdot \mathbf{b}
\end{align} \tag{2.6}$$

若二维向量 $\mathbf{a}$、$\mathbf{b}$ 用笛卡尔坐标表示，利用 $\mathbf{x} \cdot \mathbf{x} = \mathbf{y} \cdot \mathbf{y} = 1$ 与 $\mathbf{x} \cdot \mathbf{y} = 0$，可推导出它们的点积为：

$$\begin{align}
\mathbf{a} \cdot \mathbf{b} &= (x_a\mathbf{x} + y_a\mathbf{y}) \cdot (x_b\mathbf{x} + y_b\mathbf{y}) \\
&= x_ax_b(\mathbf{x} \cdot \mathbf{x}) + x_ay_b(\mathbf{x} \cdot \mathbf{y}) + x_by_a(\mathbf{y} \cdot \mathbf{x}) + y_ay_b(\mathbf{y} \cdot \mathbf{y}) \\
&= x_ax_b + y_ay_b
\end{align}$$

类似地，三维情形为：

$$\mathbf{a} \cdot \mathbf{b} = x_ax_b + y_ay_b + z_az_b$$

![Figure2.17-2.18](Figure2-17-18.png)

### 2.4.4 叉积（The Cross Product）

**叉积**（cross product）$\mathbf{a} \times \mathbf{b}$ 通常只对三维向量定义；广义叉积的讨论见本章注释中的参考文献。叉积返回一个垂直于两个参数向量的三维向量，其长度与 $\sin \phi$ 有关：

$$\|\mathbf{a} \times \mathbf{b}\| = \|\mathbf{a}\| \|\mathbf{b}\| \sin \phi$$

量值 $\|\mathbf{a} \times \mathbf{b}\|$ 等于由 $\mathbf{a}$ 与 $\mathbf{b}$ 张成的**平行四边形的面积**。此外，$\mathbf{a} \times \mathbf{b}$ 同时垂直于 $\mathbf{a}$ 和 $\mathbf{b}$（图2.19）。注意，这样的垂直向量只有两个可能的方向。

![Figure2-19](Figure2-19.png)

按定义，$x$、$y$、$z$ 轴方向的向量为：

$$\begin{align}
\mathbf{x} &= (1, 0, 0) \\
\mathbf{y} &= (0, 1, 0) \\
\mathbf{z} &= (0, 0, 1)
\end{align}$$

我们约定 $\mathbf{x} \times \mathbf{y}$ 指向正 $z$ 方向（或负 $z$ 方向）。这种选择多少有些任意，但标准做法是假设：

$$\mathbf{z} = \mathbf{x} \times \mathbf{y}$$

三个笛卡尔单位向量的所有可能叉积为：

$$\begin{align}
\mathbf{x} \times \mathbf{y} &= +\mathbf{z} \\
\mathbf{y} \times \mathbf{x} &= -\mathbf{z} \\
\mathbf{y} \times \mathbf{z} &= +\mathbf{x} \\
\mathbf{z} \times \mathbf{y} &= -\mathbf{x} \\
\mathbf{z} \times \mathbf{x} &= +\mathbf{y} \\
\mathbf{x} \times \mathbf{z} &= -\mathbf{y}
\end{align}$$

由 $\sin \phi$ 的性质可知，向量与自身的叉积为零向量，即 $\mathbf{x} \times \mathbf{x} = \mathbf{0}$，依此类推。注意叉积**不满足交换律**：$\mathbf{x} \times \mathbf{y} \neq \mathbf{y} \times \mathbf{x}$。

细心的读者会注意到，以上讨论并没有明确坐标轴之间的空间关系。更具体地说，如果把 $\mathbf{x}$、$\mathbf{y}$ 放在地面上，$\mathbf{x}$ 指向东、$\mathbf{y}$ 指向北，那么 $\mathbf{z}$ 指向天空还是指向地面？通常约定 $\mathbf{z}$ 指向天空，这称为**右手坐标系**（right-handed coordinate system）。该名称来自一个记忆方法：用右手手掌和手指“握住” $\mathbf{x}$，再将其转向 $\mathbf{y}$，此时拇指所指即为 $\mathbf{z}$ 的方向。图2.20对此作了说明。

![Figure2-20](Figure2-20.png)

叉积满足分配律：

$$\mathbf{a} \times (\mathbf{b} + \mathbf{c}) = \mathbf{a} \times \mathbf{b} + \mathbf{a} \times \mathbf{c}$$

以及数乘性质：

$$\mathbf{a} \times (k\mathbf{b}) = k(\mathbf{a} \times \mathbf{b})$$

但叉积不满足交换律；由右手定则可得：

$$\mathbf{a} \times \mathbf{b} = -(\mathbf{b} \times \mathbf{a})$$

在笛卡尔坐标下，可以通过显式展开计算叉积：

$$\begin{align}
\mathbf{a} \times \mathbf{b} &= (x_a\mathbf{x} + y_a\mathbf{y} + z_a\mathbf{z}) \times (x_b\mathbf{x} + y_b\mathbf{y} + z_b\mathbf{z}) \\
&= x_ax_b\mathbf{x} \times \mathbf{x} + x_ay_b\mathbf{x} \times \mathbf{y} + x_az_b\mathbf{x} \times \mathbf{z} \\
&\quad + y_ax_b\mathbf{y} \times \mathbf{x} + y_ay_b\mathbf{y} \times \mathbf{y} + y_az_b\mathbf{y} \times \mathbf{z} \tag{2.7} \\
&\quad + z_ax_b\mathbf{z} \times \mathbf{x} + z_ay_b\mathbf{z} \times \mathbf{y} + z_az_b\mathbf{z} \times \mathbf{z} \\
&= (y_az_b - z_ay_b)\mathbf{x} + (z_ax_b - x_az_b)\mathbf{y} + (x_ay_b - y_ax_b)\mathbf{z}
\end{align}$$

因此，坐标形式为：

$$\mathbf{a} \times \mathbf{b} = (y_az_b - z_ay_b, z_ax_b - x_az_b, x_ay_b - y_ax_b) \tag{2.8}$$

### 2.4.5 标准正交基和坐标系（Orthonormal Bases and Coordinate Frames）

坐标系管理几乎是所有图形程序的核心任务之一，其关键在于管理**标准正交基**。任意两个二维向量 $\mathbf{u}$、$\mathbf{v}$ 构成标准正交基，当且仅当它们正交（成直角）且各自为单位长度，即：

$$\|\mathbf{u}\| = \|\mathbf{v}\| = 1$$

并且

$$\mathbf{u} \cdot \mathbf{v} = 0$$

三维情形下，三个向量 $\mathbf{u}$、$\mathbf{v}$、$\mathbf{w}$ 构成标准正交基的条件是：

$$\|\mathbf{u}\| = \|\mathbf{v}\| = \|\mathbf{w}\| = 1$$

并且

$$\mathbf{u} \cdot \mathbf{v} = \mathbf{v} \cdot \mathbf{w} = \mathbf{w} \cdot \mathbf{u} = 0$$

若还满足

$$\mathbf{w} = \mathbf{u} \times \mathbf{v}$$

则该标准正交基是**右手**的，否则是**左手**的。

注意，笛卡尔标准正交基只是无穷多个可能的标准正交基之一。它之所以特殊，是因为它连同隐含的原点一起被用作程序内部的底层表示：向量 $\mathbf{x}$、$\mathbf{y}$、$\mathbf{z}$ 以及标准原点 $\mathbf{o}$ 都无需显式存储。全局模型通常存储在这个标准坐标系中，因此它常被称为**全局坐标系**（global coordinate system）。

然而，如果我们要使用另一个坐标系，其原点为 $\mathbf{p}$、标准正交基向量为 $\mathbf{u}$、$\mathbf{v}$、$\mathbf{w}$，就必须显式存储这些向量。这样的系统称为**参考系**（frame）或**坐标系**（coordinate system）。例如，在飞行模拟器中，可能希望维护一个以机头为原点、基向量与飞机对齐的坐标系，同时保留主标准坐标系（图2.21）。与特定对象（如飞机）关联的坐标系通常称为**局部坐标系**（local coordinate system）。

![Figure2-21](Figure2-21.png)

在底层，局部坐标系仍以标准坐标存储。例如，若 $\mathbf{u}$ 的坐标为 $(x_u, y_u, z_u)$，那么：

$$\mathbf{u} = x_u\mathbf{x} + y_u\mathbf{y} + z_u\mathbf{z}$$

位置则隐式包含相对标准原点的偏移：

$$\mathbf{p} = \mathbf{o} + x_p\mathbf{x} + y_p\mathbf{y} + z_p\mathbf{z}$$

其中 $(x_p, y_p, z_p)$ 是 $\mathbf{p}$ 的坐标。

注意，如果把向量 $\mathbf{a}$ 存储在 $\mathbf{u}$-$\mathbf{v}$-$\mathbf{w}$ 坐标系中，我们存储三元组 $(u_a, v_a, w_a)$，其几何含义是：

$$\mathbf{a} = u_a\mathbf{u} + v_a\mathbf{v} + w_a\mathbf{w}$$

要把 $\mathbf{u}$-$\mathbf{v}$-$\mathbf{w}$ 坐标系中的向量 $\mathbf{a}$ 转换到标准坐标，只需回忆 $\mathbf{u}$、$\mathbf{v}$、$\mathbf{w}$ 本身就是用笛卡尔坐标存储的，因此显式计算 $u_a\mathbf{u} + v_a\mathbf{v} + w_a\mathbf{w}$ 便直接得到笛卡尔坐标。

反之，要把标准坐标系中的向量 $\mathbf{b}$ 表示成 $\mathbf{u}$-$\mathbf{v}$-$\mathbf{w}$ 坐标，可以利用点积：

$$u_b = \mathbf{u} \cdot \mathbf{b}; \quad v_b = \mathbf{v} \cdot \mathbf{b}; \quad w_b = \mathbf{w} \cdot \mathbf{b}$$

这是可行的，因为对某些 $u_b$、$v_b$、$w_b$ 有：

$$u_b\mathbf{u} + v_b\mathbf{v} + w_b\mathbf{w} = \mathbf{b}$$

点积可以“分离”出坐标 $u_b$：

$$\begin{align}
\mathbf{u} \cdot \mathbf{b} &= u_b(\mathbf{u} \cdot \mathbf{u}) + v_b(\mathbf{u} \cdot \mathbf{v}) + w_b(\mathbf{u} \cdot \mathbf{w}) \\
&= u_b
\end{align}$$

该式成立，正是因为 $\mathbf{u}$、$\mathbf{v}$、$\mathbf{w}$ 标准正交。

使用矩阵管理坐标系变换的内容见第6.2.1节与第6.5节。

### 2.4.6 从单个向量构建基（Constructing a Basis from a Single Vector）

我们经常需要构造一个与给定向量对齐的标准正交基：给定向量 $\mathbf{a}$，希望找到标准正交向量 $\mathbf{u}$、$\mathbf{v}$、$\mathbf{w}$，使得 $\mathbf{w}$ 与 $\mathbf{a}$ 同向（Hughes & Möller, 1999），至于 $\mathbf{u}$、$\mathbf{v}$ 具体是什么则无所谓。单个向量不足以唯一确定答案；我们只需要一个稳健的构造过程，得到任意一个可行基即可。

这可以借助叉积完成，步骤如下。首先令 $\mathbf{w}$ 为 $\mathbf{a}$ 方向上的单位向量：

$$\mathbf{w} = \frac{\mathbf{a}}{\|\mathbf{a}\|}$$

然后任选一个与 $\mathbf{w}$ 不共线的向量 $\mathbf{t}$，用叉积构造垂直于 $\mathbf{w}$ 的单位向量 $\mathbf{u}$：

$$\mathbf{u} = \frac{\mathbf{t} \times \mathbf{w}}{\|\mathbf{t} \times \mathbf{w}\|}$$

如果 $\mathbf{t}$ 与 $\mathbf{w}$ 共线，分母将为零；即使只是几乎共线，结果也会损失精度。一个简单可靠的选 $\mathbf{t}$ 的方法是：从 $\mathbf{t} = \mathbf{w}$ 出发，把 $\mathbf{t}$ 中绝对值最小的分量改为 1。例如，若 $\mathbf{w} = (1/\sqrt{2}, -1/\sqrt{2}, 0)$，则取 $\mathbf{t} = (1/\sqrt{2}, -1/\sqrt{2}, 1)$。

得到 $\mathbf{w}$ 和 $\mathbf{u}$ 后，完成基的构建就很简单：

$$\mathbf{v} = \mathbf{w} \times \mathbf{u}$$

这类构建的一个例子是表面着色：需要一个与表面法线对齐的基，但绕法线的旋转通常无关紧要。

### 2.4.7 从两个向量构建基（Constructing a Basis from Two Vectors）

上一节的方法同样适用于基绕给定向量旋转也重要的情况。一个常见例子是为相机构建基：需要一个与相机观察方向对齐的向量，但相机绕该方向的方向并非任意，需要以某种方式指定。一旦方向确定，基就完全确定了。

完全指定一个坐标系的常见做法是提供两个向量：$\mathbf{a}$（指定 $\mathbf{w}$）与 $\mathbf{b}$（指定 $\mathbf{v}$）。若已知两向量垂直，则只需用 $\mathbf{u} = \mathbf{b} \times \mathbf{a}$ 构造第三个向量。

为了确保结果基真正标准正交（即使输入向量并不完全标准），建议采用与单向量构造非常相似的过程：

$$\mathbf{w} = \frac{\mathbf{a}}{\|\mathbf{a}\|}$$

$$\mathbf{u} = \frac{\mathbf{b} \times \mathbf{w}}{\|\mathbf{b} \times \mathbf{w}\|}$$

$$\mathbf{v} = \mathbf{w} \times \mathbf{u}$$

实际上，即使 $\mathbf{a}$ 与 $\mathbf{b}$ 不垂直，这个过程也依然有效。此时 $\mathbf{w}$ 严格沿 $\mathbf{a}$ 方向构造，而 $\mathbf{v}$ 取所有垂直于 $\mathbf{w}$ 的向量中最接近 $\mathbf{b}$ 的那个。

若 $\mathbf{a}$ 与 $\mathbf{b}$ 共线，这个过程就会失效：此时 $\mathbf{b}$ 无法帮助选择垂直于 $\mathbf{a}$ 的特定方向——它垂直于所有这些方向。

在相机定位的例子中（第4.3节），我们要构建一个坐标系，使 $\mathbf{w}$ 平行于相机观察方向，$\mathbf{v}$ 指向相机顶部。为使相机保持竖直，我们以正上方向为参考向量，围绕视线方向构建基，以此确定相机绕视线的朝向。让 $\mathbf{v}$ 尽量接近正上方，正好符合“保持相机竖直”的直观含义。

### 2.4.8 基的正交化（Orthonormalizing a Basis）

有时你会发现，计算中的问题源于本应标准正交的基混入了误差——例如计算中的舍入误差，或基以低精度存储在文件中。

可以借助上一节的方法：仅用现有的 $\mathbf{w}$、$\mathbf{v}$ 向量重建基，即可得到一组接近原基的标准正交基。

这种方法对许多应用都足够好，但不是最优的。它确实能产生精确正交的向量，对接近标准正交的初始基，结果也不会偏离起点太远。但该过程是非对称的：它“偏爱” $\mathbf{w}$ 胜过 $\mathbf{v}$，又胜过 $\mathbf{u}$（$\mathbf{u}$ 的初始值被舍弃）。它选出的基接近初始基，却不能保证是最接近的那一个。当这一要求还不够时，可以使用奇异值分解（singular value decomposition, SVD，见第5.4.1节）来求与原始基最接近的标准正交基。

## 2.5 积分（Integrals）

图形学可能给人一个误解：既然它充满积分，就必然要求擅长代数求解积分。事实绝非如此。图形学中的大多数积分都无法解析求解，需要借助数值方法。一个人完全可以在图形学领域拥有辉煌的职业生涯，却从未用代数方法求过一个积分。

虽然不必会代数求解积分，但确实需要能“读”懂积分，以便对其作数值求解。一维情况下，积分通常相当易读。例如，积分

$$\int_{\pi}^{2\pi} \sin(x) dx$$

可以理解为“计算函数 $\sin(x)$ 在 $x = \pi$ 与 $x = 2\pi$ 之间的面积”。计算机科学背景的读者可以把这一部分：

$$\int_{\pi}^{2\pi} dx$$

看作一个函数调用。我们可以称之为 `integrate()`：它接收两个对象——一个函数和一个定义域（区间）。于是整个调用可以是：

```c
float area = integrate(sin(), [pi, 2*pi]);
```

在更高级的微积分中，我们可能要在球面上积分；对图形学来说，令人欣慰的是仍可沿用这种思路：

```c
float area = integrate(cos(), unit_sphere)
```

这个函数内部的机制可能不同，但所有积分都有两个要素：

1. 被积函数（integrand）
2. 积分的定义域（domain of integration）

通常，诀窍就是仔细辨认手头问题的第 1 点和第 2 点分别是什么。这与从有时令人困惑的文档中正确理解 API 调用，在精神上非常相似。

### 2.5.1 平均值和加权平均值（Averages and Weighted Averages）

积分计算的是“总和”：长度、面积、体积等。但它们也经常被用来计算平均值。例如，在一个区域（如一个国家）上对高程积分，可以得到该区域的总体积：

```c
float volume = integrate(elevation(), country)
```

同样可以计算平均高程：

```c
float averageElevation = integrate(elevation(), country) / integrate(1, country)
```

这本质上就是“体积除以面积”，可抽象为：

```c
float averageElevation = average(elevation, country)
```

还可以计算加权平均值（weighted average）：引入一个权重函数，让某些点在平均值中占更大比重。例如，想按温度对区域的各部分加权（这一选择相当随意，下一节会看到更多与图形学相关的例子）：

```c
float weightedAverageElevation =
    integrate(temperature() * elevation(), country) /
    integrate(temperature(), country)
```

留意这种形式很有好处：积分中经常隐含加权平均而没有明说，识别出来往往有助于理解。

写成数学表达式为：

**平均值**：
$$\text{平均高程} = \frac{\int_{\text{country}} \text{elevation}(\mathbf{x}) \, d\mathbf{x}}{\int_{\text{country}} 1 \, d\mathbf{x}}$$

**加权平均值**：
$$\text{加权平均高程} = \frac{\int_{\text{country}} \text{temperature}(\mathbf{x}) \cdot \text{elevation}(\mathbf{x}) \, d\mathbf{x}}{\int_{\text{country}} \text{temperature}(\mathbf{x}) \, d\mathbf{x}}$$

### 2.5.2 立体角积分（Integrals over Solid Angles）

我们经常见到的一类积分具有如下形式（或其变体）：

```c
float shade = integrate(cos() * f(), unit_hemisphere)
```

注意，由于 `integrate(cos(), unit_hemisphere) = pi`，加权平均版本就是：

```c
float shade = integrate((1/pi) * cos() * f(), unit_hemisphere)
```

这个积分的更传统形式是：

$$S = \int_{\mathbf{v} \in H} \frac{1}{\pi} (\mathbf{v} \cdot \mathbf{n}) f(\mathbf{v}) (\mathbf{v} \cdot \mathbf{n}) d\sigma(\mathbf{v})$$

或者采用球面坐标（正如我们可能为代数求解这些积分所做的那样）：

$$S = \int_{\phi=0}^{2\pi} \int_{\theta=0}^{\pi/2} \frac{1}{\pi} f(\theta,\phi) \cos\theta \sin\theta \, d\theta \, d\phi$$

正弦项是球面坐标中的面积修正因子。注意，在图形学中我们很少需要完整写出这些积分，而是在数值求解时使用不显式依赖坐标的更简单形式。

上述特定积分正是理想漫反射（朗伯，Lambert）表面的着色值，也是所有入射颜色的加权平均值。这种结构对直觉理解很有帮助：表面的颜色通常与入射颜色的加权平均值密切相关。

立体角上的积分几乎总是大同小异，只是记号五花八门。关键在于识别出这不过是记号差异，并把眼前的记号映射到自己最熟悉的记号上——这很像读伪代码！

**重要说明**：在这个积分中：
- $\mathbf{v} \cdot \mathbf{n}$ 是入射方向与表面法向量的点积，即 $\cos\theta$
- $f(\mathbf{v})$ 是从方向 $\mathbf{v}$ 入射的光强度
- $H$ 表示单位半球
- $d\sigma(\mathbf{v})$ 是立体角微元
- $\frac{1}{\pi}$ 是归一化因子，确保完美漫反射表面的反射率为1

## 2.6 密度函数（Density Functions）

密度函数在图形学中经常出现（例如“概率密度函数”），有时会令人意外地困惑；但弄清其确切含义，既有助于正确使用它们，也能在困惑时找到出路。我们知道函数是什么，而密度函数就是返回密度的函数。那么什么是密度？密度是“单位某物中的量”，更正式地说，是一种强度量（intensive quantity）。例如，体重不是密度：它是广延量（extensive quantity），是“物质的量”，而不是“每单位某物中的物质量”。一个人在固定时期（比如一年）内增加的体重，是某种物质的量，以千克计量，因此是广延量而非密度；而“每天”或“每小时”增加的体重则是强度量，因而是密度。

举一个非密度函数的例子：太阳能电池板在特定一天（2014年7月1日）产生了 120 千焦耳能量。这固然不错，但够不够驱动我的计算机呢？如果是台式机，计算机需要的是能量密度，即能量的速率，才能判断能否持续工作。那么如何把这一天的能量转换成能量速率？办法是把它按时间段切分：例如切成四小时、两小时或一小时的区间。我们会发现速率在一天内不断变化；同时，如图2.22所示，随着时间段越切越短，每个区间内的能量也越来越小。

![Figure2-42](Figure2-42.png)

把时间不断细分到分钟、秒，我们能获得越来越多随时间变化的信息，但每个柱条（bin）的高度会小到几乎看不见。于是我们可以按柱条的宽度重新标定其高度，即 (30 kJ)/(0.5 h) = 60 kJ/h。

改用“千焦/小时”这个度量后，柱条的高度不再随区间缩短而变矮，如图2.23所示。把这一过程推向极限，让柱条宽度趋于无穷小，就得到一条光滑曲线。

![Figure2-42](Figure2-43.png)

这条曲线就是**密度函数**（density function）的一个例子。有人会称它为“能量密度”函数——密度的维度是时间；在某些语境下也叫“单位时间能量密度”函数。因为这个密度十分常用，它有自己的专门名称——**功率**（power）：我们不说“焦耳每小时”，而说**瓦特**（watt）。注意，按惯例“瓦特”指焦耳每秒而非每小时；选择特定单位而非维度只是为了方便。例如，某些物理量用米更合适，另一些用千米或纳米更合适（还有一些量，比如光的光谱辐射亮度，同一量中米和纳米都会出现——所以当你感到困惑时，并不是你的错）。

总结一下：**(1) 密度总是一个比率**——即“每单位 Y 有多少 X”或“每 Y 有多少 X”，例如“每小时多少千米”（若说“每单位长度多少千米”会显得奇怪，但只要大家都同意默认的长度单位，就说得通）；**(2) 密度函数就是返回密度的函数。**

密度函数本身很适合比较两个不同点的相对密集程度。例如，借助按时间定义的能量密度（功率），我们可以说“下午 2 点的功率是上午 9 点的两倍”。另一种用法是通过积分计算某个区间内的总量。例如，要计算下午 2 点到 4 点之间产生的能量，只需积分：

$$E = \int_{2\text{pm}}^{4\text{pm}} P(t) \, dt$$

许多积分本质上都是“对密度函数积分”，只是没有明说。如果能在积分中辨认出它是在对某个区间或区域上的密度求“总量”，事情往往会清晰很多。

**关键要点**：
- 密度函数描述的是强度量（每单位某物的量）
- 对密度函数积分可得到广延量（总量）
- 在图形学中，这一概念广泛应用于概率密度函数、辐射度量等

## 2.7 曲线和曲面（Curves and Surfaces）

曲线几何，尤其是曲面几何，在图形学中处于核心地位。本节回顾二维与三维空间中曲线和曲面的基础知识。

### 2.7.1 二维隐式曲线（2D Implicit Curves）

直观地说，曲线是纸上一笔不间断画出的点的集合。描述曲线的一种常见方式是隐式方程（implicit equation）。二维隐式方程的形式为：

$$f(x,y) = 0$$

函数 $f(x,y)$ 返回实数值：使之为零的点 $(x,y)$ 位于曲线上，使之为非零的点不在曲线上。例如，设 $f(x,y)$ 为：

$$f(x,y) = (x-x_c)^2 + (y-y_c)^2 - r^2 \tag{2.9}$$

其中 $(x_c, y_c)$ 是二维点，$r$ 是非零实数。令 $f(x,y) = 0$，满足该方程的点位于以 $(x_c, y_c)$ 为圆心、$r$ 为半径的圆上。之所以称其为“隐式”方程，是因为曲线上的点 $(x,y)$ 无法直接从方程算出，而必须通过求解方程确定。也就是说，曲线上的点并非由方程显式生成，而是隐含在方程之中。

![Figure2-22](Figure2-22.png)

有趣的是，$f$ 对一切 $(x,y)$ 都有定义。可以把 $f$ 想象成地形，海平面位于 $f = 0$（图2.22）：海岸线就是隐式曲线，$f$ 的取值就是海拔高度。另一点要注意的是，曲线把空间划分为 $f > 0$、$f < 0$ 和 $f = 0$ 三个区域，因此只需计算 $f$ 就能判断点是否在曲线“内部”。注意，对任意常数 $c$，$f(x,y) = c$ 都定义一条曲线，$c = 0$ 只是惯例上的选择。例如，若 $f(x,y) = x^2 + y^2 - 1$，改变 $c$ 只会得到以原点为中心的一系列同心圆（图2.23）。

![Figure2-23](Figure2-23.png)

向量可以简化记号。设 $\mathbf{c} = (x_c, y_c)$、$\mathbf{p} = (x, y)$，则以 $\mathbf{c}$ 为圆心、$r$ 为半径的圆由满足下式的位置向量 $\mathbf{p}$ 定义：

$$(\mathbf{p} - \mathbf{c}) \cdot (\mathbf{p} - \mathbf{c}) - r^2 = 0$$

这个方程若展开，将得到方程(2.9)；但通过几何方式“读”它更容易看出这是圆的方程。它的意思是：“圆上的点 $\mathbf{p}$ 满足：从 $\mathbf{c}$ 指向 $\mathbf{p}$ 的向量与自身的点积等于 $r^2$。”由于向量与自身的点积就是其长度的平方，也可以理解为：“圆上的点 $\mathbf{p}$ 满足：从 $\mathbf{c}$ 到 $\mathbf{p}$ 的向量长度平方为 $r^2$。”

更好的理解是，长度平方正是从 $\mathbf{c}$ 到 $\mathbf{p}$ 的距离平方，这提示了等价形式：

$$\|\mathbf{p} - \mathbf{c}\|^2 - r^2 = 0$$

当然，这又提示：

$$\|\mathbf{p} - \mathbf{c}\| - r = 0$$

上式可以理解为“圆上的点 $\mathbf{p}$ 是与中心 $\mathbf{c}$ 距离为 $r$ 的点”，这是圆的最佳定义之一。由此可见，方程的向量形式通常比展开的笛卡尔形式（含 $x$、$y$）更具几何直观。因此，应尽可能使用向量形式。此外，代码中可以提供向量类，用向量形式写出的代码更清晰，也更不易出错：一旦向量类型在代码中实现并调试完毕，那些涉及 $x$、$y$、$z$ 的复制粘贴错误便不会再出现。习惯用向量书写这些方程需要一点时间，但一旦掌握，回报巨大。

### 2.7.2 二维梯度（2D Gradients）

若把函数 $f(x,y)$ 看作高度场（高度 $= f(x,y)$），则梯度向量指向最陡的上坡方向。梯度向量 $\nabla f(x,y)$ 由下式给出：

$$\nabla f(x,y) = \left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}\right)$$

在隐式曲线 $f(x,y) = 0$ 上某点处，梯度向量垂直于该点处曲线的切向量。这个垂直向量通常称为曲线的法向量。此外，由于梯度指向上坡方向，它指示了 $f(x,y) > 0$ 区域所在的一侧。

![Figure2-24](Figure2-24.png)

在高度场的背景下，偏导数与梯度的几何意义比平时更加清晰。假设在点 $(a,b)$ 附近 $f(x,y)$ 近似为一个平面（图2.24）。该平面存在确定的上坡与下坡方向；与之垂直的方向是平面内“等高”的方向。平面与 $f(x,y) = 0$ 平面的任何交线都沿着这样的等高方向，因此上坡/下坡方向垂直于交线 $f(x,y) = 0$。要理解偏导数为何与此相关，需要看清其几何意义。回忆一元函数 $y = g(x)$ 的通常导数定义为：

$$\frac{dy}{dx} = \lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} \equiv \lim_{\Delta x \to 0} \frac{g(x+\Delta x) - g(x)}{\Delta x} \tag{2.10}$$

它度量的是 $g$ 的切线斜率（图2.25）。

![Figure2-25](Figure2-25.png)

偏导数是一维导数的推广。对于二元函数 $f(x,y)$，不能像方程(2.10)那样直接对 $x$ 取极限，因为 $x$ 变化时 $f$ 可能以多种方式随之变化。然而，若保持 $y$ 不变，就可以定义导数的类比——偏导数（partial derivative）（图2.26）：

$$\frac{\partial f}{\partial x} \equiv \lim_{\Delta x \to 0} \frac{f(x+\Delta x, y) - f(x, y)}{\Delta x}$$

![Figure2-26](Figure2-26.png)

为什么 $x$、$y$ 方向的偏导数恰好构成梯度向量的分量？这里同样是几何直观胜过代数推导。在图2.27中，向量 $\mathbf{a}$ 沿着 $f$ 不变的路径移动。注意，这里的尺度足够小，表面高度 $h(x,y) = f(x,y)$ 可以视为局部平面。由图可见 $\mathbf{a} = (\Delta x, \Delta y)$。

![Figure2-27](Figure2-27.png)

由于上坡方向垂直于 $\mathbf{a}$，二者点积为零：

$$(\nabla f) \cdot \mathbf{a} \equiv (x_{\nabla}, y_{\nabla}) \cdot (x_a, y_a) = x_{\nabla}\Delta x + y_{\nabla}\Delta y = 0 \tag{2.11}$$

同样，$f$ 沿方向 $(x_a, y_a)$ 的变化为零：

$$\Delta f = \frac{\partial f}{\partial x}\Delta x + \frac{\partial f}{\partial y}\Delta y \equiv \frac{\partial f}{\partial x}x_a + \frac{\partial f}{\partial y}y_a = 0$$

对任意两个垂直向量 $(x,y)$ 与 $(x',y')$，夹角为 90 度，点积为零（回忆点积与两向量夹角的余弦成正比），即 $xx' + yy' = 0$。给定 $(x,y)$，很容易构造与其点积为零的向量，最明显的两个是 $(y, -x)$ 与 $(-y, x)$；可以验证它们与 $(x,y)$ 的点积确实为零。该观察可推广为：$(x,y)$ 垂直于 $k(y, -x)$，其中 $k$ 为任意非零常数。这意味着：

$$(x_a, y_a) = k\left(\frac{\partial f}{\partial y}, -\frac{\partial f}{\partial x}\right) \tag{2.12}$$

结合方程(2.11)与(2.12)得到：

$$(x_{\nabla}, y_{\nabla}) = k'\left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}\right)$$

其中 $k'$ 为任意非零常数。按定义，“上坡”意味着 $f$ 沿正方向增大，因此应取 $k' > 0$；约定 $k' = 1$ 完全合理。

作为梯度的例子，考虑隐式圆 $x^2 + y^2 - 1 = 0$，其梯度为 $(2x, 2y)$，表明圆外是 $f(x,y) = x^2 + y^2 - 1$ 的正区域。注意，梯度长度可能因隐式方程的乘数而不同：例如，单位圆也可写作 $Ax^2 + Ay^2 - A = 0$，其中 $A$ 为任意非零数，此时梯度为 $(2Ax, 2Ay)$，依然垂直于圆，但长度由 $A$ 决定。$A > 0$ 时法向量指向圆外，$A < 0$ 时指向圆内。法向量由指向圆外翻转为指向圆内是正确的，因为正区域也从圆外切换到了圆内。从高度场的角度看，$h = Ax^2 + Ay^2 - A$ 在圆上为零高度：$A > 0$ 时圆围着一个凹坑，$A < 0$ 时圆围着一个凸丘。当 $A$ 变得更负，凸丘升高而 $h = 0$ 的圆保持不变：最陡上坡方向不变，但坡度变陡，梯度的长度正反映了这一变化。因此直观上，可以把梯度的方向理解为上坡方向，其大小度量坡度陡缓。

#### 隐式二维直线（Implicit 2D Lines）

直线常见的“斜截式”（slope-intercept form）为：

$$y = mx + b \tag{2.13}$$

这可以很方便地转换为隐式形式（图2.28）：

$$y - mx - b = 0 \tag{2.14}$$

![Figure2-28](Figure2-28.png)

其中 $m$ 是“斜率”（rise over run），$b$ 是直线与 $y$ 轴交点处的 $y$ 值，通常称为 $y$ 截距。直线同样把二维平面分成两部分，只是这里的“内部”“外部”更直观地应称为“上方”与“下方”。

由于隐式方程可以乘以任意常数而不改变其为零的点集，对任意非零 $k$，$kf(x,y) = 0$ 表示同一条曲线。这使同一条直线有多种隐式形式，例如：

$$2y - 2mx - 2b = 0$$

斜截式不方便之处在于它无法表示 $x = 0$ 这类直线，因为此时 $m$ 必须为无穷大。因此更一般的形式往往更有用：

$$Ax + By + C = 0 \tag{2.15}$$

其中 $A$、$B$、$C$ 为实数。

设已知直线上两点 $(x_0, y_0)$ 与 $(x_1, y_1)$，什么样的 $A$、$B$、$C$ 能描述经过这两点的直线？由于这两个点都在直线上，它们必须满足方程(2.15)：

$$\begin{align}
Ax_0 + By_0 + C &= 0 \\
Ax_1 + By_1 + C &= 0
\end{align}$$

可惜我们有三个未知数 $A$、$B$、$C$，却只有两个方程。问题的根源在于隐式方程可以乘以任意常数。为方便起见，可以设 $C = 1$：

$$Ax + By + 1 = 0$$

但这会重蹈斜截式在无穷斜率时的覆辙：过原点的直线须满足 $A(0) + B(0) + 1 = 0$，这自相矛盾。例如，过原点、倾角 45 度的直线可写作 $x - y = 0$、$y - x = 0$，甚至 $17y - 17x = 0$，却无法写成 $Ax + By + 1 = 0$ 的形式。

![Figure2-29](Figure2-29.png)

遇到这类棘手的代数问题时，不妨以几何直观为指引。如第2.7.2节所讨论的，一个有用的工具是梯度。对直线 $Ax + By + C = 0$，梯度向量为 $(A, B)$，它垂直于直线（图2.29），并指向 $Ax + By + C$ 为正的一侧。已知直线上两点 $(x_0, y_0)$、$(x_1, y_1)$，它们之间的向量 $(x_1 - x_0, y_1 - y_0)$ 与直线平行，因而也垂直于梯度向量 $(A, B)$。回忆隐式方程具有任意缩放的性质，描述该直线的 $(A, B, C)$ 有无穷多组，我们只需要其中任意一组有效的。

可取任意垂直于 $(x_1 - x_0, y_1 - y_0)$ 的 $(A, B)$。按第2.7.2节的相同推理，$(A, B) = (y_0 - y_1, x_1 - x_0)$ 即满足要求。这意味着经过 $(x_0, y_0)$、$(x_1, y_1)$ 的直线方程为：

$$(y_0 - y_1)x + (x_1 - x_0)y + C = 0 \tag{2.16}$$

现在只需确定 $C$。由于 $(x_0, y_0)$、$(x_1, y_1)$ 都在直线上，代入其中任一点即可求出 $C$。代入 $(x_0, y_0)$ 得 $C = x_0y_1 - x_1y_0$，于是完整的直线方程为：

$$(y_0 - y_1)x + (x_1 - x_0)y + x_0y_1 - x_1y_0 = 0 \tag{2.17}$$

再次强调，这只是经过两点的无穷多个有效隐式方程之一；但该形式不含除法，因此对坐标为有限值的点不存在数值退化。方程(2.17)还有一个好处：只要斜截式存在，总可以把非 $y$ 项移到等号右边，再除以 $y$ 项的系数，转回斜截式：

$$y = \frac{y_1 - y_0}{x_1 - x_0}x + \frac{x_1y_0 - x_0y_1}{x_1 - x_0}$$

![Figure2-30](Figure2-30.png)

隐式直线方程的一个有趣性质是，可以用它求点到直线的有符号距离（signed distance）：$Ax + By + C$ 的值与点到直线的距离成正比（图2.30）。如图2.31所示，点到直线的距离等于向量 $k(A,B)$ 的长度，即：

$$\text{距离} = k\sqrt{A^2 + B^2} \tag{2.18}$$

![Figure2-31](Figure2-31.png)

对点 $(x,y) + k(A,B)$，$f(x,y) = Ax + By + C$ 的值为：

$$\begin{align}
f(x + kA, y + kB) &= Ax + kA^2 + By + kB^2 + C \\
&= k(A^2 + B^2) \tag{2.19}
\end{align}$$

这里的化简利用了 $(x,y)$ 在直线上、即 $Ax + By + C = 0$ 的事实。由方程(2.18)与(2.19)可知，点 $(a,b)$ 到直线 $Ax + By + C = 0$ 的有符号距离为：

$$\text{距离} = \frac{f(a,b)}{\sqrt{A^2 + B^2}}$$

所谓“有符号距离”，指其绝对值等于几何距离，且在直线一侧为正、另一侧为负。如果你的问题更希望某一侧为正，可以在同样有效的 $f(x,y) = 0$ 与 $-f(x,y) = 0$ 之间任选。注意，若 $(A,B)$ 为单位向量，则 $f(a,b)$ 直接就是有符号距离。我们可以给方程(2.17)乘以一个常数，使 $(A,B)$ 成为单位向量：

$$f(x,y) = \frac{y_0-y_1}{\sqrt{(x_1-x_0)^2 +(y_0-y_1)^2}}x + \frac{x_1-x_0}{\sqrt{(x_1-x_0)^2 +(y_0-y_1)^2}}y + \frac{x_0y_1-x_1y_0}{\sqrt{(x_1-x_0)^2 +(y_0-y_1)^2}} = 0 \tag{2.20}$$

注意，直接计算方程(2.20)中的 $f(x,y)$ 即可得到有符号距离，但构造该方程时需要开平方根。隐式直线对三角形光栅化（rasterization）非常有用（见第8.1.2节）。二维直线的其他形式将在第14章讨论。

#### 隐式二次曲线（Implicit Quadric Curves）

上一节中，线性函数 $f(x,y)$ 给出隐式直线 $f(x,y) = 0$。若 $f$ 是关于 $x$、$y$ 的二次函数，其一般形式为：

$$Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0$$

所得隐式曲线称为二次曲线（conic section）。二维二次曲线包括椭圆与双曲线，以及抛物线、圆和直线等特殊情况。

二次曲线的例子包括以 $(x_c, y_c)$ 为圆心、$r$ 为半径的圆：

$$(x - x_c)^2 + (y - y_c)^2 - r^2 = 0$$

以及轴对齐椭圆：

$$\frac{(x - x_c)^2}{a^2} + \frac{(y - y_c)^2}{b^2} - 1 = 0$$

其中 $(x_c, y_c)$ 为椭圆中心，$a$、$b$ 为两个半轴（图2.32）。

![Figure2-32](Figure2-32.png)

### 2.7.3 三维隐式曲面（3D Implicit Surfaces）

正如隐式方程可以定义二维曲线，它们同样可以定义三维曲面。与二维情形类似，隐式方程隐式地刻画了曲面上的点集：

$$f(x,y,z) = 0$$

位于曲面上的点 $(x,y,z)$ 代入 $f$ 得零，不在曲面上的点代入得非零值。可以通过计算 $f$ 判断点是否在曲面上，也可以通过 $f$ 的符号判断点位于曲面哪一侧，但通常不能显式构造出曲面上的点。用向量记号，这种关于 $\mathbf{p} = (x,y,z)$ 的函数写作：

$$f(\mathbf{p}) = 0$$

### 2.7.4 隐式曲面的表面法向量（Surface Normals of Implicit Surfaces）

表面法向量（surface normal，光照计算等需要）是垂直于表面的向量，表面上每一点的法向量都可能不同。正如梯度为二维隐式曲线提供法向量，隐式曲面上点 $\mathbf{p}$ 处的表面法向量由隐式函数的梯度给出：

$$\mathbf{n} = \nabla f(\mathbf{p}) = \left(\frac{\partial f(\mathbf{p})}{\partial x}, \frac{\partial f(\mathbf{p})}{\partial y}, \frac{\partial f(\mathbf{p})}{\partial z}\right)$$

推理与二维情形相同：梯度指向 $f$ 增长最快的方向，该方向垂直于 $f$ 保持恒定的所有切线方向。梯度指向 $f(\mathbf{p}) > 0$ 的一侧；在具体上下文中，可以把这一侧理解为“进入”表面或“远离”表面。

若 $f$ 的特定形式给出向内的梯度，而我们需要向外的梯度，那么曲面 $-f(\mathbf{p}) = 0$ 与 $f(\mathbf{p}) = 0$ 相同，只是梯度方向相反：

$$-\nabla f(\mathbf{p}) = \nabla(-f(\mathbf{p}))$$

### 2.7.5 隐式平面（Implicit Planes）

作为例子，考虑经过点 $\mathbf{a}$、法向量为 $\mathbf{n}$ 的无限平面。该平面的隐式方程为：

$$(\mathbf{p} - \mathbf{a}) \cdot \mathbf{n} = 0 \tag{2.21}$$

注意 $\mathbf{a}$、$\mathbf{n}$ 为已知量，$\mathbf{p}$ 是满足方程的任意未知点。其几何含义是：“从 $\mathbf{a}$ 指向 $\mathbf{p}$ 的向量垂直于平面法向量。”若 $\mathbf{p}$ 不在平面内，则 $(\mathbf{p} - \mathbf{a})$ 与 $\mathbf{n}$ 不成直角（图2.33）。

![Figure2-33](Figure2-33.png)

有时需要得到经过 $\mathbf{a}$、$\mathbf{b}$、$\mathbf{c}$ 三点的平面的隐式方程。该平面的法向量可由平面内任意两个向量的叉积求得，例如：

$$\mathbf{n} = (\mathbf{b} - \mathbf{a}) \times (\mathbf{c} - \mathbf{a})$$

由此可写出隐式平面方程：

$$(\mathbf{p} - \mathbf{a}) \cdot ((\mathbf{b} - \mathbf{a}) \times (\mathbf{c} - \mathbf{a})) = 0 \tag{2.22}$$

该方程的几何含义是：由 $\mathbf{p} - \mathbf{a}$、$\mathbf{b} - \mathbf{a}$、$\mathbf{c} - \mathbf{a}$ 张成的平行六面体体积为零，即三者共面。这仅在 $\mathbf{p}$ 与 $\mathbf{a}$、$\mathbf{b}$、$\mathbf{c}$ 共面时成立。该方程的完整笛卡尔形式由行列式给出（详见第5.3节）：

$$\begin{vmatrix}
x - x_a & y - y_a & z - z_a \\
x_c - x_a & y_c - y_a & z_c - z_a \\
x_b - x_a & y_b - y_a & z_b - z_a
\end{vmatrix} = 0 \tag{2.23}$$

该行列式可以展开（展开方法见第5.3节）成包含许多项的长表达式。

方程(2.22)与(2.23)等价，比较二者颇有启发。方程(2.22)易于几何解释，也能生成高效代码；此外，借助已经调试好的叉积、点积代码，还能避免把排版笔误编译进代码。方程(2.23)同样易于几何解释，只要实现了高效的 $3 \times 3$ 行列式函数，它也同样高效；若有 `determinant(a,b,c)` 函数可用，实现也不易出错。若把行列式函数改名为 `volume`，他人阅读代码时将一目了然。因此，方程(2.22)与(2.23)都能很好地映射为代码。

若把任一方程完全展开成 $x$、$y$、$z$ 分量的形式，极易产生笔误，而这些笔误往往仍能通过编译，尤其令人头疼。这是“简洁的数学带来简洁的代码，冗长的数学带来冗长的代码”的绝佳例证。

#### 三维二次曲面（3D Quadric Surfaces）

正如二元二次多项式在二维中定义二次曲线，关于 $x$、$y$、$z$ 的二次多项式在三维中定义二次曲面（quadric surface）。例如，球面可以写作：

$$f(\mathbf{p}) = (\mathbf{p} - \mathbf{c})^2 - r^2 = 0$$

轴对齐椭球面可以写作：

$$f(\mathbf{p}) = \frac{(x - x_c)^2}{a^2} + \frac{(y - y_c)^2}{b^2} + \frac{(z - z_c)^2}{c^2} - 1 = 0$$

#### 从隐式曲面构造三维曲线（Constructing 3D Curves from Implicit Surfaces）

人们或许希望能用单个方程 $f(\mathbf{p}) = 0$ 定义隐式三维曲线。然而，这类“曲线”都只是退化曲面，实践中很少有用。三维曲线可以通过两个隐式方程的交集构造：

$$\begin{cases}
f(\mathbf{p}) = 0 \\
g(\mathbf{p}) = 0
\end{cases}$$

例如，三维直线可以由两个隐式平面的交线形成。通常，使用参数曲线（parametric curve）更为方便；它们将在后续章节讨论。

### 2.7.6 二维参数曲线（2D Parametric Curves）

参数曲线由单个参数驱动，该参数可看作沿曲线连续移动的索引。这类曲线具有如下形式：

$$\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} g(t) \\ h(t) \end{pmatrix}$$

这里 $(x, y)$ 是曲线上的点，$t$ 是驱动曲线的参数。对给定的 $t$，由函数 $g$、$h$ 确定一个点。若 $g$、$h$ 连续，$t$ 的微小变化只会带来 $x$、$y$ 的微小变化；因此 $t$ 连续变化时，点将扫出一条连续曲线。这是很好的性质，因为借助参数 $t$ 可以显式构造出曲线上的点。

通常可以把参数曲线写成向量形式：

$$\mathbf{p} = \mathbf{f}(t)$$

其中 $\mathbf{f}$ 是向量值函数，$\mathbf{f}: \mathbb{R} \rightarrow \mathbb{R}^2$。这样的向量函数能写出非常简洁的代码，应尽可能使用。

可以把曲线看作位置关于时间的函数。曲线可以延伸至任意远处，也可能形成环路甚至自相交；还可以认为曲线在任一点都有速度。例如，点 $\mathbf{p}(t)$ 在 $t = -2$ 附近移动缓慢，而在 $t = 2$ 到 $t = 3$ 之间移动迅速。即使曲线并非真的描述运动点，讨论参数曲线时也常借用“运动点”的术语。

#### 二维参数直线（2D Parametric Lines）

经过点 $\mathbf{p}_0 = (x_0, y_0)$ 与 $\mathbf{p}_1 = (x_1, y_1)$ 的二维参数直线可以写作：

$$\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} x_0 + t(x_1 - x_0) \\ y_0 + t(y_1 - y_0) \end{pmatrix}$$

由于 $x$、$y$ 的公式结构相同，可以对 $\mathbf{p} = (x, y)$ 使用向量形式（图2.34）：

$$\mathbf{p}(t) = \mathbf{p}_0 + t(\mathbf{p}_1 - \mathbf{p}_0)$$

![Figure2-34](Figure2-34.png)

可这样从几何上理解该公式：“从 $\mathbf{p}_0$ 出发，朝 $\mathbf{p}_1$ 方向走一段由参数 $t$ 决定的距离。”这种形式的一个优点是 $\mathbf{p}(0) = \mathbf{p}_0$、$\mathbf{p}(1) = \mathbf{p}_1$。由于点随 $t$ 线性变化，$t$ 在 0 到 1 之间度量了 $\mathbf{p}_0$ 与 $\mathbf{p}_1$ 之间的比例距离；$t < 0$ 的点位于 $\mathbf{p}_0$ 的“外侧”，$t > 1$ 的点位于 $\mathbf{p}_1$ 的“外侧”。

参数直线也可以简洁地描述为一个点 $\mathbf{o}$ 和一个向量 $\mathbf{d}$：

$$\mathbf{p}(t) = \mathbf{o} + t\mathbf{d}$$

当 $\mathbf{d}$ 为单位向量时，直线即按弧长（arc length）参数化，此时 $t$ 精确度量沿直线的距离。任何参数曲线原则上都可以按弧长参数化，这显然非常方便，但并非所有曲线都能解析地化为此形式。

#### 二维参数圆（2D Parametric Circles）

圆心为 $(x_c, y_c)$、半径为 $r$ 的圆具有参数形式：

$$\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} x_c + r\cos\phi \\ y_c + r\sin\phi \end{pmatrix}$$

为了确保圆上每个点对应唯一的参数 $\phi$，可以限制其定义域：$\phi \in [0, 2\pi)$、$\phi \in (-\pi, \pi]$，或任何其他长度为 $2\pi$ 的半开区间。

轴对齐椭圆可以通过分别缩放 $x$、$y$ 的参数方程构造：

$$\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} x_c + a\cos\phi \\ y_c + b\sin\phi \end{pmatrix}$$

### 2.7.7 三维参数曲线（3D Parametric Curves）

三维参数曲线与二维情形非常相似：

$$\begin{align}
x &= f(t), \\
y &= g(t), \\
z &= h(t).
\end{align}$$

例如，绕 $z$ 轴的螺旋线可以写作：

$$\begin{align}
x &= \cos t, \\
y &= \sin t, \\
z &= t.
\end{align}$$

与二维曲线一样，函数 $f$、$g$、$h$ 定义在定义域 $D \subset \mathbb{R}$ 上。向量形式为：

$$\begin{bmatrix} x \\ y \\ z \end{bmatrix} = \mathbf{p}(t)$$

本章只详细讨论三维参数直线。一般的三维参数曲线将在第15章展开讨论。

#### 三维参数直线（3D Parametric Lines）

三维参数直线可以看作二维参数直线的直接推广，例如：

$$\begin{align}
x &= 2 + 7t, \\
y &= 1 + 2t, \\
z &= 3 - 5t.
\end{align}$$

这种写法既冗长，又不便于转换成代码变量，因此改写成向量形式：

$$\mathbf{p} = \mathbf{o} + t\mathbf{d}$$

在这个例子中，$\mathbf{o}$ 与 $\mathbf{d}$ 分别为：

$$\mathbf{o} = (2, 1, 3)$$
$$\mathbf{d} = (7, 2, -5)$$

注意这与二维情形非常相似。直观上，这条直线通过点 $\mathbf{o}$ 且平行于向量 $\mathbf{d}$。对任意 $t$，都能得到直线上的点 $\mathbf{p}(t)$。例如 $t = 2$ 时，$\mathbf{p}(t) = (2, 1, 3) + 2(7, 2, -5) = (16, 5, -7)$。这一基本概念与二维情形相同（图2.30）。

![Figure2-30](Figure2-30.png)

与二维情形一样，线段可以由三维参数直线加上区间 $t \in [t_a, t_b]$ 描述。两点 $\mathbf{a}$、$\mathbf{b}$ 之间的线段由 $\mathbf{p}(t) = \mathbf{a} + t(\mathbf{b} - \mathbf{a})$ 给出，其中 $t \in [0, 1]$。此时 $\mathbf{p}(0) = \mathbf{a}$、$\mathbf{p}(1) = \mathbf{b}$，而 $\mathbf{p}(0.5) = (\mathbf{a} + \mathbf{b})/2$ 是 $\mathbf{a}$、$\mathbf{b}$ 的中点。

射线（ray），即半直线（half-line），是定义在半开区间（通常为 $[0, \infty)$）上的三维参数直线。从现在起，我们将直线、线段与射线统称为“射线”。这种叫法虽不够严谨，却符合通用惯例，也能让讨论更简洁。

### 2.7.8 三维参数曲面（3D Parametric Surfaces）

参数化方法同样可用于定义三维空间中的曲面，与定义曲线的方式非常相似，区别在于需要两个参数来覆盖曲面的二维区域。这类曲面的形式为：

$$\begin{align}
x &= f(u,v), \\
y &= g(u,v), \\
z &= h(u,v).
\end{align}$$

或者用向量形式表示：

$$\begin{bmatrix} x \\ y \\ z \end{bmatrix} = \mathbf{p}(u,v)$$

![Figure2-35](Figure2-35.png)

**示例**：地球表面上的点可以用经度、纬度两个参数描述。若把原点设在地心、$r$ 为地球半径，则原点位于球心的球坐标系（图2.35）给出参数方程：

$$\begin{align}
x &= r\cos\phi\sin\theta, \\
y &= r\sin\phi\sin\theta, \\
z &= r\cos\theta.
\end{align} \quad (2.24)$$

理想情况下希望写成向量形式，但对这种特定参数形式而言并不可行。

我们还希望从给定的 $(x,y,z)$ 反求出对应的 $(\theta,\phi)$。若约定 $\phi \in (-\pi,\pi]$，利用公式(2.2)中的 atan2 函数即可轻松做到：

$$\theta = \arccos\left(\frac{z}{\sqrt{x^2 + y^2 + z^2}}\right)$$

对隐式曲面，函数 $f$ 的导数给出曲面法向量；对参数曲面，$\mathbf{p}$ 的导数同样蕴含曲面几何信息。

考虑函数 $\mathbf{q}(t) = \mathbf{p}(t, v_0)$。它定义了一条位于曲面内的参数曲线，由固定 $v = v_0$、仅改变 $u$ 得到，称为等参数曲线（isoparametric curve，有时简称 isoparm）。$\mathbf{q}$ 的导数给出该曲线的切向量；由于曲线在曲面内，$\mathbf{q}'$ 也位于曲面内。因为曲线只改变 $\mathbf{p}$ 的一个参数，$\mathbf{q}'$ 正是 $\mathbf{p}$ 关于 $u$ 的偏导数，记作 $\mathbf{p}_u$。同理，偏导数 $\mathbf{p}_v$ 给出 $u$ 固定时等参数曲线的切向量，即曲面的第二个切向量。

于是，$\mathbf{p}$ 的偏导数在曲面上任意一点给出两个切向量。曲面法向量可由二者的叉积得到：两者都与曲面相切，其叉积同时垂直于这两个切向量，即为曲面法向量。叉积的右手定则决定了曲面哪一侧是正面/外侧；本书约定向量

$$\mathbf{n} = \mathbf{p}_u \times \mathbf{p}_v$$

指向曲面外侧。

### 2.7.9 曲线和曲面总结（Summary of Curves and Surfaces）

**隐式曲线和曲面**：二维隐式曲线或三维隐式曲面由二元或三元标量值函数定义，$f : \mathbb{R}^2 \to \mathbb{R}$ 或 $f : \mathbb{R}^3 \to \mathbb{R}$，曲面由函数值为零的所有点组成：

$$S = \{\mathbf{p} | f(\mathbf{p}) = 0\}$$

**参数曲线**：二维或三维参数曲线由单变量的向量值函数定义，$\mathbf{p} : D \subset \mathbb{R} \to \mathbb{R}^2$ 或 $\mathbf{p} : D \subset \mathbb{R} \to \mathbb{R}^3$；当 $t$ 在整个定义域 $D$ 上变化时，曲线被扫出：

$$S = \{\mathbf{p}(t) | t \in D\}$$

**参数曲面**：三维参数曲面由二变量的向量值函数定义，$\mathbf{p} : D \subset \mathbb{R}^2 \to \mathbb{R}^3$，曲面由定义域中所有点 $(u,v)$ 的像组成：

$$S = \{\mathbf{p}(u,v) | (u,v) \in D\}$$

对于**隐式曲线和曲面**，法向量由 $f$ 的导数（梯度）给出；切向量（曲线）或切向量组（曲面）可通过构造基底从法向量推导得出。

对于**参数曲线和曲面**，$\mathbf{p}$ 的导数给出切向量（曲线）或切向量组（曲面）；法向量可通过构造基底从切向量推导得出。

## 2.8 线性插值（Linear Interpolation）

线性插值（linear interpolation）可能是图形学中最常用的数学运算。前面已经见过位置线性插值的例子：在二维和三维中，两个点 $\mathbf{a}$、$\mathbf{b}$ 由参数 $t$ 关联，形成直线 $\mathbf{p} = (1-t)\mathbf{a} + t\mathbf{b}$。之所以称为插值，是因为 $t = 0$ 和 $t = 1$ 时 $\mathbf{p}$ 恰好经过 $\mathbf{a}$ 与 $\mathbf{b}$。之所以是线性插值，是因为权重 $t$ 与 $1-t$ 都是 $t$ 的线性多项式。

另一种常见的线性插值针对 $x$ 轴上的一组位置：$x_0, x_1, \ldots, x_n$，每个 $x_i$ 对应一个高度 $y_i$。我们希望构造连续函数 $y = f(x)$ 插值这些数据点，使 $f$ 经过每个数据点，即 $f(x_i) = y_i$。在线性插值中，点 $(x_i, y_i)$ 之间用直线段连接，自然可以用参数直线方程表示这些线段。参数 $t$ 即 $x_i$ 与 $x_{i+1}$ 之间的比例距离：

$$f(x) = y_i + \frac{x - x_i}{x_{i+1} - x_i}(y_{i+1} - y_i) \quad (2.26)$$

由于权重函数是 $x$ 的线性多项式，这便是一次线性插值。

以上两个例子都符合线性插值的通用形式：变量 $t$ 从 0 变化到 1 时，对应从数据项 $A$ 过渡到数据项 $B$，中间值由函数 $(1-t)A + tB$ 给出。注意到公式(2.26)正是这种形式，其中：

$$t = \frac{x - x_i}{x_{i+1} - x_i}$$

## 2.9 三角形（Triangles）

三角形是二维和三维图形程序中最基本的建模图元（primitive）。通常，颜色等信息附着在三角形顶点上，再在三角形内部插值。让这类插值变得简单直接的坐标系是重心坐标（barycentric coordinates）；本节将从零开始推导这一概念。我们还将讨论二维三角形——在二维屏幕上绘制三角形图像之前，这是必须理解的基础。

### 2.9.1 二维三角形（2D Triangles）

设二维三角形由点 $\mathbf{a}$、$\mathbf{b}$、$\mathbf{c}$ 定义，可以首先求出它的面积：

$$\text{area} = \frac{1}{2}\begin{vmatrix} x_b-x_a & x_c-x_a \\ y_b-y_a & y_c-y_a \end{vmatrix}$$

$$= \frac{1}{2}(x_ay_b + x_by_c + x_cy_a - x_ay_c - x_by_a - x_cy_b) \tag{2.27}$$

该公式的推导见第5.3节。若 $\mathbf{a}$、$\mathbf{b}$、$\mathbf{c}$ 按逆时针顺序排列，面积为正，否则为负。

![Figure2-56](Figure2-56.png)

图形学中常需为三角形各顶点指定属性（如颜色），并在三角形内部平滑插值。实现方式有多种，最简单的是借助重心坐标。一种理解重心坐标的方式，是把它看作非正交坐标系——第2.4.2节对此有过简要讨论。这样的坐标系如图2.36所示，原点为 $\mathbf{a}$，从 $\mathbf{a}$ 指向 $\mathbf{b}$、$\mathbf{c}$ 的向量作为基向量。有了这个原点和基向量，任何点 $\mathbf{p}$ 都可以写成：

$$p = a + \beta(b-a) + \gamma(c-a) \tag{2.28}$$

重新整理方程(2.28)中的项，可以得到：

$$p = (1-\beta-\gamma)a + \beta b + \gamma c$$

人们通常定义新变量 $\alpha$ 来改善方程的对称性：

$$\alpha \equiv 1-\beta-\gamma$$

由此得到方程：

$$p(\alpha,\beta,\gamma) = \alpha a + \beta b + \gamma c \tag{2.29}$$

约束条件为：

$$\alpha + \beta + \gamma = 1 \tag{2.30}$$

重心坐标乍看像是抽象、不直观的构造，但实践证明它既强大又方便。可以这样联想：在一个拥有两组平行但互不垂直的街道的城市里，门牌号是怎么工作的？这种自然的系统本质上就是重心坐标，你会很快习惯它。

重心坐标对平面上所有点都有定义。它的一个特别好的性质是：点 $\mathbf{p}$ 位于由 $\mathbf{a}$、$\mathbf{b}$、$\mathbf{c}$ 构成的三角形内部，当且仅当：

$$0 < \alpha < 1,$$
$$0 < \beta < 1,$$
$$0 < \gamma < 1.$$

若一个坐标为 0、另两个在 0 到 1 之间，则点在边上；若两个坐标为 0、第三个为 1，则点在顶点上。重心坐标的另一个优点是，方程(2.29)其实是在以平滑方式混合三个顶点的坐标；同样的混合系数 $(\alpha,\beta,\gamma)$ 也可用于混合其他属性（如颜色），下一章就会看到。

给定点 $\mathbf{p}$，如何计算它的重心坐标？一种方法是把方程(2.28)写成关于未知数 $\beta$、$\gamma$ 的线性方程组并求解，再令 $\alpha = 1-\beta-\gamma$。该线性方程组为：

$$\begin{bmatrix} x_b-x_a & x_c-x_a \\ y_b-y_a & y_c-y_a \end{bmatrix} \begin{bmatrix} \beta \\ \gamma \end{bmatrix} = \begin{bmatrix} x_p-x_a \\ y_p-y_a \end{bmatrix} \tag{2.31}$$

虽然对方程(2.31)作代数求解很直接，但采用直接的几何解法往往更有效。

![Figure2.39](Figure2-39.png)

重心坐标的一个几何性质是：它们是到三角形各边所在直线的缩放有符号距离，如图2.39中的 $\beta$ 所示。回忆第2.7.2节：对直线 $f(x,y) = 0$，计算 $f(x,y)$ 得到的是点 $(x,y)$ 到该直线的缩放有符号距离。同样回忆：若 $f(x,y) = 0$ 是某条直线的方程，则对任意非零 $k$，$kf(x,y) = 0$ 表示同一条直线；改变 $k$ 会缩放距离，并决定直线两侧哪边为正的有符号距离、哪边为负。我们希望选取 $k$，使例如 $kf(x,y) = \beta$。由于 $k$ 只有一个未知数，可以用一个约束确定它：在点 $\mathbf{b}$ 处 $\beta = 1$。因此，若直线 $f_{ac}(x,y) = 0$ 经过点 $\mathbf{a}$、$\mathbf{c}$，则点 $(x,y)$ 的 $\beta$ 可如下计算：

$$\beta = \frac{f_{ac}(x,y)}{f_{ac}(x_b,y_b)}\tag{2.32}$$

$\gamma$、$\alpha$ 可类似求出。出于效率考虑，通常直接计算其中两个重心坐标，再用方程(2.30)求出第三个。

为得到经过两点 $\mathbf{p}_0$、$\mathbf{p}_1$ 的直线的“理想”形式，可以先用第2.7.2节的方法，求出经过顶点的一条有效隐式直线。方程(2.17)给出：

$$f_{ab}(x,y) \equiv (y_a-y_b)x+(x_b-x_a)y +x_ay_b-x_by_a = 0$$

注意 $f_{ab}(x_c,y_c)$ 未必等于 1，因此它可能不是我们寻求的理想形式。用 $f_{ab}(x_c,y_c)$ 去除，得到：

$$\gamma = \frac{(y_a-y_b)x+(x_b-x_a)y +x_ay_b-x_by_a}{(y_a-y_b)x_c +(x_b-x_a)y_c +x_ay_b-x_by_a}$$

引入除法难免让人担心除零，但只要三角形面积不接近零，就不会发生。$\alpha$、$\beta$ 也有类似公式，但通常只需其一：

$$\beta = \frac{(y_a-y_c)x+(x_c-x_a)y +x_ay_c-x_cy_a}{(y_a-y_c)x_b +(x_c-x_a)y_b +x_ay_c-x_cy_a}$$

$$\alpha = 1-\beta-\gamma$$

![Figure2.40](Figure2.40.png)

计算重心坐标的另一种方法是计算图2.40所示的子三角形面积 $A_a$、$A_b$、$A_c$。重心坐标遵循如下规则：

$$\alpha = A_a/A,$$
$$\beta = A_b/A,$$
$$\gamma = A_c/A,$$

其中 $A$ 为三角形面积。注意 $A = A_a + A_b + A_c$，因此只需两次加法即可得到 $A$，无需动用完整的面积公式。若采用有符号面积，该规则对三角形外的点依然成立，原因如图2.41所示。注意这些是有符号面积：只要 $A$ 与各子三角形面积使用同一套有符号面积计算方式，结果就正确。

### 2.9.2 三维三角形（3D Triangles）

重心坐标的精妙之处在于，它可以几乎无缝地推广到三维。设 $\mathbf{a}$、$\mathbf{b}$、$\mathbf{c}$ 为三维点，则上述表示依然成立：

$$\mathbf{p} = (1-\beta-\gamma)\mathbf{a} +\beta\mathbf{b} +\gamma\mathbf{c}$$

现在，当 $\beta$、$\gamma$ 变化时，我们扫过整个平面。

![Figure2.42](Figure2.42.png)

三角形法向量可由平面内任意两个向量的叉积求得（图2.42），最简单的是取三条边中的两条，例如：

$$\mathbf{n} = (\mathbf{b}-\mathbf{a})\times(\mathbf{c}-\mathbf{a})\tag{2.34}$$

注意该法向量不一定为单位长度，方向遵循叉积的右手定则。

三角形的面积可以通过叉积的长度求得：

$$\text{area} = \frac{1}{2}\|(\mathbf{b}-\mathbf{a})\times(\mathbf{c}-\mathbf{a})\|\tag{2.35}$$

注意这里不是有符号面积，不能直接用于计算重心坐标。不过可以观察到：同一平面内，顶点“顺时针”排列的三角形与“逆时针”排列的三角形，其法向量方向相反。

回顾：

$$\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\| \|\mathbf{b}\| \cos\phi$$

其中 $\phi$ 是两个向量之间的夹角。若 $\mathbf{a}$、$\mathbf{b}$ 平行，则 $\cos\phi = \pm 1$，这提供了一种判断两向量同向或反向的方法。

该性质与方程(2.33)、(2.34)、(2.35)相结合，提示我们采用以下公式：

$$\alpha = \frac{\mathbf{n} \cdot \mathbf{n}_a}{\|\mathbf{n}\|^2},$$

$$\beta = \frac{\mathbf{n} \cdot \mathbf{n}_b}{\|\mathbf{n}\|^2},$$

$$\gamma = \frac{\mathbf{n} \cdot \mathbf{n}_c}{\|\mathbf{n}\|^2},$$

其中 $\mathbf{n}$ 由顶点 $\mathbf{a}$、$\mathbf{b}$、$\mathbf{c}$ 按方程(2.34)计算；$\mathbf{n}_a$ 由顶点 $\mathbf{b}$、$\mathbf{c}$、$\mathbf{p}$ 按方程(2.34)计算，依此类推，即：

$$\mathbf{n}_a = (\mathbf{c}-\mathbf{b})\times(\mathbf{p}-\mathbf{b}),$$
$$\mathbf{n}_b = (\mathbf{a}-\mathbf{c})\times(\mathbf{p}-\mathbf{c}),$$
$$\mathbf{n}_c = (\mathbf{b}-\mathbf{a})\times(\mathbf{p}-\mathbf{a}).$$

## 2.10 离散概率（Discrete Probability）

概率论研究带有随机结果的现象；离散概率（discrete probability）指随机结果只有有限多个的情形。经典例子是六面骰子：每次投掷，骰子从集合 $\{1,2,3,4,5,6\}$ 中随机取值，各结果等概率出现。某个结果的概率即该结果出现的频率比例；所有可能结果的总频率比例为 1。因此每次投掷，每个面出现的概率都是 $\frac{1}{6}$。

随机性中比较令人困惑的一点，是要把“随机结果”（要么尚未发生，要么已经发生但我们不知道结果）与“已经掷出的骰子”区分开来。随机变量（random variable）是一个取值未知的单一数值，但它会以已知的概率从已知的可能性集合中取值。这里的“变量”沿用数学含义，与编程中的“变量”直接相关。随机变量的一个例子是 $X$，其中 $X$ = 骰子的最终结果。变量可以用任意符号；数学中常以大写字母 $X$ 表示随机变量，正如计算机科学中常以 $i$、$j$ 作循环变量。随机变量在计算机程序中有十分直接的应用：

```c
int X = rand_from(1,6)
```

这里 $X$ 是取值未知的变量，但我们知道程序运行时将得到六个值之一，且每个值的概率都是 $\frac{1}{6}$，这与随机变量“$X$ = 骰子的最终结果”的情形直接对应。

随机变量有两个常用性质：期望值（expected value）与方差（variance）。随机变量 $X$ 的期望值有时简称期望，通常记作 $E[X]$ 或 $E(X)$。更贴切的叫法或许是“期望平均值”，但标准术语并非如此；如果你这么说，熟悉标准术语的人会感到困惑。期望值就是所有“掷骰子”的平行宇宙中 $X$ 取值的平均值，计算方式是把每个结果乘以其概率后求和：

$$E[X] = \frac{1}{6}(1) + \frac{1}{6}(2) + \frac{1}{6}(3) + \frac{1}{6}(4) + \frac{1}{6}(5) + \frac{1}{6}(6) = 3.5$$

因此，对大量掷骰结果求平均，我们会“期望”得到接近 3.5 的值。

明知骰子只会掷出整数，却说“我期望骰子掷出 3.5”虽然不算荒谬，但这确实是个不幸的术语。该术语在各领域都相当标准；尽管有瑕疵，只要用心接受它，与其他领域的人讨论时就不会出现沟通障碍。

期望值告诉我们随机变量“趋向于”什么，却不能说明这种趋势需要多长时间才显现，也不能说明取值偏离均值有多远。例如，一个有 3 个面是 1、3 个面是 6 的骰子，期望值仍是 3.5，但其“偏离均值”的程度大于普通骰子。那么如何度量离散程度呢？

一种做法是计算相对 3.5 的平均偏差；但若带符号，平均偏差为零——掷出 1 时的 $-2.5$ 偏差会被掷出 6 时的 $+2.5$ 抵消。也可以取绝对偏差，但这样做既有实际困难（含绝对值的代数运算很棘手），也有理论问题。实践中更常用的做法是采用平均平方偏差，即方差：

$$V(X) = \text{average}((X - E[X])^2)$$

由于这是统计平均，该平均值就是期望值，因此：

$$V(X) = E[(X - E[X])^2]$$

对于骰子的情形，$E[X] = 3.5$，$X - E[X]$ 的取值分别为 $-2.5, -1.5, -0.5, 0.5, 1.5, 2.5$，因此 $(X - E[X])^2$ 的取值分别为 $6.25, 2.25, 0.25, 0.25, 2.25, 6.25$，故 $X$ 的方差（通常记作 $V(X)$）等于 $\frac{17.5}{6}$。

对方差公式作代数变换，可得到有时更便于使用的形式：

$$V(X) = E[X^2] - (E[X])^2$$

期望与方差有一些常用的代数性质。

例如，设 $X$、$Y$ 为两个随机变量，定义 $Z = X + Y$，$E[Z]$ 是多少？结果是：

$$E[Z] = E[X + Y] = E[X] + E[Y]$$

令人惊讶的是，即使 $X$、$Y$ 并非“统计独立”（statistically independent）——例如它们可能以某种方式相互影响——该公式依然成立。极端地说：掷出第一个骰子后，直接把第二个骰子设为相同点数，公式依然成立！这是非常强的性质，程序设计中常被默认使用而不加说明。

方差也有类似的线性性质，但仅当 $X$、$Y$ 独立时成立：

$$V(Z) = V(X + Y) = V(X) + V(Y)$$

一个反例即可说明该公式对相关变量不成立：掷出 $X$ 后，令 $Y$ 取骰子的相对面，即 $X=1$ 时 $Y=6$，$X=2$ 时 $Y=5$，$X=3$ 时 $Y=4$，依此类推。此时 $Z$ 恒为 7，方差为零；但 $X$ 的方差并非 0，也不等于独立情形下和方差应得的 $2 \times \frac{17.5}{6}$。

方差的缺点在于平方运算使其不够直观，因此常用其平方根——标准差（standard deviation），通常记作 $\sigma(X)$：

$$\sigma(X) = \sqrt{V(X)}$$

$\sigma(X + Y)$ 没有同样简洁的公式，因此方差的吸引力（拥有好公式）更加凸显。以骰子为例，标准差 $\sigma = \sqrt{\frac{17.5}{6}} \approx 1.7$。它“大致等于”距均值 3.5 的平均距离，但并不完全一致，因为实际的平均绝对距离是 1.5。因此，尽管在实践中把标准差当作平均绝对偏差的直觉几乎总是无害，最好还是牢记二者并不相同。

## 2.11 连续概率（Continuous Probability）

图形学中经常使用在某个连续范围内取值的随机变量，即连续随机变量（continuous random variable）。好消息是，离散随机变量的大部分内容都能直接沿用：术语、期望的定义与公式、方差的定义与公式等。但有一个重大区别：连续随机变量取任何特定值的概率都为零。

设 $X$ 为在 0 到 10 之间均匀分布的随机变量：

```c
X = continuous_random_from(-2.3, 10.9)
```

取到 1.7、$\pi$ 或 $e$ 的可能性是“相等”的；问题在于，精确取到 1.7 的概率是零。

密度函数恰好解决了这一问题。正如“焦耳每秒”那样，在一维情形下，我们可以使用“单位长度上的概率”。在上述 $X = \text{continuous\_random\_from}(-2.3, 10.9)$ 的例子中，度量概率的维度是长度。若长度采用某种未指明的单位，我们就说概率是“单位长度”上的度量。

## 2.12 蒙特卡洛积分（Monte Carlo Integration）

第2.5节讨论了如何“理解”积分，并把它抽象为 `integrate()` 函数。但这个函数该如何真正实现？图形学中最常用的方法是蒙特卡洛积分（Monte Carlo integration）。其代数推导往往又丑又吓人，但只要看看下面这个函数：

```cpp
float shade = average(f(), hemisphere)
```

直觉就会告诉我们正确答案：在半球上取一组随机点 $v_i$，计算 $f(v_i)$ 并求平均，例如：

```cpp
float sum = 0.0
N = 10000; // 或用户设置的其他大数
for (int i = 1; i <= N; i++) {
    vec3 v = random_point_on_hemisphere();
    sum = sum + f(v);
}
average = sum / N;
```

就这么简单！现在需要一个在单位半球上均匀取随机点的函数。最简单的方法是“拒绝采样”（rejection sampling）：先在单位立方体中反复取三个均匀随机数，从而在单位球内均匀取点：

```cpp
do {
    X = random_from(-1,1);
    Y = random_from(-1,1);
    Z = random_from(-1,1);
} while (X*X + Y*Y + Z*Z > 1);
```

然后按需翻转 $Z$，使其进入半球：

```cpp
if (Z < 0) Z = -Z;
```

最后把点投影到单位半球上：

```cpp
v = unit_vector(X, Y, Z);
```

以上处理的是平均值。一般积分又该怎么办？回想：

$$\text{average}(f(), \text{domain}) = \frac{\text{integrate}(f(), \text{domain})}{\text{integrate}(1, \text{domain})}$$

所以：

$$\text{integrate}(f(), \text{domain}) = \text{average}(f(), \text{domain}) \times \text{integrate}(1, \text{domain})$$

在半球的情形下，$\text{integrate}(1, \text{domain})$ 就是面积，即 $2\pi$。

因此，蒙特卡洛积分通常就是随机点平均值的常数倍，该常数即定义域的大小（长度、面积等）。

### 2.12.1 重要性采样（Importance Sampling）

当被求平均的函数在高值与低值之间起伏很大时，把样本集中在某些区域、再用权重修正非均匀性，往往对我们有利。概率密度函数（probability density function, PDF）正是合适的工具：知道了样本的 PDF，就等于直接度量了该区域被“过度采样”的程度。若使用非均匀样本，则有：

$$\text{积分} = \text{average\_of\_nonuniform\_samples}\left(\frac{f()}{p()}, \text{domain}\right)$$

该公式的精妙之处在于，它对均匀随机样本同样适用：此时 $p() = \frac{1}{\text{integrate}(1, \text{domain})}$，定义域的“大小”便编码在 PDF 中。

对任何蒙特卡洛重要性采样（importance sampling）问题，至少开始时可以遵循一套相当程式化的流程：

1. **识别函数 $f()$ 与积分定义域**（例如单位球面上的点或三角形上的点）。

2. **选择在该定义域上生成随机样本 $x_i$ 的方法**，并确保能计算出每个样本的 PDF $p(x_i)$。

3. **对许多 $x_i$ 计算比值 $\frac{f(x_i)}{p(x_i)}$ 的平均值**，这就是对积分的估计。

另一个巧妙之处是：任意 $p()$ 都可以使用，最终都会收敛到正确答案（注意，在 $f()$ 非零处 $p()$ 也必须非零）。选择不同的 $p()$ 只影响估计的收敛速度。因此，调试代码时通常先从常数 $p()$ 开始。

## 常见问题解答（Frequently Asked Questions）

### 为什么没有向量除法？

事实证明，向量没有“好”的除法对应物。不过，深入研究这个问题会引出四元数（quaternion）的概念（参见本章注释引用的 Hoffmann 的著作）。

### 多于三边的多边形有没有类似重心坐标的简洁工具？

遗憾的是没有。即便凸四边形也要复杂得多。这正是三角形成为图形学中最常见几何图元的原因之一。

### 三维直线有隐式形式吗？

没有。不过，两个三维平面的交线可定义一条三维直线，因此三维直线可以用两个三维隐式方程联立描述。

### 准蒙特卡洛（QMC）或蓝噪声采样与蒙特卡洛采样有何关系？

蒙特卡洛的核心思想是：对一批“公平”的样本求平均，即可估计真实平均值。这里的“公平”可按统计意义理解；但有些样本集合即使不是随机的，也可以证明其“公平”。准蒙特卡洛（quasi-Monte Carlo, QMC）正是这样的集合：它们具有明显的确定性结构，并非随机，但在形式上均匀（这种均匀性不是统计意义上的），通常比随机点集收敛得更快。蓝噪声（blue noise）样本集合则对样本施加约束以避免聚集；与 QMC 类似，它在不完全随机的情况下也能提高收敛性。

实践中，大多数技术先用蒙特卡洛的形式化框架开发（因为数学上更易处理），随后在代码中改用 QMC 或蓝噪声点集——这是基于经验上的信心：在实践中，均匀性往往就足够了。
