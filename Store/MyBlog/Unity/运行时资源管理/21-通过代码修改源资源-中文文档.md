# 通过代码修改源资源（Modify source assets from code）

> 来源：[Unity 6000.7 官方手册 · Modify source assets from code](https://docs.unity3d.com/6000.7/Documentation/Manual/ModifyingSourceAssetsThroughScripting.html)

你可以从运行时代码修改资源。根据资源类型和你使用的方法，修改可以是临时的，也可以是永久的。临时修改在退出 Play 模式时重置，永久修改在退出 Play 模式后仍然保留。

## 临时修改

应用运行时对资源的修改通常是临时的。例如，你可能想修改角色的材质着色器组件，以表现临时的无敌道具效果。此例中的着色器修改不是永久的，退出 Play 模式后不会保留。

以下示例通过更改材质组件的着色器属性来演示这一点：

```csharp
using UnityEngine;

public class ExampleScript : MonoBehaviour
{
    private Shader invincibleShader;

    void Start()
    {
        invincibleShader = Shader.Find("Specular");
    }

    public void StartInvincibility()
    {
        if (TryGetComponent<Renderer>(out Renderer renderer))
        {
            renderer.material.shader = invincibleShader;
        }
    }
}
```

退出 Play 模式后，[Material](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Material.html) 的状态会重置为进入 Play 模式之前的状态。访问 `renderer.material` 会自动实例化材质并返回该实例。此实例会同时自动应用到渲染器，因此你做出的任何更改都不会是永久的。

> **注意**：如果你声明一个保存材质引用的公共变量，并通过该变量修改，而不是直接修改 `renderer.material.shader` 类成员，你将无法获得修改应用前自动实例化的好处。

## 永久修改

> **重要提示**：这里介绍的方法会修改 Unity 中使用的实际源资源文件。这些修改无法撤销。请谨慎使用。

为避免材质在退出 Play 模式时重置，你可以使用 [Renderer.sharedMaterial](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Renderer-sharedMaterial.html)。`sharedMaterial` 属性返回渲染器实际使用的资源。

以下示例永久更改材质，使其使用 Specular 着色器，并且不会将材质重置为进入 Play 模式之前的状态：

```csharp
using UnityEngine;

public class ExampleScript : MonoBehaviour
{
    private Shader invincibleShader;

    void Start()
    {
        invincibleShader = Shader.Find("Specular");
    }

    public void StartInvincibility()
    {
        if (TryGetComponent<Renderer>(out Renderer renderer))
        {
            renderer.sharedMaterial.shader = invincibleShader;
        }
    }
}
```

### 适用的类与属性

前面描述的编程模式——使用局部属性进行临时更改，或使用共享属性进行永久更改——适用于以下资源类型：

| 资源类型 | 临时更改的属性 | 永久更改的属性 |
| --- | --- | --- |
| Material（材质） | [Renderer.material](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Renderer-material.html) | [Renderer.sharedMaterial](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Renderer-sharedMaterial.html) |
| Mesh（网格） | [MeshFilter.mesh](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/MeshFilter-mesh.html) | [MeshFilter.sharedMesh](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/meshFilter-sharedMesh.html) |
| 物理材质（Physics Materials） | [Collider.material](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Collider-material.html) | [Collider.sharedMaterial](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Collider-sharedMaterial.html) |

> **注意**：如果你声明这些类中任意一个的公共变量，并通过该变量修改资源，而不是使用相关的类成员，你将无法获得修改应用前自动实例化的好处。

### 不会自动实例化的资源

以下资源类型在修改时不会自动实例化：

- [Texture2D](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Texture2D.html)
- [TerrainData](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/TerrainData.html)

对这些资源从代码进行的任何修改都是永久的，无法撤销。例如，如果你从代码更改地形的高度图或纹理文件的像素，你需要手动处理实例化和赋值。
