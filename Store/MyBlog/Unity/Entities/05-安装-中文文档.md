# 安装（Installation）

> 来源：[Unity Package 官方文档 · Installation](https://docs.unity3d.com/Packages/com.unity.entities@6.6/manual/getting-started-installation.html)

要使用 Entities 包，你必须安装受支持的 Unity 版本。Entities 包兼容 Unity 2022.3 及更高版本。

[通过 Package Manager 窗口](https://docs.unity3d.com/Manual/upm-ui-actions.html)安装 Entities 包。如果你选择[按名称添加包](https://docs.unity3d.com/6000.0/Documentation/Manual/upm-ui-quick.html)选项，请使用 `com.unity.entities` 名称。

## IDE 支持

Entities 包使用 [Roslyn 源生成器](https://docs.microsoft.com/en-us/dotnet/csharp/roslyn-sdk/source-generators-overview)。因此，你应该使用与源生成器兼容的 IDE。旧版本的 IDE 可能会遇到速度变慢或将有效代码标记为错误的情况。以下 IDE 与源生成器兼容：

- Visual Studio 2022+
- Rider 2021.3.3+

## 禁用域重载（Domain Reload）

为了在 Entities 项目中获得最佳性能，请禁用 Unity 的 [Domain Reload](https://docs.unity3d.com/Manual/ConfigurableEnterPlayMode.html)（域重载）设置。有关如何禁用域重载的信息，请参阅[配置 Play mode 设置](https://docs.unity3d.com/Manual/ConfigurableEnterPlayMode.html)的文档。

有关禁用域重载影响的更多信息，请参阅[禁用域和场景重载的细节](https://docs.unity3d.com/Manual/ConfigurableEnterPlayModeDetails.html)文档。
