# AssetBundleModule（AssetBundle 模块）

## 描述

AssetBundle 模块实现了 AssetBundle 类及相关 API，用于从 AssetBundle 中加载数据。

## 类

| 类 | 说明 |
| --- | --- |
| [AssetBundle](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssetBundle.html) | 用于访问 AssetBundle 文件内容的 API。 |
| [AssetBundleCreateRequest](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssetBundleCreateRequest.html) | AssetBundle 的异步加载请求。 |
| [AssetBundleManifest](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssetBundleManifest.html) | 构建所生成的所有 AssetBundle 的清单（Manifest）。 |
| [AssetBundleRecompressOperation](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssetBundleRecompressOperation.html) | 将 AssetBundle 从一种压缩方式/级别异步重压缩为另一种。 |
| [AssetBundleRequest](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssetBundleRequest.html) | 从 AssetBundle 异步加载资源的请求。 |
| [AssetBundleUnloadOperation](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssetBundleUnloadOperation.html) | AssetBundle 的异步卸载操作。 |

## 枚举

| 枚举 | 说明 |
| --- | --- |
| [AssetBundleLoadResult](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssetBundleLoadResult.html) | AssetBundle 加载或重压缩操作的结果。 |
