## 概要（Summary）

要真正提升游戏的打磨程度，你应该为玩家角色的不同动作添加动画：一个待机动画、一个行走动画和一个攻击动画。

到本教程结束时，你将完成以下内容：

- 为 PlayerCharacter 游戏对象添加 Animator 组件，以便进行动画制作。
- 使用 Animation 窗口，用精灵表中的精灵为动画创建关键帧。
- 使用 Animator 窗口将玩家角色的动画状态连接起来，让每个动画之间流畅地衔接过渡。

## 1. 概述（Overview）

为了让游戏更有生气，让我们为它添加一些动画吧！动画不仅能通过增加视觉趣味来提升玩家的体验，还能让应用呈现出更高水准的打磨感和专业感。

## 2. 待机动画（Idle animation）

让我们从玩家的简单待机动画开始，这样即使玩家没有移动，画面上也仍然有一些视觉趣味。要为你的玩家角色添加待机动画，请按照以下说明操作：

1. 在 Hierarchy 窗口中选择 PlayerCharacter 游戏对象，并在 Inspector 窗口中为它添加 Animator 组件。

2. 在 Project 窗口中右键点击 Assets 文件夹，选择 Create > Folder，将新文件夹命名为 "Animation"。

3. 在 Animation 文件夹内右键点击，选择 Create > Animation > AnimatorController，添加一个 AnimatorController，命名为 "PlayerAnimator"。

4. 在 Hierarchy 窗口中选择 PlayerCharacter 游戏对象。在 Inspector 窗口的 Animator 组件下，选择 Controller 属性选择器（⊙），选择 PlayerAnimator。

5. 从主菜单中选择 Window > Animation > Animation，打开 Animation 窗口。

    在继续之前，Animation 窗口会要求你创建一个 Animation Clip（动画剪辑）。

6. 选择 Create 按钮，将新剪辑保存为 "Idle.anim"，放在你的 Animation 文件夹中。

    本教程不会详细讲解一切是如何运作的，只介绍如何创建和处理动画；如果你想了解更深入的信息，可以随时再去看看《2D 冒险游戏》课程。

7. 从 Project 窗口的 Sprites 文件夹（Roguelike2D > TutorialAssets > Sprites）中，把你想要用于待机动画的所有精灵一个一个地拖放到 Animation 窗口的时间轴上，将它们添加为新的关键帧。

    让精灵之间保持相同的间隔，以维持恒定的速度。

    注意：根据你选择使用的帧和主题，你的关键帧数量可能与上图所示不同。

    如果现在点击 Animation 窗口中的 Play 按钮，你会在 Scene 视图中看到玩家角色游戏对象上的动画预览。如果你像示例中那样放置精灵，动画可能会显得非常快。

时间轴顶部的数字由以下部分组成：

- 冒号（:）左边的数字是动画当前的秒数时间。
- 冒号（:）右边的数字是该秒内的帧号。

因此 0:15 表示动画第 0 秒的第 15 帧，3:40 表示动画第 3 秒的第 40 帧。

目前动画在 1 秒内有 60 帧，所以你可以看到数字会一直升到 0:59，然后才变成 1:00。

要让动画慢下来，你可以把每个精灵单独移动到动画中更靠后的帧上，但当一个动画只有几帧长时，一秒内 60 个可能的帧是很浪费的。不如改变每秒的帧数。

例如，如果你的动画有六帧，把采样率（sample rate）设为每秒三帧，动画就会持续两秒。

8. 打开时间轴旁边的 More（⋮）菜单，选择 Show Sample Rate，然后把左侧的 Samples 属性改为你帧数的大约一半（在我们的例子中是 3）。

    像往常一样，尽管试验不同的数值！

然后你需要重新排列精灵，因为当你更改采样率时，系统自动移动它们的方式可能会导致动画非常慢。缩小时间轴，移动每一帧，直到它们位于连续的帧上。

你的动画现在应该会以看起来更好的速度播放。

如果现在进入 Play 模式，玩家角色应该会在整个游戏过程中持续循环播放这个待机动画！

## 3. 行走动画（Walking animation）

现在，你可以为玩家在单元格之间行走时添加一个新动画：

1. 在 Animation 窗口中，保持 PlayerCharacter 游戏对象仍处于选中状态，打开 Idle 下拉菜单，选择 Create New Clip…。

2. 将新剪辑命名为 "Walk.anim"，保存到 Animation 文件夹中。

3. 从 Project 窗口的 Sprites 文件夹中，把行走动画精灵拖放到 Animation（译注：原文此处误写为 Animator）窗口的时间轴上，并编辑帧位置或帧速率，使其看起来令人满意。

    使用与上面相同的技巧，把采样率改成让你的角色行走看起来好看的值。

动画创建完成后，你需要一种只在玩家角色行走时触发它的方式。为此，你将使用一个名为动画状态机（Animation State Machine）的新工具。

4. 从主菜单中选择 Window > Animation > Animator，打开 Animator 窗口。

    它应该包含你创建的两个动画对应的状态。如果你是以不同的方式创建动画，导致它们没有出现在那里，只需把 Project 窗口中的动画剪辑拖放到 Animator 窗口中即可添加它们。

5. 在 Animator 窗口中选择 Parameters 选项卡，点击 Add（+）按钮，选择 Bool，并重命名为 "Moving"。

    你将使用这个新参数作为触发器：当 Moving 布尔值为 true 时，创建从 Idle 到 Walk 状态的过渡。

6. 右键点击 Idle 状态，选择 Make Transition。

    会出现一个从 Idle 状态开始的箭头。

7. 选择 Walk 状态，创建 Idle 和 Walk 状态之间的过渡。

8. 选择过渡箭头，在 Inspector 窗口中显示其设置，然后取消勾选 Has Exit Time（有退出时间）复选框。

    如果启用了 Has Exit Time，那么只要该时间过去，从 Idle 到 Walk 的过渡就会发生。这不是你想要的；你希望 Idle 一直循环，直到 Moving 布尔值为 true，所以禁用 Has Exit Time 可以让动画循环。

9. 使用展开箭头（三角形）展开 Settings 部分，将 Transition Duration（过渡时长）属性设置为 0。

    这个时间允许从一个动画逐渐混合到另一个动画，但在 2D 应用中混合动画没有意义，因为你想要的是立即从一个状态切换到另一个状态。

10. 在 Inspector 窗口底部、Conditions（条件）部分下，点击 Add（+）按钮添加一个新条件。打开最左边的下拉菜单，选择 Moving，然后打开最右边的下拉菜单，选择 true。

    这会告诉控制器：当 Moving 参数设置为 true 时，需要把动画从 Idle 切换为 Walk。

重复以上步骤，但这次是从 Walk 到 Idle 动画。这一次，过渡会在 Moving 被设回 false 时触发。

注意：你可能会在控制台中看到一些关于过渡没有退出时间或没有任何条件的警告；这些警告可以安全地忽略，因为它们只出现在你禁用 Has Exit Time 之后、设置条件之前。

过渡设置好之后，你需要找到一种在代码中触发它的方式。你需要在 PlayerController 中做以下事情：

- 创建一个 Animator 类型的私有变量，用来存储 Animator Controller 组件。
- 添加一个 Awake 函数，使用 GetComponent 获取 Animator 组件。
- 在代码中凡是修改 IsMoving 变量的地方，你都需要在 Animator 组件的 Moving 布尔值上调用 SetBool 函数。

```csharp
public class PlayerController : MonoBehaviour
{
   . . .

   private Animator m_Animator;

   private void Awake()
   {
       m_Animator = GetComponent<Animator>();
   }
   . . .
  
   public void MoveTo(Vector2Int cell, bool immediate)
   {
       m_CellPosition = cell;

       if (immediate)
       {
           m_IsMoving = false;
           transform.position = m_Board.CellToWorld(m_CellPosition);
       }
       else
       {
           m_IsMoving = true;
           m_MoveTarget = m_Board.CellToWorld(m_CellPosition);
       }
      
       m_Animator.SetBool("Moving", m_IsMoving);
   }

   private void Update()
   {

        . . .

       if (m_IsMoving)
       {
           transform.position = Vector3.MoveTowards(transform.position, m_MoveTarget, MoveSpeed * Time.deltaTime);
          
           if (transform.position == m_MoveTarget)
           {
               m_IsMoving = false;
               m_Animator.SetBool("Moving", false);
               var cellData = m_Board.GetCellData(m_CellPosition);
               if(cellData.ContainedObject != null)
                   cellData.ContainedObject.PlayerEntered();
           }

           return;
       }
   }
}
```

注意：在 Animator 组件上进行基于字符串的查找效率不高，高效的方式是用 Animator.StringToHash 函数存储 Moving 的哈希引用。但对于这么小的游戏，而且这个函数不会经常被调用，保持原样也没问题。不过，你也可以随时通过查看 StringToHash 的文档来学习如何修复它。

## 4. 挑战（Challenge）

你有可以被伤害的墙壁，也有可以伤害它们的玩家角色。作为一项挑战，试着在玩家攻击墙壁时实现一个攻击动画。在查看下面的解决方案之前，先看看你能不能自己解决！

这是我们的解决方案：

1. 使用正确的精灵，为玩家角色创建一个新的攻击动画。

2. 在 Animator 窗口中，添加一个名为 Attack、类型为 Trigger（触发器）的新参数。

    Trigger 没有任何值；它是一种用于「只发生一次」的事情的参数类型。以攻击为例，动画应该在攻击发生时被触发，但你不希望玩家角色像移动那样停留在攻击状态；一旦攻击完成，玩家角色应该立即回到 Idle。

3. 创建从 Idle 到 Attack 的过渡，禁用 Has Exit Time，将 Transition Duration 设置为 0，并把 Attack 触发器参数选为条件。

    你会注意到，Attack 触发器参数不像 Moving 那样需要值。这是因为一旦你从代码中激活触发器，过渡就会发生。

4. 创建从 Attack 到 Idle 的过渡，并保持 Has Exit Time 启用。将 Exit Time 设置为 1，将 Transition Duration 设置为 0。

    你需要保持 Has Exit Time 启用，因为你希望 Attack 动画播放一次，然后通过这个过渡回到 Idle。将 Exit Time 设置为 1 可以确保整个攻击动画播放完毕后，过渡才开始。Transition Duration 需要设置为 0，因为 2D 动画中不能有混合！

5. 在代码中使用 m_Animator.SetTrigger("Attack") 来激活 Idle 到 Attack 的过渡。

    在哪里调用这个方法由你决定，但一些合理的位置包括：PlayerWantsToEnter 返回 false 时，或者在 PlayerController 中新增一个名为 "Attack" 的公共方法、让 WallObject 在受到伤害时调用它，等等。
