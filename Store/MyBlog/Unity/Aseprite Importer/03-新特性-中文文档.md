# 新特性（What's new）

> 来源：[Unity Package 官方文档 · What's new](https://docs.unity3d.com/Packages/com.unity.2d.aseprite@6.0/manual/whats-new.html)

## 1.2.0 版本的新特性

- 新增导入模式 **Tile Set**（瓦片集）：从 Aseprite 导入瓦片数据，并在导入时生成 Unity Tilemap 资源。
- 为生成的动画事件新增参数支持。
- 新增动画事件存储方式的选择：以独立事件存储，或分组后通过 `OnAnimationEvent(string)` 监听。
