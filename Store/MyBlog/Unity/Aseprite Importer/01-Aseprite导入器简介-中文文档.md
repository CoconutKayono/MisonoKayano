# Aseprite 导入器简介（Introduction to Aseprite Importer）

> 来源：[Unity Package 官方文档 · Introduction to Aseprite Importer](https://docs.unity3d.com/Packages/com.unity.2d.aseprite@6.0/manual/index.html)

Aseprite Importer 是一个资源导入器，用于将 [Aseprite](https://www.aseprite.org/) 的 `.ase` 和 `.aseprite` 文件导入 Unity。

请参阅 [Aseprite 功能支持](https://docs.unity3d.com/Packages/com.unity.2d.aseprite@6.0/manual/AsepriteFeatures) 了解导入器支持哪些 Aseprite 功能；参阅 [导入器功能](https://docs.unity3d.com/Packages/com.unity.2d.aseprite@6.0/manual/ImporterFeatures) 了解 Aseprite Importer 提供了哪些功能。

## 包版本

Aseprite Importer 包的不同版本分别由以下 Unity 版本支持：

| 包版本 | Unity 编辑器版本 |
| --- | --- |
| 6.x | 6.6 |
| 5.x | 6.5 |
| 4.x | 6.4 |
| 3.x | 6.3 |
| 2.x | 6.2 |
| 1.2.x | 6.1 |
| 1.1.x | 6.0、2022.3 和 2021.3 |
| 1.0.x | 6.0、2022.3 和 2021.3 |
