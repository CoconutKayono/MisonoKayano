# 导入器功能（Importer features）

> 来源：[Unity Package 官方文档 · Importer features](https://docs.unity3d.com/Packages/com.unity.2d.aseprite@6.0/manual/ImporterFeatures)

## 默认纹理设置

Aseprite Importer 会为生成的纹理设置以下默认设置：

| 设置 | 默认值 |
| --- | --- |
| **Texture type（纹理类型）** | Sprite |
| **Sprite mode（精灵模式）** | Multiple |
| **Pixel per unit（每单位像素）** | 100 |
| **Mesh type（网格类型）** | Tight |
| **Wrap mode（环绕模式）** | Clamp |
| **Filter mode（过滤模式）** | Point |
| **Compression（压缩）** | None |
| **Generate Mip Maps（生成 Mip 贴图）** | False |
| **Texture Max Size（纹理最大尺寸）** | 16384 |

## Aseprite Importer Inspector 属性

将 `.ase`/`.aseprite` 文件导入项目后，即可使用 Aseprite Importer。

### 常规（General）

| 属性 | 说明 |
| --- | --- |
| **Import Mode** | 文件的导入方式。默认设置为 **Animated Sprite**。选项：<br>**Sprite Sheet**：文件作为精灵表导入，可在 Sprite Editor 中切片。<br>**Animated Sprite**：以动画为目标导入文件。导入时会生成动画资源并附加到模型预制件上。<br>**Tile Set**：导入器查找文件中的所有瓦片数据，并在导入时生成 Unity Tilemap 资源。 |
| **Pixels Per Unit** | 设置等于一个 Unity 单位的像素数。 |
| **Mesh Type** | 设置 Unity 为 Sprite 生成的网格类型。默认设置为 **Tight**。选项：<br>[**Full Rect**](https://docs.unity3d.com/Documentation/ScriptReference/SpriteMeshType.FullRect.html)：Unity 将 Sprite 映射到矩形网格上。<br>[**Tight**](https://docs.unity3d.com/Documentation/ScriptReference/SpriteMeshType.Tight.html)：Unity 根据 Sprite 的轮廓生成网格。如果 Sprite 小于 32 x 32 像素，即使选择 **Tight**，Unity 也总是将其映射到 **Full Rect** 四边形网格上。 |
| **Generate Physics Shape** | 当 Sprite Editor 中未设置物理形状时，从 Sprite 的轮廓生成默认物理形状。 |

### 图层导入（适用于 Animated Sprites）

| 属性 | 说明 |
| --- | --- |
| **Include Hidden Layers** | 启用此属性可在导入中包含 `.ase`/`.aseprite` 文件的隐藏图层。此属性默认设置为 **False**。 |
| **Import Mode** | 使用此属性指定源文件中图层的导入方式。此属性默认设置为 **Merge Frame**。选项：<br>**Individual Layers**：每帧的每个图层都会生成一个 Sprite。<br>**Merge Frame**：默认选项。每帧的所有图层合并为一个 Sprite。 |
| **Pivot Space** | 选择枢轴（pivot）计算所在的空间。此属性默认设置为 **Canvas**。选项：<br>**Canvas**：根据 Sprite 在源资源画布上的位置计算枢轴。如果 Sprite 在动画中被替换，这很有用。<br>**Local**：在 Unity 中导入标准图像时使用的常规枢轴空间。 |
| **Pivot Alignment** | Sprite 图形矩形与其枢轴点的对齐方式。此属性默认设置为 **Bottom**。 |
| **Mosaic Padding** | 每个 SpriteRect 之间的外部填充。此属性默认设置为 **4** 像素。 |
| **Sprite Padding** | 每个 SpriteRect 内部的填充。此属性默认设置为 **0** 像素。 |

### 图层导入（适用于 Tile Set）

| 属性 | 说明 |
| --- | --- |
| **Mosaic Padding** | 每个 SpriteRect 之间的外部填充。此属性默认设置为 **4** 像素。 |

### 生成资源（适用于 Animated Sprites）

| 属性 | 说明 |
| --- | --- |
| **Model Prefab** | 启用此属性可生成与 Aseprite 中第一帧外观一致的模型预制件。此属性默认设置为 **True**。 |
| **Sorting Group** | 如果生成的模型预制件有多个 Sprite Renderer，则在其根上添加 Sorting Group 组件。此属性默认设置为 **True**。 |
| **Shadow Casters** | 启用此属性可为所有带 SpriteRenderer 的 GameObject 添加阴影投射器（Shadow Caster）。此属性默认设置为 **False**。注意：此复选框仅在 Unity 2023.1 及更新版本中可用。 |
| **Animation Clips** | 启用此属性可根据文件中的帧数据生成 Animation Clip。Aseprite 中的每个标签都会生成一个 Animation Clip。如果没有标签，则生成一个覆盖文件中所有帧的 Animation Clip。动画速度基于 Aseprite 中定义的恒定帧速率（Constant Frame Rate），长度基于标签/文件包含的帧数。此属性默认设置为 **True**。 |
| **Individual Events** | 启用此属性可让动画事件以各自的方法名生成。如果禁用，所有事件都会由 `OnAnimationEvent(string)` 方法接收。此属性默认设置为 **True**。 |
| **Export Animation Assets** | Animator Controller 和 Animation Clips 以只读资源的形式生成。此选项可用于导出这些资源的可编辑版本。 |

## Aseprite Importer 首选项

Aseprite Importer 首选项位于 **Unity > Settings > 2D > Aseprite Importer**。

| 属性 | 说明 |
| --- | --- |
| **Background import** | 启用此属性可在 Unity 编辑器位于后台时导入资源。此属性默认设置为 **True**。 |
