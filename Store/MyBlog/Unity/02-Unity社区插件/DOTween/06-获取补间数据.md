# 获取补间数据（Getting data from tweens）

## 静态方法（DOTween）

### PausedTweens / PlayingTweens

```cs
static List<Tween> PausedTweens()
static List<Tween> PlayingTweens()
```

返回所有处于暂停/播放状态的活跃补间列表；如果没有，则返回 `NULL`。

> [!WARNING]
> 调用这些方法会产生垃圾分配，因为每次调用都会生成一个新的 `List`。

### TweensById / TweensByTarget

```cs
static List<Tween> TweensById(object id, bool playingOnly = false)
static List<Tween> TweensByTarget(object target, bool playingOnly = false)
```

- `TweensById`：返回所有具有指定 id 的活跃补间列表；如果没有则返回 `NULL`。
- `TweensByTarget`：返回所有具有指定 target 的活跃补间列表；如果没有则返回 `NULL`。
  - 注意：使用快捷方式时 target 会自动设置；泛型方式不会。
  - 注意：DOTweenAnimation 可视化编辑器会把其 gameObject 设为 target（而不是 Transform、Material 等实际目标），想获取可视化创建的补间时要用它。
- **playingOnly**：`TRUE` 时只返回当前正在播放的补间。

> [!WARNING]
> 调用这些方法会产生垃圾分配，因为每次调用都会生成一个新的 `List`。

### IsTweening

```cs
static bool IsTweening(object idOrTarget, bool alsoCheckIfPlaying = false)
```

如果存在具有指定 id 或 target 的活跃补间，返回 `TRUE`。也可以用来判断某个目标上是否有快捷方式补间在运行。

- **alsoCheckIfPlaying**：`FALSE`（默认）时只要目标/id 上有活跃补间就返回 `TRUE`；`TRUE` 时还要求它正在播放。

```cs
transform.DOMoveX(45, 1); // transform 会自动成为补间目标
DOTween.IsTweening(transform); // 返回 TRUE
```

### 数量统计

```cs
static int TotalActiveSequences()    // 活跃 Sequence 总数（无论是否在播放）
static int TotalActiveTweens()       // 活跃补间总数（包含 Sequence 和 Tweener）
static int TotalActiveTweeners()     // 活跃 Tweener 总数
static int TotalPlayingTweens()      // 活跃且正在播放的补间总数（延迟播放也算播放中）
static int TotalTweensById(object id) // 指定 id 的活跃补间总数
```

```cs
int totalActiveSequences = DOTween.TotalActiveSequences();
int totalActive = DOTween.TotalActiveTweens();
int totalActiveTweeners = DOTween.TotalActiveTweeners();
int totalPlaying = DOTween.TotalPlayingTweens();
int totalTweensWithId = DOTween.TotalTweensById(someId);
```

## 实例方法（Tween/Tweener/Sequence）

### fullPosition

```cs
float fullPosition
```

获取和设置补间的时间位置（包含循环、不含延迟）。

### CompletedLoops

```cs
int CompletedLoops()
```

返回补间已完成的循环总数。

```cs
int completedLoops = myTween.CompletedLoops();
```

### Delay

```cs
float Delay()
```

返回补间设置的延迟（没有则为 0）。

```cs
float eventualDelay = myTween.Delay();
```

### Duration

```cs
float Duration(bool includeLoops = true)
```

返回补间的时长（不含延迟；includeLoops 为 `TRUE` 时包含循环）。

- 注意：使用 SpeedBased 等设置时，时长会在补间开始时重新计算。
- **includeLoops**：`TRUE` 返回含循环的总时长；`FALSE` 返回单个循环周期的时长。

```cs
float loopCycleDuration = myTween.Duration(false);
float fullDuration = myTween.Duration();
```

### Elapsed

```cs
float Elapsed(bool includeLoops = true)
```

返回补间当前已流逝的时间（不含延迟；includeLoops 为 `TRUE` 时包含循环）。

- **includeLoops**：`TRUE` 返回自启动以来的总流逝时间（含循环）；`FALSE` 返回当前循环周期内的流逝时间。

```cs
float loopCycleElapsed = myTween.Elapsed(false);
float fullElapsed = myTween.Elapsed();
```

### ElapsedDirectionalPercentage / ElapsedPercentage

```cs
float ElapsedDirectionalPercentage()
float ElapsedPercentage(bool includeLoops = true)
```

- `ElapsedDirectionalPercentage`：返回流逝百分比（0~1，不含延迟），基于单个循环计算；Yoyo 回程按 1→0 计算而不是 0→1。
- `ElapsedPercentage`：返回流逝百分比（0~1，不含延迟；includeLoops 为 `TRUE` 时含循环）。
  - **includeLoops**：`TRUE` 返回自启动以来的流逝百分比（含循环）；`FALSE` 返回当前循环周期内的百分比。

```cs
float loopCycleElapsedPerc = myTween.ElapsedPercentage(false);
float fullElapsedPerc = myTween.ElapsedPercentage();
```

### IsActive / IsBackwards / IsComplete / IsInitialized / IsPlaying / IsTimeScaleIndependent

```cs
bool IsActive()               // 补间已被杀死时返回 FALSE
bool IsBackwards()            // 补间被反转且设置为倒放时返回 TRUE
bool IsComplete()             // 补间完成时返回 TRUE（补间已被杀死则静默失败返回 FALSE）
bool IsInitialized()          // 补间已初始化时返回 TRUE
bool IsPlaying()              // 补间正在播放时返回 TRUE
bool IsTimeScaleIndependent() // 补间通过 tween.SetUpdate 设为 timeScale 独立时返回 TRUE
```

```cs
bool isActive = myTween.IsActive();
bool isBackwards = myTween.IsBackwards();
bool isComplete = myTween.IsComplete();
bool isInitialized = myTween.IsInitialized();
bool isPlaying = myTween.IsPlaying();
bool isTimeScaleIndependent = myTween.IsTimeScaleIndependent();
```

### Loops

```cs
int Loops()
```

返回补间被设置的循环总数。

```cs
int totLoops = myTween.Loops();
```

## 路径补间的实例方法

以下方法中，路径会在其补间开始后初始化；如果补间由 Path Editor 创建（DOTween Pro 功能），则立即初始化。也可以通过调用 `ForceInit` 强制初始化路径。

### PathGetPoint

```cs
Vector3 PathGetPoint(float pathPercentage)
```

根据给定的路径百分比返回路径上的一个点。如果不是路径补间、补间无效、或路径尚未初始化，返回 `Vector3.zero`。

- **pathPercentage**：要取点的路径百分比（0 到 1）。

```cs
Vector3 myPathMidPoint = myTween.PathGetPoint(0.5f);
```

### PathGetDrawPoints

```cs
Vector3[] PathGetDrawPoints(int subdivisionsXSegment = 10)
```

返回一组可用于绘制路径的点。如果不是路径补间、补间无效、或路径尚未初始化，返回 `NULL`。

- 注意：此方法会产生分配，因为它会创建新数组。
- **subdivisionsXSegment**：每个路径段（路径点到路径点）创建多少个点，仅对非 Linear 路径生效。

```cs
Vector3[] myPathDrawPoints = myTween.PathGetDrawPoints();
```

### PathLength

```cs
float PathLength()
```

返回路径的长度。如果不是路径补间、补间无效、或路径尚未初始化，返回 -1。

```cs
float myPathLength = myTween.PathLength();
```
