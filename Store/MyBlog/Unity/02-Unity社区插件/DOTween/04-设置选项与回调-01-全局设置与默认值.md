# 设置、选项与回调（一）：全局设置与默认值

DOTween 通过链式调用来设置补间的各种参数；你也可以修改全局默认选项，它们会应用到所有新建的补间上。

## 常规全局设置

### DOTween.logBehaviour

```cs
static LogBehaviour DOTween.logBehaviour
```

默认值：`LogBehaviour.ErrorsOnly`

根据所选模式，DOTween 只记录错误、错误与警告，或记录所有内容并附带额外信息。

- `LogBehaviour.ErrorsOnly`：只记录错误。
- `LogBehaviour.Default`：记录错误和警告。
- `LogBehaviour.Verbose`：记录错误、警告及附加信息。

### DOTween.maxSmoothUnscaledTime

```cs
static float DOTween.maxSmoothUnscaledTime
```

默认值：`0.15f`

当 `useSmoothDeltaTime` 为 `TRUE` 时，该值表示 timeIndependent（时间独立）补间所考虑的最大流逝时间。（注：官方文档将类型误标为 `bool`，实际为 `float`。）

### DOTween.nestedTweenFailureBehaviour

```cs
static NestedTweenFailureBehaviour DOTween.nestedTweenFailureBehaviour
```

默认值：`NestedTweenFailureBehaviour.TryToPreserveSequence`

安全模式开启时，序列内嵌套补间失败时的处理行为。（注：官方文档将类型误标为 `bool`。）

### DOTween.onWillLog

```cs
static bool DOTween.onWillLog<LogType, object>
```

用于拦截 DOTween 的日志。若该方法不为 `NULL`，DOTween 在通过 Unity 自身的 `Debug` 日志方法输出日志之前，会先调用它。返回 `TRUE` 表示让 DOTween 继续输出日志，`FALSE` 则取消输出。

该方法必须返回 `bool`，并接受两个参数：`LogType`（DOTween 想要输出的 Unity 日志类型）、`object`（DOTween 想要输出的消息）。

### DOTween.showUnityEditorReport

```cs
static bool DOTween.showUnityEditorReport
```

默认值：`FALSE`

若为 `TRUE`，退出播放模式时会显示一份 DOTween 报告（仅编辑器内）。它可以帮助你了解曾达到的最大 Tweener / Sequence 数量，从而优化最终项目。注意：这会轻微拖慢 Unity 编辑器内的性能。

### DOTween.timeScale

```cs
static float DOTween.timeScale
```

默认值：`1`

作用于所有补间的全局 timeScale，包括普通补间和时间独立补间。

### DOTween.unscaledTimeScale

```cs
static float DOTween.unscaledTimeScale
```

默认值：`1`

仅作用于时间独立（timeScaleIndependent）补间的全局 timeScale。

### DOTween.useSafeMode

```cs
static bool DOTween.useSafeMode
```

默认值：`TRUE`

若为 `TRUE`，补间运行会稍慢但更安全，DOTween 会自动处理诸如"补间运行期间目标被销毁"之类的问题。若为 `FALSE`，你需要自行确保在目标被销毁或失效之前杀死对应补间。

> [!WARNING]
> 在 iOS 上，safeMode 仅在剥离级别设置为 "Strip Assemblies"、或脚本调用优化设置为 "Slow and Safe" 时生效；在 Windows 10 WSA 上，如果选择了 Master Configuration 与 .NET，它将无法生效。

### DOTween.useSmoothDeltaTime

```cs
static bool DOTween.useSmoothDeltaTime
```

默认值：`FALSE`

若为 `TRUE`，DOTween 将使用 `Time.smoothDeltaTime` 代替 `Time.deltaTime` 来驱动 `UpdateType.Normal` 和 `UpdateType.Late` 的补间（除非补间被设为 timeScaleIndependent，此时会使用介于上一个时间步长与 `maxSmoothUnscaledTime` 之间的值）。设为 `TRUE` 可以让动画更平滑。

### DOTween.SetTweensCapacity

```cs
static DOTween.SetTweensCapacity(int maxTweeners, int maxSequences)
```

为了提升性能，DOTween 限制了同时活跃的补间最大数量。超过该限制也不用担心：它会自动扩容。但如果你提前知道需要更多（或更少）的容量（默认是 200 个 Tweener、50 个 Sequence），可以在启动时设置容量，避免自动扩容时出现卡顿。

```cs
// 将最大 Tweener 设为 2000，最大 Sequence 设为 100
DOTween.SetTweensCapacity(2000, 100);
```

## 应用于所有新建补间的默认值

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `DOTween.defaultAutoKill` | `TRUE` | 新建补间的默认 autoKill 行为。 |
| `DOTween.defaultAutoPlay` | `AutoPlay.All` | 新建补间的默认 autoPlay 行为。 |
| `DOTween.defaultEaseOvershootOrAmplitude` | `1.70158f` | 缓动函数使用的默认 overshoot / amplitude。 |
| `DOTween.defaultEasePeriod` | `0` | 缓动函数使用的默认 period。 |
| `DOTween.defaultEaseType` | `Ease.OutQuad` | 应用于所有新建 Tweener 的默认缓动。 |
| `DOTween.defaultLoopType` | `LoopType.Restart` | 应用于所有涉及循环的新建补间的默认循环类型。 |
| `DOTween.defaultRecyclable` | `false` | 新建补间的默认回收行为。 |
| `DOTween.defaultTimeScaleIndependent` | `false` | 新建补间默认是否受 Unity 的 timeScale / maximumDeltaTime 影响。 |
| `DOTween.defaultUpdateType` | `UpdateType.Normal` | 应用于所有新建补间的默认 UpdateType。 |

## Tweener 与 Sequence 的实例属性

### timeScale

```cs
float timeScale
```

默认值：`1`

设置补间内部的 timeScale。

```cs
// 让补间以一半速度播放
myTween.timeScale = 0.5f;
```

> [!TIP]
> 这个值可以被另一个补间补间，从而实现平滑的慢动作效果。
