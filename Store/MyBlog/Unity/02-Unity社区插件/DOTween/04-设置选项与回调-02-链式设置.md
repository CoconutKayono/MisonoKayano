# 设置、选项与回调（二）：链式设置

以下设置可以链式挂接到**所有类型**的补间上。补间运行期间也可以链式调用（`SetAs`、`SetInverted`、`SetLoops` 和 `SetRelative` 除外）。

## SetAs —— 套用其他补间/参数包的设置

```cs
SetAs(Tween tween \ TweenParams tweenParams)
```

将补间的参数（id、缓动、循环、延迟、timeScale、回调等）设置为给定补间或给定 `TweenParams` 对象的参数（不会复制特定的 `SetOptions` 设置，那些需要每次手动应用）。若补间已经开始，则无效。

```cs
transform.DOMoveX(4, 1).SetAs(myOtherTween);
```

## SetAutoKill —— 完成后是否自动杀死

```cs
SetAutoKill(bool autoKillOnCompletion = true)
```

若为 `TRUE`，补间一完成就会被杀死；否则会留在内存中以便复用。

注意：默认情况下补间会在完成时自动杀死（所以通常只有在想传 `FALSE` 参数时才需要调用此方法），但你可以在 DOTween 的 Utility Panel 中修改默认行为。

```cs
transform.DOMoveX(4, 1).SetAutoKill(false);
```

## SetEase —— 缓动函数

```cs
SetEase(Ease easeType \ AnimationCurve animCurve \ EaseFunction customEase)
```

设置补间的缓动函数。

- 如果作用在 `Sequence` 上（而非 `Tweener`），缓动会应用到整个序列，就像它是一条单一的动画时间轴。Sequence 默认始终使用 `Ease.Linear`，不受全局默认缓动设置影响。
- 可以传入默认缓动（`Ease`，想看默认缓动曲线的样子可以去 easings.net）、`AnimationCurve` 或自定义缓动函数。
- 可选参数 `overshoot`、`amplitude`、`period` 只对 Back 和 Elastic 缓动生效：
  - `overshoot`：Back 缓动使用的 overshoot（默认 1.70158），或 Flash 缓动的闪烁次数。
  - `amplitude`：Elastic 缓动使用的 amplitude（默认 1.70158）。
  - `period`：Elastic 缓动使用的 period（默认 0），或 Flash 缓动的幂。

> [!WARNING]
> Back 和 Elastic 缓动（即任何会超出起始/结束值的缓动）不能用于路径。

```cs
transform.DOMoveX(4, 1).SetEase(Ease.InOutQuint);
transform.DOMoveX(4, 1).SetEase(myAnimationCurve);
transform.DOMoveX(4, 1).SetEase(MyEaseFunction);
```

### 全部缓动一览（Ease 枚举）

DOTween 的 `Ease` 枚举包含大量预设缓动，但官方文档只详细讲解了其中一小部分。这里按曲线族整理全部枚举值：`In*` 表示缓入（由慢到快），`Out*` 表示缓出（由快到慢），`InOut*` 表示缓入缓出。

常见缓动曲线总览：

![[EASE.png]]

| 分组 | Ease | 说明 |
| --- | --- | --- |
| 线性 | `Ease.Linear` | 全程匀速，适合速度恒定的移动（常配合 `SetSpeedBased`）。 |
| 正弦 | `Ease.InSine` / `Ease.OutSine` / `Ease.InOutSine` | 正弦曲线，起止最柔和自然。 |
| 二次方 | `Ease.InQuad` / `Ease.OutQuad` / `Ease.InOutQuad` | 二次方曲线：缓入加速、缓出减速。**`OutQuad` 是 DOTween 的默认缓动。** |
| 三次方 | `Ease.InCubic` / `Ease.OutCubic` / `Ease.InOutCubic` | 三次方曲线，加速/减速效果比 Quad 更明显。 |
| 四次方 | `Ease.InQuart` / `Ease.OutQuart` / `Ease.InOutQuart` | 四次方曲线，变化更陡。 |
| 五次方 | `Ease.InQuint` / `Ease.OutQuint` / `Ease.InOutQuint` | 五次方曲线，陡峭程度最高。 |
| 指数 | `Ease.InExpo` / `Ease.OutExpo` / `Ease.InOutExpo` | 指数曲线，起止阶段变化极快。 |
| 圆弧 | `Ease.InCirc` / `Ease.OutCirc` / `Ease.InOutCirc` | 按圆弧轨迹插值，接近终点/起点时放缓。 |
| 回退 | `Ease.InBack` / `Ease.OutBack` / `Ease.InOutBack` | 先反向后退再冲向目标（过冲），可用 `overshoot` 调节（默认 1.70158）。 |
| 弹性 | `Ease.InElastic` / `Ease.OutElastic` / `Ease.InOutElastic` | 弹簧式振荡回弹，可用 `amplitude` / `period` 调节。 |
| 弹跳 | `Ease.InBounce` / `Ease.OutBounce` / `Ease.InOutBounce` | 球体落地式弹跳效果。 |
| 闪烁 | `Ease.Flash` / `Ease.InFlash` / `Ease.OutFlash` / `Ease.InOutFlash` | 闪烁效果，见下方「特殊缓动」。 |
| 未设置 | `Ease.Unset` | 未指定缓动，将使用全局默认值（`DOTween.defaultEaseType`）。 |
| 内部 | `INTERNAL_Zero` / `INTERNAL_Custom` | 内部枚举值，请勿直接使用。 |

> [!TIP] 如何选择缓动
> - `In*`（缓入）：由慢到快，适合“离开”的动作（如物体飞出屏幕）。
> - `Out*`（缓出）：由快到慢，适合“到达”的动作，是日常最常用的方向。
> - `InOut*`（缓入缓出）：起止都平滑，适合循环往复的动画。
> - `Back` / `Elastic` / `Bounce` 带有明显的视觉余韵，适合强调、庆祝类效果，但不要滥用。
> - 除了预设的 `Ease`，还可以用 `AnimationCurve` 自定义曲线，或实现自定义 `EaseFunction`（见上方 SetEase 说明）。

### 特殊缓动（SPECIAL EASES）

`Flash`、`InFlash`、`OutFlash`、`InOutFlash`：这些缓动会对补间属性施加闪烁效果。

- `overshoot`：闪烁的总次数。偶数次在起始值结束，奇数次在结束值结束。
- `period`：缓动在时间上的幂，范围必须在 -1 到 1 之间。0 为均衡；1 表示缓动随时间完全衰减；-1 表示缓动一开始就完全衰减，在结尾获得力量。

### 附加：EaseFactory

`EaseFactory.StopMotion` 是给缓动额外加的一层效果，让缓动看起来像定格动画（实际上，补间过程中会模拟指定的 FPS）。它可以作为任意缓动的包装器使用。

```cs
EaseFactory.StopMotion(int fps, Ease\AnimationCurve\EaseFunction ease)
```

```cs
transform.DOMoveX(4, 1).SetEase(EaseFactory.StopMotion(5, Ease.InOutQuint));
```

## SetId —— 设置 ID

```cs
SetId(object id)
```

为补间设置 ID（之后可以作为过滤器用于 DOTween 的静态方法）。可以是 int、string、object 或任何东西。

注意：使用 `int` 或 `string` 作为 ID 会让过滤操作快得多（其中 int 又比 string 快）。

```cs
transform.DOMoveX(4, 1).SetId("supertween");
```

## SetInverted —— 反转补间

```cs
SetInverted()
```

实验性：反转补间，让它从结尾播到开头（此时调用 `PlayBackwards` 反而会从开头播到结尾）。

- 注意：如果只是想倒放一个补间，直接用 `tween.PlayBackwards()` 即可。
- 若补间已经开始，或嵌套在 Sequence 中，则无效。

```cs
tween.SetInverted();
```

## SetLink —— 链接 GameObject

```cs
SetLink(GameObject target, LinkBehaviour linkBehaviour = LinkBehaviour.KillOnDestroy)
```

将补间链接到某个 GameObject，并根据其激活状态指定行为。当该 GameObject 被销毁时，补间也会被自动杀死。

- 注意：补间被加入 Sequence 后此方法无效。
- **target**：链接目标（与 `SetTarget` 设置的目标无关）。
- **linkBehaviour**：使用的行为（`LinkBehaviour.KillOnDestroy` 总是会被评估——且为默认设置——即使你选择了其他行为）。

```cs
transform.DOMoveX(4, 1).SetLink(aGameObject, LinkBehaviour.PauseOnDisableRestartOnEnable);
```

## SetLoops —— 循环

```cs
SetLoops(int loops, LoopType loopType = LoopType.Restart)
```

设置循环选项（Restart、Yoyo、Incremental）。

- 若补间已经开始则无效。另外，无限循环不会应用到序列内部的补间上。
- 将 loops 设为 -1 可让补间无限循环。
- `LoopType.Restart`：循环结束后从头重新开始。
- `LoopType.Yoyo`：循环结束后倒放，完成一个循环后再正放，如此反复。
- `LoopType.Incremental`：每次循环结束，把 endValue 与 startValue 的差值加到 endValue 上，让补间的目标值随循环次数递增。此循环类型仅适用于 Tweener。

```cs
transform.DOMoveX(4, 1).SetLoops(3, LoopType.Yoyo);
```

## SetRecyclable —— 回收

```cs
SetRecyclable(bool recyclable)
```

设置补间的回收行为。如果不设置，将使用默认值（通过 `DOTween.Init` 或 `DOTween.defaultRecyclable` 设置）。

- **recyclable**：`TRUE` = 补间被杀死后进入回收池；`FALSE` = 被销毁。

```cs
transform.DOMoveX(4, 1).SetRecyclable(true);
```

## SetRelative —— 相对模式

```cs
SetRelative(bool isRelative = true)
```

若为 `TRUE`，将补间设为相对模式（endValue 按 `startValue + endValue` 计算，而不是直接使用）。对 Sequence 来说，会将其所有嵌套补间设为相对模式。

- 重要：对 FROM 补间无效，因为那时需要在链式调用 `From` 时直接选择是否相对。
- 若补间已经开始则无效。

```cs
transform.DOMoveX(4, 1).SetRelative();
```

## SetTarget —— 设置目标

```cs
SetTarget(object target)
```

为补间设置目标（之后可以作为过滤器用于 DOTween 的静态方法）。使用泛型方式创建补间时很有用；快捷方式会自动把目标设为其所属对象。

- 注意：谨慎使用。如果只是想设置 ID，请改用 `SetId`。

```cs
DOTween.To(()=> myInstance.aFloat, (x)=> myInstance.aFloat = x, 2.5f, 1).SetTarget(myInstance);
```

## SetUpdate —— 更新类型

```cs
SetUpdate(UpdateType updateType, bool isIndependentUpdate = false)
```

设置补间的更新类型（Normal、Late 或 Fixed），并可选择让它忽略 Unity 的 timeScale 和 maximumDeltaTime。

- 若补间嵌套在 Sequence 中则无效（只有 Sequence 本身的 SetUpdate 生效）。
- **updateType**：
  - `UpdateType.Normal`：在 Update 阶段逐帧更新。
  - `UpdateType.Late`：在 LateUpdate 阶段逐帧更新。
  - `UpdateType.Fixed`：使用 FixedUpdate 更新。
  - `UpdateType.Manual`：通过手动调用 `DOTween.ManualUpdate` 更新。
- **isIndependentUpdate**：`TRUE` = 忽略 Unity 的 `Time.timeScale` 和 `maximumDeltaTime`。

> [!NOTE]
> 独立更新也支持 `UpdateType.Fixed`，但此时不推荐使用（因为 timeScale 为 0 时 FixedUpdate 不会运行）。

```cs
transform.DOMoveX(4, 1).SetUpdate(UpdateType.Late, true);
```
