# 第 26 课 · 纵横比修正的 UV

> 学习目标：理解为什么圆会变椭圆，并用画布宽高比修正坐标。

UV 的 x、y 都是 0~1，但画布的**物理宽高**可能不一样。不修正的话，圆会被拉成椭圆。

---

## 1. 完整代码

```hlsl
Shader "Lesson/26_AspectCorrect"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float aspectRatio = _ScreenParams.x / _ScreenParams.y;   // 画布宽高比

                float2 centeredUV = IN.uv - 0.5;
                centeredUV.x *= aspectRatio;                             // 修正横向拉伸

                float distanceToCenter = length(centeredUV);
                float circleMask = 1.0 - smoothstep(0.28, 0.3, distanceToCenter);
                return half4(circleMask, circleMask, circleMask, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 26_AspectCorrect`。你会看到一个保持正圆的白色圆（在全屏/非正方形画布下不会变椭圆）。

---

## 2. 问题：圆为什么会变椭圆

```hlsl
float2 centeredUV = IN.uv - 0.5;
float distanceToCenter = length(centeredUV);   // 不修正，圆会被拉伸
```

UV 的 x 和 y 都是 0~1，但画布的宽和高（像素数）不同。比如宽是高的 1.78 倍（16:9），那么 `centeredUV.x` 的 0.1 代表的**物理距离**是 `centeredUV.y` 的 0.1 的 1.78 倍——圆就被横向拉成椭圆。

---

## 3. 修正：乘以宽高比

```hlsl
float aspectRatio = _ScreenParams.x / _ScreenParams.y;   // 宽 / 高
centeredUV.x *= aspectRatio;
```

`_ScreenParams` 是 Unity 内置变量，`x` 是屏幕宽（像素）、`y` 是屏幕高（像素）。宽高比 = 宽 ÷ 高。把 `centeredUV.x` 乘以它，就相当于「把 x 的刻度拉回和 y 一致」，圆就不变形了。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 故意让圆变扁/变长 | 把 `centeredUV.x *= aspectRatio` 改成 `centeredUV.y *= aspectRatio` |
| 不用平滑边缘 | 把 `smoothstep(0.28, 0.3, distanceToCenter)` 换成 `step(0.3, distanceToCenter)` |
| 换方向修正 | 改成 `centeredUV.y /= aspectRatio`（等效于 x 方向修正的另一种写法） |

---

## 5. 练习

练习代码里 `centeredUV = IN.uv - 0.5` 之后**没有**做纵横比修正。补充 `aspectRatio` 的计算和 `centeredUV.x *= aspectRatio`，让圆保持正圆。

### 答案解析

```hlsl
float aspectRatio = _ScreenParams.x / _ScreenParams.y;
float2 centeredUV = IN.uv - 0.5;
centeredUV.x *= aspectRatio;
```

`_ScreenParams.x / _ScreenParams.y` 得到宽高比。把它乘到 `centeredUV.x` 上，让 x 方向的单位和 y 方向一致，`length(centeredUV)` 算出的才是「真实几何距离」，圆才不会被拉变形。

注意：只有在「画布不是正方形」时这个修正才有效果。正方形画布（宽=高）下 `aspectRatio = 1`，修正前后完全一样。

---

## 6. 【小灶解析】专家补充

### ① Unity 里「画布」的概念要分清

这类「按屏幕比例画形状」的效果，画布就是整个屏幕，所以要用屏幕尺寸做修正。**在 Unity 里，这个课对应的是「全屏效果」（UI 或后处理）**，此时屏幕尺寸由内置变量 `_ScreenParams` 提供（x=宽、y=高，单位是像素）。

如果你把这个 shader 贴在**3D 物体**（比如 Cube、Quad）上，情况不同：物体每张脸的 UV 是 0~1 的正方形，圆在 UV 里永远是圆的，但它投射到屏幕上后会不会变形，取决于**物体本身的屏幕比例**，而不是屏幕分辨率。这时要把「物体的宽高比」作为材质属性传进来，而不是用 `_ScreenParams`。这是一个很重要的区别，后面做「UI 圆角」「全屏涟漪」时要反复遇到。

### ② 修正的本质：让两个轴的单位一致

UV 的 x、y 数字都是 0~1，但**1 个单位的 x 和 1 个单位的 y 代表的物理长度不同**。修正就是在做「单位归一化」——让两个轴用同一把尺子。这是任何「在非正方形区域画几何图形」都要做的第一步。

### ③ _ScreenParams 是什么

`_ScreenParams` 是 Unity 传给 shader 的内置变量（float4），含义：`x`=屏幕宽（像素）、`y`=屏幕高（像素）、`z`=1+1/宽、`w`=1+1/高。这里只用到了 `x` 和 `y` 来算宽高比。它是**全屏效果**里替代「画布分辨率」的官方变量。
