# 第 18 课 · 圆形描边

> 学习目标：使用 `abs(距离 - 半径)` 与 `smoothstep()` 绘制圆环描边。

实心圆用到中心的距离。描边（空心圆）需要测量另一个距离：**到圆周的距离**。

---

## 1. 完整代码

```hlsl
Shader "Lesson/18_Ring"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;
                float distanceToCenter = length(centeredUV);

                float radius = 0.28;
                float thickness = 0.02;
                float ringMask = 1.0 - smoothstep(thickness, thickness + 0.006, abs(distanceToCenter - radius));
                return half4(ringMask, ringMask, ringMask, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 18_Ring`。画面中央出现一个白色圆环描边。

---

## 2. 到圆周的距离

圆周是所有到中心距离等于半径 `radius` 的点。一个像素到圆周的距离就是：

```hlsl
abs(distanceToCenter - radius)
```

- `distanceToCenter < radius`（圆内）：距离是 `radius - distanceToCenter`
- `distanceToCenter > radius`（圆外）：距离是 `distanceToCenter - radius`
- `distanceToCenter = radius`（圆周上）：距离是 `0.0`

---

## 3. 用 smoothstep 生成描边

```hlsl
float radius = 0.28;
float thickness = 0.02;
float ringMask = 1.0 - smoothstep(thickness, thickness + 0.006, abs(distanceToCenter - radius));
```

`abs(distanceToCenter - radius) < thickness` 的区域遮罩接近 1（描边），超过 `thickness + 0.006` 的区域遮罩为 0（背景）。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 更粗的描边 | 把 `thickness` 改成 `0.04` |
| 更小的圆环 | 把 `radius` 改成 `0.2` |
| 更硬的边缘 | 把 `0.006` 改得更小，如 `0.001` |

---

## 5. 练习

练习代码里 `ringMask = 0.0`（全背景色）。用 `1.0 - smoothstep(thickness, thickness + 0.006, abs(distanceToCenter - radius))` 计算遮罩，让圆形描边出现。

### 答案解析

```hlsl
float ringMask = 1.0 - smoothstep(thickness, thickness + 0.006, abs(distanceToCenter - radius));
```

`abs(distanceToCenter - radius)` 把圆周当作「零点」：圆周上距离为 0，向内向外都增大。`smoothstep` 用这个距离做边缘衰减，`thickness` 控制描边宽度（半宽），`0.006` 控制边缘模糊度。

改变 `thickness = 0.04` 让描边更粗，改变 `radius = 0.2` 让圆更小。

---

## 6. 【小灶解析】专家补充

### ① abs(distanceToCenter - radius) 是「把距离场以圆周为轴折叠」

`abs` 把圆内和圆外的距离都折成正值，于是「到圆周的距离」变成了一个对称的、以圆周为 0 的场。这是画描边、圆环、空心图形的标准手法——**先算到「形状边界」的距离，再阈值化**。

### ② 这其实就是 SDF 的雏形

实心圆用「到中心的距离」，描边用「到圆周的距离」。后者已经非常接近 SDF（有符号距离场）了——SDF 的核心就是「任意点到形状边界的距离」。第 28 课《SDF 圆环》会正式展开这个概念。

### ③ 为什么用 smoothstep 而不是 step

描边宽度 `thickness` 很小（只有 0.02），如果用 step 硬切，这一圈细边会严重锯齿。smoothstep 的 `thickness ~ thickness+0.006` 给了 0.006 的过渡带，让细边也平滑。**越细的图形越需要 smoothstep 抗锯齿**。
