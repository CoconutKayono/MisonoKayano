# 第 08 课 · 反向渐变

> 学习目标：使用 `1.0 - 亮度` 反转渐变方向。

水平渐变从左（黑）到右（白）。如果想反过来，只需一个操作：`1.0 - 亮度`。

---

## 1. 完整代码

```hlsl
Shader "Lesson/08_Reverse"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float brightness = 1.0 - IN.uv.x;   // ★ 反转
                return half4(brightness, brightness, brightness, 1);  // 左白 → 右黑
            }
            ENDHLSL
        }
    }
}
```

---

## 2. 用 1.0 - 反转

```hlsl
float brightness = 1.0 - IN.uv.x;
```

- 左边：`IN.uv.x = 0.0` → `brightness = 1.0`（白色）
- 右边：`IN.uv.x = 1.0` → `brightness = 0.0`（黑色）

原本 0 的地方变成 1，原本 1 的地方变成 0——方向完全翻转。

---

## 3. 试着改一改

| 效果 | 写法 |
|------|------|
| 竖直反向（下白上黑） | `float brightness = 1.0 - IN.uv.y;` |
| 反向后再整体压暗 | `float brightness = (1.0 - IN.uv.x) * 0.5;` |

---

## 4. 练习

练习代码里 `brightness = 0.0`（全黑）。把 `brightness` 改成 `1.0 - IN.uv.x`，让渐变从左白到右黑。

初始状态：

```hlsl
half4 frag (Varyings IN) : SV_Target
{
    float brightness = 0.0;             // 全黑
    return half4(brightness, brightness, brightness, 1);
}
```

### 答案解析

```hlsl
float brightness = 1.0 - IN.uv.x;
```

`1.0 - x` 是最简单的「取反」操作：输入 0 得 1，输入 1 得 0，中间值也对称翻转。

这个技巧不只用于渐变。任何 0~1 的遮罩，用 `1.0 -` 就能反转：白变黑、黑变白、圆内变圆外。

---

## 5. 【小灶解析】专家补充

### ① 1.0 - x 是「关于 0.5 的镜像」

`1.0 - x` 的效果：0 ↔ 1、0.25 ↔ 0.75、0.5 ↔ 0.5（不变）。它是一种**对称操作**，所以是「取反」而不是「平移」。理解这一点，你就能预判任意值经过它之后会变成多少。

### ② 遮罩反转的普遍性

第 03 课的 clamp、后面的 step/smoothstep 生成的遮罩，都可以用 `1.0 -` 反转含义。「圆内亮」变成「圆外亮」、「线条」变成「底纹」，全靠这一个操作。它是「遮罩」思维里和正向同等重要的另一半。

### ③ 和 lerp 的联系

`lerp(a, b, t) = lerp(b, a, 1 - t)`。所以第 07 课「反向渐变」既可以调换颜色顺序，也可以把混合因子取反——两条路殊途同归。看到 `1.0 - x`，你要能想到它等价于「把两个端点对调」。
