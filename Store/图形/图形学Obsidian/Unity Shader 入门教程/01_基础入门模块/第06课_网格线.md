# 第 06 课 · 网格线

> 学习目标：使用 `frac()` 与 `step()` 绘制网格线。

条纹是「在一个方向上重复」，网格线是「同时在两个方向重复」，并在每段边界附近显示线条。

---

## 1. 完整代码

```hlsl
Shader "Lesson/06_Grid"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float density = 10.0;                  // 每个方向的格子数量
                float2 gridCell = frac(IN.uv * density);  // 每格内 0~1 重复

                float lineWidth = 0.05;                // 线宽（格子宽度的 5%）
                float lineMask = step(1.0 - lineWidth, gridCell.x) + step(1.0 - lineWidth, gridCell.y);
                lineMask = min(lineMask, 1.0);

                return half4(lineMask, lineMask, lineMask, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 06_Grid`。你会看到 10×10 的网格，格线是白色。

---

## 2. 构造网格坐标

```hlsl
float density = 10.0;
float2 gridCell = frac(IN.uv * density);
```

`frac(IN.uv * 10.0)` 把画面分成 10×10 的格子，每格内 `gridCell` 从 0~1 重新开始。

`frac` 是 HLSL 里「取小数部分」的函数：`frac(x) = x - floor(x)`。所以 3.7 的小数部分是 0.7——这正是「重复」的秘诀：把 UV 放大 10 倍后取小数，每一格都变成一段全新的 0~1。

---

## 3. 在边界处绘制线条

每格内，`gridCell.x` 接近 1.0 时意味着靠近右边界。用 `step` 检测：

```hlsl
float lineWidth = 0.05;   // 线条宽度（格子宽度的 5%）
float lineMask = step(1.0 - lineWidth, gridCell.x) + step(1.0 - lineWidth, gridCell.y);
lineMask = min(lineMask, 1.0);
```

- `step(1.0 - lineWidth, gridCell.x)` 在 `gridCell.x > 0.95` 时返回 1（靠近右边界）
- 加上 y 方向的检测，两者相加
- `min(lineMask, 1.0)` 防止两线交叉处超过 1

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 更细的线 | 把 `lineWidth` 改成 `0.02` |
| 更多格子 | 把 `density` 改成 `20.0` |
| 只保留竖线 | 删掉 `+ step(1.0 - lineWidth, gridCell.y)` |
| 线变红色 | `return half4(lineMask, 0.0, 0.0, 1.0);` |

## 5. 练习

练习代码里 `lineMask = 0.0`（全背景色）。用 `step(1.0 - lineWidth, gridCell.x) + step(1.0 - lineWidth, gridCell.y)` 计算线条遮罩，再用 `min` 限制范围。

初始状态：

```hlsl
half4 frag (Varyings IN) : SV_Target
{
    float density = 10.0;
    float2 gridCell = frac(IN.uv * density);
    float lineWidth = 0.05;
    float lineMask = 0.0;               // 全黑
    return half4(lineMask, lineMask, lineMask, 1);
}
```

### 答案解析

```hlsl
float lineMask = step(1.0 - lineWidth, gridCell.x) + step(1.0 - lineWidth, gridCell.y);
lineMask = min(lineMask, 1.0);
```

x 方向和 y 方向各产生一条线，用 `+` 叠加后最大值为 2（两边界交叉处），`min(lineMask, 1.0)` 把它压回 1。

调整 `lineWidth = 0.02` 可以让线条更细，改变 `density` 可以控制格子数量。

---

## 6. 【小灶解析】专家补充

### ① frac 是「重复 / 平铺」的核心工具

取小数部分让函数周期性重复，这是 Shader 里最常用的技巧之一。后面平铺贴图（让 UV 重复）、做程序化噪点、做水波纹，全都建立在 `frac` 上。记住：**想重复，就乘一个倍数再 frac**。

### ② step 的参数顺序容易记反

HLSL 里 `step(edge, x)` 返回「x 是否大于等于 edge」：`x >= edge` 得 1，否则得 0。读法建议记成「x 有没有跨过 edge 这道坎」。写反了结果就是「网格线的补集」，一眼就能看出来不对。

### ③ min(lineMask, 1.0) 的另一种写法

两线交叉处 step 相加会到 2，不限制就超出颜色范围（回忆第 03 课的截断）。`min(lineMask, 1.0)` 和 `saturate(lineMask)` 在这里完全等价，都是「夹回 0~1」。

### ④ 网格 = 条纹的二维推广

条纹是「一个方向重复 + 一条线」，网格是「两个方向重复 + 两条线叠加」。你其实已经掌握了画「任何周期性图案」的骨架：**frac 做重复 → step 做边界检测 → + 做组合**。这三个动作的组合，能生出棋盘格、波点、砖墙纹理等一大类图案。
