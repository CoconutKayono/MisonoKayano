# 第 21 课 · 暗角（边缘变暗）

> 学习目标：用「到中心的距离」加 `smoothstep` 做一个暗角（vignette）效果。

暗角是摄影里常见的边缘变暗效果。原理：**离中心越远，颜色越暗**——正好用距离场做。

---

## 1. 完整代码

```hlsl
Shader "Lesson/21_Vignette"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 darkColor  = float3(0.02, 0.02, 0.04);  // 深色（边缘）
                float3 lightColor = float3(0.85, 0.9, 1.0);    // 亮色（中心）

                float2 centeredUV = IN.uv - 0.5;
                float distanceToCenter = length(centeredUV);

                float vignetteFactor = 1.0 - smoothstep(0.25, 0.6, distanceToCenter);
                float3 color = lerp(darkColor, lightColor, vignetteFactor);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 21_Vignette`。中心亮、四角暗。

---

## 2. 距离驱动的亮度

```hlsl
float2 centeredUV = IN.uv - 0.5;
float distanceToCenter = length(centeredUV);
```

`distanceToCenter` 从中心的 0 到四角的约 0.707 变化。

---

## 3. smoothstep 控制过渡

```hlsl
float vignetteFactor = 1.0 - smoothstep(0.25, 0.6, distanceToCenter);
```

- `distanceToCenter < 0.25`（中心区）：`smoothstep` = 0，`vignetteFactor` = 1（亮）
- `distanceToCenter` 在 0.25~0.6 之间：平滑过渡
- `distanceToCenter > 0.6`（边缘）：`smoothstep` = 1，`vignetteFactor` = 0（暗）

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 更明显的暗角 | 把范围改小，如 `smoothstep(0.15, 0.4, distanceToCenter)` |
| 更柔和的暗角 | 把范围拉宽，如 `smoothstep(0.2, 0.7, distanceToCenter)` |
| 反相（边缘亮） | `float vignetteFactor = smoothstep(0.25, 0.6, distanceToCenter);` |

---

## 5. 练习

练习代码里 `vignetteFactor = 1.0`（全亮）。用 `1.0 - smoothstep(0.25, 0.6, distanceToCenter)` 计算亮度，让边缘变暗。

### 答案解析

```hlsl
float vignetteFactor = 1.0 - smoothstep(0.25, 0.6, distanceToCenter);
```

`smoothstep(0.25, 0.6, distanceToCenter)` 在中心区返回 0、边缘返回 1，用 `1.0 -` 反转后，中心为 1（亮）、边缘为 0（暗），中间平滑过渡。

`0.25` 和 `0.6` 控制暗角范围：两个值越接近，过渡越陡、暗角边缘越硬；拉得越开越柔和。

---

## 6. 【小灶解析】专家补充

### ① 暗角本质是「径向渐变」

暗角和第 02 课的径向渐变是同一个东西，只是把「颜色随距离渐变」反过来用——中心亮、边缘暗。**同一个距离场，换个映射方向就是完全不同的效果**。这就是为什么距离场值得你反复练。

### ② 暗角在游戏里的真实用途

真实游戏后处理里，暗角用于：把玩家视线集中到画面中心、掩盖画面边缘的低质量内容、增强氛围。Unity 的后处理组件（Post Processing / URP Volume）就自带 Vignette，参数和这里几乎一一对应（强度 = 深色有多暗，平滑度 = smoothstep 的过渡带宽度）。**你现在写的，就是后处理暗角的底层原理**。

### ③ 为什么 darkColor 不是纯黑

纯黑 `float3(0,0,0)` 会让边缘完全死黑、丢失细节。真实的暗角通常是「变暗但不归零」，所以这里用了 `0.02` 而不是 `0`。这是美术向的细节——**暗角压暗，而不是抹黑**。
