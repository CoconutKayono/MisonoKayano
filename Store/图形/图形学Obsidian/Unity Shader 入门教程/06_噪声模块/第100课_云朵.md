# 第 100 课 · 云朵

> 学习目标：用 `smoothstep` 从 FBM 噪声中「提亮」高值区，在蓝天上叠出白云。

噪声是连续灰度，要变云朵，就切出高密度区域做白色。

---

## 1. 完整代码

```hlsl
Shader "Lesson/100_Clouds"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            float fbm(float2 coord)
            {
                float value = 0.0;
                float amplitude = 0.5;
                for (int i = 0; i < 4; i++)
                {
                    value += amplitude * valueNoise(coord);
                    coord *= 2.0;
                    amplitude *= 0.5;
                }
                return value;
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float noiseValue = fbm(IN.uv * 5.0 + _Time.y * 0.05);
                float cloudMask = smoothstep(0.5, 0.75, noiseValue);

                float3 skyColor = float3(0.5, 0.7, 1.0);
                float3 cloudColor = float3(1.0, 1.0, 1.0);
                float3 color = lerp(skyColor, cloudColor, cloudMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是淡蓝天空上漂浮着缓缓漂移的白色云朵，云缘柔和。

---

## 2. FBM 噪声长什么样

这里用的是 FBM（分形布朗运动）噪声——4 层不同频率的值噪声叠加，每层振幅减半、频率翻倍。叠加后既有大块低频起伏、又有小颗粒细节，整体像白云的密度分布。

---

## 3. smoothstep 做「阈值」

`smoothstep(0.5, 0.75, noiseValue)` 对噪声做平滑截断：n < 0.5 → 0（天空），0.5~0.75 → 平滑过渡（云缘），n > 0.75 → 1（云核心）。只有高值区显示白色，低值区保持蓝天。

---

## 4. lerp 把云叠在天空上

`cloudMask` 为 0 输出天蓝、为 1 输出纯白，中间值产生柔和云缘。**「噪声 → smoothstep 阈值 → lerp 叠色」是云朵的标准三件套。**

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 云变稀、只留高密度区 | `smoothstep(0.5, 0.75, ...)` 改成 `smoothstep(0.6, 0.8, ...)` |
| 云变厚、覆盖更大 | 改成 `smoothstep(0.3, 0.6, ...)` |
| 云朵更细碎 | `5.0` 改成 `10.0` |
| 漂移加速 | `_Time.y * 0.05` 改成 `_Time.y * 0.2` |

## 6. 练习

练习代码里 `cloudMask = 0.0`（无云，全天空）。用 `smoothstep` 从噪声提取云朵轮廓。

### 答案解析

```hlsl
float cloudMask = smoothstep(0.5, 0.75, noiseValue);
```

`smoothstep(0.5, 0.75, noiseValue)` 把 FBM 高值区（>0.5）映射为非零，再经 `lerp(sky, cloud, cloudMask)` 渲染为白色。两个边界 0.5、0.75 分别决定云的密度阈值和边缘柔和度。

试着用 `step(0.6, noiseValue)` 替换，对比硬切割和平滑过渡的边缘差异。

## 7. 【小灶解析】专家补充

### ① 云 = 高密度的噪声

云的本质是「水汽密度场」，噪声恰好能模拟这个密度场。**用 smoothstep 切出高密度区**，就得到云的轮廓。这是程序化天空盒、体积云的最简雏形。

### ② 两个边界值 = 两个旋钮

`smoothstep(a, b, n)` 的 a 决定「云有多厚」（覆盖率），b 决定「云缘多柔和」。真实调云效果时就是拧这两个旋钮。**把参数含义和视觉效果对应起来，是 TA 调参的直觉来源。**

### ③ 时间偏移放坐标里，云就漂

`fbm(IN.uv * 5.0 + _Time.y * 0.05)` 里的时间偏移让整片云场缓慢平移，模拟风吹云动。云漂得慢（0.05）才自然——太快就成了「跑马灯」。真实感往往来自「慢」。
