# 第 109 课 · 域扭曲

> 学习目标：用噪声扭曲采样坐标、再采样噪声，做出卷曲感极强的有机形态。

Domain Warp（域扭曲）= 用噪声推偏坐标 + 对推偏后的坐标再采样噪声。

---

## 1. 完整代码

```hlsl
Shader "Lesson/109_DomainWarp"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            float fbm(float2 coord)
            {
                float value = 0.0;
                float amplitude = 0.5;
                for (int i = 0; i < 4; i++)
                {
                    value += amplitude * valueNoise(coord);
                    coord *= 2.0;
                    amplitude *= 0.5;
                }
                return value;
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 coord = IN.uv * 5.0;

                float2 warpOffset = float2(fbm(coord + 3.1), fbm(coord + 7.7));
                float noiseValue = fbm(coord + warpOffset * 1.2);

                float3 color = float3(noiseValue, noiseValue, noiseValue);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是漩涡般卷曲的有机形态，像流动的墨水或熔岩。

---

## 2. 思路：先扭曲坐标

普通噪声是对 `coord` 采样：`fbm(coord)`。域扭曲多一步：先用两次独立 fbm 算出偏移向量 `warpOffset`，再用 `coord + warpOffset` 作为新坐标采样。

`warpOffset.x` 和 `.y` 是两个方向的偏移，分别用不同偏置（3.1 和 7.7）让它们互相独立、不产生对称。最终每个像素的采样坐标被噪声「推开」一段距离，产生漩涡卷曲。

---

## 3. 1.2 是什么

`warpOffset * 1.2` 里的 1.2 是扭曲强度。值越大，坐标被推得越远、卷曲越剧烈；接近 0，结果退化成普通 fbm。

---

## 4. 为什么偏置要不同

两次 fbm 用不同偏置（3.1 和 7.7），让 X、Y 两个方向的扭曲场互不相关。如果偏置相同或太接近，两个方向可能产生对称，扭曲就「死板」了。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 扭曲更剧烈、大漩涡 | `1.2` 改成 `3.0` |
| 扭曲很轻微、接近普通 fbm | `1.2` 改成 `0.2` |
| 偏置不够独立、出现对称 | `3.1` 和 `7.7` 改成 `1.0` 和 `2.0` |
| 二次扭曲、形态更复杂 | 最终 fbm 外再套一层域扭曲 |

---

## 6. 练习

练习代码里 `noiseValue = fbm(coord)`。先算 `warpOffset`，再对 `coord + warpOffset * 1.2` 采样。

### 答案解析

```hlsl
float2 coord = IN.uv * 5.0;
float2 warpOffset = float2(fbm(coord + 3.1), fbm(coord + 7.7));
float noiseValue = fbm(coord + warpOffset * 1.2);
```

`fbm(coord + 3.1)`、`fbm(coord + 7.7)` 是两个独立噪声场，分别作 X、Y 偏移；`coord + warpOffset * 1.2` 把坐标用噪声向量推移后再采样。坐标先被噪声扭曲再采样，出现漩涡般的有机形态。

试着把 `1.2` 改成 `4.0`，看卷曲感急剧增强。

## 7. 【小灶解析】专家补充

### ① 域扭曲是噪声的「王炸」

域扭曲能做出火焰、云、水、熔岩、油画笔触等几乎所有有机形态，是程序化纹理里表现力最强的技巧之一。**普通噪声 = 地形，域扭曲噪声 = 流动的液体/烟雾。**

### ② 第 102 课的大理石是它的前奏

大理石扰动的是 sin 的相位（一维偏移），域扭曲扰动的是采样坐标（二维偏移）。**两者同源：用噪声推偏「采样位置」**。学到这里，噪声模块的所有技巧已经串成了一张网。

### ③ 恭喜完成噪声模块

从哈希格点（95）到域扭曲（109），你走完了程序化噪声的完整旅程：hash → valueNoise → FBM → 折叠变体（脊状/湍流）→ 大理石/木纹 → 域扭曲。**这套工具箱已经能生成山脉、云海、木石、火焰、烟雾**——它们是所有程序化材质和体积效果的根基。下一步的进阶方向是：用这些噪声去驱动 3D 表面（法线扰动、置换）、以及学习 Shader Graph 里如何节点化地搭建同样的效果。
