# 第 96 课 · 噪声动画

> 学习目标：在噪声采样的坐标里加时间偏移，让静止的噪声流动起来。

噪声动画的秘诀只有一句话：**把时间加进坐标**。

---

## 1. 完整代码

```hlsl
Shader "Lesson/96_NoiseAnimation"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float noiseValue = valueNoise(IN.uv * 8.0 + _Time.y * 0.2);
                float3 color = float3(noiseValue, noiseValue, noiseValue);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一团平滑的灰色噪声，缓慢斜向流动，像漂浮的雾。

---

## 2. 为什么加时间就能动

`valueNoise` 的输入是一个二维坐标。每一帧 `_Time.y` 都在增大，把它加到坐标上，相当于把采样点在噪声空间里向前推进——画面图案就流动起来。

`0.2` 是流速：越大流动越快，越小越接近静止。若改成 `float2(_Time.y * 0.2, 0.0)` 只沿 X 偏移，就是水平流动。

---

## 3. 偏移 vs 缩放

加法偏移 `+ _Time.y * 0.2` 让噪声像在一张无限大的纸上滑动——旧图案移出画面、新图案从另一边进入。**如果你改的是坐标的缩放系数，那改变的是频率，不会产生动画**。动画靠平移，不靠缩放。

---

## 4. valueNoise 是怎么来的

`valueNoise` 是第 105 课的主角，这里先当工具用：它把格子里的随机值做平滑插值，产生连续斑块（而不是第 95 课那种马赛克）。本课专注「怎么让它动」，函数细节后面再拆。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 流速变快、有急流感 | `0.2` 改成 `1.0` |
| 流速极慢、像薄雾 | `0.2` 改成 `0.02` |
| 斜向流动 | `_Time.y * 0.2` 改成 `float2(_Time.y * 0.2, _Time.y * 0.1)` |
| 换成分形噪声 | `valueNoise` 换成 `fbm`（配合 fbm 函数） |

## 6. 练习

练习代码里 `noiseValue = valueNoise(IN.uv * 8.0)`（静止）。在坐标参数里加 `_Time.y * 0.2` 让噪声动起来。

### 答案解析

```hlsl
float noiseValue = valueNoise(IN.uv * 8.0 + _Time.y * 0.2);
```

把 `valueNoise(IN.uv * 8.0)` 改成 `valueNoise(IN.uv * 8.0 + _Time.y * 0.2)`。`IN.uv * 8.0` 是噪声频率（不变）；`+ _Time.y * 0.2` 每帧把采样点向 (1,1) 方向推进一小步，产生流动感；`0.2` 是速度系数。

试着改成只沿 X 轴流动：`valueNoise(IN.uv * 8.0 + float2(_Time.y * 0.2, 0.0))`。

---

## 7. 【小灶解析】专家补充

### ① 动画 = 采样点随时间移动

回顾动画模块的心法「动画是变换坐标」。噪声动画是同一招的又一次印证：**图案不变，采样点在噪声空间里走**。烟雾、水流、云层飘动，本质都是给噪声坐标加时间偏移。

### ② 偏移方向决定流动方向

加标量 `_Time.y * 0.2` 是沿 (1,1) 对角流；加 `float2(t*0.2, 0)` 沿 X 流；加 `float2(0, t*0.2)` 沿 Y 流。想往哪流，就在哪个分量上加时间。**这是控制噪声流动方向的最简单方式。**

### ③ 流速是「每秒推进多少噪声单元」

`_Time.y * 0.2` 里 0.2 的含义：每秒采样点推进 0.2 个噪声单元。因为噪声周期是 1（坐标每跨 1 格走完一个周期），所以流速 1.0 ≈ 每秒流过一整块噪声。要精确控制速度，就把这个系数暴露成 Properties。
