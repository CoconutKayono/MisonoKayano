# 第 97 课 · 噪声颜色映射

> 学习目标：用噪声值当 `lerp` 的混合比例，把灰度噪声变成双色渐变噪声。

噪声是 0~1 的浮点数，正好能当 `lerp` 的 t 参数。

---

## 1. 完整代码

```hlsl
Shader "Lesson/97_NoiseColorMap"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float noiseValue = valueNoise(IN.uv * 8.0);

                float3 colorA = float3(0.15, 0.2, 0.95);   // 深蓝
                float3 colorB = float3(1.0, 0.6, 0.15);    // 橙黄
                float3 color = lerp(colorA, colorB, noiseValue);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是深蓝到橙黄的双色斑块噪声，明暗结构清晰可见。

---

## 2. lerp 把噪声变成颜色

`lerp(colorA, colorB, noiseValue)` 在两种颜色间插值，混合比例就是噪声值：低噪声区偏深蓝、高噪声区偏橙黄，中间连续过渡。**把灰度噪声变成双色渐变，一行就够。**

---

## 3. 为什么选这对颜色

深蓝和橙黄是对比色（互补色），对比度高，能把噪声的明暗结构最清晰地呈现出来。选颜色时**高对比 = 结构更明显**，低对比 = 更柔和。

---

## 4. valueNoise 回顾

`valueNoise` 把画布分成格子，每个格点一个随机值，格点之间平滑插值，得到连续斑块。`IN.uv * 8.0` 放大 8 倍，画面里约 8×8 个噪声周期。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 噪声频率降低、色块变大 | `8.0` 改成 `3.0` |
| 低值区偏绿 | `colorA` 改成 `float3(0.05, 0.3, 0.1)` |
| 高值区米白 | `colorB` 改成 `float3(1.0, 0.95, 0.8)` |
| 换成分形噪声更细腻 | `valueNoise` 换成 `fbm` |

## 6. 练习

练习代码里 `color = colorA`（纯深蓝，看不出噪声）。用 `lerp(colorA, colorB, noiseValue)` 输出。

### 答案解析

```hlsl
float3 color = lerp(colorA, colorB, noiseValue);
```

把固定色 `colorA` 换成 `lerp(colorA, colorB, noiseValue)`。噪声值决定每个像素的混合比例：低噪声区偏蓝、高噪声区偏橙、中间平滑过渡，噪声的空间分布以颜色形式显现。

试着改成 `lerp(colorA, colorB, pow(noiseValue, 3.0))`，体验指数变换让低值区更大、高值区更小的效果。

---

## 7. 【小灶解析】专家补充

### ① 噪声值是「现成的混合权重」

任何 0~1 的值都能直接当 `lerp` 的 t。噪声天然落在 0~1，所以「噪声 → 颜色 / 高度 / 透明度 / 金属度」都是同一个套路：**`lerp(低端, 高端, 噪声)`**。这是程序化材质里出现频率最高的写法之一。

### ② 对 t 做变换 = 重塑分布

`pow(noiseValue, 3.0)` 会让低值区变宽（更多暗部）、高值区变窄。`smoothstep`、`sqrt`、`pow` 都能重塑噪声的明暗分布。**直接 lerp 是「线性的」，想要风格化就得改 t 的曲线。**

### ③ 颜色映射是最便宜的风格化

同一个噪声，换一对颜色就换一种材质感：蓝橙是「噪点测试图」，棕白是「沙地」，绿黑是「苔藓」。**先有噪声、后上色**——把「生成结构」和「映射颜色」两步分开思考，是程序化纹理的核心工作流。
