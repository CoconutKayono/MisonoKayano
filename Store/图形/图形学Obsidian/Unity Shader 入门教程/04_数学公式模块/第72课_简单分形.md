# 第 72 课 · 简单分形

> 学习目标：用「放大 + frac」的迭代制造自相似的细节层次，理解分形与递归。

每次迭代把坐标放大 2 倍再取小数，就能不断产生自相似的细节层次。

---

## 1. 完整代码

```hlsl
Shader "Lesson/72_Fractal"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 currentPos = IN.uv;
                float patternValue = 0.0;

                for (int i = 0; i < 4; i++)
                {
                    currentPos *= 2.0;
                    currentPos = frac(currentPos) - 0.5;
                    float distanceToCenter = length(currentPos);
                    float circleMask = 1.0 - smoothstep(0.1, 0.3, distanceToCenter);
                    patternValue += circleMask / pow(2.0, (float)i + 1.0);
                }

                patternValue += 0.1 * sin(_Time.y + length(IN.uv - 0.5) * 5.0);
                patternValue = saturate(patternValue);

                float3 darkColor = float3(0.05, 0.06, 0.1);
                float3 lightColor = float3(0.9, 0.85, 0.7);
                float3 color = lerp(darkColor, lightColor, patternValue);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一个层次丰富的分形图案，带随时间流动的波纹。

---

## 2. 放大 + frac = 自相似

每次循环做两件事：

- `currentPos *= 2.0`：把坐标空间放大 2 倍，原来一个大格子变成 4 个小格子
- `currentPos = frac(currentPos) - 0.5`：取小数部分并重新居中，每个格子都重置为 [-0.5, 0.5] 的独立小空间

放大一次，坐标空间里出现更小的相同图案。放大四次，就有四个尺度的相同图案叠加，看起来细节无限向下延伸——这就是分形。

---

## 3. 权重递减

```hlsl
patternValue += circleMask / pow(2.0, (float)i + 1.0);
```

第一次迭代权重 1/2（50%）、第二次 1/4（25%）、第三次 1/8（12.5%）、第四次 1/16（6.25%）。大尺度圆贡献最多、细节层贡献递减，整体轮廓清晰、细节丰富但不淹没主体。

---

## 4. 动态脉冲

```hlsl
patternValue += 0.1 * sin(_Time.y + length(IN.uv - 0.5) * 5.0);
```

用 `sin(时间 + 距中心距离)` 添加随时间变化的波纹，让静态图案有生命感。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 细节减少、图案更粗 | 循环次数 `4` 改成 `2` |
| 细节更丰富 | 循环次数改成 `6` |
| 细节层权重更高 | `pow(2.0, ...)` 改成 `pow(1.5, ...)` |
| 图案密度更高 | 放大倍率 `2.0` 改成 `3.0` |

## 6. 练习

练习代码里循环结构已写好，但 `patternValue` 初始为 0 且缺少迭代累加。补全循环体内的「放大 + frac + 画圆 + 加权累加」。

### 答案解析

```hlsl
float patternValue = 0.0;
for (int i = 0; i < 4; i++)
{
    currentPos *= 2.0;
    currentPos = frac(currentPos) - 0.5;
    float distanceToCenter = length(currentPos);
    float circleMask = 1.0 - smoothstep(0.1, 0.3, distanceToCenter);
    patternValue += circleMask / pow(2.0, (float)i + 1.0);
}
```

每次迭代对坐标做「放大 + frac + 居中」，相当于把画布无限细分。`circleMask / pow(2.0, (float)i + 1.0)` 保证每层贡献随尺度缩小而递减。四次迭代叠加后，有圆的地方接近 1、空白处接近 0。

试着把 `smoothstep(0.1, 0.3, ...)` 改成 `smoothstep(0.05, 0.25, ...)`，让每个圆更实心，看分形密度变化。

## 7. 【小灶解析】专家补充

### ① 分形 = 迭代 + 自相似

分形的核心不是「递归函数」，而是「同一个操作反复作用在自己身上」。`放大 + frac` 就是制造自相似的迭代器。理解这一点，就能自己造各种分形图案。

### ② for 循环在 shader 里很便宜

shader 的 `for` 循环会被编译器展开执行（本课循环 4 次就是 4 遍相同代码）。循环次数要写成**编译期常量**（字面量 4），不能用运行时变量当上限，否则很多平台不支持。

### ③ 权重递减是「层次感」的关键

每层除以 2 的幂，让大结构主导、小细节点缀。不递减的话所有层次一样重，画面会糊成一团。**「主次分明」在程序化纹理里靠权重控制**。
