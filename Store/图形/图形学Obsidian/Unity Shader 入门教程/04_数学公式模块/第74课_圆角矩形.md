# 第 74 课 · 圆角矩形

> 学习目标：在矩形 SDF 上减一个圆角半径，得到圆角矩形。

圆角矩形的 SDF 只比普通矩形多一个参数——圆角半径 `cornerRadius`：

```hlsl
float sdRoundBox(float2 point, float2 halfSize, float cornerRadius)
{
    float2 distanceComponents = abs(point) - halfSize;
    return length(max(distanceComponents, float2(0.0, 0.0))) - cornerRadius
         + min(max(distanceComponents.x, distanceComponents.y), 0.0);
}
```

---

## 1. 完整代码

```hlsl
Shader "Lesson/74_SdfRoundBox"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            float sdRoundBox(float2 point, float2 halfSize, float cornerRadius)
            {
                float2 distanceComponents = abs(point) - halfSize;
                return length(max(distanceComponents, float2(0.0, 0.0))) - cornerRadius
                     + min(max(distanceComponents.x, distanceComponents.y), 0.0);
            }

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;
                float distanceToBox = sdRoundBox(centeredUV, float2(0.22, 0.14), 0.05);
                float boxMask = 1.0 - smoothstep(0.0, 0.01, distanceToBox);

                return half4(float3(boxMask, boxMask, boxMask), 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一个四角圆润的白色圆角矩形。

---

## 2. 和 sdBox 的区别

普通 `sdBox` 返回到矩形边界的距离，四个角是尖的。`sdRoundBox` 在返回值里减去圆角半径 `cornerRadius`（`return ... - cornerRadius`）：相当于把整个形状向外「膨胀」了 `cornerRadius`，但四个角因为是用 `length` 算的，膨胀后自然变成圆弧——圆角出现了。半径越大角越圆。

---

## 3. 参数是什么

调用 `sdRoundBox(centeredUV, float2(0.22, 0.14), 0.05)`：

- `centeredUV` = 像素相对中心的位置（`IN.uv - 0.5`）
- `float2(0.22, 0.14)` = 矩形半宽 0.22、半高 0.14
- `0.05` = 圆角半径

实际矩形宽 0.44、高 0.28，四角各带 0.05 的圆角。

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 圆角很大、接近椭圆 | `0.05` 改成 `0.14` |
| 回到直角矩形 | `0.05` 改成 `0.0` |
| 正方形圆角 | `float2(0.22, 0.14)` 改成 `float2(0.2, 0.2)` |
| 边缘柔化更明显 | `0.01` 改成 `0.04` |

## 5. 练习

练习代码里 `distanceToBox = 0.0`。调用 `sdRoundBox(centeredUV, float2(0.22, 0.14), 0.05)` 计算距离，让画面显示圆角矩形。

### 答案解析

```hlsl
float distanceToBox = sdRoundBox(centeredUV, float2(0.22, 0.14), 0.05);
```

`sdRoundBox` 与 `sdBox` 几乎相同，只在最后减去圆角半径 0.05，使每个角的尖锐区域被削成圆弧。`1.0 - smoothstep(0.0, 0.01, distanceToBox)` 把内部映射为白、外部为黑。起始 `distanceToBox = 0.0` 全屏都被视为边界。

## 6. 【小灶解析】专家补充

### ① 「减半径」是 SDF 的通用膨胀法

`distanceField - r` 让形状向外「变胖」r 个单位。对矩形这么做就得到圆角（因为角部的距离是 `length` 算的），对圆这么做就是「半径增大」。**SDF 的加减就是形状的缩放与圆角**。

### ② 圆角半径不能超过半宽/半高

当 `cornerRadius` 大于 `halfSize` 的较小值时，圆角互相重叠，形状会退化成胶囊或椭圆。这在 UI 圆角框里是常见的边界情况，要注意。

### ③ SDF 家族可以互相推导

`sdBox` → `sdRoundBox`（减半径）→ 胶囊体（线段距离减半径）→ 圆（点到点距离减半径）。理解了「距离减半径」这个统一操作，整个 SDF 家族就串起来了。
