# 第 71 课 · 正弦波动画

> 学习目标：用 `sin` 创建会流动的波形，理解频率、振幅、相位如何驱动动画。

`sin` 的输出在 -1 到 +1 之间来回震荡，用 `_Time.y` 推动相位，波形每帧都会移动。

---

## 1. 完整代码

```hlsl
Shader "Lesson/71_SineWaveAnimation"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float animatedWave = sin(IN.uv.x * 10.0 + _Time.y);
                float normalizedWave = animatedWave * 0.5 + 0.5;

                float waveStripe = 1.0 - smoothstep(0.0, 0.1, abs(IN.uv.y - normalizedWave));

                float3 color1 = float3(1.0, 0.5, 0.1);   // 橙
                float3 color2 = float3(0.1, 0.4, 1.0);   // 蓝
                float colorMix = sin(_Time.y) * 0.5 + 0.5;
                float3 waveColor = lerp(color1, color2, colorMix);

                float3 backgroundColor = float3(0.04, 0.04, 0.08);
                float3 color = lerp(backgroundColor, waveColor, waveStripe);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一条流动的波浪线，颜色在橙和蓝之间随时间切换。

---

## 2. sin 的值范围问题

`sin` 输出 -1 到 +1，但 UV 坐标在 0~1。直接用 `sin` 的值做 y 坐标会产生负数，落到画布外。标准修正是「缩放并平移」：

```hlsl
float normalizedWave = animatedWave * 0.5 + 0.5;
```

`* 0.5` 把 ±1 压缩到 ±0.5，`+ 0.5` 把范围从 [-0.5, +0.5] 平移到 [0, 1]，可以安全地当 y 坐标或混合比例。

---

## 3. 把波形变成可见的线

```hlsl
float waveStripe = 1.0 - smoothstep(0.0, 0.1, abs(IN.uv.y - normalizedWave));
```

`abs(IN.uv.y - normalizedWave)` 是像素到波形的距离，`smoothstep(0.0, 0.1, ...)` 在距离 0~0.1 内从 0 过渡到 1，取反后近处 1（亮）、远处 0（暗）。

---

## 4. 颜色随时间变化

```hlsl
float colorMix = sin(_Time.y) * 0.5 + 0.5;
float3 waveColor = lerp(color1, color2, colorMix);
```

`colorMix` 也是一个归一化的 sin 值，在 0~1 之间振荡，让波的颜色在橙和蓝之间交替变化。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 频率减半、波浪变稀疏 | `10.0` 改成 `5.0` |
| 线条变细 | `0.1`（smoothstep 宽度）改成 `0.02` |
| 颜色按位置渐变而非随时间 | `colorMix = sin(_Time.y) * 0.5 + 0.5` 改成 `colorMix = IN.uv.x` |
| 流动加速 | `_Time.y` 改成 `_Time.y * 3.0` |

---

## 6. 练习

把 `colorMix = sin(_Time.y) * 0.5 + 0.5` 改成 `colorMix = IN.uv.x`，让波的颜色按水平位置渐变。

### 答案解析

```hlsl
float colorMix = IN.uv.x;
```

原代码 `sin(_Time.y) * 0.5 + 0.5` 让整条波统一随时间在橙蓝间切换。改成 `IN.uv.x` 后，左边偏橙、右边偏蓝，颜色沿水平方向空间渐变、不再随时间变化。这展示了核心思路：**任何 0~1 的值都可以当 `lerp` 的第三个参数**。

试着把 `colorMix` 改成 `normalizedWave`，让颜色跟着波形本身的高度变化。

---

## 7. 【小灶解析】专家补充

### ① 动画 = 静态图案 + 时间偏移

把 `_Time.y` 加进任何 `sin`/`frac` 的参数，图案就会动起来。**「静态图案 + 时间」是 shader 动画的统一公式**，你之前学的所有图案都能这样让它动。

### ② 频率、振幅、相位，各司其职

`sin(uv.x * 10.0 + _Time.y)` 里：`10.0` 是频率（密不密）、`* 0.5 + 0.5` 是振幅和偏移（高不高、放哪里）、`_Time.y` 是相位（动不动作）。调波形就是调这三个旋钮。

### ③ 颜色也可以被 sin 驱动

`colorMix = sin(_Time.y) * 0.5 + 0.5` 用 sin 驱动颜色混合。这说明 sin 不只是「位置」，任何数值都能用它来「呼吸」：颜色、透明度、大小、速度。
