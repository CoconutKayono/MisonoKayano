# 第 48 课 · 砖墙

> 学习目标：用 `floor` + `fmod` 识别奇偶行，做出砖块错缝排列的重复图案。

砖墙的关键是每隔一行把砖块向右偏移半格，只需一行代码。

---

## 1. 完整代码

```hlsl
Shader "Lesson/48_BrickWall"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float tileCount = 8.0;
                float2 scaledUV = IN.uv * tileCount;

                // 奇数行向右偏移半格，形成错缝
                scaledUV.x += step(1.0, fmod(floor(scaledUV.y), 2.0)) * 0.5;

                float2 localUV = frac(scaledUV);   // 每个砖块内的局部坐标
                float mortarMask = min(step(0.95, localUV.x) + step(0.95, localUV.y), 1.0);

                float3 brickColor = float3(0.75, 0.25, 0.2);    // 砖红
                float3 mortarColor = float3(0.9, 0.85, 0.8);    // 砖缝浅色
                float3 color = lerp(brickColor, mortarColor, mortarMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面呈现错缝排列的砖墙，砖缝是浅色细线。

---

## 2. 识别奇偶行

```hlsl
scaledUV.x += step(1.0, fmod(floor(scaledUV.y), 2.0)) * 0.5;
```

`floor(scaledUV.y)` 取当前行号（0、1、2、3…）；`fmod(行号, 2.0)` 对 2 取余，偶数行得 0、奇数行得 1；`step(1.0, ...)` 把余数转成 0/1，奇数行为 1；`* 0.5` 让奇数行的 x 坐标右移半格，形成错缝。

---

## 3. 画砖缝

```hlsl
float mortarMask = min(step(0.95, localUV.x) + step(0.95, localUV.y), 1.0);
```

`frac(scaledUV)` 得到每个砖块内的局部坐标。`step(0.95, localUV.x)` 在格子右侧 5% 处返回 1，`step(0.95, localUV.y)` 在顶部 5% 处返回 1，两者相加后 `min(..., 1.0)` 保证不超过 1。这就是砖缝遮罩：砖缝处为 1，砖面为 0。

### 答案解析

```hlsl
scaledUV.x += step(1.0, fmod(floor(scaledUV.y), 2.0)) * 0.5;
```

`floor(scaledUV.y)` 得到行号，`fmod(..., 2.0)` 判断奇偶，`step(1.0, ...)` 把奇数行映射为 1，`* 0.5` 让奇数行右移半格。没有偏移时所有砖块垂直对齐，不像真正的砖墙；加上后奇偶行交错，错缝就自然出现了。

## 6. 【小灶解析】专家补充

### ① 砖墙 = 分格 + 错位 + 砖缝

大多数重复图案都可以拆成三件事：**把画面分成格子、给某些格子加扰动、在格子里画图案**。本课就是「分格（乘 8）→ 错位（奇数行偏移）→ 画砖缝（step）」。记住这个套路，之后自己设计图案就有章法了。

### ② HLSL 里取余用 fmod，不是 mod

取余用 **`fmod(x, y)`**（浮点取余）。`fmod(3.0, 2.0)` 结果是 1.0。注意别写错成别的名字，后面棋盘格、Truchet 还会反复用到。

### ③ 奇数行偏移是「程序化纹理」的经典招

真实砖墙的砖块不会上下对齐，这是它「像真的」的关键。这个「每隔一行偏移半格」的操作，在程序化纹理里叫 **staggering（错位）**，砖墙、瓷砖、木地板都靠它。
