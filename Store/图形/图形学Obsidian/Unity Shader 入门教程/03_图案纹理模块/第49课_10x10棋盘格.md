# 第 49 课 · 10×10 棋盘格

> 学习目标：用 `floor` 识别格子编号、用 `fmod` 区分黑白，生成棋盘格。

棋盘格核心就两行：分格编号 + 奇偶判断。

---

## 1. 完整代码

```hlsl
Shader "Lesson/49_Checker10x10"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 cellIndex = floor(IN.uv * 10.0);        // 格子编号
                float patternMask = fmod(cellIndex.x + cellIndex.y, 2.0);   // 奇偶

                float3 darkColor = float3(0.1, 0.1, 0.1);
                float3 lightColor = float3(0.9, 0.9, 0.9);
                float3 color = lerp(darkColor, lightColor, patternMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是 10×10 的黑白棋盘格。

---

## 2. floor 怎么识别格子编号

```hlsl
float2 cellIndex = floor(IN.uv * 10.0);
```

`IN.uv * 10.0` 把 0~1 的坐标拉伸成 0~10，`floor` 向下取整：3.7 变 3，0.2 变 0。每个格子都得到一对整数编号，比如第 3 列第 7 行的格子编号是 (3, 7)。

---

## 3. fmod 怎么区分黑白

```hlsl
float patternMask = fmod(cellIndex.x + cellIndex.y, 2.0);
```

`cellIndex.x + cellIndex.y` 把列号行号相加，`fmod(..., 2.0)` 对 2 取余：和为偶数得 0.0，和为奇数得 1.0。相邻格子的编号之和必然奇偶交替，所以颜色也自然交替。`lerp(darkColor, lightColor, patternMask)` 按 0/1 输出对应颜色。

## 4. 试着改一改

## 5. 练习

练习代码里 `cellIndex = float2(0, 0)`、`patternMask = 0.0`。改成正确表达式，让画面出现 10×10 棋盘格。

### 答案解析

```hlsl
float2 cellIndex = floor(IN.uv * 10.0);
float patternMask = fmod(cellIndex.x + cellIndex.y, 2.0);
```

`floor(IN.uv * 10.0)` 把 UV 离散成 10×10 的整数格子编号。`fmod(cellIndex.x + cellIndex.y, 2.0)` 把两个编号相加后对 2 取余，相邻格子余数必相差 1，颜色必然交替。初始代码所有格子同一编号，只能输出一种颜色。

试着把 `fmod(cellIndex.x + cellIndex.y, 2.0)` 改成 `fmod(cellIndex.x * cellIndex.y, 2.0)`，看会出现什么图案。

## 6. 【小灶解析】专家补充

### ① 棋盘格是「编号奇偶」的产物

棋盘格本质上不是「画出来的」，而是「格子的行号列号之和是奇数还是偶数」这个**数学性质**决定的。这是程序化图案的重要思路：**先给格子编号，再用编号的算术性质决定图案**。

### ② 只看 x 或只看 y 会怎样

把公式里的 `x + y` 换成 `x`，奇数行不变、偶数行交替，得到**垂直条纹**；换成 `y` 得到水平条纹。一个加减号的差别，图案完全不同——这就是程序化纹理「牵一发动全身」的魅力。

### ③ 程序化 vs 贴图

棋盘格这种图案既可以用 shader 算（本课），也可以贴一张贴图。shader 算的优点是**无限分辨率、零内存、随时改颜色**；缺点是复杂图案很难用数学表达。TA 的日常就是在这两者之间权衡。
