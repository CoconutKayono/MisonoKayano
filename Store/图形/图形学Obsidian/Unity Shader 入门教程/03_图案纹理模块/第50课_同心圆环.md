# 第 50 课 · 同心圆环

> 学习目标：用 `frac` 把「到中心的距离」折叠成重复的圆环。

同心圆环的核心：距离场 + `frac` 折叠 + `step` 切硬边。

---

## 1. 完整代码

```hlsl
Shader "Lesson/50_ConcentricRings"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;
                float distanceToCenter = length(centeredUV);

                float ringPattern = frac(distanceToCenter * 12.0);   // 折叠成重复波形
                float ringMask = step(0.5, ringPattern);

                float3 darkColor = float3(0.1, 0.12, 0.2);
                float3 lightColor = float3(0.85, 0.9, 1.0);
                float3 color = lerp(darkColor, lightColor, ringMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是从中心向外扩散的双色同心圆环。

---

## 2. 先算距离

```hlsl
float2 centeredUV = IN.uv - 0.5;
float distanceToCenter = length(centeredUV);
```

`IN.uv - 0.5` 把原点移到画面中心，`length` 计算每个像素到中心的距离：中心为 0，边缘约 0.5~0.7。这是一个从中心向外均匀增大的数值场。

---

## 3. frac 把距离变成圆环

```hlsl
float ringPattern = frac(distanceToCenter * 12.0);
float ringMask = step(0.5, ringPattern);
```

`distanceToCenter * 12.0` 把距离范围扩大，`frac` 把它折叠成多段 0~1 的锯齿波，每一段对应一个圆环。`step(0.5, ringPattern)` 把每段切成内半（0）和外半（1），形成双色交替的同心圆环。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 圆环变宽、数量减少 | `12.0` 改成 `6.0` |
| 圆环变细、数量增多 | `12.0` 改成 `24.0` |
| 深色环变窄、浅色环变宽 | `step(0.5, ...)` 改成 `step(0.3, ...)` |
| 圆环中心移到左上角 | `IN.uv - 0.5` 改成 `IN.uv - float2(0.2, 0.7)` |

---

## 5. 练习

练习代码里 `ringPattern = 0.0`。改成正确表达式，让画面出现以中心为圆心的同心圆环。

### 答案解析

```hlsl
float ringPattern = frac(distanceToCenter * 12.0);
```

`distanceToCenter` 是像素到中心的距离，乘 12 后 `frac` 把它折叠成重复的 0~1 波形，每折叠一次产生一个圆环。初始 `ringPattern = 0.0` 让 `step(0.5, 0.0)` 恒为 0，画面全是深色。

试着把 `frac(distanceToCenter * 12.0)` 改成 `frac(distanceToCenter * distanceToCenter * 50.0)`，圆环间距会随距离变化，产生向外收缩的效果。

---

## 6. 【小灶解析】专家补充

### ① frac 是「重复」的万能钥匙

`frac` 只保留小数部分，等于把整个数轴**每隔 1 折叠一次**。任何「均匀增大的数值场」乘个系数再 `frac`，都能变成重复图案：距离 → 圆环，x → 条纹，角度 → 扇形。**这是程序化纹理里最重要的一个函数**。

### ② 圆环间距为什么外密内疏

`distanceToCenter` 从 0 均匀增长，乘 12 后 `frac` 折叠的次数也均匀。但圆环的面积随半径平方增长，所以视觉上**外围的环看起来更密**。第 50 课练习里的 `d²` 版本就是利用这一点做出非均匀间距。

### ③ 距离场是「形状的骨架」

本课的「距离场 + 阈值」和第 16 课画圆、第 28 课 SDF 圆环是同一套思想。距离场让你能把「离中心多远」当成一个可操作的数值，圆环、螺旋、声波扩散效果都建立在这个数值场上。
