# 第 52 课 · 渐变网格

> 学习目标：用一行 `floor` 把连续渐变变成格子状的阶梯渐变（量化）。

`floor(uv * 6.0) / 6.0` 把连续坐标「压」成 6×6 的离散台阶。

---

## 1. 完整代码

```hlsl
Shader "Lesson/52_GradientGrid"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 cellCoord = floor(IN.uv * 6.0) / 6.0;
                return half4(float3(cellCoord, 0.0), 1);
            }
            ENDHLSL
        }
    }
}
```

画面是 6×6 的格子，格与格之间有明显的颜色跳跃（红绿渐变被量化）。

---

## 2. floor 怎么把渐变「量化」

```hlsl
float2 cellCoord = floor(IN.uv * 6.0) / 6.0;
```

`IN.uv * 6.0` 把 0~1 的 UV 扩展成 0~6，画面分成 6×6 的格子；`floor` 向下取整，把每个格子内所有连续值压缩成同一个整数（0.1、0.3、0.5、0.9 → 0；1.2、1.7 → 1）；再 `/ 6.0` 缩回 0~1。结果：同一格子里所有像素的 `cellCoord` 完全相同，格与格之间有跳跃。

---

## 3. 怎么上色

```hlsl
return half4(float3(cellCoord, 0.0), 1);
```

`float3(cellCoord, 0.0)` 把 `cellCoord.x` 作为红通道、`cellCoord.y` 作为绿通道、蓝固定为 0：左下格 (0,0) 黑，右下格红，左上格绿，右上格黄（红+绿）。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 格子变大（3×3） | `6.0` 改成 `3.0` |
| 格子变小（12×12） | `6.0` 改成 `12.0` |
| 颜色换到绿蓝通道 | `float3(cellCoord, 0.0)` 改成 `float3(0.0, cellCoord.x, cellCoord.y)` |
| 变回平滑渐变 | 去掉 `floor(...)`，只保留 `IN.uv * 6.0 / 6.0` |

## 5. 练习

练习代码里 `cellCoord = IN.uv`。改成正确表达式，让渐变呈现阶梯状的 6×6 网格。

### 答案解析

```hlsl
float2 cellCoord = floor(IN.uv * 6.0) / 6.0;
```

`floor(IN.uv * 6.0)` 把连续坐标离散成 0~5 的整数，`/ 6.0` 缩回 0~1 让颜色幅度不变。初始 `cellCoord = IN.uv` 是平滑渐变，没有格子边界。

试着把 `/ 6.0` 改成 `/ 3.0`，看颜色分布会怎么变化。

## 6. 【小灶解析】专家补充

### ① 量化的本质：连续 → 离散

本课的「连续渐变 → 阶梯」和第 36 课卡通光照的「连续光照 → 色阶」是**同一个操作**：用 `floor` 把连续值离散化。记住这一招，你在任何地方都能把「平滑」变成「块状」。

### ② floor 和 frac 是一对

`frac(x) = x - floor(x)`：`floor` 取整数部分（格子编号），`frac` 取小数部分（格子内局部坐标）。它们经常成对出现——一个负责「我在第几格」，一个负责「我在格内哪里」。第 55 课 Truchet 就是典型。

### ③ 颜色也能当数据可视化

把坐标塞进 RGB 通道，本质上是在「可视化数据」。这个技巧是 TA 调试 shader 的利器：想知道某个数值场长什么样，就把它写进颜色输出。
