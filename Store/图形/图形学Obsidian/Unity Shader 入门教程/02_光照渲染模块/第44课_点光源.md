# 第 44 课 · 点光源

> 学习目标：在方向光基础上加入「位置」和「距离衰减」，理解点光源与方向光的本质区别。

方向光只有方向；点光源有位置，每个像素到光源的方向不同，且越远越暗——就像蜡烛。

---

## 1. 完整代码

```hlsl
Shader "Lesson/44_PointLight"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float3 normalOS : NORMAL;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float3 normalWS : TEXCOORD0;
                float3 positionWS : TEXCOORD1;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
                OUT.positionWS = TransformObjectToWorld(IN.positionOS.xyz);
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 normal = normalize(IN.normalWS);
                float3 surfacePos = IN.positionWS;

                float3 lightPosition = float3(-0.5, 0.6, 0.6);   // 点光源位置

                float3 lightVector = lightPosition - surfacePos;
                float3 lightDir = normalize(lightVector);

                // 距离衰减：dot(v,v) 等于长度平方，省一次开方
                float attenuation = 1.0 / (1.0 + 3.0 * dot(lightVector, lightVector));

                float diffuse = max(dot(normal, lightDir), 0.0) * attenuation;
                float3 baseColor = float3(0.9, 0.5, 0.2);
                float3 color = baseColor * (0.1 + diffuse * 2.0);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

场景准备同第 31 课。球体靠近光源的一侧亮、远离的一侧暗，产生真实的明暗过渡。

---

## 2. 方向光 vs 点光源

方向光只有方向、没有位置，画面里每个像素收到光的方向都一样。点光源有位置，每个像素到光源的方向不同，而且越远收到的光越弱。

---

## 3. 光照方向随位置变化

```hlsl
float3 lightVector = lightPosition - surfacePos;
float3 lightDir = normalize(lightVector);
```

`lightVector` 从表面指向光源，`normalize` 后只保留方向。每个像素算出的 `lightDir` 都不一样——这就是点光源和方向光最本质的区别。

---

## 4. 距离衰减

```hlsl
float attenuation = 1.0 / (1.0 + 3.0 * dot(lightVector, lightVector));
```

`dot(v, v)` 等于向量长度的平方，省去开根号。`1.0 / (1.0 + 3·d²)` 的形状：距离 0 时 `attenuation = 1`，距离越大越趋向 0。系数 `3.0` 控制衰减速度。最后 `max(dot(normal, lightDir), 0.0) * attenuation` 把漫反射和衰减相乘。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 光源移到左侧 | `lightPosition` 改成 `float3(-0.6, 0.3, 0.6)` |
| 衰减更快、球变暗 | 系数 `3.0` 改成 `10.0` |
| 衰减更慢、范围更广 | 系数 `3.0` 改成 `0.5` |
| 环境光增强、背光也亮 | `0.1` 改成 `0.4` |

## 6. 练习

练习代码里已经算了 `lightDir`，但缺衰减。补全 `attenuation` 并乘进 `diffuse`，让球体呈现随距离变暗的点光源效果。

### 答案解析

```hlsl
float attenuation = 1.0 / (1.0 + 3.0 * dot(lightVector, lightVector));
float diffuse = max(dot(normal, lightDir), 0.0) * attenuation;
```

起始代码 `diffuse = max(dot(normal, lightDir), 0.0)` 没乘衰减，相当于光源无限强、距离无影响。加上 `attenuation` 后，近处像素几乎不损失亮度，远处像素趋近 0，球体产生真实明暗过渡。`dot(lightVector, lightVector)` 是距离平方，比 `length()` 少一次开根号。

试着把光源位置 z 分量从 0.6 改成 0.1，让光源更贴近球面，观察衰减形状的变化。

## 6. 【小灶解析】专家补充

### ① dot(v, v) 的省开销技巧

`length(v) = sqrt(dot(v, v))`。如果衰减公式里只需要距离的**平方**（如 `1/(1+k·d²)`），就用 `dot(v, v)` 直接得到 d²，省掉一次开方。GPU 上开方不便宜，这种「能不开方就不开方」的意识和第 02 课「用平方距离代替距离」一脉相承。

### ② 点光源 → 聚光灯只差一步

点光源向四面八方发光；聚光灯（Spot Light）多了一个「锥形范围」——把衰减再乘一个「锥角遮罩」即可。Unity 里三种真实光源（方向光、点光源、聚光灯）都遵循「方向 + 衰减」这套结构。

### ③ 真实引擎里的衰减曲线

Unity 的点光源衰减比 `1/(1+k·d²)` 更复杂（带 range 截断和可调曲线），但核心思想一致：**离得越远越暗，并且衰减曲线可调**。本课的公式是理解它的最小版本。
