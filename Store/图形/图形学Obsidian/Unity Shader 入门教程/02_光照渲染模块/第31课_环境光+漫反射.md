# 第 31 课 · 环境光 + 漫反射

> 学习目标：理解光照的两个基础项——环境光（兜底亮度）与漫反射（随方向变化），并学会它们的合成。

**场景准备（新）**：前面 30 课 shader 都贴在平面四边形上；从本课起，shader 贴在**真正的 3D 球体网格**上。在 Hierarchy 里右键 → 3D Object → Sphere 新建一个球体，新建材质把 Shader 选为 `Lesson → 31_AmbientDiffuse`，拖到球体上。

---

## 1. 完整代码

```hlsl
Shader "Lesson/31_AmbientDiffuse"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float3 normalOS : NORMAL;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float3 normalWS : TEXCOORD0;
                float3 positionWS : TEXCOORD1;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
                OUT.positionWS = TransformObjectToWorld(IN.positionOS.xyz);
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 normal = normalize(IN.normalWS);
                float3 lightDir = normalize(float3(-0.4, 0.6, 0.7));

                float3 baseColor = float3(0.9, 0.5, 0.2);        // 橙色材质
                float ambient = 0.18;                            // 环境光：固定兜底亮度
                float diffuse = max(dot(normal, lightDir), 0.0); // 漫反射：随方向变化

                float3 color = baseColor * (ambient + diffuse);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

球体受光面亮、背光面保留 18% 的基础亮度，不再漆黑一片。

---

## 2. 为什么需要环境光

```hlsl
float ambient = 0.18;
```

纯漫反射的背光面是完全黑的。现实中光会在空间里多次反弹，没有直接受光的地方也不会是绝对的黑。环境光（ambient）就是对这种「间接照明」的最简单模拟：一个固定的、不受方向影响的亮度底层。

---

## 3. ambient 和 diffuse 的关系

```hlsl
float3 color = baseColor * (ambient + diffuse);
```

`ambient` 是常数（0.18 = 18%），不管朝哪个方向都一样。`diffuse` 随方向变化：正对光时接近 1.0，背光时为 0.0。两者相加，亮部接近 1.18（有一点过曝感），背光面保留 18% 的亮度。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 暗部更暗、对比更高 | `ambient` 从 0.18 改成 0.05 |
| 暗部很亮、整体偏平 | `ambient` 从 0.18 改成 0.5 |
| 平滑混合、不过曝 | 把 `(ambient + diffuse)` 改成 `lerp(ambient, 1.0, diffuse)` |

## 5. 练习

练习代码里 `ambient = 0.0`，背光面完全黑。补全 TODO，给 `ambient` 设置一个合适的值（如 0.18），让球体暗部也有基础亮度。

### 答案解析

```hlsl
float ambient = 0.18;
```

初始状态 `ambient = 0.0` 相当于没有环境光，背光面和纯 Lambert 一样黑。改成 0.18 后，所有像素都加上 18% 的固定亮度底层，背光面不再漆黑。

试着把 0.18 改成 0.35，再和 0.05 对比，感受不同环境光强度对整体氛围的影响。

## 6. 【小灶解析】专家补充

### ① 从「画布」到「真球体」：法线从哪来

前 30 课你在全屏四边形上画画，坐标只有 uv。本课起 shader 贴在真正的 Sphere 网格上，**法线是模型自带的**——顶点 shader 通过 `NORMAL` 语义拿到模型法线，`TransformObjectToWorldNormal` 把它转到世界空间，片元里再 `normalize`（插值会破坏单位长度，必须重新归一化）。这是 Unity 做光照的标准姿势，也是 TA 的第一块地基。

### ② 为什么背光面全黑

`dot(normal, lightDir)` 在背光面是**负数**（法线和光线方向夹角大于 90°）。颜色不能为负，所以用 `max(..., 0.0)` 截断成 0。这就是纯漫反射「死黑」的来源。

### ③ ambient 是「经验兜底」，不是物理

`ambient = 0.18` 没有任何物理依据，是美术的「手感参数」——模拟多次反弹的间接光。真实引擎里这件事由**全局光照（GI）/ 光照探针（Light Probe）/ 环境光**来做，比一个常数复杂得多。但「先加个兜底常数」这个思路，是理解一切光照合成的第一步。
