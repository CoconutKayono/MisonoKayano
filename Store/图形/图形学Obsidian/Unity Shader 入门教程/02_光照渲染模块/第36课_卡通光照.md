# 第 36 课 · 卡通光照

> 学习目标：用 `floor` 把连续的漫反射切成几个色阶，做出卡通分级效果。

普通光照是连续渐变；卡通渲染把这个渐变「量化」成几个固定档位。本课用 `floor` 一行完成。

---

## 1. 完整代码

```c
Shader "Lesson/36_ToonBands"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float3 normalOS : NORMAL;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float3 normalWS : TEXCOORD0;
                float3 positionWS : TEXCOORD1;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
                OUT.positionWS = TransformObjectToWorld(IN.positionOS.xyz);
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 normal = normalize(IN.normalWS);
                float3 lightDir = normalize(float3(-0.4, 0.6, 0.7));

                float diffuse = max(dot(normal, lightDir), 0.0);
                diffuse = floor(diffuse * 4.0) / 3.0;   // 切成 4 个亮度档

                float3 baseColor = float3(0.85, 0.6, 0.35);
                float3 color = baseColor * (0.15 + 0.85 * diffuse);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

场景准备同第 31 课。球体光影出现硬朗的色阶分界，像漫画的阴影。

---

## 2. floor 分级的原理

```hlsl
diffuse = floor(diffuse * 4.0) / 3.0;
```

`diffuse` 是 0~1 的连续渐变。`floor(diffuse * 4.0)` 先把范围扩大 4 倍（0~4），再向下取整，结果只可能是 0、1、2、3 四个整数；除以 3.0 缩回 0~1，得到四个离散档位：0 / 0.33 / 0.67 / 1.0。

---

## 3. 档位数怎么控制

公式是 `floor(diffuse * N) / (N - 1.0)`，N 是档位数：

- N = 2：只有亮/暗两档，极简漫画风
- N = 4：四档（当前效果）
- N = 8：八档，接近平滑但有轻微阶梯感

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 只有两个亮度档 | `4.0` 改 `2.0`，`3.0` 改 `1.0` |
| 八个档位、接近平滑 | `4.0` 改 `8.0`，`3.0` 改 `7.0` |
| 亮部更亮、暗部更暗 | 在外面套 `pow(diffuse, 0.5)` |

## 5. 练习

练习代码里 `diffuse` 没有经过 floor 处理，球体是平滑渐变。补全 TODO，对 `diffuse` 做分级，让球体呈现卡通色阶。

### 答案解析

```hlsl
diffuse = floor(diffuse * 4.0) / 3.0;
```

初始状态 `diffuse = max(dot(normal, lightDir), 0.0)` 是连续漫反射。用 `floor(diffuse * 4.0) / 3.0` 替换，把 0~1 分成四个离散档位。这行写在 `diffuse` 计算之后、颜色合成之前。

试着把 `4.0 / 3.0` 改成 `3.0 / 2.0`（三个档位），感受减少档位后卡通感的变化。

## 6. 【小灶解析】专家补充

### ① 为什么「分级」就是卡通感

真实世界的明暗是连续渐变的；漫画、动画的阴影是**成块**的。把连续值量化成有限档位，光影边界变得清晰硬朗，就产生了「手绘/漫画」的视觉语言。这是非真实感渲染（NPR）最核心的一招。

### ② 两种「分级」写法殊途同归

本课用数学 `floor(x * N) / (N-1)`；第 47 课会用 `if-else` 逐个判断阈值。**两者结果相同**：if-else 直观、适合任意阈值；floor 写法紧凑、改档位数只需改一个数字。工程里两种都会遇到，本课先教你更优雅的 floor 版。

### ③ 分级 + 轮廓线 = 完整卡通

只有色阶还不够「卡通」，通常还要配一条**轮廓线**（第 47 课会补上）。色阶负责「块状阴影」，轮廓线负责「描边」，两者结合才是完整的 Toon Shading。
