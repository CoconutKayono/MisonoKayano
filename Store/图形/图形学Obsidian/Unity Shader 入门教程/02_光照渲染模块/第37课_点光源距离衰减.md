# 第 37 课 · 点光源距离衰减

> 学习目标：为点光源加入距离衰减，让光照强度随空间距离自然变化。

方向光只有方向；点光源还有位置，且离得越远光照越弱。本课学习 `1.0 / (1.0 + k·d²)` 衰减公式。

---

## 1. 完整代码

```hlsl
Shader "Lesson/37_PointLightAttenuation"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float3 normalOS : NORMAL;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float3 normalWS : TEXCOORD0;
                float3 positionWS : TEXCOORD1;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
                OUT.positionWS = TransformObjectToWorld(IN.positionOS.xyz);
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 normal = normalize(IN.normalWS);

                float3 lightPosition = float3(0.6, 0.8, 0.6);   // 点光源位置（球体上方偏右）
                float3 lightVector = lightPosition - IN.positionWS;
                float lightDistance = length(lightVector);       // 先保存距离
                float3 lightDir = lightVector / lightDistance;   // 再归一化用于漫反射

                float attenuation = 1.0 / (1.0 + 2.0 * lightDistance * lightDistance);

                float diffuse = max(dot(normal, lightDir), 0.0) * attenuation;

                float3 baseColor = float3(0.9, 0.5, 0.2);
                float3 color = baseColor * (0.08 + diffuse * 1.6);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

场景准备同第 31 课。球体靠近光源的一侧明显更亮，越远离光源越暗，有自然的明暗过渡。

---

## 2. 先算距离，再归一化

```hlsl
float3 lightVector = lightPosition - IN.positionWS;
float lightDistance = length(lightVector);       // 真实距离
float3 lightDir = lightVector / lightDistance;   // 方向（长度为 1）
```

方向光只需要方向；点光源还需要**位置**。关键顺序：**先保存距离，再归一化**。如果先归一化，`lightVector` 长度变成 1，距离信息就丢了。

---

## 3. 衰减公式

```hlsl
float attenuation = 1.0 / (1.0 + 2.0 * lightDistance * lightDistance);
```

距离 0 时 `attenuation = 1`（100% 亮），距离越大越趋向 0。系数 `2.0` 控制衰减速度：越大衰减越快。最后 `diffuse * attenuation` 让亮度随距离减弱。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 光源移到左侧 | `lightPosition` 的 x 改成 `-0.6` |
| 衰减更快、球变暗 | 系数 `2.0` 改成 `6.0` |
| 衰减更慢、范围更广 | 系数 `2.0` 改成 `0.5` |
| 环境光增强、背光也亮 | `0.08` 改成 `0.3` |

## 5. 练习

练习代码里只算了 `lightDir`，缺衰减。补全 `attenuation` 的计算，并乘进 `diffuse`，让球体呈现随距离变暗的效果。

### 答案解析

```hlsl
float attenuation = 1.0 / (1.0 + 2.0 * lightDistance * lightDistance);
float diffuse = max(dot(normal, lightDir), 0.0) * attenuation;
```

起始代码里 `diffuse` 没有乘衰减，相当于光源无限强、距离无影响。加上 `attenuation` 后，近处像素几乎不损失亮度，远处像素趋近 0，球体产生真实明暗过渡。

试着把 `lightPosition` 的 z 分量从 0.6 改成 0.1，让光源更贴近球面，观察衰减形状的变化。

## 6. 【小灶解析】专家补充

### ① 方向光 vs 点光源：有没有「位置」

方向光（Directional Light）只有方向、没有位置，所有像素收到的光方向都一样——用来模拟太阳。点光源（Point Light）有位置，每个像素到光源的方向不同，且随距离衰减——用来模拟灯泡、蜡烛。**区分这两者，是理解整个光照体系的第一步**。

### ② 1/(1+k·d²) 为什么是这个形状

物理上光的强度按**平方反比** `1/d²` 衰减。但纯 `1/d²` 在 d 趋近 0 时会爆炸，所以实时渲染常用 `1/(1+k·d²)` 这个「安全版」：d=0 时是 1，之后平滑下降。`1+` 项既防止除零，又让衰减可控。

### ③ 常见错误：先归一化再算距离

如果先 `normalize(lightVector)` 再 `length(lightVector)`，长度永远是 1，衰减完全失效。正确顺序是「先存距离、再归一化」，这也是为什么我把 `lightDistance` 单独提出来。
