# 第 40 课 · 光照模型对比

> 学习目标：在同一画面并排比较 Lambert、Phong、Blinn-Phong 与边缘光，理解不同光照模型的视觉差异。

> 场景准备：本课是**纯 2D 场景**，shader 贴在全屏四边形（Quad）或全屏 UI 上。四个球体都是数学解析出来的，并排显示。

---

## 1. 完整代码

```hlsl
Shader "Lesson/40_LightModelCompare"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                // —— 把屏幕切成 4 栏，每栏独立画一个球 ——
                float panelIndex = floor(IN.uv.x * 4.0);
                float2 panelUV = float2(frac(IN.uv.x * 4.0), IN.uv.y);
                float2 centeredUV = panelUV - 0.5;
                centeredUV.x *= _ScreenParams.x / _ScreenParams.y / 4.0;  // 修正本栏宽高比

                float3 backgroundColor = float3(0.05, 0.06, 0.08);
                float3 color = backgroundColor;

                // 射线与球求交（球心原点，半径 1），相机在 (0,0,-3)
                float3 rayOrigin = float3(0.0, 0.0, -3.0);
                float3 rayDirection = normalize(float3(centeredUV, 1.0));
                float centerProjection = dot(rayOrigin, rayDirection);
                float centerDistSqMinusRadiusSq = dot(rayOrigin, rayOrigin) - 1.0;
                float discriminant = centerProjection * centerProjection - centerDistSqMinusRadiusSq;

                if (discriminant >= 0.0)
                {
                    float hitDistance = -centerProjection - sqrt(discriminant);
                    float3 surfacePos = rayOrigin + rayDirection * hitDistance;
                    float3 normal = normalize(surfacePos);
                    float3 viewDir = -rayDirection;                       // 从表面指向相机
                    float3 lightDir = normalize(float3(-0.4, 0.6, 0.7));

                    float diffuse = max(dot(normal, lightDir), 0.0);
                    float3 baseColor = float3(0.18, 0.68, 0.95);

                    if (panelIndex < 1.0)
                    {
                        // 第一栏：Lambert 漫反射
                        color = baseColor * (0.15 + diffuse);
                    }
                    else if (panelIndex < 2.0)
                    {
                        // 第二栏：Phong 高光
                        float3 reflectDir = reflect(-lightDir, normal);
                        float phongSpec = pow(max(dot(reflectDir, viewDir), 0.0), 18.0);
                        color = baseColor * (0.15 + diffuse) + float3(1.0, 1.0, 1.0) * phongSpec * 0.55;
                    }
                    else if (panelIndex < 3.0)
                    {
                        // 第三栏：Blinn-Phong 高光
                        float3 halfVector = normalize(lightDir + viewDir);
                        float blinnSpec = pow(max(dot(normal, halfVector), 0.0), 28.0);
                        color = baseColor * (0.15 + diffuse) + float3(1.0, 1.0, 1.0) * blinnSpec * 0.65;
                    }
                    else
                    {
                        // 第四栏：边缘光
                        float rimFactor = pow(1.0 - max(dot(normal, viewDir), 0.0), 2.5);
                        color = baseColor * (0.15 + diffuse) + float3(0.85, 0.92, 1.0) * rimFactor * 0.9;
                    }
                }

                return half4(color, 1.0);
            }
            ENDHLSL
        }
    }
}
```

四个球体并排：第一栏纯漫反射，第二栏带 Phong 高光，第三栏带 Blinn-Phong 高光，第四栏带边缘光。

---

## 2. 分栏逻辑

```hlsl
float panelIndex = floor(IN.uv.x * 4.0);
float2 panelUV = float2(frac(IN.uv.x * 4.0), IN.uv.y);
```

`floor(uv.x * 4.0)` 把屏幕横向分成 0、1、2、3 四栏；`frac(uv.x * 4.0)` 得到每栏内部 0~1 的局部坐标。每栏用 `if` 分支走不同的光照公式。

---

## 3. 四种光照的区别

- **Lambert**：`baseColor * (0.15 + diffuse)`，只有漫反射，没有高光，效果稳定，适合卡通/哑光。
- **Phong**：用反射向量 `reflectDir` 和视线 `viewDir` 的夹角算高光，高光位置随视角移动。
- **Blinn-Phong**：用半向量 `halfVector` 替代反射向量，更高效、掠射角更稳定；同样视觉效果下指数通常是 Phong 的 2~4 倍（这里 28 vs 18）。
- **边缘光**：`pow(1 - dot(normal, viewDir), 2.5)`，法线越偏离视线边缘越亮，纯粹是视角效果，与光源无关。

## 5. 练习

练习代码里三种高光和边缘光全部为 0.0，只有第一栏有效果。补全三个 TODO，让四栏都正确显示。

### 答案解析

```hlsl
float phongSpec = pow(max(dot(reflectDir, viewDir), 0.0), 18.0);
float blinnSpec = pow(max(dot(normal, halfVector), 0.0), 28.0);
float rimFactor = pow(1.0 - max(dot(normal, viewDir), 0.0), 2.5);
```

Phong 用 `dot(reflectDir, viewDir)`（反射方向和视线对齐程度）；Blinn-Phong 用 `dot(normal, halfVector)`（法线和半向量对齐程度）；边缘光用 `1.0 - dot(normal, viewDir)`（法线偏离视线越多越强）。对比两种高光可注意到：同样视觉下 Blinn-Phong 的指数（28）大于 Phong（18）。

## 6. 【小灶解析】专家补充

### ① Phong vs Blinn-Phong：一个向量的差别

Phong 要先算 `reflect`（一次反射），再点乘视线；Blinn-Phong 直接算半向量 `normalize(lightDir + viewDir)`，省掉了反射计算。当相机和光源离物体很远时，半向量几乎不变，可以每帧只算一次——**这是实时渲染更常用 Blinn-Phong 的核心原因**。

### ② 指数换算经验值

同样的高光大小，Blinn-Phong 需要的指数约为 Phong 的 **2~4 倍**。所以把 Phong 的 18 换成 Blinn-Phong 的 28，两者看起来差不多。记住这个倍率，换模型时就不会「高光突然变大」。

### ③ 并排对比是学光照最快的方式

把不同模型放一起 A/B 对比，是 TA 建立「视觉直觉」最高效的方法。本课的「分栏 + 解析球体」结构很实用，以后你想对比任何 shader 变体，都可以套这个架子。
