# 第 90 课 · 往返移动亮带

> 学习目标：让一条水平亮带在竖直方向上来回往返（弹跳），理解「sin 生成往返运动」。

亮带的中心 y 坐标用 `sin` 驱动，亮带就在屏幕里上下弹跳。

---

## 1. 完整代码

```hlsl
Shader "Lesson/90_BouncingBand"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float bandCenterY = sin(_Time.y * 1.2) * 0.35 + 0.5;   // 0.15~0.85 往返

                float distanceToBand = abs(IN.uv.y - bandCenterY);
                float bandMask = 1.0 - smoothstep(0.05, 0.1, distanceToBand);

                float3 backgroundColor = float3(0.05, 0.05, 0.1);
                float3 bandColor = float3(0.3, 0.7, 1.0);
                float3 color = lerp(backgroundColor, bandColor, bandMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一条蓝色亮带，在屏幕上下来回弹跳，到顶到底都平滑掉头。

---

## 2. sin 自带「掉头」

`bandCenterY = sin(_Time.y * 1.2) * 0.35 + 0.5`：正弦波到峰值自然回落，所以亮带运动到顶就平滑减速、掉头向下，到底再掉头向上。**「往返弹跳」用 `sin` 天然实现，不需要任何条件判断。**

---

## 3. 亮带怎么画

`abs(IN.uv.y - bandCenterY)` 是每个像素到亮带中心的竖直距离；`smoothstep(0.05, 0.1, ...)` 在 0.05~0.1 内做柔和过渡，`1.0 -` 翻转后亮带中心最亮、上下渐暗。这是一个「水平亮带」的一维版本。

---

## 4. 位置范围 0.15~0.85

`sin` 输出 -1~1，`* 0.35` 后是 -0.35~0.35，`+ 0.5` 后是 0.15~0.85。这样亮带永远不会碰到屏幕上下边缘。如果想让它顶到边，把振幅调大即可。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 弹跳更快 | `1.2` 改成 `3.0` |
| 弹跳幅度更大 | `0.35` 改成 `0.48`（几乎顶到边） |
| 亮带更细 | `smoothstep(0.05, 0.1, ...)` 改成 `smoothstep(0.02, 0.04, ...)` |
| 改成左右弹跳 | `abs(IN.uv.y - bandCenterY)` 改成 `abs(IN.uv.x - bandCenterY)` |

## 6. 练习

练习代码里 `bandCenterY = 0.5`。补全用 `sin` 生成的往返中心坐标。

### 答案解析

```hlsl
float bandCenterY = sin(_Time.y * 1.2) * 0.35 + 0.5;
```

`sin(_Time.y * 1.2)` 在 -1~1 振荡，`* 0.35 + 0.5` 映射到 0.15~0.85。正弦波的峰值、谷值自然减速掉头，所以亮带平滑往返，无需 if 判断。

试着把 `sin` 换成 `frac(_Time.y * 0.5)`，看「平滑掉头」变成「瞬间跳回」的差别。

---

## 7. 【小灶解析】专家补充

### ① sin 是「平滑往返」的首选

需要「来回动」且「端点平滑」的动画，直接用 `sin`。它天然在两端减速掉头。如果你用 `frac` 做往返，会得到「瞬移回起点」的硬跳变——除非你就是要那种循环感（第 84 课滚动渐变）。

### ② 一维亮带 = 二维图案的切片

`abs(uv.y - center)` 是只关心竖直距离的「一维距离场」，画出的是一条水平带。把 y 换成 x 就是竖直带。**很多复杂图案都能拆成「一维距离场」的组合**，先吃透一维，二维只是两条一维的叠加。

### ③ 弹跳感 vs 匀速感

真正的「弹跳」其实更接近 `abs(sin)` 或抛物线，因为物体落地瞬间要「弹」。本课是正弦往返（两端减速），更像漂浮。若想要「弹球」效果，可以试 `1.0 - abs(sin(_Time.y * 3.0))`——谷底尖锐、弹跳有力。对比两种波形，体会「波形形状决定运动质感」。
