# 第 86 课 · 呼吸色块

> 学习目标：让一个矩形的尺寸随时间呼吸缩放，做出「膨胀收缩」的色块动画。

把矩形边长从固定值换成脉冲，色块就会一呼一吸。

---

## 1. 完整代码

```hlsl
Shader "Lesson/86_BreathingBlock"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;

                float breathe = sin(_Time.y) * 0.5 + 0.5;      // 0~1 呼吸
                float blockSize = lerp(0.1, 0.3, breathe);      // 边长在 0.1~0.3 往返

                float2 distanceComponents = abs(centeredUV) - blockSize;
                float blockMask = 1.0 - step(0.0, max(distanceComponents.x, distanceComponents.y));

                float3 backgroundColor = float3(0.05, 0.05, 0.08);
                float3 blockColor = float3(0.2, 0.8, 0.5);
                float3 color = lerp(backgroundColor, blockColor, blockMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面中心是一个绿色方块，从小到大又从大到小，像在呼吸。

---

## 2. 静态矩形回顾

`abs(centeredUV)` 取到中心的曼哈顿距离分量，`- blockSize` 后判断是否在矩形内（第 24 课）。`max(dx, dy)` 里只要有一个大于 0 就说明跑出了矩形，`step` + `1.0 -` 得到矩形遮罩。

---

## 3. 让尺寸呼吸

```hlsl
float breathe = sin(_Time.y) * 0.5 + 0.5;
float blockSize = lerp(0.1, 0.3, breathe);
```

`breathe` 是 0~1 脉冲，`lerp(0.1, 0.3, breathe)` 把边长映射到 0.1~0.3 之间往返。**`lerp` 在这里不是混合颜色，而是「把脉冲映射成尺寸」**——它是个通用插值工具。

---

## 4. 遮罩为什么用 step 而不是 smoothstep

矩形的硬边用 `step` 最干脆：内部全 1、外部全 0。如果想柔边，把 `step(0.0, ...)` 换成带过渡的 `smoothstep`。本课专注「呼吸」这个动画效果，所以保留硬边。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 呼吸更快 | `sin(_Time.y)` 改成 `sin(_Time.y * 3.0)` |
| 方块更大 | `lerp(0.1, 0.3, ...)` 改成 `lerp(0.1, 0.45, ...)` |
| 改成柔边方块 | `1.0 - step(0.0, max(...))` 改成 `1.0 - smoothstep(0.0, 0.02, max(...))` |
| 换成圆形呼吸 | 用 `length(centeredUV)` 和 `smoothstep` 重写遮罩 |

## 6. 练习

练习代码里 `breathe = 0.0`、`blockSize = 0.2`。补全呼吸脉冲，并用 `lerp` 把它映射到方块尺寸。

### 答案解析

```hlsl
float breathe = sin(_Time.y) * 0.5 + 0.5;
float blockSize = lerp(0.1, 0.3, breathe);
```

`breathe` 用 `sin(_Time.y) * 0.5 + 0.5` 得到 0~1 往返的脉冲；`lerp(0.1, 0.3, breathe)` 把这个脉冲映射成 0.1~0.3 的方块边长。边长随时间变化，方块就呼吸缩放。

试着把 `lerp(0.1, 0.3, ...)` 的两个端点改成 `0.05` 和 `0.4`，观察呼吸幅度变化。

## 7. 【小灶解析】专家补充

### ① lerp 是「万用映射」

`lerp(a, b, t)` 不止用来混色——它本质是把 0~1 的 t 映射到 a~b 的区间。用在这里把脉冲映射成尺寸，用在别处可以把脉冲映射成位置、角度、透明度、亮度。**看到一个 0~1 的值，就要想到「我可以用 lerp 把它映射到任何范围」。**

### ② 呼吸 = 时间驱动的缩放

「呼吸」这个词在动效里特指「缓慢、循环的缩放或透明度变化」。它的通用配方就是：`breathe = sin(_Time.y * speed) * 0.5 + 0.5`，再 `lerp` 到目标参数。UI 呼吸灯、加载动画、能量球都这么写。

### ③ 缩放会让形状「顶到边」

方块边长到 0.3 时已经快贴到屏幕边缘。真实场景里通常会叠一个 `smoothstep` 限制范围，或让缩放中心偏移。注意观察你做的呼吸是否超出屏幕，养成「检查边界」的习惯。
