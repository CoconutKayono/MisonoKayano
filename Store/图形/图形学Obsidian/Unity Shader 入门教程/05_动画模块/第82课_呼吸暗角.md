# 第 82 课 · 呼吸暗角

> 学习目标：把上一课的脉冲，接到「暗角」的边界上，让暗角范围随时间收缩扩张。

暗角（vignette）在第 21 课讲过：离中心越远越暗。这一课让它的边界「呼吸」起来。

---

## 1. 完整代码

```hlsl
Shader "Lesson/82_BreathingVignette"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;
                float distanceToCenter = length(centeredUV);

                // 边界在 0.3~0.8 之间往返
                float strength = sin(_Time.y) * 0.25 + 0.55;
                float vignette = 1.0 - smoothstep(strength - 0.15, strength, distanceToCenter);

                float3 baseColor = float3(0.1, 0.35, 0.75);
                float3 edgeColor = float3(0.0, 0.0, 0.0);
                float3 color = lerp(edgeColor, baseColor, vignette);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一块蓝色，四周的暗角一圈圈地往外扩又往回收，像在呼吸。

---

## 2. 静态暗角怎么画

`distanceToCenter = length(centeredUV)` 是每个像素到屏幕中心的距离，范围约 0~0.7。`smoothstep(strength - 0.15, strength, distanceToCenter)`：离中心越远，这个值越接近 1，表示「越接近暗角边缘」。`1.0 -` 翻转后，中心是 1（保留底色）、边缘是 0（变黑），就是标准暗角。

---

## 3. 让边界动起来

```hlsl
float strength = sin(_Time.y) * 0.25 + 0.55;
```

`strength` 在 0.3~0.8 之间往返。它决定 `smoothstep` 的边界位置：strength 大时暗角边界往外移（暗角收缩），strength 小时边界往内收（暗角扩张）。**把静态参数换成时间函数，静态效果就变成动画**——这是本课的核心动作。

---

## 4. 为什么用 0.15 的过渡带

`smoothstep(strength - 0.15, strength, ...)` 两个端点相差 0.15，是暗角的柔和过渡宽度。过渡带越窄，明暗交界越锐利；越宽越柔和。让边界「呼吸」时，过渡带保持不变，只有位置在动。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 呼吸幅度更大 | `0.25` 改成 `0.4`（边界在 0.15~0.95 之间往返） |
| 过渡更硬 | `0.15` 改成 `0.03` |
| 暗角更柔和 | `0.15` 改成 `0.3` |
| 底色变绿 | `baseColor` 改成 `float3(0.15, 0.6, 0.3)` |

### 答案解析

```hlsl
float strength = sin(_Time.y) * 0.25 + 0.55;
float vignette = 1.0 - smoothstep(strength - 0.15, strength, distanceToCenter);
```

`strength` 用 `sin(_Time.y) * 0.25 + 0.55` 在 0.3~0.8 往返，作为暗角边界。`smoothstep` 在 `strength - 0.15` 到 `strength` 之间做 0~1 的柔和过渡，`1.0 -` 翻转后中心亮、边缘暗，得到呼吸暗角。

## 7. 【小灶解析】专家补充

### ① 参数化 = 动画化

一个效果只要把「关键数值」抽出来，就具备了被时间驱动的能力。暗角的边界、圆形的半径、颜色混合的比例……任何参数都能换成 `sin(_Time.y) * 幅度 + 偏移` 变成动画。**写 shader 时养成「哪些数是参数」的意识，是走向程序化动画的第一步。**

### ② 偏移 + 幅度控制取值范围

`sin(t) * 0.25 + 0.55` 拆开看：`0.25` 是振幅（决定动多大幅度），`0.55` 是中心值（决定围绕哪里动）。想要一个值在 `[a, b]` 之间往返，公式就是 `sin(t) * ((b-a)/2) + ((a+b)/2)`。这是一个通用套路。

### ③ 暗角是后处理常客

真实游戏里暗角通常在后处理阶段做（URP 的 Vignette 组件），但原理和这里一模一样：以屏幕中心为圆心的径向渐变。理解了 shader 版暗角，你就理解了后处理暗角在算什么。
