# 第 94 课 · 波纹

> 学习目标：做出从中心向外扩散、逐渐衰减的水面波纹，为动画模块收尾。

波纹 = 距离场 + `sin` 折叠 + 径向衰减 + 时间推进，是本模块的综合课。

---

## 1. 完整代码

```hlsl
Shader "Lesson/94_Ripple"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;
                float distanceToCenter = length(centeredUV);

                // sin 折叠出同心环，时间让它向外扩散
                float ripple = sin(distanceToCenter * 30.0 - _Time.y * 4.0);
                float rippleMask = ripple * 0.5 + 0.5;

                // 越往外越淡，波纹逐渐消失
                rippleMask *= 1.0 - smoothstep(0.0, 0.5, distanceToCenter);

                float3 backgroundColor = float3(0.02, 0.05, 0.12);
                float3 rippleColor = float3(0.3, 0.8, 1.0);
                float3 color = lerp(backgroundColor, rippleColor, rippleMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一圈圈从中心向外扩散、边缘逐渐消失的淡蓝色水波纹。

---

## 2. 同心环从哪来

`sin(distanceToCenter * 30.0)`：把到中心的距离乘 30 再取正弦，距离每变化一段，正弦就来回一次，于是画出明暗相间的同心环。**「sin(距离 × 频率)」是画同心波纹的标准手法**，和第 50 课的 `frac` 折叠异曲同工。

---

## 3. 时间让它扩散

`sin(distanceToCenter * 30.0 - _Time.y * 4.0)` 里的 `- _Time.y * 4.0` 是相位偏移。时间推进时，波纹的明暗环整体向外移动，看起来就是波纹从中心扩散。**「减号」决定扩散方向**——想让它向中心收缩就改成加号。

---

## 4. 径向衰减

`rippleMask *= 1.0 - smoothstep(0.0, 0.5, distanceToCenter)`：靠近中心波纹清晰，越往外越淡，到边缘完全消失。没有这行，波纹会一直延伸到屏幕边，不像真实水波。**衰减让波纹「有源头、有尽头」**。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 波纹更密 | `30.0` 改成 `60.0` |
| 扩散更快 | `4.0` 改成 `8.0` |
| 波纹向中心收缩 | `- _Time.y * 4.0` 改成 `+ _Time.y * 4.0` |
| 衰减更快（波纹范围更小） | `smoothstep(0.0, 0.5, ...)` 改成 `smoothstep(0.0, 0.25, ...)` |

## 6. 练习

练习代码里 `ripple = 0.0`、`rippleMask` 没有衰减。补全 sin 折叠和径向衰减。

### 答案解析

```hlsl
float ripple = sin(distanceToCenter * 30.0 - _Time.y * 4.0);
float rippleMask = ripple * 0.5 + 0.5;
rippleMask *= 1.0 - smoothstep(0.0, 0.5, distanceToCenter);
```

`sin(distanceToCenter * 30.0 - _Time.y * 4.0)` 用距离做正弦折叠、用时间做相位偏移，产生向外扩散的同心波纹；`* 0.5 + 0.5` 映射到 0~1；最后乘 `1.0 - smoothstep(...)` 让波纹随距离衰减。

试着在 `sin` 里再加一项 `+ distanceToCenter * 10.0`，观察频率随距离变化（啁啾）的效果。

## 7. 【小灶解析】专家补充

### ① 恭喜完成动画模块

到这里，你掌握了 shader 动画的核心套路：**`sin(t)*0.5+0.5` 做脉冲、`frac` 做循环、时间驱动位置/尺寸/角度、旋转矩阵、坐标扭曲、径向衰减**。这些是 2D 程序化动画的全部常用积木。

### ② 波纹 = 距离场 + 相位推进

把「距离场 + 相位推进」这个组合记牢：距离场决定图案的「空间结构」，相位推进决定图案「如何随时间流动」。不只是波纹，声波可视化、能量扩散、冲击波特效都是同一套。

### ③ 动画模块之后的下一步

你现在能独立写出呼吸、滚动、旋转、波纹等动画 shader。下一步的自然延伸是：**噪声（noise）**——用不规则函数替代 `sin`，做出火焰、云、水面、地形；以及**后处理（post-processing）**——把 shader 应用到整个屏幕画面，做模糊、扭曲、调色。这两个方向会让你的 TA 技能树长出新的大枝干。
