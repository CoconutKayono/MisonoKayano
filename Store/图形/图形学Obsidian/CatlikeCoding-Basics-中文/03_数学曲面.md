## 函数库

完成[上一篇教程](02_构建图表.md)后，我们有了一个在运行模式下显示动画正弦波的点状图表。它也可以显示其他数学函数。你可以修改代码，函数也会随之改变。你甚至可以在 Unity 编辑器处于运行模式时这样做。执行会被暂停，当前游戏状态被保存，然后脚本重新编译，最后游戏状态被重新加载并继续运行。这就是所谓的热重载（hot reload）。并非所有东西都能在热重载中存活，但我们的图表可以。它会切换到动画显示新的函数，而完全意识不到发生了什么变化。

虽然在运行模式下修改代码很方便，但这并不是在多个函数之间来回切换的好办法。如果能够通过图表的一个配置选项来改变函数，那就好多了。

### 库类

我们本可以在 `Graph` 里声明多个数学函数，但让这个类专注于显示函数、而对具体的数学方程一无所知会更好。这是特化（specialization）和关注点分离（separation of concerns）的一个例子。

新建一个 `FunctionLibrary` C# 脚本，把它放到 *Scripts* 文件夹里，挨着 `Graph`。你可以用菜单选项创建新资源，也可以复制 `Graph` 再重命名。无论哪种方式，清空文件内容，从使用 `UnityEngine` 开始，并声明一个不继承任何东西的空 `FunctionLibrary` 类。

```diff
+using UnityEngine;

+public class FunctionLibrary {}
```

这个类不会是一个组件类型。我们也不会创建它的对象实例。相反，我们用它来提供一组可公开访问的、代表数学函数的方法，类似于 Unity 的 `Mathf`。

要表明这个类不被当作对象模板使用，可以把它标记为 static——在 `class` 前写上 `static` 关键字。

```diff
public static class FunctionLibrary {}
```

### 函数方法

我们的第一个函数将是 `Graph` 当前显示的那个正弦波。我们需要为它创建一个方法。这和创建 `Awake` 或 `Update` 方法的方式相同，只不过这次我们把它命名为 `Wave`。

```diff
public static class FunctionLibrary {

+	void Wave () {}
}
```

默认情况下方法是实例方法，也就是说必须在对象实例上调用它们。要让它们直接在类级别上工作，我们必须把它标记为 static，就像 `FunctionLibrary` 本身一样。

```diff
+	static void Wave () {}
```

再给它加上 `public` 访问修饰符，使它可公开访问。

```diff
+	public static void Wave () {}
```

这个方法将表示我们的数学函数 `f(x,t)=sin(pi(x+t))`。这意味着它必须产生一个结果，这个结果必须是浮点数。所以函数的返回类型需要是 `float`，而不是 `void`。

```diff
	public static float Wave () {}
```

接下来，我们要在方法的参数列表中加入两个参数，就像数学函数那样。唯一不同的是，我们必须在每个参数前写出类型，也就是 `float`。

```diff
	public static float Wave (float x, float t) {}
```

现在我们可以把计算正弦波的代码放进方法里，使用它的 `x` 和 `t` 参数。

```diff
	public static float Wave (float x, float t) {
+		Mathf.Sin(Mathf.PI * (x + t));
	}
```

最后一步是明确指明方法的结果是什么。因为这是一个 `float` 方法，所以结束时它必须返回一个 `float` 值。我们通过写 `return` 后面跟上结果来表明这一点，这个结果就是我们的数学计算。

```diff
	public static float Wave (float x, float t) {
+		return Mathf.Sin(Mathf.PI * (x + t));
	}
```

现在就可以在 `Graph.Update` 里调用这个方法了，把 `position.x` 和 `time` 作为其参数的实参。它的结果可以用来设置点的 Y 坐标，取代显式的数学方程。

```diff
	void Update () {
		float time = Time.time;
		for (int i = 0; i < points.Length; i++) {
			Transform point = points[i];
			Vector3 position = point.localPosition;
			position.y = FunctionLibrary.Wave(position.x, time);
			point.localPosition = position;
		}
	}
```

### 隐式使用类型

我们在 `FunctionLibrary` 里会大量使用 `Mathf.PI`、`Mathf.Sin` 以及 `Mathf` 的其他方法。如果能不用每次显式地写出类型名就好了。我们可以通过在 `FunctionLibrary` 文件顶部再加一条 `using` 语句来实现，在额外的 `static` 关键字后面跟上显式的 `UnityEngine.Mathf` 类型。这样该类型的所有常量和静态成员就都可以直接使用，而无需显式写出类型本身。

```diff
using UnityEngine;

+using static UnityEngine.Mathf;

public static class FunctionLibrary { … }
```

现在我们就可以省略 `Mathf`，把 `Wave` 中的代码缩短。

```diff
	public static float Wave (float x, float z, float t) {
		return Sin(PI * (x + t));
	}
```

### 第二个函数

我们再添加一个函数方法。这次我们做一个稍微复杂一点的函数，用到不止一个正弦波。先把 `Wave` 方法复制一份，重命名为 `MultiWave`。

```diff
	public static float Wave (float x, float t) {
		return Sin(PI * (x + t));
	}

+	public static float MultiWave (float x, float t) {
+		return Sin(PI * (x + t));
+	}
```

我们保留已有的正弦函数，但给它加上一些额外的东西。为了做起来容易，先把当前结果赋给一个 `y` 变量，然后再返回它。

```diff
	public static float MultiWave (float x, float t) {
+		float y = Sin(PI * (x + t));
+		return y;
	}
```

给正弦波增加复杂度最简单的方式是再加一个频率加倍的正弦波。这意味着它变化的速度是原来的两倍，做法是把正弦函数的参数乘以 2。同时，我们把该函数的结果减半。这样新正弦波的形状与原来相同，但大小只有一半。

```diff
		float y = Sin(PI * (x + t));
+		y += Sin(2f * PI * (x + t)) / 2f;
		return y;
```

这就给出了数学函数 `f(x,t)=sin(pi(x+t))+sin(2pi(x+t))/2`。由于正弦函数正负极值分别是 1 和 −1，这个新函数的最大值和最小值可能是 1.5 和 −1.5。为了保证我们保持在 −1–1 的范围内，我们应该把和除以 1.5。

```diff
		return y / 1.5f;
```

除法比乘法要多花一点功夫，所以经验法则是优先用乘法而不是除法。不过像 `1f / 2f` 以及 `2f * Mathf.PI` 这样的常量表达式，编译器已经把它们的值折成一个数字了。所以我们可以改写代码，让运行时只做乘法。我们必须利用运算顺序和括号，确保常量部分先被折叠。

```diff
		y += Sin(2f * PI * (x + t)) * (1f / 2f);
		return y * (2f / 3f);
```

我们也可以直接把 `1f / 2f` 写成 `0.5f`，但 1.5 的倒数无法用十进制精确表示，所以继续用 `2f / 3f`，编译器会把它折成精度最高的浮点表示。

```diff
		y += 0.5f * Sin(2f * PI * (x + t));
```

现在在 `Graph.Update` 里用这个函数取代 `Wave`，看看它长什么样。

```diff
			position.y = FunctionLibrary.MultiWave(position.x, time);
```

两道正弦波之和。

你可以说现在是一道较小的正弦波跟着一道较大的正弦波。我们也可以让小的那道沿着大的那道滑动，比如把大波的时间减半。结果将是一个随时间推移不只是平移、而且形状也在变化的函数。现在这个图案要四秒才重复一次。

```diff
		float y = Sin(PI * (x + 0.5f * t));
		y += 0.5f * Sin(2f * PI * (x + t));
```

变形波。

### 在编辑器中选择函数

接下来我们可以添加一些代码，让 `Graph` 使用哪个方法变得可控。我们可以用一个滑动条来实现，就像图表的 resolution 那样。因为我们要在两个函数之间选择，所以需要一个范围为 0–1 的可序列化整数字段。把它命名为 `function`，让它控制什么一目了然。

```diff
	[SerializeField, Range(10, 100)]
	int resolution = 10;

+	[SerializeField, Range(0, 1)]
+	int function;
```

![函数滑动条。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/function-library/function-slider.png)

现在我们可以在 `Update` 的循环里检查 `function`。如果它是零，图表就应该显示 `Wave`。为了做出这个选择，我们使用 `if` 语句，后面跟一个表达式和一个代码块。这跟 `while` 类似，只不过它不会循环回去，所以代码块要么执行、要么被跳过。这里的测试是 `function` 是否等于零，可以用 `==` 相等运算符来完成。

```diff
	void Update () {
		float time = Time.time;
		for (int i = 0; i < points.Length; i++) {
			Transform point = points[i];
			Vector3 position = point.localPosition;
+			if (function == 0) {
				position.y = FunctionLibrary.Wave(position.x, time);
+			}
			point.localPosition = position;
		}
	}
```

我们可以在 if 块后面跟一个 `else` 和另一个代码块，如果测试失败就执行它。这种情况下，图表应该显示 `MultiWave`。

```diff
			if (function == 0) {
				position.y = FunctionLibrary.Wave(position.x, time);
			}
+			else {
+				position.y = FunctionLibrary.MultiWave(position.x, time);
+			}
```

这样就能通过图表的 Inspector 控制函数了，在运行模式下也可以。

> **在运行模式下拖动 resolution 滑动条有效果吗？**
>
> 那会改变图表的 resolution 值，但 `Graph.Update` 并不依赖它，所以没有可见的效果。要在运行模式下改变点的数量，需要删除和实例化点，但本教程不支持这样做。

### 波纹函数

让我们给库添加第三个函数，一个产生类似波纹效果的函数。我们通过让一道正弦波从原点向外扩散来创建它，而不是总是朝同一个方向传播。我们可以基于到中心的距离来实现，也就是 X 的绝对值。先在一个新的 `FunctionLibrary.Ripple` 方法里只计算这个距离，借助 `Mathf.Abs`。把距离存进 `d` 变量，然后返回它。

```diff
+	public static float Ripple (float x, float t) {
+		float d = Abs(x);
+		return d;
	}
```

要显示它，把 `Graph.function` 的范围增大到 2，并在 `Update` 里为 `Wave` 方法再添加一个代码块。我们可以通过在 `else` 之后直接再写一个 `if` 来串联多个条件块，这样就变成了一个 else-if 块，当 `function` 等于 1 时执行。然后为波纹添加一个新的 `else` 块。

```diff
	[SerializeField, Range(0, 2)]
	…

	void Update () {
		float time = Time.time;
		for (int i = 0; i < points.Length; i++) {
			Transform point = points[i];
			Vector3 position = point.localPosition;
			if (function == 0) {
				position.y = FunctionLibrary.Wave(position.x, time);
			}
			else if (function == 1) {
				position.y = FunctionLibrary.MultiWave(position.x, time);
			}
+			else {
+				position.y = FunctionLibrary.Ripple(position.x, time);
+			}
			point.localPosition = position;
		}
	}
```

![X 的绝对值。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/function-library/absolute-x.png)

回到 `FunctionLibrary.Ripple`，我们把距离作为正弦函数的输入，并让它成为结果。具体来说，我们用 `y=sin(4pid)`，其中 `d=|x|`，这样波纹就会在图表的定义域里上下起伏多次。

```diff
	public static float Ripple (float x, float t) {
		float d = Abs(x);
+		float y = Sin(4f * PI * d);
		return y;
	}
```

![距离的正弦。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/function-library/sin-d.png)

结果在视觉上很难解读，因为 Y 变化得太多了。我们可以通过减小波的振幅来缓解。但波纹没有固定的振幅，它会随距离衰减。所以让我们把函数改成 `y=sin(4pid)/(1+10d)`。

```diff
		float y = Sin(4f * PI * d);
		return y / (1f + 10f * d);
```

最后的润色是让波纹动起来。要让它向外流动，我们必须从传给正弦函数的值中减去时间。我们用 `pit`，这样最终函数就是 `y=sin(pi(4d-t))/(1+10d)`。

```diff
		float y = Sin(PI * (4f * d - t));
		return y / (1f + 10f * d);
```

动画波纹。

## 管理方法

一连串的条件块对两三个函数还行，但要支持更多函数就会很快变得难以维护。如果我们能够根据某种条件向库要一个方法的引用，然后反复调用它，那就方便多了。

### 委托

使用委托（delegate）可以获取方法的引用。委托是一种特殊类型，它定义了什么方法可以被引用。对于我们的数学函数方法，没有标准的委托类型，但我们可以自己定义。因为它是一种类型，我们可以把它放在自己的文件里，但由于它专门用于我们库的方法，我们将把它定义在 `FunctionLibrary` 类内部，使它成为内部类型或嵌套类型。

要创建委托类型，复制 `Wave` 函数，重命名为 `Function`，并把它的代码块替换为分号。这样就定义了一个没有实现的方法签名。然后我们把 `static` 关键字替换成 `delegate`，把它变成委托类型。

```diff
public static class FunctionLibrary {

	public delegate float Function (float x, float t);

	…
}
```

现在我们可以引入一个 `GetFunction` 方法，它根据一个索引参数返回一个 `Function`，使用与循环中相同的 if-else 逻辑，只不过在每个块里我们返回相应的方法，而不是调用它。

```diff
	public delegate float Function (float x, float t);

+	public static Function GetFunction (int index) {
+		if (index == 0) {
+			return Wave;
+		}
+		else if (index == 1) {
+			return MultiWave;
+		}
+		else {
+			return Ripple;
+		}
+	}
```

接下来，我们在 `Graph.Update` 的开头用这个方法，根据 `function` 获取一个函数委托，并把它存进一个变量。因为这段代码不在 `FunctionLibrary` 内部，我们必须把嵌套的委托类型写成 `FunctionLibrary.Function`。

```diff
	void Update () {
+		FunctionLibrary.Function f = FunctionLibrary.GetFunction(function);
		…
	}
```

然后在循环里调用委托变量，而不是显式的方法。

```diff
		for (int i = 0; i < points.Length; i++) {
			Transform point = points[i];
			Vector3 position = point.localPosition;
-			//if (function == 0) {
-			//	position.y = FunctionLibrary.Wave(position.x, time);
-			//}
-			//else if (function == 1) {
-			//	position.y = FunctionLibrary.MultiWave(position.x, time);
-			//}
-			//else {
-			//	position.y = FunctionLibrary.Ripple(position.x, time);
-			//}
+			position.y = f(position.x, time);
			point.localPosition = position;
		}
```

### 委托数组

我们大大简化了 `Graph.Update`，但只是把 if-else 代码挪到了 `FunctionLibrary.GetFunction`。我们可以通过改用数组索引来彻底消除这段代码。先给 `FunctionLibrary` 添加一个 `functions` 数组的静态字段。这个数组仅供内部使用，所以不要设为 public。

```diff
	public delegate float Function (float x, float t);

+	static Function[] functions;

	public static Function GetFunction (int index) { … }
```

我们总是往这个数组里放相同的元素，所以可以在声明时显式定义它的内容。做法是赋一个逗号分隔的数组元素序列，放在花括号之间。最简单的是一个空列表。

```diff
	static Function[] functions = {};
```

这意味着我们立即得到一个数组实例，但它是空的。把它改成包含指向我们方法的委托，顺序与之前相同。

```diff
	static Function[] functions = { Wave, MultiWave, Ripple };
```

现在 `GetFunction` 方法只需索引数组，返回相应的委托。

```diff
	public static Function GetFunction (int index) {
+		return functions[index];
	}
```

> **为什么不直接把数组设为 public？**
>
> 那样任何代码都可以修改这个数组。把它对库保持私有，我们就保证了它永远不会改变。

### 枚举

整数滑动条能用，但 0 代表波函数这一点并不明显。如果有一个包含函数名称的下拉列表，就会清晰得多。我们可以用枚举（enumeration）来实现。

枚举可以通过定义一个 `enum` 类型来创建。我们再一次在 `FunctionLibrary` 内部定义，这次命名为 `FunctionName`。这种情况下，类型名后面跟着花括号内的标签列表。我们可以复制数组元素列表，但不要分号。注意这些是简单的标签，它们不引用任何东西，尽管它们遵循与类型名相同的规则。保持这两个列表一致是我们的责任。

```diff
	public delegate float Function (float x, float t);

+	public enum FunctionName { Wave, MultiWave, Ripple }

	static Function[] functions = { Wave, MultiWave, Ripple };
```

现在把 `GetFunction` 的索引参数替换为类型为 `FunctionName` 的 name 参数。这表明实参必须是一个有效的函数名。

```diff
	public static Function GetFunction (FunctionName name) {
		return functions[name];
	}
```

枚举可以视为语法糖。默认情况下，枚举的每个标签代表一个整数。第一个标签对应 0，第二个对应 1，依此类推。所以我们可以用名字来索引数组。然而编译器会报错，说枚举不能隐式转换为整数。我们必须显式地进行转换。

```diff
		return functions[(int)name];
```

最后一步是把 `Graph.function` 字段的类型改为 `FunctionLibrary.FunctionName`，并移除它的 `Range` 属性。

```diff
-	//[SerializeField, Range(0, 2)]
+	[SerializeField]
+	FunctionLibrary.FunctionName function;
```

`Graph` 的 Inspector 现在会显示一个包含函数名称的下拉列表，大写单词之间会自动加空格。

![函数下拉列表。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/managing-methods/function-name.png)

## 增加另一个维度

到目前为止，我们的图表只包含单行的点。我们把 1 维值映射到其他 1D 值，尽管如果把时间算进去，它实际上是把 2D 值映射到 1D 值。所以我们已经在把更高维的输入映射到 1D 值了。就像我们加入时间那样，我们也可以加入额外的空间维度。

目前，我们使用 X 维度作为函数的空间输入。Y 维度用来显示输出。这样 Z 就留作第二个用于输入的空间维度。把 Z 加为输入，就把我们的线升级成了一个方形网格。

### 3D 颜色

Z 不再恒定之后，修改我们的 *Point Surface* 着色器，让它也修改蓝色的反照率分量，从赋值中移除 `.rg` 和 `.xy` 代码。

```diff
			surface.Albedo = saturate(input.worldPos * 0.5 + 0.5);
```

并调整我们的 *Point URP* 着色器图，让 Z 与 X 和 Y 一样被处理。

![调整过的 Multiply 和 Add 节点输入。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/adding-another-dimension/shader-graph.png)

### 升级函数

为了给我们的函数支持第二个非时间输入，在 `FunctionLibrary.Function` 委托类型的 `x` 参数之后加一个 `z` 参数。

```diff
	public delegate float Function (float x, float z, float t);
```

这要求我们也要给三个函数方法加上这个参数。

```diff
	public static float Wave (float x, float z, float t) { … }

	public static float MultiWave (float x, float z, float t) { … }

	public static float Ripple (float x, float z, float t) { … }
```

并且在 `Graph.Update` 里调用函数时，把 `position.z` 作为实参加上。

```diff
			position.y = f(position.x, position.z, time);
```

### 创建点的网格

要显示 Z 维度，我们必须把点组成的线变成点的网格。我们可以通过创建多条线来实现，每条线沿 Z 偏移一步。我们让 Z 的范围与 X 相同，所以创建的线的数量与我们当前点的数量一样多。这意味着点的数量要平方。调整 `Awake` 里 `points` 数组的创建，让它大到能容纳所有点。

```diff
		points = new Transform[resolution * resolution];
```

因为我们在 `Awake` 的循环里每次迭代都根据 resolution 增加 X 坐标，所以仅仅创建更多点只会得到一条很长的线。我们必须调整初始化循环，把第二个维度考虑进去。

![2500 个点组成的长线。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/adding-another-dimension/long-line.png)

首先，让我们显式地跟踪 X 坐标。做法是在 `for` 循环里、与 `i` 迭代变量一起声明并递增一个 `x` 变量。`for` 语句的第三部分可以为此变成一个逗号分隔的列表。

```diff
		points = new Transform[resolution * resolution];
		for (int i = 0, x = 0; i < points.Length; i++, x++) {
			…
		}
```

每次我们完成一行，就必须把 `x` 重置回零。当 `x` 等于 `resolution` 时，一行结束，所以我们可以用循环顶部的一个 `if` 块来处理。然后用 `x` 而不是 `i` 来计算 X 坐标。

```diff
		for (int i = 0, x = 0; i < points.Length; i++, x++) {
+			if (x == resolution) {
+				x = 0;
+			}
			Transform point = points[i] = Instantiate(pointPrefab);
			position.x = (x + 0.5f) * step - 1f;
			…
		}
```

接下来，每一行都要沿 Z 维度偏移。这可以通过也在 `for` 循环里加一个 `z` 变量来实现。这个变量不能每次迭代都递增。相反，它只在我们进入下一行时递增，而我们已经为此有了一个 `if` 块。然后像设置 X 坐标那样设置位置的 Z 坐标，用 `z` 而不是 `x`。

```diff
		for (int i = 0, x = 0, z = 0; i < points.Length; i++, x++) {
			if (x == resolution) {
				x = 0;
+				z += 1;
			}
			Transform point = points[i] = Instantiate(pointPrefab);
			position.x = (x + 0.5f) * step - 1f;
+			position.z = (z + 0.5f) * step - 1f;
			…
		}
```

现在我们创建的是一个方形点阵，而不是单条线。因为我们的函数仍然只使用 X 维度，它看起来就像原来的点被拉伸成了线。

![图表网格。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/adding-another-dimension/grid.png)

### 更好的视觉效果

除此之外，我们可以微调一下阴影质量。使用默认渲染管线时阴影可能已经可以接受，但它们的配置是针对远距离观察的，而我们现在是近距离观察图表。

你可以通过进入 *Quality* 项目设置并选择其中一个预配置级别，来为默认渲染管线选择视觉质量级别。默认下拉框控制独立应用默认使用哪个级别。

![质量级别。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/adding-another-dimension/quality-levels.png)

我们可以进一步微调阴影的性能和精度，进入下方的 *Shadows* 部分，把 *Shadow Distance* 减小到 10，并把 *Shadow Cascades* 设为 *No Cascades*。默认设置会渲染阴影四次，对我们来说过于浪费了。

![默认渲染管线的阴影设置。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/adding-another-dimension/shadow-settings-default-quality.png)

> **阴影级联和距离控制的是什么？**
>
> Unity——以及大多数游戏引擎——把阴影投射体渲染到纹理中，之后再采样这些纹理来生成阴影。这些阴影贴图有固定的分辨率。如果它们必须覆盖很大的区域，单个像素也会变大，导致块状的阴影。
>
>
> 通过减小最大阴影距离，我们减小了阴影贴图必须覆盖的区域，从而提高了阴影质量，代价是失去远处的阴影。
>
>
> 阴影级联在此基础上，对方向光更进一步：根据距离使用多张贴图，使近处阴影的有效分辨率比远处阴影更高。两种渲染管线都支持最多四个级联。

URP 不使用这些设置，它的阴影是通过我们的 *URP* 资源的 Inspector 配置的。默认情况下它已经只渲染一次方向光阴影，但 *Shadows / Max Distance* 可以减小到 10。另外，为了匹配默认渲染管线标准的 *Ultra* 质量，启用 *Shadows / Soft Shadows*，并把 *Lighting* 下 *Lighting / Main Light / Shadow Resolution* 提高到 4096。

![URP 的阴影设置。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/adding-another-dimension/shadow-settings-urp-inspector.png)

最后，你在运行模式下可能会注意到视觉撕裂。这可以通过游戏窗口工具栏左侧第二个下拉菜单启用 *VSync (Game view only)* 来防止。启用后，新帧的呈现会与显示刷新率同步。这只有在同时没有场景窗口可见时才能可靠工作。独立应用的 VSync 通过质量设置的 *Other* 部分来配置。

![为游戏窗口启用 VSnyc。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/adding-another-dimension/game-window-vsync.png)

> **为什么帧率下降了？**
>
> 与之前单条线相比，网格包含的点要多得多。分辨率 50 时有 2,500 个点。分辨率 100 时有 10,000 个点。为了获得最佳性能，任何时候都只让一个场景或游戏窗口可见。另外，确保 `Graph` 的对象层级在 Hierarchy 窗口中是折叠的，这样就不必列出任何点了。
>
>
> 我们将在下一篇教程中更仔细地探讨性能。

### 融入 Z

在 `Wave` 函数里使用 Z 最简单的方式是使用 X 和 Z 的和，而不是只用 X。那会创建一道对角线方向的波。

```diff
	public static float Wave (float x, float z, float t) {
		return Sin(PI * (x + z + t));
	}
```

对角线波。

而 `MultiWave` 最直接的改动是让每道波使用各自的维度。让我们让小的那道使用 Z。

```diff
	public static float MultiWave (float x, float z, float t) {
		float y = Sin(PI * (x + 0.5f * t));
		y += 0.5f * Sin(2f * PI * (z + t));
		return y * (2f / 3f);
	}
```

两个维度上的两道波。

我们还可以加入第三道沿 XZ 对角线传播的波。让我们使用与 `Wave` 相同的波，只是时间放慢到四分之一。然后把结果除以 2.5 来缩放，让它保持在 −1–1 范围内。

```diff
		float y = Sin(PI * (x + 0.5f * t));
		y += 0.5f * Sin(2f * PI * (z + t));
+		y += Sin(PI * (x + z + 0.25f * t));
		return y * (1f / 2.5f);
```

注意，第一道波和第三道波会以规律的间隔相互抵消。

三道波。

最后，要让波纹在 XZ 平面上向所有方向扩散，我们必须计算两个维度上的距离。我们可以用勾股定理，借助 `Mathf.Sqrt` 方法。

> **什么是勾股定理？**
>
> 勾股定理指出 `a^2+b^2=c^2`，其中 `c` 是直角三角形斜边的长度，`a` 和 `b` 是它另外两条边的长度。
>
>
> ![使用勾股定理。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/adding-another-dimension/pythagorean-theorem.png)
>
>
> 对于 XZ 平面中的 2D 点，这样一个三角形的斜边对应原点到该点的线段，其 X 和 Z 坐标是另外两条边的长度。因此我们每个点到原点的距离是 `sqrt(x^2+z^2)`。

```diff
	public static float Ripple (float x, float z, float t) {
		float d = Sqrt(x * x + z * z);
		float y = Sin(PI * (4f * d - t));
		return y / (1f + 10f * d);
	}
```

XZ 平面上的波纹。

## 离开网格

通过用 X 和 Z 来定义 Y，我们能创建描述各种各样曲面的函数，但它们总是绑定在 XZ 平面上。不可能有两个点拥有相同的 X 和 Z 坐标却有不同的 Y 坐标。这意味着我们曲面的曲率是有限的。它们的斜率不能变成垂直，也不能向后折叠。要实现这些，我们的函数就不能只输出 Y，还要输出 X 和 Z。

### 三维函数

如果我们的函数输出 3D 位置而不是 1D 值，我们就可以用它们创建任意曲面。例如，函数 `f(x,z)=[[x],[0],[z]]` 描述 XZ 平面，而函数 `f(x,z)=[[x],[z],[0]]` 描述 XY 平面。

因为这些函数的输入参数不再需要对应最终的 X 和 Z 坐标，再叫它们 `x` 和 `z` 就不合适了。相反，它们用来创建参数曲面，通常被命名为 `u` 和 `v`。所以我们得到像 `f(u,v)=[[u],[sin(pi(u+v))],[v]]` 这样的函数。

调整我们的 `Function` 委托类型来支持这种新方法。唯一必需的改动是把它的 `float` 返回类型替换为 `Vector3`，但我们也顺便重命名它的参数。

```diff
	public delegate Vector3 Function (float u, float v, float t);
```

我们也要相应地调整函数方法。我们直接让 U 和 V 分别作为 X 和 Z。并不要求调整参数名——只有它们的类型需要与委托匹配——但为了保持一致，我们还是这么做。如果你的代码编辑器支持，你可以通过菜单或上下文菜单选项快速重构重命名参数和其他东西，一次把所有用到的地方都改名。

从 `Wave` 开始。让它先声明一个 `Vector3` 变量，然后设置它的分量，最后返回它。我们不必给向量一个初始值，因为在返回之前我们设置了它的所有字段。

```diff
	public static Vector3 Wave (float u, float v, float t) {
+		Vector3 p;
+		p.x = u;
+		p.y = Sin(PI * (u + v + t));
+		p.z = v;
+		return p;
	}
```

然后对 `MultiWave` 和 `Ripple` 做同样的处理。

```diff
	public static Vector3 MultiWave (float u, float v, float t) {
+		Vector3 p;
+		p.x = u;
+		p.y = Sin(PI * (u + 0.5f * t));
+		p.y += 0.5f * Sin(2f * PI * (v + t));
+		p.y += Sin(PI * (u + v + 0.25f * t));
+		p.y *= 1f / 2.5f;
+		p.z = v;
+		return p;
	}

	public static Vector3 Ripple (float u, float v, float t) {
		float d = Sqrt(u * u + v * v);
+		Vector3 p;
+		p.x = u;
+		p.y = Sin(PI * (4f * d - t));
+		p.y /= 1f + 10f * d;
+		p.z = v;
+		return p;
	}
```

因为点的 X 和 Z 坐标不再是恒定的，我们也就不能再依赖它们在 `Graph.Update` 里的初始值了。我们可以把 `Update` 里的循环替换成与 `Awake` 相同的那个循环来解决这个问题，只不过现在可以直接把函数结果赋给点的位置。

```diff
	void Update () {
		FunctionLibrary.Function f = FunctionLibrary.GetFunction(function);
		float time = Time.time;
+		float step = 2f / resolution;
		for (int i = 0, x = 0, z = 0; i < points.Length; i++, x++) {
+			if (x == resolution) {
+				x = 0;
+				z += 1;
+			}
+			float u = (x + 0.5f) * step - 1f;
+			float v = (z + 0.5f) * step - 1f;
+			points[i].localPosition = f(u, v, time);
		}
	}
```

注意，我们只需要在 `z` 变化时重新计算 `v`。这确实要求我们在循环开始前设置它的初始值。

```diff
+		float v = 0.5f * step - 1f;
		for (int i = 0, x = 0, z = 0; i < points.Length; i++, x++) {
			if (x == resolution) {
				x = 0;
				z += 1;
+				v = (z + 0.5f) * step - 1f;
			}
			float u = (x + 0.5f) * step - 1f;
-			//float v = (z + 0.5f) * step - 1f;
			points[i].localPosition = f(u, v, time);
		}
```

还要注意，因为 `Update` 现在使用了 resolution，在运行模式下改变它会使图表变形，把网格拉伸或压扁成矩形。

> **为什么不用嵌套的双重循环？**
>
> 那也是可以的，而且是在两个维度上循环时的常用做法。然而，这种方法主要是在点之间循环，而不是在维度之间。即使分辨率在运行模式下被改变，它也总是更新所有点。

我们不再需要在 `Awake` 里初始化位置，所以可以让那个方法简单得多。只设置点的缩放和父级就够了。

```diff
	void Awake () {

		var scale = Vector3.one * step;
-		//var position = Vector3.zero;

-			//position.z = (z + 0.5f) * step - 1f;
-			//point.localPosition = position;
			point.localScale = scale;
			point.SetParent(transform, false);
		}
	}
```

### 创建球体

为了证明我们确实不再受限于每个 (X, Z) 坐标对只能有一个点，让我们创建一个定义球体的函数。为此给 `FunctionLibrary` 添加一个 `Sphere` 方法。还要在 `FunctionName` 枚举和 `functions` 数组中为它添加一项。先让它总是返回原点处的点。

```diff
	public enum FunctionName { Wave, MultiWave, Ripple, Sphere }

	static Function[] functions = { Wave, MultiWave, Ripple, Sphere };

	…

+	public static Vector3 Sphere (float u, float v, float t) {
+		Vector3 p;
+		p.x = 0f;
+		p.y = 0f;
+		p.z = 0f;
+		return p;
+	}
```

创建球体的第一步是描述一个平躺在 XZ 平面上的圆。我们可以用 `[[sin(piu)],[0],[cos(piu)]]`，只依赖 `u`。

```diff
		p.x = Sin(PI * u);
		p.y = 0f;
		p.z = Cos(PI * u);
```

![一个圆。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/leaving-the-grid/circle.png)

现在我们有了多个完美重叠的圆。我们可以基于 `v` 让它们沿 Y 拉伸，得到一个无盖的圆柱体。

```diff
		p.x = Sin(PI * u);
		p.y = v;
		p.z = Cos(PI * u);
```

![一个圆柱体。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/leaving-the-grid/cylinder.png)

我们可以通过把 X 和 Z 乘以某个值 `r` 来调整圆柱体的半径。如果我们使用 `r=cos(pi/2v)`，那么圆柱体的顶部和底部就会收缩成单个点。

```diff
+		float r = Cos(0.5f * PI * v);
		Vector3 p;
		p.x = r * Sin(PI * u);
		p.y = v;
		p.z = r * Cos(PI * u);
```

![半径收缩的圆柱体。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/leaving-the-grid/cylinder-collapsing.png)

这已经很接近球体了，但圆柱体半径的减小还不是圆形的。这是因为圆是由正弦和余弦一起构成的，而此刻我们只用了余弦来算半径。方程的另一部分是 Y，目前仍等于 `v`。要在各处都补全圆，我们必须使用 `y=sin(pi/2v)`。

```diff
		p.y = Sin(PI * 0.5f * v);
```

![一个球体。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/leaving-the-grid/sphere.png)

结果是一个球体，用通常被称为 UV 球体的方式创建。虽然这种方法创建出正确的球体，但注意点的分布并不均匀，因为球体是通过堆叠不同半径的圆构成的。另外，我们也可以把它看作由多个绕 Y 轴旋转的半圆组成。

### 扰动球体

让我们调整球体的表面，让它更有趣。为此我们必须稍稍调整公式。我们将使用 `f(u,v)=[[ssin(piu)],[rsin(pi/2v)],[scos(piu)]]`，其中 `s=rcos(pi/2v)`，`r` 是半径。这样就能让半径动起来。例如，我们可以用 `r=(1+sin(pit))/2` 基于时间来缩放它，从而让它动画。

```diff
		float r = 0.5f + 0.5f * Sin(PI * t);
+		float s = r * Cos(0.5f * PI * v);
		Vector3 p;
		p.x = s * Sin(PI * u);
		p.y = r * Sin(0.5f * PI * v);
		p.z = s * Cos(PI * u);
```

缩放球体。

我们不必使用均匀的半径。我们可以基于 `u` 来变化它，比如 `r=(9+sin(8piu))/10`。

```diff
		float r = 0.9f + 0.1f * Sin(8f * PI * u);
```

![带垂直条纹的球体；分辨率 100。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/leaving-the-grid/sphere-vertical-bands.png)

这使球体看起来有垂直条纹。我们可以改用 `v` 而不是 `u`，切换成水平条纹。

```diff
		float r = 0.9f + 0.1f * Sin(8f * PI * v);
```

![带水平条纹的球体。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/leaving-the-grid/sphere-horizontal-bands.png)

而同时用两者，我们就得到扭转的条纹。再加上时间让它们旋转，最终得到 `r=(9+sin(pi(6u+4v+t)))/10`。

```diff
		float r = 0.9f + 0.1f * Sin(PI * (6f * u + 4f * v + t));
```

旋转的扭转球体。

### 创建环面

最后，给 `FunctionLibrary` 添加一个环面曲面。复制 `Sphere`，重命名为 `Torus`，并把它的半径设为 1。还要更新名称和函数数组。

```diff
	public enum FunctionName { Wave, MultiWave, Ripple, Sphere, Torus }

	static Function[] functions = { Wave, MultiWave, Ripple, Sphere, Torus };

	…

+	public static Vector3 Torus (float u, float v, float t) {
+		float r = 1f;
+		float s = r * Cos(0.5f * PI * v);
+		Vector3 p;
+		p.x = s * Sin(PI * u);
+		p.y = r * Sin(0.5f * PI * v);
+		p.z = s * Cos(PI * u);
+		return p;
+	}
```

我们可以通过把它的垂直半圆拉开、并把它们变成整圆，来把球体变形为环面。先切换到 `s=1/2+rcos(pi/2v)`。

```diff
		float s = 0.5f + r * Cos(0.5f * PI * v);
```

![被拉开的球体。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/leaving-the-grid/sphere-pulled-apart.png)

这给了我们半个环面，只算上了它环的外侧部分。要完成环面，我们必须用 `v` 描述整个圆而不是半个圆。这可以通过在 `s` 和 `y` 中使用 `piv` 而不是 `pi/2v` 来实现。

```diff
		float s = 0.5f + r * Cos(PI * v);
		Vector3 p;
		p.x = s * Sin(PI * u);
		p.y = r * Sin(PI * v);
		p.z = s * Cos(PI * u);
```

![一个自相交的纺锤环面。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/leaving-the-grid/torus-spindle.png)

因为我们把球体拉开了半个单位，这产生了一个自相交的形状，称为纺锤环面（spindle torus）。如果我们改为拉开一个单位，就会得到一个不自相交、但也没有洞的环面，称为角环面（horn torus）。所以把球体拉开多远，会影响环面的形状。具体来说，它定义了环面的主半径（major radius）。另一个半径是次半径（minor radius），决定环的粗细。让我们把主半径定义为 `r_1`，并把另一个重命名为 `r_2`，这样 `s=r_2cos(piv)+r_1`。然后主半径用 0.75、次半径用 0.25，让点保持在 −1–1 范围内。

```diff
-		//float r = 1f;
+		float r1 = 0.75f;
+		float r2 = 0.25f;
		float s = r1 + r2 * Cos(PI * v);
		Vector3 p;
		p.x = s * Sin(PI * u);
		p.y = r2 * Sin(PI * v);
		p.z = s * Cos(PI * u);
```

![一个圆环面。](https://catlikecoding.com/unity/tutorials/basics/mathematical-surfaces/leaving-the-grid/torus-ring.png)

现在我们有两只半径可玩，可以做出更有趣的环面。例如，我们可以通过使用 `r_1=(7+sin(pi(6u+t/2)))/10` 把它变成一个旋转的星形图案，同时通过使用 `r_2=(3+sin(pi(8u+4v+2t)))/20` 来扭转环。

```diff
		float r1 = 0.7f + 0.1f * Sin(PI * (6f * u + 0.5f * t));
		float r2 = 0.15f + 0.05f * Sin(PI * (8f * u + 4f * v + 2f * t));
```
