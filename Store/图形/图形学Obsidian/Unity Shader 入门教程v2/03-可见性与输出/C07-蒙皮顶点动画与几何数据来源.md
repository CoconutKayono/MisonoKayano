# C07｜蒙皮、顶点动画与几何数据来源

> **核心问题：模型已经动起来了，为什么读取 Mesh 顶点仍是原姿势，或者角色在摆动，阴影却没有跟上？**
> 
> 导入 Mesh、骨骼蒙皮结果和顶点 Shader 进一步变形是不同层的数据。必须说明“哪个时刻、哪个空间、哪个处理阶段”的顶点。多个 Pass 要表达同一几何表面，也必须使用一致的变形与裁剪约定。

## 1. 范围与必要概念

本文讨论线性混合蒙皮（LBS）与简单顶点变形，面向 Unity 6 / URP；不覆盖所有蒙皮算法或 Unity 每个平台的内部调度。API 核对本地 6000.7 Beta 文档（2026-06-26 构建）；URP 阴影源码固定提交 `275a7f9ad9330e3cf7f3ea57a0b242a551fde291`，Core/URP 17.0.4。

- **绑定姿势（bind pose）**：建立网格顶点与骨骼坐标关系时的参考姿势。
- **骨骼权重**：一个顶点受各骨骼影响的系数，常用非负、归一化权重。
- **蒙皮**：利用当前骨骼变换，把参考顶点变到当前姿态。
- **顶点动画/位移**：顶点 Shader 等阶段进一步修改位置，不会自动回写原始 Mesh 的 CPU 顶点数组。
- **bounds**：用于剔除等处理的包围体，不等于屏幕上最终几何的逐顶点扫描结果。

## 2. 把蒙皮矩阵的空间写全

采用列向量约定。设 `M_bind` 为绑定时网格对象到世界的矩阵，`B_i_bind` 为绑定时第 i 根骨骼到世界的矩阵，则绑定矩阵为：

`Bind_i = inverse(B_i_bind) × M_bind`

它把绑定网格对象空间顶点变为该骨骼绑定空间坐标。设当前 Renderer 对象到世界为 `M_now`，当前骨骼到世界为 `B_i_now`，则对象空间蒙皮矩阵为：

`S_i = inverse(M_now) × B_i_now × Bind_i`

`p_skinned_OS = Σ_i w_i × S_i × p_bind_OS`，其中 `Σ_i w_i = 1`。

最后 `p_world=M_now×p_skinned_OS`。不要在已经是世界空间的结果上再乘一次对象矩阵。

### 两个可以手算的输入

1. 当前姿势与绑定姿势相同，矩阵关系一致，则每个 `S_i=I`，权重和为 1 时顶点保持不动。绑定矩阵写反，经常在这个最基本测试就会暴露。
2. 顶点 `(1,0,0)` 受到两根骨骼影响：一根不动，另一根只向上平移 2；权重 0.25/0.75，结果为 `(1,1.5,0)`。这是纯平移教学例，不模拟关节体积保持。

旋转矩阵的线性混合通常不再是纯旋转，因此 LBS 可产生关节塌缩、扭转缩细等伪影。增加权重数量不自动消除算法本身的这些问题。法线也不是带平移的点；对一般非均匀变形，要考虑法线变换与归一化，不能把常见加权法线近似理解成任意变形下的精确几何法线。

## 3. Unity 中的三层数据

| 层次 | 代表入口 | 得到什么、不能推断什么 |
| --- | --- | --- |
| 导入/共享 Mesh | `SkinnedMeshRenderer.sharedMesh` | 网格及蒙皮输入；不是自动更新的最终世界空间顶点数组 |
| 当前蒙皮快照 | `BakeMesh` | CPU 计算的蒙皮快照，相对 Renderer Transform；不执行材质顶点 Shader |
| GPU 蒙皮缓冲 | `GetVertexBuffer` / `GetPreviousVertexBuffer` | 当前/上一帧的 GPU 顶点缓冲入口；仍需知道时序、布局和绑定能力 |

Unity 明确说明 `BakeMesh` 即使开启 GPU Skinning 也在 CPU 执行。因此用它“检查 GPU 动画结果”会引入另一条计算路径，且不会包括本例材质中的正弦位移。[BakeMesh 文档](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/SkinnedMeshRenderer.BakeMesh.html)

`GetVertexBuffer` 提供当前帧缓冲；运动矢量路径可能交替使用两份缓冲。不能把一次拿到的缓冲永久认作之后每帧的当前结果，也不能假设某个固定字节偏移永远是位置。绑定目标、步长、数据格式、生命周期和获取时机都需要核对。[GPU 顶点缓冲文档](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/SkinnedMeshRenderer.GetVertexBuffer.html)

固定 UnityCsReference `9d487cab41b00c50af020b56d27a3c768d54f770` 的 `GraphicsRenderers.bindings.cs` 中，BakeMesh 进入 extern；GetVertexBuffer 转入原生实现并登记缓冲包装。公开 C# 不足以证明某平台蒙皮一定在 CPU、Compute 或顶点阶段完成。[固定托管入口](https://github.com/Unity-Technologies/UnityCsReference/blob/9d487cab41b00c50af020b56d27a3c768d54f770/Runtime/Export/Graphics/GraphicsRenderers.bindings.cs)

## 4. 多 Pass 需要一致的是表面

主体颜色、ShadowCaster、DepthOnly、DepthNormals 和 MotionVectors 可能使用不同投影或输出，但应以相同姿态和变形约定描述同一表面。

- 主体摆动、ShadowCaster 没摆动：投影阴影形状或位置错误。
- 主体裁剪发丝、深度 Pass 没裁剪：透明洞写成实心遮挡。
- 主体用当前时刻、运动矢量没有对应上一时刻：时间重建可能拖影。
- 顶点向外移、bounds 仍很小：物体可能被过早剔除，根本到不了顶点 Shader。

共享变形函数有助于一致性，但参数、时刻、LOD、空间、裁剪和输入姿态也必须一致。深度纹理若来自 CopyDepth，读取的是已经写出的深度；若来自预通道，则依赖对应 Pass。不能看到 `_CameraDepthTexture` 就断言执行过 DepthOnly。

## 5. Unity 实验：两根骨骼、CPU 快照和 Shader 摆动

脚本自行生成一条带两根骨骼的细分带状网格，无需导入角色模型。主对象由骨骼弯曲，再经 Shader 横向位移；右侧快照使用 BakeMesh，材质位移设为 0。Shader 的 `_MatchAux` 可故意让阴影/深度漏掉额外位移。

正弦位移为 `x'=x+A sin(ωy+t)`，相应局部法线修正为 `n'∝(nx, ny-k nx, nz)`，`k=Aω cos(ωy+t)`。这是对这个特定剪切变形的逆转置推导，不能当作任意位移的法线修复公式。

保存以下文件；空对象挂脚本，将 Shader 拖入 Lab Shader。相机对准原点上方的两条带，使用 URP Forward、关闭 TAA 和额外后处理。添加 URP/Lit 地面及开启实时阴影的方向光以观察阴影。副本：[C#](../实验/C07SkinningLab.cs)、[Shader](../实验/C07DeformationLab.shader)。

```shaderlab
Shader "Encyclopedia/C07DeformationLab"
{
    Properties
    {
        _Color("Color",Color)=(0.2,0.7,1,1)
        _Amplitude("Additional Displacement",Range(0,0.5))=0.2
        _Frequency("Frequency",Float)=4
        _Speed("Speed",Float)=2
        [Toggle] _MatchAux("Deform Depth And Shadow",Float)=1
    }
    SubShader
    {
        Tags { "RenderPipeline"="UniversalPipeline" "Queue"="Geometry" "RenderType"="Opaque" }
        HLSLINCLUDE
        #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
        #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Shadows.hlsl"
        CBUFFER_START(UnityPerMaterial)
            float4 _Color;
            float _Amplitude, _Frequency, _Speed, _MatchAux;
        CBUFFER_END
        float3 _LightDirection, _LightPosition;
        struct Input { float3 positionOS:POSITION; float3 normalOS:NORMAL; };
        struct Output { float4 positionCS:SV_POSITION; };
        float3 Deform(float3 p,float amount)
        {
            p.x+=amount*sin(p.y*_Frequency+_Time.y*_Speed);
            return p;
        }
        float3 DeformNormal(float3 p,float3 n,float amount)
        {
            float k=amount*_Frequency*cos(p.y*_Frequency+_Time.y*_Speed);
            return normalize(float3(n.x,n.y-k*n.x,n.z));
        }
        Output MainVert(Input input)
        {
            Output o;
            o.positionCS=TransformObjectToHClip(Deform(input.positionOS,_Amplitude));
            return o;
        }
        Output DepthVert(Input input)
        {
            Output o;
            o.positionCS=TransformObjectToHClip(Deform(input.positionOS,_Amplitude*step(0.5,_MatchAux)));
            return o;
        }
        Output ShadowVert(Input input)
        {
            float a=_Amplitude*step(0.5,_MatchAux);
            float3 p=TransformObjectToWorld(Deform(input.positionOS,a));
            float3 n=TransformObjectToWorldNormal(DeformNormal(input.positionOS,input.normalOS,a));
            #if defined(_CASTING_PUNCTUAL_LIGHT_SHADOW)
                float3 lightDirection=normalize(_LightPosition-p);
            #else
                float3 lightDirection=_LightDirection;
            #endif
            Output o;
            o.positionCS=ApplyShadowClamping(TransformWorldToHClip(ApplyShadowBias(p,n,lightDirection)));
            return o;
        }
        float4 ColorFrag():SV_Target { return _Color; }
        float4 DepthFrag():SV_Target { return 0; }
        ENDHLSL
        Pass
        {
            Name "Forward"
            Tags { "LightMode"="SRPDefaultUnlit" }
            Cull Off ZWrite On ZTest LEqual
            HLSLPROGRAM
            #pragma target 3.5
            #pragma vertex MainVert
            #pragma fragment ColorFrag
            ENDHLSL
        }
        Pass
        {
            Name "DepthOnly"
            Tags { "LightMode"="DepthOnly" }
            Cull Off ZWrite On ZTest LEqual ColorMask 0
            HLSLPROGRAM
            #pragma target 3.5
            #pragma vertex DepthVert
            #pragma fragment DepthFrag
            ENDHLSL
        }
        Pass
        {
            Name "ShadowCaster"
            Tags { "LightMode"="ShadowCaster" }
            Cull Off ZWrite On ZTest LEqual ColorMask 0
            HLSLPROGRAM
            #pragma target 3.5
            #pragma vertex ShadowVert
            #pragma fragment DepthFrag
            #pragma multi_compile_vertex _ _CASTING_PUNCTUAL_LIGHT_SHADOW
            ENDHLSL
        }
    }
}
```

```csharp
using UnityEngine;
using UnityEngine.Rendering;

public class C07SkinningLab : MonoBehaviour
{
    public Shader labShader;
    [Range(0,0.5f)] public float amplitude=0.2f;
    public bool matchDepthAndShadow=true;
    GameObject ownedRoot;
    Transform upper;
    SkinnedMeshRenderer skin;
    Mesh inputMesh, snapshot;
    Material liveMaterial, snapshotMaterial;
    bool ready;
    void Start()
    {
        if(labShader==null || !labShader.isSupported) return;
        ownedRoot=new GameObject("C07 Owned Experiment");
        ownedRoot.transform.SetParent(transform,false);
        var live=new GameObject("Live Skinned Strip");
        live.transform.SetParent(ownedRoot.transform,false);
        var lower=new GameObject("Lower Bone").transform;
        lower.SetParent(live.transform,false);
        upper=new GameObject("Upper Bone").transform;
        upper.SetParent(lower,false);
        upper.localPosition=Vector3.up;
        inputMesh=new Mesh { name="C07 Two Bone Strip" };
        const int segments=16;
        var positions=new Vector3[(segments+1)*2];
        var normals=new Vector3[positions.Length];
        var weights=new BoneWeight[positions.Length];
        var triangles=new int[segments*6];
        for(int row=0;row<=segments;row++)
        {
            float y=2f*row/segments;
            float w=Mathf.Clamp01(y-0.5f);
            for(int col=0;col<2;col++)
            {
                int i=row*2+col;
                positions[i]=new Vector3(col==0 ? -0.25f : 0.25f,y,0);
                normals[i]=Vector3.back;
                weights[i]=new BoneWeight { boneIndex0=0,weight0=1-w,boneIndex1=1,weight1=w };
            }
            if(row<segments)
            {
                int i=row*2, t=row*6;
                triangles[t]=i; triangles[t+1]=i+2; triangles[t+2]=i+1;
                triangles[t+3]=i+1; triangles[t+4]=i+2; triangles[t+5]=i+3;
            }
        }
        inputMesh.vertices=positions; inputMesh.normals=normals;
        inputMesh.triangles=triangles; inputMesh.boneWeights=weights;
        inputMesh.bindposes=new Matrix4x4[] {
            lower.worldToLocalMatrix*live.transform.localToWorldMatrix,
            upper.worldToLocalMatrix*live.transform.localToWorldMatrix };
        liveMaterial=new Material(labShader);
        skin=live.AddComponent<SkinnedMeshRenderer>();
        skin.sharedMesh=inputMesh;
        skin.bones=new Transform[] {lower,upper}; skin.rootBone=lower;
        skin.quality=SkinQuality.Bone2;
        skin.sharedMaterial=liveMaterial;
        skin.updateWhenOffscreen=false;
        skin.localBounds=new Bounds(new Vector3(0,1,0),new Vector3(4,4,2));
        var frozen=new GameObject("CPU Snapshot Without Shader Displacement");
        frozen.transform.SetParent(ownedRoot.transform,false);
        frozen.transform.localPosition=new Vector3(1.8f,0,0);
        snapshot=new Mesh { name="C07 CPU Snapshot" };
        frozen.AddComponent<MeshFilter>().sharedMesh=snapshot;
        snapshotMaterial=new Material(labShader);
        snapshotMaterial.SetFloat("_Amplitude",0);
        snapshotMaterial.SetColor("_Color",new Color(1,0.6f,0.1f,1));
        frozen.AddComponent<MeshRenderer>().sharedMaterial=snapshotMaterial;
        ready=true;
        UpdatePose();
        BakeSnapshot();
    }
    void UpdatePose()
    {
        upper.localRotation=Quaternion.AngleAxis(35*Mathf.Sin(Time.time),Vector3.forward);
        liveMaterial.SetFloat("_Amplitude",amplitude);
        liveMaterial.SetFloat("_MatchAux",matchDepthAndShadow ? 1 : 0);
    }
    void LateUpdate() { if(ready) UpdatePose(); }
    [ContextMenu("Bake Snapshot")]
    public void BakeSnapshot()
    {
        if(!ready) return;
        UpdatePose();
        skin.BakeMesh(snapshot,false);
        snapshot.RecalculateBounds();
    }
    void OnGUI()
    {
        if(ready && GUI.Button(new Rect(10,10,180,30),"Bake Snapshot")) BakeSnapshot();
    }
    void OnDestroy()
    {
        if(ownedRoot!=null) Destroy(ownedRoot);
        if(inputMesh!=null) Destroy(inputMesh);
        if(snapshot!=null) Destroy(snapshot);
        if(liveMaterial!=null) Destroy(liveMaterial);
        if(snapshotMaterial!=null) Destroy(snapshotMaterial);
    }
}
```

## 6. 预测、观察和源码对应

1. 实验父对象先保持单位缩放。Amplitude=0 时点击 Bake Snapshot，右边冻结当前骨骼姿势；左边继续动画。两者左右平移用于区分，不能直接拿屏幕位置相等判断快照正确。
2. Amplitude>0 时再 Bake，右侧仍只包含骨骼姿势，不带正弦位移。它没有“漏算 GPU 结果”，而是 API 本就不执行材质顶点 Shader。
3. 保持 Match Depth And Shadow 开启，观察主体和投影阴影都包含额外位移；关闭后，阴影仍有骨骼动画，但漏掉材质位移。不要误述为阴影完全静止。
4. 深度检查先确认相机是否实际执行 DepthOnly。可在 URP 中尝试 Forced Depth Priming 并用 Frame Debugger 核对；若确有预通道，关闭匹配会让预通道与主体表面不一致，可能在深度相等复用路径中直接造成主体缺口。若只是 CopyDepth，不应预测同样的预通道错误。
5. 脚本给 Renderer 设置了保守局部 bounds，避免新增位移越界引起错误剔除。它不是性能最优包围体；真实角色应估算动画、位移与描边的边界。[Renderer.localBounds](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Renderer-localBounds.html)

本 Shader 的阴影位置流程对照固定 URP `ShadowCasterPass.hlsl`：位置/法线转世界空间，选择光方向，ApplyShadowBias，投影并 ApplyShadowClamping。它没有照搬完整 Lit 功能，不包含 Alpha Clip、DepthNormals、MotionVectors、XR 或 GPU Instancing 支持。[固定 ShadowCasterPass.hlsl](https://github.com/Unity-Technologies/Graphics/blob/275a7f9ad9330e3cf7f3ea57a0b242a551fde291/Packages/com.unity.render-pipelines.universal/Shaders/ShadowCasterPass.hlsl)

全粉色先查 URP 包及 Shader 编译；阴影缺失查灯光、距离、Renderer 投影设置和地面接收阴影材质；运动缺失查 Play 状态；相机边缘消失先看 bounds，而非先改三角形绕序。快照是手动 CPU 实验，不能把其耗时当作正常 GPU 蒙皮耗时。

## 7. NPR 迁移与自测

反壳描边应基于正确的动画姿态和变形法线；头发摆动必须同时考虑阴影、深度和运动矢量。脸部 SDF 的方向计算与骨骼空间约定也应匹配，不可混用模型原始轴和动画后的头部轴。

1. **sharedMesh 顶点不变是否说明 GPU 没动？** 否，蒙皮与顶点程序输出可以存在于其他资源或执行阶段。
2. **BakeMesh 能否截取材质正弦位移？** 本 API 不执行该 Shader，因此不能。
3. **主体和阴影共享函数就一定一致吗？** 还要匹配输入、参数、时间和裁剪；不同投影本身是正常的。
4. **顶点 Shader 能否救回已被 bounds 剔除的物体？** 不能，该 Draw 可能根本未提交。
