# B01—B04 实验｜从编译条件到三角形朝向

这一组实验服务于四个独立问题：程序何时确定、执行组怎样受条件影响、命令何时生效、面朝向由什么决定。完整代码同时保留在每张卡中；下面只是集中操作入口，不替代卡片正文。

## 2. 无需 Unity 的数值检查

在本目录运行：

```powershell
python .\验证Shader执行与图元.py
```

13 项测试涵盖变体候选组合、互斥集合、真实 FP16 存储反例、教学 wave 掩码利用率、寄存器约束、理想 CPU/GPU 流水线、索引寻址、绕序翻转和跨平面裁剪。

这些模型刻意标明假设。它们不模拟真实 GPU、不能预测帧率、不能证明 Unity Shader 采用了 FP16，也不能保证实际 wave 以相同方法调度。

## 4. 本组通过条件与当前状态

能独立解释以下反例后，再把个人学习状态更新为已验证：

1. 同一画面可由不同变体或运行时条件产生；画面相同不能证明指令相同。
2. 分支条件统一时不必产生 wave 内路径分歧；高占用率不等于高有效吞吐。
3. 已记录 Draw 但不执行缓冲，不会因此刷新离屏目标；CPU 返回不是 GPU 完成证明。
4. 翻法线改变着色输入，翻索引改变绕序；两者不可互换。
