DSTemplate快速上手业务系统接入指南：成就系统
📌
本文以成就系统作为业务系统接入的标准范例，按章节顺序完成对应文件的新建与修改即可跑通完整链路。​
示例行为：按键 1 解锁随机成就，按键 0 打开成就界面并输出已解锁列表。​
​
能力概述​
成就功能示意逻辑链路​
    客户端点击按键 1，调用接口 AchievementSystem:CSUnLockAchievement(id)，触发成就解锁流程。​
    客户端把 CSUnLockAchievement 指令上报至服务端（DS）。​
    服务端交由 ServerAchievementManager.HandleUnlockAchievement 完成合法性校验，并写入聚合缓存。​
    服务端下发给客户端 SCUnLockAchievement 反馈消息，附带当前最新的成就数据。​
    客户端响应 AchievementSystem:OnSCUnLockAchievement，使用新数据全覆盖本地 ClientAchievementData._data。​
    点击客户端按键 0，调用 AchievementSystem:OpenAchievementView()，页面展示已解锁成就。​
实现分层​
  • 服务端：​
  • 协议层 → Logic（Manager）→ 聚合层（ServerPlayerData）→ Data 域（ServerAchievementData 继承 ServerDataBase）→ DataStore（云 KV，框架层）。​
  • 客户端：​
  • 协议层 → Logic（System）→ 聚合层（ClientPlayerData）→ Data 域（ClientAchievementData 继承 ClientDataBase，纯内存）。​
1.3 聚合层​
​
​​​
​
玩家数据操作规范链路（不要绕开聚合直接 new 域）：​
  • 服务端：​
  • 统一数据访问入口：访问服务端内存数据ServerPlayerDataManager.Get(openId).xxxData → ​
  • 用户数据查询：查 Get(key)（无 key 返回整表）；​
  • 操作数据：增删改 Create / Update / Remove（或 Add）；​
  • 只有确实需要整体覆盖数据表时，才使用SetCache(snap, true)。​
  • 业务逻辑需要修改数据时，不要 Get() 数据后直接修改数据再 SetCache，也不要直接调 ServerDataCache。​
  • 客户端：GetMol("ClientPlayerData").xxxData:GetData()/:ReplaceRootDataFromServer(...)（或各域 ApplyServerData）。​
新增数据域必须接入聚合层（详见第四步、第七步）。​

域内增删改查（继承自 ServerDataBase）​
​
方法​
作用​
Get(key?)​
查：key 为 nil 返回整表快照；否则返回 snapshot[key]（查内存，不走 KV）​
Create(key, value) / Add(key, value)​
增：写键值并标脏（Add 为 Create 别名）​
Update(key, value)​
改：与 Create 等价（覆盖写）​
Remove(key) / Delete(key)​
删：移除键并标脏​
Delete()​
无参时为 OOP 实例析构（obj:Delete()），与删键不同​
SetCache(snapshot, markDirty)​
写整表快照；markDirty=false 仅框架 Load 回写用，true 用于整表替换​

已无 :Read，查统一用 Get。第三步 Manager 示例用 Get("achievements") + Update("achievements", achievements) 即标准写法。​

第三步：实现服务端 Logic​
目标：写一个 Manager 处理 CSUnLockAchievement：校验请求 → 取聚合 → 改快照 → 回包。不直接读写 DataStore，落盘交给聚合层 Flush。​
文件：Server/Logic/ServerAchievementManager.lua​
​
ServerAchievementManager = {}​
_G["ServerAchievementManager"] = ServerAchievementManager​
​
function ServerAchievementManager.HandleUnlockAchievement(player, packet)​
local playerOpenId = tostring(player.playerOpenID)​
local requestData = packet.data or {}​
if not requestData.achievementId then​
ServerEventNetwork.SendToPlayer(player, NetPacketType.SCUnLockAchievement, -1, "缺少成就ID")​
return​
end​
local achievementId = tostring(requestData.achievementId or "")​
local agg = ServerPlayerDataManager.Get(playerOpenId)​
if not agg then​
ServerEventNetwork.SendToPlayer(player, NetPacketType.SCUnLockAchievement, -2, "缺少玩家缓存数据")​
return​
end​
local achDomain = agg.achievementData​
if not achDomain:IsLoaded() then​
ServerEventNetwork.SendToPlayer(player, NetPacketType.SCUnLockAchievement, -3, "缺少成就数据缓存")​
return​
end​
local achievements = achDomain:Get("achievements")​
if type(achievements) ~= "table" then​
achievements = {}​
end​
achievements[achievementId] = true​
local achievementData = achDomain:Update("achievements", achievements)​
ServerEventNetwork.SendToPlayer(player, NetPacketType.SCUnLockAchievement, 0, "", {​
achievementData = achievementData,​
})​
end​
​
约定：​
  • 玩家身份必须 tostring(player.playerOpenID)，聚合层缓存键统一为字符串。​
  • 写本域用 Get(key) 读出 → 改 Lua 表 → Update(key, table)（或 Create / Remove）写回并标脏；不要 Get() 整表手改后再 SetCache。确需整表替换时用 SetCache(snapshot, true)；框架 Load 回写用 SetCache(_, false)。标脏后由聚合 Flush 落盘。​
  • 回包签名：ServerEventNetwork.SendToPlayer(player, packetType, code, msg, dataTable)，客户端收到 { code, msg, data = dataTable }。​
​

第六步：实现客户端 Logic​
目标：写一个继承 BaseSystem 的成就 System 处理请求与回包，再写一个 host 脚本让框架挂载。​
6-1. 业务类​
文件：Client/System/AchievementSystem/AchievementSystem.lua​
​
AchievementSystem = BaseClass:DefineClass("AchievementSystem", BaseSystem)​
​
function AchievementSystem:__init()​
BaseSystem.__init(self)​
end​
​
function AchievementSystem:OpenAchievementView()​
local agg = GetMol("ClientPlayerData")​
self.achievementData = agg and agg.achievementData or nil​
if self.achievementData == nil then​
print("[AchievementSystem] achievementData is nil")​
return​
end​
local achievements = self.achievementData:GetData()​
print("[AchievementSystem] 打开成绩界面，成绩数据：" .. TPrintUtil.Print(achievements))​
end​
​
function AchievementSystem:OnSCUnLockAchievement(payload)​
if not payload or (tonumber(payload.code) or -1) < 0 then​
print("[AchievementSystem] 成就解锁失败：", payload and payload.msg)​
return​
end​
local serverAchievement = payload.data and payload.data.achievementData​
print("[AchievementSystem] 解锁成就：" .. TPrintUtil.Print(serverAchievement))​
self.achievementData:ReplaceRootDataFromServer(serverAchievement)​
end​
​
function AchievementSystem:CSUnLockAchievement(achievementID)​
print("[AchievementSystem] 解锁 成绩：" .. achievementID)​
if achievementID == nil or achievementID == "" then​
return​
end​
local packet = NetPacketManager.CreatePacket(NetPacketType.CSUnLockAchievement)​
packet.data = { achievementId = tostring(achievementID or "") }​
ClientEventNetwork.FireServer(NetPacketType.CSUnLockAchievement, packet:Serialize())​
end​
​
约定：​
  • 通过 GetMol("ClientPlayerData").xxxData 访问数据域。​
  • payload 为三段式 { code, msg, data }，code >= 0 视为成功。​
  • ReplaceRootDataFromServer 整体替换本地 _data，不做 diff。​
6-2. host 脚本​
文件：Client/System/AchievementSystem/AchievementSystemRegister.lua​
裸生命周期函数 Awake / Update / OnDestroy 由框架在场景加载时自动挂载。​
​
local achievementSystem = nil​
​
function Awake()​
if achievementSystem ~= nil then​
return​
end​
achievementSystem = AchievementSystem.New();​
IOCContainer:Register("AchievementSystem", achievementSystem)​
end​
​
function Update()​
if CS.UnityEngine.Input.GetKeyDown("0") then​
achievementSystem:OpenAchievementView()​
elseif CS.UnityEngine.Input.GetKeyDown("1") then​
local achievementID = math.random(1, 100)​
achievementSystem:CSUnLockAchievement(achievementID)​
end​
end​
​
function OnDestroy()​
if achievementSystem ~= nil then​
IOCContainer:RemoveSystem("AchievementSystem")​
achievementSystem:Delete()​
achievementSystem = nil​
end​
end​
​
约定：​
  • 带裸生命周期函数（Awake/Start/OnEnable/Update/OnDestroy/OnActor* 等）的脚本由框架自动挂载，禁止在 index.lua 中 require。​
  • IOC 注册后，其他脚本通过 GetSys("AchievementSystem") 访问。​
  • 销毁时必须 IOCContainer:RemoveSystem + instance:Delete()。​

第七步：接入客户端聚合层​
目标：在 ClientPlayerData 里登记新域，并在 PlayerSystem 4 处把首包、重同步、缺域探测、IOC 清理串起来。​

__init 接收单一 payload 表。新增域只增减体内一行，形参不变。​
​
function ClientPlayerData:__init(playerOpenId, payload)​
self.playerOpenId = tostring(playerOpenId)​
self.actorData = ClientActorData.New(payload.actorData)​
self.bagData = ClientBagData.New(payload.bagData)​
self.socialData = ClientSocialData.New(payload.socialData)​
self.rankingData = ClientRankingData.New(payload.rankingData)​
self.achievementData = ClientAchievementData.New(payload.achievementData) -- 新增​
end​
​
function ClientPlayerData:__delete()​
if self.actorData then self.actorData:Delete(); self.actorData = nil end​
if self.bagData then self.bagData:Delete(); self.bagData = nil end​
if self.socialData then self.socialData:Delete(); self.socialData = nil end​
if self.rankingData then self.rankingData:Delete(); self.rankingData = nil end​
if self.achievementData then self.achievementData:Delete(); self.achievementData = nil end -- 新增​
end​
​
payload 由上游 PlayerSystem（见下方 7-2）在首包阶段组装，key 与 self.xxxData 字段名对齐。​

local function PlayerDataApplyResyncChanged(payload)​
local changed = payload.changed or {}​
local localAgg = GetMol("ClientPlayerData")​
if not localAgg then return end​
if changed.actorData then localAgg.actorData:ApplyServerData(changed.actorData) end​
if changed.bagData then localAgg.bagData:ApplyServerData(changed.bagData) end​
if changed.socialData then localAgg.socialData:ApplyServerData(changed.socialData) end​
if changed.rankingData then localAgg.rankingData:ApplyServerData(changed.rankingData) end​
if changed.achievementData then localAgg.achievementData:ApplyServerData(changed.achievementData) end -- 新增​
end​

local function PlayerDataBuildMissingDomains()​

第九步：联调与排查​
按下面顺序跑一遍，确认整条链路通畅。​
    启动客户端与 DS。​
    进入主场景，等待首屏流水线完成（控制台输出 [DS_TRACE][DATA_STORE][CLIENT_SC_FIRST_APPLIED]）。​
    按下 1：​
  • 客户端：[AchievementSystem] 解锁 成绩：<id>​
  • 服务端：收到 CSUnLockAchievement，achievements[id] = true 写入聚合缓存​
  • 客户端：[AchievementSystem] 解锁成就：{achievements = {...}}​
    按下 0：​
  • 客户端：[AchievementSystem] 打开成绩界面，成绩数据：{achievements = {...}}​
    退出回房后 DS 落盘，下次进入按 0 应能看到上次解锁记录。​
出问题怎么排查​
  • 按 1 无反应：检查 host 脚本是否被框架挂载；类定义文件是否成功 require。​
  • 回包 code < 0：​
  • -2：聚合不存在，通常由 OnPlayerJoined 未执行导致，检查协议注册顺序与 host 启动顺序。​
  • -3：achievementData:IsLoaded() 为 false，通常由聚合层 LoadIntoCache 漏接新域或进房未完成加载所致（第四步 4-5）。​
  • 首屏无 achievementData：第七步 7-2 ① 首包 payload 漏键，或第四步 4-3 服务端首屏快照漏字段。​
