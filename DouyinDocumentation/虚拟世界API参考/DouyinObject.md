# 描述
DouyinObject 类用于表示一个具有唯一标识符（UID）的游戏对象。
提供了对该对象进行同步和销毁设置的方法。
# 公开属性
| [UID](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=ah4ak91v) | 该类实例的唯一标识符，在对象创建时初始化 |
| --- | --- |
| [gameObject](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=0tp7stie) | 该类实例关联的 Unity 游戏对象，在对象创建时初始化 |
# 公开方法
| [EnableSync](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=icmvur0e) | 开或关闭网络同步，默认是开启 |
| --- | --- |
| [SetDestoryWhenDrop](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=67z0qwfp) | 房间内最后一个用户断线的时候，是否当玩家丢弃此对象时立即销毁此对象 |
