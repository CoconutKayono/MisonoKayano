# 描述
DouyinDataStore 类是抖音数据存储相关的核心类，提供了一系列用于数据存储、检索、更新和删除的方法。
# 公开方法
| [GetData](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=d0d2r10w) | 根据键获取数据 |
| --- | --- |
| [SetData](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=frosc1zb) | 设置数据 |
| [IncrementData](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=m8od337b) | 对数值型数据进行增量操作 |
| [RemoveData](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=t1u32gca) | 删除与键对应的数据 |
| [UpdateData](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=nrjmhvn2) | 通过回调函数更新与键对应的数据 |
