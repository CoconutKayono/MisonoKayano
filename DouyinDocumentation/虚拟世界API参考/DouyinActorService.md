# 描述
控制对象([Actor](https://arcosite.bytedance.net/sites/1724838533199/67e3b8b7505b920501ed9205/editor/680da496fe7e0d0504f399c5?docLang=zh&bv=67e3b8b8505b920501ed9219))管理类。
可以通过各种方式查询并获取当前场景内的可控制对象。

| [GetMaxActorCount](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=wovhluj7) | 获取最大 Actor 数量 |
| --- | --- |
| [GetActors](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=hgj0vexd) | 获取 Actor 列表 |

| [GetLocalActor](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=79qzall9) | 获取本地 Actor |
