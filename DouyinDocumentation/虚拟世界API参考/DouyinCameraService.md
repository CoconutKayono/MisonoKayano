| [GetCamera](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=ingh70nc) | 获取与主角绑定的相机 |

| [GetPitch](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=qygdomxs) | 获取主相机与主角之间的俯仰角，游戏模式有效 |
| [SetPitch](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=ltzzwbqx) | 设置主相机与主角之间的俯仰角，游戏模式有效 |
| [GetYaw](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=rk6inhcx) | 获取主相机与主角之间的偏航角，游戏模式有效 |
| [SetYaw](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=sxnai15s) | 设置主相机与主角之间的偏航角，游戏模式有效 |
| [SetDistance](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=etk4t0kq) | 设置主相机与主角之间的距离，游戏模式有效 |

| [StartPhotograph](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=keb0pdvu) | 进入相机功能模式 |
