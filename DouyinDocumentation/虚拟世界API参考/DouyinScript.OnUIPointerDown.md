function OnUIPointerDown(UIType ui)
# 参数
| 参数 | 参数描述 |
| --- | --- |
| ui | 玩家按下的按钮类型 |

# 描述
当UI按钮被按下时触发。

UIType的枚举如下：
| UIType | 描述 |
| --- | --- |
| CustomMain | 自定义主按钮 |
| CustomSub | 自定义副按钮 |
| Throw | 丢弃 |
| Jump | 跳跃 |
| MoveJoyStick | 移动摇杆 |
| HoldHands | 牵手 |
| StopHoldHands | 取消牵手 |
| Fly | 飞行/悬浮 |
| StandUp | 站起 |
