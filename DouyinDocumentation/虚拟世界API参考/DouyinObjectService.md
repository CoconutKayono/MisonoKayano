# 描述
DouyinObjectService 是一个静态类，主要用于管理 DouyinObjectService 实例。
提供网络对象操作相关功能。
# 静态方法
| [NetSpawn](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=ge4lsnsr)（重载方法） | 动态生成网络对象 |
| --- | --- |
| [NetDestroy](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=cgknb1p6) | 可以销毁所有的网络对象，只有主权方可以销毁物体； <br> autoRequest 代表是否自动请求主权 |
| [GetDouyinObject](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=9x8bdcgz) | 通过objectID获取对应的DouyinObject对象 |
