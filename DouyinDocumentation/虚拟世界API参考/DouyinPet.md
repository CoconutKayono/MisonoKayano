# 描述
DouyinPet 类表示游戏中小火人的相关信息和操作。
提供了小火人的基本属性和操作方法。
# 公开属性
| [petID](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=yh04xtgl) | 获取合养精灵的 ID |
| --- | --- |
| [petOpenID](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=qk7vkmjc) | 合养精灵的唯一标识符，在创建合养精灵对象时进行初始化，属性为只读。 |
| [petName](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=95wp6wfr) | 获取合养精灵的名称 |
| [petLevel](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=eqstirn7) | 获取合养精灵等级 |
| [petAppearance](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=jxg7vi6q) | 获取合养精灵的形象 |
| [petAccesory](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=d8ibu3a1) | 获取合养精灵的装扮列表 |
| [isMaster](https://arcosite.bytedance.net/sites/1724838533199/67e3b8b7505b920501ed9205/editor/680a34c7fe0185053f856de2?docLang=zh&bv=67e3b8b8505b920501ed9219) | 判断当前用户是不是控制者 |
