# 描述
用于管理与获取房间内 DouyinPlayer 对象。
# 静态方法
| [GetLocalPlayer](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=k1meecgn) | 获取本地玩家 |
| --- | --- |
| [GetPlayer](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=4ht2pxay) | 通过 playerID，获取指定 DouyinPlayer 的信息 |
| [GetPlayers](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=jj7dzn4c) | 获取当前房间内所有的 DouyinPlayer |
| [GetPlayerCount](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=w5a78205) | 获取当前房间 DouyinPlayer 的数量 |
| [GetPlayerByOpenID](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=to1c4v1g) | 通过open ID获取房间内的DouyinPlayer |
