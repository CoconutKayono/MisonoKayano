# 描述
您可以使用这个类来设置传入的元数据表。
# 公开方法
| [GetMetaData](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=muaemn8t) | 获取自定义元数据的值，即Datasetoptions对象的值 |
| --- | --- |
| [SetMetadata](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=4s7rb0l5) | 设置自定义元数据的值，即Datasetoptions对象的值 |
| [SetPlayerDataOwner](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=nos6cdbf) | 设置数据关联的玩家（仅用于检测），平台侧即可检测到该玩家因多房间同时写入而导致的数据回档异常。 |
| [SetPetDataOwner](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=hym0oow5) | 设置数据关联的火人（仅用于检测），平台侧即可检测到该火人因多房间同时写入而导致的数据回档异常。 |
