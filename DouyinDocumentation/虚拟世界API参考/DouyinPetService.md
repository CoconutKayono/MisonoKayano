# 描述
负责管理 DouyinPet 的实例。
它提供一系列静态方法，用于创建、移除、获取单个或多个 DouyinPet 实例（合养精灵）
# 静态方法
| [GetPet](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=b3d3mh27) | 通过 PetID，获取当前场景内的合养精灵 |
| --- | --- |
| [GetLocalPet](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=gw4r5yi9) | 获取当前玩家控制的合养精灵 |
| [GetPets](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=w2nq4vhn) | 获取当前场景内所有的合养精灵 |
| [GetPetCount](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=r17p9qij) | 获取当前场景内合养精灵的数量 |
