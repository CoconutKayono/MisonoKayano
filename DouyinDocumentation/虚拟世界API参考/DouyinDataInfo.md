# 描述
此对象提供了关于单个数据对象的详细信息。
# 公开属性
| version | number | 当前数据版本号 |
| --- | --- | --- |
| key | string | 键 |
| value | number，string, boolean, 或包含这些类型的表 | 值 |
| createdTime | number | 创建时间 |
| updateedTime | number | 最后更新时间 |
# 公开方法
| [GetMetaData](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=whn7gese) | 获取数据对象的元信息 |
