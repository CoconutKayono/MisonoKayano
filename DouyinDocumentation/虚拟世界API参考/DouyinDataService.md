# 描述
这项服务提供统一的 API 用于获取 DataStore 信息

# 公开方法
| [GetDataStore](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=alqvli97) | 创建或获取数据存储对象 |
| --- | --- |
| [GetOrderedDataStore](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=l0s0nl1x) | 创建或获取排序数据的储存对象 |
| [CreateDataSetOptions](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=rbry6oew) | 创建一个DataSetoptions对象，用于用户自定义创建元数据 |
