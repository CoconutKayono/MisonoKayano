# 描述
主要负责管理和处理与用户输入相关的各类事件，涵盖了屏幕点击、移动输入、视角旋转、屏幕缩放以及跳跃等操作的事件监听与响应。
# 静态事件
| [onTouchEvent](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=ugujuzws) | 屏幕点击事件 |
| --- | --- |
| [onMoveInputStart](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=4eacbuya) | 开始有移动输入 |
| [onMoveInputPerform](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=46su05f8) | 持续有移动输入 |
| [onMoveInputCancel](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=vh4b5ttc) | 移动输入取消 |
| [onLookInputStart](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=u7h7wx0k) | 旋转视角操作开始 |
| [onLookInputPerform](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=l006we1d) | 旋转视角（屏幕空白区域） |
| [onLookInputCancel](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=4bns9zjd) | 旋转视角操作取消 |
| [onZoomInput](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=v6vz3wfz) | 屏幕缩放（双指） |
| [onJumpInputStart](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=e8y8k4lw) | 跳跃，无论在 PC 上按下空格，还是手机屏幕点击跳跃，均触发跳跃输入事件 |
| [onJumpInputPerform](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=1rw7207m) | 跳跃时事件 |
| [onJumpInputCancel](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=nq0v9wyh) | 取消跳跃事件 |
