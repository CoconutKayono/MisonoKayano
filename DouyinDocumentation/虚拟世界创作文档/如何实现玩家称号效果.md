在开启本篇教程之前，有一些概念需要先了解：

* **非网络对象**：场景中没有交互的模型对象，用 GameObject.Instantiate 动态创建的对象这些都不是网络对象，不支持同步变量和 RPC 消息。
* **网络对象**：带有 Douyin Script 组件或者 Douyin Object Sync 组件的游戏对象。
* **动态网络房间对象**：使用 **DouyinObjectService.NetSpawn** 创建出来的是动态房间网络对象，它和房间存在的时间相同，不会自动消失（需要管理对象销毁）。A创建的房间网络对象NetA，即便A下线了，NetA也不会自动销毁，会一直留在房间里。
* **与玩家关联的动态网络对象**：使用 **DouyinActor.NetSpawn** 创建出来的是与玩家关联的动态网络对象，该对象和创建它的Actor存在时间相同。A创建的NetA，当A下线时，会跟随A一起销毁，不会残留在房间内，我们不需要管理它的销毁（除非有特殊需求）。


**效果描述**：玩家进入房间后，会展示“青铜”，碰撞到不同的方块后，会切换不同的称号。

首先，我们需要先准备好称号UI预制体，并创建好[网络对象生成配置](/s196aspp/5gzuf4g9)（NetSpawnObjects），将称号UI预制体拖拽至网络对象生成配置中，并设置好key值。

1. **定义称号显示逻辑变量**

```Lua
                                -- ActorTitle.lua
-- 称号显示位置的差值
---@var offsetY:float = 1
-- 定义称号的同步变量  
---@varSync titleName:string = "青铜"
-- 记录称号对应的玩家的actorid
---@varSync targetActorId:int
---@end

local Vector3 = UnityEngine.Vector3
local UI = UnityEngine.UI

local titleText --显示称号的text
local titleTextTrans --称号预制体的transform
local targetCamera --本地玩家的摄像机
local targetCameraTrans --本地玩家的摄像机的transform

-- Start is called before the first frame update
function Start()
    --称号改变时刷新称号名称
    titleName:OnValueChange(function(curVal, preVal)
        if titleText then
            titleText.text = curVal
        end
    end)
end
--获取称号对应actor的id
function GetTargetActorId()
    return targetActorId:GetValue()
end
--设置称号对应actor的id
function SetTargetActorId(actorId)
    targetActorId:SetValue(actorId)
end
```

创建一个 DouyinScript Lua 脚本，修改脚本名字为“ActorTitle”，并将上面代码块中的代码复制进脚本中。
保存代码，并将代码挂载到称号预制体上。
* titleName：这是一个[同步变量](/s196aspp/69hivh74)，同步变量在变化时，所有客户端都将会收到，所以用它来定义称号的内容。
* targetActorId：一个称号与一个actor绑定，所以需要一个变量来记录每个称号对应的actorid，这里我们也是使用了[同步变量](/s196aspp/69hivh74)来处理。
* Start函数：Unity的Start函数，对象生成时调用一次，这里我们处理了 titleName 变量在变化时的逻辑，也就是刷新 titleText 的文本内容。

* 同步变量在赋值时不能使用“=”，而是需要使用“:SetValue(value)”，注意调用的是冒号，而不是点
* 同步变量在获取值时使用的是“:GetValue()”，注意调用的是冒号，而不是点
* **同步变量变化时会调用OnValueChange函数，回调中第1个参数为变化后的值，第2个参数为变化前的值**


2. **动态生成称号**

```Lua
                                    --TitleManager.lua
---@var titleKeyName:string
---@end
--缓存房间内所有的称号，用这个表来管理
local allTitleTable = {}

function Awake()
    -- _G 是Lua中一个全局变量，它是一个表，你可以将它理解为一个全局变量索引表
    _G["__Title_Manager__"] = self.script
end

function OnActorSpawned(actor)
    if actor == nil then
        return
    end
    if not actor.isLocal then
        return
    end
    if allTitleTable[actor.actorID] then return end
    actor:NetSpawn(titleKeyName, function(go, id)
        local actorTitle = go:GetDouyinScript("ActorTitle")
        local actorTitleScript = actorTitle.script
        actorTitleScript.SetTargetActorId(actor.actorID)
    end)
end
```

创建一个 DouyinScript Lua 脚本，修改脚本名字为“TitleManager”，并将上面代码块中的代码复制进脚本中。
保存代码，在场景中创建一个空物体，然后将该脚本挂载到空物体上。（场景中只能存在唯一一个挂载该脚本的物体）
这段代码的主要逻辑是当有玩家在房间内生成时，先判断是否为本地玩家，如果是本地玩家，那么就通过 NetSpawn 动态生成网络对象（UI称号预制体），并记录该玩家的ID。（用 ActorTitle 脚本中的 targetActorId 来记录）
* 使用本地table来管理房间内所有的称号，数据结构是actorid为key，生成的UI称号对象为value。
* 使用_G这个全局变量表的的好处是：其他对象脚本中不需要通过定义DouyinScript变量并拖拽挂载TitleManager的对象来调用TitleManager的函数。
* 当有玩家生成时会调用OnActorSpawned函数，在该函数中通过调用 DouyinActor.NetSpawn 接口来动态生成一个与玩家关联的网络对象。
* DouyinActor.NetSpawn 接口的第1个参数是网络对象生成配置的key值，第2个参数是一个对象生成后的回调，go是生成的对象，id是生成对象的唯一标识。


3. **记录actor和对应的称号UI预制体**

```Lua
                                   --TitleManager.lua
--将actorid和对应的称号UI预制体存入表中
function RegisterTitleTable(actorID, actorTitle)
    if actorID == nil or actorTitle == nil then
        return
    end
    allTitleTable[actorID] = actorTitle
end
--将actorid和对应的称号UI预制体从表中移除
function UnRegisterTitleTable(actorID)
    if actorID == nil then
        return
    end
    allTitleTable[actorID] = nil
end
```

在 TitleManager 脚本中，新增 RegisterTitleTable 函数和 UnRegisterTitleTable 函数，用于管理actor和actor所对应的动态生成的称号UI。

4. **称号初始化逻辑**

```Lua
                                -- ActorTitle.lua
--网络对象生成时，会调用该函数--
function OnNetSpawned()
    InitTitle(GetTargetActorId())
end
--初始化称号--
function InitTitle(targetActorIdValue)
    if targetActorIdValue == nil then
        return
    end
    --根据ID获取对应的actor
    local targetActor = DouyinActorService.GetActorById(targetActorIdValue)
    if not targetActor then
        print("---targetActor is nil" .. targetActorIdValue)
        return
    end

    --将actorid和称号UI脚本传入管理脚本中，使用allTitleTable表来统一管理
    _G["__Title_Manager__"].RegisterTitleTable(targetActorIdValue, self)

    --初始化UI
    self.transform:SetParent(targetActor.gameObject.transform)
    self.transform.localPosition = Vector3(0, offsetY, 0)
    titleText = self.transform:Find("TitleText"):GetComponent(typeof(UI.Text))
    titleText.text = titleName:GetValue()

    --设置UI持续面向摄像机逻辑的相关变量
    titleTextTrans = self.transform
    targetCamera = DouyinCameraService.GetCamera()
    targetCameraTrans = targetCamera.transform
end

--销毁称号--
function OnDestroy()
    _G["__Title_Manager__"].UnRegisterTitleTable(GetTargetActorId())
end
```

* 在网络对象生成后，所有客户端都会调用 OnNetSpawned 这个函数，我们可以在这个函数里做一个初始化的操作。
* 动态生成网络对象时，一定要牢记：有生成，就要有销毁。

## 称号面向摄像机逻辑
称号生成后，我们会发现它并没有始终面朝摄像机。
想要实现称号始终面向摄像机，可以通过 LookAt 函数来实现。
```Lua
                                -- ActorTitle.lua
-- Unity LateUpdate 函数--
function LateUpdate()
    TitleLookAtCamera()
end
--让称号持续面向摄像机--
function TitleLookAtCamera()
    if not titleText then
        return
    end
    if not targetCamera then
        targetCamera = DouyinCameraService.GetCamera()
        if not targetCamera then
            return
        end
        targetCameraTrans = targetCamera.transform
    end
    titleTextTrans:LookAt(
        titleTextTrans.position + targetCameraTrans.rotation * Vector3.forward,
        targetCameraTrans.rotation * Vector3.up)
end
```

## 更新称号逻辑
当需要改变玩家的称号时，我们可以在 ActorTitle 脚本中定义一个 SetTitleValue 函数，用于更新玩家的称号；然后再在 TitleManager 脚本中定义一个 UpdateActorTitle 函数，用于统一管理称号的更换。
```Lua
                                    -- ActorTitle.lua
--设置称号，需要注意主权的转换--
function SetTitleValue(titlestr)
    if titlestr == nil then
        return
    end
    --注意判断主权
    if self:HasOwnership() then
        titleName:SetValue(titlestr)
    else
        self:SendMessageToOwner("SetTitleValue", titlestr)
    end
end
```

```Lua
                                    --TitleManager.lua
function UpdateActorTitle(actorID, titlestr)
    if actorID and titlestr then
        local targetTitle = allTitleTable[actorID]
        if targetTitle and targetTitle.script then
            targetTitle.script.SetTitleValue(titlestr)
        end
    end
end
```

## 新玩家加入时的同步逻辑
当房间进入新玩家后，需要根据同步变量 targetActorId 的变化对房间内所有玩家进行同步处理。
在 ActorTitle 脚本中定义一个 local 变量 actorId，然后在Start函数中监听同步变量 targetActorId 的OnValueChange 事件。

```Lua
-- 称号显示位置的差值
---@var offsetY:float = 1
-- 定义称号的同步变量  
---@varSync titleName:string = "青铜"
-- 记录称号对应的玩家的actorid
---@varSync targetActorId:int
---@end
local Vector3 = UnityEngine.Vector3
local UI = UnityEngine.UI
local titleText --显示称号的text
local titleTextTrans --称号预制体的transform
local targetCamera --本地玩家的摄像机
local targetCameraTrans --本地玩家的摄像机的transform

local actorId = nil
-- Start is called before the first frame update
function Start()
    --称号改变时刷新称号名称
    titleName:OnValueChange(function(curVal, preVal)
        if titleText then
            titleText.text = curVal
        end
    end)
    targetActorId:OnValueChange(function (curVal,preVal)
        InitTitle(curVal)
    end)
end
```

同时在 InitTitle 方法中，过滤掉 同步变量 targetActorId 变化时对客户端自己的处理。
```Lua
function InitTitle(targetActorIdValue)
    if targetActorIdValue == nil then
        return
    end
    if actorId == targetActorIdValue then
        return
    end
    local targetActor = DouyinActorService.GetActorById(targetActorIdValue)
    if not targetActor then
        print("---targetActor is nil" .. targetActorIdValue)
        return
    end

    actorId = targetActorIdValue
    _G["__Title_Manager__"].RegisterTitleTable(targetActorIdValue, self)
    self.transform:SetParent(targetActor.gameObject.transform)
    self.transform.localPosition = Vector3(0, offsetY, 0)
    titleText = self.transform:Find("TitleText"):GetComponent(typeof(UI.Text))
    titleText.text = titleName:GetValue()
    titleTextTrans = self.transform
    targetCamera = DouyinCameraService.GetCamera()
    targetCameraTrans = targetCamera.transform
end
```
