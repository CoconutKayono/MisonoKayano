## 1. 能力概述
该文档为开发者介绍了如何在“世界”中集成和使用抖音的社交分享能力，包括自定义IM卡分享和图片分享。通过这些能力，开发者可以鼓励用户将“世界”中的精彩内容分享给好友或群组，从而提升用户活跃度和世界的曝光度。
## 2. IM卡自定义分享能力
### 2.1 功能介绍
为了满足更丰富的分享场景，平台提供了IM（即时通讯）场景下分享卡片的自定义能力。开发者可以自定义分享卡片的标题、描述和封面图，让分享内容更具吸引力。
### 2.2 准备工作

* **素材设计规范**：
   * **标题字数限制**：最多 13 个字符

![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/925e2a803aea43c4a4f57185b11e26bf~tplv-goo7wpa0wc-image.image)
### 2.3 实现步骤

1. **配置分享内容**：在调用分享API前，在虚拟创作后台 - 社交分享能力 - 设置好要分享的标题、描述和图片。
2. **调用分享接口**：通过调用分享API，传入配置好的参数，唤起分享流程。[分享API>>](https://vcreate.douyin.com/pet/wiki/4j78bceb/04h7zkl4?_lang=zh)
3. **分享用法示例：**

```Lua
-- 假设这是在创作者平台获取到的，已审核通过的自定义分享模板 ID
local CUSTOM_TEMPLATE_ID = "tmpl_ab12cdefg345hijk"
-- 分享方法
function ShareWorld()
--判断当前是否为本地调试器环境，本地调试器不支持分享
    if DouyinApplication.isSimulator then
        print("世界分享测试 调试器不支持","yellow")
        return
    end
    print("正在调用 ShareWorld 进行世界分享...")
    DouyinSocialService.ShareWorld(CUSTOM_TEMPLATE_ID,function (value)
        if value then
            print("世界分享成功完成", "green")
        else
            print("世界分享失败或被取消", "red")
        end
    end)
    print("ShareWorld 调用成功","green")
    print("请检查是否成功打开世界分享界面","yellow")
end
```

## 3. 图片分享能力
### 3.1 功能介绍
允许用户将“世界”内的画面截图或渲染的图片直接分享给抖音好友。这常用于成就炫耀、精彩瞬间记录等场景。被分享用户可点击该图片进入世界，典型使用场景：

* 游戏结算时，生成一张包含玩家得分、排名的精美图片，并提供按钮让玩家可以一键分享“战绩截图”。
* 在一个装扮或建造类玩法中，允许玩家对自己当前的作品进行“拍照”，并将照片分享给好友。

### 3.2 实现方式
通常分为两步：生成图片和调用分享。

1. **生成/获取图片**：
   * 可以使用预先制作好的图片资源。图片尺寸建议：168 * 264（安卓）/168 * 224（IOS），尺寸过小会导致预览视图图片显示不全。
   * 可以实时渲染图片。
2. **调用图片分享API**：将图片数据传递给分享接口。
