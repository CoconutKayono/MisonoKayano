消息互通是指玩家直接互发消息的方式，这个方式有更高的自由度，方便大家实现各类想要的规则逻辑。  
比如玩家进入舞池开始跳舞，并且可以施放特殊舞姿，就可以使用玩家之间消息互通来实现：玩家A使用某个舞姿开始跳舞，并通知所有人，其他人接收到这个消息，并在自己的客户端上为玩家A播放这个舞姿动作。
# 发送与接收消息
你可以使用 DouyinScript API 向其他玩家发送消息，具体有以下几种方式：
| [DouyinScript.SendMessageToOwner(string method, params object[] args)](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=aahe4ifa) | 向主权方发送消息 |
| --- | --- |
| [DouyinScript.SendMessageToAll(string method, params object[] args)](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=irjzzgik) | 向所有人发送消息，包括自己 |
| [DouyinScript.SendMessageToTarget(string method, ParaPlayer target, params object[] args)](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=vugq9ty9) | 向某个玩家发送消息 |

* 第一个参数均为 method，接收方收到消息后，会自动运行与 method 同名的函数。
* 后面可以传递可变参数，根据自己的需要进行传递即可，method 函数的输入参数需要与此处对应，即可在函数中直接使用参数。  

参数当前支持的类型包括：**bool, byte, short, int, long, float, double, string**。  
# 远程调用
Douyin World 提供另一种消息互通的方式，允许某个玩家直接调用其他玩家客户端上的某个函数。这是一种更加灵活的方式。
| [DouyinScript.OwnerCall(string method, Action onFinish, params object[] args)](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=y31jtrrg) | 调用主权方的某个函数 |
| --- | --- |
| [DouyinScript.TargetCall(string method, ParaPlayer target, Action onFinish, params object[] args)](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=xernotd7) | 调用某个玩家的某个函数 |
# 消息互通 vs 同步变量
聪明的你已经发现，消息同步如同同步变量一样，都属于玩家之间进行通信的方式。  
完全可以使用消息互通实现与同步变量相同的效果，只是那样会需要写很多代码，而同步变量更加的简洁。  
但是消息互通可以根据需要，一次性同步多个参数，而同步变量只能一个一个的单独同步；所以，当你需要通过多个数据来综合做一些逻辑判断时，使用消息互通的函数会更加方便。
另外，思考一下，在消息已经被发送之后，再加入你的世界的玩家会怎么样？很简单，他能够获得最新的同步变量的值，但无法收到已经被发送过的消息。
注意思考不同方式的特性，尝试去实现自己的世界吧。
