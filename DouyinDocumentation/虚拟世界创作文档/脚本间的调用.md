# 脚本调用
有时我们会有这样的一个需求：在A脚本中去调用B脚本的某个方法。
想要实现这样的逻辑，你需要先获得对应脚本的容器，也就是 Douyin Script 对象，然后才可以调用绑定的Lua脚本中的**非local方法**。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7d292de90a2f4598a9d646130104d861~tplv-goo7wpa0wc-image.image" width="264px" /></div>

使用方式为：**变量.script.方法(参数)**
比如：
```Go
---@var myScript:DouyinScript
---@end
myScript.script.Func() --注意使用的是点，而不是冒号
```

# 相同物体不同脚本的调用
相同物体之间不同的Lua脚本想要相互引用的话，除了可以在Inspector面板上将物体拖拽至自身对应组件的目标位置处外，还可以通过如下2个API接口来获取指定脚本：

* DouyinScript GetDouyinScript(string name)：通过名字获得 DouyinScript，如果有多个同名的 DouyinScript，默认返回第一个； 
* DouyinScript[] GetDouyinScripts(string name)：如果有多个同名的 DouyinScript，可以通过此方法获得一个数组。

比如：相同物体身上绑定了A和B这2个脚本，我们要在A脚本中通过代码的形式来调用B脚本中的Func方法。
```Go
local bScript = self:GetDouyinScript("A") --self表示脚本挂载物体的所属对象
if bScript ~= nil then
    bScript.script.Func()
end
```

# 不同物体之间脚本的调用
如果你想要在代码中调用其他物体上的lua脚本，但又不想通过绑定脚本的形式，那么你也可以通过 GetDouyinScript/GetDouyinScripts 来获取指定脚本，但前提是先获取绑定脚本的物体实例。
