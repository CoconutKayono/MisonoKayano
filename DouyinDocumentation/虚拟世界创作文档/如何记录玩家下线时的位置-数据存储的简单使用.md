很多玩法中需要记录玩家在下线时的位置，当玩家再次上线时，就可以将玩家的初始位置设置为上次下线时的位置。想要实现这个效果，需要借助[数据存储功能](https://vcreate.douyin.com/tutorial?book=s196aspp&doc=ld5p68ra)。
本篇教程将会通过 实现记录玩家下线时的位置这样的一个小案例 向各位开发者介绍数据存储功能的简单应用，更多关于数据存储的内容，请参加：[数据存储使用说明](/s196aspp/5olca5xj)
# 步骤1：存储下线时的位置
为了能更加准确的记录玩家的位置，我们可以**每分钟（或更短时间）来记录一次玩家当前的位置**。
打开准备好的场景，创建一个Lua脚本，修改名字为“PlayerDataManager”，并在场景中创建一个空物体，用于挂载创建的 PlayerDataManager 脚本。
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f19c9a7d00a34483b5619c30210c5747~tplv-goo7wpa0wc-image.image)
双击打开脚本，并将下述代码复制粘贴到脚本中。
SavePlayerPosition 函数的作用是开启数据存储，保存当前玩家的位置信息。
```Go
function SavePlayerPosition()
    --启用数据存储时需要在 DATASTORE 关键词内书写，此为固定格式
    DATASTORE(
        function ()
            --数据存储需要使用唯一标识ID作为key，我们可以使用玩家的playerOpenID来作key
            local player = CS.DouyinPlayerService.GetLocalPlayer() 
            if player == nil then
                print("error: 玩家获取失败")
                return
            end

            --获取DataStore对象
            local ok, store = DouyinDataService.GetDataStore("playerData", "player_info_"..player.playerOpenID)
            if ok ~= 0 then
                print('数据存储加载失败，失败详情:' .. ok .. tostring(store))
                -- 如果没有拿到数据，可以给一个初始位置，可根据错误码提示自行补充逻辑
                return
            end

            --记录玩家当前位置
            local curActor = player:GetActor()
            if curActor == nil then
                print("error: 获取当前玩家失败")
            end
            local key = player.playerOpenID
            local value = {curActor.position.x,curActor.position.y,curActor.position.z}
            store:SetData(key,value)
        end
    )
end
```

# 步骤2：再次上线时传送至记录的位置
完成位置信息保存后，就可以在玩家再次进入世界时调用该信息来刷新玩家的位置。
可以将下述代码复制粘贴进脚本中。
SetPlayerPosition 函数是用来设置玩家的位置，若是在获取数据时失败，玩家将会按照 Douyin World Root 组件上的出生点来设置自己的位置。
```Go
function SetPlayerPosition()
    --启用数据存储时需要在 DATASTORE 关键词内书写，此为固定格式
    DATASTORE(
        function ()
            --数据存储需要使用唯一标识ID作为key，我们可以使用玩家的playerOpenID来作key
            local player = CS.DouyinPlayerService.GetLocalPlayer() 
            if player == nil then
                print("error: 玩家获取失败")
                return
            end
            
            --获取DataStore对象
            local ok, store = DouyinDataService.GetDataStore("playerData", "player_info_"..player.playerOpenID)
            if ok ~= 0 then
                print("数据存储加载失败，失败详情:" .. ok .. tostring(store))
                return
            end
            
            --获取存储的玩家位置
            local curActor = player:GetActor()
            if curActor == nil then
                print("error: 获取当前玩家失败")
            end
            local key = player.playerOpenID
            local ok,value,info = store:GetData(key)
            if ok ~= 0 then
                print("获取数据失败，失败详情："..ok.." 失败描述："..value)
                return
            end

            --数据获取成功，将玩家传送至对应位置
            local posTable = dkjson.decode(value) --使用json反序列化，详情可查JSON反序列化
            local position = UnityEngine.Vector3(posTable[1],posTable[2],posTable[3])
            curActor:Teleport(position)
            print("位置修改成功-----------")
        end
    )
end
```


# 步骤3：补充逻辑
为了让玩家进入世界后能够传送至上次下线前记录的位置，我们可以在 OnActorSpawned 函数中调用 SetPlayerPosition 函数。
代码如下：
```Go
function OnActorSpawned(actor)
    if actor == nil then
        return
    end
    if actor.isLocal == false then
        return
    end
    SetPlayerPosition()
end
```


因为我们要每分钟记录一次玩家位置，那么我们可以在 Update 函数中来每隔60秒来调用一次 SavePlayerPosition 函数。
代码如下：
```Go
local timer = 0
function Update()
    --计时，每60秒记录一次玩家当前的位置
    timer = timer + UnityEngine.Time.deltaTime
    if timer > 60 then
        timer = 0
        SavePlayerPosition()
    end
end
```

# 步骤4：开启数据存储&测试
完成代码编写后，回到 Unity，启动调试器，勾选启用数据存储，选择任意云处理成功的世界（若没有，需要先上传一个世界）。

# 扩展思路：
## 添加手动保存按钮
目前代码逻辑上仅能按照固定时间进行自动存储，针对一些特殊场景，例如玩家在游戏中进行长时间的操作，需要手动保存，可以考虑增加一个手动保存按钮，点击后触发存储逻辑。
## 增加 Loading 界面
目前在小火人进入世界后会有一个传送的过程（出生点->保存点），可以使用 loading 界面挡住这个传送过程，当传送结束后，再关闭 loading 界面，这样在体验上会更友好一些。
