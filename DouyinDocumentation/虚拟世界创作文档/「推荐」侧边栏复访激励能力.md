# 能力概述
随着抖音造世界复访能力的完善，抖音首页侧边栏日活持续增高，平台推荐开发者均接入抖音首页侧边栏复访教育，引导用户从首页侧边栏进入游戏，养成用户 **打开抖音 → 打开首页侧边栏 → 快速访问小游戏** 的心智，大幅提升世界的次留、7留。[相关API >>](https://vcreate.douyin.com/pet/wiki/4j78bceb/a41czq0t?_lang=zh)
**适配宿主：​**抖音、抖音极速版。
# 能力示例
开发者在游戏内设置奖励，引导复访的能力 → 游戏版本发布 → 用户在游戏主界面看到引导礼包 → 用户根据指引从侧边栏进入游戏 → 进入礼包界面获取复访奖品
