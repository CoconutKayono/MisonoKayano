# **什么是虚拟世界？**
虚拟世界是抖音重点布局的社交互动与内容消费新场景，用户以 “合养精灵” 的身份进入其中，畅游各类世界，进行拍照、聊天、音视频、购物、互动社交等多元玩法探索，融合了探索、社交、创作、娱乐四大核心体验，是一个用户共创、持续进化的 3D 虚拟互动平台。用户可体验官方世界（如 “海岛乐园”）的道具互动、同台共舞等基础玩法，也能穿梭于迪士尼、熊出没等 IP 主题世界，感受剧情沉浸、解谜跑酷、种植农场等特色内容。
为了满足用户探索更多元虚拟场景的需求，抖音开放了虚拟世界创作平台。这是一个 3D 世界创作平台，旨在激发创作者的无限创意，设计出各种生动有趣的 3D 虚拟世界，供抖音用户体验，成为他们社交互动的新阵地、内容新场景！

# **如何开始？**（四步搞定）

* **报名加入**：点击下方链接填写报名表。

点击下方链接填写报名信息即可参与：
https://bytedance.larkoffice.com/share/base/form/shrcnvfMNgEmG35mey8FhRjlYjf


* **获取工具**：在电脑上安装指定版本的 **Unity (2021.3.14f1)**，并下载我们提供的 **DouyinWorld SDK (创作插件包)**。👉下载链接[下载 Unity](/s196aspp/no8pol8a)，有详细步骤
* **动手创作**：在Unity中发挥你的创意，搭建3D世界。
* **发布上线**：在Unity中完成创作后，一键打包上传。审核通过后，你就可以选择将你的世界正式在抖音对用户开放！

**详细创作指南和创作相关同步可见**：[准备场景](/s196aspp/3so0iush)
任何实际创作中的问题都可以与我们联系，会有专门的技术同事提供指导。
