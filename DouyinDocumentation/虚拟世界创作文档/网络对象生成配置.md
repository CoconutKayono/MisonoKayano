# 网络对象
网络对象用于想要在所有玩家端上同步的对象。
只需要将场景中的GameObject挂载 **Douyin Object Sync（网络同步组件）​**即可将物体变成一个网络对象。

## 网络同步组件
**网络同步（Douyin Object Sync）​**组件用于在网络环境中同步游戏对象的状态，确保世界内玩家看到的游戏对象的状态是一致的。例如玩家拿起一个物品，其他玩家也要看到物品被拿起。
当游戏对象需要被同步时，可以挂载此组件，此游戏对象会变成网络对象。默认同步tranform，若此物体同时挂载了 rigidbody，则同步刚体的postion和rotation，所有人可同步获取到此物体的位置和状态信息。
当对象重生后，会将对象传送回初始位置和方向；若为刚体，则速度也会被设为 0，并以下参数重置并自动同步：
如未挂载刚体： 
  transform.position 设置为初始位置。
  transform.rotation 设置为初始角度。
如挂载刚体：
 rigidbody.velocity 设置为 0。
 rigidbody.angularVelocity设置成 0。
 rigidbody.position 设置为初始位置。
 rigidbody.rotation 设置为初始角度。

# 网络对象配置
想要使用网络对象，需要在 Douyin World Root 组件上进行关联配置。
你需要创建 **Douyin Net Spawn Object Asset**
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a46fd4ff307d40d2afec0d3118923fc5~tplv-goo7wpa0wc-image.image" width="500px" /></div>

然后将创建的 **Douyin Net Spawn Object Asset** 拖入 Douyin World Root 组件的网络对象生成配置中，点击数组列表+号，即可添加网络对象。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/43a2a37d3aec4e379a4a3417ab6ddb3d~tplv-goo7wpa0wc-image.image" width="500px" /></div>

你可增删网络对象数组，数组中每个元素包含： 

* 主键：长度不限，但必须唯一。 
* 游戏对象：可关联场景中的 GameObject，GameObject需挂载**网络同步组件。**

更多关于网络对象的内容请参见[网络对象](/s196aspp/3vb3ze0u)
