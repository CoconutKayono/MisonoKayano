# 椅子组件介绍
在抖音虚拟世界SDK中提供了椅子组件（**DouyinSeat**）。如果你想让玩家在世界里坐下，可以用该组件。把这个组件添加在椅子模型上，当玩家靠近椅子时，会弹出UI提示，玩家点击“**坐下**”按钮，就能坐到椅子上指定的位置。点击“**站起**”按钮，玩家就会从椅子上站起来。
在Assets/DouyinVCreateSDK/World/Examples/DouyinSeat 文件夹中有SDK提供的椅子组件预制体。你可以将预制体拖入场景中使用，也可以将组件脚本挂载到自己准备的模型上。

# 属性
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/69cef50f9f124e33a9fd758d8a69d513~tplv-goo7wpa0wc-image.image" width="300px" /></div>

| **属性** | **说明** |
| --- | --- |
| 脚本文件 | 此组件为Lua组件，需添加 **Douyin Script** 组件后，在脚本文件中添加 **DouyinSeat** 脚本。 |
| 交互触发范围 | **范围类型** <br>  <br> 1. **圆形区域**：在物体的中心点生成一个球形的Collider，输入数字即可改变范围大小。 <br> 2. **自定义范围**：可自定义碰撞体（Collider），改变碰撞体大小可改变交互范围。 <br>  <br> **范围半径**：以米为单位的半径大小。 <br> **区域**：可拖入自定义碰撞体（Collider）。 |
| 座位设置 | **坐下位置：​**玩家坐下的位置，通过在座位上设置挂点来设置。 <br> **站起位置：​**玩家站起的位置，通过在座位旁设置挂点来设置。 <br> **自定义坐下动作：​**自定义角色坐下的动画。 |
| 坐下按钮设置 | **按钮图标**：推荐使用72*72的贴图，默认使用官方贴图。 <br> **按钮底板**：推荐使用369*90的贴图，默认使用官方贴图。 <br> **按钮文本**：默认为“坐下”。 <br> **文本颜色**：默认为黑色。 |
