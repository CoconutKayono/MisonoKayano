问：可以使用Unity的协程吗？
答：可以，支持使用xlua的协程，同时搭配Unity的延时方法来使用。
具体代码可参考：
```Lua
local util = require('xlua.util')
local UE = CS.UnityEngine

function Start()
    local action = util.cs_generator(function(second)
        for i=1,10,1 do
            coroutine.yield(UE.WaitForSeconds(second))
            print(i)
        end
    end,1)
    self:StartCoroutine(action)
end
```
