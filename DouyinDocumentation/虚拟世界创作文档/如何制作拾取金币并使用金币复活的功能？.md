本篇教程实现的具体效果如下：

1. 玩家进入世界后可以拾取金币，此时玩家界面上将会展示金币数量以及金币增加的动画效果。
2. 玩家进入存档点区域，若该存档点还未记录，则将会更新当前存档点为最近存档点。
   1. 存档点的ID要按照先后顺序从小到大填写。
3. 玩家触碰失败区域时，会弹出金币复活面板，此时玩家的外观被隐藏，同时也无法飞行、移动、与他人牵手。
   1. 如果玩家点击取消按钮，那么玩家将会回到出生点位置，记录的存档点也会被清空，各项功能也都会恢复正常。
   2. 如果玩家点击复活按钮，那么将会扣除玩家复活需要的金币数量，同时玩家将会被传送到最新存档点位置，各项功能也都会恢复正常。
      1. 扣除金币时，金币UI会展示扣除动画。
      2. 若金币不够时，会弹出toast提示。

# 金币管理器
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1ddac0a67bd64efeadaff0d950dac7e9~tplv-goo7wpa0wc-image.image" width="264px" /></div>

示例工程的 Game Scripts 文件夹中的 CoinManager 是一个 module script，它的作用是初始化金币数据、管理金币的增加/减少相关操作的存储、作为获取金币数量的唯一入口。

<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a8ba6f2c99b04f27a16b4510fb523ec6~tplv-goo7wpa0wc-image.image" width="264px" /></div>

SDK内使用 module script，需要将其所在的文件夹拖拽至 Douyin World Root 组件所挂载的对象上的自定义脚本文件夹中。
在文件夹中的 module script 会在SDK初始化时进行加载，具体的加载流程可参阅[自定义 Module Script](/s196aspp/63pmv6dd)。

<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fd34cc408d6443dca5230482f46105c7~tplv-goo7wpa0wc-image.image" width="500px" /></div>

想要在其他 Lua 脚本中调用 module script 的实例，需要使用 require 关键词，根据相对路径来加载对应的 module script。
比如示例工程中的 GameManager 脚本中开头的 `require "CoinManager"` ，这就是加载了 CoinManager 这个module script。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c6e1be722d2d4646ba17e5d099666dc6~tplv-goo7wpa0wc-image.image" width="500px" /></div>

金币管理器中的脚本带有详细的注释，可根据注释理解对应的函数和代码的作用，下面简单介绍各个函数的执行逻辑：

* CoinManager:InitCoin：初始化金币数据，参数为一个回调函数，当金币数据初始化完成后，会调用该回调函数。执行时机是当合养精灵进入世界加载成功后调用，回调参数是刷新金币UI显示。
* UpdateCoin：这是一个不可被调用的函数，用于在金币数量更新时刷新存储的金币数据。
* CoinManager:AddCoin：增加金币，参数是增加的金币数量。
* CoinManager:ReduceCoin：减少金币，参数是减少的金币数量。
* CoinManager:GetCoin：获取当前金币数量，注意这里获取的不是存储的金币数量，而是本地缓存的金币数量。

# 游戏管理器
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7d0e5fd528a149b5ad6195a1a8b4553f~tplv-goo7wpa0wc-image.image" width="264px" /></div>

示例工程的 Game Scripts 文件夹中的 GameManager 是一个 DouyinScript 的 Lua 脚本，使用它是需要在场景中创建一个空物体，给空物体增加 DouyinScript 组件，并将该脚本挂载到组件的脚本文件属性上。
该脚本主要负责如下逻辑功能：

* 小火人加载完成时的数据初始化
* 获取/消耗金币时调用的函数、金币UI的刷新与动画
* 复活面板上的复活按钮和取消按钮的点击事件
* 存档点的记录
* 玩家失败时调用的函数

<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4d9fb2b5b1344de196b23ee0860cbeee~tplv-goo7wpa0wc-image.image" width="500px" /></div>

脚本中的注释详细介绍了每个变量和函数的作用，这里简单介绍一下各个函数的执行逻辑：

* Start ：Unity 的 Start 函数，在游戏开始时调用。
* OnActorSpawned：合养精灵在世界内生成时自动调用一次，参数为进入世界的actor，在这里使用该函数来初始化金币数据，记录当前本地玩家，记录出生点等操作。
* UpdateCoinUI：更新金币UI的函数，在金币变化时调用。
* AddCoin：当玩家触碰到场景中的金币时调用该函数。
* OnPlayerFail：当玩家触碰到场景中的失败区域时调用该函数。
* OnClickRespawn：当玩家点击复活面板上的重生按钮时调用该函数，函数内会判断玩家的金币数量是否满足复活所需要的金币数量，如果不满足，则会弹出toast提示；反之，则会扣除复活所需要的金币数量，并执行复活操作。
* OnClickCancel：当玩家点击复活面板上的取消按钮时调用该函数，函数内会执行关闭复活面板，将玩家传送回出生点，以及一些初始化的逻辑。
* UpdateSavePosition：当玩家触碰到存档点区域时调用，会判断当前存档点与记录的存档点之间的ID大小对比，只按照ID从小到大的顺序记录存档点。
* Update：Unity 的 Update 函数，每帧调用，主要是处理金币UI动画效果。
* PlayUIAnim：当金币增加/减少时，触发调用，用于展示金币UI的动画效果。

# 拾取金币脚本
示例工程的 Game Scripts 文件夹中的 PickUpCoin 脚本是拾取金币脚本，使用该脚本时，需要确保金币物体挂载了碰撞组件，且勾选了Is Trigger选项。

然后，即可通过 DouyinScript 组件来挂载该脚本，同时需要将 GameManager 脚本所挂载的物体推拽至对应的属性上。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8289f6e7230a460a8836f6c3c748d662~tplv-goo7wpa0wc-image.image" width="500px" /></div>

该脚本的逻辑非常简单，也即是当玩家碰撞到金币物体时，调用 GameManager 脚本中的 AddCoin 函数，同时将自己隐藏。
