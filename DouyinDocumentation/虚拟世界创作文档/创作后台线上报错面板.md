# 什么是线上报错
当我们设计的虚拟世界成功上线后，并不意味着我们可以“高枕无忧”，因为线上环境复杂多变，在复杂的网络环境下，线上的虚拟世界也会出现一些问题，从而影响用户的体验。
所以我们要密切关注“线上报错”，及时发现它们，并且解决它们，让线上报错的影响尽可能的降到最低。
# 如何查看线上报错
目前抖音虚拟世界线上报错面板已上线，该面板允许开发者查看最新的Luau系统的错误。你可以按照如下路径打开线上报错面板：[抖音虚拟创作平台 -> 创作中心页面 -> 选择世界 -> 分析-错误报告](https://vcreate.douyin.com/console/world)。

# 监控错误
你可以在错误报告中应用以下过滤器和切换项：

* **日期范围:** 过滤最近 1 小时、最近 1 天、最近 7 天或最近 14 天。
* **数据类型:** 按照**错误数**和**影响用户数**进行分类，查看错误的影响趋势

在过滤器和切换项下方，图表显示选定时间内的错误和警告数量。使用此图表查看错误和警告随时间的增加情况。如果看到错误和警告的大幅上升，请使用错误报告表进行故障排除。
