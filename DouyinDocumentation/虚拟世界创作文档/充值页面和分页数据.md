## 商品分页
随着商品数量持续增加，若通过`DouyinMarketingService.GetProductInfos`接口单次请求获取所有商品信息，可能因数据量过大导致请求超时。为保障接口调用稳定性，建议根据商品数量选择合适的获取方式：当商品数量不超过 50 时，使用`DouyinMarketingService.GetProductInfos`接口一次性获取所有商品信息；当商品数量超过 50 时，推荐采用分页方式获取商品信息。
### 商品分页数据
分页数据通过`DouyinProductPage`类封装，具体字段说明如下：
```C#
public class DouyinProductPage 
{
    public int pageOffset; // 当前商品页的起始索引
    public int pageSize; // 当前商品页的页面大小
    public Int64 totalSize; // 当前所有商品的数量
    public Int64 queryTime; // 查询时间
    public bool hasMore; // 是否还有更多的商品信息
    public List<DouyinProductInfo> productInfos; // 当前页面的所有的商品信息
    
    // 获取下一页的商品数据
    public void AdvanceToNextPage(Action<int, string, DouyinProductPage> callback) 
}
```

### 获取商品分页信息
通过`DouyinMarketingService.GetProductPage`接口获取分页数据，具体定义如下：
```C#
public static class DouyinMarketingService 
{
    public static void GetProductPage(int pageSize, Action<int, string, DouyinProductPages> callback)
}
```


* **方法定义**：该接口用于获取商品分页的首页数据，并返回`DouyinProductPage`。
* **参数说明**：
   * `pageSize`: 每页展示的商品数量（建议根据业务场景设置合理值）
   * `callback`：结果回调
      * 返回状态码：0 成功，非0 失败
      * 错误信息：返回状态码非0时的错误信息描述
      * 返回首页商品分页数据对象`DouyinProductPage`

### 示例

* **获取首页数据**：调用`GetProductPage`并传入期望的`pageSize`，通过回调获取首页的`DouyinProductPage`对象（包含首页商品列表及`hasMore`状态）。
* **获取后续页面**：若`hasMore`为`true`，调用当前`DouyinProductPage`对象的`AdvanceToNextPage`方法获取下一页数据，重复此步骤直至`hasMore`为`false`。
* **终止条件**：当`hasMore`为`false`时，说明已获取所有商品数据，无需继续分页请求。

```Lua
function GetNextProductPage(page)
    if page.hasMore then
        page:AdvanceToNextPage(function(code, msg, nextPage)
            -- TODO：遍历nextPage.productInfos展示商品信息
       
            GetNextProductPage(nextPage)
        end)
    end
end

function GetFirstProductPage() 
    DouyinMarketingService.GetProductPage(50, function(code, msg, page) 
        if code ~= 0 then
            print("获取商品页数据失败，错误码:"..code.." 错误描述"..msg)
            return
        end
        -- TODO：遍历page.productInfos展示商品信息
        GetNextProductPage(page)
    end)
end
```
