# 🎁 活动激励
## 梯度激励
> 本次活动按照连续7天日均用户数或日均游玩总时长划分出了6个档位，**每个档位名额有限，先到先得哦～**

| **档位** | **作品需满足以下任意一个条件** |  | **奖金/款** | **每档名额数量** <br> **（先到先得）** |
| --- | --- | --- | --- | --- |
|  | **日均访问量** | **日均游玩总时长** |  |  |
| S+ | ≥ 100万 | ≥ 200 万分钟 | **100万** | **2** |
| S | ≥ 50万 | ≥ 150 万分钟 | **50万** | **5** |
| A+ | ≥ 20万 | ≥ 60 万分钟 | **25万** | **8** |
| A | ≥ 10万 | - | **15万** | **10** |
| B | ≥ 5万 | - | **5万** | **20** |
| C | ≥ 1万 | - | **1万** | **100** |
结算周期内，作品需在连续7天满足档位条件，即可获得对应最高档位激励！

* **日均访问量条件说明**：

> 简单理解：只要每天保持人均时长在4+分钟，剩下的就看访问量能不能达到档位啦


   * **作品在满足日均访问量时，需满足数据周期（7天）内每日人均时长大于4分钟**
   * **人均时长计算公式：周期内世界每日游玩总时长之和 / 周期内世界每日访问量之和（uid不去重）**
* **日均游玩总时长条件说明：**
   * A+、S、S+ 等3个档位除了通过达到日均访问量条件来获取激励外，如果作品连续7日的日均游玩总时长达到对应阈值，也可获得对应档位的激励
   * 日均游玩总时长计算公式：周期内每日游玩总时长之和 / 周期天数
   * 举例：X世界连续7日的每日游玩总时长之和为595万分钟，X世界的日均游玩总时长就等于85万分钟，那么X世界可以获得A+级档位奖励
* **结算周期：**
   * 活动周期内按照季度公示，并在活动结束后进行结算
* **统计规则：**
   * 每个季度初统计前期季度内数据，对于满足阶梯档位的作品予以公示
   * 若作品在连续季度中都满足阶梯档位，则在活动结束后取最高档位激励进行结算
      * 举例：X世界在1-3月中达到C级档位，在4-6月中达到B级档位，那么在活动结束后X世界将会获得B级档位的激励
* **统计口径：**
   * 日均访问量：取活动周期内连续7日日均最高访问量
   * 人均时长：在日均访问量最高的连续7日中，保持每日人均时长大于4分钟
   * 游玩总时长：所有进入世界的用户当日的累计游玩时长之和

* 发现刷量、买量作弊、诱导分享、灰产拉新等：
   * 取消当期激励；严重者追溯近3个月并扣回
* 数据异常处理：平台有权发起复核，必要时暂停发放直至核验完成
* 激励发放：激励将发放至世界上传的账号的抖音钱包，开发者可在抖音钱包提现
