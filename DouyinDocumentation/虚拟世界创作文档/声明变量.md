在Lua脚本中声明变量时，需要区分2种情况。
# 在 Inspector 面板上显示变量
想要在 Inspector 面板上显示声明的变量，从而对变量进行赋值修改等操作，需要按照如下规则进行声明。

* 使用 **---@var** 表示声明一个变量
* 使用 **---@end** 表示变量声明结束

<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a3aa6ce0a4d245e9a372191254365aca~tplv-goo7wpa0wc-image.image" width="264px" /></div>

通过这种方式声明的变量将会在 Unity 的 Inspector 面板上显示出来。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3a48a4a887a54e5b8662eb964c3974b7~tplv-goo7wpa0wc-image.image" width="264px" /></div>

> 注：与常规代码语言中声明变量一样，变量名不可重复，不可使用中文，区分大小写。
> 注：在变量声明结束后，一定要使用 ---@end 作为结束标识

# 按照Lua语法声明变量
对于那些不需要在 Unity 的 Inspector 面板上显示的变量，可以使用 Lua 语法进行声明。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3ea4ff1412bc4df39a7ceeb0859a50f4~tplv-goo7wpa0wc-image.image" width="264px" /></div>

> 注：Lua中声明变量时，需要注意local关键词的作用域，local 声明的变量在其以上的代码中是不可使用的。

# 支持的变量类型
当前支持的基础类型包括：
bool, byte, sbyte, short, ushort, int, uint, long, ulong, float, double, string, Vector2, Vector3, Vector4, Quaternion, Color。 

也可声明变量为 **Unity Class**，但在声明时需要包含完整的命名空间。
```Plain Text
---@var obj:UnityEngine.GameObject
---@end
```


也可声明以上类型的数组。
```Go
---@var intValues:int[]
---@var stringValues:string[]
---@var gameObjects:UnityEngine.GameObject[]
---@end
```


也可声明 **List** 和 **Dictionary**，Dictionary 的 key type 允许是 byte, short, int, long, string。
```Go
---@var list:List<int>
---@var dic:Dictionary<int,UnityEngine.GameObject>
---@end
```

也可以声明 DouyinScript 类型，来获取挂载Lua脚本的容器对象，用于调用绑定的Lua脚本中的非local方法。

```Go
---@var myscript:DouyinScript
---@end
```

# 使用变量
在 Lua 脚本中使用变量时，只需要直接书写变量名即可。
```Go
---@var message:string
---@end

-- Start is called before the first frame update
function Start()
    print(message)
end
```

# 同步变量
在 Douyin Script 中，我们提供了一种用于玩家之间数据同步的变量，也即是同步变量。
在声明同步变量时，需要使用 **---varSync** 来标识。
```Go
---@varSync intValue:int
---@varSync floatValue:float
---@varSync vectorValue:Vector3
---@end
```

声明同步变量之后，会在 Inspector 面板上显示出来。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1f58098a3a3e4acb96a88f5a337b0028~tplv-goo7wpa0wc-image.image" width="264px" /></div>

> 注：若是声明同步变量后，最好在场景中点击一下挂载同步变量脚本的物体，也即是刷新一下该物体，以确保同步变量的声明生效
