## 播放动作
你可能想要让世界中的显示对象播放动作，或者修改他们的动画状态机，来实现一些有趣的体验。比如：当玩家走进舞池时，会开始跳舞；或者，当玩家拿起武器后，会成为一个战士并使用一些技能。 
你可以使用以下几种方式来控制动作： 
| **控制玩家动画的API** | **描述** |
| --- | --- |
| DouyinActor.PlayAnimation | 使某个显示对象播放一个动作。  |
| DouyinActor.StopAnimation | 使某个显示对象停止播放被指定的动作。与PlayAnimation一起使用。  |
| DouyinActor.SetOverrideAnimation | 重载一个当前的动作。  <br> 设置重载动作为nil，就会还原到原本的动作。  |
| DouyinActor.SetOverrideAnimationController | 重载当前的动作控制器。  <br> 设置重载动作控制器为nil，就会还原到原本的动作控制器。  |
### 播放某个动作 
使用 PlayAnimation 可以让显示对象立刻播放一个新动作。而 StopAnimation 使某个显示对象停止播放由 Play Animation 触发的动作。 
Play Animation 方法有3个参数： 

1. 需要播放的动作。 
2. 可以设置一个回调函数，来实现在动作播放到某个时间时触发一些逻辑。 
* 此方法支持使用 Animation Event。可以通过设置 Animation Event 触发回调函数，从而实现在动画播放到某个时间时，触发想要的逻辑。关于 Animation Event 的设置方法，请参考：[Unity Animation Event](https://docs.unity3d.com/Manual/script-AnimationWindowEvent.html)。 
* Animation Event 只能触发这个被传入的回调函数，所以设置在 Event 中的 Function 名称不会起作用。所有 Event 都会触发这个回调函数。回调函数中可以读取到 Event 中的其他参数。 
3. 可以设置动作的 mask来控制动作播放影响的 Avatar 区域，比如只播放上本身动作等。具体请参考：**DouyinAnimatorMask**

Example 中的 PlayAnimation 就是用此方法实现。请参考代码： 
```Lua
---@var Animation:UnityEngine.AnimationClip;

-- Play animation when click the gameobject
function PlayAnimation()
    local me = DouyinActorService.GetLocalActor();
    -- Sync to all players in the room
    self:SendMessageToAll("SyncAnimation", me.actorID);
end

-- Receive the message, and play animation on all players' clients
function SyncAnimation(actorID)
    local actor = DouyinActorService.GetActorById(actorID);
    actor:PlayAnimation(Animation);
end

-- Stop playing animation when exit the collision
-- this will run on all clients
function OnActorTriggerExit(actor)
    actor:StopAnimation();
end
```

### 重载某个动作 
如果你想要在世界中动态替换当前动作控制器中的某个动作，可以使用[DouyinActor.SetOverrideAnimation]方法。 
重载时，需要指定被重载的动作名称。设置重载动作为nil，就会还原到原本的动作。 
在舞池中跳舞，就是使用此方法实现，代码参考如下： 
```Lua
function StartDance(actorID, normalIndex)
    local actor = DouyinActorService.GetActorById(actorID);
    -- After entering the dance floor, the idle animation will be replaced by a dance animation.
    actor:SetOverrideAnimation("proxy_Idle", NormalDance);
end

function EndDance(playerID)
    local actor = DouyinActorService.GetActorById(actorID);
    -- When leaving the dance floor, it will revert back to the normal idle animation.
    actor:SetOverrideAnimation("proxy_Idle", nil);
end
```

### 重载动作控制器 
如果你想要让显示对象在你的世界中拥有完全不同的动作逻辑，那么你可以重载当前的动作控制器。这也是最复杂的一种控制动作的方式。你可以用这种方式实现自己全新的动作游戏！ 
首先，你需要配置好一个新的动作控制器，他需要包含正确的状态切换逻辑，然后你可以使用[DouyinActor.SetOverrideAnimationController]方法将其重载到显示对象上，再使用 Unity 相关 API 控制新的动作控制器。 
当设置重载动作控制器为nil时，就会还原到原本的动作控制器。 
在 Unity 引擎中，AnimatorOverrideController 是用于重载 AnimatorController 中特定动作的组件，它可以让开发者在运行时更改动作，实现动作的动态替换和混合。 
[关于 Unity Animation](https://docs.unity3d.com/Manual/AnimationSection.html)
[关于 AnimatorOverrideController](https://docs.unity3d.com/Manual/AnimatorOverrideController.html)
