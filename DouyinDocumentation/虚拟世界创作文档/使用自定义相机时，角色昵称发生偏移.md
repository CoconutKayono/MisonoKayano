问：当在世界内使用自定义相机时，角色的昵称（等UI）发生了偏转/偏移
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/705a9974af1b49c796842aed2194a17f~tplv-goo7wpa0wc-image.image)

答：需要自定义相机的tag设置为MainCamera，如果只是将自定义相机预制体的tag修改为MainCamera是无效的，必须使用代码修改。
> 注意：在使用自定义相机时需要确保本地玩家已经完成创建，若是想要获取玩家主相机，可以调用[DouyinCameraService](/4j78bceb/q5jmqwtv)相关方法

```Lua
function Test()
    --    这里camera是指自定义相机
    Camera.gameObject.tag = "MainCamera"
end
```

使用自定义相机时，最好先关闭主相机（通过SetActive(false)设置）
