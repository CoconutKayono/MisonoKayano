# 关注组件介绍
在抖音虚拟世界SDK中提供了关注组件。它的效果是展示地图作者的抖音头像、抖音昵称、抖音粉丝数等信息，并在玩家靠近时，若玩家未关注作者，则展示关注按钮和查看主页按钮；若已关注作者，则展示查看主页按钮。
在 Assets/DouyinVCreateSDK/World/Examples/DouyinFollowPlane 文件夹中提供了关注组件预制体。你可以将预制体拖入场景中使用。

> 注：关注组件的名字是“DouyinFollowPlane”

# 属性
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/30a3d595ccaa428bb4b15d5fe4e35a71~tplv-goo7wpa0wc-image.image" width="300px" /></div>

| 属性 | 说明 |
| --- | --- |
| **脚本文件** | 此组件为Lua组件，由 **DouyinInteractor** 组件和 **DouyinFollowPlane**组件共同组成。 |
| **DouyinInteractor 组件** | 1. 交互逻辑：在交互逻辑中绑定了 **DouyinFollowPlane**组件中的 OpenCreatorInformation 方法。 <br>  <br>  |
| **DouyinFollowPlane 组件** | 1. 创作者头像：用于展示创作者头像的 Mesh Renderer <br> 2. 创作者名称：用于展示创作者昵称的 Text <br> 3. 粉丝数：用于展示创作者粉丝数的 Text <br> 4. 关注按钮图标：用于展示关注按钮图标的 Image <br> 5. 关注成功反馈：用于展示关注成功反馈的 UI |
> 注：关注组件仅能关注地图作者～
