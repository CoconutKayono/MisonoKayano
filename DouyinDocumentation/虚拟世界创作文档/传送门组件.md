# 传送门组件介绍
在抖音虚拟世界SDK中提供了传送门组件（**Douyin World Portal** ）。它的效果是将玩家跨世界传送至指定世界。
> 注：这个传送门是跨世界传送，并不是传送合养精灵的位置。

在 Assets/DouyinVCreateSDK/World/Examples/DouyinWorldPortal 文件夹中提供了传送门组件预制体。你可以将预制体拖入场景中使用。

# 属性
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e7b09373b7414733863f8fe3d5052188~tplv-goo7wpa0wc-image.image" width="300px" /></div>

| 属性 | 说明 |
| --- | --- |
| 脚本文件 | 该组件类型是 **C#组件**， 可直接搜索并添加 **Douyin World Portal** 组件。 |
| 交互触发范围 | * 范围类型： <br>    * 圆形区域：使用圆形区域需要指定范围半径，默认2米。 <br>    * 自定义范围：使用自定义范围需要指定碰撞区域。 <br>  <br>  |
| 传送门配置 | * 世界ID：必须是已发布上线世界的ID。 <br> * 传送门模型：可以用来更换传送门模型。 <br> * 世界名称：可在关联的Text组件上输入世界的名称。 |
该组件效果仅限于在线上世界测试，无法在本地和扫码测试环境下测试。
