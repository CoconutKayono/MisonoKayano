# 拾取组件介绍
在抖音虚拟世界SDK中提供了拾取组件（**DouyinPickUp**）。它的效果是当玩家靠近时，物体边框会高亮显示。玩家点击按钮，就能把物体拿在手上。拿起来后，你可以设置一些操作，比如别人能不能拿走，或者能不能扔掉。
还可以自己加脚本，让物体在被使用后做一些特别的事情，比如触发一个动作或者效果。例如：一个汉堡，玩家拿起来后，可以点击“吃”这个副功能按钮，然后触发”吃“的动作。
在Assets/DouyinVCreateSDK/World/Examples/DouyinPickup 文件夹内有SDK提供的拾取组件预制体，你可以将预制体拖入场景中使用，也可以将组件脚本挂载到自己准备的模型上。

# 属性
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ebd2cdf2653b4d25a93b8b937f40b932~tplv-goo7wpa0wc-image.image" width="300px" /></div>

| **属性** | **说明** |
| --- | --- |
| **脚本文件** | 此组件为Lua组件，需添加 **Douyin Script** 组件后，在脚本文件中添加 **DouyinPickUp** 脚本，挂载后自动挂载同步组件 **Douyin Object Sync**。 |
| **交互触发范围** | **范围类型** <br>  <br> 1. 圆形区域：在物体的中心点生成一个球形的Collider，输入数字即可改变范围大小。 <br> 2. 自定义范围：可拖入自定义的Collider，改变Collider大小可改变交互范围。 <br>  <br> **范围半径**：选择”圆形区域“时显示，以米为单位的半径大小。 <br> **区域**：选择”自定义范围“时显示，可拖入自定义碰撞Collider。 |
| **拾取物基础属性设置** <br>  | **物品持握位置：​**默认右手拾取，合养精灵持握位置在右手挂点位置。 <br> **可被丢弃：​**物体是否可被丢弃。 <br> **丢弃后物品是否销毁：​**物体被丢弃后是否可以要被销毁。 <br> 丢弃后自动销毁时间：物品丢弃后，指定时间（秒）后物品被销毁。 <br> **拾取后可被他人拿走：​**物体被拾取后是否可被他人拿走。 <br> > ⚠️注：想要物品被销毁，需要将物品作为网络对象进行使用，同时需要使用生成网络对象的方式来生成物品，直接摆放到场景中的物品是无法被销毁的。 |
| **拾取按钮设置** | **按钮图标**：推荐使用72*72的贴图，默认使用官方贴图。 <br> **按钮底板**：推荐使用369*90的贴图，默认使用官方贴图。 <br> **按钮文本**：默认为“拾取”。 <br> **文本颜色**：默认为黑色。 |
| **主功能按钮设置** | **显示主交互按钮**：是否启用主功能按钮。 <br> **交互按钮类型：** <br>  <br> 1. 按钮：下方显示按钮逻辑和参数。 <br> 2. 摇杆：下方显示摇杆逻辑和参数。 |
| **主功能按钮设置** | **按钮可交互**：默认为勾选，即按钮交互。 <br> **按钮图标**：推荐使用144*144的贴图。 <br> **显示按钮文本**：是否显示按钮文字。 <br> **按钮文本**：设置文本。 <br> **文本颜色**：设置文本的颜色。 |
| **交互逻辑** | * **脚本：​**将挂载有Douyin Script脚本的 GameObject 拖拽至此进行绑定关联，即可获取物体对象身上的脚本。 <br> * **方法：​**输入绑定关联对象脚本中的方法名，即可在点击按钮时触发该方法。 |
| **副交互按钮设置** | 除了按钮类型默认为按钮，不可设置为摇杆，其他参数与主按钮一致。 |
