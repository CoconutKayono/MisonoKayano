# 🔔 活动规则

1. 本次活动主题为“主题挑战赛”，**仅限新作品参与**
2. ⚠️单个世界仅可使用 1 款 IP，不可以混用或魔改
3. 参与斗罗大陆主题活动的作品中必须要在特定位置（比如：场景还原位置、出生点、终点等）带有“斗罗大陆：魂师对决”的Logo，且场景上需要有斗罗大陆主题元素，详情参见下方
4. 作品在“作品推广期”内不得下线，仅能进行细微调整和bug修复，若出现内容重大调整/下线则视为无效作品
5. **每款作品仅能参与单一作品分类，但可在单作品分类内提交多款作品**
6. 奖励将在活动截止后 30 个工作日下发，激励奖金均为税前标准，税务成本由参赛作者自行承担

> **玩法类作品说明**：作品内有完整的可玩性内容，且玩法逻辑清晰明了。比如：跑酷玩法要有明显的起点，终点，以及各类关卡；密室解密玩法要有解密机关，观察搜索，物品互动等元素；非对称竞技玩法要有分队匹配逻辑，对抗区域，获胜展示等内容
> **景观类作品说明**：作品地图要完整，主题要明确，美术风格整体统一，没有明显的材质渲染问题，有可交互的内容，比如可以坐下的椅子，可以手持的烟花等

以下作品将无法参与活动：

1. **无任何或少量斗罗大陆主题元素/美术风格的作品**，比如：仅使用了几个斗罗大陆元素模型，或者几张斗罗大陆的贴图，甚至仅仅在作品名上带有斗罗大陆字样等
2. 有血腥暴力，涉黄涉政等相关性内容的作品
3. 带有其他产品元素内容的作品
4. 使用商业侵权内容的作品，包括不限于模型，贴图，音效等
