# 🔔 活动规则

1. 本次活动主题为“守望先锋主题创作赛”，**仅限新作品参与**
2. 参与活动的作品中必须要在特定位置（比如：守望先锋场景还原位置、出生点、终点等）带有“守望先锋”Logo，且场景上需要从“漓江塔还原”和“自定义还原”中选择一个，详情参见下方**活动硬性要求**
3. 作品在流量推广时间内不得下线，仅能进行细微调整和bug修复，若出现内容重大调整/下线则视为无效作品
4. **每款作品仅能参与单一作品分类，但可在单作品分类内提交多款作品**
5. **每个赛道每位创作者最多获得 3 份奖励，如有超出将取最高奖励方案**
6. 确认报名请务必填写参赛报名表：[守望先锋创作赛-参赛报名表](https://bytedance.larkoffice.com/share/base/form/shrcnAnXOjsalhWfUAqEzekBUqb)

> **玩法类作品说明**：作品内有完整的可玩性内容，且玩法逻辑清晰明了。比如：跑酷玩法要有明显的起点，终点，以及各类关卡；密室解密玩法要有解密机关，观察搜索，物品互动等元素；非对称竞技玩法要有分队匹配逻辑，对抗区域，获胜展示等内容
> **景观类作品说明**：作品地图要完整，主题要明确，美术风格整体统一，没有明显的材质渲染问题，有可交互的内容，比如可以坐下的椅子，可以手持的烟花等

以下作品将无法参与活动：

1. **无任何或少量守望先锋主题元素/美术风格的作品**，比如：仅使用了几个守望先锋元素模型，或者几张守望先锋的贴图，甚至仅仅在作品名上带有守望先锋字样等
2. 有血腥暴力，涉黄涉政等相关性内容的作品
3. 带有其他游戏元素内容的作品
4. 使用商业侵权内容的作品，包括不限于模型，贴图，音效等

# 💡 活动常见问答

1. **参与了之前活动地图的作品能否参与本次守望先锋主题创作活动？**
   * 参与了之前活动地图的作品不能参与本次活动，两个活动并行，本次挑战赛会以实际报名问准，报名链接[>>](https://bytedance.larkoffice.com/share/base/form/shrcnAnXOjsalhWfUAqEzekBUqb)；
2. **新地图作品可以同时参与2个活动吗？**
   * 新地图作品只能参与「首期创作活动」或「守望先锋挑战赛」之一，不能同时参与2个活动；
3. **如何确定自己的作品符合活动主题？**
   * 若场景元素上符合上述中的要求底线，即符合活动主题；玩法上如果有不确定或者任何疑问可以进入答疑群咨询官方运营；
4. **参选标准是什么意思？**
   * 为避免刷量或低质世界影响比赛公平性，参选标准为++活动奖励入选门槛++，只有达到参选标准的作品才能进入奖励评选名单；
5. **有官方素材可以使用吗？**
   * 有的，目前守望先锋官方素材及预制体将在一周内释出，景观类作者可以参照上述的素材规范标准自行准备模型或贴图，不触及底线的守望先锋素材均可被使用；玩法类作者可以先进行玩法设计与制作，官方素材将会在答疑群打包释出并通知。
