# 合养精灵形象兑换组件介绍
在抖音虚拟世界SDK中提供了合养精灵形象兑换组件（**Douyin Pet Pedestal**）。它的效果是玩家可以在世界内领取到合养精灵形象。
在 Assets/DouyinVCreateSDK/World/Examples/DouyinPetPedestal 文件夹中提供了合养精灵形象兑换组件预制体。你可以将预制体拖入场景中使用。

> ⚠️注：该组件由 **DouyinPetPedestal** 脚本和 **DouyinPetPedestalInteractor 脚本**组成，使用时请注意是否同时添加了上述2个脚本，以及是否绑定了交互逻辑方法。

| 属性名称 | 属性类型 | 说明 |
| --- | --- | --- |
| 合养精灵ID | int | * 需填写已审核收录成功的合养精灵唯一标识ID |
| 精灵模型展示位置 | transform | * 用于精确定位精灵形象在“精灵形象展示组件”上的具体位置与朝向 |

# API
除了使用组件之外，创作者还可以在世界内使用脚本调用以下 API 来完成合养精灵形象的兑换：

* [DouyinOfficialRewardService.IssueReward](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=np5vuxnp)

1. 该接口需要传入兑换的合养精灵形象的奖励标识ID（与组件上的ID不一样），ID获取方法可在飞书答疑群中询问官方运营同学。
2. 该接口可发放非世界作者本人帐号的形象或装扮，具体情况请联系官方运营同学。

# 合养精灵形象创作与兑换
## 合养精灵形象创作
想要使用合养精灵形象兑换组件，需要先制作一个精灵形象，并完成形象的收录。
精灵形象的制作可参阅：[合养精灵创作文档](https://vcreate.douyin.com/tutorial?book=m2fyknwy&doc=ng6bocaz)
## 合养精灵形象兑换
### 兑换方式

* 用户在世界中可通过消耗火星币兑换。
* 用户在世界中可免费获得该形象的30天使用权限。

### 兑换设置

> * 若合养精灵形象需要上架形象商店，请勿勾选 “仅限在世界中领取”

<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/75a9b6d0eb9541598853c31ca5867155~tplv-goo7wpa0wc-image.image" width="1435px" /></div>


1. **「仅在世界中领取」发布选项**
* **默认状态（未启用）**：合养精灵将在精灵商店正常上架，并可在世界中放置，用户需按定价兑换。
* **启用状态**：合养精灵不会在商店中展示，仅能通过世界中设置的精灵形象兑换组件免费兑换。
2. **发布后不可修改**
* 合养精灵一经发布，所有信息即被锁定，无法修改。所有属性与设置可在合养精灵详情页面中查看。

# 使用注意事项

* 上传合养精灵形象的账号需与地图账号一致
* 若合养精灵形象已提交上架商店的审核，在审核未通过前，该组件**无法在世界中正常拉取到该精灵形象的数据**，**也无法点击仅在世界中领取**
* 当发现精灵形象既没有上架形象商店，又无法勾选**「仅在世界中领取」**选项时，可能是因为形象已进入上架形象商店的队列中，需要先下架形象再重新进入Unity中提交审核，并在审核通过后，进入创作中心勾选**「仅在世界中领取」**
