Unity 中的脚本与传统的程序概念不同。在传统程序中，代码在循环中连续运行，直到完成任务。相反，Unity 通过调用在脚本中声明的某些方法来间歇地将控制权交给脚本。方法执行完毕后，控制权将交回 Unity。  
这些方法由 Unity 激活以响应世界中发生的事件，因此称为**Event Function**。  
如同 Unity 的事件函数，Douyin Script 也提供一些事件函数，在某些时刻调用脚本中的函数，函数执行完毕后，控制权将交回 Douyin Script 。  
Unity 使用一种命名方案来标识要对特定事件调用的函数。例如，先前介绍过的 Start 函数（在对象的第一次帧更新之前立即调用）。Douyin Script 也沿用这种方式，只要重写特定命名的函数，即可在事件发生时，执行对应函数。

# Unity 事件函数
对于 Douyin Script 关联的 Lua Script，其运行符合 Unity MonoBehavior 的规则和生命周期。在脚本中可以使用的 Unity MonoBehavior 事件函数列表如下：
| Awake   | 当脚本实例被加载时调用Awake方法。 |
| --- | --- |
| Start   | Start方法在脚本启用后的第一帧，在首次调用任何Update方法之前被调用。 |
| Update   | 如果MonoBehaviour处于启用状态，Update方法会在每一帧被调用。 |
| FixedUpdate   | 用于物理计算的帧率无关的MonoBehaviour.FixedUpdate消息。 |
| LateUpdate   | 如果Behaviour处于启用状态，LateUpdate方法会在每一帧被调用。 |
| OnDisable   | 当Behaviour被禁用时调用此函数。 |
| OnEnable  | 当对象变为启用且激活状态时调用此函数。 |
| OnCollisionEnter   | 当前碰撞体/刚体开始接触另一个刚体/碰撞体时调用OnCollisionEnter。 |
| OnCollisionExit   | 当前碰撞体/刚体停止接触另一个刚体/碰撞体时调用OnCollisionExit。 |
| OnTriggerEnter   | 当游戏对象与另一个游戏对象发生碰撞时，Unity会调用OnTriggerEnter。 |
| OnTriggerExit | 当另一个碰撞体停止接触触发器时调用OnTriggerExit。 |
为了更好地理解以上事件的运行规则，请仔细阅读：[Unity事件函数介绍](https://docs.unity3d.com/2021.3/Documentation/Manual/EventFunctions.html)。  
对于入门创作者而言，只需要关注**初始化事件（Awake、Start）**、**常规更新事件（Update、FixedUpdate、LateUpdate）**、**物理相关事件**即可。
关于Unity MonoBehavior ，可以阅读：[MonoBehavior 生命周期介绍](https://docs.unity3d.com/2021.3/Documentation/Manual/ExecutionOrder.html)

# Douyin Script事件函数
Douyin Script提供了大量的事件函数；可在抖音虚拟世界API参考手册中找到事件函数的完整列表以及详细的用法说明。以下是一些最常见和最重要的事件。
## 玩家事件
当需要处理和玩家相关的逻辑时，需要用到玩家相关事件。比如：当有玩家加入房间时，给他分配一个游戏身份；当玩家离开房间时，清除他的游戏数据；当玩家进入某个区域后，触发一些特殊行为……
| OnPlayerJoined(player) | 当有玩家加入房间时触发， player参数代表加入的玩家对象。 |
| --- | --- |
| OnPlayerLeft(player) | 当有玩家离开房间时触发， player参数代表离开的玩家对象。 |
| OnPlayerRespawn(player) | 当玩家重生时。 |
| OnPlayerTriggerEnter(player) | 当玩家的碰撞胶囊体进入一个触发区域时。 |
| OnPlayerTriggerExit(player) | 当玩家的碰撞胶囊体离开一个触发区域时。   <br> 注意：如果玩家在触发区域内下线，无法收到此事件，需要用OnPlayerLeft来处理相关逻辑。 |
| OnPlayerCollisionEnter(player) | 当玩家的碰撞胶囊体碰到另一个碰撞区域。 |
| OnPlayerCollisionExit(player) | 当玩家的碰撞胶囊体离开另一个碰撞区域。   <br> 注意：如果玩家在触发区域内下线，无法收到此事件，需要用OnPlayerLeft来处理相关逻辑。 |
## 交互事件
当你需要去自定义一些交互后的逻辑时，需要用到交互相关事件。比如：当捡起一个烟花后，烟花开始播放；当把一个炸弹丢到地上，会发生爆炸。
| OnPickup(player, handType, pickUpPoint) | 当某物体被玩家捡起时触发；  player代表操作的玩家，handType代表是左手还是右手，pickUpPoint对应物体上被拾取的点位。 |
| --- | --- |
| OnDrop(player, handType) | 当某物体被玩家丢弃时触发；  player代表操作的玩家，handType代表是左手丢弃还是右手丢弃。 |
## 网络事件
当你开始关注网络对象，需要处理网络对象的初始化，或者主权转移等问题，需要使用网络相关事件。  
网络相关概念详见章节：[多人联网概述](/s196aspp/9wjja85l)。
| OnNetSpawned() | 当网络对象生成后触发，在此函数内，可以处理一些网络初始化相关的逻辑。 |
