很多世界在设计玩法时都有存档点和传送门的设计需求，那么本篇内容将会向大家展示如何快速制作一个针对本地玩家的简易版本的存档点和传送门，大家可以通过学习本篇内容来设计符合自己世界的存档点和传送门功能！
# 步骤1：设计存档点
存档点的功能其实很简单，就是在玩家进入存档点触发区域时，将此时的存档点位置记录下来。

1. 创建一个Cube和一个空物体，将Cube的名字修改为“SavePoint”，将空物体的名字修改为“GameManger”。SavePoint 用来作为存档点，GameManger 作为用来管理存档点数据的实例对象。

注：需要勾选Cube的碰撞组件中的 Is Trigger 属性。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1b8efc6210dd42c293ea96385b966736~tplv-goo7wpa0wc-image.image" width="2559px" /></div>


2. 在 Assets 窗口中新建一个 Lua 脚本，并修改名字为 GameManager，同时打开该脚本，将下面的代码复制到 Game Manager 中。

```Go
local curSavePoint = nil

--记录存档点
function SetSavePoint(point)
    if point == nil then
        return
    end
    curSavePoint = point
end

--获取当前存档点
function GetSavePoint()
    return curSavePoint
end
```


3. 复制完成代码后，记得保存一下脚本，然后回到 Unity 中，给 GameManager 物体添加 Douyin Script 组件，并将 GameManager 脚本挂载到脚本文件上。

<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6f59d1ac778649cfba7b097d9900c85d~tplv-goo7wpa0wc-image.image" width="500px" /></div>


4. 在 Assets 窗口中新建一个 Lua 脚本，并修改名字为 SavePoint，同时打开该脚本，将下面的代码复制到 SavePoint 中。

```Go
---@var gameManager:DouyinScript
---@end

--当玩家进入触发区域时调用触发函数
function OnActorTriggerEnter(actor)
    if actor == nil then
        return
    end
    if actor.isLocal == false then
        return
    end
    if gameManager == nil then
        return
    end
    --调用GameManager的SetSavePoint方法，将当前存档点的位置记录下来
    gameManager.script.SetSavePoint(self.transform.position)
end
```


5. 复制完成代码后，记得保存一下脚本，然后回到 Unity 中，给 SavePoint 物体添加 Douyin Script 组件，并将 SavePoint 脚本挂载到脚本文件上，同时将 GameManager 物体拖拽到 gameManager 属性上。

# 步骤2：设计传送门
传送门的逻辑也很简单，当玩家进入传送门触发区域时，将会检查当前是否有记录过存档点。如果有记录，那么就将玩家传送到存档点位置；如果没有记录，那么就向玩家弹出一个toast提示，告诉玩家还没有保存存档点（或者可以按照你自己的需求来设计）。

1. 在场景中创建一个新的 Cube，调整一下它的大小位置，与存档点有所区分，并修改它的名字为 Portal，同时记得勾选碰撞组件的 Is Trigger 属性。

<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/eddb427dd1ef493fa0e323eb49e7d2ae~tplv-goo7wpa0wc-image.image" width="2560px" /></div>


2. 在 Assets 窗口中新建一个 Lua 脚本，并修改名字为 Portal，同时打开该脚本，将下面的代码复制到 Portal 中。

```Go
---@var gameManager:DouyinScript
---@end

--当玩家进入触发区域时调用触发函数
function OnActorTriggerEnter(actor)
    if actor == nil then
        return
    end
    if actor.isLocal == false then
        return
    end
    if gameManager == nil then
        return
    end

    --调用GameManager的GetSavePoint方法，获取当前记录的存档点
    local pos = gameManager.script.GetSavePoint()
    if pos ~= nil then
        actor:Teleport(pos)
    else
        DouyinUtility.Toast("还没有记录存档点哦～")
    end
end
```


3. 复制完成代码后，记得保存一下脚本，然后回到 Unity 中，给 Portal 物体添加 Douyin Script 组件，并将 Portal 脚本挂载到脚本文件上，同时将 GameManager 物体拖拽到 gameManager 属性上。

# 注意事项

1. 如果想要多个存档点，那么就创建多个存档点物体，然后挂载 SavePoint 脚本即可。
2. 如果想要多个传送门，那么就创建多个传送门物体，然后挂载 Portal 脚本即可。
3. 请务必保证场景中有且只有一个 GameManager 物体对象。

# 扩展思路

1. 可以在存档点记录成功的时候也弹出一个toast提示，或者播放一段音频/特效。
2. 可以给 GameManager 增加一些判断（比如：给每个存档点一个ID），来让传送门只传送最新的存档点。
