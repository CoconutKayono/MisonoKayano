# 聊天气泡组件介绍
在抖音虚拟世界SDK中提供了聊天气泡对话组件（**DouyinNameBoard**）。它的效果是在世界内的NPC角色或者某个物体上方展示对话气泡框。
在Assets/DouyinVCreateSDK/World/Examples/DouyinNameBoard 文件夹中提供了聊天气泡组件预制体。你可以将预制体拖入场景中使用。
# 属性

| 属性 | 说明 |
| --- | --- |
| **脚本文件** | 此组件为Lua组件，需添加 **Douyin Script** 组件后，在脚本文件中添加 **DouyinNameBoard** 脚本。 |
| **名字版设置** | 1. **绑定对象（挂点）**：将想要展示聊天气泡的物体拖入即可。 <br> 2. **位置（offset）**：气泡展示的位置。 <br> 3. **名字Text组件**：用于展示名称的Text组件。 <br> 4. **名称**：输入展示气泡的对象的名字，比如NPC的名字。 <br>  <br>  |
| **头顶气泡设置** | 1. **停留时长**： <br>    1. 设置当前聊天气泡的停留时长 <br>    2. 以秒为单位，到达该时长后，气泡消失 <br>    3. 默认值为5 <br>    4. 该值为负数时，运行时会重置为默认值 <br> 2. **最大显示数量**：最多可展示的对话条数 <br> 3. **气泡模板**：默认，可自行参考默认预制体来定制自己的气泡 <br> 4. **气泡内容配置**：用于配置当前聊天气泡内的内容展示，支持富文本。 |
