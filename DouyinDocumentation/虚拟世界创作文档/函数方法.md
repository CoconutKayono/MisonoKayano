除了调用 API 来完成逻辑编写，你也可以自定义函数方法来完成逻辑编写。 
函数方法是一些可以被反复执行和调用的代码块，常用作完成一个固定的逻辑，或作为 **回调**（Callbacks）使用。 
# 基本形式
Douyin Script 中定义函数方法的形式与Lua基础语法一致。
```Go
local function 函数名(参数1,参数2，参数3)
    //todo
    return 返回值
end
```

使用函数方法时，只需要书写函数名并传入相关参数（若有）即可。若有返回值，只需声明一个变量来存储返回值，或者直接在需要使用返回值的地方调用方法。
比如：
```Go
-- This function will add two parameters up and return the result.
local function addNumbers(num1, num2)
        local result = num1 + num2
        return result
end

print(addNumbers(1, 2)) -- It prints 3. You can call this function directly on where the return value is needed.
local seven = addNumbers(3, 4)
print(seven) -- It prints 7. You can also store the return value in a variable and use it later.
```

# local 关键词
如果一个方法或变量被定义为 local，代表它只对本脚本文件可用，且只能在后续的代码中被调用；也就是说，一个写在文件底部的 local 方法，无法在文件的开头被调用，如果调用将会出错。 
如果一个方法或变量没有被定义为 local，代表它可以被所有脚本文件调用；而且在同一个文件中，不受书写位置先后的影响，可以在任意位置被调用。 
> **注：如果函数方法使用了local来修饰，那么其他脚本将无法调用该方法**

# 调用函数方法
Lua语法中规定函数方法是归属于某个类（Class）或者表（Table）的。它的第一个参数通常是其归属的本体（self）。 
当你要要调用某个脚本的函数方法时，推荐使用冒号（:），这样使用起来更简便，相当于自动将第一个参数（self）传入方法。 
当然如果你更习惯使用点（.）来调用函数方法也可以，但这样需要将 self 参数传递也写出来。相当于冒号（:）是点（.）的一种简写。
当在Douyin Script脚本中调用Unity API或者SDK内置的C#组件时，如果调用的方法是**静态方法**，那么需要使用点（.）来直接调用；如果调用的是成员函数，则需要使用冒号（:）来调用。
比如：
```Go
local localPlayer = DouyinPlayerService.GetLocalPlayer() -- Static method； use a dot (.) to call.
if localPlayer ~= nil then
    localPlayer:Jump() -- Use a colon (:) to call. Here, Jump is the method of the localPlayer.
    localPlayer.Jump(localPlayer) -- Use a dot (.) to call.
    end)
end
```

* 如果你要调用一个静态方法，使用点（.）
* 如果你要调用一个属于某个对象的非静态方法，使用冒号（:）
* 在脚本内，调用所有 DouyinScript 的方法，需要写作：self:FunctionName() 

在脚本中 self 可以用来表示脚本挂载物体的本身，可以用self来调用物体本身的一些属性，比如：self.gameObject

# 回调（callbacks）
Callbacks，即回调，是在其他方法返回时执行的方法。 
一些常用的方法会用用到回调，相当于将方法作为另一个方法的参数使用，使用方法如下： 
```Go
-- Delay 1 second before outputting Hello World
setTimeout(function()
    print("Hello World")
  end, 1000)
```
