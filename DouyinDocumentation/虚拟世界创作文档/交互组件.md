# 交互组件介绍
在抖音虚拟世界SDK中提供了一个交互组件（**DouyinInteractor**），你可以使用该组件来实现玩家与世界中的物体互动的效果。比如“玩家按下开关，面前的门就会自动打开”，或者“走进灯的感应区域，灯就亮起来”。
# **属性**

| **属性名称** | **属性说明** |
| --- | --- |
| 脚本文件  | 此组件为Lua组件，需先添加 **Douyin Script** 组件后，在脚本文件中添加 **DouyinInteractor** 脚本。  |
| 交互触发范围  | **范围类型** <br>  <br> 1. **圆形区域**：在物体的中心点生成一个球形的Collider，输入数字即可改变范围大小。  <br> 2. **自定义范围**：可自定义碰撞体（Collider），改变碰撞体大小可改变交互范围。  <br>  <br> **范围半径**：以米为单位的半径大小。  <br> **区域**：可拖入自定义碰撞体（Collider）。  |
| 交互按钮设置  | **按钮图标**：按钮显示时的图标。  <br> **按钮底板**：按钮图标的背景图。  <br> **按钮文本**：输入的文字会在可交互按钮上显示。  <br> **文本颜色**：按钮上显示的文本的颜色。 |
| 交互逻辑  | **脚本：​**将含有Douyin Script脚本的GameObject（交互对象）拖拽进此，即可能对此对象进行交互。  <br> **方法：​**可将游戏对象挂载的脚本里的方法名输入，点击交互按钮时即可触发对应的方法。  |
