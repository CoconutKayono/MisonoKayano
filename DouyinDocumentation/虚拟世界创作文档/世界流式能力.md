## 流式能力简介
在世界中开启的流式能力，允许动态加载和卸载场景中的3D 内容和相关实例。这可以通过以下几种方式改善整体玩家体验：

* **世界获得更短的加载时间：​**玩家可以在世界的一个部分开始游戏，而其他部分在进入世界后再加载。
* **内存效率：​**由于内容是动态流入和流出，用户可以在内存较少的设备上体验世界。
* **模型细节层次：​**配置时，远处的模型即使没有完整在客户端加载但仍然可见，使世界获得上述优化而不会完全牺牲视觉效果。

## 技术实现介绍
## 基础介绍
**场景流式加卸载（Streaming Load）​**让世界场景按区块切分、按角色的视点距离对资源做加载、卸载、分级，并提供运行时只读查询与变化通知接口，供 gameplay、UI 与调试工具按需获取加载状态。本文是该功能的对外开发者文档，覆盖场景侧的配置组件、运行时 API、以及推荐的接入方式。
**功能概览**

* 把整张世界地图切分为若干区域，按角色的视点距离分为 `Release / Low / Medium / High` 四个状态进行加卸载。
* 区域加载/卸载、actor 跨区域、加载完成等事件，由运行时统一驱动；调用方只需要订阅事件并在需要时按区域查询完整快照 。
* 加载距离、是否启用低模、是否启用流式总开关等参数在场景的 `DouyinWorldRoot` 上配置，构建期固化到产物，运行时只读，**无法在运行时动态修改**。

**如何接入能力？**

1. 在场景里挂好 **`DouyinWorldRoot`** 并勾选 **`启用流式加载`**，按需调整加载距离与低模参数。
2. 对于不能被流式拆分或必须常驻的物体，挂 **`DouyinHLODNodeSettings`** 并按需勾选 **`Atomic`** / **`Permanent`**。
3. 在 gameplay/UI 代码里通过 **`DouyinStreamingService`** 订阅区域和 actor 事件，配合 `TryGet*` 系列接口拿到当前状态。

**文档目标**

* 说明场景流式加卸载功能在**场景配置**与**运行时接口**两侧的对外接入方式。
* 明确每个能力的语义边界，避免把内部实现细节误用成业务语义。
* 提供推荐调用方式和常见排查路径。

### Streaming Area（流式加载区域）
流式系统把空间划分为离散区域，使用 `DouyinStreamingGridCoord` 标识：

* `Level`
* `X`
* `Y`
* `Z`

### Area State（区域状态）
`DouyinStreamingAreaState` 表示区域当前已经生效的状态：

* `Release`
* `Low`
* `Medium`
* `High`

这不是预测态，也不是“未来将要切到的状态”。
### Load Done （是否加载完成）
`DouyinStreamingAreaInfo` 里有两个 load done 概念：

* `IsLoadDoneSelf`：仅表示当前节点自身是否稳定，并且当前层级资源已齐。
* `IsLoadDone`：更强语义。在 `High` 状态下还要求子节点也满足整体 load done。

### Streaming View
`DouyinStreamingViewInfo` 表示当前驱动 streaming 的视角快照：

* `ActiveCamera`
* `CameraPosition`
* `CameraRotation`
* `IsStreamingEnabled`

`IsStreamingEnabled` 直接来自当前 active HLOD camera recognizer。
## 流式加卸载接入说明
本节面向需要在世界场景中接入流式加卸载能力的开发者，介绍构建期需要在场景里配置的两类内容：

* 每个世界场景必须挂一个 `DouyinWorldRoot`，用于打开流式加卸载并设置加载距离与分层参数。
* 在需要精细控制加载行为的物体上，可选地挂 `DouyinHLODNodeSettings` 组件。

合理配置好这两块后，运行时就能通过 `DouyinStreamingService` 提供的接口查询区域状态、监听变化并对接 gameplay / UI / 调试逻辑（详见后文「API 清单」）。
### DouyinWorldRoot：流式加卸载参数
`DouyinWorldRoot` 是世界场景的根组件，每个场景只挂一份。是否启用流式加卸载，以及加载距离、是否生成低模等行为，全部由它 Inspector 上的「**流式加载**」分组决定，所有字段仅在构建期生效。下图为「流式加载」分组在 Unity Inspector 中的实际样貌，下方表格按截图中字段从上到下的顺序逐项说明，接入时按下表对照配置即可。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f2e1002e690f4d64a49cf0fbbc1d947a~tplv-goo7wpa0wc-image.image" width="903px" /></div>

| Inspector 显示名 | 类型 | 说明 |
| --- | --- | --- |
| `启用流式加载` | bool | 流式加卸载总开关。**未勾选时本分组其余字段不生效**，世界会以传统整体加载方式发布；勾选后才会进入流式加卸载链路并生成对应产物。 |
| `最小地块尺寸` | float | 空间划分的最小地块的边长，决定运行时区域网格（`DouyinStreamingGridCoord`）的基本尺度。值越小划分越细、加卸载粒度越精细，但运行时带来的收益也越小。 |
| `高模加载距离` | float | `High`（高模）状态加载半径。区域到视点距离小于该值时进入 `DouyinStreamingAreaState.High`，使用高精度模型与材质。值最小是地块尺寸的2倍。 |
| `中模加载距离` | float | `Medium`（中模）状态加载半径，应大于「高模加载距离」。区域到视点距离介于高/中之间时进入 `Medium`。 |
| `启用低模` | bool | 是否启用 `Low`（低模）层。**未勾选时下面两项不生效**，区域不会进入 `Low` 状态，只在 `High` / `Medium` / `Release` 之间切换。 |
| `低模加载距离` | float | `Low` 状态加载半径，仅在「启用低模」勾选时生效，应大于「中模加载距离」。 |
| `低模大物件阈值` | float | 生成低模时纳入的最小物件尺寸阈值。小于该值的物件不会出现在低模产物中，用于在远距离剔除碎小物体、控制低模复杂度。 |
上述参数仅在构建期生效。运行时通过 `DouyinStreamingService.TryGetLoadingDistanceSettings` 拿到的是构建产物里固化的快照（`HighRange / MediumRange / LowRange / EnableLowModel`），不能在运行时动态修改。

### DouyinHLODNodeSettings：对象加载优先级设置
`DouyinHLODNodeSettings`添加到 GameObject 上后在 Unity Inspector 中显示为「**Node Settings**」。它会影响该节点以及该节点下的对象在流式加载中的策略，下图为该组件的 Inspector 样貌，仅有两个勾选项，含义见下表。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/42da9169e1694809a3b68a68a37c91d4~tplv-goo7wpa0wc-image.image" width="900px" /></div>


* 添加方式：在目标 GameObject 上 `Add Component` → `Douyin/HLOD/Node Settings`，每个 GameObject 最多挂一份；两个字段默认均未勾选——不勾选即默认走流式规则。

#### 字段说明
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `Permanent` | bool | **永久保留**。命中后整棵子树从流式加卸载体系中排除，永远跟随场景常驻，不参与高低模拆分、合批、碰撞抽离等任何 HLOD 处理。 |
| `Atomic` | bool | **不可拆分独立单元根**。命中后整个子树作为一个整体归属（要么整体静态、要么整体动态），不会被子节点的 `Atomic` / `static` 等属性进一步拆开。仅在 `Permanent = false` 时可设置。 |
#### 使用约束
Inspector 上对父子层级做了强约束：

* 父链上已有 `Permanent` 节点时，**子节点不允许取消** `Permanent`。
* 子树中已有非 `Permanent` 节点时，**当前节点不允许新开启** `Permanent`。
* 子树中已有 `Permanent` 节点时，**当前节点不允许开启** `Atomic`。
* 同一节点上 `Permanent` 永远优先于 `Atomic`；`Permanent = true` 时 `Atomic` 字段不再可见。

### 动静态根归属规则
构建期会自动把场景里的物体分成**静态根**和**动态根**两类，再按区域打包参与流式加卸载。多数情况下使用方不需要关心细节，按以下规则配置即可获得预期表现。
#### 优先级判定
按优先级**从高到低**判定，命中即停止：

1. **`Permanent = true`**：整棵子树排除，不参与流式加卸载。
2. **`Atomic = true`**（`Permanent = false`）：整个 Atomic 子树作为一个整体归属。
   * 子树内含粒子 `Renderer`、含忽略标记，或处于 ignore 父链下：整体归**动态**。
   * 否则按 Atomic 节点自身 `isStatic` 决定；未勾 `static` 时归**动态**。
3. **普通节点**：
   * 处于 ignore 子树：当前节点及子树按**动态**处理。
   * 自身挂粒子 `Renderer`：按**动态**根处理。
   * 自身勾选 `static`：按**静态**根处理。
   * 默认按**动态**处理。

#### 推荐配置

* 大量重复且远距离观察的环境物件（建筑、地形、装饰等）：勾 `static`，参与流式加卸载与高低模合批，是收益最大的部分。
* 角色出生点、UI 锚点、剧情触发器、必须常驻的逻辑节点：挂 `DouyinHLODNodeSettings` 并勾 `Permanent`，避免被卸载。
* 不能拆开的预制（载具、机关、复合特效等）：在预制根挂 `DouyinHLODNodeSettings` 并勾 `Atomic`，子树整体归属。
* 粒子特效：默认会被识别为动态，无需手动配置；如需常驻请使用 `Permanent`。

**碰撞体与 inactive 节点**：静态碰撞体会在构建期被抽离到独立的静态碰撞树；动态与 `Permanent` 子树下的碰撞体会跟随原物体保留。inactive 节点仍参与归属判定与层级恢复，不影响运行时行为。

## API 清单
### 变化通知
Actor 区域变化
```C#
public static void RegisterActorAreaChangedListener(
    DouyinActor actor,
    DouyinStreamingService.ActorAreaChangedHandler handler);

public static void UnregisterActorAreaChangedListener(
    DouyinActor actor,
    DouyinStreamingService.ActorAreaChangedHandler handler);
```

```C#
public struct DouyinActorAreaChangedInfo
{
    public readonly DouyinActor DouyinActor;
    public readonly Bounds WorldBounds;
    public readonly DouyinStreamingGridCoord OldArea;
    public readonly DouyinStreamingGridCoord NewArea;
}
```

区域状态变化
```C#
public static void RegisterAreaStateChangedListener(
    DouyinStreamingService.AreaStateChangedHandler handler);

public static void UnregisterAreaStateChangedListener(
    DouyinStreamingService.AreaStateChangedHandler handler);
```

```C#
public struct DouyinStreamingAreaStateChangedInfo
{
    public readonly DouyinStreamingGridCoord Area;
    public readonly DouyinStreamingAreaState OldState;
    public readonly DouyinStreamingAreaState NewState;
}
```

注意
区域状态变化事件不携带 `WorldBounds`。如果需要几何信息，请额外调用 `TryGetAreaWorldBounds` 或 `TryGetAreaInfo`。
### 区域查询
查询指定区域状态
```C#
public static bool TryGetAreaState(
    DouyinStreamingGridCoord area,
    out DouyinStreamingAreaState state);
```

查询指定区域 bounds
```C#
public static bool TryGetAreaWorldBounds(
    DouyinStreamingGridCoord area,
    out Bounds worldBounds);
```

查询指定区域完整信息
```C#
public static bool TryGetAreaInfo(
    DouyinStreamingGridCoord area,
    out DouyinStreamingAreaInfo info);
```

```C#
public struct DouyinStreamingAreaInfo
{
    public readonly DouyinStreamingGridCoord Area;
    public readonly Bounds WorldBounds;
    public readonly DouyinStreamingAreaState State;
    public readonly bool IsLoadDone;
    public readonly bool IsLoadDoneSelf;
}
```

### 位置查询
世界坐标映射到区域
```C#
public static bool TryGetAreaAtPosition(
    Vector3 worldPosition,
    out DouyinStreamingGridCoord area);
```

世界坐标直接查询区域完整信息
```C#
public static bool TryGetAreaInfoAtPosition(
    Vector3 worldPosition,
    out DouyinStreamingAreaInfo info);
```

### Actor 查询
查询 Actor 当前区域
```C#
public static bool TryGetActorArea(
    DouyinActor actor,
    out DouyinStreamingGridCoord area);
```

查询 Actor 当前区域完整信息
```C#
public static bool TryGetActorAreaInfo(
    DouyinActor actor,
    out DouyinActorAreaInfo info);
```

```C#
public struct DouyinActorAreaInfo
{
    public readonly DouyinActor DouyinActor;
    public readonly Bounds WorldBounds;
    public readonly DouyinStreamingGridCoord Area;
}
```

### 批量区域查询
获取当前已加载区域
```C#
public static void GetLoadedAreas(List<DouyinStreamingAreaInfo> results);
```


* 只追加当前非 `Release` 状态区域。
* 不会自动 `Clear(results)`。

获取与指定 bounds 相交的区域
```C#
public static void GetAreasInBounds(
    Bounds worldBounds,
    List<DouyinStreamingAreaInfo> results);
```


* 返回与传入 `worldBounds` 相交的区域。
* 不会自动 `Clear(results)`。

## 推荐调用方式
### 只想知道一个区域现在是什么状态
```C#
DouyinStreamingService.TryGetAreaState(area, out var state);
```

### 想同时拿状态、bounds 和 load done
```C#
DouyinStreamingService.TryGetAreaInfo(area, out var info);
```

### 手里只有世界坐标
```C#
DouyinStreamingService.TryGetAreaInfoAtPosition(worldPosition, out var info);
```

### 想知道当前有哪些区域已经被拉起
```C#
results.Clear();
DouyinStreamingService.GetLoadedAreas(results);
```

### 想排查为什么某个位置没有触发正确加载
```C#
DouyinStreamingService.TryGetStreamingViewInfo(out var viewInfo);
DouyinStreamingService.TryGetLoadingDistanceSettings(out var settings);
DouyinStreamingService.TryGetAreaInfoAtPosition(worldPosition, out var areaInfo);
```

## 语义边界

* `State` 是当前已经生效的状态，不是预测态。
* `IsLoadDoneSelf` 只看节点自身，`IsLoadDone` 是更强的整体完成语义。
* 区域状态变化事件只表达状态变化本身，不承担 bounds 传递职责。
* `GetLoadedAreas` 和 `GetAreasInBounds` 都是 append 语义，调用方自己清空容器。

## 常见排查
### 没有任何区域在加载 
```C#
if (DouyinStreamingService.TryGetStreamingViewInfo(out var viewInfo))
{
    Debug.Log($"camera={viewInfo.ActiveCamera}, enabled={viewInfo.IsStreamingEnabled}, pos={viewInfo.CameraPosition}");
}
```

重点看：

* 当前是否存在 active camera。
* `IsStreamingEnabled` 是否为 `true`。
* 相机位置是否停留在异常初始位姿。

### 某个区域状态没有按预期变化
```C#
DouyinStreamingService.TryGetAreaInfoAtPosition(worldPosition, out var areaInfo);
DouyinStreamingService.TryGetStreamingViewInfo(out var viewInfo);
DouyinStreamingService.TryGetLoadingDistanceSettings(out var settings);
```

### 为什么事件触发后还要再查一次信息
因为事件负责描述“发生了什么变化”，查询接口负责给出“当前完整快照”，这是故意拆开的职责设计。
## 当前不提供的能力

* 强制加载指定区域。
* 强制卸载指定区域。
* 直接设置区域状态。
* 对外暴露内部 HLOD 实现细节。
* 由业务在运行时直接修改场景流式加卸载内部的相机视角识别器开关。
