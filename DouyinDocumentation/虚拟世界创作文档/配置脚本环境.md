抖音虚拟世界SDK基于Unity引擎运行，开发者可通过编写Lua脚本构建丰富有趣的交互功能。借助Lua脚本，开发者能够打造个性化虚拟世界，无论是派对跑酷类场景，还是剧情解谜类玩法，都能实现多样化的交互体验。
为方便开发者随时更新和上传自己创建的虚拟世界，在开发过程中，所有功能逻辑必须使用Lua脚本来编写，而非C#脚本。
当前，该SDK支持Lua 5.3版本。Lua 5.3具有运行速度快、安全性高且易于使用的特点，开发者可运用其语法进行脚本编写。此版本的Lua语言为开发者提供了稳定且高效的开发环境，有助于开发者更便捷地实现各种创意和功能。
使用抖音虚拟世界SDK，开发者能够充分发挥Lua脚本的优势，创建出独具特色的虚拟世界，满足不同用户群体的需求。无论是对于新手开发者还是有经验的专业人士，该SDK都提供了一个强大且友好的开发平台，助力开发者实现自己的创意和想法。 
# 下载 VS Code

VSCode的下载地址：[https://code.visualstudio.com/](https://code.visualstudio.com/)

# 配置脚本环境
在Unity中选择任意的Lua脚本文件，或在Assets目录下按照 **Create->Douyin->Lua script** 创建一个Lua脚本，并使用VS Code打开它。
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/96ebe0e6713d40b18356b355a8454810~tplv-goo7wpa0wc-image.image)

2. 在VScode界面的右下角找到 Select Language Mode，选择Lua语言，即有Lua语言的代码高亮。 

![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/39d67924d7cc4c0e8587869c60b23eed~tplv-goo7wpa0wc-image.image)

3. 每次写完代码，记得随手CTRL+S保存，否则Unity无法读取你最新写的代码。 

# 断点调试插件（Windows系统）

1. 安装插件 

在VSCode的扩展商店中搜索“**Lua Debugger**” 并安装插件。 
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f63229e940614ac88c53e0cc6b6553ea~tplv-goo7wpa0wc-image.image)

2. 设置工程目录 

在VSCode中点击File-Open Folder，打开Unity项目工程的根目录。例如你将工程目录放在 D:/Project/MYWorld/下，那么用VSCode打开“MYWorld”目录。 

3. 配置调试 
* 在VSCode中点击打开调试面板，点击 “**create a launch.json**”，并选择 **** “**Lua Debugger**”。 

![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/963fabf28c6945adb6b0f3cf3de2f326~tplv-goo7wpa0wc-image.image)

* 此时会创建一个启动描述文件，删除另外两个启动项，只保留名为“**wait**”的启动项。 

![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cce7f6b182a64e4292c698b5433308bd~tplv-goo7wpa0wc-image.image)

4. 开始调试 

在VSCode中按F5启动调试，会出现如下提示表示等待模拟器链接。 
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/28d73a31440d4b86a8aa222cb5a336aa~tplv-goo7wpa0wc-image.image)

5. 设置断点 
* 打开工程目录下被执行的Lua代码， 点击行号设置断点。 

![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f9ea4b8e45b84542a24f936349ff0dba~tplv-goo7wpa0wc-image.image)

* 如果这里设置不上断点，那么在VSCode设置中搜索“**allowBreakpointsEverywhere**” 字段，并将它改成true。具体方法为快捷键“Ctrl+Shift+P” 打开命令面板，输入"**Setting**" ,并选择"**Open Workspace Settings**"。 

![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dd8a25da668b46d68dfec8f9d6c376fa~tplv-goo7wpa0wc-image.image)

* 断点设置好以后在UnityEditor 中启动模拟器，查看断点是否命中。
