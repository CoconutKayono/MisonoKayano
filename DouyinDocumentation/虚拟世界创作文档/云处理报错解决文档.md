# 概述
世界制作完成后，需要将世界进行上传到创作者后台以进行扫码测试、审核、发布等后续操作。在世界上传过程中，会对世界的资源格式、规范进行统一的云处理检查，该文档提供了云处理预检查的工具说明和一些常见的云处理报错的解决方案。
# 检查工具
**为了减少云处理失败情况，强烈建议在上传世界前，使用该工具对世界进行云处理预检查。**

为了方便创作者自查云处理报错问题，在真正的云处理报错检查之前，SDK新增了在本地资源检查工具，会前置对当前世界的资源格式进行**部分检查。​**检查完成后，会给出预检查结果。检查结果中会出现错误码，错误码对应具体的错误信息，可根据错误信息进行错误的修复。
**工具入口**：

1. 点击抖音虚拟创作SDK - 工具箱 - 云处理预检查工具

![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b668c1a86ad04167873cac1811a3a0cd~tplv-goo7wpa0wc-image.image)

2. 首次进入会立即进行一次检查，进入面板后，可以点击右下角 - 运行检查再次进行检查

![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6d35129287604f40969706337e18d0fe~tplv-goo7wpa0wc-image.image)

3. 等待弹窗提示出现后，点击OK，即可开始检查

**检查结果**：

1. 错误码：当前报错的错误编码，每条错误码对应一个具体大类下的错误信息
2. 报错内容：原始的报错信息
3. 解决建议：针对错误码的具体解决建议，解决方案持续收集补全中
4. 查找：方便快速定位出问题的资源文件
