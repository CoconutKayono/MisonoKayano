# 网络同步组件介绍
抖音虚拟世界SDK提供了基础的网络同步组件（**Douyin Object Sync**），创作者可以使用该组件让游戏对象实现基础的同步效果。
网络同步组件用于在网络环境中同步游戏对象的状态，确保世界内玩家看到的游戏对象的状态是一致的。例如玩家拿起一个物品，其他玩家也要看到物品被拿起。 
当游戏对象需要被同步时，可以挂载此组件，此游戏对象会变成网络对象。默认同步 Transform，若此物体同时挂载了 Rigidbody，则同步刚体的 Postion 和 Rotation，所有人可同步获取到此物体的位置和状态信息。

# 注意事项
当对象重生后，会将对象传送回初始位置和方向；如果是角色对象，则速度会被设为 0，并以下参数重置并自动同步： 
如未挂载刚体： 
 transform.position 设置为初始位置。 
 transform.rotation 设置为初始角度。 
如挂载刚体： 
 rigidbody.velocity 设置为 0。 
 rigidbody.angularVelocity设置成 0。 
 rigidbody.position 设置为初始位置。 
 rigidbody.rotation 设置为初始角度。
