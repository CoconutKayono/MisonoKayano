想要在世界中实现丰富的交互效果，肯定离不开编写 Lua 脚本。本篇内容将会向各位创作者介绍如何通过编写 Lua 脚本来实现一个可以打开和关闭的灯。
在开始之前，请务必已经确定下载了最新版本的 [Douyin world SDK ](https://vcreate.douyin.com/tutorial?book=s196aspp&doc=3505dbut)和创建了URP项目，并将SDK导入至该项目内。

1. 进入场景，并在 Hierarchy 面板上点击鼠标右键，通过 Light-> Point Light 创建一个点光源。

Tips：一个场景最多可添加 8 个动态光源，否则可能出现性能问题，导致上传失败。请谨慎使用光源。更多信息请参阅[资源规范](/s196aspp/ok71g68d)。

# 步骤2：创建灯的开关对象
在场景中创建一个Cube，作为灯的开关物体。让玩家通过与它进行交互来控制灯的打开与关闭。
为了便于记忆，可以将Cube的名字修改为 Switch。

# 步骤3：将交互组件添加到开关对象上
为了让 Switch 对象能够与玩家进行交互，需要为它添加一个交互组件。抖音虚拟世界SDK提供了[交互组件](/s196aspp/n6gft8af)，可以让玩家通过触碰、点击按钮的方式与物体进行交互。
使用该组件非常简单，先在 Switch 对象上添加 Douyin Script 组件，该组件是用于运行 Lua 脚本的容器。
注：更多关于 Douyin Script 组件的内容请参阅[脚本 Script 介绍](/s196aspp/kj1za7v1)。

然后，在 Douyin Script 组件的脚本文件属性中搜索 **DouyinInteractor** 组件，并添加。
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/98d35b83b40342ffa2553d2fd6510d1c~tplv-goo7wpa0wc-image.image" width="300px" /></div>

这里，我们将交互组件中的范围半径调整为2，按钮文本修改为“开关灯”，更多属性含义请参阅[交互组件](/s196aspp/n6gft8af)。
# 步骤4：编写控制灯开关的Lua脚本
现在，虽然可以和 Switch 对象进行交互，但其实还没有触发交互逻辑，需要我们编写 Lua 代码来实现控制打开或关闭灯的效果。
为了能够编写Lua代码，你需要提前安装好脚本IDE，这里我们推荐使用 VS Code，你可参阅[配置脚本环境](/s196aspp/jadih6ql)来安装IDE。

在 Unity 的 Assets 窗口里，点击鼠标右键，选择 Create->Douyin->Lua Script，即可创建一个Lua 脚本。
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/800d3f1c3c564c07beb824c1660c32f4~tplv-goo7wpa0wc-image.image)
可以根据要实现的逻辑来修改脚本的名字，比如这里我们将脚本的名字修改为“SwitchLight”，来表示它内部的逻辑是用来控制灯开关的。
双击脚本，即可打开该脚本，然后将下面的代码粘贴复制到脚本中。
```Go
---@var light:UnityEngine.GameObject
---@end

function SwitchLight()
    light:SetActive(not(light.activeSelf))
end
```

这段代码的含义如下：

* 定义了一个 UnityEngine.GameObject 类型的变量 light。
* 编写了一个切换 light 对象激活状态的函数，函数名叫 SwitchLight。

**复制完成后，记得 ctrl/command + s 保存一下代码～**
# 步骤5：绑定交互逻辑
现在，我们已经准备好了交互逻辑代码，只需要在玩家与 Switch 对象交互时，执行我们编写的 SwitchLight 函数即可。
回到 Unity 中，创建一个空物体用于挂载 SwitchLight 脚本，并将点光源拖拽至 light 变量上。
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dabd1b9002364fbdb7539d1e562e6ab7~tplv-goo7wpa0wc-image.image)
最后，也是最关键的一步，我们需要在交互组件上新增一个交互逻辑事件，并将 Switch 对象拖拽到事件的脚本属性上，然后输入我们要调用的函数名 SwitchLight。
