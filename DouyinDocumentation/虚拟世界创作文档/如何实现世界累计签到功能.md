# 实现累计签到功能
> 注：下述讲解介绍中仅包含主要的功能逻辑，部分细节可下载案例后在脚本中查看。

## 搭建签到界面框架
打开 Unity，创建一个 Canvas，然后在该 Canvas 下创建一个按钮（Button）和一个滑动面板（Scroll），然后创建一个签到项（至少要包括一个签到按钮和一个签到完成的image），用于展示每个签到信息。
可以参考教程工程的SignTest场景中的签到界面。

## 签到界面数据初始化
首先，创建一个DouyinScript，并重命名为 SignManager。
双击打开脚本，在脚本中需要定义如下几个变量：

* totalDays：累计签到的天数
* item：每个签到元素
* itemParent：滑动面板上的签到元素的父节点
* signBtn：主界面上的签到入口按钮
* closeBtn：签到界面上的关闭按钮
* signPanel：签到界面
* isInit：本次进入世界是否第一次打开签到面板
* signInfos：缓存签到信息

在 Start 函数中绑定 signBtn 和 closeBtn 这2个按钮的点击事件。分别是打开 signPanel和关闭signPanel。
其中，打开signPanel的时候，是通过 OpenSignPanel 函数来进行的。
```Lua
function Start()
    signBtn.onClick:AddListener(OpenSignPanel)
    closeBtn.onClick:AddListener(function ()
        if signPanel ~= nil then
            signPanel:SetActive(false)
        end
    end)
    --默认关闭signPanel
    signPanel:SetActive(false)
end
```


新建一个 InitSignPanel 函数 和 UpdateUIPanel 函数，InitSignPanel 函数的作用是：当玩家进入世界后，如果是第一次打开签到面板，将会调用该函数来获取数据存储里的签到信息，并根据签到信息调用 UpdateUIPanel 函数刷新签到面板。
```Lua
--本次进入世界，第一次打开签到界面
function InitSignPanel()
    if curPlayer == nil then
        return
    end
    --根据playerOpenID来调用数据存储，获得签到信息
    DATASTORE(function ()
        local ok,store = DouyinDataService.GetDataStore("World","PlayerInfos"..curPlayer.playerOpenID)
        if ok ~= 0 then
            print('Load  Failed:' .. ok .. tostring(store))
            return
        end

        local ok,data = store:GetData('TOTAL_SIGN_DAYS')
        if ok ~= 0 then
            --初始化面板
            print('Get data failed!, code:' .. ok .. ' error_msg:' .. data)
            UpdateUIPanel(signInfos)
            return
        end
        --签到信息按照表存入，但获取时拿到的是字符串，需要通过json反序列化将字符串转成table
        signInfos = dkjson.decode(data)
        --根据获取到的签到信息表的长度来判断是否已经全部签到完了，如果已经完成全部签到，那就初始化面板，重新开启签到
        if #signInfos >= totalDays then
            print("已经签到完了，重新开启新一轮的签到～")
            local finalData = signInfos[#signInfos]
            local curTime = GetLocalTime()
            if finalData.year < curTime.year then
                signInfos = {}
            elseif finalData.month < curTime.month then
                signInfos = {}
            elseif finalData.day < curTime.day then
                signInfos = {}
            end 
        end
        -- 刷新签到面板
        UpdateUIPanel(signInfos) 
        --标记完成数据初始化
        isInit = true
    end)
end
```


在 OpenSignPanel 函数中，根据 isInit 这个布尔值来判断是否初始化了数据，如果已经初始化了，那么就使用缓存的 signInfos 来刷新签到面板，否则就获取数据存储里的签到信息；这是为了让避免玩家反复打开签到界面，反复加载数据存储，因数据延迟导致界面卡顿或者显示错误等问题。
```Lua
--打开签到界面，如果本地进入世界已经打开过，那么使用缓存数据来打开界面
function OpenSignPanel()
    if not isInit then
        InitSignPanel()
        return
    end
    --判断是否未下线，同时又进入新的一天
    if #signInfos >= totalDays then
        print("已经签到完了，重新开启新一轮的签到～")
        local finalData = signInfos[#signInfos]
        local curTime = GetLocalTime()
        if finalData.year < curTime.year then
            signInfos = {}
        elseif finalData.month < curTime.month then
            signInfos = {}
        elseif finalData.day < curTime.day then
            signInfos = {}
        end 
    end
    UpdateUIPanel(signInfos)
end
```

## 签到界面刷新逻辑
UpdateUIPanel 函数是用来刷新签到界面的，通过 totalDays 变量来展示有多少个签到项，每个签到项根据 signInfos 记录的信息来展示已签到还是未签到。
```Lua
--刷新签到界面
function UpdateUIPanel(infos)
    if infos == nil then
        return
    end
    
    local allItem = {}
    print("ItemParent 下面的子级数量是："..itemParent.childCount)
    for i=1, itemParent.childCount do
        allItem[i] = itemParent:GetChild(i-1)
    end

    for i=1,totalDays do
        local itemObj = allItem[i]
        local isDnoe = false
        if itemObj == nil then
            itemObj = UnityEngine.GameObject.Instantiate(item,itemParent).transform
            local btn = itemObj:Find("sign").gameObject:GetComponent(typeof(UnityEngine.UI.Button))
            btn.onClick:AddListener(function ()
                OnSignClick(itemObj)
            end)
        end
        if infos[i] ~= nil then
            isDnoe = true
        end
        SetItem(itemObj,isDnoe,i)
    end
    signPanel:SetActive(true)
end

function SetItem(item,isdone,index)
    if item == nil then
        return
    end
    item.gameObject.name = tostring(index)
    item:Find("done").gameObject:SetActive(isdone)
    item:Find("sign").gameObject:SetActive(not isdone)
    item.gameObject:SetActive(true)
end
```

## 点击签到逻辑
在刷新签到界面时，会给每一个签到项中的签到按钮绑定一个点击事件 OnSignClick，通过该点击事件来进行签到逻辑。
在玩家点击签到按钮后，需要判断如下内容：

* 点击的签到按钮是否为签到顺序的按钮（签到需要按照前后顺序依次签到）
* 点击签到按钮时，自然日内是否已经签到过

如果满足当前自然日内第一次签到，并且点击的是签到顺序的按钮，那么就刷新 signInfos 记录的信息，并对数据进行存储。
```Lua
--点击签到按钮
function OnSignClick(item)
    if isClick then
        return
    end
    if curPlayer == nil then
        return
    end
    if item == nil then
        return
    end

    isClick = true
    --根据按钮名字来获取点击的是哪一个签到项
    local btnName = item.gameObject.name
    if #signInfos == 0 and btnName ~= "1" then
        print("点击的不是第一个签到按钮！")
        DouyinUtility.Toast("请按照顺序签到哦～")
        isClick = false
        return
    end

    if #signInfos > 0 then
        local len = #signInfos
        if btnName ~= tostring(len+1) then
            print("点击的是 "..btnName.." 应该点击签到按钮是"..tostring(len+1))
            DouyinUtility.Toast("请按照顺序签到哦～")
            isClick = false
            return
        end
    end
    
    local curTime = GetLocalTime()
    local isNewDay = false
    if #signInfos > 0 then
        local index = #signInfos
        local t = signInfos[index]
        if curTime.year < t.year then
            isClick = false
            return
        end
        if curTime.year == t.year then
            if curTime.month == t.month then
                if curTime.day > t.day then
                    isNewDay = true
                end
            elseif curTime.month > t.month then
                isNewDay = true
            end
        else
            isNewDay = true
        end
    else
        isNewDay = true
    end

    print("是否是新的一天："..tostring(isNewDay))
    if isNewDay == false then
        isClick = false
        return
    end

    print("准备开始签到，签到人的ID是："..curPlayer.playerOpenID)
    DATASTORE(function ()
        local ok,store = DouyinDataService.GetDataStore("World","PlayerInfos"..curPlayer.playerOpenID)
        if ok ~= 0 then
            print('Load  Failed:' .. ok .. tostring(store))
            isClick = false
            return
        end
        local t = {}
        t["sign"] = 1
        t["year"] = curTime.year
        t["month"] = curTime.month
        t["day"] = curTime.day
        table.insert(signInfos,t)
        
        local setdata = dkjson.encode(signInfos) --将表数据用json进行序列化
        local ok,msg = store:SetData("TOTAL_SIGN_DAYS",setdata)
        if ok ~= 0 then
            print('Set data failed! code is:' .. ok .. ' message is:' .. msg) 
            isClick = false
            return
        end
        print("------签到成功，数据长度为："..#signInfos)
        for i = 1, #signInfos do
            print("索引为："..i.." 的数据：",signInfos[i].year,signInfos[i].month,signInfos[i].day)
        end
        isClick = false
        item:Find("done").gameObject:SetActive(true)
        item:Find("sign").gameObject:SetActive(false)
        SignSuccessCallBack(#signInfos)
    end)
end

--当签到成功后，可以在这里处理成功逻辑
function SignSuccessCallBack(n)
    if n == nil then
        return
    end
    print("第"..n.."次签到成功～")
end
```
