# 主权介绍
主权用来决定哪个玩家可以更改网络对象的属性，并将其发送给其他玩家。每个网络对象的主权在某个时刻一定归属于某位玩家，一个玩家可以同时是多个网络对象的主权方。如果你希望玩家能够更改物体的属性，请务必先检查或请求主权。
当因为一些原因，物体的主权方更改后，新的主权方负责网络数据的修改和同步。比如，当你捡起一个挂有 Douyin Pickup 的物体后，会成为他的新的主权方。
**当某位玩家离开房间时（必须是离开房间），此玩家将不再拥有任何对象的主权。**
# 主权相关接口
在使用网络对象过程中，你或许需要对网络对象的主权归属进行判断，或者是想要更换某个网络对象的主权，或者是在网络对象的主权进行切换时执行某些操作，那么下面这些接口，你需要仔细阅读了解。
## 判断网络对象的主权归属
使用以下接口可以判断挂载当前脚本的网络对象的主权归属。  
| [DouyinScript.HasOwnership()](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=pgzk6tms) | 判断自己是否拥有当前物体的主权 |
| --- | --- |
| DouyinPlayer [DouyinScript.GetOwner()](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=65m23jlf) | 直接获取主权方的玩家对象 |
| [DouyinScript.IsOwner(DouyinPlayer player)](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=idfmrew3) | 判断某个玩家是否是当前物体的主权方 |
```Go
function OnActorTriggerEnter(actor)
    if self:HasOwnership() then
        //todo
    end
end
```

## 变更主权
主权的变更有以下几种情况：

* 自动切换主权：当某网络对象的主权方离开房间时，该网络对象的主权将会由系统自动转移至房间内某个玩家身上
* 主动请求主权：房间内某个玩家申请成为某个网络对象的主权方
* 直接指定主权：直接设置某个网络对象的主权方为房间内指定玩家

### **自动切换主权**
当房间内持有某个网络对象的玩家离开房间后，该网络对象的主权将会被系统自动分配给房间内的某个玩家，你可以通过在网络对象所挂载的Lua脚本中编写事件函数[ DouyinScript.OnOwnershipTransferred ](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=hmuqupj3)来获知主权转移。
当主权被转移时，所有房间内的玩家都将收到这个事件，你可以在该事件中使用 [DouyinScript.GetOwner()](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=65m23jlf) 获取新的主权方。
```Go
function OnOwnershipTransferred()
    print("New Owner =", self:GetOwner().playerID);
end
```

1. **当主权玩家切后台时，主权会自动转移至房间内其他玩家；所以在使用主权设计数据同步等相关逻辑时，需要注意这一点。**

### **主动请求主权**
#### 如何主动请求主权
通过调用 [DouyinScript.RequestOwnership(Action onFinished) ](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=m0zecpga)可以请求当前脚本所属物体的主权。  
任何玩家都可以调用这个方法，并且可以在此方法的回调中直接处理收到请求结果之后的逻辑。示例如下：
```Lua
RequestOwnership(function(bSucceed) -- The bSucceed parameter of the callback function indicates whether that request was successful.
        if bSucceed then
             print("request succeeded")
        end
end)
```

#### 如何答复主权请求
通过事件函数 [DouyinScript.OnOwnershipRequest(int senderID)](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=isb7h6vh) 可以答复主权转移的请求。
当向主权方申请主权时，主权方会收到这个事件。当主权方已经是自己时，自己也会收到这个事件。  
主权方返回 true 代表同意主权转移，返回 false 代表不同意主权转移，当主权方同意后，会发送[OnOwnershipTransferred](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=hmuqupj3) 事件给房间内所有人。
**将返回值设置为 true 与根本不设置返回值具有相同的效果**。
如果你完全不实现 OnOwnershipRequest 事件函数，相当于没有设置返回值，也即是相当于直接同意主权转移请求。

**如果一个物体上有多个脚本都有此事件函数，则所有脚本都返回 true 才是同意请求，只要有一个脚本返回 false，则拒绝请求，且后续其他脚本中的对应事件将不再执行。**

```Lua
function OnOwnershipRequest(senderID)
    return true;
end
```

### 直接指定主权
直接调用 [DouyinScript.SetOwner](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=c6gki6bo) 来直接设置某个玩家成为新的主权方。此方法也会触发 [OnOwnershipTransferred](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=hmuqupj3) 事件。
