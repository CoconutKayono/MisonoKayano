# 访问数据对象
所有 DataStore 操作均由 DouyinDataStore 和 DouyinOrderedDataStore 实体类触发。
## DouyinDataStore
用于 DataStore 操作的实体类。每个 DouyinDataStore 类代表一个相同类型的数据集合。DouyinDataStore 中存储的所有数据均由键值对组成，并支持元数据相关操作。
更多API接口可以看：[DouyinDataStore](/4j78bceb/d0p8l756)
## DouyinOrderedDataStore
用于 DataStore 操作的实体类。每个 DouyinOrderedDataStore 类表示一个由键值对组成的同类型数据集合。DouyinOrderedDataStore 中存储的所有数据只能为数值类型，不支持元数据和版本相关操作。此外，DouyinOrderedDataStore 中存储的数据还支持排序。默认情况下，数据根据数值按升序或降序排序。
更多API接口可以看：[DouyinOrderedDataStore](/4j78bceb/3cse86k4)
## 创建并获取 DouyinDataStore 或 DouyinOrderedDataStore 对象
要存储和访问数据，您必须创建或获取一个 DouyinDataStore 或 DouyinOrderedDataStore 对象。您可以调用 DouyinDataService 提供的 GetDataStore 或 GetOrderedDataStore API 来创建或获取 DouyinDataStore 或 DouyinOrderedDataStore 对象。请注意，创建和获取 DouyinDataStore 或 DouyinOrderedDataStore 对象都是通过调用这两个 API 来完成的。
```Lua
--获取DataStore对象
local ok, store1 = DouyinDataService.GetDataStore(string name, string scope = “global”, bool all_scope = false)
--获取OrderedDataStore对象 
local ok, store2 = DouyinDataService.GetOrderedDataStore(string name, string scope = “global”)
```

介绍一下这两个API使用的参数：

* name：DouyinDataStore 或 DouyinOrderedDataStore 对象的名称。
* scope：指定域名的字符串，所有字符串自动按域名拆分成表。
* allScope：指定是否访问所有范围内的数据。如果设置为 true，则获取到的 DataStore 对象可以访问同一个 DataStore 对象中不同范围内的数据。但是，必须在获取数据的 API 的参数 key（即“scope:key”）中指定范围，否则该对象只能访问指定范围内的数据。当 allScope 设置为 true 时，scope 参数必须为空或设置为 nil。当 allScope 设置为 false 且 scope 参数未指定范围时，scope 参数将被赋值为默认值“global”。

如果您使用的是模拟器，且未启用DataStore或者不满足启用条件，这些API将返回相应的错误码和信息。
# 操作数据
## 获取数据
获取数据需要遵循代码格式规则，**即 DataStore 相关的代码必须放在DATASTORE()代码块内部，也就是传入一个函数给 DATASTORE 调用。具体代码示例如下。**
您可以调用DataStore的GetData接口获取相应数据，如果接口操作成功，GetData会返回以下3个值：

* code：数值类型，值为0表示API操作成功，否则API操作失败。
* value：如果API操作成功，该value等于key对应的value；如果API操作失败（code不为0），该value为字符串类型的错误信息。
* info：如果 API 操作成功（code 为 0），info 会以 DouyinDataStoreInfo 结构体的形式包含详细的数据信息，包括具体的元数据以及具体的键值。您可以使用以下代码示例访问数据并执行后续操作。

```Lua
DATASTORE(  
        function()  
        -- Get my_world's bag capacity for local player  
        local player = CS.DouyinPlayerService.GetLocalPlayer()  
        local pet = CS.DouyinPetService.GetLocalPet() 
        -- 获取对象，player代表当前玩家的账户，pet代表当前玩家选择的小火人
        if player == nil then  
            print('Local player is nil')
            return
        end        
        local ok, store1 = DouyinDataService.GetDataStore('my_world1', 'bag_' .. player.playerOpenID)
        local ok, store2 = DouyinDataService.GetDataStore('my_world2', 'bag_' .. pet.petOpenID)

            return
        end
        local ok, bag_capacity, info = store:GetData('capacity')
        if ok ~= 0 then
            print('Get data failed!, code:' .. ok .. ' error_msg:' .. bag_capacity)
            return
        end
        print('Bag capacity for player:' .. player.UID .. ' is:' .. bag_capacity)
    end)
```

**备注**：目前建议使用火人ID（petOpenID）和账号ID（playerOpenID）对玩家数据进行存储，需要注意一下火人ID（petOpenID）和账号ID（playerOpenID）的区别：一个账号ID会对应多个火人ID。存在火人ID下，数据就会跟着小火人走，存在账号ID下，就会跟着抖音账号走，按需使用
**playerOpenID: 绑定抖音账户的ID，切换个人抖音账号时变化**
**petOpenID：关系主导的ID，绑定合养小火人关系的ID，切换合养人时变化（举例：你和张三养了个小火人，你可以随意切换你们的小火人形象，但是这个ID不变；但是你切换成和李四养的火人，这ID就变了）**
## 设置数据
* 若直接将table类型的数据存入数据库，那么在获取数据时，数据库返回的是string类型的数据，而不是table类型的数据，可以使用序列化和反序列化接口来处理table类型的数据（具体API在下方）

可以通过 DataStore 的 SetData API 设置数据。SetData API 的输入参数包括 key、value 和 options。key 参数表示数据的键，value 参数表示数据的值，options 参数表示附加信息。SetData API 的返回值与 GetData API 的返回值相同。
实际上，数据是以键值对的形式存储在 DataStore 中的。当 DataStore 中存在相同键的数据时，新设置的数据会替换原有相同键的数据。如果不存在这样的数据，则会创建一个新的键，并将对应的值保存在该键中。
要修改该值的元数据，可以使用 options 参数。API 的使用方法请参见后续章节的描述。需要注意的是，options 参数不能用于设置 DouyinOrderedDataStore 中存储的元数据。
## 增量更新数据
增量更新可以在不获取数据当前值的情况下更新数据。与 SetData 相比，增量更新可以降低数据不一致的风险。例如，如果在获取数据和设置数据之间，数据被其他操作修改，再次调用 SetData 可能会导致数据不一致。增量更新通常用于修改全局唯一或局部唯一值，或者其他可能被多个服务器同时修改的值，例如房间内玩家总数或任务的整体进度。
您可以通过 DataStore 的 IncrementData API 执行增量更新：
```Lua
ok, value, DouyinDataStoreInfo info = IncrementData(string key, number delta, DouyinDataSetOptions options = nil)
```

下面的代码示例显示当新玩家加入游戏时，游戏中的玩家总数增加 1：
```Lua
 DATASTORE(  
        function()  
            -- Get my_world's players info  
            local ok, store = DouyinDataService.GetDataStore('my_world', 'players_info')  
            if ok ~= 0 then  
                print('Load  Failed:' .. ok .. tostring(store))  
                return  
            end  
            ok, message = store:IncrementData('total_player_count', 1)  
            if ok ~= 0 then  
                print('Increment data failed!, code:' .. ok .. ' error_msg:' .. message)  
                return  
            end  
            ok, total_players = store:GetData('total_player_count')  
            if ok ~= 0 then  
                print('Get data failed!, code:' .. ok .. ' error_msg:' .. total_players)  
                return  
            end  
            print('Total player count is:' .. total_players)  
        end)
```

## IncrementData 与 SetData 与 UpdateData
DataStore 提供 3 种数据更新模式，您需要根据不同的使用场景选择合适的上传模式。

1. SetData

最基本的 DataStore API。它适合执行基本的 DataStore 操作，例如保存玩家等级、积分和登录时间等数据。但是，当您调用此 API 设置可能被多台服务器同时修改的数据时，可能会出现数据不一致的情况。当您使用此 API 设置全服务器积分或游戏状态等数据时，需要根据操作的实际业务逻辑，避免因跨多台服务器同时操作而导致的数据不一致。

2. IncrementData

针对跨多服务器 SetData 操作可能带来的数据不一致问题，IncrementData 提供了原子性的增量更新模式，可以有效保证数据一致性。然而，IncrementData 只能操作数值型数据，无法基于当前值进行针对性的逻辑处理，因此更适合全局数值型字段的更新。IncrementData 只能处理简单的数据更新逻辑，对于更复杂的更新逻辑，IncrementData 可能不够用。

3. UpdateData

UpdateData 是一个基于函数的更新 API，适用于对一致性要求较高的复杂数据更新场景，但 UpdateData API 使用难度较大，操作流程复杂，对于一般的更新请求来说效率和简洁性不够。

## 对数据进行排序
DouyinOrderedDataStore 可以自动根据数据值对数据进行排序，并以分页方式获取数据。
好的，DataStorePages pages = GetSortedData（bool ascending，int pagesize，double min_value = -math.huge，double max_value = math.huge）
DouyinOrderedDataStore 允许您通过 GetSortedData API 获取按值排序的数据列表。调用此 API 时，您可以设置每页显示的数据项数量以及要获取的最小值和最大值。页码从 0 开始递增。最小值和最大值的默认值分别是 Lua 中浮点数的最小值和最大值。当它们设置为 nil 或无值时，您将获取存储在 DataStore 对象中的所有数据。
GetSortedData 的返回值是一个错误码和一个包含分页信息的 DouyinDataPages 对象。您可以调用 DouyinDataPages 接口按页遍历数据。相关接口将在后续章节中介绍。以下代码示例获取玩家物品栏中的物品：
```Lua
    DATASTORE(  
        function()  
            local page_size = 10  
            -- Get my_world's arena rank points  
            local ok, store = DouyinDataService.GetOrderedDataStore('my_world','arena_rank')  
            if ok ~= 0 then  
                print('Load data store failed! code is:' .. ok .. ' message is:' .. store) 
                return  
            end

            local ok, message = store:SetData('rank_1', 100)
            if ok ~= 0 then
                print('Set data failed! code is:' .. ok .. ' message is:' .. message)  
                return
            end
            local ok, message = store:SetData('rank_2', 80)
            if ok ~= 0 then
                print('Set data failed! code is:' .. ok .. ' message is:' .. message)  
                return
            end

            local ok, pages = store:GetSortedData(true, page_size)
            if ok ~= 0 then
                print('GetSortedData failed! code is:' .. ok .. ' message is:' .. pages)
                return
            end
            local page_index = 1
            repeat
                local success, page_values = pages:GetCurrentPage()
                local index = 1
                if success == 0 then
                    for k, v in pairs(page_values) do
                        print('rank:' .. (page_index - 1) * page_size + index .. 
                                ' points:' .. tostring(v.value))
                        index = index + 1
                    end
                end
                page_index = page_index + 1
            until(not pages:AdvanceToNextPage())
        end)
```

## 前缀搜索
DouyinDataStore 支持根据 key 进行前缀查找，并可以自动对数据进行排序以及分页获取数据。
```Lua
ok, DataStorePages pages = ListKeys(string prefix, bool ascending, int pagesize)
ok, DataStorePages pages = ListValues(string prefix, bool ascending, int pagesize)
```

DouyinDataStore 允许您通过 ListKeys 或 ListValue API 获取按键排序的键值列表或数据。调用任一 API 时，您可以设置每页显示的数据项数量。如果您在创建或获取 DouyinDataStore 时启用了跨域 all_scope 功能，则需要以 scope:prefix 的格式添加 scope 作为前缀。当然，任何字母都可以作为前缀进行前缀搜索。
ListKeys 和 ListValues 的返回值分别为错误码和包含分页信息的 DouyinDataPages 对象。您可以调用 DouyinDataPages 接口逐页遍历数据。相关接口将在后续章节中介绍。以下代码示例获取某个 World 的积分排行榜：
```Lua
    DATASTORE(
        function()
            print('==============Sorted Section============')
            ok, store = DouyinDataService.GetDataStore('PlayerInventory', 'player001')
            if ok ~= 0 then
                print('LoadDataStore Failed:' .. ok .. tostring(store))
                return
            end

            for v = 1, 100 do
                ok, val, info = store:SetData('item'..v, v)
            end

            print('==============ListKeys============')
            success, value = store:ListKeys('item3', false, 5)
            Log.log_page(success, value)
            if success == 0 then
                repeat
                    success, val = value:GetCurrentPage()
                    for k, v in pairs(val) do
                        print('ListKeys:' .. k .. ' : ' .. v)
                    end
                until(not value:AdvanceToNextPage())
            end

            print('==============ListValues============')
            success, value = store:ListValues('item3', false, 5)
            Log.log_page(success, value)
            if success == 0 then
                repeat
                    success, val = value:GetCurrentPage()
                    for k, v in pairs(val) do
                        print('ListValues:', k, v)
                    end
                until(not value:AdvanceToNextPage())
            end
        end)
```

# 元数据
在保存数据时，为了保证数据的有效性和一致性，DataStore 会额外记录某些数据存储操作。DataStore 也允许您在保存数据时以元数据的形式记录自定义操作信息。这两种类型的数据都以元数据的形式存储。
系统记录的操作信息称为系统元数据。
用户自定义的附加信息称为用户元数据。
DataStore的系统元数据包括：

* 数据创建时间
* 数据最后更新时间
* 当前数据版本号

所有系统元数据都可以通过GetData返回值中的第三个参数DouyinDataInfo实例获取，具体属性名称描述如下：

* createTime：数据创建时间
* updateTime：上次更新时间
* version：当前数据版本号

IncrementData、SetData、UpdateData三个接口都提供了options参数用于设置用户元数据，options的类型为DouyinDataSetOptions，DataStore通过DouyinDataSetOptions封装了元数据设置接口。
所有用户元数据都可以通过GetData返回值中的第三个参数DouyinDataInfo实例获取，具体API为：
tableGetMetadata()
下面的代码展示了如何使用GetData获取相应的用户元数据，然后使用SetData修改获取的元数据：
       **SetMetadata(key, value)，现在需要SetMetadata的参数需要严格遵循KV结构。**

```Lua
    DATASTORE(  
        function()  
          -- Get my_world's arena rank info  
          local ok, store = DouyinDataService.GetDataStore('my_world', 'arena_rank_point')  -- 创建/获取一个名称为my_world，scope为arena_rank_point的store对象
          if ok ~= 0 then  
            print('Load data store failed! code is:' .. ok .. ' message is:' .. store)  
            return  
          end  
          local player = CS.DouyinPlayerService.GetLocalPlayer() -- 获取玩家对象
          if player == nil then  
            print('Local player is nil')  
            return  
          end  
          local point_key = 'point_' .. player.UID -- 定义一个以玩家UID为后缀的key
          local set_options = DouyinDataService.CreateDataSetOptions() -- 定义一个DataStoreSetOptions对象
          local meta = {reason = 'init'} -- 定义自定义元数据内容
          set_options:SetMetadata(meta) -- 写入元数据内容
          local ok, message = store:SetData(point_key, 20, set_options) -- 将元数据内容写入datastore
          if ok ~= 0 then  
            print('Load data failed: error code is:' .. ok .. ' error message is:' .. message)  
            return  
          end

          local ok, point, point_info = store:GetData(point_key) -- 获取数据，point为key对应的value，pointinfo为对应的metadata实例对象
          if ok ~= 0 then  
            print('Load data failed: error code is:' .. ok .. ' error message is:' .. point)  
            return  
          end  
          local meta_data = point_info:GetMetadata()  
          local new_meta = {}  
          if meta_data ~= nil then  
            for k, v in pairs(meta_data) do  
              if k == 'reason' then  
                print('Arena point change to ' .. point .. ' due to ' .. v)  
                new_meta[k] = 'change to new reason'  
              else  
                new_meta[k] = v  
              end  
            end  
          end  
          local set_options =  DouyinDataService.CreateDataSetOptions()
          set_options:SetMetadata(new_meta)  
          local ok, point, point_info = store:SetData(point_key, point, set_options)  
          if ok ~= 0 then  
            print('Set data failed: error code is:' .. ok .. ' error message is:' .. point)  
            return  
          end  
          print('Set data succeed!')  
        end)
```

# 数据序列化
平台提供对数据进行Json序列化和反序列化的能力，具体API为：

```Lua
--数据序列化
dkjson.encode(data)
--数据反序列化
dkjson.decode(data)

--对数据进行序列化和反序列化时，如果数据中带有特殊字符，那么需要再对数据进行一轮处理，处理接口如下：
--序列化
Local jsonStr = dkjson.encode(sampleData)
jsonstr = CS.System.Net.WebUtility.UrlEncode(jsonStr)

--反序列化
Local decodeData = dkjson.decode(data1)
decodeData = CS.System.Net.WebUtility.UrlDecode(decodeData)
```

# 注意事项
* 在Share Mode模式下，若用户处于网络环境较差的环境下，不能保证数据存储可执行成功，因此，各位开发者在设计数据存储业务逻辑时，需注意小心因未获取用户真正数据而将用户数据初始化/将初始数据存入的风险。
* DataStore 存/取时字符串报错（ expected near 's' ），可检查下是否有特殊字符，例如英文单引号' 和反斜杠 \。业务侧可使用base64编码处理该问题，存之前 base64 编码、取出来再解码即可（base64 输出只含安全字符，不会有单引号问题）。
