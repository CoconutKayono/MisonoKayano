# 什么是组件？
组件是 Unity 中的一个特殊概念。你可以通过向游戏对象添加组件来让游戏对象执行具体的交互行为或效果。每个组件都是游戏对象的一个功能部件。Unity 包含许多内置组件，例如刚体（使游戏对象能够受到物理力的影响）和音频源（使游戏对象能够发出声音）。
要了解有关 Unity 中组件的更多信息，请参阅文章：[https://docs.unity3d.com/2021.3/Documentation/Manual/UsingComponents.html](https://docs.unity3d.com/2021.3/Documentation/Manual/UsingComponents.html)。
同样，抖音虚拟世界也提供了一批组件供用户使用，例如：[拾取组件](/s196aspp/lp5ii81h)（允许玩家捡起或放下挂载拾取组件的游戏对象），你可以使用这些组件来创造丰富的交互体验。
# 如何使用这些组件？
抖音虚拟世界提供两种类型的组件。一种是类似 Unity 的原生组件，称为 **C#组件**，例如 [网络同步组件](/s196aspp/fwkk26yn)。另一种是基于 Lua 脚本的组件，称为 **Lua组件**，例如 [拾取组件](/s196aspp/lp5ii81h) 和 [椅子组件](/s196aspp/o51cosgn)。
两种组件的主要区别在于：

* 使用方式有所不同：
   * C# 组件类似于 Unity原生组件，可以直接在 Inspector 面板中点击 Add Component 进行搜索和添加。
   * Lua 组件需要先在 Inspector 面板中添加 Douyin Script 组件，然后再将对应的 Lua 脚本挂载到该组件的脚本文件属性上。
* 是否允许创作者修改：
   * C# 组件虽然简单便捷，但创作者无法查看和修改组件的源代码。
   * Lua组件则可以直接查看和修改源代码，非常方便。
* 是否允许创作者新增：
   * 由于SDK在处理创作者所提交的世界时会剔除非SDK内的 C#脚本，所以创作者目前无法新建自己的C#组件或者使用第三方的 C#插件。
   * 创作者可以通过编写 Lua脚本来实现自己的 Lua组件，并将该脚本挂载到 Douyin Script 组件的脚本文件属性上。
