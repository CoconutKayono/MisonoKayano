# 网络对象介绍
网络对象是指一个需要被同步的对象，在所有客户端上都存在。
默认情况下，世界中的对象是“**本地”​**的。这意味着对物体造成的变化，其他玩家都看不到。要同步该对象，需要将它变成一个“**网络对象**”。
你可以向其添加 Douyin Script 组件或 Douyin Object Sync 组件，使一个物体成为网络对象。
当然，一些带有网络同步功能组件的物体，也是网络对象，比如 Douyin Portal、Douyin MusicPlayer、DouyinVideoPlayer。每个玩家也是一个网络对象，他们的位置、动画状态机参数、语音都会自动同步。
# 网络对象分类
| **分类** | **对象** | **描述** |
| --- | --- | --- |
| **创建时机** | * ++静态网络对像++ | * 默认在Unity场景里面放置的++网络对象++ |
|  | * ++动态网络对象++ | * 运行时创建的网络对象 <br>    * 通过 DouyinObjectService.NetSpawn 动态创建的网络对象 <br>    * 通过 DouyinActor.NetSpawn 动态创建的网络对象 |
| **生命周期** | * ++房间网络对象++ | * 所有++静态网络对象++都属于++房间网络对象++ <br>    * 它和房间的存在时间是一样的 <br>    * 房间创建时它也创建，房间销毁时它也销毁 <br> * 通过DouyinObjectService.NetSpawn动态创建的网络对象 <br>    * 必须使用DouyinObjectService.NetDestroy来销毁 <br>    * 如果不销毁，这个网络对象会在房间销毁时一起被销毁 |
|  | * ++玩家关联的网络对象++ | * 通过DouyinActor.NetSpawn动态创建的对象 <br>    * 必须使用DouyinActor.NetDestroy来销毁 <br>    * 如果不销毁，这个网络对象会在玩家被销毁时一起被销毁 |
| **对象类型** | * ++玩家网络对象++ | * 玩家控制的网络对象：DouyinActor |
|  | * ++普通网络对象++ | * 所有的++静态网络对象++ <br> * 所有的++动态网络对象++：DouyinObject |
# 动态生成网络对象
想要动态生成网络对象，需要先在 Douyin World Root 组件上进行关联配置。

1. 创建 **Douyin Net Spawn Object Asset**

<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a46fd4ff307d40d2afec0d3118923fc5~tplv-goo7wpa0wc-image.image" width="264px" /></div>


2. 将创建的 **Douyin Net Spawn Object Asset** 拖入 Douyin World Root 组件的网络对象生成配置中，点击数组列表+号，即可添加网络对象。

<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/43a2a37d3aec4e379a4a3417ab6ddb3d~tplv-goo7wpa0wc-image.image" width="264px" /></div>

你可增删网络对象数组，并填充数组列表中的每一项，每一项中都包含： 

* 主键：也即是key，key 的长度没有数量限制，但 key 不允许重复。
* 游戏对象：也即是要使用的网络对象，可以关联场景中的 GameObject，也可以关联 Assets 目录中的Prefab。
3. 你可以使用 [DouyinObjectService.NetSpawn 接口](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=ge4lsnsr) **** 在 Lua 脚本中通过代码生成指定的网络对象，该接口将会返回一个 UnityEngine.GameObject 类型的实例。

```Lua
DouyinObjectService.NetSpawn(key, function(go,id)
-- go为动态创建的网络对象
-- id为动态创建的网络对象的id
end)
```

哪个玩家生成的对象，其主权就归属于此玩家。生成后的对象的名字和配置中对象的名字是一样的。生成后的物体不会自动销毁，**为了更好的性能，需要注意管理销毁逻辑**，如果需要销毁网络对象，可以使用 [DouyinObjectService.NetDestory 接口](https://vcreate.douyin.com/tutorial?book=4j78bceb&doc=cgknb1p6)
口诀：生成必销毁

# 动态网络对象
使用DouyinObjectService.NetSpawn创建出来的是**动态房间网络对象**。关于这个“**动态房间网络对象**”，有两个重要的概念：

* **动态网络对象：​**它是在运行的时候创建的。假如有A、B两个客户端在房间里，A执行了DouyinObjectService.NetSpawn()方法，而B没有执行。这样A就会创建出一个网络对象NetA，B会收到创建网络对象NetA的消息，然后自动创建出网络对象NetA。这时C进入房间，C同样会收到创建网络对象NetA的消息，也会自动创建出网络对象NetA。所以这三个客户端都会有一个NetA。
* **房间网络对象：​**它和房间存在的时间相同，不会自动消失。A创建的房间网络对象NetA，即便A下线了，NetA也不会自动销毁，会一直留在房间里。

注意：由于房间网络对象不会自动销毁，所以上面的例子中，A再次进入同一个房间，它又创建了一个新的网络对象NetA1，那么房间内就会再多一个NetA1对象。如此反复，就会导致房间内的网络对象越来越多，所以使用DouyinObjectService.NetSpawn()动态创建网络对象的时候，要注意反复创建的问题，以及销毁网络对象的时机。

# 注意事项

1. 目前每个房间内单个角色下最多动态生成1000个网络对象。
2. 房间内每多一个角色时，就可以多动态生成1000个网络对象。
3. 网络对象销毁后，key可复用，也即是只关注同一时间内存在的网络对象数量。
4. 使用 DouyinObjectService.NetSpawn 接口动态创建网络对象时，若创建失败，则会返回 nil。
5. 只要挂载了 DouyinNetworkGuid 的对象都算是网络对象，如果对象不需要挂载 DouyinScript 脚本来处理逻辑，建议删除物体上挂载的 DouyinNetworkGuid 组件
6. 动态创建的网络对象在生成后会调用 OnNetSpawned 函数，可以用来处理一些初始化的逻辑
