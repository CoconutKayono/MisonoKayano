| 序号 | 格式 |  |  | Untiy Audio Source支持格式 | 播放结果 |
| --- | --- | --- | --- | --- | --- |
| 1 | 无损音频格式 | **FLAC** | .flac | 支持 | 支持 |
| 2 |  | **ALAC** <br>  | .m4a（与 AAC 共用） <br>  | 不支持 | 不支持 |
| 3 |  | **WAV** | .wav | 支持 | 支持 |
| 4 |  | **DSF/DFF** | .dsf/.dff | 不支持 | 不支持 |
| 5 |  | **APE** | .ape | 不支持 | 不支持 |
| 6 | 有损音频格式 | **AAC** | .aac/.m4a | 不支持（.aac） | 不支持（.aac） |
| 7 |  | **MP3** | .mp3 | 支持 | 支持 |
| 8 |  | **OGG Vorbis** | .ogg | 支持 | 支持 |
| 9 |  | **WMA** | .wma | 不支持 | 不支持 |
| 10 |  | **AMR** | .amr | 不支持 | 不支持 |
| 11 | 特殊用途音频格式 | **MIDI** | .mid/.midi | 不支持 | 不支持 |
| 12 |  | **Opus** | .opus | 不支持 | 不支持 |
| 13 |  | **Wwise Audio** | .wem | 不支持 | 不支持 |
