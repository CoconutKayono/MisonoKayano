```c
int n = 7;

int countPairs() {
    int cnt = 0;
    int i = 0, j = n - 1;
    while (i < j) {
        if (data[i] + data[j] <= 50) {
            cnt += j - i;
            i++;
        } else {
            j--;
        }
    }
    return cnt;

void merge(int l, int m, int r) {
    int n1 = m - l + 1, n2 = r - m;
    int L[n1], R[n2];
    for (int i = 0; i < n1; i++) L[i] = data[l + i];
    for (int j = 0; j < n2; j++) R[j] = data[m + 1 + j];
    int i = 0, j = 0, k = l;
    while (i < n1 && j < n2) data[k++] = (L[i] <= R[j]) ? L[i++] : R[j++];
    while (i < n1) data[k++] = L[i++];
    while (j < n2) data[k++] = R[j++];

    if (l == 0 && r == n - 1) {
```

### 22. 限定池抽卡日志分析（10 分）



#### 题目描述

某二次元手游的限定池活动结束。玩家一共抽了 $n$ 抽，其中出了 $k$ 次五星（俗称"出金"）。第 $i$ 次出金发生在第 $p_i$ 抽，结果为 $r_i$：

- $r_i=1$：当期五星（没歪）；
- $r_i=2$：常驻五星（歪了）。

数据保证 $p_1<p_2<\dots<p_k$，即输入已经按抽数从小到大排好序。

请统计并输出：

1. **出金次数**（就是 $k$）；
2. **歪了几次**（$r_i=2$ 的个数）；
3. **最长垫抽**：把整场日志切成若干段"连续没有出金的抽"，取最长的那一段。**出金的那一抽不计入垫抽**；日志开头到第一次出金之前、每两次出金之间、最后一次出金之后到第 $n$ 抽，都按同一规则统计。例如第 3 抽和第 8 抽出金，则中间垫了第 4~7 抽，共 4 抽（是位置差 $8-3=5$ 再减 1，不是 5）；
4. **当前水位**：日志结束时，距离上一次出金已经垫了多少抽，也就是最后一段的长度（如果全程没出金，就是 $n$）。

#### 输入形式

第一行两个整数 $n,k$（$1\le n\le 10^7$，$0\le k\le n$）。

接下来 $k$ 行，每行两个整数 $p_i,r_i$（$1\le p_i\le n$，$r_i$ 为 $1$ 或 $2$）。

当 $k=0$ 时，后面没有输入。

#### 输出形式

```
出金次数: A 歪了: B 次 最长垫抽: M 当前水位: W
```

输出一行，各项之间用一个空格隔开，行末不要输出多余空格。

#### 样例输入 1（小抽数）

```
5 2
3 1
5 2
```

#### 样例输出 1

```
出金次数: 2 歪了: 1 次 最长垫抽: 2 当前水位: 0
```

#### 样例解释 1

第 3、5 抽各出金一次，其中第 5 抽歪了。没出金的段是"第 1~2 抽"（2 抽）与"第 4 抽"（1 抽），最长垫抽为 2；第 5 抽之后没再抽，水位 0。

#### 样例输入 2（边界：最长垫抽出现在结尾）

```
100 2
10 1
20 2
```

#### 样例输出 2

```
出金次数: 2 歪了: 1 次 最长垫抽: 80 当前水位: 80
```

#### 样例解释 2

第 10、20 抽出金。三段垫抽分别是开头 9 抽、中间 9 抽、**结尾 80 抽**，最长垫抽为 80；结尾这一段同时也是当前水位 80，可见结尾部分不能漏算。

#### 样例输入 3（大抽数）

```
500 6
10 1
80 2
160 1
250 1
340 2
430 1
```

#### 样例输出 3

```
出金次数: 6 歪了: 2 次 最长垫抽: 89 当前水位: 70
```

#### 样例解释 3

500 抽里出金 6 次，其中第 2、5 次歪了（第 80、340 抽），共歪 2 次。相邻两次出金之间垫得最多的是第 250 抽与第 340 抽之间：第 251~339 抽都没出金，共垫了 89 抽（两次出金的位置差是 90），所以最长垫抽为 89；最后一次出金在第 430 抽，之后第 431~500 抽没再出金，又垫了 70 抽，水位 70。

注意处于地图边界的格子相邻格子不足 8 个，只统计实际存在的相邻格子。

#### 输入形式

接下来 $n$ 行，每行 $m$ 个字符，只由 `.` 与 `*` 组成，行内没有空格。

输出 $n$ 行，每行 $m$ 个字符，表示数字地图。

#### 样例输入 1

```
.*..
...*
....
```

#### 样例输出 1

```
112*
0011
```

#### 样例解释 1

雷区共有 2 颗雷，分别在第 1 行第 2 列、第 2 行第 4 列。

- 第 1 行第 1 列的周围只有第 1 行第 2 列这一颗雷，输出 `1`；
- 第 1 行第 3 列的周围有第 1 行第 2 列和第 2 行第 4 列两颗雷，输出 `2`；
- 第 2 行第 1、2 列的周围都只有第 1 行第 2 列这一颗雷，输出 `1`；

#### 样例输入 2

```

*.
.*
```

#### 样例输出 2

```

```

#### 样例解释 2

### 24. 暮色大师（10 分）



#### 题目描述

某人在玩游戏《暮色大师》时, 按键输入可看作一个由小写字母组成的字符串, 每个关卡都有一个标准通关方式, 它对应的键盘输入记为`T`,由于误触, 实际通关的输入`S`可能会在`T`的任意位置多出若干个小写字母, `S`相对于`T`多出来的按键看作是误触, 误触次数为误触按键个数 (误触只表现为插入,不会替换原有按键,也不改变 `T` 中按键的先后顺序)

某人游玩某关卡时有两次输入分别为`A`和`B`, 两次均由同一个标准通关输入误触产生

现给出`A`和`B`, 请求出在所有可能的标准通关输入下, `A`和`B`两次误触次数之和的最小值

(如果存在一个输入`T`能通过误触产生`A`和`B`, 那么称`T`是可能的标准通关输入, `T`可能为空)

#### 数据范围

`1 <= |A|, |B| <= 1000`  (`|A|`表示`A`的长度)

字符串`A`,`B`仅由小写英文字母组成

#### 输入格式

输入两行:

每行一个字符串，分别表示两次输入 `A` 和 `B`。

#### 输出格式

输出一行:

一个整数, 表示 `A` 和 `B` 两次误触次数之和的最小值

#### 样例 1

#### 样例输入 1

```text
abcde
ace
```

#### 样例输出 1

```text
2
```

#### 样例解释 1

可能的标准通关输入 `T` 为：`""、a、c、e、ac、ae、ce、ace`, 其中 `""` 表示空串。

对于任意 `T`，两次误触次数分别为 `5 - |T|` 和 `3 - |T|`，因此两次误触次数之和如下：

| `T`              | 第一次误触次数 | 第二次误触次数 | 误触次数之和 |
| ---------------- | --------------:| --------------:| ------------:|
| `""`             | 5              | 3              | 8            |
| `a`、`c`、`e`    | 4              | 2              | 6            |
| `ac`、`ae`、`ce` | 3              | 1              | 4            |
| `ace`            | 2              | 0              | 2            |

因此最小值为 `2`。

------

#### 样例 2

#### 样例输入 2

```text
abc
def
```

#### 样例输出 2

```text
6
```

#### 样例解释 2

`A` 和 `B` 中没有相同的字符，标准通关输入只能取 `T = ""`

`A`, `B`均由空串误触3次得到，两次误触次数之和为：3 + 3 = 6
