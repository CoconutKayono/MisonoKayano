# 第 61 课 · 渐变效果（四种渐变）

> 学习目标：一次学会线性、径向、角度、波形四种渐变，并用时间在它们之间切换。

四种渐变其实是四种不同的「数值场」，最后都喂给 `lerp`。

---

## 1. 完整代码

```hlsl
Shader "Lesson/61_GradientShowcase"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float time = _Time.y;
                float2 centeredUV = IN.uv - 0.5;

                // 1. 线性渐变（左→右）
                float linearGradient = IN.uv.x;

                // 2. 径向渐变（中心→外）
                float radialGradient = length(centeredUV) * 1.5;

                // 3. 角度渐变（绕中心一圈）
                float angularGradient = atan2(centeredUV.y, centeredUV.x) / 6.28318 + 0.5;

                // 4. 波形渐变（随时间流动）
                float waveGradient = 0.5 + 0.5 * sin((IN.uv.x + time) * 8.0);

                // 每 6~7 秒在四种渐变间切换一次
                float selector = frac(time * 0.15) * 4.0;
                float chosen;
                if (selector < 1.0)      chosen = linearGradient;
                else if (selector < 2.0) chosen = radialGradient;
                else if (selector < 3.0) chosen = angularGradient;
                else                     chosen = waveGradient;

                float3 colorA = float3(0.1, 0.3, 0.6);
                float3 colorB = float3(1.0, 0.7, 0.2);
                float3 color = lerp(colorA, colorB, chosen);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面随时间在四种渐变之间循环切换。

## 2. 四种数值场

```hlsl
float linearGradient = IN.uv.x;                            // 沿 x 单调增
float radialGradient = length(centeredUV) * 1.5;           // 从中心向外增
float angularGradient = atan2(centeredUV.y, centeredUV.x) / 6.28318 + 0.5;  // 绕中心 0~1
float waveGradient = 0.5 + 0.5 * sin((IN.uv.x + time) * 8.0);  // 波浪起伏
```

线性渐变用 `uv.x`；径向用 `length(centeredUV)`；角度用 `atan2(y, x)`（结果范围 -π~π，除以 2π 加 0.5 映射到 0~1）；波形用 `sin` 把坐标压成 0~1 的波浪。

---

## 3. 用时间切换

```hlsl
float selector = frac(time * 0.15) * 4.0;
```

`_Time.y` 是 Unity 内置的「从启动到现在经过的秒数」。`time * 0.15` 让它变慢，`frac` 折叠成 0~1 循环，`* 4.0` 扩成 0~4，再用 `if` 分成四段，每段选一种渐变。`_Time.y` 不断增长，所以会循环播放。

## 5. 练习

练习代码里 `angularGradient` 那行是 TODO。补全：用 `atan2` 把绕中心的角度映射到 0~1。

### 答案解析

```hlsl
float angularGradient = atan2(centeredUV.y, centeredUV.x) / 6.28318 + 0.5;
```

`atan2(y, x)` 返回向量 (x, y) 与 x 轴的夹角，范围 -π~π；`/ 6.28318`（即 2π）映射到 -0.5~0.5；`+ 0.5` 平移到 0~1。这样绕中心一圈正好扫过整个 0~1，颜色形成一圈彩虹般的渐变。

试着把 `atan2(centeredUV.y, centeredUV.x)` 改成 `atan2(centeredUV.x, centeredUV.y)`，角度起点会旋转 90 度。

## 6. 【小灶解析】专家补充

### ① 渐变 = 数值场 + lerp

四种渐变看似不同，结构完全一样：**先算出一个 0~1 的数值场，再 `lerp(colorA, colorB, 数值场)`**。区别只在数值场怎么算。掌握了这个结构，你可以自己发明第 N 种渐变。

### ② atan2 是「角度坐标」

`atan2(y, x)` 把二维坐标转换成「绕原点的角度」。配合 `length`（距离），你就能把任何点表示成「角度 + 距离」的极坐标。极坐标是画扇形、螺旋、雷达扫描的基础。

### ③ _Time 是内置动画开关

`_Time` 是 Unity 内置的 4 维时间变量：`_Time.y` 是秒。任何「想让它动起来」的数值，加上 `_Time.y` 再配合 `frac`/`sin` 就能循环。**动画 = 静态图案 + 时间偏移**，记住这句话。
