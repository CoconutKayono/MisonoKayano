# 第 58 课 · 波点

> 学习目标：在每个格子里画一个圆点，做出规律的波点阵。

波点 = 分格 + 每格局部坐标 + 距离场画圆。

---

## 1. 完整代码

```hlsl
Shader "Lesson/58_DotPattern"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float dotCount = 8.0;

                float2 cellUV = frac(IN.uv * dotCount) - 0.5;   // 每格局部坐标，居中
                float distanceToCellCenter = length(cellUV);
                float dotMask = 1.0 - smoothstep(0.18, 0.19, distanceToCellCenter);

                float3 darkColor = float3(0.1, 0.1, 0.12);
                float3 lightColor = float3(0.85, 0.9, 1.0);
                float3 color = lerp(darkColor, lightColor, dotMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是 8×8 的浅色圆点阵，圆点边缘柔和。

---

## 2. 分格 + 居中

```hlsl
float2 cellUV = frac(IN.uv * dotCount) - 0.5;
```

`IN.uv * 8.0` 把画面分成 8×8 的格子，`frac` 取每格内的局部坐标（0~1），`- 0.5` 把原点移到格子中心，范围变成 -0.5~0.5。

---

## 3. 距离场画圆点

```hlsl
float distanceToCellCenter = length(cellUV);
float dotMask = 1.0 - smoothstep(0.18, 0.19, distanceToCellCenter);
```

`length(cellUV)` 是像素到格子中心的距离。`smoothstep(0.18, 0.19, 距离)` 在半径 0.18~0.19 之间从 0 平滑过渡到 1，`1.0 - ...` 反转：圆内为 1、圆外为 0、边缘柔和。这正是第 16 课画圆的思路，只不过圆被复制到了每个格子里。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 波点变大变稀疏 | `dotCount` 从 `8.0` 改成 `4.0` |
| 圆点变大 | `smoothstep(0.18, 0.19, ...)` 改成 `smoothstep(0.25, 0.26, ...)` |
| 圆点变硬边 | `smoothstep(0.18, 0.19, ...)` 改成 `step(0.2, ...)` |
| 圆点偏移到格子一角 | 去掉 `- 0.5` |

## 5. 练习

练习代码里 `dotMask = 0.0`。改成正确表达式，让画面出现 8×8 的圆点阵。

### 答案解析

```hlsl
float dotMask = 1.0 - smoothstep(0.18, 0.19, distanceToCellCenter);
```

`length(cellUV)` 是像素到格子中心的距离，`smoothstep(0.18, 0.19, ...)` 在圆点边缘做平滑过渡，`1.0 - ...` 让圆内为 1。初始 `dotMask = 0.0` 让画面全深色。

试着把 `distanceToCellCenter` 换成 `abs(cellUV.x) + abs(cellUV.y)`，圆点会变成菱形。

## 6. 【小灶解析】专家补充

### ① 图案 = 基础形状 + 分格复制

圆点、方块、十字，任意「基础形状」加上「分格（frac + floor）」就能复制成满屏图案。**先在一个格子里画对，再乘个系数铺满全屏**，是程序化纹理的核心工作流。

### ② smoothstep 负责抗锯齿

`smoothstep(0.18, 0.19, ...)` 的两个阈值相差极小（0.01），圆点边缘有约 1 像素宽的柔和过渡，消除了锯齿。**任何「硬边形状」都能用这个手法做抗锯齿**。

### ③ 距离场的「形状替换」

第 16 课的圆用 `length`、本课的圆用 `length`、第 62 课的方块用 `max(abs)`、菱形用 `abs 相加`。**换了距离函数，形状就换了**——这是 SDF（有向距离场）思想在 2D 图案里的直接应用。
