# 第 54 课 · 垂直条纹

> 学习目标：把第 53 课的 y 换成 x，条纹就从水平变垂直。

垂直条纹只关心 x：`frac(uv.x * 数量)` 让条纹沿水平方向重复。

---

## 1. 完整代码

```hlsl
Shader "Lesson/54_VerticalStripes"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float stripeCount = 12.0;

                float stripePattern = frac(IN.uv.x * stripeCount);
                float stripeMask = step(0.5, stripePattern);

                float3 darkColor = float3(0.2, 0.1, 0.3);
                float3 lightColor = float3(1.0, 0.8, 0.9);
                float3 color = lerp(darkColor, lightColor, stripeMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是纵向的深浅交替条纹。

---

## 2. 为什么只看 x

`IN.uv.x` 沿水平方向从 0 增到 1，同一竖直线上的所有像素 x 值相同。所以「按 x 值着色」得到垂直条纹——每条纹路沿竖直方向延伸、沿水平方向重复。

---

## 3. frac + step 制造重复

```hlsl
float stripePattern = frac(IN.uv.x * stripeCount);
float stripeMask = step(0.5, stripePattern);
```

`IN.uv.x * 12.0` 把 x 拉伸成 0~12，`frac` 折叠成 12 段 0~1 的锯齿波，每段是一条深 + 一条浅。`step(0.5, ...)` 把每段切成左右两半，形成硬边条纹。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 条纹变粗 | `stripeCount` 从 `12.0` 改成 `6.0` |
| 条纹变细 | `stripeCount` 从 `12.0` 改成 `24.0` |
| 深色条变窄、浅色条变宽 | `step(0.5, ...)` 改成 `step(0.3, ...)` |
| 变对角条纹 | `IN.uv.x` 改成 `IN.uv.x + IN.uv.y` |

---

## 5. 练习

练习代码里 `stripePattern = 0.0`。改成正确表达式，让画面出现 12 条垂直条纹。

### 答案解析

```hlsl
float stripePattern = frac(IN.uv.x * stripeCount);
```

`IN.uv.x * 12.0` 把水平坐标拉伸成 0~12，`frac` 折叠成 12 段循环。初始 `stripePattern = 0.0` 让 `step` 恒为 0，画面全深色。

试着把 `step(0.5, stripePattern)` 改成 `smoothstep(0.4, 0.6, stripePattern)`，硬边会变成柔和过渡。

---

## 6. 【小灶解析】专家补充

### ① 硬边 vs 软边

`step(阈值, x)` 是硬边（0 直接跳 1），`smoothstep(a, b, x)` 是软边（0 平滑过渡到 1）。**条纹的「硬边」和「柔边」就靠这两个函数切换**。抗锯齿场景下柔边更常用，因为它没有像素级突变。

### ② 横向纵向是坐标系约定

「水平条纹 / 垂直条纹」的说法依赖 UV 方向：`uv.y` 决定水平条纹、`uv.x` 决定垂直条纹。这个对应关系在不同引擎、不同 UV 展开里可能翻转，TA 要养成「先确认 UV 方向」的习惯。

### ③ 条纹是「周期函数」的最简形态

从数学上看，条纹就是一个**方波（square wave）**：`step(0.5, frac(x))` 就是标准方波。理解了这一点，正弦波（第 16 课）、三角波、方波之间的转换你就都能推导了。
