# 第 51 课 · 对角条纹

> 学习目标：把 x 和 y 坐标相加，让条纹倾斜 45 度。

水平条纹用 `uv.y`，垂直条纹用 `uv.x`；两者相加，条纹就沿对角线走。

---

## 1. 完整代码

```hlsl
Shader "Lesson/51_DiagonalStripes"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float stripeCount = 14.0;

                float diagonalFactor = frac((IN.uv.x + IN.uv.y) * stripeCount);
                float stripeMask = step(0.5, diagonalFactor);

                float3 darkColor = float3(0.1, 0.1, 0.15);
                float3 lightColor = float3(0.9, 0.85, 0.7);
                float3 color = lerp(darkColor, lightColor, stripeMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是 45 度倾斜的对角条纹。

---

## 2. 为什么相加就能倾斜

水平条纹只用 `uv.y`，垂直条纹只用 `uv.x`。两者相加 `uv.x + uv.y` 后，沿 45 度方向（左上到右下）的像素 `x+y` 值保持不变，而垂直这个方向的分量均匀变化——条纹就沿 45 度斜线排列。

---

## 3. frac 制造重复

```hlsl
float diagonalFactor = frac((IN.uv.x + IN.uv.y) * stripeCount);
float stripeMask = step(0.5, diagonalFactor);
```

`(uv.x + uv.y)` 范围是 0~2，乘 `stripeCount = 14.0` 拉伸成 0~28，`frac` 折叠成 14 段重复的 0~1 锯齿波，每段就是一对条纹。`step(0.5, ...)` 把每段切成深/浅两半，形成硬边条纹。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 条纹变宽 | `stripeCount` 从 `14.0` 改成 `6.0` |
| 倾斜方向反转（左下→右上） | `uv.x + uv.y` 改成 `uv.x - uv.y` |
| 深色条变窄、浅色条变宽 | `step(0.5, ...)` 改成 `step(0.3, ...)` |
| 条纹偏向水平 | `uv.x + uv.y` 改成 `uv.x * 2.0 + uv.y` |

---

## 5. 练习

练习代码里 `diagonalFactor = 0.0`。改成正确表达式，让画面出现 45 度倾斜的对角条纹。

### 答案解析

```hlsl
float diagonalFactor = frac((IN.uv.x + IN.uv.y) * stripeCount);
```

`IN.uv.x + IN.uv.y` 是沿对角线方向的线性坐标，范围 0~2，乘 14 后 `frac` 折叠成 14 段循环。初始 `diagonalFactor = 0.0` 让 `step` 恒为 0，画面全是深色。

试着把 `uv.x + uv.y` 改成 `uv.x * 0.5 + uv.y`，条纹角度会向垂直方向倾斜。

---

## 6. 【小灶解析】专家补充

### ① x+y 是「对角线坐标」

`x + y = 常数` 是一族**斜率为 -1 的直线**。所以「按 x+y 的值着色」就是在沿着对角线方向做渐变或分条。同理 `x - y = 常数` 是斜率 +1 的直线。**用坐标的线性组合，你就能控制条纹的任意角度**。

### ② 条纹角度公式

一般地，`dot(uv, float2(a, b))` 生成的条纹方向垂直于向量 (a, b)。`x + y` 就是 `dot(uv, float2(1, 1))`，条纹垂直于 (1,1)，即沿 -45° 方向。想精确控制角度，用这个点积写法即可。

### ③ 条纹的「占空比」

`step(0.5, ...)` 里的 0.5 决定深色条和浅色条各占多少（占空比）。改成 0.3 深色条只占 30%，浅色条占 70%。这个参数在真实项目里（比如 UI 背景、警示条纹）经常要调。
