# 第 57 课 · 颜色混合渐变

> 学习目标：用 `lerp` 做水平方向的两种颜色混合，并了解混合比例决定过渡位置。

`lerp(颜色A, 颜色B, uv.x)`：左边是颜色A，右边是颜色B。

---

## 1. 完整代码

```hlsl
Shader "Lesson/57_ColorMixGradient"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 colorA = float3(0.2, 0.6, 0.9);   // 左：青蓝
                float3 colorB = float3(0.9, 0.3, 0.6);   // 右：粉红

                float3 color = lerp(colorA, colorB, IN.uv.x);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面从左侧青蓝平滑过渡到右侧粉红。

---

## 2. lerp 的三种角色

`lerp(colorA, colorB, IN.uv.x)` 里有三个参数：混合起点 `colorA`、混合终点 `colorB`、混合比例 `IN.uv.x`。比例 0 输出起点，1 输出终点，中间线性过渡。

---

## 3. 用 uv.x 控制过渡

```hlsl
float3 color = lerp(colorA, colorB, IN.uv.x);
```

`IN.uv.x` 在屏幕左边是 0、右边是 1。左边完全取 `colorA`，右边完全取 `colorB`，中间平滑混合。这就是水平颜色混合渐变。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 变竖直渐变 | `IN.uv.x` 改成 `IN.uv.y` |
| 过渡点右移（青色占 2/3） | `IN.uv.x` 改成 `IN.uv.x * 1.5` |
| 快速过渡、两侧纯色 | 用 `smoothstep(0.3, 0.7, IN.uv.x)` 代替 `IN.uv.x` |
| 反向 | 交换 `colorA` 和 `colorB` |

---

## 5. 练习

练习代码里 `color = colorA`。改成正确表达式，让画面从左侧青蓝渐变到右侧粉红。

### 答案解析

```hlsl
float3 color = lerp(colorA, colorB, IN.uv.x);
```

`IN.uv.x` 从 0 到 1 扫过整个屏幕，作为 `lerp` 的混合比例，让颜色从左侧青蓝过渡到右侧粉红。初始 `color = colorA` 恒定，没有渐变。

试着把 `IN.uv.x` 换成 `frac(IN.uv.x * 2.0)`，渐变会在屏幕上重复出现两次。

---

## 6. 【小灶解析】专家补充

### ① 混合比例可以「超出」0~1

`lerp` 的比例 t 其实允许超过 0~1：`t > 1` 会「越过」终点继续外插，`t < 0` 会反向外插。这不是 bug，而是特性——有时你会故意用它做「过冲」效果。

### ② 渐变方向 = 你选的坐标

第 56 课用 `uv.y` 做竖直渐变，本课用 `uv.x` 做水平渐变。**渐变只是「把某个坐标塞进 lerp 的第三个参数」**，选哪个坐标就是哪个方向。

### ③ 多种渐变可以组合

真实项目里很少只用两种颜色。可以用多个 `lerp` 嵌套做出多段渐变：先 `lerp(A, B, t1)` 再 `lerp(结果, C, t2)`。三色、四色渐变的本质就是「多次两两混合」。
