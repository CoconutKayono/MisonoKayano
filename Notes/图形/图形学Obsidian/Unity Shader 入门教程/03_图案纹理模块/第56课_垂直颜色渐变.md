# 第 56 课 · 垂直颜色渐变

> 学习目标：用 `lerp` 在两种颜色之间做竖直方向的平滑过渡。

`lerp(下颜色, 上颜色, uv.y)`：y=0 是下颜色，y=1 是上颜色。

---

## 1. 完整代码

```hlsl
Shader "Lesson/56_VerticalGradient"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 bottomColor = float3(0.05, 0.1, 0.3);   // 底部深蓝
                float3 topColor = float3(1.0, 0.6, 0.4);       // 顶部暖橙

                float3 color = lerp(bottomColor, topColor, IN.uv.y);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面从底部的深蓝平滑渐变到顶部的暖橙。

---

## 2. lerp 是什么

`lerp(A, B, t)` 按比例 t 混合 A 和 B：`t=0` 输出 A，`t=1` 输出 B，`t=0.5` 输出两者的中点。

---

## 3. 用 uv.y 当混合比例

```hlsl
float3 color = lerp(bottomColor, topColor, IN.uv.y);
```

`IN.uv.y` 在屏幕底部是 0、顶部是 1，作为混合比例 t：底部完全取 `bottomColor`，顶部完全取 `topColor`，中间平滑过渡。这就是竖直渐变。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 变水平渐变 | `IN.uv.y` 改成 `IN.uv.x` |
| 渐变反向（顶部深蓝底部暖橙） | 交换 `bottomColor` 和 `topColor` |
| 三色渐变（需两次 lerp） | 先 `lerp(A, B, uv.y*2)` 再 `lerp(B, C, uv.y*2-1)` |
| 加入中间停顿 | 用 `smoothstep(0.3, 0.7, IN.uv.y)` 代替 `IN.uv.y` |

---

## 5. 练习

练习代码里 `color = bottomColor`。改成正确表达式，让画面从底部深蓝渐变到顶部暖橙。

### 答案解析

```hlsl
float3 color = lerp(bottomColor, topColor, IN.uv.y);
```

`IN.uv.y` 从 0 到 1 扫过整个屏幕，作为 `lerp` 的混合比例，让颜色从底部到底部一路过渡。初始 `color = bottomColor` 恒定不变，没有渐变。

试着把 `IN.uv.y` 换成 `IN.uv.y * IN.uv.y`，渐变会变得「上重下轻」，顶部区域变化更快。

---

## 6. 【小灶解析】专家补充

### ① lerp 是颜色世界的「万能胶」

几乎所有颜色过渡、混合、遮罩都用 `lerp`。你之前学的 `step`/`smoothstep` 生产「混合比例」，`lerp` 负责「按比例混合」——两者配合就能做任何颜色效果。TA 一天要写几十次 `lerp`。

### ② 用 uv 当参数 = 用位置驱动颜色

渐变就是把**坐标（位置）**直接当成 `lerp` 的参数。y 是竖直渐变、x 是水平渐变、`length(uv-0.5)` 是径向渐变（第 59 课）。**「位置 → 参数 → 颜色」**是最常见的着色思路。

### ③ 渐变是「线性插值」的直观例子

`lerp` 数学上就是线性插值 `A + (B-A)*t`。它不只是颜色工具，任何两个数值（高度、速度、密度）之间都能 lerp。这是图形学里使用频率最高的函数，没有之一。
