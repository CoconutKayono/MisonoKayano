# 第 05 课 · 对角线因子

> 学习目标：构造 `(uv.x + uv.y) / 2` 的对角线因子并可视化。

水平方向用 `uv.x`，垂直方向用 `uv.y`。把它们加起来除以 2，就得到对角线方向的渐变因子。

---

## 1. 完整代码

```hlsl
Shader "Lesson/05_Diagonal"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float diagonalFactor = (IN.uv.x + IN.uv.y) * 0.5;   // ★ 对角线因子
                return half4(diagonalFactor, diagonalFactor, diagonalFactor, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 05_Diagonal`。你会看到从**左下角（黑）到右上角（白）**的对角线渐变。

---

## 2. 构造对角线因子

```hlsl
float diagonalFactor = (IN.uv.x + IN.uv.y) * 0.5;
```

两个分量相加取平均：

| 位置 | IN.uv.x | IN.uv.y | diagonalFactor（平均） |
|------|---------|---------|-----------|
| 左下角 | 0.0 | 0.0 | 0.0 |
| 右上角 | 1.0 | 1.0 | 1.0 |
| 左上角 | 0.0 | 1.0 | 0.5 |
| 右下角 | 1.0 | 0.0 | 0.5 |

结果是从左下角（黑）到右上角（白）的对角线渐变，两侧中间值是灰色。

---

## 3. 试着改一改

| 效果 | 写法 |
|------|------|
| 乘法版本（只有右上角亮，其余都偏黑） | `float diagonalFactor = IN.uv.x * IN.uv.y;` |
| 反向对角线（左下白、右上黑） | `float diagonalFactor = 1.0 - (IN.uv.x + IN.uv.y) * 0.5;` |
| 只保留红色通道 | `return half4(diagonalFactor, 0.0, 0.0, 1.0);` |

---

## 4. 练习

练习代码里 `diagonalFactor = 0.0`（全黑）。把 `diagonalFactor` 改成 `(IN.uv.x + IN.uv.y) * 0.5`，让画面出现对角线渐变。

初始状态：

```hlsl
half4 frag (Varyings IN) : SV_Target
{
    float diagonalFactor = 0.0;         // 全黑
    return half4(diagonalFactor, diagonalFactor, diagonalFactor, 1);
}
```

### 答案解析

```hlsl
float diagonalFactor = (IN.uv.x + IN.uv.y) * 0.5;
```

`IN.uv.x + IN.uv.y` 范围是 0 到 2，乘以 0.5 缩回 0 到 1。

这个因子不是严格的对角线（左上和右下的值相同），但视觉上就是对角线方向的渐变。

进阶：试试 `diagonalFactor = IN.uv.x * IN.uv.y`，看看乘法和加法的区别（乘法里，任何一个分量为 0，结果就是 0，所以只有右上角最亮）。

---

## 5. 【小灶解析】专家补充

### ① 为什么「相加取平均」就是对角线：等值线

`(x + y) / 2` 是一个「随 x 和 y 同步增长」的量。想象物体表面：沿着左下→右上的方向，x 和 y 一起增大，`diagonalFactor` 单调上升；而沿着左上↔右下的方向，一个增大一个减小，加起来刚好抵消，`diagonalFactor` 保持不变。

所以 `diagonalFactor` 相等的那些点（**等值线**），正好是一条条垂直于对角线的平行线——这就是「对角线渐变」的几何本质。等值线的思路后面做形状、做距离场都会反复用到。

### ② 加法 vs 乘法：两个完全不同的「组合」逻辑

- `(x + y) * 0.5`：**互补**。x 小的时候 y 能补上，所以左上、右下都是中等灰度 0.5。
- `x * y`：**门槛**。必须两个都大结果才大，任何一个为 0 结果就是 0，所以只有右上角 (1,1) 是白，其余两角都是黑。

乘法这个「任何一个为 0 就全灭」的特性，正是后面做**遮罩（masking）**的基础——用一张 0/1 的图去乘，就能把不需要的区域「抹掉」。

### ③ 对角线因子其实是「点积」的雏形

把 `(x + y) * 0.5` 换个写法：`dot(uv, float2(0.5, 0.5))`——也就是 uv 和方向 (1,1)（归一化后）做**点积**。点积衡量「一个向量在另一个方向上的投影长度」。

这是本课最值得记住的伏笔：**「取某一方向上的渐变」=「和那个方向做点积」**。后面讲光照时，「光线方向和法线做点积算亮度」用的就是同一个数学工具，只是方向从 (1,1) 换成了光线方向。

### ④ 不一定非要「平均」：加权混合

`* 0.5` 是平均，但你可以换成任意权重，比如 `x * 0.7 + y * 0.3`，让渐变更偏水平方向。这种「按比例混合两个值」的操作，后面有个专门的内置函数叫 `lerp(a, b, t)`，它俩是一回事——你现在已经在手动做混合了。

### ⑤ 为什么要缩回 0~1

`x + y` 最大是 2，除以 2 才缩回 0~1。这个「把结果映射回 0~1」的习惯贯穿整个 Shader 学习：颜色、亮度、比例，几乎都要求落在 0~1。超出这个区间不是不能用，但会失去控制——正如第 03 课 clamp 讲的，0~1 是 Shader 计算的「通用货币」。
