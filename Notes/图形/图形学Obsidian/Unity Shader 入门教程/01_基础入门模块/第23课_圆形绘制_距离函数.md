# 第 23 课 · 圆形绘制（距离函数）

> 学习目标：用圆形遮罩做「形状选择」，在背景色与前景色之间切换。

把圆形遮罩当成一个「选择器」：遮罩为 1 的地方显示前景色，为 0 的地方显示背景色。用 `lerp` 完成。

---

## 1. 完整代码

```hlsl
Shader "Lesson/23_CircleMask"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;
                float distanceToCenter = length(centeredUV);
                float circleMask = 1.0 - step(0.3, distanceToCenter);

                float3 backgroundColor = float3(0.06, 0.07, 0.1);   // 背景色（深）
                float3 foregroundColor = float3(0.2, 0.85, 1.0);    // 前景色（亮蓝）

                float3 color = lerp(backgroundColor, foregroundColor, circleMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 23_CircleMask`。深色背景上有一个亮蓝色圆。

---

## 2. 圆形遮罩

```hlsl
float2 centeredUV = IN.uv - 0.5;
float distanceToCenter = length(centeredUV);
float circleMask = 1.0 - step(0.3, distanceToCenter);
```

`circleMask` 在圆内是 1、圆外是 0。这就是一个「二值遮罩」。

---

## 3. 用遮罩选择颜色

```hlsl
float3 color = lerp(backgroundColor, foregroundColor, circleMask);
```

- `circleMask = 0`（圆外）：`lerp` 结果 = `backgroundColor`（背景色）
- `circleMask = 1`（圆内）：`lerp` 结果 = `foregroundColor`（前景色）

遮罩把画面分成了「圆内/圆外」两个区域，分别填上不同颜色。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 更大的圆 | 把半径 `0.3` 改成 `0.45` |
| 换个前景色 | 把 `foregroundColor` 改成别的颜色，如 `float3(1.0, 0.5, 0.1)` |
| 圆外亮、圆内暗 | 把 `lerp(backgroundColor, foregroundColor, circleMask)` 改成 `lerp(foregroundColor, backgroundColor, circleMask)` |

## 5. 练习

练习代码里 `color = backgroundColor`（全背景色）。计算圆形遮罩 `circleMask`，并用 `lerp` 在背景和前景之间选择。

### 答案解析

```hlsl
float circleMask = 1.0 - step(0.3, distanceToCenter);
float3 color = lerp(backgroundColor, foregroundColor, circleMask);
```

`circleMask` 是 0/1 的二值遮罩，作为 `lerp` 的因子时，0 端取 `backgroundColor`、1 端取 `foregroundColor`。这是「遮罩选色」的最基础形态。

注意：如果想让圆的边缘抗锯齿，把 `step` 换成 `smoothstep` 即可（下一课《平滑边缘》会展开）。

---

## 6. 【小灶解析】专家补充

### ① 遮罩 = 选择器

这一课的核心思想是：**遮罩不是颜色，而是一个 0~1 的「开关/权重」，用来在两个（或多个）颜色之间做选择**。把「形状」和「颜色」解耦，是程序化绘制的关键一步——形状管「哪里」，颜色管「什么」。

### ② 二值遮罩 vs 连续遮罩

`step` 产生的是 0/1 二值遮罩（硬边），`smoothstep` 产生的是 0~1 连续遮罩（软边）。用二值遮罩做 lerp 是「跳变」，用连续遮罩做 lerp 是「渐变」。什么时候用哪个，取决于你要硬边还是软边。

### ③ 遮罩可以任意组合

这个「遮罩 → lerp」的模板可以无限扩展：多个遮罩相乘、相加、相减，就能拼出复杂图形。第 30 课《形状组合》就是它的延伸。**先练熟「一个遮罩选一个颜色」，再学「多个遮罩拼一个图形」**。
