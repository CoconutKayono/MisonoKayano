# 第 12 课 · UV 可视化

> 学习目标：把 UV 坐标直接转成颜色，看见 UV 的「地图」。

`IN.uv` 是归一化坐标，范围 0 到 1。把它直接映射成颜色，就能「看见」UV 坐标长什么样。

---

## 1. 完整代码

```hlsl
Shader "Lesson/12_UVVisualize"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 color = float3(IN.uv, 0.0);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 12_UVVisualize`。你会看到一张四角颜色不同的「色块图」——这就是 UV 坐标的地图。

---

## 2. 怎么把 UV 变成颜色

`float3` 需要三个分量（红、绿、蓝），而 `IN.uv` 只有两个（x、y）。补一个固定的蓝色值就够了：

```hlsl
float3 color = float3(IN.uv, 0.0);
// 等价于 float3(IN.uv.x, IN.uv.y, 0.0)
```

这样：

- `uv.x` 控制红色：左边红 = 0，右边红 = 1
- `uv.y` 控制绿色：下边绿 = 0，上边绿 = 1
- 蓝色固定为 0

---

## 3. 四个角的颜色

| 位置 | IN.uv | 颜色 |
|------|-------|------|
| 左下角 | (0.0, 0.0) | 黑色 |
| 右下角 | (1.0, 0.0) | 红色 |
| 左上角 | (0.0, 1.0) | 绿色 |
| 右上角 | (1.0, 1.0) | 黄色 |

（红 + 绿 = 黄，所以右上角是黄色。）

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 红固定 0，绿蓝由 UV 控制 | `float3(0.0, IN.uv)` |
| 红蓝对调 | `float3(IN.uv.y, 0.0, IN.uv.x)` |
| 只看 x 分量（灰度） | `float3(IN.uv.x, IN.uv.x, IN.uv.x)` |

## 5. 练习

练习代码的 color 是 `float3(0.0, 0.0, 0.0)`（黑色）。修改它，用 `IN.uv` 输出上面描述的 UV 颜色图。

初始状态：

```hlsl
half4 frag (Varyings IN) : SV_Target
{
    float3 color = float3(0.0, 0.0, 0.0);
    return half4(color, 1);
}
```

### 答案解析

```hlsl
float3 color = float3(IN.uv, 0.0);
```

`float3(IN.uv, 0.0)` 把 `IN.uv`（一个 `float2`）展开成 `float3` 的前两个分量，第三个分量（蓝色）设为 0。

这是 HLSL 的构造函数拼接——用更小的向量拼成更大的向量：`float3(IN.uv, 0.0)` = `float3(IN.uv.x, IN.uv.y, 0.0)`。

进阶：试试改成 `float3(0.0, IN.uv)` 或 `float3(IN.uv.y, 0.0, IN.uv.x)`，看颜色怎么变。

---

## 6. 【小灶解析】专家补充

### ① float3(float2, 标量) 的构造器拼接

HLSL 允许用小向量拼大向量：`float3(IN.uv, 0.0)` 就是「float2 + 标量 = float3」。这是**重组通道**的常用手法——交换红蓝、灰度化、把某个通道换成别的数据，全靠它。

### ② 为什么要「看见」UV：这是 Shader 的调试器

Shader 里不能下断点、不能 printf。于是最朴素的调试手段就是：**把任何中间量输出成颜色，用眼睛看它**。UV 可视化是第一次示范这个思路。后面可视化法线、深度、世界坐标，用的都是同一招。

### ③ 「分量」思维

你已经把 `uv.x` 当「红色强度」、`uv.y` 当「绿色强度」了。这培养的是「把任意数据映射到颜色通道」的直觉——这是 TA 看画面、读 Shader 的基本功。

### ④ UV 地图是「连续」的

四角只是特殊值；中间每一点都是这两个分量的连续渐变。理解「UV 是一张平滑的场」，是后面用 UV 做图案、做光照、做扰动的心理模型。
