# 第 17 课 · 对角线渐变（综合练习）

> 学习目标：用对角线因子 + `clamp` + `lerp` 完成一个带颜色的对角线渐变。

这是模块二的综合练习。回顾三个步骤：构造因子 → clamp 限制范围 → lerp 映射颜色。

---

## 1. 完整代码

```hlsl
Shader "Lesson/17_DiagonalGradient"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 colorA = float3(0.1, 0.15, 0.25);   // 深蓝
                float3 colorB = float3(1.0, 0.6, 0.15);    // 橙

                float diagonalFactor = (IN.uv.x + IN.uv.y) * 0.5;   // ① 构造因子
                diagonalFactor = clamp(diagonalFactor, 0.0, 1.0);   // ② 限制范围
                float3 color = lerp(colorA, colorB, diagonalFactor); // ③ 映射颜色
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

左下角深蓝，右上角橙色，对角方向渐变。

---

## 2. 回顾：三个步骤

**① 构造因子**——把 x 和 y 分量合并成一个 0~1 的值：

```hlsl
float diagonalFactor = (IN.uv.x + IN.uv.y) * 0.5;
```

**② 用 clamp 限制范围**——确保因子不会超出 0~1：

```hlsl
diagonalFactor = clamp(diagonalFactor, 0.0, 1.0);
```

**③ 用 lerp 映射颜色**：

```hlsl
float3 color = lerp(colorA, colorB, diagonalFactor);
```

---

## 3. 为什么需要 clamp

`(IN.uv.x + IN.uv.y) * 0.5` 的最大值是 1.0（两个坐标都是 1.0 时），最小值是 0.0，所以这里其实不会超界。但在更复杂的情况下，因子可能超出范围，**`clamp` 是好习惯**——它保证无论输入多大多小，输出都落在 0~1。

---

## 4. 练习

练习代码里 `diagonalFactor = 0.0`，三个步骤的 TODO 都等你填写。按顺序完成：构造因子 → clamp → 得到颜色。

### 答案解析

```hlsl
float diagonalFactor = (IN.uv.x + IN.uv.y) * 0.5;
diagonalFactor = clamp(diagonalFactor, 0.0, 1.0);
float3 color = lerp(colorA, colorB, diagonalFactor);
```

`clamp(diagonalFactor, 0.0, 1.0)` 把因子限制在 0~1；`lerp(colorA, colorB, diagonalFactor)` 用它在深蓝和橙色之间插值——左下角是 colorA（深蓝），右上角是 colorB（橙色）。

进阶：改变因子的计算方式，比如 `diagonalFactor = IN.uv.x * IN.uv.y`，看渐变形状会怎么变。

---

## 5. 【小灶解析】专家补充

### ① 「因子 + clamp + lerp」是一条万能流水线

本课把前面几课串成了一条清晰的 pipeline：**先算出因子（可以是任何数学），再 clamp 到 0~1，最后 lerp 映射颜色**。这条流水线能表达几乎所有「数值 → 颜色」的效果，建议你把它当成一个固定的心智模板。

### ② clamp 的「防御性」价值

本课因子天然不会超界，为什么还 clamp？因为实际项目里，因子常常来自会波动的数据（光照、时间、噪声），写 clamp 是在「主动声明边界」。这和第 03 课小灶 ① 一个道理：可控 > 侥幸。

### ③ 乘法因子 vs 加法因子

`x * y` 是「门槛型」（任何一个为 0 结果就为 0），`(x+y)/2` 是「互补型」。练习里的进阶提示就是让你体会这个差别——回顾第 05 课小灶 ②。
