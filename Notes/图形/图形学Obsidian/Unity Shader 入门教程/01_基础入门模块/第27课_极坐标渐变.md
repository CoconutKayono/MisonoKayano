# 第 27 课 · 极坐标渐变（角度）

> 学习目标：用 `atan2` 计算角度，把角度映射成渐变颜色。

除了用位置（x、y、距离）做渐变，还可以用**角度**。角度由 `atan2` 计算。

---

## 1. 完整代码

```hlsl
Shader "Lesson/27_PolarGradient"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 colorA = float3(0.1, 0.15, 0.25);   // 深蓝
                float3 colorB = float3(1.0, 0.6, 0.15);    // 橙

                float2 centeredUV = IN.uv - 0.5;
                float angle = atan2(centeredUV.y, centeredUV.x);   // 角度（-π ~ π）

                float angleFactor = (angle + 3.14159265) / 6.2831853;   // 映射到 0~1
                float3 color = lerp(colorA, colorB, angleFactor);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 27_PolarGradient`。颜色绕中心一圈渐变，呈现「极坐标」分布。

---

## 2. 计算角度

```hlsl
float angle = atan2(centeredUV.y, centeredUV.x);
```

`atan2(y, x)` 返回点 (x, y) 相对原点的角度，范围是 **-π ~ π**（约 -3.14 ~ 3.14）。这是 HLSL 里的二参反正切函数。

---

## 3. 把角度映射到 0~1

```hlsl
float angleFactor = (angle + 3.14159265) / 6.2831853;
```

`angle` 在 -π ~ π，加上 π 后变成 0 ~ 2π，再除以 2π 就归一化到 0~1，可以直接当 `lerp` 的因子。

`3.14159265` 是 π，`6.2831853` 是 2π。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 更丰富的循环渐变 | 把 `angleFactor` 换成 `frac(angleFactor * 3.0)`（绕三圈） |
| 从中心向外辐射 | 改成 `float angleFactor = length(centeredUV) * 2.0;` |
| 只留一半角度 | 把 `6.2831853` 改成 `3.14159265` |

---

## 5. 练习

练习代码里 `angleFactor = 0.0`（全 colorA）。用 `atan2` 计算角度并归一化到 0~1。

### 答案解析

```hlsl
float angle = atan2(centeredUV.y, centeredUV.x);
float angleFactor = (angle + 3.14159265) / 6.2831853;
```

`atan2(centeredUV.y, centeredUV.x)` 得到 -π~π 的角度。加 π 平移、除以 2π 归一化后得到 0~1 的 `angleFactor`，再用 `lerp` 映射颜色。

试试 `angleFactor = frac(angleFactor * 3.0)`：`frac` 让渐变重复 3 次，形成「三等分的扇形」效果——这是极坐标图案（风车、雷达、色环）的基础。

---

## 6. 【小灶解析】专家补充

### ① 极坐标 = 距离 + 角度

笛卡尔坐标用 (x, y) 定位，极坐标用 (距离 r, 角度 θ) 定位。`length(centeredUV)` 得到 r，`atan2(centeredUV.y, centeredUV.x)` 得到 θ。**掌握了这两个函数，你就有了「极坐标系」这个新画布**——圆环、螺旋、风车、雷达图，全在这个坐标系里诞生。

### ② HLSL 里计算角度用 atan2

HLSL 计算「点相对原点的角度」用 **`atan2(y, x)`**，返回范围 -π~π。注意参数顺序是 **y 在前、x 在后**（不是 x 在前），写反了渐变方向会出错，务必记住。

### ③ 角度归一化是固定套路

`(angle + PI) / TWO_PI` 把 -π~π 的角度变成 0~1，是极坐标编程里最高频的一行代码。Unity 里其实有内置常量 `UNITY_PI`、`UNITY_TWO_PI`（在 Core.hlsl 里），可以写成 `(angle + UNITY_PI) / UNITY_TWO_PI`，更清晰也不用背小数。
