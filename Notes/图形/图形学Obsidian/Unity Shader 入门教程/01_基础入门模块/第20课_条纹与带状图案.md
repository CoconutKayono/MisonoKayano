# 第 20 课 · 条纹与带状图案

> 学习目标：使用 `frac` 与 `step` 构造重复的条纹图案，并用 `lerp` 在两种颜色之间切换。

`frac` 把坐标在 0~1 范围内重复多次，`step` 把每次重复分成两半——这是制造条纹的基本方法。

---

## 1. 完整代码

```hlsl
Shader "Lesson/20_Stripes"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 colorA = float3(0.1, 0.12, 0.2);     // 深蓝
                float3 colorB = float3(0.95, 0.95, 1.0);    // 近白

                float stripeCount = 12.0;
                float repeatedX = frac(IN.uv.x * stripeCount);   // 每段 0~1 重复
                float stripeMask = step(0.5, repeatedX);          // 分两半

                float3 color = lerp(colorA, colorB, stripeMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 20_Stripes`。你会看到 12 条等宽的竖直条纹。

---

## 2. frac 制造重复

```hlsl
float repeatedX = frac(IN.uv.x * stripeCount);
```

`IN.uv.x * 12.0` 把 0~1 拉伸到 0~12。`frac` 取小数部分，相当于每隔 1 重置一次——把整个画面分成 12 段，每段内 `repeatedX` 都是 0~1。

---

## 3. step 分两半

```hlsl
float stripeMask = step(0.5, repeatedX);
```

每段内，`repeatedX < 0.5` 时遮罩为 0（colorA），`repeatedX >= 0.5` 时遮罩为 1（colorB）。结果就是等宽的交替条纹。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 更细更密的条纹 | 把 `stripeCount` 改成 `24.0` |
| colorA 占 30%、colorB 占 70% | 把阈值改成 `step(0.3, repeatedX)` |
| 水平条纹 | 把 `IN.uv.x` 改成 `IN.uv.y` |
| 对角条纹 | 把 `IN.uv.x` 改成 `(IN.uv.x + IN.uv.y) * 0.5` |

---

## 5. 练习

练习代码里 `stripeCount = 8.0`（8 条纹）。把 `stripeCount` 改成 `12.0`，让条纹数量和参考图一致。

### 答案解析

```hlsl
float stripeCount = 12.0;
float repeatedX = frac(IN.uv.x * stripeCount);
float stripeMask = step(0.5, repeatedX);
```

`stripeCount` 越大，条纹越细越密。`step(0.5, repeatedX)` 的阈值 0.5 让两种颜色宽度相等；改成 `step(0.3, repeatedX)` 则 colorA 占 30%、colorB 占 70%。

把 `IN.uv.x` 换成 `IN.uv.y` 得到水平条纹，换成 `(IN.uv.x + IN.uv.y) * 0.5` 得到对角条纹。

---

## 6. 【小灶解析】专家补充

### ① frac 的「重复」本质

第 06 课网格线用的是 `frac`，这里条纹用的还是 `frac`——它们共享同一个「重复」技巧。**想制造周期性图案，第一步永远是把坐标放大 N 倍再取小数**。这是程序化纹理（棋盘格、砖墙、波点）的地基。

### ② step 阈值 = 占空比

`step(0.5, repeatedX)` 里的 0.5 是「占空比」——colorB 占据的比例。改成 0.3，colorB 就只占 30%。这是做「宽条纹/细条纹」最简单的旋钮，也是 PWM（脉冲宽度调制）思想的雏形。

### ③ 条纹方向 = 你喂给 frac 的那个量

喂 `uv.x` 得到竖条纹，喂 `uv.y` 得到横条纹，喂对角线因子得到斜条纹。**条纹的方向，取决于你「重复」的是哪个方向的分量**。这和第 05 课「对角线因子」是同一个道理。
