# 第 07 课 · 水平渐变（两色混合）

> 学习目标：使用 `uv.x` 与 `lerp()` 创建从左到右的两色渐变。

之前我们一直在做「黑白灰」渐变（三个通道同一个值）。这一课引入真正的**颜色**：用 `lerp` 在两种颜色之间平滑过渡。

---

## 1. 完整代码

```hlsl
Shader "Lesson/07_TwoColorGradient"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 colorA = float3(0.15, 0.2, 0.95);   // 深蓝
                float3 colorB = float3(1.0, 0.6, 0.15);    // 橙

                float blendFactor = IN.uv.x;               // 左 0 右 1
                float3 color = lerp(colorA, colorB, blendFactor);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 07_TwoColorGradient`。左边深蓝、右边橙，中间平滑过渡。

---

## 2. 渐变因子

`lerp(colorA, colorB, blendFactor)` 里的 `blendFactor` 决定颜色偏向哪边。把 `uv.x` 当 `blendFactor`，左边是颜色 A，右边是颜色 B：

```hlsl
float blendFactor = IN.uv.x;            // 左边 0.0，右边 1.0
float3 color = lerp(colorA, colorB, blendFactor);
```

注意：HLSL 里「线性插值」函数叫 **`lerp`**（Linear interpolation），公式是 `colorA * (1 - blendFactor) + colorB * blendFactor`。当 `blendFactor = 0` 得到 colorA，`blendFactor = 1` 得到 colorB，中间按比例混合。

---

## 3. 示例颜色

代码里两种颜色是：

- `colorA = float3(0.15, 0.2, 0.95)` — 深蓝色
- `colorB = float3(1.0, 0.6, 0.15)` — 橙色

## 5. 练习

练习代码里因子 `blendFactor` 被设成了 0.0（画面全是颜色 A）。把 `blendFactor` 改成 `IN.uv.x`，让颜色从左到右渐变。

初始状态：

```hlsl
half4 frag (Varyings IN) : SV_Target
{
    float3 colorA = float3(0.15, 0.2, 0.95);
    float3 colorB = float3(1.0, 0.6, 0.15);
    float blendFactor = 0.0;            // 全是颜色 A
    float3 color = lerp(colorA, colorB, blendFactor);
    return half4(color, 1);
}
```

### 答案解析

```hlsl
float blendFactor = IN.uv.x;
```

就改这一行。`IN.uv.x` 在左边是 0、右边是 1，`lerp` 用它在两色间平滑插值。

进阶：把 `blendFactor = IN.uv.x` 改成 `blendFactor = 1.0 - IN.uv.x`，渐变方向会反过来。

---

## 6. 【小灶解析】专家补充

### ① lerp 是「加权平均」的官方版

第 05 课我们手动写过 `x * 0.7 + y * 0.3`，那其实就是 lerp 的特例。`lerp` 是 HLSL 里使用频率最高的函数之一——颜色混合、动画插值、材质混合、渐变色，全都靠它。

### ② 颜色是向量：插值是逐通道的

`float3` 的 lerp 是每个通道各自独立插值（R 对 R、G 对 G、B 对 B）。所以「混合两个颜色」本质上就是「分别混合它们的三个分量」。理解这一点，你就明白为什么 `lerp` 对 float2/float3/float4 都能用。

### ③ lerp 的混合因子可以不只在 0~1

`blendFactor < 0` 或 `blendFactor > 1` 时会发生「外插（extrapolate）」，颜色会超出 colorA~colorB 的范围——可能得到比 colorA 更暗、或比 colorB 更亮的颜色。有时这是故意要的效果，有时是 bug，用的时候心里要有数。

### ④ lerp 的对称性

`lerp(colorA, colorB, blendFactor)` 和 `lerp(colorB, colorA, 1 - blendFactor)` 结果完全相同。所以「反向渐变」既可以调换颜色顺序，也可以把混合因子取反——两条路殊途同归，这正好接上下一课。
