# 第 30 课 · 形状组合

> 学习目标：用 `max` / `min` 组合多个形状遮罩，理解形状的布尔运算。

多个形状可以像积木一样组合：`max` 取**并集**，`min` 取**交集**。

---

## 1. 完整代码

```hlsl
Shader "Lesson/30_ShapeCombine"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;
                float2 distanceToCenter = abs(centeredUV);

                // 矩形遮罩
                float rectMask = (1.0 - step(0.18, distanceToCenter.x)) * (1.0 - step(0.10, distanceToCenter.y));
                // 圆形遮罩
                float circleMask = 1.0 - smoothstep(0.22, 0.228, length(centeredUV));

                float combinedMask = max(rectMask, circleMask);
                return half4(combinedMask, combinedMask, combinedMask, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 30_ShapeCombine`。你会看到矩形和圆**叠在一起**（并集）。

---

## 2. 两个形状各自的遮罩

```hlsl
float rectMask = (1.0 - step(0.18, distanceToCenter.x)) * (1.0 - step(0.10, distanceToCenter.y));
float circleMask = 1.0 - smoothstep(0.22, 0.228, length(centeredUV));
```

矩形是一个横的扁矩形，圆在中心。两个遮罩都是 0~1。

---

## 3. max 取并集

```hlsl
float combinedMask = max(rectMask, circleMask);
```

`max(a, b)` 取两个遮罩中**较大**的那个。只要任意一个遮罩是 1，结果就是 1——这就是**并集**（矩形 ∪ 圆）。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 取交集（只剩重叠部分） | `min(rectMask, circleMask)` |
| 取差集（矩形挖掉圆） | `rectMask * (1.0 - circleMask)` |
| 把圆往上移 | 圆形部分改成 `length(centeredUV - float2(0.0, 0.15))` |

---

## 5. 练习

练习代码里 `combinedMask = 0.0`（全黑）。用 `max(rectMask, circleMask)` 组合两个形状。

### 答案解析

```hlsl
float combinedMask = max(rectMask, circleMask);
```

`max` 取两个遮罩的较大值，实现「并集」——矩形和圆都显示出来，重叠部分也是 1。

试试 `min(rectMask, circleMask)`：取较小值，只有**同时**在两个形状内的区域才为 1，即「交集」。这是形状布尔运算的基本功。

---

## 6. 【小灶解析】专家补充

### ① max / min = 并集 / 交集

把遮罩当 0/1 的「集合」，`max` 是并集（任意一个为 1 就为 1），`min` 是交集（两个都为 1 才为 1）。这是形状布尔运算（Boolean）的数学基础，也是 SDF 领域「平滑布尔」的起点。

### ② SDF 的平滑布尔更强大

用二值遮罩做 max/min，交界处是硬边。而如果对**真正的 SDF 距离场**做 max/min，交界处可以做**平滑过渡**（用 smooth-min/smooth-max 函数），能让两个形状「融合」在一起，像水滴粘连的效果。这是程序化建模里非常迷人的技巧，等你吃透 SDF 后可以去探索。

### ③ 形状组合 = 组合数学

本课是整套课程的「收官」：圆（距离场）、矩形（区间相乘）、遮罩选色（lerp）、硬边软边（step/smoothstep）、形状布尔（max/min）——**这些积木拼起来，就能画出任何 2D 图形**。后面进阶的 Ray Marching、程序化地形、UI 特效，都是在这个地基上继续盖楼。
