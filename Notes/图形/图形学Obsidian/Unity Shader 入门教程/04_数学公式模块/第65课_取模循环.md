# 第 65 课 · 取模循环（frac 重复）

> 学习目标：用 `frac` 把一段坐标无限重复，理解「乘以几就重复几次」。

`frac(x)` 只保留小数部分，是程序化纹理里制造重复的万能钥匙。

---

## 1. 完整代码

```hlsl
Shader "Lesson/65_FractRepeat"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float gradientValue = frac(IN.uv.x * 5.0);
                return half4(float3(gradientValue, gradientValue, gradientValue), 1);
            }
            ENDHLSL
        }
    }
}
```

画面是 5 条重复的渐变带。

---

## 2. frac 是什么

`frac(x)` 只返回小数部分，整数部分直接丢掉：

- `frac(0.3) = 0.3`
- `frac(1.7) = 0.7`
- `frac(2.9) = 0.9`

效果像一个锯齿波：从 0 涨到 1，一到 1 立刻跳回 0，不断循环。

---

## 3. 乘以倍数改变频率

`IN.uv.x * 5.0` 把原本 0~1 的坐标放大成 0~5。`frac` 把 0~5 切成 5 段，每段都是 0~1 的渐变，于是出现 5 条重复带。规律：**乘以几就重复几次**。

- `frac(IN.uv.x * 1.0)` = 不重复，就是原渐变
- `frac(IN.uv.x * 3.0)` = 重复 3 次
- `frac(IN.uv.x * 10.0)` = 重复 10 次

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 渐变带翻倍更细密 | `5.0` 改成 `10.0` |
| 改为垂直方向重复 | `IN.uv.x` 改成 `IN.uv.y` |
| 渐变变硬边条纹 | `gradientValue = step(0.5, gradientValue)` |
| 渐变方向翻转 | `gradientValue = 1.0 - frac(IN.uv.x * 5.0)` |

## 5. 练习

练习代码里 `gradientValue = IN.uv.x`。改成 `frac(IN.uv.x * 5.0)`，让画面出现 5 条重复的渐变带。

### 答案解析

```hlsl
float gradientValue = frac(IN.uv.x * 5.0);
```

`IN.uv.x * 5.0` 把 0~1 拉伸到 0~5，`frac` 取每个位置的小数部分，每隔 1 单位重置一次，产生 5 段各自从 0 到 1 的循环渐变。起始 `gradientValue = IN.uv.x` 只有一段普通渐变。

试着把 `5.0` 换成 `5.5`，看渐变带在边缘被截断的效果。

## 6. 【小灶解析】专家补充

### ① frac 是「重复」的万能钥匙

`frac` 只保留小数部分，等于把整条数轴每隔 1 折叠一次。任何「均匀增长的数值场」乘个系数再 `frac`，都能变成重复图案：x → 条纹、距离 → 圆环、角度 → 扇形。第 50 课同心圆环就是「距离 + frac」。

### ② frac 与 floor 是一对

`frac(x) = x - floor(x)`：`floor` 取整数部分（第几格），`frac` 取小数部分（格内哪里）。分格类图案几乎总是两者成对出现。

### ③ frac 的「硬跳变」是特性也是麻烦

`frac` 在整数处会突然从 1 跳回 0，这种硬边既是有用的（做条纹），也是锯齿的来源。需要柔化时，把 `frac` 换成 `sin` 就能得到平滑循环。
