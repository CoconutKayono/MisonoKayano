# 第 75 课 · 平滑最小值（smin）

> 学习目标：用 `smin` 平滑连接两个距离场，让形状像橡皮泥一样「融合」。

普通 `min(a, b)` 在两个形状边界处产生硬折痕；`smin` 用曲线平滑连接，让形状融合。

```hlsl
float distanceField = smin(distanceCircle1, distanceCircle2, 0.2);
```

---

## 1. 完整代码

```hlsl
Shader "Lesson/75_SmoothMin"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            float smin(float distanceA, float distanceB, float blendWidth)
            {
                float blendFactor = clamp(0.5 + 0.5 * (distanceB - distanceA) / blendWidth, 0.0, 1.0);
                return lerp(distanceB, distanceA, blendFactor)
                     - blendWidth * blendFactor * (1.0 - blendFactor);
            }

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;

                float distanceCircle1 = length(centeredUV - float2(-0.12, 0.0)) - 0.18;
                float distanceCircle2 = length(centeredUV - float2(0.12, 0.0)) - 0.18;

                float distanceField = smin(distanceCircle1, distanceCircle2, 0.2);
                float shapeMask = 1.0 - smoothstep(0.0, 0.01, distanceField);

                return half4(float3(shapeMask, shapeMask, shapeMask), 1);
            }
            ENDHLSL
        }
    }
}
```

画面是两个像水滴一样融合在一起的圆。

---

## 2. min 和 smin 的区别

`min(d1, d2)` 取两者中较小的那个，两个圆的边界在交汇处出现尖锐折角——因为距离场在那里不连续。`smin(d1, d2, k)` 在两个形状靠近时把距离场柔和混合，交汇处变成圆滑连接，视觉上像橡皮泥被捏在一起。

---

## 3. 第三个参数控制融合范围

```hlsl
float smin(float distanceA, float distanceB, float blendWidth)
{
    float blendFactor = clamp(0.5 + 0.5 * (distanceB - distanceA) / blendWidth, 0.0, 1.0);
    return lerp(distanceB, distanceA, blendFactor)
         - blendWidth * blendFactor * (1.0 - blendFactor);
}
```

`blendWidth = 0.2` 时，融合发生在两个形状距离约 0.2 单位的范围内。`blendWidth` 越大融合区越宽越软，趋近 0 时效果接近普通 `min`。

---

## 4. 场景里有什么

两个圆形 SDF 圆心分别在 (-0.12, 0) 和 (0.12, 0)，半径 0.18，微微重叠。用 `min` 合并时交汇处有硬折；改用 `smin` 后两圆像水滴一样融合。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 融合区缩小、接近硬 min | `0.2` 改成 `0.05` |
| 融合区很大、像被强力捏合 | `0.2` 改成 `0.5` |
| 两圆不再重叠 | 圆心间距从 `0.12` 改成 `0.4` |
| 两圆变小 | 半径 `0.18` 改成 `0.12` |

## 6. 练习

练习代码里 `distanceField = min(distanceCircle1, distanceCircle2)`。改成用 `smin`，让两个圆平滑融合。

### 答案解析

```hlsl
float distanceField = smin(distanceCircle1, distanceCircle2, 0.2);
```

`min(d1, d2)` 在两圆交汇处产生尖角——两个距离场直接相切、没有过渡。`smin(d1, d2, 0.2)` 在约 0.2 单位范围内引入平滑混合曲线，距离场在交汇处变得连续，渲染出的形状像两个水滴合并。

试着把第三个参数改成 `1.0`，感受极宽融合区下整个形状变成一个椭圆形整体。

## 7. 【小灶解析】专家补充

### ① smin 是「有机形状」的开关

硬 `min` 拼出来的是「积木」，`smin` 拼出来的是「泥巴」。做角色、流体、UI 里的柔美图形时，`smin` 是让形状「活起来」的关键函数。

### ② smin 的公式是「插值 + 修正」

`smin` = 常规 `lerp` 混合两个距离场，再减去 `k·h·(1-h)` 这个「凹陷修正项」。修正项在过渡区中间最大，把边界「吸」进去形成平滑凹陷。理解「插值 + 修正」的结构，你自己也能造其他平滑运算符。

### ③ 还有 smax（平滑最大值）

有 `smin` 就有对应的 `smax`（平滑最大值），用于平滑的「交集」运算。第 30 课的布尔运算（max 并集 / min 交集）都能对应出平滑版本。
