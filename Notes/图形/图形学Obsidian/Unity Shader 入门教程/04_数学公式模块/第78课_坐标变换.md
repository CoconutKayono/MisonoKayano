# 第 78 课 · 坐标变换

> 学习目标：把旋转、缩放、重复三种变换串联起来，理解 2D 坐标变换的基本原理。

把三种变换串成一条流水线，就能产生动态运动的圆形网格：

```hlsl
float2 centered = IN.uv - 0.5;   // 1. 平移：原点移到中心
float2 rotated = ...;            // 2. 旋转
float2 scaled = rotated * scale; // 3. 缩放
float2 repeated = frac(scaled * 3.0); // 4. 重复
```

---

## 1. 完整代码

```hlsl
Shader "Lesson/78_CoordinateTransform"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                // 1. 平移：原点移到中心
                float2 centered = IN.uv - 0.5;

                // 2. 旋转
                float angle = _Time.y;
                float cosAngle = cos(angle);
                float sinAngle = sin(angle);
                float2 rotated = float2(
                    centered.x * cosAngle - centered.y * sinAngle,
                    centered.x * sinAngle + centered.y * cosAngle
                );

                // 3. 缩放（呼吸感）
                float scale = 1.0 + sin(_Time.y * 2.0) * 0.5;
                float2 scaled = rotated * scale;

                // 4. 重复：fract 铺开
                float2 repeated = frac(scaled * 3.0) - 0.5;

                float distanceToCenter = length(repeated);
                float circleMask = 1.0 - smoothstep(0.2, 0.3, distanceToCenter);

                float3 backgroundColor = float3(0.05, 0.05, 0.1);
                float3 circleColor = float3(0.9, 0.7, 0.3);
                float3 color = lerp(backgroundColor, circleColor, circleMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一个旋转、呼吸缩放的 3×3 圆形网格。

---

## 2. 第一步：平移

`IN.uv` 范围 0~1、左下角是原点，但旋转缩放需要以中心为基准，所以先 `centered = IN.uv - 0.5`，坐标变成 -0.5~+0.5、中心是 (0,0)。

---

## 3. 第二步：旋转

用二维旋转公式（第 76 课）：`newX = x·cos - y·sin`，`newY = x·sin + y·cos`。`angle = _Time.y` 让图案随时间转动。

---

## 4. 第三步：缩放

`scale = 1.0 + sin(_Time.y * 2.0) * 0.5` 在 0.5~1.5 之间呼吸变化，`scaled = rotated * scale` 让网格缩放动画。

---

## 5. 第四步：重复

`frac(scaled * 3.0)` 只取小数部分，把坐标无限重复铺开，乘 3.0 表示每行每列重复 3 次。再 `- 0.5` 居中，用 `length` 算距离画圆。

---

## 6. 试着改一改

| 效果 | 写法 |
|------|------|
| 网格密度翻倍 | `3.0` 改成 `6.0` |
| 旋转加速 | `_Time.y`（旋转角）改成 `_Time.y * 3.0` |
| 圆形变空心环 | `1.0 - smoothstep(0.2, 0.3, ...)` 改成 `1.0 - smoothstep(0.2, 0.3, abs(distanceToCenter - 0.25))` |
| 缩放更剧烈 | 振幅 `0.5` 改成 `1.0` |

## 7. 练习

练习代码里旋转的两行是 TODO。用正确的 cos/sin 公式旋转 `centered` 坐标。

### 答案解析

```hlsl
float2 rotated = float2(
    centered.x * cosAngle - centered.y * sinAngle,
    centered.x * sinAngle + centered.y * cosAngle
);
```

这是标准 2D 旋转公式：新 x = 原 x·cos - 原 y·sin，新 y = 原 x·sin + 原 y·cos。`cosAngle`、`sinAngle` 由 `angle = _Time.y` 算得，让整个网格随时间旋转。

## 8. 【小灶解析】专家补充

### ① 坐标变换是「流水线」

平移 → 旋转 → 缩放 → 重复，每步都是对坐标的一次操作。**变换的顺序不能随便换**：先缩放再旋转、先旋转再缩放，结果不同。写变换时在脑子里过一遍这个流水线。

### ② fract 的「- 0.5」是居中

`frac(scaled * 3.0)` 得到的局部坐标是 0~1，`- 0.5` 把每格中心移到 0。这样 `length` 算出来的圆才居中。**「fract 后减 0.5」是分格图案的标准动作**。

### ③ 变换矩阵可以合并

平移、旋转、缩放本质上都是矩阵，可以乘成一个矩阵一步完成（这就是顶点着色器里 `TransformObjectToHClip` 做的事——把模型空间坐标一路变到裁剪空间）。理解了 2D 变换，就理解了 3D 渲染管线的一半。
