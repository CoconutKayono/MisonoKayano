# 第 34 课 · 边缘光

> 学习目标：用视角方向做一圈轮廓亮边，理解 `1.0 - dot(normal, viewDir)` 的几何意义。

边缘光（Rim Light）是电影和游戏里常用的打光技巧：让角色轮廓发光，把角色从背景中「抠」出来。着色器里不需要真的放灯，只用视角方向就能模拟。

---

## 1. 完整代码

```hlsl
Shader "Lesson/34_RimLight"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float3 normalOS : NORMAL;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float3 normalWS : TEXCOORD0;
                float3 positionWS : TEXCOORD1;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
                OUT.positionWS = TransformObjectToWorld(IN.positionOS.xyz);
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 normal = normalize(IN.normalWS);
                float3 viewDir = normalize(GetCameraPositionWS() - IN.positionWS);

                float rimFactor = pow(1.0 - max(dot(normal, viewDir), 0.0), 2.0);

                float3 baseColor = float3(0.25, 0.9, 0.85);   // 青色底色
                float3 color = lerp(baseColor, float3(1.0, 1.0, 1.0), rimFactor);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

场景准备同第 31 课。球体边缘出现一圈白色亮边，像从背景里浮出来。

---

## 2. `1.0 - dot(normal, viewDir)` 在做什么

`viewDir` 是「从表面指向相机」的方向。`dot(normal, viewDir)` 计算法线和视线的对齐程度：

- 球体中心：法线正对镜头 → 接近 1.0
- 球体边缘：法线几乎侧向 → 接近 0.0

`1.0 - dot(normal, viewDir)` 翻转这个结果：边缘大、中心小。`max(..., 0.0)` 防止背面出现负值。

---

## 3. pow 和 lerp 的作用

```hlsl
float rimFactor = pow(1.0 - max(dot(normal, viewDir), 0.0), 2.0);
float3 color = lerp(baseColor, float3(1.0, 1.0, 1.0), rimFactor);
```

`pow(..., 2.0)` 把渐变压缩，让亮边集中在更窄的边缘带。`lerp(a, b, t)` 在 a 和 b 之间按 t 插值：`rimFactor` 在边缘接近 1，所以边缘接近白色；中心接近 0，保持底色。

### 答案解析

```hlsl
float rimFactor = pow(1.0 - max(dot(normal, viewDir), 0.0), 2.0);
```

初始状态 `rimFactor = 0.0`，lerp 里的 t 始终为 0，球体只显示底色。`1.0 - dot(normal, viewDir)` 让边缘接近 1.0，`pow(..., 2.0)` 把效果集中在轮廓处，`lerp` 把底色渐变到白色。

## 6. 【小灶解析】专家补充

### ① 边缘光为什么能「抠出」角色

背景和角色之间没有光照差异时，两者会「糊」在一起。边缘光在轮廓处加一圈亮边，形成明暗分界，人眼立刻能区分前景和背景——这是摄影里「轮廓光」的原理，在游戏里用来突出主角、表示选中/受击状态。

### ② 这是 Fresnel 的「简化版」

`pow(1 - dot(n, v), n)` 这个公式在物理里叫 **Fresnel（菲涅尔）效应**（第 42 课会细讲）：掠射角反射增强。边缘光就是把它当成一个「发光遮罩」来用，不追求物理，只追求好看。

### ③ 视角方向怎么算

`GetCameraPositionWS()` 是 URP 提供的函数，返回世界空间相机位置。`GetCameraPositionWS() - IN.positionWS` 得到「表面指向相机」的向量，`normalize` 后就是视线方向。它和之前第 26 课的「全屏四边形」不同——那里没有真实 3D 位置，这里每个片元都有真实的 `positionWS`。
