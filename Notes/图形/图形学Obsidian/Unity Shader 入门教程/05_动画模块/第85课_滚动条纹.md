# 第 85 课 · 滚动条纹

> 学习目标：把第 53 课的静态水平条纹，接上时间偏移，做成不断滚动的条纹动画。

条纹的周期性正好和 `frac` 的周期性契合，滚动起来非常自然。

---

## 1. 完整代码

```hlsl
Shader "Lesson/85_ScrollingStripes"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float scrollValue = _Time.y * 2.0;
                float stripeValue = frac(IN.uv.y * 8.0 + scrollValue);
                float stripeMask = step(0.5, stripeValue);

                float3 colorA = float3(0.05, 0.05, 0.1);
                float3 colorB = float3(0.9, 0.6, 0.2);
                float3 color = lerp(colorA, colorB, stripeMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是 8 条橙色条纹，整体从下往上匀速滚动，滚到顶又接回来。

---

## 2. 静态条纹回顾

`frac(IN.uv.y * 8.0)` 把竖直方向切成 8 段，每段 0~1；`step(0.5, ...)` 让每段下半黑、上半橙，就是 8 条水平条纹（第 53 课）。

---

## 3. 加偏移让它滚

```hlsl
float scrollValue = _Time.y * 2.0;
float stripeValue = frac(IN.uv.y * 8.0 + scrollValue);
```

把 `scrollValue` 加进 `frac` 里：时间每增 1 秒，条纹坐标整体偏移 2 格，于是条纹向上滚动。`frac` 自动折回，滚到顶就无缝接回底部，形成无限滚动。

---

## 4. 偏移加在 frac 里还是外面

这里偏移加在 `frac` **里面**（`frac(uv * 8 + scroll)`），所以条纹整体平移；如果加在外面（`frac(uv * 8) + scroll`），则只有图案内的小数在变、条纹不动。**偏移放哪，决定了「平移整块图案」还是「图案内部流动」。**

## 6. 练习

练习代码里 `scrollValue = 0.0`、`stripeMask = 0.0`。补全时间偏移和条纹遮罩。

### 答案解析

```hlsl
float scrollValue = _Time.y * 2.0;
float stripeValue = frac(IN.uv.y * 8.0 + scrollValue);
float stripeMask = step(0.5, stripeValue);
```

`frac(IN.uv.y * 8.0 + scrollValue)` 把竖直方向切成 8 段、并随时间整体偏移；`step(0.5, ...)` 取每段后一半，形成滚动的水平条纹。时间偏移加在 `frac` 内部，所以整块条纹平移。

试着把 `step(0.5, stripeValue)` 换成 `1.0 - step(0.5, stripeValue)`，观察黑白对调。

## 7. 【小灶解析】专家补充

### ① 周期图案天然适合做循环动画

条纹、网格、棋盘这类用 `frac` 生成的图案，本身就具备周期性。只要把时间偏移塞进 `frac` 的输入，就能零成本做出无限滚动。**这是程序化动画最便宜、最常用的一类**。

### ② 「平移」的两种语义

「偏移加在 `frac` 里」= 整块图案平移；「偏移加在 `frac` 外」= 图案内部的采样点流动。两种写法只差一个括号位置，效果却完全不同。写这类 shader 时，想清楚你到底想让「哪一层」动。

### ③ 滚动速度的工程化

`_Time.y * 2.0` 直接写死速度不便于调。实际项目里会把它放进 Properties，用 `_ScrollSpeed` 暴露给材质面板，美术不用改代码就能调速度。下一课我们就会见到 Properties 的用法。
