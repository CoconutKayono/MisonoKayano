# 第 83 课 · 颜色循环

> 学习目标：让 R、G、B 三个通道各自用不同相位的正弦波，做出不断流转的彩色循环。

三条正弦波错开相位，颜色就会像走马灯一样循环流转。

---

## 1. 完整代码

```hlsl
Shader "Lesson/83_ColorCycle"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float redPulse   = sin(_Time.y) * 0.5 + 0.5;
                float greenPulse = sin(_Time.y + 2.094) * 0.5 + 0.5;   // 2π/3
                float bluePulse  = sin(_Time.y + 4.188) * 0.5 + 0.5;   // 4π/3

                float3 color = float3(redPulse, greenPulse, bluePulse);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是不断流转的彩色：红→黄→绿→青→蓝→紫→红，循环往复，没有跳跃。

---

## 2. 三个通道各是一条波

红、绿、蓝三条正弦波，频率相同（都是 `_Time.y`），但相位不同：绿比红晚 2.094，蓝比红晚 4.188。三色此起彼伏，加起来永远是和谐的过渡。

---

## 3. 相位差怎么来的

`sin(_Time.y + 2.094)` 里的 `+ 2.094` 是相位偏移。三个偏移量分别是 0、2.094、4.188——它们正好把一整圈（2π ≈ 6.283）三等分。**三条同频率、相位各差 2π/3 的波，是「三色均衡」的关键**：任何时刻三通道亮度之和接近恒定，颜色明亮且不停流转。

---

## 4. 为什么颜色能循环

把红绿蓝三通道想成三个滑块，各滑块在 0~1 之间按正弦规律来回推。因为相位错开，一个到达峰值时另一个正在回落，第三个在中段。于是 RGB 的组合值在色环上持续绕圈，而不是乱跳。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 循环更快 | `_Time.y` 全部改成 `_Time.y * 2.0` |
| 循环更慢 | 全部改成 `_Time.y * 0.5` |
| 颜色更饱和鲜艳 | 用 `sin(...) * 0.5 + 0.5` 得到 pulse 后，加一行 `pulse = smoothstep(0.0, 1.0, pulse);`（提高对比） |
| 只剩红蓝两色闪 | 把 `greenPulse` 相位改成和红相同（`+ 0.0`） |

## 6. 练习

练习代码里三个 pulse 都是 0。补全三条相位各差 2π/3 的正弦波。

### 答案解析

```hlsl
float redPulse   = sin(_Time.y) * 0.5 + 0.5;
float greenPulse = sin(_Time.y + 2.094) * 0.5 + 0.5;
float bluePulse  = sin(_Time.y + 4.188) * 0.5 + 0.5;
float3 color = float3(redPulse, greenPulse, bluePulse);
```

三条正弦波频率相同，相位分别偏移 0、2π/3、4π/3，把一整圈三等分。各自 `* 0.5 + 0.5` 映射到 0~1，组合出的 RGB 在色环上平滑循环。

试着把三个相位改成 `0.0`、`1.0`、`2.0`（不再是三等分），看颜色循环变得多不均衡。

---

## 7. 【小灶解析】专家补充

### ① 2π/3 ≈ 2.094，4π/3 ≈ 4.188

这两个数字会反复出现，值得记住：`2.094 = 2π/3`，`4.188 = 4π/3`。它们是「把一圈三等分」的相位偏移。也可以写 `float3(0.0, 2.094, 4.188)` 一次声明三个偏移，更紧凑。

### ② 相位是「延迟」不是「变速」

`sin(t + φ)` 的 φ 改变的是波在时间轴上的位置——让一条波比另一条「早开始」或「晚开始」，但频率不变。**频率决定快慢，相位决定错开多少**，别混淆。

### ③ 这是「色相循环」的土办法

更标准的做法是在 HSV 空间里把色相 H 从 0 转到 360°。但本课直接用三条错相正弦波，绕开了 HSV 转换，同样能做出连续流转的颜色。两者思路不同、效果相近，理解本课就为后面理解 HSV 打下了基础。
