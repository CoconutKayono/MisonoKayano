# 第 102 课 · 大理石纹理

> 学习目标：用噪声扰动正弦波的相位，把整齐条纹变成大理石脉络。

大理石纹路的本质：**被噪声推偏了相位的正弦波**。

---

## 1. 完整代码

```hlsl
Shader "Lesson/102_Marble"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            float fbm(float2 coord)
            {
                float value = 0.0;
                float amplitude = 0.5;
                for (int i = 0; i < 4; i++)
                {
                    value += amplitude * valueNoise(coord);
                    coord *= 2.0;
                    amplitude *= 0.5;
                }
                return value;
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float noiseValue = fbm(IN.uv * 6.0);
                float marbleValue = sin((IN.uv.x * 6.0 + noiseValue * 2.0) * 3.14159265);
                marbleValue = marbleValue * 0.5 + 0.5;

                float3 color = float3(marbleValue, marbleValue, marbleValue);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是弯曲的黑白条纹，像大理石纹路的基本形态。

---

## 2. 噪声扰动正弦波

先看不加噪声：`sin(IN.uv.x * 6.0 * π)` 是均匀竖条纹，每隔固定距离重复。

加上 `noiseValue * 2.0` 后：每个像素的相位被噪声偏移，有的地方快、有的地方慢，平直条纹就弯曲了——正是大理石脉络的样子。`2.0` 控制扰动幅度：越大弯曲越剧烈，越小越接近直线。

---

## 3. `* 0.5 + 0.5` 映射范围

`sin` 输出 -1~1，`* 0.5 + 0.5` 映射到 0~1 作为亮度。又是这个老朋友——第 81 课起反复出现的「正弦波到亮度」标准写法。

---

## 4. 为什么乘 π

`* 3.14159265` 让 sin 的输入以 π 为单位，整数倍处正好是零交叉点，条纹周期更规整。**「坐标 × 频率 × π」让正弦条纹以整数周期排列**，是画条纹类图案的常用技巧。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 脉络弯曲更剧烈、像水波 | `2.0` 改成 `5.0` |
| 脉络几乎变直线 | `2.0` 改成 `0.5` |
| 条纹更密、脉络更细 | `6.0`（正弦频率）改成 `12.0` |
| 上大理石颜色 | 外层套 `lerp(darkGray, white, marbleValue)` |

## 6. 练习

练习代码里 `marbleValue = 0.0`。用 fbm 扰动正弦波相位，计算大理石亮度。

### 答案解析

```hlsl
float noiseValue = fbm(IN.uv * 6.0);
float marbleValue = sin((IN.uv.x * 6.0 + noiseValue * 2.0) * 3.14159265);
marbleValue = marbleValue * 0.5 + 0.5;
```

`IN.uv.x * 6.0` 沿 X 生成竖条纹；`+ noiseValue * 2.0` 用噪声扰动相位让条纹弯曲；`* π` 让条纹以整数周期排列；`* 0.5 + 0.5` 把 [-1,1] 映射到 [0,1]。

试着把 `IN.uv.x * 6.0` 改成 `(IN.uv.x + IN.uv.y) * 4.0`，让脉络方向变斜。

---

## 7. 【小灶解析】专家补充

### ① 大理石 = 噪声 + 正弦

这是「噪声扰动」的经典应用：**用一个规则的周期函数（正弦），再用噪声推偏它的相位**。规则 + 随机 = 自然。木纹、水波、熔岩流动，都能用「周期函数 + 噪声扰动」做出来。

### ② 扰动幅度是「写实度」旋钮

`noiseValue * 2.0` 里的 2.0 决定脉络弯曲多少。0 是完美直线（人造感），很大是剧烈卷曲（抽象感），真实大理石在中间。**调这个幅度就是在「规则」和「随机」之间找平衡。**

### ③ 相位扰动是「域扭曲」的一维版

这里扰动的是 sin 的相位（一维偏移），第 109 课的域扭曲是扰动采样坐标（二维偏移）。两者同源：**用噪声去推偏某个东西**。学完第 109 课再回头看本课，会豁然开朗。
