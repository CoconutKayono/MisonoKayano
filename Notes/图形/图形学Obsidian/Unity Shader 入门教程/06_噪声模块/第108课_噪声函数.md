# 第 108 课 · 噪声函数

> 学习目标：认识三种噪声——随机噪声、值噪声、梯度噪声，理解「随机但连续」的核心。

程序化噪声的核心是「随机但连续」：相邻像素值接近，整体平滑起伏。三种噪声从左到右逐级「更连续」。

---

## 1. 完整代码

```hlsl
Shader "Lesson/108_NoiseFunctions"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            float2 randomGradient(float2 gridCoord)
            {
                float randomAngle = hash21(gridCoord) * 6.2831853;
                return float2(cos(randomAngle), sin(randomAngle));
            }

            float perlinNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float dotBottomLeft  = dot(randomGradient(cell),               fracCoord);
                float dotBottomRight = dot(randomGradient(cell + float2(1, 0)), fracCoord - float2(1, 0));
                float dotTopLeft     = dot(randomGradient(cell + float2(0, 1)), fracCoord - float2(0, 1));
                float dotTopRight    = dot(randomGradient(cell + float2(1, 1)), fracCoord - float2(1, 1));

                float bottom = lerp(dotBottomLeft, dotBottomRight, smoothCoord.x);
                float top    = lerp(dotTopLeft, dotTopRight, smoothCoord.x);
                return lerp(bottom, top, smoothCoord.y) * 0.5 + 0.5;
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 coord = IN.uv * 5.0;
                float noiseValue = 0.0;

                // 左 1/3：随机噪声（雪花）
                if (IN.uv.x < 1.0 / 3.0)
                    noiseValue = hash21(coord * 10.0);
                // 中 1/3：值噪声
                else if (IN.uv.x < 2.0 / 3.0)
                    noiseValue = valueNoise(coord);
                // 右 1/3：梯度噪声（Perlin 简化版）
                else
                    noiseValue = perlinNoise(coord);

                float3 color = float3(noiseValue, noiseValue, noiseValue);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面左右并排三种噪声：左边电视雪花、中间平滑斑块、右边更自然的梯度噪声。

---

## 2. 三种噪声的对比

随机噪声（`hash21(coord * 10.0)`）：像素间完全独立，像电视雪花。值噪声（`valueNoise`）：平滑连续斑块，相邻像素相关。梯度噪声（`perlinNoise`）：比值噪声更自然、对比度更均匀。

---

## 3. 值噪声是怎么工作的

把平面分成均匀格子，每个格点分配伪随机值；当前像素落在某格里，取四个角随机值，用平滑曲线插值。`floor` 取格点、`frac` 取格内位置。

---

## 4. 为什么用 `f*f*(3-2f)` 而不用直接插值

直接 `f`（线性插值）在格点处导数不连续，有折痕。`f*f*(3-2f)` 是平滑阶跃函数（smoothstep 的多项式等价），在 0 和 1 处导数都是 0，过渡平滑无折痕。**这是值噪声的关键。**

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 噪声频率翻倍、斑块变小 | `IN.uv * 5.0` 改成 `IN.uv * 10.0` |
| 噪声频率减半、斑块变大 | 改成 `IN.uv * 2.0` |
| 值噪声出现折痕 | `smoothCoord` 改成 `fracCoord` |
| 只看值噪声 | 把 if 分支全删，直接 `valueNoise(coord)` |

## 6. 练习

在 valueNoise 里把 `smoothCoord = fracCoord`（线性）改成多项式 `f * f * (3.0 - 2.0 * f)`，观察折痕消失。

### 答案解析

```hlsl
float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);
```

`smoothstep(0, 1, f)` 和 `f*f*(3-2f)` 数学上完全等价——smoothstep 内部就是这个多项式。两者都在 f=0、f=1 处导数为 0，产生平滑过渡。直接写多项式更直观地表明「我在做平滑插值」。

## 7. 【小灶解析】专家补充

### ① 噪声谱系：随机 → 值 → 梯度

三种噪声是「连续性」递进的谱系：随机（无相关性）→ 值（值插值）→ 梯度（方向插值）。**Perlin 噪声（梯度噪声）是 Ken Perlin 在 1983 年发明的，为此拿了奥斯卡技术奖**，是图形学最著名的算法之一。

### ② 梯度噪声为什么更自然

值噪声在格点附近有「平顶」，会产生轻微的格状伪影；梯度噪声给每个格点分配随机「方向」而非「值」，插值的是方向点积，过渡更均匀、格子感更弱。**这就是 Perlin 优于纯 Value Noise 的原因。**

### ③ 生产环境用现成的

Unity 里不必手写 Perlin——`Unity.Mathematics` 有 `noise.snoise()`（Simplex 噪声，Perlin 的改进版）。但**理解底层原理**能让你读懂别人的 shader、判断噪声质量、按需选择。手写一遍，胜过调用一百次。
