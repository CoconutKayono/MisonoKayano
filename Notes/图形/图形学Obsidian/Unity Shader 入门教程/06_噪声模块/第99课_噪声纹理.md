# 第 99 课 · 噪声纹理

> 学习目标：综合分形叠加、时间动画、分段颜色映射，做流动的蓝白云雾纹理。

这一课把前面几课的积木组合起来：分形叠加 + 时间流动 + 两段颜色映射。

---

## 1. 完整代码

```hlsl
Shader "Lesson/99_NoiseTexture"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                // 分形叠加 + 时间流动
                float fractalNoise = 0.0;
                float amplitude = 0.5;
                float frequency = 1.0;
                for (int i = 0; i < 4; i++)
                {
                    fractalNoise += amplitude * valueNoise(IN.uv * frequency + _Time.y * 0.1);
                    amplitude *= 0.5;
                    frequency *= 2.0;
                }

                // 两段颜色映射：深蓝 → 浅蓝 → 白
                float3 color1 = float3(0.2, 0.3, 0.8);   // 深蓝
                float3 color2 = float3(0.8, 0.9, 1.0);   // 浅蓝
                float3 color3 = float3(1.0, 1.0, 1.0);   // 白色

                float lowerMix = smoothstep(0.0, 0.4, fractalNoise);
                float upperMix = smoothstep(0.4, 1.0, fractalNoise);
                float3 color = lerp(color1, color2, lowerMix);
                color = lerp(color, color3, upperMix);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是缓慢流动的蓝白云雾，暗部深蓝、亮部发白，有云朵质感。

---

## 2. 分形叠加

循环 4 次，每次叠加一层：`amplitude` 从 0.5 开始减半，`frequency` 从 1.0 开始翻倍。结果同时包含大尺度起伏和细小纹路——这就是 FBM 的思路（第 101 课详解）。

---

## 3. 时间偏移让噪声流动

`+ _Time.y * 0.1` 让采样坐标每帧向前推进，产生缓慢流动。注意这里是**每层都加**，所以所有尺度的细节一起流动，比只动一层更自然。

---

## 4. 两段颜色映射

`fractalNoise` 小于 40% 时在深蓝和浅蓝间插值，大于 40% 时在浅蓝和白色间插值。用两个 `smoothstep` 分段：`lowerMix` 管低段、`upperMix` 管高段。亮部呈现云朵感，暗部沉入深蓝。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 流动加快 | `_Time.y * 0.1` 改成 `_Time.y * 0.5` |
| 细节更丰富 | 循环 `i < 4` 改成 `i < 6` |
| 红色熔岩风格 | `color1` 改成 `float3(0.8, 0.3, 0.1)` |
| 白色区域扩大 | 两处 `0.4` 改成 `0.6` |

## 6. 练习

练习代码是蓝白云雾，结构不变。把配色从蓝白改成暖色（橙黄白），让它像流动的熔岩。

### 答案解析

```hlsl
float3 color1 = float3(0.6, 0.1, 0.0);   // 深红
float3 color2 = float3(0.9, 0.5, 0.1);   // 橙色
float3 color3 = float3(1.0, 0.95, 0.6);  // 浅黄白
```

只换三个颜色变量，其余不动。暗部（低值）→ 深红，中间 → 橙，亮部（高值）→ 浅黄白。同样的明暗结构，配色一换就从云朵变成流动熔岩。

试着把 `_Time.y * 0.1` 改成 `float2(_Time.y * 0.15, _Time.y * 0.05)`，让流动变对角。

## 7. 【小灶解析】专家补充

### ① 这是「程序化贴图」的完整雏形

分形叠加（生成结构）→ 颜色映射（上色）→ 时间偏移（动画），三步就是**程序化生成一张会动的贴图**的完整流程。理解了本课，你就理解了为什么 shader 能替代大量手绘贴图。

### ② 分段映射 = 更多颜色控制

一段 `lerp` 只能两色渐变，两段 `smoothstep` 叠加能做出「暗部 → 中段 → 亮部」三段控制。想更多层次就叠更多段。**这是「伪色图」（false color）技术的基础**——用颜色把数值范围可视化。

### ③ 循环里的时间偏移

时间偏移写在循环里（每层都加）比写在外面更好：每层细节同步流动，不会出现「大块动了、小纹路没动」的违和。做流动烟雾、云海时牢记这一点。
