# 第 106 课 · 木纹年轮

> 学习目标：用「径向距离 + 噪声扰动 + frac 折叠」模拟木头的年轮。

真实木头的年轮是一圈圈同心环，用极坐标半径加噪声扰动就能模拟。

---

## 1. 完整代码

```hlsl
Shader "Lesson/106_WoodGrain"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            float fbm(float2 coord)
            {
                float value = 0.0;
                float amplitude = 0.5;
                for (int i = 0; i < 4; i++)
                {
                    value += amplitude * valueNoise(coord);
                    coord *= 2.0;
                    amplitude *= 0.5;
                }
                return value;
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;
                float radius = length(centeredUV) * 8.0;
                float noiseValue = fbm(IN.uv * 6.0);

                float woodValue = frac(radius + noiseValue);

                float3 color = float3(woodValue, woodValue, woodValue);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一圈圈被扰动、边缘不规则的同心年轮。

---

## 2. 半径 + 噪声

`radius = length(centeredUV) * 8.0` 算到中心的距离（乘以 8 让年轮有合适圈数）。`frac(radius)` 取小数，把距离折叠成重复的 0~1——这就是年轮结构。单独 `frac(radius)` 是完美同心圆；加上 `noiseValue` 后年轮被随机扰动，边缘弯曲，更接近真实木纹。

---

## 3. frac 如何产生重复

`frac(x)` 只留小数：`frac(3.2) = 0.2`。对一个随距离线性增长的值取 frac，得到锯齿形重复模式——视觉上就是一圈圈环。

---

## 4. FBM 噪声做扰动

`noiseValue = fbm(IN.uv * 6.0)` 是 0~1 的平滑噪声，带真实木纹的不规则大块感。加到 `radius` 上，相当于在径向距离引入随机偏移，让每圈年轮稍微弯曲。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 年轮变宽、圈数减少 | `* 8.0` 改成 `* 4.0` |
| 年轮变细、圈数增多 | `* 8.0` 改成 `* 16.0` |
| 纹路更细碎 | `fbm(IN.uv * 6.0)` 改成 `fbm(IN.uv * 12.0)` |
| 扰动减弱、接近正圆 | 扰动量 `noiseValue` 改成 `noiseValue * 0.3` |

## 6. 练习

练习代码里 `woodValue = 0.0`。用 `frac(radius + noiseValue)` 计算木纹值。

### 答案解析

```hlsl
float woodValue = frac(radius + noiseValue);
```

`frac(radius + noiseValue)` 把径向距离加上 FBM 噪声再取小数。`radius` 增大时 `frac(radius)` 不断重置回 0，形成一圈圈环；加 `noiseValue` 后环的边界在不同角度被推远或拉近，产生木纹弯曲。

试着把 `float3(w)` 改成 `lerp(float3(0.35, 0.2, 0.05), float3(0.8, 0.5, 0.15), woodValue)`，给年轮上木头颜色。

## 7. 【小灶解析】专家补充

### ① 木纹 = 极坐标 + 扰动

「径向距离做重复（年轮）+ 噪声扰动（弯曲）」是木纹的经典配方。**所有「同心环」类纹理（木纹、树桩、靶心、指纹）都从 `frac(length(p))` 起步。**

### ② frac 是「径向重复」的工具

第 50 课的同心圆环用的是 `frac(distance)` 折叠，本课是同一招再叠上噪声。**「距离 → frac → 环」**这个流水线值得反复用。

### ③ 扰动量控制「写实 vs 规整」

扰动为 0 是完美的同心圆（像靶子，人造感）；扰动大则乱成一团。真实木纹在中间——轻微不规则。**调 `noiseValue` 的系数，就是在调「这木头多自然」。**
