📐 第1章 数学基础 基础篇

Shader编程所需的向量、矩阵、三角函数等核心数学知识

📊 核心数学公式速查

点积 (Dot Product) a · b = |a||b|cosθ = ax·bx + ay·by
叉积 (Cross Product) a × b = (ay·bz - az·by, az·bx - ax·bz, ax·by - ay·bx)
向量归一化 normalize(v) = v / |v|
2D旋转矩阵 [cosθ, -sinθ; sinθ, cosθ]
透视除法 ndc = (x/w, y/w, z/w)
Blinn-Phong高光 H = normalize(L + V), spec = pow(max(N·H,0), shininess)
📍

笛卡尔坐标系

Unity使用左手坐标系：X轴向右，Y轴向上，Z轴朝向屏幕内。UV坐标原点在左下角，V向上增长。

🔢

齐次坐标

四维坐标(x,y,z,w)用于表示点和方向。w=1表示点，w=0表示方向。透视投影通过w分量实现。

🔄

矩阵变换

模型矩阵(M)、视图矩阵(V)、投影矩阵(P)。MVP变换将顶点从模型空间转换到裁剪空间。

📐 坐标系系统 基础篇

理解 Model → World → View → Clip → NDC → Screen 六大坐标空间及其变换关系

📦

Model Space（模型空间）

顶点的原始定义空间，原点为模型自身中心。每个网格资源独立定义，坐标通常在局部 [-1,1] 范围内。

P_model = vertex (raw local position)
🌍

World Space（世界空间）

场景全局坐标系。通过 Model Matrix 将所有物体平移/旋转/缩放后放置到统一世界中。

P_world = M_model × P_model
📷

View Space（观察空间）

以相机为原点的坐标系。View Matrix 是相机世界变换的逆矩阵，将世界坐标转换到相机视角下。

P_view = M_view × P_world
✂️

Clip Space（裁剪空间）

应用投影矩阵后的齐次坐标空间 (x,y,z,w)。视锥体映射为立方体，w 分量承载深度用于裁剪判断。

P_clip = M_projection × P_view
🖥️

NDC + Screen Space

透视除法（除以 w）后得到归一化设备坐标 [-1,1]³，再经视口映射变换为屏幕像素坐标。

NDC = clip.xyz / clip.w → Screen

① 输入装配 (IA)

从顶点缓冲区读取顶点数据（位置、法线、UV、颜色等），按索引组装为三角形、线段等图元。

🔺

② 顶点着色器 (VS)

每个顶点执行一次。MVP矩阵链式变换：模型空间→世界空间→观察空间→裁剪空间。处理法线、UV传递。

✂️

③ 裁剪 (Clipping)

剔除完全在视锥体外的图元；对部分在外部的图元，在裁剪面处生成新顶点，确保只绘制可见部分。

🗺️

④ 屏幕映射

齐次除法（透视除法）将裁剪坐标转为NDC，再映射到屏幕像素坐标系，准备光栅化。

🔍

⑤ 光栅化

三角形设置：计算边界方程；三角形遍历：扫描线逐行生成片元(Fragment)，为后续着色做准备。

🎨

⑥ 片元着色器 (FS)

每个片元执行一次。光照计算(Blinn-Phong/PBR)、纹理采样、法线贴图等，输出最终颜色。

📝 第3章 ShaderLab 基础 基础篇

Unity Shader 的结构、属性、语义和 HLSL 语法（URP）

🎯 Shader结构解析

// 完整的 Unity Shader 结构（URP + HLSL） Shader "Custom/MyShader" { // ========== 属性块 ========== Properties { _Color ("主颜色", Color) = (1,1,1,1) _MainTex ("主纹理", 2D) = "white" {} _Glossiness ("光滑度", Range(0,1)) = 0.5 } // ========== SubShader ========== SubShader { Tags { "Queue" = "Geometry" "RenderType" = "Opaque" "RenderPipeline" = "UniversalPipeline" // URP 管线标识 } Pass { Name "UniversalForward" // URP 前向渲染 Pass Tags { "LightMode" = "UniversalForward" } HLSLPROGRAM #pragma vertex vert #pragma fragment frag // URP 核心库（替代内置管线的 UnityCG.cginc） #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl" // 材质属性放进常量缓冲区，SRP Batcher 才能合批 CBUFFER_START(UnityPerMaterial) half4 _Color; float4 _MainTex_ST; // Scale, Transform CBUFFER_END // 纹理与采样器分离声明（HLSL 没有 sampler2D 这种合并写法） TEXTURE2D(_MainTex); SAMPLER(sampler_MainTex); struct Attributes { float4 positionOS : POSITION; float2 uv : TEXCOORD0; float3 normalOS : NORMAL; }; struct Varyings { float4 positionHCS : SV_POSITION; float2 uv : TEXCOORD0; float3 normalWS : TEXCOORD1; }; Varyings vert (Attributes IN) { Varyings OUT; OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz); OUT.uv = TRANSFORM_TEX(IN.uv, _MainTex); OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS); return OUT; } half4 frag (Varyings IN) : SV_Target { return _Color * SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, IN.uv); } ENDHLSL } } // ========== 后备 Shader（URP 下写 URP 自己的 Fallback） ========== Fallback "Universal Render Pipeline/Simple Lit" }
语义 (Semantic)说明类型
POSITION模型空间顶点位置float4
NORMAL模型空间法线方向float3
TEXCOORD0-3纹理坐标float2/3/4
SV_POSITION裁剪空间顶点位置float4
SV_Target渲染目标颜色输出half4
SV_Depth深度值输出float

💡 URP 与内置管线核心差异

内置管线写 CG（CGPROGRAM / fixed / tex2D / _LightColor0），URP 写 HLSL：① 用 HLSLPROGRAM / ENDHLSL 包裹代码；② HLSL 没有 fixed 类型，精度用 half / float；③ 纹理采样用 TEXTURE2D + SAMPLER + SAMPLE_TEXTURE2D；④ 必须 #include Core.hlsl，顶点/法线变换用 TransformObjectToHClip / TransformObjectToWorldNormal；⑤ Tags 里要写 RenderPipeline=UniversalPipeline 和 LightMode=UniversalForward；⑥ 材质属性放进 CBUFFER 才能启用 SRP Batcher 合批；⑦ 内置管线的 Surface Shader 在 URP 完全不支持。

// 完整 Blinn-Phong 光照实现（URP） float3 BlinnPhong(float3 normal, float3 viewDir, float diffuse, float specular, float shininess) { // URP：主光用 GetMainLight() 获取（替代内置管线的 _LightColor0 / _WorldSpaceLightPos0） Light mainLight = GetMainLight(); float3 lightColor = mainLight.color; float3 lightDir = mainLight.direction; // 1. 环境光（URP 用 SampleSH 采样球谐环境光） float3 ambientColor = SampleSH(normal); // 2. 漫反射 (Lambert) float NdotL = max(dot(normal, lightDir), 0); float3 diffuseColor = diffuse * NdotL * lightColor; // 3. 高光反射 (Blinn-Phong) float3 halfDir = normalize(lightDir + viewDir); float NdotH = max(dot(normal, halfDir), 0); float3 specularColor = specular * pow(NdotH, shininess) * lightColor; return ambientColor + diffuseColor + specularColor; }

💡 URP 光照差异

内置管线用全局变量 _LightColor0 / _WorldSpaceLightPos0 拿主光；URP 用 GetMainLight()，返回 Light 结构体（color / direction / shadowAttenuation）。环境光从 UNITY_LIGHTMODEL_AMBIENT 变成 SampleSH(normal)（采样球谐）。写真实光照需 #include Lighting.hlsl——上面是「原理级」函数，实际 URP 里直接复用 Lit / Simple Lit 即可。

纹理采样模式

  • Point - 最近邻采样，块状像素风
  • Bilinear - 双线性插值，平滑但模糊
  • Trilinear - 结合Mipmap，消除条带
  • Anisotropic - 各向异性，适合长条纹理

纹理Wrap模式

  • Repeat - 超出[0,1]重复平铺
  • Clamp - 超出范围钳制到边缘色
  • Mirror - 奇数区间镜像翻转
  • Border - 超出范围使用边框颜色

Mipmap级别

  • 预计算不同分辨率纹理
  • 根据距离自动选择级别
  • 节省带宽，减少噪点
  • 增加33%显存占用

🗺️ 第8章 法线贴图 初级篇

切线空间法线、世界空间法线、TBN矩阵转换

🏔️ 平面着色 vs 法线贴图

1.00
🔵

法线贴图原理

存储的是"偏移量"，RGB颜色映射到法线方向。蓝色(128,128,255)代表朝向观察者，紫红色表示法线偏斜。

📐

TBN矩阵

T=切线(Tangent)，B=副切线(Bitangent)，N=法线(Normal)。用于将切线空间法线转换到世界空间。

⚡

性能对比

法线贴图可在低多边形上模拟高多边形细节，节省50%-70%几何开销，是游戏美术的必备技术。

// 世界空间法线计算（URP） float3 WorldNormal(Attributes v, float2 uv) { float3 worldNormal = TransformObjectToWorldNormal(v.normalOS); float3 worldTangent = TransformObjectToWorldDir(v.tangentOS.xyz); float3 worldBitangent = cross(worldNormal, worldTangent) * v.tangentOS.w; float3 tnormal = UnpackNormalScale(SAMPLE_TEXTURE2D(_BumpMap, sampler_BumpMap, uv), _BumpScale); float3 bumpedNormal = normalize( worldTangent * tnormal.x + worldBitangent * tnormal.y + worldNormal * tnormal.z ); return bumpedNormal; }

💡 URP 法线贴图差异

① 采样用 SAMPLE_TEXTURE2D；② 解包用 UnpackNormalScale(tex, _BumpScale)（比 UnpackNormal 多一个法线强度参数）；③ 切空间→世界空间仍需手算 TBN 矩阵。注意 Attributes 结构体要带 float4 tangentOS : TANGENT 字段，法线贴图才有切线可用。

🚀 第9章 渲染优化技术 初级篇

批处理、LOD、遮挡剔除、GPU Instancing

📦

静态批处理

将不会移动的静态物体合并成一个Mesh。简单高效，但会增加内存占用。

🔄

动态批处理

对小网格物体自动合批。900顶点以下共享一个Draw Call，但CPU端有合批开销。

🎯

GPU Instancing

使用Instancing关键字，对大量相同Mesh渲染不同实例。适合草、粒子、岩石等。

🔍

LOD系统

根据相机距离切换不同细节层次模型。减少远处物体的面数和纹理分辨率。

🚫

遮挡剔除

被其他物体完全遮挡的物体不参与渲染。Occlusion Culling配合Frustum Culling使用。

💾

纹理图集

将多个小纹理合并成一张大纹理，减少材质切换和Draw Call数量。

// GPU Instancing 示例（URP） #pragma multi_compile_instancing // 逐实例属性用 Instancing 常量缓冲区声明 UNITY_INSTANCING_BUFFER_START(Props) UNITY_DEFINE_INSTANCED_PROP(float4, _InstanceColor) UNITY_INSTANCING_BUFFER_END(Props) Varyings vert (Attributes v, uint instanceID : SV_InstanceID) { Varyings OUT = (Varyings)0; UNITY_SETUP_INSTANCE_ID(v); // 建立实例 ID UNITY_TRANSFER_INSTANCE_ID(v, OUT); // 传递到片元 OUT.positionHCS = TransformObjectToHClip(v.positionOS.xyz); OUT.color = UNITY_ACCESS_INSTANCED_PROP(Props, _InstanceColor); return OUT; }

💡 URP Instancing 差异

URP 用 UNITY_INSTANCING_BUFFER_START/END + UNITY_DEFINE_INSTANCED_PROP + UNITY_ACCESS_INSTANCED_PROP 声明逐实例属性（不再是手写 InstanceData 结构体）。更大提升是 SRP Batcher：只要材质属性进了 CBUFFER，不同材质也能合批——这是 URP 相对内置管线在大批量小物体场景下的核心优化。

🎬 第10章 渲染路径 中级篇

前向渲染、延迟渲染、路径渲染路径详解

前向渲染 (Forward)

  • 每个物体逐光源渲染
  • 支持实时阴影
  • 简单场景效率高
  • 光源数量有限(通常8个)
  • 适合移动设备

延迟渲染 (Deferred)

  • 先渲染到G-Buffer
  • 光照计算与几何分离
  • 大量光源效率高
  • 不支持半透明(需前向)
  • 显存占用大

路径渲染 (Legacy Deferred)

  • 改进版延迟渲染
  • 支持光照剪影
  • MSAA更友好
  • 渲染质量高
  • 性能开销较大

💡 G-Buffer可视化

// G-Buffer结构 (延迟渲染) // GBuffer0: RGB=漫反射颜色, A=未使用 // GBuffer1: RGB=法线(视空间), A=高光反射度 // GBuffer2: RGB=自发 emission, A=反射遮挡 // GBuffer3: RGBA=附加缓冲数据 // DepthBuffer: 场景深度 // URP 延迟渲染：G-Buffer 填充 Pass Pass { Name "UniversalGBuffer" Tags { "LightMode" = "UniversalGBuffer" } // 从 G-Buffer 采样并计算光照（URP 中此步由引擎内部完成，此处仅示意内容） float4 albedo = SAMPLE_TEXTURE2D(_GBuffer0, sampler_GBuffer0, i.uv); float4 normalSpec = SAMPLE_TEXTURE2D(_GBuffer1, sampler_GBuffer1, i.uv); float depth = SampleSceneDepth(i.uv); }

💡 URP 延迟渲染差异

内置管线的 LightMode=Deferred 在 URP 变成 LightMode=UniversalGBuffer（往 G-Buffer 写数据），且延迟光照由引擎内部完成，不需要像内置管线那样手写 lighting pass。前提：URP Asset 的渲染路径设为 Deferred。

🏔️

视差遮蔽贴图 (POM)

通过高度图调整纹理采样位置，模拟深度感。比法线贴图更真实，适合砖墙、地面。

💧

流体遮罩 (Flow Map)

存储UV偏移方向，用于流体动画。适合河流、熔岩等流动效果。

🔲

细节贴图

叠加高频细节纹理，增加表面细节密度。使用单独的UV或UV2通道。

📦

立方体纹理

6个面的2D纹理组成3D环境。用于反射、天空盒、环境光照采样。

// 视差遮蔽贴图 float2 ParallaxCoord(float2 uv, float3 viewDir) { const float heightScale = 0.05; float height = SAMPLE_TEXTURE2D(_HeightMap, sampler_HeightMap, uv).r; float2 p = viewDir.xy / viewDir.z * height * heightScale; return uv - p; }

🌑 第12章 阴影系统 中级篇

正交/透视阴影、级联阴影、柔和阴影原理

💡 阴影映射可视化

☀️

实时阴影

Shadow Map技术：从光源视角渲染深度图，比较片元深度判断是否在阴影中。

🔲

正交 vs 透视

Directional Light使用正交投影，Spot/Point Light使用透视投影。正交阴影无透视变形。

🌊

PCF软阴影

Percentage Closer Filtering：对阴影图多次采样并平均，产生柔和边缘阴影。

🔢

级联阴影 (CSM)

Cascaded Shadow Maps：根据距相机远近使用不同分辨率阴影图，近处精度高。

// 阴影采样 float SampleShadow(float4 shadowCoord) { float shadow = SAMPLE_TEXTURE2D(_ShadowMap, sampler_ShadowMap, shadowCoord.xy).r; // 超过光锥范围的片元返回0(完全光照) return shadowCoord.w > 0 && shadow < shadowCoord.z ? 0.0 : 1.0; } // PCF 3x3采样 float SampleShadowPCF(float4 shadowCoord) { float shadow = 0; for(int x=-1; x<=1; x++) { for(int y=-1; y<=1; y++) { shadow += SampleShadow(shadowCoord + float4(x,y,0,0) * 0.001); } } return shadow / 9; }

💡 URP 阴影差异

// HLSL 2D Simplex Noise (Stefan Gustavson) float3 mod289(float3 x) { return x - floor(x * (1.0 / 289.0)) * 289.0; } float2 mod289(float2 x) { return x - floor(x * (1.0 / 289.0)) * 289.0; } float3 permute(float3 x) { return mod289((x * 34.0 + 1.0) * x); } float snoise(float2 v) { float4 C = float4(0.211324865405187, 0.366025403784439, -0.577350269189626, 0.024390243902439); float2 i = floor(v + dot(v, C.yy)); float2 x0 = v - i + dot(i, C.xx); float2 i1 = (x0.x > x0.y) ? float2(1, 0) : float2(0, 1); float4 x12 = x0.xyxy + C.xxzz; x12.xy -= i1; i = mod289(i); float3 p = permute(permute(i.y + float3(0, i1.y, 1)) + i.x + float3(0, i1.x, 1)); float3 m = max(0.5 - float3(dot(x0,x0), dot(x12.xy,x12.xy), dot(x12.zw,x12.zw)), 0); m = m * m; m = m * m; float3 x = 2.0 * frac(p * C.www) - 1.0; float3 h = abs(x) - 0.5; float3 ox = floor(x + 0.5); float3 a0 = x - ox; m *= 1.79284291400159 - 0.85373472095314 * (a0*a0 + h*h); float3 g; g.x = a0.x * x0.x + h.x * x0.y; g.yz = a0.yz * x12.xz + h.yz * x12.yw; return 130.0 * dot(m, g); } // FBM (分形布朗运动) float fbm(float2 p) { float value = 0.0; float amplitude = 0.5; for(int i=0; i<6; i++) { value += amplitude * snoise(p); p *= 2.0; amplitude *= 0.5; } return value; }

⚖️

能量守恒

反射光 + 折射光 ≤ 入射光。漫反射和镜面反射的总能量不能超过入射光能量。

📊

微表面理论

表面由无数微小镜面组成。Roughness控制这些镜面的取向分布，影响高光大小。

🔲

BRDF函数

双向反射分布函数，描述给定入射方向和观察方向的光照分布。PBR使用Cook-Torrance模型。

// Cook-Torrance BRDF float3 CookTorrance(float3 N, float3 L, float3 V, float roughness) { float3 H = normalize(L + V); float NDF = GGXDistribution(N, H, roughness); float G = SmithSchlickGGX(N, V, L, roughness); float3 F = SchlickFresnel(dot(H, V)); float3 numerator = NDF * G * F; float denominator = 4.0 * dot(N,V) * dot(N,L) + 0.0001; return numerator / denominator; } // GGX法线分布函数 float GGXDistribution(float3 N, float3 H, float roughness) { float a = roughness * roughness; float a2 = a * a; float NdotH = max(dot(N,H), 0); float NdotH2 = NdotH * NdotH; return a2 / (3.14159 * pow(NdotH2*(a2-1)+1, 2)); }
