# HTML 阅读版使用说明

> 历史版本说明：当前系列已恢复以 Markdown 为正式入口，主线 01—42 课均已完成。这里说明的 HTML 仅保留先前 01—24 的试验版，不再同步。请从[Markdown 总目录](00-系列总计划与目录.md)继续阅读。

双击本文件夹里的 **[index.html](index.html)**，用浏览器阅读。无需联网、账号或安装开发环境；请保留 `index.html`、`reader.css`、`reader.js`、`blink.html` 与 `assets` 文件夹之间的位置关系。

## 阅读和练习

- 左侧目录按阶段排列，一次显示一课。搜索可以查标题和正文；手机窄屏用顶部“目录”按钮展开。
- 图片下面有“点击放大”按钮，可切换适合窗口与原始尺寸，按 Esc 关闭。
- 每课练习区可以折叠，检查项可以勾选；课末的“我已经练习过这一课”用于累计练习进度。
- “字号 A”在三档正文字号间切换。“打印”打印当前课；打印前可展开想保留的练习。
- 进度保存在当前浏览器本机存储中，不上传、不跨设备同步。某些浏览器限制本地文件存储时，页面会提示记录可能不能保存。
- 首页“继续上次阅读”会回到上次打开的编号课。移动文件或换浏览器后，本机记录可能不共用。

## 眨眼练习

第 24 课嵌入了[blink.html](blink.html)，也可以单独打开。默认是程序绘制的眼睑示意；选择自己的三张 PNG 后，可以切换为自己的头像。

工具检查尺寸一致性，但不会自动对齐人物，不修改原文件，也不导出动画。刷新后请重新选择图片。默认不自动播放，可先逐步观察。

## 以后怎样维护正文

编号 Markdown 是可编辑源稿，HTML 是生成后的阅读版。修改源稿不会立即改变已经生成的页面，需要重新构建。

维护时安装 Python 及 Markdown 库，然后在本文件夹运行：

```powershell
python -m pip install markdown
python build_reader.py
```

重新打开或刷新 `index.html` 即可。日常阅读完全不需要 Python。所有正文被嵌入 HTML，不通过 `fetch` 请求本地 Markdown，因此可以直接以本地文件方式打开。

`reader.css` 控制排版，`reader.js` 控制导航和记录，`blink.html` 是独立工具。请只在需要维护阅读器时修改这些文件。

## 配图说明

图文教程配图使用内置 image_gen 生成，提示词与检查记录位于 `assets` 中的记录文档。角色和步骤图帮助观察关系；不同格之间可能存在细小差异，不应直接当作精确比例模板或对齐的动画帧。

HTML 为透明底配图提供白色底板。实际练习请从自己的同一份画稿复制修改，保留可编辑图层，并自行导出一致的状态图。
