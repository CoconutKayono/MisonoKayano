# 角色小作品：运行与练习说明

这是第 39—42 课随附的 **Python 桌面示例**。默认显示程序绘制的简化脸；载入你自己画的四张 PNG 后，可以眨眼、暂停检查、点击微笑。不会上传或修改原图，不依赖 HTML，不导出 GIF 或视频。

## 1. 先检查 Python 和 Tkinter

在终端运行：

```powershell
python --version
python -m tkinter
```

第二条应打开 Tk 演示窗口，关闭后继续。建议使用带 Tcl/Tk 的 Python 3.10 或更新版本。本示例没有第三方 Python 包依赖，Tkinter 属于部分安装中可能缺少的可选组件。

检查方法见 [Python 官方 Tkinter 文档](https://docs.python.org/3/library/tkinter.html)。如果系统使用 `py` 启动 Python，可将下面命令中的 `python` 换成 `py`。

## 2. 运行示例

在当前文件夹中打开终端，运行：

```powershell
python character_demo.py
```

如果不确定终端当前目录，可以在文件管理器进入本文件夹，再使用“在终端中打开”。程序入口：[character_demo.py](character_demo.py)。

首次运行默认暂停在睁眼状态。先按“睁眼、半闭、闭眼、微笑”看静态差别，再按“播放”。

## 3. 放入自己的图

从自己的同一源画布导出以下四张文件。它们必须尺寸相同、人物位置一致，建议先使用便于观看的 480 × 480：

| 名字 | 图像 |
| --- | --- |
| `open.png` | 平静睁眼 |
| `half.png` | 半闭眼 |
| `closed.png` | 完全闭眼 |
| `smile.png` | 微笑 |

有两种载入方式：

1. 放进程序旁边的 `my_frames` 文件夹。四张齐全时，下次启动自动载入。
2. 放进任意自己的素材目录，点击“载入我的图片文件夹”选择。这个临时选择不会跨启动保存。

缺文件、尺寸不一致或 PNG 无法读取时，程序会显示错误，保留之前的素材。点击“恢复示意”可以回到程序自带的简化图形。教程配图没有作为你的动画帧自动装入。

程序使用 Tk 的 PNG 读取功能，并保留图片对象引用。较大图片用同一个整数倍率在内存中缩小；四张共享同一位置，原文件不变。整数抽样可能损失细节，正式展示可在绘画软件里统一导出更合适的尺寸。

## 4. 按钮与预设

- **播放 / 暂停：** 开始一轮眨眼，或停在当前状态。
- **四个状态按钮：** 切到对应状态并暂停，用来检查素材。
- **点击画面 / 点击微笑：** 微笑约 900 ms，再从睁眼重新开始眨眼；再次点击延长到最新一次点击后 900 ms。
- **十字参考线：** 固定在窗口中心，用来观察画稿是否跳动；不是自动检测的鼻尖定位线。
- **短眨练习：** 一轮 3000 ms，时间为 1000、80、80、80、1760。
- **等时对照：** 五步各 600 ms，整轮仍为 3000 ms。
- **慢放检查：** 默认五段统一放慢四倍，整轮 12000 ms。

从手动暂停状态点击画面，也会进入微笑反馈并恢复播放。需要继续检查时再按某个手动状态按钮。

## 5. 读代码时先看哪里

| 位置 | 解决的问题 | 对应课 |
| --- | --- | --- |
| `FILES`、`load_frames`、`validate_dimensions` | 找到四张图片、检查尺寸、统一缩放 | 39 |
| `TIMINGS`、`frame_at` | 根据实际经过时间选取图像状态 | 40 |
| `Player.smile`、`Player.current` | 微笑优先、重复点击、恢复规则 | 41 |
| `launch` 中的 `DrawingApp` | 将控制器结果画到窗口、连接按钮 | 42 |

先读控制器与时间表，不必一开始逐行读完整个界面代码。改变图片不要求修改这些函数，只需要替换同尺寸的素材。

## 6. 不打开窗口的逻辑检查

```powershell
python character_demo.py --self-test
```

输出 `PASS` 表示内置的时间边界、循环、点击优先级、重复点击、暂停恢复与尺寸规则检查通过。它不等于你的画稿已经对齐，也不代替可见窗口的人工检查。

## 7. 排错

| 现象 | 先做什么 |
| --- | --- |
| `python` 找不到 | 检查 Python 安装，或尝试 `py --version` |
| 缺少 `tkinter` 或无法找到 Tcl/Tk | 用带 Tcl/Tk 的 Python，先通过 `python -m tkinter` 检查 |
| 一直是示意脸 | 检查四张名字，或手动选择实际素材目录 |
| 报尺寸不一致 | 回绘画软件使用同一画布范围重新导出四张 |
| 画稿太小或锯齿明显 | 统一导出适合 480 像素显示范围的图片，不分别缩放 |
| 头发或鼻子在跳 | 回第 39 课修素材位置，先别改时间表 |

窗口的背景色是预览背景；PNG 透明区域透出该颜色。这个程序不是桌面透明悬浮宠物，也没有打包安装器；它是能替换自己画稿的第一版交互作品。
