## 这套卡怎样教

- 一张只解决一个核心问题，最多三个重要新概念。
- 先说学完能做什么，再用画面和直觉解释。
- 分成“必须掌握、理解即可、暂时跳过”三层。
- 核心代码尽量短，完整可复制示例放在后部。
- 每张有一次单变量预测实验、三个结论、两个自测问题和一个最小实践。
- GPU 架构、调度与平台细节在当前效果不需要时明确写“现在不用学”。
