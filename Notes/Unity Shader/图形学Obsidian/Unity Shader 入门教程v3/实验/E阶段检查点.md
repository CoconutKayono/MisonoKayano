## 3. 先分场景验证，再谈组合

共同基线为 URP Forward、Linear、单 Base Game Camera、静态不透明对象。关闭 MSAA、XR、动态分辨率、GPU Resident Drawer、Depth Priming、SSAO 和额外后处理。阴影只在对应 E02/E03 实验中开启。

E07/E08 开启 Render Graph，Renderer 的 Intermediate Texture=Always。**两个描边 Feature 先分别启用**；同时使用时，一条最终黑线无法直接说明来自壳体还是屏幕检测。

| 实验 | 准备与避免的干扰 |
| --- | --- |
| E05 | 内置 Cube + MeshFilter；进入 Play 生成私有 Mesh；不拿 SkinnedMeshRenderer 直接代替 |
| E06 | Capsule/Sphere 需有有效切线；MatCap 脚本在 Play 克隆材质，应修改 Renderer 当前实例 |
| E07 | 主体 URP/Lit；指定 E07Outline Layer；描边材质只赋给 Feature，不替换主体 |
| E08 | 主体 URP/Lit；两个不重叠的 GameObject Layer 组；ID 材质值分别为 1/2 |

E05 Shader 没有 DepthNormals Pass；若直接把它带入 E08，法线图未必含有正确物体。阶段整合不能假定每个教学 Shader 都是完整生产 Shader，这正是进入 F01 要解决的几何与数据一致性问题。

## 4. 阶段作品：材质与轮廓研究板

用 Sphere、Capsule、Cube 或已有可用头模搭建一张静态研究板即可，不需要为了验证机制另做完整角色资产。研究板应留下以下五组对照记录。

1. **明暗与阴影**：同一光方向下区分 Half-Lambert 分类和外物投影，记录 Ramp 合成顺序。
2. **面部与法线**：说明面部角度数据、普通法线与描边方向各自存在哪个空间；完成一次转头/平移预测。
3. **材质响应**：固定物体分别移动灯与相机，比较阈值高光、发流和 MatCap；解释至少一次不随灯运动的图案。
4. **轮廓宽度**：用 E07 记录近/远、整体缩放、非均匀缩放和硬边接缝；写明宽度单位与例外。
5. **边界分类**：用 E08 分别显示深度、法线、ID，记录一次“同组 ID 看不到组内边”的反例，并验证前方物体遮挡 ID。

可将主体和轮廓截图并排记录，但不把“肉眼好看”作为唯一标准。每个结果应有明确输入、预期、实际观察、资源/Draw 证据和适用范围。

## 5. 关键验收题与答案

1. **改变光照法线会自动改变模型剪影吗？** 不会，位置未变；外扩几何需要另一步。
2. **跨相同位置平滑总是正确吗？** 不一定，重合薄层或设计硬边可能不应合并。
3. **为什么 UV 中保存的方向可能在骨骼动画下失效？** 它未必参与与顶点/法线相同的变形，必须设计重建路径。
4. **高光遮罩和发流方向可以互相替代吗？** 不能，一个决定区域，一个决定方向响应。
5. **基础 MatCap 是实时世界环境反射吗？** 不是，本例按观察空间法线查预制颜色。
6. **为什么反壳像素偏移要乘 w？** 让透视除法后得到预定 NDC 偏移。
7. **投影偏移 3 像素是否所有线段都正好 3 像素厚？** 不保证，几何插值、尖角、深度和采样都会影响最终轮廓。
8. **E08 的两个 ID 是否对应所有对象的唯一身份？** 不是，只区分两个组与未标记区域。
9. **ID 重绘为什么需要现有深度？** 为了避免将隐藏对象标签写到前景上。
10. **相同深度和法线时，颜色不同能否自动生成 ID 边？** 不会，必须真的写入不同 ID。
11. **同时启用反壳与屏幕描边是否必定更好？** 不一定，可能重复加粗、暴露数据差异或增加成本，应先分别验证。
12. **完成这些卡是否意味着可以稳定交付动画角色？** 还不能，需要多 Pass 一致性、透明/裁剪、空间与时间抗锯齿、色彩和平台验证。
