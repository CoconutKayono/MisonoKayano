# 先做出二段明暗，再向下深入

你现在不需要先学完整 GPU 架构。第一阶段的终点是一颗能响应主光方向、可调整明暗分界的二段明暗球。

## 第一阶段：看懂方向，做出明暗

| 卡片      | 单个核心问题                  | 可观察结果             |
| ------- | ----------------------- | ----------------- |
| N00，已生成 | Shader 怎样决定最简单的表面颜色？    | 方块从红变绿            |
| N01，已生成 | 向量的三个数字怎样表示位移？          | 方块沿指定轴移动          |

| N03，已生成 | 同样的右方，为什么旋转后不同？         | 分清世界右方和物体右方       |
| N04，待生成 | 法线怎样表示表面朝向？             | 从表面想象并辨认垂直箭头      |

## 第二阶段：让角色效果成立

完成二段明暗球后再安排这些小问题，每个问题独立成卡：

- 朝向光的暗面与被别的物体挡住的阴影有什么区别？
- 怎样让主体接收 URP 阴影？
- 怎样做最简单的反壳描边，再单独处理宽度？
- 发梢应该裁剪还是半透明？先做单一方案，再比较限制。
- 为什么动画后主体、阴影或描边对不上？

具体编号在开始这一阶段时确定，避免现在就被完整工程细节压住。

## 什么时候再读底层

| 遇到的问题 | 再回来学习 |
| --- | --- |
| 不明白某个 Pass 为什么没有执行 | URP Pass 选择与 LightMode |
| 自定义效果需要多张中间图 | Render Graph 与资源寿命 |
| 效果正确但明显慢 | GPU 时间、覆盖、采样和提交成本 |
| 需要 Compute 或异步任务协作 | 资源依赖与同步 |
| 需要针对某类手机优化 | 分块渲染、附件存储与平台细节 |

Wave、Occupancy、Barrier、Fence 和 tile memory 现在不用学。等它们能够回答你正在遇到的具体问题，再参考原版百科全书相应卡片。
