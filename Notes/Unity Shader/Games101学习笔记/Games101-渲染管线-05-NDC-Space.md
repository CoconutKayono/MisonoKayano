# 05 NDC Space：归一化设备坐标

## 它是什么？

NDC 是 Normalized Device Coordinates，中文通常称为归一化设备坐标。它是透视除法之后得到的坐标：

$$
p_{ndc}=(x_{ndc},y_{ndc},z_{ndc})
$$

它已经不再需要 $w$，并且位于固定的归一化范围内。

## 常见范围

在许多课程和图形学约定中：

$$
x_{ndc},y_{ndc}\in[-1,1]
$$

$z$ 的范围可能是 $[-1,1]$ 或 $[0,1]$，具体取决于图形 API 和坐标系约定。

## 为什么需要 NDC？

屏幕分辨率可以是 $800\times600$、$1920\times1080$ 或其他尺寸。NDC 把可见区域规范化到固定范围，后面只需要通过视口变换映射到具体屏幕尺寸。

## NDC 还不是像素坐标

```text
NDC 中心：大约是 (0, 0)
屏幕中心：大约是 (width / 2, height / 2)
```

把 NDC 变成像素范围，需要 [[Games101-渲染管线-06-视口变换]]。

## 深度的意义

NDC 中的 $z$ 会参与后续深度比较。但“$z$ 越小越近”还是“$z$ 越大越近”，必须按照当前投影和深度测试约定来判断。
