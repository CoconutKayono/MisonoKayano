01

材质，就是光的回答

课程主线 · 官方课件 3–5 页
给定一束从某个方向来的光：朝相机的那个方向，会有多少光？

几何告诉我们光在哪里与表面相遇，光照告诉我们到达了多少光，材质则决定这次相遇怎样改变光。表面的颜色只是这种行为的一部分：两块同样“红色”的物体，一个可能是哑光塑料，另一个可能是金属漆。

本讲用 BRDF（双向反射分布函数）描述局部表面的反射。它的输入是入射方向与出射方向；输出是一个“把入射辐照度转成出射辐亮度”的比例密度。

fr(ωi,ωo)=dLo(ωo)dEi(ωi)=dLo(ωo)Li(ωi) cos⁡θi dωif_r(\omega_i,\omega_o)=\frac{\mathrm d L_o(\omega_o)}{\mathrm d E_i(\omega_i)}=\frac{\mathrm d L_o(\omega_o)}{L_i(\omega_i)\,\cos\theta_i\,\mathrm d\omega_i}BRDF 的单位为 sr⁻¹；它不是一个必须小于 1 的概率。
符号含义要记住的区别
Lᵢ、Lₒ入射 / 出射辐亮度，W·m⁻²·sr⁻¹描述某个方向上的光，不是所有方向的总和。
E辐照度，W·m⁻²到达单位表面积的功率；把方向贡献积分后得到。
ωᵢ、ωₒ单位方向向量每个方向由极角 θ 与方位角 φ 描述。
dω立体角微元球坐标下 dω = sinθ dθ dφ。
n、H²宏观法线、其上方半球本页反射积分在表面同侧半球上进行。
ρ、η反照率、折射率一个描述能量反射比例，一个决定介质内光的传播性质。

把所有入射方向的贡献加起来，就回到熟悉的渲染方程：

Lo(x,ωo)=Le(x,ωo)+∫H2fr(x,ωi,ωo)Li(x,ωi)(n ⁣⋅ ⁣ωi) dωiL_o(x,\omega_o)=L_e(x,\omega_o)+\int_{H^2} f_r(x,\omega_i,\omega_o)L_i(x,\omega_i)(\mathbf n\!\cdot\!\omega_i)\,\mathrm d\omega_i

灯光进入 LiL_i，材质进入 frf_r，入射投影进入余弦项。BRDF 固定时，改变灯光会改变外观；灯光固定时，改变 BRDF 也会改变外观。纹理还可以让参数随位置 x 变化。

“材质 = BRDF”是本讲反射问题的简化视角。玻璃需要描述透射的 BTDF；反射与透射合称 BSDF。皮肤、蜡等显著的次表面散射还会涉及不同入射点与出射点，单个局部 BRDF 不够。
02

漫反射：为什么偏偏要除以 π？

课程主线 · 官方课件 6–8 页

把粉笔近似成理想漫反射体。同一点、同一照明下，从不同方向观察，它的出射辐亮度相同。这是 Lambertian（朗伯）反射。模型里 BRDF 是与两个方向都无关的常数 c。

反照率是 ρ，为什么不能直接写 fᵣ = ρ？
  1. 先问反照率的定义。给定一束入射光，ρ 是反射到整个上半球的总能量占入射能量的比例。
  2. 每个方向对应的通量带投影因子。某方向出射的功率为 dΦₒ = Lₒ cosθₒ dA dωₒ。因此即使 Lₒ 恒定，各个等立体角小锥体携带的功率也不相同。
  3. 对上半球积分，求出常数。ρ = ∫ c cosθₒ dωₒ。关键就是算这个余弦加权半球的“大小”。
∫H2cos⁡θ dω=∫02π∫0π/2cos⁡θsin⁡θ dθ dϕ=2π⋅12=π\int_{H^2}\cos\theta\,\mathrm d\omega=\int_0^{2\pi}\int_0^{\pi/2}\cos\theta\sin\theta\,\mathrm d\theta\,\mathrm d\phi=2\pi\cdot\frac12=\pi
ρ=cπ⟹fr=ρπLo=ρπEi\rho=c\pi\quad\Longrightarrow\quad\boxed{f_r=\frac{\rho}{\pi}}\qquad\boxed{L_o=\frac{\rho}{\pi}E_i}没有余弦加权时，半球立体角是 2π；这里积分的是 cosθ，所以结果是 π。

课上也可以用均匀环境光来推导：设每个方向入射辐亮度都是 L，则 Eᵢ = πL，得到 Lₒ = πcL。对不吸收的理想白色漫反射体，ρ = 1、Lₒ = L，于是 c = 1/π。均匀照明只是方便推导的特例，ρ/π 对非均匀照明也成立。

实验 1｜转动光源，改变反照率

LAMBERTIAN

设垂直于光束的单位面积收到 1 W/m²，表面实际接收 Eᵢ = cosθᵢ。右侧每根出射箭头等长表示辐亮度相同；箭头并不表示每个方向携带相同功率。

算一遍，才能真的记住

若 ρ = 0.6，入射辐照度 Eᵢ = 10 W/m²，那么 fᵣ ≈ 0.191 sr⁻¹，Lₒ ≈ 1.910 W/(m²·sr)。反射总出射度为 Mₒ = πLₒ = 6 W/m²，恰好是入射的 60%。如果误写 fᵣ = 0.6，总反射比例会变成 0.6π ≈ 1.885，凭空产生能量。

“均匀反射”要说清楚：朗伯表面各方向的出射 radiance 相同；不是各方向的 flux 相同，也不是整件物体每个位置一样亮。球上不同点的法线不同，Eᵢ 也不同，仍然会形成明暗。
记忆连接：BRDF 是 ρ/π，积分里的 cosθ 来自投影。这两件事各有来源，不要把余弦重复乘进 BRDF。
03

从一片高光，到唯一的反射方向

课程主线 · 官方课件 9–15 页

漫反射把出射辐亮度均匀地铺向各方向；glossy（光泽反射）则把反射集中在某个方向附近，形成一个有限宽度的反射瓣。它不是金属的专利：塑料、清漆、陶瓷釉面也能出现高光。

模型方向分布观察到的特征
理想漫反射BRDF 常数没有随视点移动的尖锐镜面高光。
Glossy某些方向的 BRDF 较大模糊的光源像；通常粗糙度越大，高光越宽。
理想镜面能量集中于唯一合法方向清晰反射周围环境，适合用 δ 分布表示。

反射方向从几何直接得到

将 ωᵢ 分解为法线分量与切线分量。反射后，法线分量保持不变，切线分量反号。因此：

ωo=2(n⋅ωi)n−ωi,θo=θi\omega_o=2(\mathbf n\cdot\omega_i)\mathbf n-\omega_i,\qquad\theta_o=\theta_i若程序使用沿光传播方向的入射向量 d = −ωᵢ，则公式变成 r = d − 2(d·n)n。

在局部球坐标中，出射方位角与入射方位角相差 π。不要只检查入射角等于反射角：方向还必须位于入射方向与法线张成的平面内。

为什么镜面 BRDF 不能“只有某一点等于 1”？

普通连续积分中，一个孤立方向的立体角测度为零；在那里写一个有限数字，其积分仍然为零。镜面需要一个积分有限、能量却集中在一点的 Dirac δ 分布。

fr(ωi,ωo)=F(ωi) δΩ(ωo−R(ωi))∣n⋅ωo∣f_r(\omega_i,\omega_o)=\frac{F(\omega_i)\,\delta_{\Omega}(\omega_o-R(\omega_i))}{|\mathbf n\cdot\omega_o|}δΩ 是相对于立体角的方向 δ；R 为镜面反射映射。对出射方向做余弦加权积分，结果为反射比例 F。

这解释了路径追踪中的特殊处理：随机挑一个半球方向，几乎不可能恰好命中镜面方向。应直接计算反射方向，沿它继续追踪；镜面事件的离散概率也不能与普通立体角 PDF 混为一谈。

观察线索：镜子不是“固定的银灰色”。黑暗环境里的镜子可能很暗，白色环境里的镜子可能很亮。它把环境的方向结构保留下来了。
04

进入另一种介质，光会怎样转弯？

课程主线 · 官方课件 16–19 页

在玻璃或水面上，光不仅反射，还可以进入另一侧。平整界面的透射方向由 Snell 定律决定。ηᵢ 和 ηₜ 分别是入射与透射介质的折射率，两个角都相对界面法线测量。

ηisin⁡θi=ηtsin⁡θt⟹sin⁡θt=ηiηtsin⁡θi\eta_i\sin\theta_i=\eta_t\sin\theta_t\qquad\Longrightarrow\qquad\sin\theta_t=\frac{\eta_i}{\eta_t}\sin\theta_i

从较低折射率进入较高折射率介质，例如空气 → 玻璃，折射角变小，光线靠近法线；反过来则远离法线。常用近似值：空气 1.00，水 1.333，普通玻璃约 1.5。实际折射率随波长和具体材料变化。

实验 2｜亲手找到全内反射的边界

SNELL'S LAW
入射光反射光透射光

这里画的是光的实际传播方向，入射箭头指向交点。线宽不编码能量，反射与透射的比例由下一节的菲涅尔计算。

根号里的负数，揭示了一个物理现象

cos⁡θt=1−(ηiηt)2(1−cos⁡2θi)\cos\theta_t=\sqrt{1-\left(\frac{\eta_i}{\eta_t}\right)^2(1-\cos^2\theta_i)}

如果根号内小于零，就不存在满足折射定律的传播透射方向。这发生在从高折射率进入低折射率，且入射角足够大的时候，称为全内反射（TIR）。

θc=arcsin⁡ηtηi(ηi>ηt),θi>θc⇒TIR\theta_c=\arcsin\frac{\eta_t}{\eta_i}\quad(\eta_i>\eta_t),\qquad\theta_i>\theta_c\Rightarrow\text{TIR}

玻璃 → 空气的临界角约为 41.81°；水 → 空气约为 48.61°。恰好处于临界角时，折射方向沿界面，θₜ = 90°。实验中将玻璃 → 空气设为 45°，就能看到透射方向消失。

水下的“斯涅尔窗口”

人在水下抬头看，水面上方整个半球的景物被压缩进一个圆锥视野。用光路可逆性从眼睛向外想：只有相对竖直方向夹角不超过约 48.61° 的视线能穿过水面，圆锥的完整张角约 97.2°。更外侧的视线发生全内反射，看到水下环境的倒影。平静水面时边界最清楚。

全内反射里的“全”，描述无吸收理想界面上的反射比例为 1，不代表在有吸收介质中走完整段路径后仍没有能量损失。本讲的几何光学模型也不展开倏逝场。
05

菲涅尔：方向确定后，还缺一个比例

课程主线 · 官方课件 20–23 页 · 补充参考：PBRT 4e §9.3
正对玻璃看，容易看穿；沿着表面斜看，为什么越来越像镜子？

反射定律和 Snell 定律只回答“往哪里走”。Fresnel（菲涅尔）反射率 F回答“反射掉多少”。对常见无吸收介电界面，反射比例通常在掠射时显著升高；没有全内反射时，剩余功率进入另一侧。

先抓住法向入射的一个数字

F0=(ηi−ηtηi+ηt)2F_0=\left(\frac{\eta_i-\eta_t}{\eta_i+\eta_t}\right)^2

空气 → 玻璃（1 → 1.5），F₀ = 0.04。正对界面时，大约 4% 的入射功率被反射。它不是“所有非金属永远都是 4%”：空气 → 水只有约 2.0%，其他介质组合也不同。

完整公式：两种偏振分别计算

s 偏振的电场垂直于入射平面，p 偏振的电场位于入射平面。对无偏振光，通常取两种功率反射率的平均：

Rs=(ηicos⁡θi−ηtcos⁡θtηicos⁡θi+ηtcos⁡θt)2,Rp=(ηtcos⁡θi−ηicos⁡θtηtcos⁡θi+ηicos⁡θt)2R_s=\left(\frac{\eta_i\cos\theta_i-\eta_t\cos\theta_t}{\eta_i\cos\theta_i+\eta_t\cos\theta_t}\right)^2,\quad R_p=\left(\frac{\eta_t\cos\theta_i-\eta_i\cos\theta_t}{\eta_t\cos\theta_i+\eta_i\cos\theta_t}\right)^2
F=Rs+Rp2F=\frac{R_s+R_p}{2}适用于本节非吸收介电界面；发生全内反射时直接取 F = 1。

不必先死记两长串分式。先记住三个检查点：法向时两者相同；空气 → 玻璃的 p 偏振在约 56.3° 的布儒斯特角降到零；不同折射率的界面在掠射极限反射率趋近 1。

Schlick：一个便宜又直观的近似

F(θ)≈F0+(1−F0)(1−cos⁡θ)5F(\theta)\approx F_0+(1-F_0)(1-\cos\theta)^5

它用 F₀ 锚定正面反射，用五次幂表达掠射时的上升。对于一些常见介电质很方便，但不是所有介质、所有角度都准确。高折射率向低折射率传播时，必须先判定全内反射，不能盲目套用这一式。

金属和非金属，差在哪里？

导体的光学折射率一般用复数 η + iκ 描述；κ 与吸收相关。金属的可见反射率常随波长明显变化，所以铜、金会有带颜色的镜面反射。对足够厚的金属，宏观上通常不考虑可见光穿透。

常见未镀膜介电材料的界面镜面反射通常接近无色，但进入内部的光可以被选择性吸收、散射，产生有颜色的漫反射或透射。不要把“金属有高光，非金属没有高光”作为分类方法。

F 和 1−F 是理想无吸收界面的功率分配。跨折射界面传播时，radiance 与方向立体角还发生变换，不能因此断言透射 radiance 永远等于 (1−F)Lᵢ；具体输运公式含折射率比例相关因子。
06

微表面：远处是材质，近处是几何

课程主线 · 官方课件 24–29 页

从很远处看一片有波纹的水，无法分辨每个波面，却仍能看到大片闪亮的反射。假如把粗糙表面放大，它可能由许多倾斜的小面组成。微表面模型假设每个小面都是理想镜子，只是它们的法线各不相同。

如果每片都是镜子，为什么整个物体的反射却是模糊的？

因为观察一个像素时，我们平均了大量不同法线的微小镜面。不同小面把光送到不同方向，聚合后得到有宽度的反射瓣。我们不再显式建立每一片几何，而统计“朝某个方向的小面有多少”。

为什么只有半程向量方向的微表面能帮上忙？

固定入射方向 ωᵢ 和观察方向 ωₒ。小镜子要把前者反射到后者，其法线必须平分两个向外方向。因此：

h=ωi+ωo∥ωi+ωo∥,m=h\mathbf h=\frac{\omega_i+\omega_o}{\|\omega_i+\omega_o\|},\qquad\mathbf m=\mathbf h

注意，我们不是在统计所有小面，而是在查询法线恰好位于 h 附近的小面的密度。观察方向改变，h 跟着改变，于是查询到的微表面数量不同，高光便会移动。

fr(ωi,ωo)=D(h) F(ωi⋅h) G(ωi,ωo)4(n⋅ωi)(n⋅ωo)\boxed{f_r(\omega_i,\omega_o)=\frac{D(\mathbf h)\,F(\omega_i\cdot\mathbf h)\,G(\omega_i,\omega_o)}{4(\mathbf n\cdot\omega_i)(\mathbf n\cdot\omega_o)}}此式用于同在宏观表面上半球的反射；D、G 的具体形式取决于微表面模型。
D：有多少朝向合适的小镜子？
F：每片小镜子反射多少？
G：光进得去、出得来吗？
课件用“法线分布变散 → diffuse”来建立外观直觉。更严格地说，镜面微表面的分布变宽得到的是更粗糙的镜面反射，一般不会自动成为 fᵣ = ρ/π 的朗伯反射。真正漫反射常与内部散射等过程有关。
07

把 D、F、G 逐个拆开

微表面公式详解 · GGX 与 Smith 的具体形式为拓展 · 补充参考：PBRT 4e §9.6

D：法线分布函数，不是普通方向概率

D(m) 称为 NDF。直观上，D(m)dωₘ 表示单位宏观表面面积对应、法线位于小立体角 dωₘ 内的微表面面积。因为小面可能倾斜，把它们投影回宏观表面后，面积才应该加起来等于 1：

∫H2D(m)(n⋅m) dωm=1\int_{H^2}D(\mathbf m)(\mathbf n\cdot\mathbf m)\,\mathrm d\omega_m=1

因此 D 不必小于 1，也不满足一般的 ∫D dω = 1。真正能作为一种法线采样 PDF 的是 D(m)cosθₘ，更高效的可见法线采样则还会考虑观察方向。

拓展：给 D 一个可计算的形式——各向同性 GGX
DGGX(h)=α2π[(n⋅h)2(α2−1)+1]2D_{\mathrm{GGX}}(\mathbf h)=\frac{\alpha^2}{\pi\left[(\mathbf n\cdot\mathbf h)^2(\alpha^2-1)+1\right]^2}

α 越小，法线越集中在 n 附近；α 越大，分布越宽。GGX 有较明显的长尾，适合表现不少真实表面的高光。某些引擎把艺术参数 roughness 映射为 α = roughness²，这是一种参数约定，不是唯一标准。本页滑块直接控制 α。

F：要使用小镜子的入射角

光打在微表面上，应相对它的法线 h 计算角度，所以 cosθ = ωᵢ·h。这里容易写错为 ωᵢ·n。宏观表面可能看起来正对光源，但被选中的某片小镜子可能仍然倾斜。

G：方向对了，还可能被邻居挡住

Shadowing 表示入射光被别的小面挡住，到不了目标小面；masking 表示目标小面虽然反射了光，但通往观察者的方向被挡住。尤其在掠射方向，这些遮挡不可忽略。

拓展：实验使用的 Smith-GGX 几何项
G1(ω)=21+1+α2tan⁡2θ,G=G1(ωi)G1(ωo)G_1(\omega)=\frac{2}{1+\sqrt{1+\alpha^2\tan^2\theta}},\qquad G=G_1(\omega_i)G_1(\omega_o)

这里采用可分离的 Smith 近似；还有考虑高度相关性的联合几何项，数值并不完全相同。单次散射微表面模型忽略小面间多次反弹，粗糙度大时可能丢失较多反射能量，变得偏暗。不能简单归因于“粗糙就一定吸收更多”。

分母为什么不是随便补上的？

4(n·ωᵢ)(n·ωₒ) 来自微观镜面反射映射以及宏观与微观投影面积之间的换算。它把“小镜子数量 × 每片反射比例 × 可见比例”转换成宏观 BRDF。完整推导涉及方向变量变换，先把这个分母当作几何测度的校正，而不是额外的经验高光参数。

实验 4｜粗糙度如何改变高光？

GGX MICROFACET

球体使用 RGB F₀ = (0.72, 0.39, 0.16) 的示意金属、GGX + Schlick + Smith、固定的扩展光源方向采样；不加漫反射。显示经过色调映射。右图为入射角 30°、同一平面内的单通道 BRDF 切片，用 log₁₀(1+fᵣ) 纵坐标，便于同时看清峰与尾；它不是三维能量分布图。

建议先把 α 从 0.15 调到 0.7：高光逐渐变宽。再去掉 G，观察掠射附近的变化。最后冻结 F，可以分辨“几何分布变宽”和“掠射反射率升高”是两种不同原因。

不能把一个满额漫反射项和一个满额镜面项直接相加，再称它能量守恒。分层或混合材质需要分配能量；单纯加入漫反射不等于补回了微表面的多次散射。
08

把表面转一转，高光为什么会变？

课程主线 · 官方课件 30–36、39 页

观察电梯里的拉丝金属：纹理有明确的方向，高光常被拉长。这里真正关键的是微观结构沿不同切向方向的统计是否相同。

各向同性 Isotropic

固定光源与观察者，把材质局部坐标系绕法线转动，反射行为不变。等价地，同时给两个方向的方位角加上相同角度，BRDF 不变。它依赖 θᵢ、θₒ 和相对方位角 Δφ，通常只需 3 个角度变量。

各向异性 Anisotropic

旋转切线方向会改变反射。BRDF 还需知道光线相对“拉丝方向”的朝向，通常需要 4 个角度变量。材质常由切线 t、副切线 b、法线 n 建立局部坐标系。

fr(θi,ϕi;θo,ϕo)=fr(θi,θo,ϕo−ϕi)（各向同性）f_r(\theta_i,\phi_i;\theta_o,\phi_o)=f_r(\theta_i,\theta_o,\phi_o-\phi_i)\quad\text{（各向同性）}
各向同性不等于漫反射！一个圆对称的镜面高光也可以各向同性。各向同性要求“同时旋转两个方向”不变，不要求只移动观察者时亮度保持不变。

实验 5｜旋转法线分布的方向

ANISOTROPY

这是 GGX 斜率分布的等密度轮廓示意，坐标是 p = mₓ/m_z、q = mᵧ/m_z。每条椭圆对应相同的归一化半径；不是把高光照片旋转。圆点固定在世界斜率 (0.4, 0.1)，用于读取同一微表面法线的 D 值。

切换到各向同性，旋转切线后轮廓不变，查询值也不变。切回各向异性，轮廓随切线转动，固定方向对应的小面数量随之改变。拉丝金属、定向纤维能产生这类效应；真实织物还可能需要比单纯微表面更复杂的散射模型。

一个 BRDF 至少要守住哪些规则？

课程主线 · 官方课件 37–39 页

① 非负性：反射不能是负光

fr(ωi,ωo)≥0f_r(\omega_i,\omega_o)\ge 0

插值或拟合测量数据时可能出现负值，这是需要处理的非物理解。这里讨论被动、普通的反射材质。

② 线性：两盏灯的贡献可以相加

对固定材质，如果入射照明由 A、B 两部分组成，那么反射结果是各自结果之和。注意线性针对的是 BRDF 所定义的光照传输算子，不是说 BRDF 必须随入射角线性变化。

R[aLA+bLB]=aR[LA]+bR[LB]\mathcal R[aL_A+bL_B]=a\mathcal R[L_A]+b\mathcal R[L_B]

前提是在线性辐射量空间里运算。经过曝光压缩、色调映射、sRGB 编码后的像素值，一般不能这样直接相加。

③ 互易性：交换光源与相机

fr(ωi,ωo)=fr(ωo,ωi)f_r(\omega_i,\omega_o)=f_r(\omega_o,\omega_i)

对这里的普通互易反射材质，交换输入和输出方向，BRDF 值相同。这不表示两次拍照的像素值必然一样：两次照明、距离、投影、曝光可能都变了。

④ 能量守恒：积分不超过 1

∀ ωi,ρdh(ωi)=∫H2fr(ωi,ωo)(n⋅ωo) dωo≤1\forall\,\omega_i,\qquad\rho_{\mathrm{dh}}(\omega_i)=\int_{H^2}f_r(\omega_i,\omega_o)(\mathbf n\cdot\omega_o)\,\mathrm d\omega_o\le1

固定一束入射光，把所有出射方向的反射功率加总，不能多于入射功率。ρdh 是方向—半球反射率。利用互易性，也可以写成课件那种固定出射方向、对入射方向积分的等价形式。

尖峰超过 1 并不违法。例如 α = 0.1 时，GGX 在 h = n 处的 D = 1/(πα²) ≈ 31.83。密度可以很高，只要它足够窄且相关积分符合约束。判断 BRDF 是否守恒，要看余弦加权积分，而不是单点最大值。

一个 30 秒的错误检查

若有人提出常数 BRDF fᵣ = 0.5 sr⁻¹，它非负、互易，也能定义线性反射，但半球积分为 0.5π ≈ 1.57，所以不守恒。这些规则必须同时检查。

不写模型，能否直接测量真实材质？

课程主线 · 官方课件 40–47 页

可以。模型是我们对散射机制的近似；测量则是把样品放到受控光照下，记录不同入射与出射方向的响应。复杂的真实微结构会被包含进测得的反射数据。

测量装置其实就是一个“方向扫描器”

  1. 固定入射方向。使用已知光谱与强度的光束照亮样品，并标定它在表面产生的辐照度 Eᵢ。
  2. 扫描观察方向。移动传感器测 Lₒ；在窄角度、均匀照明等近似下，用 Lₒ/Eᵢ 估计该方向对的 BRDF。
  3. 再换一个入射方向。重复扫描。一般 BRDF 的两个方向各有两个角，形成四维方向数据。
  4. 校正、插值、存储。把离散采样变成能够在渲染过程中查询任意方向对的数据表示。

维度与存储：为什么数据很快就变大？

各向同性消去绝对方位角，方向维度从 4D 降到 3D。互易性允许避免交换方向后的重复测量，理想情况下可近似减少一半工作量。若再考虑位置变化、多个波长等，数据维度又会增加。

以课件展示的 MERL 数据规模为例，90 × 90 × 180 = 1,458,000 个方向样本，乘 3 个颜色通道。按每通道 8 字节计算，一个材料的数据部分约 35.0 MB（33.4 MiB）。实际采用半角 / 差角类重参数化，并非直接等间距存 θᵢ、θₒ、Δφ；这有助于更好地捕捉镜面结构。

难点不只在“测得够不够多”

挑战为什么难影响
掠射角投影面积小、照明足迹变化大，角度误差敏感。恰恰又是菲涅尔效应很重要的区域。
很尖的高光少量角度变化就可能让响应差几个数量级。粗采样会漏掉峰值，插值可能过度抹平。
逆向反射光返回接近光源方向，光源与传感器可能互相遮挡。某些特殊响应难以准确捕捉。
空间变化一块样品不同位置可能不同。一个均匀 BRDF 表无法保留全部纹理细节。

好的表示需要同时满足：存储紧凑、拟合准确、任意方向求值快，还要方便重要性采样。只有一张漂亮的数据曲线，却无法高效采样，会使路径追踪产生很大噪声。

图像式测量的直觉：已知形状的球体上，每个像素对应不同法线，于是一张照片能同时提供许多局部方向配置。但照明标定、遮挡、互反射与样品均匀性仍须处理。测量结果也只覆盖采样范围、光谱及所选散射模型所能表达的现象。

回到第 16 讲：材质如何进入路径追踪？

衔接与拓展 · 不要求在第 17 讲就掌握所有实现细节

路径追踪要计算一个方向积分。材质模型不仅决定被积函数，还影响怎样选择更有用的采样方向。固定观察方向 ωₒ，以概率密度 p(ωᵢ) 采样入射方向，蒙特卡洛估计为：

L^o=Le+1N∑k=1Nfr(ωi(k),ωo)Li(ωi(k))(n⋅ωi(k))p(ωi(k))\widehat L_o=L_e+\frac1N\sum_{k=1}^N\frac{f_r(\omega_i^{(k)},\omega_o)L_i(\omega_i^{(k)})(\mathbf n\cdot\omega_i^{(k)})}{p(\omega_i^{(k)})}

BRDF 回答“这个方向反射多少”；PDF 回答“我以多大概率选到这个方向”。它们相关但不同，不能把 fᵣ 直接当 PDF。尤其一个反射能量不等于 1 的材质，BRDF 自身更不满足普通概率归一化。

漫反射与余弦采样，为什么特别合拍？

fr=ρπ,p(ωi)=cos⁡θiπ⟹frcos⁡θip(ωi)=ρf_r=\frac\rho\pi,\qquad p(\omega_i)=\frac{\cos\theta_i}{\pi}\qquad\Longrightarrow\qquad\frac{f_r\cos\theta_i}{p(\omega_i)}=\rho

一个原本看起来复杂的路径权重，抵消后只剩反照率。这不是可以删掉公式里的 π 与 cos，而是采样分布恰好与模型匹配。若换成均匀半球采样 p = 1/(2π)，权重就变为 2ρ cosθᵢ。

微表面采样：先选小镜子，再反射

一种基础方案先以 pₘ(m) = D(m)(n·m) 采样微表面法线，再将固定 ωₒ 绕 m 反射得到 ωᵢ。转换到光线方向的 PDF 时，需要 Jacobian：

p(ωi)=pm(h)4∣ωo⋅h∣p(\omega_i)=\frac{p_m(\mathbf h)}{4|\omega_o\cdot\mathbf h|}

如果方向落到宏观表面下方，该反射事件不贡献上半球反射；实现必须正确处理。更好的方案会按可见法线分布采样，从而减少浪费。单纯把 NDF 数值当方向 PDF，往往会产生错误亮度。

拓展：BRDF 求值的最小结构（伪代码）
evaluateReflection(wi, wo, n, alpha, F0):
    NoI = dot(n, wi)
    NoO = dot(n, wo)
    if NoI <= 0 or NoO <= 0:
        return 0

    h = normalize(wi + wo)
    D = GGX_NDF(dot(n, h), alpha)
    F = F0 + (1 - F0) * (1 - dot(wi, h))^5
    G = SmithG1(NoI, alpha) * SmithG1(NoO, alpha)
    return D * F * G / (4 * NoI * NoO)

# 采样后累积路径权重，pdf 必须匹配实际采样策略：
throughput *= f * abs(dot(n, wi)) / pdf

这只是反射项求值结构，未包含纹理颜色空间、折射、法线贴图修正、混合采样、极限粗糙度与数值鲁棒性。α = 0 对应理想镜面，应另设分支处理，而不是把它硬塞进普通 GGX 公式。

第 16 讲告诉你怎么积，第 17 讲告诉你积的材质函数是什么。两讲在 fᵣ × cosθ / pdf 处接上了。

4. 某方向的 BRDF = 12 sr⁻¹，是否一定不守恒？

计算题 A：ρ = 0.8，Eᵢ = 5 W/m²，求漫反射出射辐亮度与出射度。

Lₒ = ρEᵢ/π = 4/π ≈ 1.273 W/(m²·sr)。Mₒ = πLₒ = 4 W/m²。注意 Lₒ 与 Mₒ 的单位不同，不能直接说两者相等。

计算题 B：空气进入折射率 1.5 的玻璃，入射角 30°，求折射角。

sinθₜ = (1/1.5)sin30° = 1/3，所以 θₜ ≈ 19.47°，比入射角更小，朝法线弯折。法向反射率 F₀ = ((1−1.5)/(1+1.5))² = 0.04；F₀ 是 0° 的值，不要把它误认成所有角度的精确 F。

解释题 C：一个各向同性材质从不同角度看仍有高光，这矛盾吗？

不矛盾。各向同性约束绕法线同时旋转入射与出射方向的行为不变；它仍然可以依赖 θᵢ、θₒ 和两方向的相对方位。只有理想漫反射进一步让 BRDF 对这些角度也都不变。

解释题 D：粗糙度变大，物体为什么有时显得更暗？

高光能量被摊到更宽的方向范围，当前观察方向的峰值可能降低；遮蔽也可能更强。此外单次散射微表面模型漏掉小面间多次反射，可能产生额外能量损失。显示曝光和环境结构也会影响观感，因此“更粗糙 = 更吸光”并不是一般物理定律。
