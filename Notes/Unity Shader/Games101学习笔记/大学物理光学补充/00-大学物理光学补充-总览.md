## 每篇笔记都按这个顺序阅读

1. **先观察图片**：不要急着读文字，先说出图里有什么、箭头往哪里走。
2. **想一个生活例子**：把抽象现象和镜子、水、灯、相机或彩虹联系起来。
3. **认识一个词**：例如“法线”就是表面的垂直线，“波长”就是相邻波峰的距离。
4. **只看一个公式**：先理解公式表达的变化关系，不要求马上推导。
5. **回到 GAMES101**：再看它为什么会出现在 Shader 或光线追踪里。

## 现在只需要先认识这些词

| 词 | 暂时把它想成 |
| --- | --- |
| 光线 | 光大致前进的箭头 |
| 波面 | 同一时刻处在相同“节拍”的位置连成的面 |
| 法线 | 从表面垂直竖起来的辅助线 |
| 反射 | 光碰到表面后弹回来 |
| 折射 | 光进入另一种材料后改变方向 |
| 亮度 | 某个方向、某个位置上有多少光到达 |
| 颜色 | 光谱经过人眼响应后形成的感觉和编码 |

## 物理公式的阅读方法

先问三个问题：

- 公式描述的是位置、方向、能量，还是颜色？
- 每个符号代表什么实际东西？
- 如果把某个量变大，结果应该变大还是变小？

例如：

$$
c=\lambda f
$$

先不用背。只要知道：在同一种传播环境中，光传播得越快，波长和频率的乘积就越大。

> [!note] 哪些内容可以以后再学？
> Maxwell 方程、复数振幅、完整 Fresnel 方程、Jones 矩阵和 Fourier 变换都保留在后文，但第一次阅读可以先看直观解释和“现在只需要记住”。

## 与 GAMES101 的学习节奏

- 学到第 1–4 讲时，先读 01，理解方向、法线和投影。
- 学到第 7–9 讲时，读 02 和 03，理解光照方向、余弦项和材质。
- 学到第 13–18 讲时，重点读 02、03，理解光线追踪、BRDF 和渲染方程。
- 学到第 19–20 讲时，读 04、05，理解相机、景深、颜色和采样。
