# FAQ：顶点如何组装成三角形

## Q1：顶点是在什么阶段组装成三角形的？

在常规三角形渲染管线中，图元装配发生在**顶点着色器之后、裁剪之前**。此时顶点已经被变换到裁剪空间。

```text
顶点缓冲与索引
    ↓
输入装配
    ↓
顶点着色器
    ↓
图元装配
    ↓
裁剪
    ↓
透视除法
    ↓
视口变换
    ↓
光栅化
    ↓
属性插值与片元着色
```

## Q2：图元装配是在裁剪空间进行的吗？

是的。顶点着色器通常输出裁剪空间坐标：

```glsl
gl_Position = projection * view * model * position;
```

此时每个顶点的位置形式为 `(x_c, y_c, z_c, w_c)`。GPU 根据绘制时指定的拓扑结构，把这些顶点组装成三角形、直线或点。

例如，三角形列表拓扑下：

```text
索引：0, 1, 2, 2, 1, 3
```

表示：

```text
三角形一：顶点 0、1、2
三角形二：顶点 2、1、3
```

## Q3：输入装配和图元装配有什么区别？

输入装配负责读取顶点缓冲、索引缓冲，并根据拓扑解释顶点顺序。

图元装配负责把顶点着色器输出的顶点组合成点、线、三角形等几何单元。

可以简单理解为：

```text
输入装配：读取并组织输入数据
图元装配：形成真正的图元
```

实际 GPU 可能流水化或重叠执行这些阶段，但从逻辑上可以这样区分。

## Q4：为什么必须先组装三角形，再进行裁剪？

因为裁剪的对象是完整图元，而不是孤立顶点。

如果一个三角形跨越近裁剪面，裁剪过程需要：

1. 找出三角形边与裁剪面的交点；
2. 生成新的交点顶点；
3. 保留三角形位于视锥内部的部分；
4. 将剩余部分重新组装成新的三角形；
5. 为新顶点计算 UV、法线等属性。

如果只单独判断每个顶点是否在视锥内，就无法知道三角形的边如何穿过裁剪面。因此必须先知道哪些顶点属于同一个三角形，以及三角形的三条边在哪里。

## Q5：为什么在裁剪空间裁剪，而不是在屏幕空间裁剪？

因为裁剪空间仍然保留齐次坐标中的 `w`。

在常见的 OpenGL 风格约定下，裁剪范围可以写成：

```text
-w ≤ x ≤ w
-w ≤ y ≤ w
-w ≤ z ≤ w
```

这些条件在裁剪空间中是线性的，适合计算三角形边与裁剪平面的交点。

如果提前进行透视除法：

```text
x_ndc = x_c / w_c
y_ndc = y_c / w_c
z_ndc = z_c / w_c
```

当三角形靠近或穿过相机平面时，`w` 可能接近零，容易出现无穷大、坐标符号翻转、三角形形状错误等问题。

因此正确顺序是：

```text
裁剪空间组装三角形
    ↓
裁剪
    ↓
透视除法
    ↓
视口变换
```

## Q6：裁剪后还可能产生新的顶点吗？

会。三角形被裁剪后，原来的三个顶点可能变成一个新的多边形。随后管线会将这个多边形重新三角化，产生一个或多个新的三角形。

新生成的顶点不仅需要计算位置，还需要计算对应的 UV、顶点颜色、法线、切线以及其他待插值数据。

## Q7：光栅化是在屏幕空间重新组装三角形吗？

不是。三角形在光栅化之前已经组装完成了。

光栅化器接收到的是一个已经存在的屏幕空间三角形，主要负责：

- 判断三角形覆盖哪些像素或采样点；
- 生成片元；
- 准备后续属性插值所需的信息。

因此光栅化不是“把屏幕上的顶点重新组成三角形”，而是把已经存在的三角形转换成被覆盖的屏幕采样点。

## Q8：属性插值发生在哪里？

属性插值发生在光栅化阶段之后、片元着色器执行之前。

例如三个顶点分别有不同的 UV：

```text
A：UV = (0, 0)
B：UV = (1, 0)
C：UV = (0, 1)
```

当光栅化器发现某个像素采样点位于三角形内部时，就会根据该采样点相对于三个顶点的位置，计算该点的 UV、法线、颜色等属性。

流程可以表示为：

```text
三角形顶点属性
    ↓
像素采样点在三角形中的位置
    ↓
插值得到片元属性
    ↓
片元着色器计算颜色
```

透视投影下，UV、颜色、法线等属性通常使用透视正确插值，而不是简单的屏幕空间线性插值。

## Q9：整个过程最准确的概括是什么？

```text
顶点着色器：
    对顶点进行变换，输出裁剪空间顶点

图元装配：
    按拓扑把顶点组成三角形

裁剪：
    根据完整三角形与视锥的关系，裁掉不可见部分

透视除法与视口变换：
    把裁剪空间顶点变成屏幕空间顶点

光栅化：
    判断三角形覆盖哪些像素采样点，并生成片元

插值：
    根据三个顶点的属性，计算每个片元的属性

片元着色与输出：
    计算颜色，执行深度测试、混合并写入渲染目标
```

最重要的一句话是：

> 三角形是在裁剪空间中由顶点按照拓扑结构组装出来的；裁剪完成后，三角形才被转换到屏幕空间并进行光栅化，随后再为每个片元插值顶点属性。
