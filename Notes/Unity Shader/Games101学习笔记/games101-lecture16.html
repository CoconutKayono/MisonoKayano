01 / THE QUESTION

一个表面，为什么会亮？

它可能自己发光，也可能把其他方向照来的光反射到你的眼睛里。

Lo(p, ωo) = Le(p, ωo) + ∫Ω⁺ Li(p, ωi) fr(p, ωi, ωo) cos θ dωi先把右侧的积分看成“把所有入射方向的贡献加起来”。
p，n
表面上的着色点，以及这个点朝外的单位法线。
ωo，ωi
从 p 指向观察者、从 p 指向来光方向的单位向量。ωi 指向光来的地方，与光的实际传播方向相反。
Lo，Li
出射、入射辐亮度（radiance）。辐亮度描述沿特定方向的光，不能简单当作总功率。
Le
自发光。普通墙面这一项为 0，灯的发光面这一项非零。
fr
BRDF，决定来自某方向的光有多少被散射到观察方向。它是反射分布函数，并不是采样概率。
cos θ
max(0, n · ωi)。斜着照来时，同样的光束摊到更大的表面积上，单位面积收到的贡献更小。
Ω⁺，dω
表面法线朝向的半球，以及半球上一小块立体角。这里按“方向”积分，不是按普通平面面积积分。

困难一：方向连续无穷多

不能把半球内每个方向都发射一条射线。我们要用有限次抽样，代表整个半球的贡献。

困难二：来光也有来历

沿 ωi 碰到另一块表面 q 时，Li(p, ωi) = Lo(q, −ωi)，又回到了同一个问题。这里假设两点之间是真空、没有参与介质。

为什么经典 Whitted 风格还不够？

经典做法会追踪镜面反射和折射，却通常把漫反射表面只接到光源上。这样能画出镜子，但不能完整解释“红墙把旁边的白球染红”：白球接到的光也可能经过红墙反射。路径追踪继续追踪漫反射方向，让这种间接光照自然进入计算。另一个问题是 glossy（光泽）反射：磨砂金属会在理想反射方向附近形成一片反射分布，单一镜面方向不能完整描述它；应由材质的散射分布决定采样和权重。

本讲以表面反射为主。下文算法和渲染实验限定为漫反射表面、面光源、黑色环境；一般材质、体积散射和复杂焦散需要进一步处理。

02 / MONTE CARLO INTEGRATION

不算遍每一点，怎么知道总面积？

把“求和所有可能性”，改写为“随机取样，再平均带权结果”。

先离开三维世界，看一个能手算的目标：I = ∫₀¹ x² dx = 1/3。若 X 在 [0,1] 上均匀出现，每次读取 X²，反复平均就能估计曲线下的面积。在一般区间 [a,b] 上，还要乘上区间长度 b−a。

ÎN = 1N ∑k=1N f(Xk)p(Xk)， Xk ∼ p(x)p 是概率密度函数（PDF）。均匀分布在 [a,b] 上时，p = 1/(b−a)。

为什么要除以 p？

如果你更常去某一区域，就会更常把那里的函数值计入平均。除以采样密度，是把这种“更常被访问”的偏向抵消掉。高密度区域每次权重小，低密度区域每次权重大。它不是简单的“除以采到这个点的概率”：连续分布里，采到一个精确点的概率是 0；有意义的是小邻域的概率 p(x) dx。

E[ f(X)/p(X) ] = ∫ f(x)p(x) p(x) dx = ∫ f(x) dx

这就是无偏：把同样的实验重复无数次，估计值的平均等于目标值。条件是 p 已归一化，且在 f 有贡献的区域不能漏采（允许零测集例外）；若要使用常见的误差公式，还需要有限方差。

展开推导：实验里的非均匀分布，如何采样、如何算权重？

均匀 U∈[0,1) 时，取 X=√U，就得到 p(x)=2x。因为 P(X≤x)=P(U≤x²)=x²，求导得到密度 2x。此时单样本贡献 f(X)/p(X)=X/2（X=0 的端点用极限 0 处理）。与均匀采样直接平均 X² 相比，两者目标都是 1/3。

均匀采样的单样本方差为 1/5−1/9=4/45；p=2x 时为 1/8−1/9=1/72。因此实验显示的理论标准差分别为 √(4/(45N)) 与 √(1/(72N))。不是换了积分，而是换了估计同一个积分的方法。

定义与误差分析可对照 PBRT：蒙特卡洛基础；本节 x² 实验与方差计算为独立示例。

更多样本，不等于每一步都更接近答案

对于独立同分布、有限方差样本，Var(ÎN) = Var(f/p)/N，标准差按 1/√N 下降。想让典型噪声减半，通常需要约 4 倍样本。一次实验的误差会波动，不能保证 N 每增加一次都变好。

两个旋钮，作用不同。

增加 N：多算一些，压低随机误差。改进 p：把预算投向贡献更大的区域，让每次采样更有效。后者叫重要性采样；但“偏向某处”本身不保证有效，关键是能否降低 f/p 的波动。

03 / ONE PATH AT A TIME

把半球积分，变成一条随机光路

把上一节的 f(x) 换成 Li fr cos θ，把 x 换成方向 ω，就得到渲染方程的蒙特卡洛估计。为了避免与位置 p 混淆，下文把方向概率密度写成 pω。

L̂o = Le + 1N ∑k=1N Li(ωk) fr(ωk, ωo) cos θkpω(ωk)

均匀半球采样的密度是 1/(2π)，因为半球的立体角是 2π sr。不过，“让极角 θ 均匀”并不会得到均匀的半球方向：dω=sin θ dθ dφ，靠近极点和赤道的同宽角度带面积不同。

扩展：漫反射为什么特别适合余弦加权采样？

理想漫反射（Lambertian）BRDF 为 fr=ρ/π，ρ 是反照率。均匀半球时，每次延伸的权重为 (ρ/π)cos θ÷(1/(2π))=2ρ cos θ。改用 pω=cos θ/π，权重直接化简为 ρ。注意：余弦加权只匹配了 BRDF 与余弦部分，Li 仍可能变化很大，并不是整个渲染问题变成零方差。

给定独立均匀 u₁、u₂：均匀半球取 cos θ=u₁；余弦半球取 cos θ=√u₁；两者均取 φ=2πu₂。再用 sin θ、cos φ、sin φ 构造局部方向，转换到以表面法线为轴的世界坐标系。

递归时，每次都发 N 条，会发生什么？

一个交点发 N 条，每条碰到下一个点又发 N 条，深度 d 的末层就有 Nd 个分支。解决方法很直接：每个交点只随机选一个继续方向，即局部估计使用 N=1。然后从同一像素重新发起很多条独立路径来平均。

“每次只采一个”与“每像素采很多次”不矛盾。

前者控制单条路径的分叉；后者是 SPP（samples per pixel），控制一个像素平均多少条路径。单路径会很吵，但仍然可以无偏。像素内部也要抖动采样，才能同时估计像素覆盖并改善锯齿。

一条路径的权重怎样累积？

从相机反向查找光的来历。每到一个表面，就把当前路径权重 β 乘上 fr cos θ / pω。β 常叫 throughput，可理解为“后续光照对当前像素还有多大影响”。碰到发光面时，把 βLe 加到像素结果里。

β0 = 1， βk+1 = βk · fr,k cos θkpω,k

追踪方向是“相机 → 表面 → 光源”，图像所对应的实际光传播方向相反。RGB 情况下 β、反照率和辐亮度都是三通道量，乘法逐通道进行。

04 / RUSSIAN ROULETTE

让一部分路径停止，让幸存者替它们发声

路径可能反射很多次。把所有路径强行砍在第 5 次，往往会系统性地漏光。

固定深度截断会丢弃更长路径的贡献，通常产生偏差。俄罗斯轮盘赌（Russian Roulette，RR）则用随机终止控制工作量：以概率 P 继续，并把继续后的贡献除以 P；以概率 1−P 停止，后续贡献取 0。

L̂RR = { L / P（概率 P）；0（概率 1−P）}
E[L̂RR] = P · L/P + (1−P) · 0 = L

这里的 L 可以看作当前状态下“原本要继续估计的剩余贡献”。终止只放弃未来，已经累积的直接光照和发光项不能一起抹掉。每次继续后都补偿 1/P，所以不会在期望上把图像压暗。

无偏不代表免费

P 越小，计算越少，但幸存贡献越大，方差通常越高。上面把原贡献固定成 L=1，单次方差就是 1/P−1。若每次都用同一个 P<1，RR 决策点之后继续成功的次数期望为 P/(1−P)，路径以概率 1 最终终止。

实际实现常先追踪几次，再根据路径权重选择继续概率，并为存活路径补偿。只要没有把潜在非零贡献以概率 1 直接砍掉，且条件概率权重正确，RR 就能保持期望。它用方差换计算量，目的并不是自动降噪。

05 / SAMPLE THE LIGHT

灯那么小，为什么非要等射线撞上它？

随机选半球方向，大部分会看不到灯。更有效的办法：直接在灯的表面挑一个点，再检查能不能看见它。

设着色点为 x，光源上的采样点为 y，距离 r=‖y−x‖。从 x 看过去，面积微元 dA 投影后占据的立体角为：

dω = cos θyr² dAθᵧ 是光源法线与 y → x 方向的夹角；必须取光源朝向 x 的那一侧。

这一步特别关键：你在面积上采样，就要把原来对立体角的积分改写成对面积的积分。换元后，直接光照的一次估计是：

L̂direct = Le(y → x) fr(x) V(x,y) cos θx cos θyr² pA(y)均匀采样一个面积为 A 的面光源：pₐ=1/A。V 为可见性：无遮挡取 1，有遮挡取 0。

陷阱：直接采灯 + 随机碰灯，会不会把同一份光算两遍？

会，如果把两个完整的直接光估计直接相加。课程采用的简单拆分是：直接光由光源采样负责，继续方向只递归非光源表面的反射贡献；相机直接看到光源时仍要返回它的发光。第 6 节给出对应伪代码。

扩展：真实渲染器常用多重重要性采样（MIS），让光源采样与 BSDF 采样按权重共同估计直接光。镜面反射、环境光和无法由当前采灯策略覆盖的发光路径不能机械套用“碰到灯就丢弃”。这些超出本页漫反射演示的范围。可参阅 PBRT：A Better Path Tracer。

06 / PUT IT TOGETHER

从一条相机射线，到一个像素

把工作分成两层，就不会把“样本数”和“反射次数”混在一起。

  1. 像素层：在像素内随机取一个位置，生成相机射线；重复 SPP 次，把线性辐亮度取平均。
  2. 路径层：找最近交点，估计直接光，决定是否继续，再随机选择一个方向，乘好权重后递归。

教学伪代码：光源采样 + 单路径延伸 + RR

适用范围：不发光的漫反射物体、单个纯发光面光源、黑色背景；光源只从正面发光。所有相交都是最近命中。visibleSegment 含稳健偏移和有限线段遮挡测试。

# 入口：相机直接看到灯时，保留自发光
traceCamera(ray):
    hit = intersectClosest(ray)
    if no hit: return 0
    if hit is light: return emittedRadiance(hit, -ray.dir)
    return shade(hit, -ray.dir)

shade(x, wo):
    # 1. 直接光：在灯的面积上均匀采样
    y, pA = sampleLightArea()           # pA = 1 / area
    wi = normalize(y.position - x.position)
    r2 = squaredDistance(x, y)
    cx = max(0, dot(x.normal,  wi))
    cy = max(0, dot(y.normal, -wi))
    L = 0
    if cx > 0 and cy > 0 and visibleSegment(x, y):
        L += Le(y, -wi) * fr(x, wi, wo) * cx * cy / (r2 * pA)

    # 2. RR 只决定是否估计后续间接光
    P = 0.8
    if random01() >= P: return L

    # 3. 选一个半球方向；此处使用均匀采样
    wi, pW = sampleUniformHemisphere(x.normal)   # pW = 1/(2π)
    next = intersectClosest(offsetRay(x, wi))
    if next exists and next is not light:
        Li = shade(next, -wi)
        L += Li * fr(x, wi, wo) * max(0, dot(x.normal, wi)) / (pW * P)
    # next 是灯：不再加发光，当前点的采灯已负责直接光
    return L

renderPixel(pixel, SPP):
    sum = 0
    repeat SPP times:
        ray = cameraRay(randomPositionInside(pixel))
        sum += traceCamera(ray)
    return displayTransform(sum / SPP)

检查每一个分母

直接项除以 pA，因为在面积上采样。继续项除以 pω，因为在方向上采样；还要除以 P，因为只有 P 的概率走到这里。像素最后除以 SPP，因为我们在做平均。

阴影射线不是新分支

到光源的射线只回答“挡住了吗”，不会继续递归。每个交点既做一次阴影测试，又做一次路径延伸，仍然是单条路径的线性增长。

实现时最值得排查的 6 件事

① 法线、wi、wo 都应归一化且方向一致。② cos θ 不能取负。③ 阴影射线只检测到采样灯点为止，不能被灯背后的物体挡住。④ 起点需要沿法线做小偏移，避免自相交；固定 ε 要与场景尺度匹配。⑤ BRDF 的值与采样 PDF 必须对应同一个方向、同一个测度。⑥ 先在线性空间求平均，再做色调映射或 sRGB 编码；不要平均已经编码的颜色。

16 → 64 → 256 SPP颗粒逐渐减少，细节更稳定样本平均降低随机方差；单次结果不必单调变好
关闭直接采样光源相同 SPP 下，噪点通常更大、更稀疏只靠随机方向撞到灯，很多路径贡献为 0
关闭间接光照遮挡区域变暗，彩色反弹减弱或消失只计算相机可见表面到灯的直接光路

比较采样效率时，SPP 相同不代表耗时相同：直接采灯每个交点还要做阴影测试。可同时记录右侧用时。改变光照模型（关闭间接光）会改变目标图像；切换 NEE 则只改变同一光照模型的估计方式。

08 / CHECK YOUR UNDERSTANDING

真正理解，比记住公式更重要

“随机”是不是意味着结果不准确？

有限样本有噪声，但构造正确的估计器可以无偏。系统性误差往往来自漏项、错误 PDF、错误可见性、错误权重或截断。加样本只能减少随机误差，不能修复一个有偏实现。

路径追踪是不是总要碰到灯才有贡献？

纯粹靠方向随机游走、没有环境光时，要碰到发光面才能得到非零光源贡献。使用直接光源采样后，中途每个非光源交点都能通过连接灯的阴影射线累积贡献，不必等延伸射线最终撞灯。

有 r² 分母，是不是说明两点之间的 radiance 会自然衰减？

不是。在无遮挡、无参与介质的真空中，沿同一条射线的辐亮度保持不变。这里的 1/r² 来自固定面积光源微元所张的立体角变小，是面积到立体角的几何换元。

为什么密度 p 可以大于 1？

PDF 不是单个事件的概率。比如均匀分布在长度 0.1 的区间上，密度为 10，但积分是 10×0.1=1，完全正确。只要求非负并且在整个域上的积分等于 1。

多追几次反射，等价于增加 SPP 吗？

不等价。反射深度决定考虑哪些光路，SPP 决定用多少次试验估计这些光路。只算直接光再增加 SPP，也不会凭空出现间接光。启用 RR 的无限路径模型则不依靠一个固定深度来定义光照范围。

四道即时自测

1. 在某一小区域把采样密度提高为原来的 2 倍，那里相同位置的单样本权重应当怎样变？

2. 当前为 100 SPP，要让典型噪声减半，大约需要多少 SPP？

3. RR 的继续概率是 0.25，幸存路径的剩余权重该乘多少？

4. 采灯估计直接光后，再无条件加上延伸方向碰灯的发光，会怎样？

课末术语：Ray Tracing 和 Path Tracing 是什么关系？

Ray Tracing（光线追踪）是更宽泛的概念，不应只理解为早期的 Whitted 风格。Path Tracing（路径追踪）是其中一种用蒙特卡洛方法求解光传输的算法。课程最后还提到双向路径追踪、光子映射和 Metropolis Light Transport 等方法；本页只实现单向的漫反射路径追踪。

一页心智速查

  • 要算什么？ 渲染方程里的半球积分，包含来自其他表面的反射光。
  • 怎样抽样？ 指定概率密度，按这个分布生成样本，贡献除以同一密度。
  • 怎样递归？ 一个交点只延伸一个方向，多条完整路径在像素处平均。
  • 怎样停止？ RR 随机终止，幸存路径除以继续概率，保留已累积贡献。
  • 怎样提效？ 直接采光源，进行面积与立体角换元，检测遮挡，避免重复计数。
  • 怎样排错？ 先看测度、PDF、余弦、可见性、发光项和 RR 补偿，再看 SPP。
