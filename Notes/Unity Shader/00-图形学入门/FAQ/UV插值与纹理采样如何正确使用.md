# UV 插值与纹理采样如何正确使用

## Q1：应该在顶点阶段采样纹理，还是在片元阶段采样？

通常应该采用以下流程：

```text
顶点提供 UV
    ↓
光栅化阶段插值 UV
    ↓
片元着色器根据 UV 采样纹理
```

也就是说，普通颜色贴图的纹理采样一般发生在片元着色器中。

---

## Q2：为什么不在三个顶点处采样出颜色，再把颜色插值给片元？

因为通常情况下：

```text
先采样再插值 ≠ 先插值 UV 再采样
```

纹理颜色不一定是线性变化的。例如棋盘格、文字、像素画和透明边缘等细节，无法通过三个顶点的颜色准确推算出来。

正确的思路是先得到每个片元对应的 UV，再根据这个 UV 读取纹理数据。

---

## Q3：UV 是谁插值的？

UV 通常不是片元着色器自己手动插值，而是由光栅化阶段自动完成。

顶点着色器输出三个顶点的 UV 后，GPU 会根据片元在三角形中的位置，为每个片元计算对应的 UV。在透视场景中，通常还会进行透视校正插值。

---

## Q4：片元着色器拿到的 UV 是什么？

它是当前片元对应的纹理坐标，也就是纹理中的“地址”。

例如：

```text
UV = (0.2, 0.7)
```

可以理解为去纹理横向 20%、纵向 70% 附近的位置读取数据。具体的纵向方向还要看图形 API 和纹理坐标的约定。

---

## Q5：为什么纹理采样通常放在片元阶段？

片元阶段可以根据当前片元以及相邻片元之间的 UV 变化，选择合适的采样方式，例如：

- 双线性过滤；
- Mipmap 层级选择；
- 各向异性过滤；
- 放大或缩小时的过滤方式。

因此，片元阶段采样能够更准确地得到最终屏幕位置所需的纹理颜色。

---

## Q6：顶点着色器能不能采样纹理？

可以，但这不是普通颜色贴图的常规做法。

例如，顶点着色器可以采样高度图，并使用纹理数据修改顶点位置：

```text
高度图采样
    ↓
修改顶点高度
    ↓
产生地形起伏
```

这属于“用纹理影响几何”。而普通颜色贴图通常在片元阶段采样，用来影响颜色或材质。

---

## Q7：Unity Shader 中通常怎样传递和采样 UV？

顶点数据中的 UV 先由顶点着色器传递给片元着色器：

```hlsl
struct appdata
{
    float4 vertex : POSITION;
    float2 uv     : TEXCOORD0;
};

struct v2f
{
    float4 pos : SV_POSITION;
    float2 uv  : TEXCOORD0;
};

v2f vert(appdata v)
{
    v2f o;
    o.pos = UnityObjectToClipPos(v.vertex);
    o.uv = v.uv;
    return o;
}

fixed4 frag(v2f i) : SV_Target
{
    return tex2D(_MainTex, i.uv);
}
```

其中，`o.uv = v.uv` 只是把顶点 UV 交给后续阶段。三角形内部的 UV 插值由 GPU 自动完成，`frag` 中的 `i.uv` 已经是当前片元对应的 UV。

---

## Q8：UV 不连续时怎么办？

如果同一个几何位置在纹理上需要对应不同的位置，就不能继续共用同一个顶点。

通常需要复制顶点，并为复制后的顶点设置不同的 UV。这就是 UV 接缝的基本处理方式。

---

## Q9：最终应该记住什么？

```text
顶点保存 UV
    ↓
光栅化阶段插值 UV
    ↓
片元着色器根据 UV 采样纹理
```

一句话概括：

> 不要先插值三个顶点的纹理颜色，而是插值纹理坐标，让每个片元根据自己的 UV 去纹理中取数据。
