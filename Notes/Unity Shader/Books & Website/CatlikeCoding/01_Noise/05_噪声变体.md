## 分形噪声

到目前为止，我们仅使用了 Perlin 的单个样本或每点的值噪声。结果看起来是随机的，但图案的所有特征都具有相同的大小。虽然有多种，但都是基于统一的晶格。所有变化都存在于单一尺度上，由域变换决定。噪声在较大和较小的尺度上缺乏变化，这暴露了它的人造本质。

我们可以通过以不同的尺度再次采样噪声来引入第二频率的变化。最简单的方法是以基本比例和双倍比例对其进行采样。两个样本的总和产生具有大尺度和小尺度变化的噪声。我们可以多次执行此操作，每个额外的样本在更大的域范围内添加更小的特征。由于较小的特征与较大的特征相似，由此产生的模式将表现出自相似性，因此结果被称为分形噪声。

### 噪音设置

为了支持分形噪声，我们必须添加更多配置选项来控制它。为了方便地将配置传递给 `Noise`，我们首先创建一个公共 `Noise.Settings` 结构，最初仅包含种子整数字段。由于此结构纯粹是为了方便地对配置选项进行分组，因此我们创建字段 `public` 并使用 `System.Serializable` 属性将该结构标记为可序列化。这样 Unity 就可以保存配置并且可以轻松访问其内容。

```csharp
using System;
using Unity.Burst;
…

public static partial class Noise {

	[Serializable]
	public struct Settings {

		public int seed;
	}
	
	…
}
```

结构体字段不能有除零或 `null` 以外的默认值，因此我们将通过公共静态属性提供默认的 `Settings` 配置。最初它返回一个未修改的新值，但稍后我们将向其添加字段初始化。

```csharp
	public struct Settings {

		public int seed;

		public static Settings Default => new Settings {};
	}
```

现在调整 `Noise.Job`，使其使用 `Settings` 值而不是直接使用哈希值。然后根据配置的种子在 `Execute` 中初始化哈希值。

```csharp

				domainTRS.TransformVectors(transpose(positions[i])), hash
			);
		}

		public static JobHandle ScheduleParallel (

		) => new Job<N> {
			positions = positions,
			noise = noise,
			//hash = SmallXXHash.Seed(seed),
			settings = settings,
			domainTRS = domainTRS.Matrix,
		}.ScheduleParallel(positions.Length, resolution, dependency);
```

调整委托类型以匹配 `ScheduleParallel` 的新签名。

```csharp

```

### 频率

我们仍然只对每个点的噪声进行一次采样。目前，模式的规模由域规模决定。该尺度也称为噪声频率，它描述了噪声变化的速度。频率或尺度越高，变化越快，因此其特征越小。

我们通过在 `Settings` 中添加一个字段来更轻松地调整频率。我们将频率限制为整数，原因稍后会清楚，因此将其设为整数。频率必须为正且至少为 1（通过 `Min` 属性在检查器中强制执行），让我们为其指定默认值 4。

```csharp
…
using UnityEngine;

using static Unity.Mathematics.math;

public static partial class Noise {

	[Serializable]
	public struct Settings {

		public int seed;

		[Min(1)]
		public int frequency;

		public static Settings Default => new Settings {
			frequency = 4
		};
	}
	
	…
}
```

![[images/noise-variants/fractal-noise/settings-frequency.png]]

*频率设置为 4，域尺度设置为 1。*

要应用频率，请使用它来缩放 `Noise.Job.Execute` 中的变换位置。

```csharp
		public void Execute (int i) {
			float4x3 position = domainTRS.TransformVectors(transpose(positions[i]));
			var hash = SmallXXHash4.Seed(settings.seed);
			int frequency = settings.frequency;
			noise[i] = default(N).GetNoise4(frequency * position, hash);
		}
```

从现在开始，频率和域尺度都可以用来调整噪声的尺度。频率是均匀的，而域尺度可以是不均匀的，甚至每个维度为负值。

### 八度

分形噪声由不同频率的多个样本组成。这些被称为八度。完美的分形噪声将具有无限数量的八度音阶，但我们必须单独计算每个八度音阶，因此只能支持几个。八度音程越多，噪声的细节越多，但生成时间也更长。所以我们给`Settings`添加一个整数字段来控制八度的数量。至少应该有一个八度，合理的最大值是六个。单个八度是一个很好的默认值。

```csharp
		[Range(1, 6)]
		public int octaves;

		public static Settings Default => new Settings {
			frequency = 4,
			octaves = 1
		};
```

![[images/noise-variants/fractal-noise/settings-octaves.png]]

*八度设置为 3。*

现在更改 `Noise.Job.Execute`，使其循环遍历所有八度音阶，每次调用 `GetNoise4` 并将频率加倍。对所有样本求和，并将其用作最终噪声值。

```csharp
		public void Execute (int i) {
			float4x3 position = domainTRS.TransformVectors(transpose(positions[i]));
			var hash = SmallXXHash4.Seed(settings.seed);
			int frequency = settings.frequency;
			float4 sum = 0f;

			for (int o = 0; o < settings.octaves; o++) {
				sum += default(N).GetNoise4(frequency * position, hash);
				frequency *= 2;
			}
			noise[i] = sum;
		}
```

我将使用值噪声的屏幕截图来演示结果，因为它的块状图案使不同的八度音阶比 Perlin 噪声更容易发现。

![[images/noise-variants/fractal-noise/octaves-2-full-strength.png]]

![[images/noise-variants/fractal-noise/octaves-3-full-strength.png]]

*1、2 和 3 个八度的 2D 值噪声。*

当对相同强度的多个八度音程求和时，较高的频率将主导结果。分形噪声的想法是，倍频程的振幅随着频率的增加而减小。因此，每次我们将频率加倍时，噪声的幅度也应该减半。

```csharp
			int frequency = settings.frequency;
			float amplitude = 1f;
			float4 sum = 0f;

			for (int o = 0; o < settings.octaves; o++) {
				sum += amplitude * default(N).GetNoise4(frequency * position, hash);
				frequency *= 2;
				amplitude *= 0.5f;
			}
```

除此之外，对多个八度音程求和会产生超出 -1-1 范围的噪声。因此，我们应该通过将倍频程总和除以幅度总和来标准化结果。

```csharp
			float amplitude = 1f, amplitudeSum = 0f;
			float4 sum = 0f;

			for (int o = 0; o < settings.octaves; o++) {
				sum += amplitude * default(N).GetNoise4(frequency * position, hash);
				amplitudeSum += amplitude;
				frequency *= 2;
				amplitude *= 0.5f;
			}
			noise[i] = sum / amplitudeSum;
```

### 每个八度的独特种子

我们目前正在对不同尺度的完全相同的噪声模式进行求和。其结果是，在域原点处，模式似乎塌缩成奇点。视觉上明显的重复发生在不同的尺度上，并在原点处汇聚。

![[images/noise-variants/fractal-noise/octaves-6-same-seed.png]]

*具有相同种子的六个八度。*

我们可以通过每个八度使用不同的哈希值来消除这种视觉伪影。增加 `SmallXXHash4` 的累加器就足够了，有效地使用每个八度音阶的连续种子。

向 `SmallXXHash4` 添加加法运算符方法，以支持向累加器添加整数值，从而产生不同的哈希值。

```csharp
	public static SmallXXHash4 operator + (SmallXXHash4 h, int v) =>
		h.accumulator + (uint)v;
```

然后将八度迭代器值添加到在 `Noise.Job.Execute` 循环中传递给 `GetNoise4` 的哈希中。

```csharp
				sum += amplitude * default(N).GetNoise4(frequency * position, hash + o);
```

![[images/noise-variants/fractal-noise/octaves-6-different-seeds.png]]

*六个八度具有不同的种子。*

### 空缺性

我们并不总是需要将连续八度音阶之间的频率加倍。频率缩放被称为噪声的空隙度。让我们向 `Settings` 添加一个选项，同样是一个整数，范围为 2–4，默认值为 2。

```csharp
		[Range(2, 4)]
		public int lacunarity;

		public static Settings Default => new Settings {
			frequency = 4,
			octaves = 1,
			lacunarity = 2
		};
```

![[images/noise-variants/fractal-noise/settings-lacunarity.png]]

*空隙度设置为 2。*

### 空虚是什么意思？

在这种情况下，空隙性是分形如何填充空间的几何描述。空隙度越高，八度音阶之间的间隙或空间就越大。它源自拉丁语lacuna，意思是间隙或湖泊。

要应用空隙性，请使用它来缩放 `Noise.Job.Execute` 中的频率，而不是始终将频率加倍。

```csharp
				sum += amplitude * default(N).GetNoise4(frequency * position, hash + o);
				frequency *= settings.lacunarity;
				amplitude *= 0.5f;
				amplitudeSum += amplitude;
```

### 坚持

就像间隙度可以配置而不是始终为 2 一样，八度音程之间的幅度减小也可以配置而不是始终为 0.5。这个因素被称为持久性，它控制着每倍频程振幅减少的速度。它是 0-1 范围内的浮点值。将其添加到 `Settings`，默认值为 0.5。

```csharp
		[Range(0f, 1f)]
		public float persistence;

		public static Settings Default => new Settings {
			frequency = 4,
			octaves = 1,
			lacunarity = 2,
			persistence = 0.5f
		};
```

![[images/noise-variants/fractal-noise/settings-persistence.png]]

*持久性设置为 0.5。*

使 `Noise.Job.Execute` 应用余辉，而不是始终将幅度缩放 0.5。

```csharp
				frequency *= settings.lacunarity;
				amplitude *= settings.persistence;
```

## 湍流

分形柏林噪声的一个常见变体是将每个倍频程的绝对值相加。这会导致八度音阶在将通过零的地方弹跳，从而产生折痕。将多个这样的八度音阶分层会产生 Ken Perlin 描述的湍流模式，因此通常称为 Perlin 噪声的湍流变体。它也可以应用于噪声值，因此我们将创建两种噪声类型的湍流变体。

### 插值后评估

为了获取八度音阶的绝对值，我们必须在插值后对梯度噪声值执行操作。我们可以将其概括为任意操作，按梯度类型定义。我们通过将 `EvaluateAfterInterpolation` 方法的签名添加到 `IGradient` 来实现此目的，该签名采用矢量化噪声值并对其进行评估以产生最终的插值后噪声值。

```csharp
	public interface IGradient {
		float4 Evaluate (SmallXXHash4 hash, float4 x);

		float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y);

		float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y, float4 z);

		float4 EvaluateAfterInterpolation (float4 value);
	}
```

常规的 `Value` 和 `Perlin` 渐变实现保持不变，但仍然必须实现此方法。他们只是简单地返回原值不变。

```csharp
	public struct Value : IGradient {

		…

		public float4 EvaluateAfterInterpolation (float4 value) => value;
	}

	public struct Perlin : IGradient {

		…

		public float4 EvaluateAfterInterpolation (float4 value) => value;
	}
```

要使用最终评估，请在 `GetNoise4` 末尾通过此新方法传递内插值。对 `Lattice1D`、`Lattice2D` 和 `Lattice3D` 执行此操作。

```csharp
			var g = default(G);
			return g.EvaluateAfterInterpolation(lerp(
				…
			));
```

### 一般湍流

现在，我们可以通过复制它们并更改其 `EvaluateAfterInterpolation` 方法以返回绝对值来创建 Perlin 的湍流变体和值噪声。然而，我们不是复制这两种类型，而是向 *Noise.Gradient* 引入一个通用的 `Turbulence` 结构，该结构包装任意其他渐变类型。它将所有方法调用转发到通用梯度，仅通过 `abs` 方法将最终评估更改为其绝对值。

```csharp
	public struct Turbulence<G> : IGradient where G : struct, IGradient {

		public float4 Evaluate (SmallXXHash4 hash, float4 x) =>
			default(G).Evaluate(hash, x);

		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y) =>
			default(G).Evaluate(hash, x, y);

		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y, float4 z) =>
			default(G).Evaluate(hash, x, y, z);

		public float4 EvaluateAfterInterpolation (float4 value) =>
			abs(default(G).EvaluateAfterInterpolation(value));
	}
```

## 平铺噪声

另一种有用的噪声变体是创建重复模式的噪声变体。这并不是为了直接填充大区域，而是为了生成小纹理或网格，然后可用于无缝平铺更大区域。

为了使图案平铺，样本区域的相对两侧必须相同。当我们使用晶格网格时，我们可以通过重复相同的晶格跨度序列来做到这一点。我们使该序列的长度等于噪声频率。因此，频率 4 噪声将在任何维度上每四个跨度重复一次。

为了使这种平铺成为可能，频率以及空隙度必须始终是整数，这就是我们将它们设为整数的原因。

### 晶格级频率

为了使重复成为可能，我们必须将频率传递给噪声实现，因此将其参数添加到 `INoise.GetNoise4`。

```csharp
	public interface INoise {
		float4 GetNoise4 (float4x3 positions, SmallXXHash4 hash, int frequency);
	}
```

从现在开始，我们将在这个较低的级别应用频率，因此将未修改的位置与 `Noise.Job.Evaluate` 中的频率一起传递，而不是缩放循环中的位置。

```csharp
				sum += amplitude * default(N).GetNoise4(position, hash + o, frequency);
```

晶格点是在 `GetLatticeSpan4` 中确定的，因此向其中添加频率参数并在该方法开始时缩放坐标。

```csharp
	static LatticeSpan4 GetLatticeSpan4 (float4 coordinates, int frequency) {
		coordinates *= frequency;
		float4 points = floor(coordinates);
		…

```

此调整的最后一步是将频率参数添加到点阵结构的 `GetNoise4` 方法中，并将其传递给 `GetLatticeSpan4` 的所有调用。


### 晶格接口

为了支持正常噪声和平铺噪声，我们将在 *Noise.Lattice* 中引入新的 `ILattice` 接口，该接口指定 `GetLatticeSpan4` 方法签名。这要求 `LatticeSpan4` 结构变为公共，因为整个方法必须是公共的，包括其参数的类型及其返回的内容。

```csharp
	public struct LatticeSpan4 { … }

	public interface ILattice {
		LatticeSpan4 GetLatticeSpan4 (float4 coordinates, int frequency);
	}
```

现在将 `GetLatticeSpan4` 方法包装在实现 `ILattice` 的新 `LatticeNormal` 结构类型中，将其更改为公共实例方法。

```csharp
	public struct LatticeNormal : ILattice {

		public LatticeSpan4 GetLatticeSpan4 (float4 coordinates, int frequency) {
			…
		}
	}
```

然后调整晶格结构类型，以便它们依赖通用 `ILattice` 类型来获取晶格跨度。这意味着它们现在有两个泛型类型参数。泛型类型约束是一个接一个地编写的。

```csharp

		where L : struct, ILattice where G : struct, IGradient {

		public float4 GetNoise4(float4x3 positions, SmallXXHash4 hash, int frequency) {
			LatticeSpan4 x = default(L).GetLatticeSpan4(positions.c0, frequency);

			…
		}
	}

	public struct Lattice2D<L, G> : INoise
		where L : struct, ILattice where G : struct, IGradient {

			LatticeSpan4
				x = l.GetLatticeSpan4(positions.c0, frequency),
				z = l.GetLatticeSpan4(positions.c2, frequency);

			…
		}
	}

	public struct Lattice3D<L, G> : INoise
```

### 平铺

要创建平铺晶格，请复制 `LatticeNormal` 并将其重命名为 `LatticeTiling`。然后调整其 `GetLatticeSpan4` 方法，以便在等于频率的跨度量后重复跨度点。这可以通过余数或模运算 `%` 将点的余数除以频率来完成。这必须在计算基本梯度值之后完成。

```csharp
	public struct LatticeTiling : ILattice {

		public LatticeSpan4 GetLatticeSpan4 (float4 coordinates, int frequency) {
			coordinates *= frequency;
			float4 points = floor(coordinates);
			LatticeSpan4 span;
			span.p0 = (int4)points;
			span.p1 = span.p0 + 1;
			span.g0 = coordinates - span.p0;
			span.g1 = span.g0 - 1f;

			span.p0 %= frequency;
			span.p1 %= frequency;

			span.t = coordinates - points;
			span.t = span.t * span.t * span.t * (span.t * (span.t * 6f - 15f) + 10f);
			return span;
		}
	}
```

现在我们可以添加当前支持的所有噪声选项的平铺变体。通过在 `NoiseVisualization` 的数组声明中交替使用常规点阵版本和平铺点阵版本来实现此目的。我只显示常规 Perlin 噪声的变化。

```csharp
		{
			Job<Lattice1D<LatticeNormal, Perlin>>.ScheduleParallel,
			Job<Lattice1D<LatticeTiling, Perlin>>.ScheduleParallel,
			Job<Lattice2D<LatticeNormal, Perlin>>.ScheduleParallel,
			Job<Lattice2D<LatticeTiling, Perlin>>.ScheduleParallel,
			Job<Lattice3D<LatticeNormal, Perlin>>.ScheduleParallel,
			Job<Lattice3D<LatticeTiling, Perlin>>.ScheduleParallel
		},
```

我们将使用布尔切换选项来控制平铺，而不是将下拉枚举的大小加倍。第二个数组索引它们等于维数的两倍，如果启用平铺则减一，否则减二。

```csharp
		noiseBuffer.SetData(noise);
	}
```

如果我们此时启用平铺，如果我们增加域比例来查看它，我们会得到明显的重复，因为单个平铺适合一个单位立方体。

*1 倍频程频率 2 平铺 2D Perlin；域规模 4.*

尽管存在平铺，但它是不正确的，因为图案取决于尺寸的符号。因此，2D 噪声显示出四种不同的模式。发生这种情况是因为余数受到符号的影响。要解决此问题，我们必须调整 `LatticeTiling.GetLatticeSpan4`。

首先在计算余数后检查第一个点是否为负数。如果是这样，我们就站在错误的一边，我们可以通过向该点添加频率来解决这个问题。

```csharp
			span.p0 %= frequency;
			span.p0 = select(span.p0, span.p0 + frequency, span.p0 < 0);
			span.p1 %= frequency;
```

我们还必须解决第二点。由于它总是比第一个点在正方向上更进一步，因此我们可以通过基于平铺的第一个点而不是基于平铺的点来实现这一点。

```csharp
			//span.p1 = span.p0 + 1;
			span.g0 = coordinates - span.p0;
			span.g1 = span.g0 - 1f;

			span.p0 %= frequency;
			span.p0 = select(span.p0, span.p0 + frequency, span.p0 < 0);
			span.p1 = (span.p0 + 1) % frequency;
```

### 是否可以只平铺某些尺寸而不是全部尺寸？

是的，通过在每个维度引入一个单独的通用晶格参数。因此 3D 噪声最多可以有三种晶格类型。为了使教程简单，我要么全有要么全无。

### 矢量化平铺

整数余数的计算是通过整数除法完成的，它不会矢量化。因此，平铺噪声变体必须对点进行解复用，计算每个单独点的余数，然后再次对它们进行复用，这是低效的。但这是没有必要的。

让我们考虑跨度的第二点。我们根本不必计算这一点的余数。我们可以通过将第一个点加一然后检查它是否等于频率来得到相同的结果。如果是这样，我们就必须重复这个模式了。由于模式总是从零开始，这就是第二个点。

```csharp
			//span.p1 = (span.p0 + 1) % frequency;
			span.p1 = span.p0 + 1;
			span.p1 = select(span.p1, 0, span.p1 == frequency);
```

我们确实必须计算第一个点的余数，但我们可以通过浮点除法来实现，浮点除法通过延迟到整数的转换来进行矢量化。通过将转换为整数之前的原始地板坐标除以频率，然后转换为整数，乘以频率，并从直到的第一个点中减去该值来找到余数。

```csharp
			//span.p0 %= frequency;
			span.p0 -= (int4)(points / frequency) * frequency;
			span.p0 = select(span.p0, span.p0 + frequency, span.p0 < 0);
```

由于浮点精度问题和舍入行为，直接将浮点除法的结果（实际上是与频率倒数的乘法）转换为整数是危险的。在这种情况下，我们可以在转换之前对除法进行舍入，这是通过 `ceil` 方法完成的。这可确保它在所有 CPU 类型上都能正常工作。

```csharp
			span.p0 -= (int4)ceil(points / frequency) * frequency;
```
