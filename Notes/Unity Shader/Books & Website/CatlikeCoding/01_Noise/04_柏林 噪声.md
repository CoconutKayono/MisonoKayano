## 通用梯度噪声

值噪声是定义晶格点处的常数值的晶格噪声。这些值的插值产生了平滑的图案，但晶格仍然相当明显。另一种方法是在函数之间进行插值而不是常数值。这意味着每个格点都有自己的功能。为了保持简单和统一，所有点都应该获得相同类型的函数，只是参数化不同。最简单的函数是一个常数值，这就是值噪声。在此之上的一个步骤是一个线性依赖于相对于格点的样本坐标的函数。最简单的是“f(x)=x”，其中“x”是相对坐标。这将产生以格点为中心的线性斜坡或梯度。因此，这种类型的噪声被称为梯度噪声。

由于值噪声可以被认为是梯度噪声的一个小例子，让我们调整晶格噪声，使其始终充当梯度噪声。

### 渐变界面

我们首先为 `Noise` 引入一个新的部分类资产，这次名为 *Noise.Gradient*。在其中我们声明了 `IGradient` 接口。

```csharp
using Unity.Mathematics;

using static Unity.Mathematics.math;

public static partial class Noise {

	public interface IGradient {}
}
```

梯度的目的是评估一个函数，以散列和相对坐标作为参数。为此定义一个矢量化 `Evaluate` 方法签名，最初用于 1D 噪声，这意味着除了哈希之外，它还需要具有 X 坐标的参数。

```csharp
	public interface IGradient {
		float4 Evaluate (SmallXXHash4 hash, float4 x);
	}
```

现在，我们可以在为 1D 值噪声实现 `IGradient` 的同一部分类中添加 `Value` 结构类型。它只是忽略坐标并返回散列的 A 浮点数，就像我们当前的格子噪声一样。

```csharp
	public struct Value : IGradient {

		public float4 Evaluate (SmallXXHash4 hash, float4 x) => hash.Floats01A;
	}
```

为了还支持 2D 和 3D 噪声，请将具有两个和三个坐标参数的 `Evaluate` 变体添加到 `IGradient`。

```csharp
	public interface IGradient {
		float4 Evaluate (SmallXXHash4 hash, float4 x);

		float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y);

		float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y, float4 z);
	}
```

`Value` 也必须实现这些方法，同样只需返回哈希值并忽略坐标。未使用的参数不会影响性能，因为 *Burst* 消除了所有方法调用开销和未使用的值。

```csharp
	public struct Value : IGradient {

		public float4 Evaluate (SmallXXHash4 hash, float4 x) => hash.Floats01A;

		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y) => hash.Floats01A;

		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y, float4 z) =>
			hash.Floats01A;
	}
```

### 梯度输入

为了提供渐变的相对坐标，我们将在 *Noise.Lattice* 中的 `LatticeSpan4` 添加一个名为 `g` 的矢量化浮点字段。

```csharp
	struct LatticeSpan4 {
		public int4 p0, p1;
		public float4 g;
		public float4 t;
	}
```

我们通过从 `GetLatticeSpan4` 中的坐标减去 `p0` 来找到相对坐标。

```csharp
		span.p0 = (int4)points;
		span.p1 = span.p0 + 1;
		span.g = coordinates - span.p0;
```

现在我们可以调整 `Lattice1D.GetNoise4`，以便它在 `Value` 上调用 `Evaluate`，而不是直接从哈希中获取值。将相关哈希值和相对坐标作为参数传递给 `Evaluate`。

```csharp
	public struct Lattice1D : INoise {

		public float4 GetNoise4(float4x3 positions, SmallXXHash4 hash) {
			LatticeSpan4 x = GetLatticeSpan4(positions.c0);

			var g = default(Value);
			return lerp(
				g.Evaluate(hash.Eat(x.p0), x.g), g.Evaluate(hash.Eat(x.p1), x.g), x.t
			) * 2f - 1f;
		}
	}
```

此时，对于一维值噪声，我们仍然得到与之前相同的结果，并且为作业生成的汇编代码也完全相同。但为了了解梯度噪声的工作原理，我们可以暂时更改 `Value.Evaluate`，使其成为简单的梯度函数“f(x)=x”。

```csharp
		public float4 Evaluate (SmallXXHash4 hash, float4 x) => x;
```

![[images/perlin-noise/generic-gradient-noise/raw-gradient.png]]

*原始渐变；平面上的一维噪声；第128号决议。*

生成的图案是一系列在晶格点之间从 -1 到 1 的线性一维斜坡。没有明显的混合，因为我们在每个跨度的两侧使用完全相同的渐变，相对于两端的 `p0`。要将其转换为适当的梯度噪声，第二个梯度必须基于相对于 `p1` 的坐标。因此，将 `LatticeSpan4` 中的单个 `g` 字段替换为 `g0`，并添加新的 `g1` 字段。

```csharp
	struct LatticeSpan4 {
		public int4 p0, p1;
		public float4 g0, g1;
		public float4 t;
	}
```

由于跨度的第二个晶格点沿该维度进一步位于一个单位，因此我们通过从 `g0` 中减去 1 来找到 `GetLatticeSpan4` 中的 `g1`。

```csharp
		span.p0 = (int4)points;
		span.p1 = span.p0 + 1;
		span.g0 = coordinates - span.p0;
		span.g1 = span.g0 - 1f;
```

调整 `Lattice1D.GetNoise4`，使其使用正确的相对坐标：`p0` 与 `g0` 一起以及 `p1` 与 `g1` 一起。

```csharp
			return lerp(
				g.Evaluate(hash.Eat(x.p0), x.g0), g.Evaluate(hash.Eat(x.p1), x.g1), x.t
			) * 2f - 1f;
```

![[images/perlin-noise/generic-gradient-noise/interpolated-gradients.png]]

*插值梯度。*

如果我们使用线性插值，则生成的图案将是平坦的，因为渐变会相互抵消。但因为我们使用平滑的 C2 连续插值，每个梯度在其格点附近占主导地位，我们得到了一个波浪图案。

![[images/perlin-noise/generic-gradient-noise/gradients-graph.png]]

*在两个跨度上插入三个梯度。*

请注意，梯度在其格点处为零，并且插值图案在跨度中间也为零，其中梯度相互抵消。

我们得到的模式完全是负的，因为我们随后应用了范围调整。此调整特定于值噪声，因此让我们恢复噪声并将调整移至 `Value` 方法。

```csharp
	public struct Value : IGradient {

		public float4 Evaluate (SmallXXHash4 hash, float4 x) => hash.Floats01A * 2f - 1f;

		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y) =>
			hash.Floats01A * 2f - 1f;

		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y, float4 z) =>
			hash.Floats01A * 2f - 1f;
	}
```

然后将其从 `Lattice1D.GetNoise4` 中删除。

```csharp
			return lerp(
				g.Evaluate(hash.Eat(x.p0), x.g0), g.Evaluate(hash.Eat(x.p1), x.g1), x.t
			);
			//) * 2f - 1f;
```

### 梯度插值仍然是C2连续的吗？

由于梯度在格点处具有斜率，因此一阶导数不再为零，但它在跨度上仍然是连续的，因为两侧的梯度相同。二阶导数在格点处确实仍然为零，因此也是连续的。

![[images/perlin-noise/generic-gradient-noise/gradient-derivatives-graph.png]]

*使用 1<sup>st</sup> 和 2<sup>nd</sup> 导数插值梯度，除以 6 进行拟合。*

### 通用格子

现在我们有了值噪声的梯度版本，我们可以通过给它一个 `IGradient` 结构类型参数来使 `Lattice1D` 通用，就像我们对 `Noise.Job` 所做的那样。

```csharp
	public struct Lattice1D<G> : INoise where G : struct, IGradient {

		public float4 GetNoise4(float4x3 positions, SmallXXHash4 hash) {
			LatticeSpan4 x = GetLatticeSpan4(positions.c0);

			var g = default(G);
			return lerp(
				g.Evaluate(hash.Eat(x.p0), x.g0), g.Evaluate(hash.Eat(x.p1), x.g1), x.t
			);
		}
	}
```

以同样的方式调整 `Lattice2D`，这次使用 `IGradient.Evaluate` 的 2D 变体。确保对所有晶格点使用正确的相对坐标。

```csharp
	public struct Lattice2D<G> : INoise where G: struct, IGradient {

		public float4 GetNoise4 (float4x3 positions, SmallXXHash4 hash) {
			…

			var g = default(G);
			return lerp(
				lerp(
					g.Evaluate(h0.Eat(z.p0), x.g0, z.g0),
					g.Evaluate(h0.Eat(z.p1), x.g0, z.g1),
					z.t
				),
				lerp(
					g.Evaluate(h1.Eat(z.p0), x.g1, z.g0),
					g.Evaluate(h1.Eat(z.p1), x.g1, z.g1),
					z.t
				),
				x.t
			);
			//) * 2f - 1f;
		}
	}
```

并更新 `Lattice3D`。

```csharp

					),
					y.t

				lerp(
					lerp(
```

## 柏林噪音

Ken Perlin 提出了梯度噪声的第一个版本，因此这种经典版本的噪声被称为 Perlin 噪声。与我们目前已知的梯度噪声相比，Perlin 噪声增加了梯度向量可以具有不同方向的想法。这些不同梯度的插值产生比值噪声更多样且更少块状的图案。

### Perlin 噪声不是基于排列表吗？

是的，但排列表只是生成格点伪随机值的一种方法。它适用于简单的硬件，但存在域较小且无法播种的问题。它也不会矢量化，因为它需要多个数组查找，而对此没有 SIMD 指令。因此我们以 `SmallXXHash4` 为基础。

### 第二梯度噪声类型

要实现 Perlin 噪声，请将 `Perlin` 结构类型添加到实现 `IGradient` 的 *Noise.Gradient*，就像 `Value` 一样。最初将所有评估设置为零。

```csharp
	public struct Perlin : IGradient {

		public float4 Evaluate (SmallXXHash4 hash, float4 x) => 0f;

		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y) => 0f;

		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y, float4 z) => 0f;
	}
```

然后将`NoiseVisualization`中的噪声作业数组转为二维数组。此类数组的元素有两个索引组件，因此数组类型从 `ScheduleDelegate[]` 更改为 `ScheduleDelegate[,]`。然后将现有的初始化包装在第二组花括号中，并在 Value 噪声集之前插入 Perlin 噪声作业的新集。

```csharp
	static ScheduleDelegate[,] noiseJobs = {
		{
			Job<Lattice1D<Perlin>>.ScheduleParallel,
			Job<Lattice2D<Perlin>>.ScheduleParallel,
			Job<Lattice3D<Perlin>>.ScheduleParallel
		},
		{
			Job<Lattice1D<Value>>.ScheduleParallel,
			Job<Lattice2D<Value>>.ScheduleParallel,
			Job<Lattice3D<Value>>.ScheduleParallel
		}
	};
```

为了可以在噪声类型之间进行切换，请为 Perlin 和 Value 噪声添加一个枚举配置字段，并将其用作 `UpdateVisualization` 中的第一个数组索引参数。

```csharp
	public enum NoiseType { Perlin€, Value€ }

	[SerializeField]
	NoiseType type;
	
	…
	
	protected override void UpdateVisualization (
		NativeArray<float3x4> positions, int resolution, JobHandle handle
	) {
		noiseJobs[(int)type, dimensions - 1](
			positions, noise, seed, domain, resolution, handle
		).Complete();
		noiseBuffer.SetData(noise);
	}
```

### 一维梯度

Ken Perlin 从未制作过适当的一维噪声变体，因为它不是很有用，但我们这样做是因为它使理解更高维度变得更容易。我们之前已经使用固定梯度函数“f(x)=x”测试了一维梯度噪声。 Perlin噪声的思想是格点的梯度可以不同。在一维的情况下，最明显的其他梯度就是我们已经使用的梯度的负版本：“f(x)=-x”。我们可以使用哈希值的第一位来确定我们选择正版本还是负版本。

```csharp
	public struct Perlin : IGradient {
		
		public float4 Evaluate (SmallXXHash4 hash, float4 x) =>
			select(-x, x, ((uint4)hash & 1) == 0);
		
		…
	}
```

这导致每个晶格跨度有四种可能的梯度插值：正-正、负-负、正-负和负-负。由于正负镜像相互镜像，因此只有两种独特的情况：相同梯度和不同梯度。

### 使用不同梯度时，噪声仍然是 C2 连续的吗？

是的。二阶导数在格点处始终为零，并且一阶导数是连续的，因为格点两侧仍然使用相同的梯度。

![[images/perlin-noise/perlin-noise/n-p-n-graph.png]]

*负-正-负梯度，导数除以 8 进行拟合。*

![[images/perlin-noise/perlin-noise/p-p-n-graph.png]]

*正-正-负梯度，导数除以 8 进行拟合。*

噪声在具有相反梯度的格点中间达到0.5的最大幅度。情况就是这样，因为此时两者都是 0.5，我们最终得到了它们的平均值。理想情况下，噪声的最大幅度为 1，我们可以通过将梯度加倍来实现。

```csharp
		public float4 Evaluate (SmallXXHash4 hash, float4 x) =>
			2f * select(-x, x, ((uint4)hash & 1) == 0);
```

![[images/perlin-noise/perlin-noise/1d-binary.png]]

*一维二值柏林噪声；域规模 16；第256号决议。*

### 可变梯度

我将此时得到的噪声命名为二进制 Perlin 噪声，因为它的梯度只能有两种状态。因此，噪声由梯度序列组成，这些梯度序列都指向同一方向，除非存在符号翻转。翻转显示为最大振幅波，而图案的其余部分由相同的小波组成。这看起来非常僵化，所以让我们尝试不同的方法。

不执行二元选择，而是使用散列将相对坐标缩放 -1–1 范围内的因子。我们仍然需要将其加倍才能达到最大幅度 1。

```csharp
		public float4 Evaluate (SmallXXHash4 hash, float4 x) =>
			2f * (hash.Floats01A * 2f - 1f) * x;
```

![[images/perlin-noise/perlin-noise/1d-variable.png]]

*可变梯度。*

这看起来更有趣，因为我们得到了各种各样具有不同幅度（正值和负值）的梯度。这确实使得达到最大幅度的可能性大大降低，因此噪声的平均幅度降低了。

我们还可以将变量和二进制方法结合起来，使用第一位来选择符号并通过 float A 进行缩放。

```csharp
		public float4 Evaluate (SmallXXHash4 hash, float4 x) =>
			2f * hash.Floats01A * select(-x, x, ((uint4)hash & 1) == 0);
```

但这将包括两个选择中的第一位，这会引入依赖性。为了保持选择独立，请使用第九位来确定符号。

```csharp
			2f * hash.Floats01A * select(-x, x, ((uint4)hash & 1 << 8) == 0);
```

![[images/perlin-noise/perlin-noise/1d-variable-different.png]]

*不同的可变梯度。*

这种方法的优点是我们可以引入最小振幅，而不管梯度方向如何。通过这种方式，我们可以防止出现退化区域，其中多个连续晶格点的比例最终接近于零，这将产生平坦区域。最简单的方法是将最小幅度设置为 1，并将哈希浮点数添加到其中。结果可以被认为是二元方法和变量方法的混合，保证了最小波幅，但在此基础上增加了一些变化。

```csharp
		public float4 Evaluate (SmallXXHash4 hash, float4 x) =>
			(1f + hash.Floats01A) * select(-x, x, ((uint4)hash & 1 << 8) == 0);
```

![[images/perlin-noise/perlin-noise/1d-mix.png]]

*二元变量混合。*

### 2D 渐变

继续讨论 2D Perlin 噪声，我们再次从基于第一个哈希位的单维二进制梯度开始，看看它看起来如何。

```csharp
		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y) =>
			select(-x, x, ((uint4)hash & 1) == 0);
```

![[images/perlin-noise/perlin-noise/2d-binary.png]]

*2D 二值 Perlin 噪声平面；域规模8；自上而下的视图。*

结果是一个维度上的不同二进制一维噪声带沿着另一维度的插值。让我们再次用基于 float A 的方法替换它，以使梯度更加多样化。

```csharp
		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y) =>
			(hash.Floats01A * 2f - 1f) * x;
```

![[images/perlin-noise/perlin-noise/2d-variable.png]]

*沿 X 的可变梯度。*

在 2D 噪声的情况下，我们不限于轴对齐梯度，梯度向量可以旋转 360°。为了生成这样的向量，我们可以使用类似于生成八面体球体形状的方法，但减少到二维。

我们从沿着 X 的一条线开始，从 -1 到 1。然后我们使 Y 等于 0.5 减去 X 的绝对值，就像我们在创建八面体的前半部分时定义 Z 一样，但现在是少一维。这将创建一个楔子，可以将其视为开放的正方形。然后我们减去 X 再加上 X 的 0.5 取底，以移动正方形的负数部​​分，使其闭合。

![[images/perlin-noise/perlin-noise/2d-gradient-y-graph.png]]

![[images/perlin-noise/perlin-noise/2d-gradient-xy-graph.png]]

![[images/perlin-noise/perlin-noise/2d-gradient-square-graph.png]]

*从一条线创建一个正方形的过程。*

结果是一个正方形，其角点位于 X 轴和 Y 轴上，距原点的距离为 0.5。因此，梯度向量从原点指向该正方形边缘的某处。

为了评估二维梯度，我们将其 X 和 Y 分量相加。最后，我们将结果加倍，以便轴对齐向量的长度最终为 1。

```csharp
		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y) {
			float4 gx = hash.Floats01A * 2f - 1f;
			float4 gy = 0.5f - abs(gx);
			gx -= floor(gx + 0.5f);
			return (gx * x + gy * y) * 2f;
		}
```

![[images/perlin-noise/perlin-noise/2d-square-based.png]]

*基于平方的渐变。*

如果我们想将正方形分布变成适当的圆形，我们可以通过除以梯度向量的长度来标准化梯度向量。请注意，这不会产生均匀的圆形梯度分布，因为它们沿着正方形均匀分布。它们更集中在正方形的角附近，就像八面体球体上的点更集中在八面体的角附近一样。然而这不是问题，因为分布是对称的并且足够多样化。

```csharp
			return (gx * x + gy * y) * rsqrt(gx * gx + gy * gy);
```

![[images/perlin-noise/perlin-noise/2d-normalized.png]]

*归一化梯度。*

然而，这并没有多大区别，因此我们可以省略该部分以使噪声代码运行得更快。归一化确实使对角梯度更强，但噪声本身仍然需要归一化，这也可以解决这个问题。

```csharp
			return (gx * x + gy * y) * 2f;
```

### 归一化二维噪声

为了标准化噪声，我们需要确定其当前的最大幅度。如果一个格子正方形有四个梯度都指向它的中心，那么它的最大值将在中间达到。由于这将是四个相等梯度的平均值，因此我们只需要计算该点的单个梯度值。完美的对角梯度是“f(x,y)=(x+y)/2”，因此中间的幅度将是“f(0.5,0.5)=1/2”。然而，这并不是整个噪声的最大幅度。还有另一种梯度配置，其幅度更大。

当两个梯度沿该轴直接指向彼此时，单个维度的最大值为 0.5，位于晶格跨度的中间。这是未归一化的一维二进制 Perlin 噪声。如果格子正方形另一个跨度的两个梯度都直接指向相反的跨度，那么在沿第二维插值期间，我们可能会在某处得到超过 0.5 的值。

![[images/perlin-noise/perlin-noise/2d-max-gradients.png]]

*最大幅度的梯度。*

最大值位于第一维度的中点和第二维度插值的某个位置。因此，这实际上是轴对齐梯度和 0.5 之间的平滑插值。因此，我们必须找到函数“xs(1-x)+0.5s(x)”的最大值，其中“s(t)=6t^5-15t^4+10t^3”，其中“x”的域为 0–1。

该函数的扩展形式为“6x(1-x)^5-15x(1-x)^4+10x(1-x)^3+3x^5-7.5x^4+5x^3”，简化为“-6x^6+18x^5-17.5x^4+5x^3+x”。

为了找到最大值，我们必须对该函数求导并求解为零，因为当变化率为零时，该函数已达到最大值或最小值。求解该方程是可能的，但并非易事。为了了解该函数的样子，我们可以使用 [Desmos](https://www.desmos.com/calculator/l4otmowqbe) 将其可视化。通过选择图形线，我们还可以立即了解到 X 坐标 0.6509 处的最大值为 0.5353。所以确实高于0.5。

![[images/perlin-noise/perlin-noise/2d-max-graph.png]]

*二维最大图。*

我们可以通过询问 [Wolfram|Alpha](https://www.wolframalpha.com/input/?i=Maximize%5B%7B-6x%5E6%2B18x%5E5-17.5x%5E4%2B5x%5E3%2Bx%2C0%3C%3Dx%3C%3D1%7D%2C%7Bx%7D%5D) 最大化该功能来得到更精确的答案。它甚至可以给我们一个精确的答案，但它相当复杂，所以我们就用近似值。 0.53528 就可以了，比 Desmos 显示的精确一位数。将梯度除以该值即可得到归一化的 2D Perlin 噪声。

```csharp
			return (gx * x + gy * y) * (2f / 0.53528f);
```

![[images/perlin-noise/perlin-noise/2d-normalized-perspective.png]]

*标准化 2D Perlin 噪声。*

### 圆形梯度的最大幅度是多少？

完美对角梯度的圆形版本是“f(x,y)=(x+y)/sqrt(2)”。因此，在所有梯度都指向其中心的格子正方形中心找到的最大振幅为“f(0.5,0.5)=1/sqrt(2)~~0.7071”。因此，为了标准化噪声，我们必须除以该噪声，这与乘以 `sqrt(2)~~1.4142` 相同。

### 3D 渐变

要创建 3D Perlin 噪声，我们必须执行与 2D 版本相同的操作，并扩展到包括三维。为此，我们可以使用与生成八面体球体相同的基于八面体的方法。在这种情况下，我们需要 -1–1 范围内的两个随机值。为此，我们将使用浮点数 A 和 D。 D 优于 B 或 C，因为单个位移位比移位和掩码操作都快。

```csharp
		public float4 Evaluate (SmallXXHash4 hash, float4 x, float4 y, float4 z) {
			float4 gx = hash.Floats01A * 2f - 1f, gy = hash.Floats01D * 2f - 1f;
			float4 gz = 1f - abs(gx) - abs(gy);
			float4 offset = max(-gz, 0f);
			gx += select(-offset, offset, gx < 0f);
			gy += select(-offset, offset, gy < 0f);
			return (gx * x + gy * y + gz * z);
		}
```

### 3D Perlin 噪声不是仅使用 12 个梯度向量吗？

Perlin 的参考实现确实从一组具有不同方向的 12 个 2D 对角梯度向量（指向立方体边缘的中间）中进行选择，并进行一些重复以获得总共 16 个选项。这样四位就可以转换为梯度。虽然这种方法对于常规代码或专用硬件来说非常有效，但嵌套二进制分支并不适合 SIMD 代码。如果我们不对梯度进行归一化的话，我们基于八面体的方法会更快，并且提供更多的多样性。

查找最大幅度的工作原理与 2D 相同。在使用沿该轴指向的梯度沿第三维进行插值时发现，该梯度已达到其最大值（0.53528）。所以我们必须最大化与之前相同的函数，除了将常数 0.5 替换为 0.53528：`xs(1-x)+0.53528s(x)`，它可以扩展到 `6x(1-x)^5-15x(1-x)^4+10x(1-x)^3+ 0.53528(6x^5-15x^4+10x^3)`。将其输入 [Desmos](https://www.desmos.com/calculator/vbypftfk0x) 在 X 坐标 0.6732 处产生 0.5629。

![[images/perlin-noise/perlin-noise/3d-max-graph.png]]

*3D最大图。*

[Wolfram|Alpha](https://www.wolframalpha.com/input/?i=Maximize%5B%7B6x%281-x%29%5E5-15x%281-x%29%5E4%2B10x%281-x%29%5E3%2B0.53528%286x%5E5-15x%5E4%2B10x%5E3%29%2C0%3C%3Dx%3C%3D1%7D%2C%7Bx%7D%5D) 告诉我们在 0.67321 处它是 0.56290。

```csharp
return (gx * x + gy * y + gz * z) * (1f / 0.56290f);
```

### 球形 3D 梯度的最大幅度是多少？

对于基于球体而不是八面体的梯度向量，直接指向晶格立方体中心的梯度向量为“f(x,y,z)=(x+y+z)/sqrt(3)”。因此，在所有梯度都指向其中心的格子立方体中间找到的最大振幅为“f(0.5,0.5,0.5)=1.5/sqrt(3)~~0.8660”。因此，为了标准化噪声，我们必须除以该噪声。
