# 第 69 课 · 中心圆遮罩

> 学习目标：用 `distance` 算距离、用 `step` 判断圆内外，生成圆形遮罩。

```hlsl
float distanceToCenter = distance(IN.uv, center);
float insideCircle = step(distanceToCenter, radius);
```

---

## 1. 完整代码

```hlsl
Shader "Lesson/69_CircleMask"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 center = float2(0.5, 0.5);
                float radius = 0.3;

                float distanceToCenter = distance(IN.uv, center);
                float insideCircle = step(distanceToCenter, radius);

                float3 color = lerp(float3(0.0, 0.0, 0.0), float3(1.0, 0.8, 0.2), insideCircle);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是黑色背景上一个暖黄色的实心圆。

---

## 2. distance 计算距离

`distance(a, b)` 返回两点的直线距离。`distance(IN.uv, float2(0.5, 0.5))` 就是每个像素到画面中心的距离：中心为 0、半径 0.3 处为 0.3、角落附近约 0.7。

---

## 3. step 生成硬边遮罩

`step(edge, x)` 的规则：x < edge 返回 0，x ≥ edge 返回 1。这里用 `step(distanceToCenter, radius)`——注意参数顺序：

- 距离 < 半径 → 返回 1（圆内）
- 距离 ≥ 半径 → 返回 0（圆外）

结果是一个硬边圆形遮罩：圆内 1、圆外 0。

---

## 4. lerp 把遮罩变成颜色

`lerp(float3(0,0,0), float3(1.0,0.8,0.2), insideCircle)`：`insideCircle = 1`（圆内）显示暖黄，`= 0`（圆外）显示黑色。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 圆变小 | `radius` 从 `0.3` 改成 `0.15` |
| 圆心移到左上 | `center` 改成 `float2(0.3, 0.7)` |
| 圆内黑、圆外黄 | `step(distanceToCenter, radius)` 改成 `1.0 - step(distanceToCenter, radius)` |
| 边缘柔和 | `step(...)` 换成 `smoothstep(radius - 0.01, radius + 0.01, distanceToCenter)` |

## 6. 练习

练习代码里 `insideCircle = 0.0`。补全距离计算和 `step` 判断，让画面出现一个黄色圆。

### 答案解析

```hlsl
float distanceToCenter = distance(IN.uv, center);
float insideCircle = step(distanceToCenter, radius);
```

`distance(IN.uv, center)` 算出每个像素到中心的距离。`step(distanceToCenter, radius)` 判断该距离是否在半径以内：小于 radius 返回 1（圆内），否则返回 0（圆外）。`lerp` 用这个 0/1 遮罩在黑色和黄色之间切换。起始 `insideCircle = 0.0` 画面全黑。

试着把 `step` 换成 `1.0 - smoothstep(0.29, 0.31, distanceToCenter)`，看边缘软化的效果。

## 7. 【小灶解析】专家补充

### ① 圆 = 距离场 + 阈值

「算距离 → 和半径比大小 → 上色」就是画圆的全部。这套「距离场 + 阈值」的思想，是一切 SDF 形状的起点（第 73、74 课会正式接触 SDF）。

### ② step 的参数顺序别搞反

`step(edge, x)` 是「x ≥ edge 返回 1」。本课写的是 `step(distanceToCenter, radius)`，即距离作为第一个参数、半径作为阈值，得到「圆内 1」。顺序一反圆就变黑。**写 step 前先想清楚：谁是被比较的值，谁是阈值**。

### ③ distance 和 length 等价

`distance(a, b)` 就是 `length(a - b)`。前者直白、后者通用，TA 写代码两种都常见，见到哪个都别慌。
