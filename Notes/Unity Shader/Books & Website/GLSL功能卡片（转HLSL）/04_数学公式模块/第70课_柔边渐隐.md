# 第 70 课 · 柔边渐隐

> 学习目标：用 `smoothstep` 实现圆形边缘的渐隐过渡，对比 `step`。

核心是把到中心的距离变成一个从亮到暗的遮罩：

```hlsl
float distanceToCenter = distance(IN.uv, float2(0.5, 0.5));
float fadeMask = smoothstep(0.3, 0.5, distanceToCenter);
```

---

## 1. 完整代码

```hlsl
Shader "Lesson/70_SoftEdge"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float distanceToCenter = distance(IN.uv, float2(0.5, 0.5));
                float fadeMask = smoothstep(0.3, 0.5, distanceToCenter);

                float3 color = lerp(float3(1.0, 0.8, 0.2), float3(0.0, 0.0, 0.0), fadeMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一个带柔边的暖黄色圆形光晕，中心亮、向外渐暗。

---

## 2. distance 函数

`distance(a, b)` 计算两点直线距离，等价于 `length(a - b)`。`distance(IN.uv, float2(0.5, 0.5))` 算出像素到画面中心的距离：中心为 0、角落约 0.707。

---

## 3. smoothstep 做软边

`smoothstep(0.3, 0.5, distanceToCenter)` 把距离映射成遮罩值：

- 距离 < 0.3（中心区）→ 遮罩 0（100% 显示前景色）
- 距离在 0.3~0.5 → 遮罩从 0 平滑过渡到 1
- 距离 > 0.5（外围）→ 遮罩 1（100% 显示背景黑色）

0.3 和 0.5 这两个参数，就是柔化过渡带的内边缘和外边缘。

---

## 4. lerp 混色

`lerp(黄色, 黑色, fadeMask)`：`fadeMask = 0` 取黄色中心，`= 1` 取黑色外围，中间各取一半。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 亮区更小 | `0.3` 改成 `0.1` |
| 过渡带变窄、边缘更锐 | `0.5` 改成 `0.35` |
| 外围变深紫背景 | `float3(0.0,0.0,0.0)` 改成 `float3(0.1, 0.0, 0.2)` |
| 遮罩翻转、中心变暗 | 参数对调成 `smoothstep(0.5, 0.3, distanceToCenter)` |

## 7. 【小灶解析】专家补充

### ① 硬边圆 vs 柔边圆的区别

第 69 课用 `step` 得到「要么在圆内要么在圆外」的硬边；本课用 `smoothstep` 得到「逐渐过渡」的柔边。**同一个距离场，换一个阈值函数，质感完全不同**。

### ② 光晕、暗角都是这个套路

本课的「中心亮、向外渐暗」反转一下就是「暗角」（vignette，四周压暗）。很多 UI 光晕、角色描边、距离提示圈，本质都是「距离 + smoothstep」。

### ③ 过渡带宽度 = 软硬程度

`0.5 - 0.3 = 0.2` 就是过渡带宽度。想要更柔的光晕就拉宽过渡带（如 0.2~0.6），想要接近硬边就收窄（如 0.29~0.31）。
