# 第 77 课 · 渐变重映射遮罩

> 学习目标：把 `remap` 与 `smoothstep` 结合，把线性渐变塑造成有层次的中心光晕。

把 x 重映射到 [-1,1]、用 `abs` 折叠、再用 `smoothstep` 塑形，就得到以中心为轴的双色渐变。

---

## 1. 完整代码

```hlsl
Shader "Lesson/77_GradientRemapMask"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            float remap(float value, float inMin, float inMax, float outMin, float outMax)
            {
                float ratio = (value - inMin) / (inMax - inMin);
                return lerp(outMin, outMax, ratio);
            }

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float centered = remap(IN.uv.x, 0.0, 1.0, -1.0, 1.0);
                float folded = abs(centered);
                float centerMask = 1.0 - smoothstep(0.0, 0.45, folded);
                float edgeMask = smoothstep(0.15, 0.95, folded);

                float3 centerColor = float3(0.2, 0.85, 1.0);
                float3 outerColor = float3(0.05, 0.05, 0.12);

                float3 color = lerp(outerColor, centerColor, centerMask);
                color = lerp(color, outerColor * 0.65, edgeMask * 0.55);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一条中心亮、外围渐暗的竖向光晕。

---

## 2. remap 做区间转换

`remap(IN.uv.x, 0, 1, -1, 1)` 把 x 从 0~1（左到右）变成 -1~1：左边 -1、中心 0、右边 +1。中心成了 0，方便做对称构图。

---

## 3. abs 折叠对称

`abs(centered)` 去掉负号，左右两侧镜像：中心 0（最近）、两侧 1（最远），形成以中心为轴的 V 形。

---

## 4. 两层 smoothstep 塑形

`centerMask = 1.0 - smoothstep(0.0, 0.45, folded)`：中心区 folded 小 → mask 大（亮色显现）。`edgeMask = smoothstep(0.15, 0.95, folded)`：越向外越大，给画面加一层暗化。两层叠加后中心亮、外围渐暗，形成有层次的光晕。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 亮带变窄、高光更集中 | `0.45` 改成 `0.2` |
| 边缘更暗 | `edgeMask * 0.55` 改成 `edgeMask * 1.0` |
| 中心变橙色 | `centerColor` 改成 `float3(1.0, 0.5, 0.1)` |
| 取消边缘压暗 | 删掉 `color = lerp(color, outerColor * 0.65, ...)` 那行 |

## 6. 练习

练习代码里 `centerMask` 和 `edgeMask` 都是 0。用 remap、abs、smoothstep 补全这两层遮罩。

### 答案解析

```hlsl
float centered = remap(IN.uv.x, 0.0, 1.0, -1.0, 1.0);
float folded = abs(centered);
float centerMask = 1.0 - smoothstep(0.0, 0.45, folded);
float edgeMask = smoothstep(0.15, 0.95, folded);
```

`remap` 把线性 x 转成以中心为 0 的对称空间，`abs` 让左右镜像。`centerMask` 在中心附近为 1、远离中心归 0；`edgeMask` 越向外越大，用于给外围加暗化。起始两个 mask 均为 0，画面只显示外围颜色。

试着把 remap 的输出区间改成 [-2.0, 2.0]，看亮带如何变化。

## 7. 【小灶解析】专家补充

### ① remap + abs + smoothstep 是「对称遮罩」三件套

要做一个「以中心为轴、左右对称、有层次」的遮罩，套路就是：**remap 让中心归零 → abs 折叠对称 → smoothstep 塑形**。这组合能做光晕、高光、通道过渡等大量效果。

### ② 两层 mask 分工明确

`centerMask` 管「中心有多亮」，`edgeMask` 管「边缘有多暗」。**一个控制提亮、一个控制压暗**，分开写、分开调，比一个复杂的遮罩公式好维护得多。

### ③ mask 可以叠加乘系数

`edgeMask * 0.55` 里的 0.55 是「边缘压暗强度」。把遮罩乘以系数再喂给 `lerp`，就是「效果强度」的调节旋钮。TA 调效果时大量时间在调这些系数。
