# 第 79 课 · 旋转极坐标遮罩

> 学习目标：把极角、`frac` 重复、`smoothstep` 分段串起来，做旋转的扇形遮罩。

极角归一化后 `frac` 切成扇区，再叠一个径向环，就是旋转的多扇区图案。

---

## 1. 完整代码

```hlsl
Shader "Lesson/79_RotatingWedges"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;

                // 先旋转坐标系，再取极角，扇区就会跟着转
                float angle = _Time.y * 0.8;
                float cosAngle = cos(angle);
                float sinAngle = sin(angle);
                centeredUV = float2(
                    centeredUV.x * cosAngle - centeredUV.y * sinAngle,
                    centeredUV.x * sinAngle + centeredUV.y * cosAngle
                );

                // 极角 → 0~1 → fract 切成扇区
                float polarAngle = atan2(centeredUV.y, centeredUV.x);
                float normalizedAngle = (polarAngle + 3.14159265) / 6.2831853;
                float wedges = frac(normalizedAngle * 8.0);
                float wedgeMask = 1.0 - smoothstep(0.32, 0.42, wedges);

                // 径向环：只在离中心一定距离内显示
                float ringMask = 1.0 - smoothstep(0.25, 0.5, length(centeredUV));

                float finalMask = wedgeMask * ringMask;

                float3 backgroundColor = float3(0.05, 0.05, 0.1);
                float3 foregroundColor = float3(0.9, 0.75, 0.4);
                float3 color = lerp(backgroundColor, foregroundColor, finalMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一个旋转的 8 扇区图案，像风车或雷达扫描。

---

## 2. 先旋转、再取角度

`centeredUV` 先被旋转矩阵旋转，然后才 `atan2` 取极角。旋转之后 `atan2` 读到的角度整体偏移，所以所有扇区一起转。**顺序很重要**：先算角度再旋转就无法达到这个效果。

---

## 3. 极角 → 扇区

```hlsl
float polarAngle = atan2(centeredUV.y, centeredUV.x);   // [-π, π]
float normalizedAngle = (polarAngle + 3.14159265) / 6.2831853;  // [0, 1]
float wedges = frac(normalizedAngle * 8.0);              // 切成 8 段
float wedgeMask = 1.0 - smoothstep(0.32, 0.42, wedges);
```

`frac(normalizedAngle * 8.0)` 把一圈均分 8 段，每段 0~1。`smoothstep(0.32, 0.42, ...)` 取每段的后半截断，`1.0 -` 翻转后每段靠开头是白、靠末尾是黑，形成 8 个扇区。

---

## 4. 径向环

```hlsl
float ringMask = 1.0 - smoothstep(0.25, 0.5, length(centeredUV));
```

`length(centeredUV)` 是到中心的距离，`ringMask` 让中心区域亮、向外渐暗，把扇区限制在一个圆盘内。`finalMask = wedgeMask * ringMask` 相乘 = 逻辑 AND。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 8 扇区变 12 扇区 | `8.0` 改成 `12.0` |
| 扇区亮色更宽 | `0.32` 改成 `0.1` |
| 旋转加速 | `_Time.y * 0.8` 改成 `_Time.y * 3.0` |
| 去掉径向环 | `finalMask` 直接用 `wedgeMask` |

## 6. 练习

练习代码里 `normalizedAngle = 0.0`、`wedgeMask = 0.0`。补全极角归一化、fract 分段、smoothstep 遮罩。

### 答案解析

```hlsl
float polarAngle = atan2(centeredUV.y, centeredUV.x);
float normalizedAngle = (polarAngle + 3.14159265) / 6.2831853;
float wedges = frac(normalizedAngle * 8.0);
float wedgeMask = 1.0 - smoothstep(0.32, 0.42, wedges);
```

`atan2` 把 2D 坐标转成极角（-π~+π），加 π 除以 2π 映射到 0~1 一圈。`frac(normalizedAngle * 8.0)` 把一圈均分 8 段，`smoothstep` 在每段后部做软截断，得到 8 个扇区遮罩。

试着把 `smoothstep(0.32, 0.42, wedges)` 改成 `smoothstep(0.45, 0.55, wedges)`，看扇区宽窄变化。

## 7. 【小灶解析】专家补充

### ① 极坐标是「径向 + 角度」两轴

`length` 给径向（离中心多远）、`atan2` 给角度（绕中心多少度）。有了这两轴，扇形、螺旋、雷达、色环都能描述。**这是 2D 图案的第二套坐标系**（第一套是直角 xy）。

### ② 相乘 = 遮罩的 AND

`wedgeMask * ringMask` 把「在扇区内」和「在圆盘内」两个条件叠加，只有同时满足才显示。第 24 课讲过 `step` 相乘就是逻辑 AND，这里是同一招用在遮罩上。

### ③ 旋转动画 = 变换顺序

「先旋转坐标再取角度」让扇区转动；如果「先取角度再旋转遮罩」效果不同。**变换的顺序决定动画的表现**，这是 TA 调 shader 动画时最容易踩的坑。
