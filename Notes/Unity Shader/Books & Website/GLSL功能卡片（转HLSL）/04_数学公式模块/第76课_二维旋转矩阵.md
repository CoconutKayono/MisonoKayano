# 第 76 课 · 二维旋转矩阵

> 学习目标：用 `float2x2` 旋转矩阵旋转坐标，让图案绕中心转动。

旋转坐标只需要一个 2×2 矩阵，再乘上坐标点：

```hlsl
float2x2 rotationMatrix(float angle)
{
    float cosAngle = cos(angle);
    float sinAngle = sin(angle);
    return float2x2(cosAngle, -sinAngle, sinAngle, cosAngle);
}
// 使用：
centeredUV = mul(rotationMatrix(_Time.y * 0.8), centeredUV);
```

---

## 1. 完整代码

```hlsl
Shader "Lesson/76_RotationMatrix"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            float2x2 rotationMatrix(float angle)
            {
                float cosAngle = cos(angle);
                float sinAngle = sin(angle);
                return float2x2(cosAngle, -sinAngle, sinAngle, cosAngle);
            }

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;
                centeredUV = mul(rotationMatrix(_Time.y * 0.8), centeredUV);

                float distanceToCenter = max(abs(centeredUV.x), abs(centeredUV.y));
                float boxMask = 1.0 - smoothstep(0.22, 0.23, distanceToCenter);

                float3 backgroundColor = float3(0.05, 0.06, 0.1);
                float3 foregroundColor = float3(0.3, 0.8, 0.4);
                float3 color = lerp(backgroundColor, foregroundColor, boxMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一个持续旋转的绿色正方形。

---

## 2. 什么是旋转矩阵

旋转一个点，本质是对它的 x、y 分量做混合：

```
新 x = 原x × cosA - 原y × sinA
新 y = 原x × sinA + 原y × cosA
```

把这四个系数排成 2×2 矩阵 `float2x2(cosAngle, -sinAngle, sinAngle, cosAngle)`，用 `mul(矩阵, 坐标)` 一步完成旋转。角度 `A` 用弧度表示，`_Time.y * 0.8` 让旋转随时间推进。

---

## 3. 为什么要先减 0.5

矩阵旋转以原点 (0,0) 为中心。`IN.uv` 范围 0~1，原点在左下角，直接旋转会绕左下角转圈。所以先 `centeredUV = IN.uv - 0.5` 把中心移到 (0,0)，再旋转。

---

## 4. 正方形怎么画的

旋转后用 `max(abs(x), abs(y))` 计算「切比雪夫距离」，它给出以原点为中心的正方形：距离 < 0.22 遮罩为 1（绿色）、超过 0.23 遮罩为 0（深色背景）。`smoothstep(0.22, 0.23, ...)` 做约 1 像素的柔化，几乎硬边但不锯齿。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 旋转加速 | `0.8` 改成 `2.0` |
| 正方形变小 | `0.22`、`0.23` 改成 `0.15`、`0.16` |
| 正方形变圆形 | `max(abs(x), abs(y))` 改成 `length(centeredUV)` |
| 停止旋转、固定倾斜 45° | `_Time.y * 0.8` 改成固定值 `0.785` |

## 6. 练习

练习代码里 `centeredUV = IN.uv - 0.5` 之后缺了旋转。用 `mul(rotationMatrix(_Time.y * 0.8), centeredUV)` 旋转坐标。

### 答案解析

```hlsl
centeredUV = mul(rotationMatrix(_Time.y * 0.8), centeredUV);
```

`rotationMatrix(_Time.y * 0.8)` 返回随时间变化的旋转矩阵，`mul(矩阵, 坐标)` 把坐标绕原点旋转。起始缺少这行时正方形静止，加上后就开始旋转。`rotationMatrix` 函数已定义，只需调用并赋回给 `centeredUV`。

试着把角度改成 `_Time.y * 0.8 + 0.785`，让正方形以倾斜 45° 的初始姿态开始旋转。

## 7. 【小灶解析】专家补充

### ① 旋转公式要背下来

`x' = x·cosA - y·sinA`，`y' = x·sinA + y·cosA`。这是图形学最基础的公式之一，旋转 UI、粒子、贴图到处都用，死记也要记住。

### ② HLSL 用 mul 做矩阵乘向量

HLSL 里矩阵乘向量用 **`mul(矩阵, 向量)`**。注意矩阵乘法不满足交换律，`mul(向量, 矩阵)` 结果不同，别写反。

### ③ 旋转的「顺序」很重要

先旋转再缩放、先缩放再旋转，结果不一样。第 78 课会把旋转、缩放、重复串起来，届时你会发现变换顺序决定了图案的最终形态。
