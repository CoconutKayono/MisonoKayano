# 第 63 课 · 角度可视化

> 学习目标：用 `atan2` 算出每个像素相对中心的方向角，归一化后驱动灰度，得到「角度轮」。

`atan2(y, x)` 能算出一个点相对于原点的方向角，归一化到 0~1 就能当颜色用。

---

## 1. 完整代码

```hlsl
Shader "Lesson/63_AngleWheel"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;                        // 原点移到中心
                float angle = atan2(centeredUV.y, centeredUV.x);        // 方位角，[-π, π]
                float normalizedAngle = (angle + 3.14159) / 6.28318;    // 归一化到 [0, 1]

                return half4(float3(normalizedAngle, normalizedAngle, normalizedAngle), 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一个绕中心旋转的灰度「角度轮」：正右方最暗、逆时针一圈逐渐变亮。

---

## 2. atan2 返回什么

`atan2(y, x)` 返回从正 x 轴（右侧）出发、逆时针转到向量 (x, y) 的角度，单位是弧度：

| 方向 | 角度 |
|------|------|
| 正右方（3 点钟） | 0 |
| 正上方（12 点钟） | +π/2（约 1.57） |
| 正左方（9 点钟） | +π 或 -π（边界跳变） |
| 正下方（6 点钟） | -π/2（约 -1.57） |

范围是 [-π, +π]，中间在正左方有个从 +π 跳到 -π 的断层。

---

## 3. 归一化到 [0, 1]

```hlsl
float normalizedAngle = (angle + 3.14159) / 6.28318;
```

加 π 把范围从 [-π, π] 平移成 [0, 2π]，再除以 2π 压成 [0, 1]。这样正右方是 0，逆时针转一圈平滑增到 1。用这个值做灰度，就是一圈平滑过渡的角度轮。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 换成红→蓝色相环 | 输出改成 `lerp(float3(1,0,0), float3(0,0,1), normalizedAngle)` |
| 圆心偏移 | `IN.uv - 0.5` 改成 `IN.uv - float2(0.3, 0.5)` |
| 角度分成 3 段重复 | 在归一化后加一行 `normalizedAngle = frac(normalizedAngle * 3.0)` |
| 随时间旋转 | `angle` 那行末尾加上 `+ _Time.y * 0.3` |

### 答案解析

```hlsl
float angle = atan2(centeredUV.y, centeredUV.x);
float normalizedAngle = (angle + 3.14159) / 6.28318;
```

`atan2(centeredUV.y, centeredUV.x)` 计算每个像素相对画布中心的方位角，范围 [-π, π]。加 π 变成 [0, 2π]，除以 2π 得到 [0, 1]。每个像素的 `normalizedAngle` 就是它在圆上的相对位置，灰度图呈现绕中心平滑变化的角度轮盘。

## 6. 【小灶解析】专家补充

### ① atan2 是「极坐标的角度」

`atan2(y, x)` 把二维坐标转成「绕原点的角度」，配合 `length`（距离）就是极坐标。有了极坐标，扇形、螺旋、雷达扫描、色相环都能画。这是 2D 图案里除「距离场」之外的第二根支柱。

### ② 归一化的通用公式

「把 [a, b] 映射到 [0, 1]」的公式是 `(x - a) / (b - a)`。本课就是 `(angle - (-π)) / (π - (-π)) = (angle + π) / 2π`。记住这个公式，任何区间都能归一化。

### ③ 角度可以直接当「色相」

把角度归一化到 0~1 后，可以直接当 HSV 里的色相 H，得到一圈彩虹。这也是 UI 里色环选择器的原理。
