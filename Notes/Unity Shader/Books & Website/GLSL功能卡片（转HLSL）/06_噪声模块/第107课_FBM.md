# 第 107 课 · 分形布朗运动（FBM）

> 学习目标：理解倍频程（Octave）概念，掌握「频率翻倍、振幅减半」的 FBM 叠加规律。

单层噪声太均匀、缺细节。FBM 叠加多层，每层频率翻倍、振幅减半，结果既有大起伏又有细纹理。

---

## 1. 完整代码

```hlsl
Shader "Lesson/107_Fbm"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float value = 0.0;
                float amplitude = 0.5;
                float frequency = 1.0;
                int octaveCount = 4;

                for (int i = 0; i < octaveCount; i++)
                {
                    value += amplitude * valueNoise(IN.uv * 3.0 * frequency);
                    frequency *= 2.0;
                    amplitude *= 0.5;
                }

                float3 color = float3(value, value, value);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是 4 个倍频程叠加的分形噪声：有大块轮廓，也有细密纹路。

---

## 2. 倍频程（Octave）是什么

每一「层」叫一个倍频程。第 1 层是低频大块（提供整体形状），第 2 层频率翻倍、振幅减半（加中等细节），以此类推。**层数越多细节越丰富，但超过 6 层后提升通常不明显。**

---

## 3. 频率翻倍、振幅减半

第 1 层：频率 ×1、振幅 ×0.5 → 大块、贡献多；第 2 层：×2、×0.25 → 中块；第 3 层：×4、×0.125 → 细节。振幅按 0.5 幂次衰减（1/2、1/4、1/8），理论上无限叠加收敛，不会溢出 1.0。

---

## 4. 三列对比

1 个倍频程：平滑大块，像地形高度图轮廓；3 个：加入中频细节；6 个：细节丰富，像真实地形或云层截面。**每加一层，新贡献是上一层的一半，新增复杂度逐渐降低。**

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 只有粗粒度大块 | `int octaveCount = 4` 改成 `1` |
| 极细高频细节 | 改成 `8` |
| 高层衰减慢、对比度更高 | `amplitude *= 0.5` 改成 `amplitude *= 0.7` |
| 整体频率翻倍、纹理变细 | `IN.uv * 3.0` 改成 `IN.uv * 6.0` |

## 6. 练习

把 `int octaveCount = 4` 分别改成 1、3、6，观察画面细节变化，理解倍频程数对 FBM 外观的影响。

### 答案解析

```hlsl
int octaveCount = 4;   // 改为 1、3、6 观察差异
```

1 个倍频程：只有一层平滑噪声，无细节。3 个：加入中频细节，形状开始复杂。6 个：细节丰富接近自然复杂度。关键规律：每增一个倍频程，贡献振幅是上一层一半，视觉复杂度增量递减；超过 6~8 层后几乎无感。

## 7. 【小灶解析】专家补充

### ① Octave 是「层次」的量化单位

音乐里 octave 是八度音程，图形学借来指「频率翻倍的噪声层」。**说「6 个 octave 的 FBM」，意思就是叠了 6 层频率逐层翻倍的噪声。**

### ② 层数与性能成正比

每加一层，噪声计算量翻倍（要算更多 valueNoise）。6 层比 4 层贵 50%。**移动端常压到 3~4 层，PC 可以到 6 层**——这是 TA 做性能预算的常识。

### ③ 收敛性来自等比级数

振幅 1/2、1/4、1/8……是等比级数，和为 1（收敛）。所以 FBM 结果稳定在 0~1，不会爆炸。**这是「为什么振幅要减半」的数学答案**——换别的衰减系数，要么溢出要么收敛不到 1。
