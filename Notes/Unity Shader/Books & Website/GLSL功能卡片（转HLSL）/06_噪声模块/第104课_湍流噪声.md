# 第 104 课 · 湍流噪声

> 学习目标：用 `abs(n*2-1)` 把 FBM 的平缓曲线折叠成尖锐 V 形谷。

FBM 是平缓起伏的，湍流噪声把曲线「折」成尖锐谷底，产生乱流感。

---

## 1. 完整代码

```hlsl
Shader "Lesson/104_TurbulenceNoise"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            float fbm(float2 coord)
            {
                float value = 0.0;
                float amplitude = 0.5;
                for (int i = 0; i < 4; i++)
                {
                    value += amplitude * valueNoise(coord);
                    coord *= 2.0;
                    amplitude *= 0.5;
                }
                return value;
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float noiseValue = fbm(IN.uv * 6.0);
                noiseValue = abs(noiseValue * 2.0 - 1.0);

                float3 color = float3(noiseValue, noiseValue, noiseValue);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是尖锐的暗色纹路，像燃烧的火焰边缘或大理石脉络。

---

## 2. `abs(n * 2.0 - 1.0)` 做了什么

两步看：

`n * 2.0 - 1.0`：把 0~1 映射到 -1~1，噪声 50% → 0，0% → -1，100% → 1；`abs(...)`：负值折回正值。

结果：原本平缓过 0 的地方（噪声 50%）变成 V 形谷底，极端值（0% 和 100%）都变亮峰。**所有平缓过渡的中间地带变成尖锐暗谷，产生「乱流」感。**

---

## 3. 和脊状噪声的对比

湍流：`abs(n*2-1)` → 中间暗谷、极端亮峰。脊状：`1.0 - abs(n*2-1)` → 中间亮峰、极端暗谷。**差一个 `1.0 -`，高低完全互换。**

---

## 4. 为什么像火焰

火焰边缘有强烈的「撕裂感」——暗部锐利、亮部分散。湍流噪声的 V 形暗谷正好提供这种锐利暗纹，所以常用来做火焰、熔岩的纹理。

| 纹路变大像气流 | `6.0` 改成 `3.0` |

## 6. 练习

练习代码里只有 `noiseValue = fbm(...)`。加一行 `noiseValue = abs(noiseValue * 2.0 - 1.0)`。

### 答案解析

```hlsl
float noiseValue = fbm(IN.uv * 6.0);
noiseValue = abs(noiseValue * 2.0 - 1.0);
```

`n * 2.0 - 1.0` 把 [0,1] 拉伸到 [-1,1]，中点映射到 0；`abs(...)` 把曲线中段折叠成 V 形谷底、两端变最亮。平缓 FBM 的过渡地带变成尖锐暗纹，出现强烈湍流感。

试着把 `2.0` 改成 `3.0`，V 形谷更深更窄、暗纹更锐利。

---

## 7. 【小灶解析】专家补充

### ① 湍流 = 火焰纹理的起点

火焰、熔岩、爆炸的暗纹都是「锐利暗谷 + 散落亮部」，湍流噪声的 V 形谷正好提供这个结构。**「湍流噪声 + 暖色映射」是程序化火焰的最简配方。**

### ② 折叠让噪声「变硬」

普通 FBM 是柔软的圆顶，折叠后出现尖锐转折，视觉上「硬」了很多。**想要材质更有攻击性、更锐利，就上折叠**——这是从「柔和自然」到「剧烈自然」的开关。

### ③ 三个变体一张图记住

FBM（圆顶）→ `abs` 湍流（V 谷）→ `1.0-abs` 脊状（尖峰）。**同一个噪声，三种折叠，三种地貌**。这张「噪声变形记」值得刻进脑子。
