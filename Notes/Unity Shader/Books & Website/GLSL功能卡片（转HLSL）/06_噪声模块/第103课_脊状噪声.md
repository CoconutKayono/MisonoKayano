# 第 103 课 · 脊状噪声

> 学习目标：用 `1.0 - abs(n*2-1)` 把 FBM 的圆顶丘陵翻转成尖锐脊线。

普通 FBM 的高亮区是圆顶丘陵，脊状噪声把这些圆顶「翻」成尖峰。

---

## 1. 完整代码

```hlsl
Shader "Lesson/103_RidgedNoise"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            float fbm(float2 coord)
            {
                float value = 0.0;
                float amplitude = 0.5;
                for (int i = 0; i < 4; i++)
                {
                    value += amplitude * valueNoise(coord);
                    coord *= 2.0;
                    amplitude *= 0.5;
                }
                return value;
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float noiseValue = fbm(IN.uv * 6.0);
                noiseValue = 1.0 - abs(noiseValue * 2.0 - 1.0);

                float3 color = float3(noiseValue, noiseValue, noiseValue);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一张尖锐的脊线网格，峰值锐利、谷底宽阔，像山脉山脊或发光丝线。

---

## 2. `abs(n * 2.0 - 1.0)` 做了什么

分步看：

`n * 2.0 - 1.0`：把 0~1 映射到 -1~1；`abs(...)`：取绝对值，原本靠近 0 的中间段（噪声 50% 附近）被折叠到最低点；最外层 `1.0 - ...`：低点变高、高点变低。

效果：噪声接近 0% 或 100%（极端值）→ 变 0（暗谷）；接近 50%（中间值）→ 变 1（亮峰）。**峰值尖锐、谷地宽阔，这就是「脊」的感觉。**

---

## 3. 和湍流噪声的对比

湍流用 `abs(n*2-1)`（不取反）：中间变暗谷、极端变亮峰。脊状用 `1.0 - abs(n*2-1)`（取反）：刚好相反。两者都是对噪声的数学折叠，**只差一个 `1.0 -`**。

---

## 4. 为什么脊线适合做山

山脉的形态就是「高而尖的山脊 + 宽而平的谷地」，脊状噪声的形态正好吻合。游戏地形里的山脊、岩石纹理常用它。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 脊线变稀疏、更宽 | `6.0` 改成 `3.0` |
| 脊线密集像发丝 | `6.0` 改成 `12.0` |
| 变成湍流噪声（高低翻转） | 去掉 `1.0 -` |
| 脊线发光感 | 外层套 `lerp(dark, bright, noiseValue)` |

## 6. 练习

练习代码里只有 `noiseValue = fbm(...)`。加一行 `noiseValue = 1.0 - abs(noiseValue * 2.0 - 1.0)`。

### 答案解析

```hlsl
float noiseValue = fbm(IN.uv * 6.0);
noiseValue = 1.0 - abs(noiseValue * 2.0 - 1.0);
```

`n * 2.0 - 1.0` 把 [0,1] 拉伸到 [-1,1]；`abs(...)` 把中间段折叠成谷底；`1.0 - ...` 整体翻转、谷底变峰顶。普通 FBM 的圆顶丘陵被压平谷底、提拔成尖锐脊线。

试着把 `2.0` 改成 `4.0`，脊线会更尖锐密集。

## 7. 【小灶解析】专家补充

### ① 「折叠」是噪声的高级玩法

脊状、湍流都是对噪声做「绝对值折叠」——把一段曲线折回来，制造尖锐转折。**加不加 `1.0 -` 决定高低方向，`* 2.0 - 1.0` 决定折叠位置。** 掌握了折叠，噪声就有了「形状感」。

### ② 脊状噪声是地形生成的主力

真实地形：山脊尖锐、谷底平坦，正好是脊状噪声的形态。**「山 = 脊状噪声 + 高度映射」** 是程序化地形生成（Procedural Terrain）的经典公式。

### ③ 三个噪声变体的关系

普通 FBM → 圆顶；`abs` 湍流 → V 形谷；`1.0 - abs` 脊状 → 尖峰。三者本质是同一噪声的不同折叠，**理解它们的互转关系，比死记公式更重要。**
