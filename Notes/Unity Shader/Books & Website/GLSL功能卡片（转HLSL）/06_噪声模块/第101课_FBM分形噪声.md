# 第 101 课 · FBM 分形噪声

> 学习目标：理解并实现 FBM（分形布朗运动），用多层叠加做出有层次的噪声。

单层 Value Noise 太平滑、缺层次。FBM 把多层噪声叠加，每层频率翻倍、振幅减半。

---

## 1. 完整代码

```hlsl
Shader "Lesson/101_FbmNoise"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            float fbm(float2 coord)
            {
                float value = 0.0;
                float amplitude = 0.5;
                for (int i = 0; i < 4; i++)
                {
                    value += amplitude * valueNoise(coord);
                    coord *= 2.0;      // 频率翻倍：细节更多
                    amplitude *= 0.5;  // 振幅减半：贡献越来越小
                }
                return value;
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float noiseValue = fbm(IN.uv * 6.0);
                float3 color = float3(noiseValue, noiseValue, noiseValue);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是灰度分形噪声：同时看到大块明暗起伏和叠加其上的细纹路，像真实地形。

---

## 2. octave 叠加

`fbm` 循环 4 次，每层贡献：

第 1 层（振幅 0.5）：大轮廓，贡献 50%；第 2 层（0.25）：中等细节 25%；第 3 层（0.125）：小细节 12.5%；第 4 层（0.0625）：极细纹路 6.25%。

叠加后既有大起伏又有细纹路，像真实地形一样有层次。

---

## 3. 为什么叫「分形」

每层和上一层的比例固定（频率 ×2、振幅 ×0.5），这种**自相似结构**就是分形的特征——放大任何一块，都能看到和整体相似的细节，就像海岸线或山脉轮廓。

---

## 4. 频率和振幅的方向

频率翻倍 = 细节变细；振幅减半 = 细层贡献变小。**两个方向相反**：越高频的层越「细」也越「弱」，这样总和高频不会喧宾夺主，保住大轮廓。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 整体频率降低、起伏更缓 | `6.0` 改成 `2.0` |
| 叠加更多层、细节更丰富 | `i < 4` 改成 `i < 8` |
| 高频层贡献更大、纹路更糙 | `amplitude *= 0.5` 改成 `amplitude *= 0.7` |
| 各层更接近 | `coord *= 2.0` 改成 `coord *= 1.5` |

## 6. 练习

练习代码里 `noiseValue = 0.0`。用 `fbm(IN.uv * 6.0)` 计算分形噪声输出灰度。

### 答案解析

```hlsl
float noiseValue = fbm(IN.uv * 6.0);
float3 color = float3(noiseValue, noiseValue, noiseValue);
```

`IN.uv * 6.0` 控制基础层粗细；`fbm(...)` 做 4 次 octave 叠加，返回有层次的 0~1 灰度。相比单层 valueNoise，你能同时看到大起伏和细纹路。

试着把循环次数从 4 改成 2，感受层数减少后细节的消失。

## 7. 【小灶解析】专家补充

### ① FBM 是程序化自然界的「万能底噪」

山、云、水、地形、木头、大理石……几乎所有自然材质的第一步都是 FBM。**先有 FBM 结构，再按需扭曲/阈值/上色**，就是程序化材质的主干流程。这一课是整个噪声模块的枢纽。

### ② 振幅衰减保证「收敛」

振幅按 1/2、1/4、1/8……衰减，无限叠加总和收敛（约等于 1），不会溢出。**这就是 FBM 为什么用「减半」而不是随便一个数**——数学上保证结果稳定在 0~1 附近。

### ③ 层数有性价比上限

4 层已够大多数效果，6~8 层是极限。超过 8 层，新增细节肉眼几乎不可辨，却白白多算好几倍噪声。**层数是「质量 vs 性能」的经典权衡点**，TA 要会按目标平台调它。
