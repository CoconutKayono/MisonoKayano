# 第 98 课 · 噪声阈值

> 学习目标：用 `step` 给噪声加一条阈值线，把连续灰度变成黑白二值图。

平滑噪声是连续灰度，一条阈值线就能切出有机的黑白形状。

---

## 1. 完整代码

```hlsl
Shader "Lesson/98_NoiseThreshold"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            float hash21(float2 coord)
            {
                float2 fractCoord = frac(coord * float2(123.34, 345.45));
                fractCoord += dot(fractCoord, fractCoord + 34.345);
                return frac(fractCoord.x * fractCoord.y);
            }

            float valueNoise(float2 coord)
            {
                float2 cell = floor(coord);
                float2 fracCoord = frac(coord);
                float2 smoothCoord = fracCoord * fracCoord * (3.0 - 2.0 * fracCoord);

                float cornerBottomLeft  = hash21(cell);
                float cornerBottomRight = hash21(cell + float2(1.0, 0.0));
                float cornerTopLeft     = hash21(cell + float2(0.0, 1.0));
                float cornerTopRight    = hash21(cell + float2(1.0, 1.0));

                return lerp(lerp(cornerBottomLeft, cornerBottomRight, smoothCoord.x),
                            lerp(cornerTopLeft, cornerTopRight, smoothCoord.x),
                            smoothCoord.y);
            }

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float noiseValue = valueNoise(IN.uv * 10.0);
                float thresholdMask = step(0.5, noiseValue);

                float3 color = float3(thresholdMask, thresholdMask, thresholdMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一张黑白二值图，白色区域的边界是噪声自然起伏的等高线，像斑纹或苔藓。

---

## 2. step 是什么

`step(edge, x)` 的规则：x 小于 edge → 0（黑），x 大于等于 edge → 1（白）。把它想成一把刀：edge 决定刀切在哪，噪声值在刀左边的像素变黑、右边的变白。这里 edge = 0.5，噪声 50% 以上变白、以下变黑。

---

## 3. 为什么用噪声做阈值

用网格或几何图形做阈值，只能得到规整的边界。**用噪声做阈值，边界变成有机的、不规则的形状**——像自然界的斑纹、苔藓、水面倒影轮廓。

---

## 4. 阈值 = 面积控制

阈值越高，白区越少。0.5 是「一半白一半黑」；0.3 白区更多；0.8 白区只剩零散斑点。**调 edge 就是在调黑白两色的面积占比。**

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 白色区域更多 | `0.5` 改成 `0.3` |
| 白色更少、零散斑点 | `0.5` 改成 `0.8` |
| 边界柔和过渡 | `step(0.5, ...)` 改成 `smoothstep(0.45, 0.55, ...)` |
| 斑块变大像云团 | `10.0` 改成 `4.0` |

## 6. 练习

练习代码里 `thresholdMask = 0.0`。对 `valueNoise(IN.uv * 10.0)` 的结果用 `step(0.5, noiseValue)` 做阈值。

### 答案解析

```hlsl
float noiseValue = valueNoise(IN.uv * 10.0);
float thresholdMask = step(0.5, noiseValue);
```

`valueNoise(IN.uv * 10.0)` 生成较细的平滑噪声；`step(0.5, noiseValue)` 把 ≥50% 的变白、<50% 的变黑。画面被噪声分隔成黑白两块，边界就是噪声的等高线。

## 7. 【小灶解析】专家补充

### ① 阈值化是「从连续到离散」的关键一步

现实世界的很多现象是二值的：水面反射有/无、石头上有/没有雪、皮肤有/没有斑。**用 `step` 把连续噪声切成二值，是模拟这些现象的最直接方式。**

### ② step 和 smoothstep 是两种「切」

`step` 硬切（有锯齿、边界清晰），`smoothstep` 软切（有过渡带、抗锯齿）。阈值做「图案轮廓」常用 smoothstep，做「硬边界」用 step。**记住两者差异，按需选择。**

### ③ 噪声阈值是「等高线图」的本质

阈值 0.5 的白区边界，恰好是噪声场的 0.5 等高线。想画地图上的地形等高线、海陆分界、云层边界，都是在给噪声场画等高线。这一课就是地形可视化的雏形。
