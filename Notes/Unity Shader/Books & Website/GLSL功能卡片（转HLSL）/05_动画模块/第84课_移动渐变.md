# 第 84 课 · 移动渐变

> 学习目标：给水平渐变的坐标加上随时间循环的偏移，让渐变不断向左/向右滚动。

渐变本身上一课的静态版，这一课让它「流动」起来。

---

## 1. 完整代码

```hlsl
Shader "Lesson/84_MovingGradient"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                // 随时间循环的滚动量（0~1 反复）
                float scrollValue = frac(_Time.y * 0.2);

                float movingPosition = IN.uv.x + scrollValue;
                float gradient = frac(movingPosition);

                float3 colorA = float3(0.1, 0.2, 0.9);
                float3 colorB = float3(0.9, 0.3, 0.1);
                float3 color = lerp(colorA, colorB, gradient);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是蓝到橙的水平渐变，整条渐变从左向右缓缓滚动，滚动到头又从头开始。

---

## 2. 让坐标自己走

静态渐变是 `gradient = IN.uv.x`（第 7 课）。要让渐变移动，就让它的「输入坐标」随时间变化：

```hlsl
float movingPosition = IN.uv.x + scrollValue;
```

`scrollValue` 随时间增加，相当于渐变的位置不断右移，画面上的颜色就向左滚动了。

---

## 3. frac 让滚动无限循环

```hlsl
float scrollValue = frac(_Time.y * 0.2);
float gradient = frac(movingPosition);
```

两层 `frac`：第一层让 `scrollValue` 永远是 0~1（时间一直涨，但它只取小数部分，到 1 就归 0）；第二层把超过 1 的坐标折回 0~1，让渐变图案首尾相接、无限循环，不出现跳变。

---

## 4. 为什么要两次 frac

`_Time.y` 无限增长，直接拿来做偏移会让坐标越来越大，最终超出精度。`frac(_Time.y * 0.2)` 先把滚动量锁在 0~1；`frac(movingPosition)` 再把「超出 0~1 的像素坐标」折回，保证渐变无缝衔接。**凡是要「无限循环」的动画，都用 `frac` 折回。**

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 滚动加速 | `_Time.y * 0.2` 改成 `_Time.y * 1.0` |
| 反向滚动 | `IN.uv.x + scrollValue` 改成 `IN.uv.x - scrollValue` |
| 垂直滚动 | `IN.uv.x` 改成 `IN.uv.y` |
| 三色渐变 | 中间再 `lerp` 一次，插入一个中间色 |

## 6. 练习

练习代码里 `scrollValue = 0.0`、`gradient = IN.uv.x`。补全用 `frac` 锁定的滚动量，并让它偏移坐标。

### 答案解析

```hlsl
float scrollValue = frac(_Time.y * 0.2);
float movingPosition = IN.uv.x + scrollValue;
float gradient = frac(movingPosition);
```

`frac(_Time.y * 0.2)` 把无限增长的时间折成 0~1 循环的滚动量；`IN.uv.x + scrollValue` 让渐变坐标随时间偏移；外层 `frac` 让渐变首尾相接、无缝循环。

试着把 `0.2` 改成 `0.05`，看慢速滚动时 `frac` 折回点是否依然平滑。

---

## 7. 【小灶解析】专家补充

### ① frac 是「循环动画」的开关

时间永远只增不减，但动画常常需要循环。`frac` 就是那个「折回」工具——把任意增长的值映射回 0~1，配合图案本身的周期性，就得到无限循环。滚动条纹、跑马灯、循环 UV 全都靠它。

### ② 速度 = 时间倍率

`_Time.y * 0.2` 里的 0.2 是滚动速度：每秒走过 0.2 个渐变周期。想要「每秒滚 N 次」就写 `_Time.y * N`。速度本身也可以被时间调制，做出「忽快忽慢」的滚动。

### ③ 移动的是坐标，不是颜色

初学容易想「把颜色往右移」，但正确做法是「把采样坐标往左移」。**动画的本质是变换坐标，而不是搬运颜色**。记住这个心智模型：想要图案往哪动，就把它采样的坐标往反方向加偏移。
