# 第 88 课 · 时间动画

> 学习目标：用两个不同频率的时间函数，驱动一个圆点沿「利萨茹曲线」轨迹游走。

这是「时间驱动位置」的进阶：一个圆点的坐标由两路独立的时间波控制。

---

## 1. 完整代码

```hlsl
Shader "Lesson/88_TimeAnimation"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 circleCenter = float2(
                    0.5 + sin(_Time.y) * 0.3,
                    0.5 + cos(_Time.y * 0.7) * 0.3
                );
                float distanceToCenter = length(IN.uv - circleCenter);

                float circleMask = 1.0 - smoothstep(0.05, 0.08, distanceToCenter);

                float3 backgroundColor = float3(0.05, 0.05, 0.1);
                float3 circleColor = float3(0.9, 0.4, 0.6);
                float3 color = lerp(backgroundColor, circleColor, circleMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一个粉色圆点，沿一条不断变化的「8 字 / 蝴蝶」轨迹游走。

---

## 2. 位置本身就是时间函数

之前几课是「颜色/尺寸」随时间变，这一课是「位置」随时间变。`circleCenter` 的 x 和 y 各由一路正弦/余弦波控制：

```hlsl
float2 circleCenter = float2(
    0.5 + sin(_Time.y) * 0.3,
    0.5 + cos(_Time.y * 0.7) * 0.3
);
```

x 用 `sin(_Time.y)`，y 用 `cos(_Time.y * 0.7)`——两路频率不同，合成一条不重复的曲线轨迹。

---

## 3. 为什么轨迹是「8 字」

x、y 都是绕 0.5 中心、幅度 0.3 的振荡，但 x 频率是 1、y 频率是 0.7。频率不同导致两者相位差不断变化，圆点走出一条利萨茹（Lissajous）曲线。**不同频率 + 不同波形 = 复杂且不重复的轨迹。**

---

## 4. 圆点还是那套画法

`circleCenter` 动起来后，剩下和静态画圆完全一样：`length(IN.uv - circleCenter)` 算到圆心的距离，`smoothstep` 画柔和圆点。**「先算动态位置，再按静态套路画」是动画的通用结构。**

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 轨迹幅度更大 | 两个 `0.3` 改成 `0.45` |
| 圆点更大 | `smoothstep(0.05, 0.08, ...)` 改成 `smoothstep(0.05, 0.15, ...)` |
| 换成直线来回 | y 那行改成 `0.5`（固定高度） |
| 轨迹变成圆形 | x 用 `cos(_Time.y)`、y 用 `sin(_Time.y)`（同频率） |

## 6. 练习

练习代码里 `circleCenter = float2(0.5, 0.5)`。补全由两路时间波驱动的圆心坐标。

### 答案解析

```hlsl
float2 circleCenter = float2(
    0.5 + sin(_Time.y) * 0.3,
    0.5 + cos(_Time.y * 0.7) * 0.3
);
```

x 坐标用频率 1 的正弦、y 坐标用频率 0.7 的余弦，都绕 0.5 中心、幅度 0.3 振荡。两路频率不同，合成不重复的利萨茹轨迹，圆点沿轨迹游走。

试着把 x 的 `sin` 改成 `cos`（同频率），看轨迹从「8 字」变成「圆形」。

## 7. 【小灶解析】专家补充

### ① 两路波合成轨迹

一个点在平面上的运动 = x(t) 和 y(t) 两个独立函数。想让轨迹复杂，就让两路波频率、波形、幅度都不同。**这是所有「程序化运动路径」的基础**，从 UI 飘动到粒子轨迹都靠它。

### ② 幅度、频率、相位三件套

任何一路 `A * sin(ω * t + φ)` 都由三要素决定：幅度 A（动多大）、频率 ω（动多快）、相位 φ（错开多少）。调动画就是调这三个数。x、y 两路各自独立调，就能编出无穷多种轨迹。

### ③ 动态位置 + 静态画法 = 万能公式

把「位置」当成一个随时变的值，剩下的绘制逻辑完全不用改。以后做「会动的光点」「游走的粒子」「漂移的图案」，都是先算出动态中心，再套用你已掌握的静态画法。**动画没有新画法，只有会动的位置。**
