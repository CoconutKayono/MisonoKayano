# 第 91 课 · 旋转 UV

> 学习目标：把整个 UV 坐标随时间旋转，让画面上的渐变图案跟着转。

上一课（第 76 课）学过二维旋转矩阵，这一课把它接上时间，让整个坐标系转起来。

---

## 1. 完整代码

```hlsl
Shader "Lesson/91_RotatingUV"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;

                float angle = _Time.y;
                float cosAngle = cos(angle);
                float sinAngle = sin(angle);
                float2 rotatedUV = float2(
                    centeredUV.x * cosAngle - centeredUV.y * sinAngle,
                    centeredUV.x * sinAngle + centeredUV.y * cosAngle
                );

                float gradient = rotatedUV.x + 0.5;
                float3 colorA = float3(0.1, 0.2, 0.9);
                float3 colorB = float3(0.9, 0.2, 0.4);
                float3 color = lerp(colorA, colorB, gradient);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是蓝到粉的水平渐变，整块渐变绕中心匀速旋转，像旋转的色轮。

---

## 2. 旋转矩阵回顾

```hlsl
float2 rotatedUV = float2(
    centeredUV.x * cosAngle - centeredUV.y * sinAngle,
    centeredUV.x * sinAngle + centeredUV.y * cosAngle
);
```

这是标准二维旋转公式（第 76 课）：把 `centeredUV` 绕原点转 `angle` 弧度。**必须先 `- 0.5` 把原点移到中心**，否则会绕着左下角转。

---

## 3. 接上时间

`angle = _Time.y`：角度每秒增加 1 弧度，坐标系持续旋转。旋转坐标系后，画面上的任何图案（这里是渐变）都会跟着转。**旋转的是坐标，图案自己没变**——这是旋转动画的核心心法。

---

## 4. 旋转后的渐变

`gradient = rotatedUV.x + 0.5`：取旋转后坐标的 x 分量做渐变。因为坐标系在转，渐变的「方向」也跟着转，看起来就是渐变色块在旋转。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 转得更快 | `_Time.y` 改成 `_Time.y * 3.0` |
| 反向旋转 | `_Time.y` 改成 `-_Time.y` |
| 渐变更丰富 | 渐变改成 `rotatedUV.x + rotatedUV.y`（对角渐变旋转） |
| 旋转+缩放 | 旋转后加一行 `rotatedUV *= 1.5` |

## 6. 练习

练习代码里旋转的两行是 TODO。用 cos/sin 旋转公式补全 `rotatedUV`。

### 答案解析

```hlsl
float2 rotatedUV = float2(
    centeredUV.x * cosAngle - centeredUV.y * sinAngle,
    centeredUV.x * sinAngle + centeredUV.y * cosAngle
);
```

标准 2D 旋转公式：新 x = 原 x·cos − 原 y·sin，新 y = 原 x·sin + 原 y·cos。`angle = _Time.y` 让坐标系持续旋转，渐变随之转动。

试着把旋转前的 `centeredUV = IN.uv - 0.5` 去掉（直接旋转 `IN.uv`），观察旋转中心变成左下角的效果。

## 7. 【小灶解析】专家补充

### ① 旋转是「变换坐标」不是「变换图案」

永远记住：想让图案转，就去转它采样的坐标。图案（渐变公式）一行都不用改。**变换坐标是 shader 动画最通用的手法**，旋转、平移、缩放、扭曲全是一个道理。

### ② float2x2 + mul 的写法

本课手写了旋转公式。也可以用矩阵：

```hlsl
float2x2 rotationMatrix = float2x2(cosAngle, -sinAngle, sinAngle, cosAngle);
float2 rotatedUV = mul(rotationMatrix, centeredUV);
```

两种等价，矩阵版更接近第 76 课的 `rotationMatrix` 工具函数，写复杂变换链时更清晰。

### ③ 旋转中心由「减 0.5」决定

`IN.uv - 0.5` 把旋转中心定在屏幕中心。想绕别的点转，就减那个点。想绕角上转，就不减。**旋转中心 = 你平移原点到哪里**，这是所有旋转动画的第一个决策。
