# 第 93 课 · 波动扭曲

> 学习目标：用正弦波在采样坐标上制造扭曲，让原本平直的条纹变成波浪。

先扭曲坐标、再画图案，图案就会「被掰弯」。

---

## 1. 完整代码

```hlsl
Shader "Lesson/93_WaveDistortion"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 uv = IN.uv;

                float waveHeight = sin(uv.x * 20.0 + _Time.y * 3.0) * 0.05;
                uv.y += waveHeight;

                float stripeValue = frac(uv.y * 10.0);
                float stripeMask = step(0.5, stripeValue);

                float3 colorA = float3(0.05, 0.05, 0.1);
                float3 colorB = float3(0.8, 0.4, 0.8);
                float3 color = lerp(colorA, colorB, stripeMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一排紫色水平条纹，条纹边缘被扭成持续流动的波浪。

---

## 2. 先扭曲坐标

```hlsl
float waveHeight = sin(uv.x * 20.0 + _Time.y * 3.0) * 0.05;
uv.y += waveHeight;
```

`sin(uv.x * 20 + time * 3)` 生成一条沿 x 方向传播的正弦波，幅度 0.05，加进 `uv.y`。于是每个像素的采样 y 坐标都被上下推了最多 0.05，后续画的条纹就跟着波浪起伏。

---

## 3. 再画条纹

扭曲之后的 `uv.y` 才拿去 `frac(uv.y * 10.0)` 画条纹。**顺序至关重要**：先扭曲、后画图。如果反过来先画条纹再扭曲颜色，效果完全不同（且复杂得多）。

---

## 4. 时间让波流动

`+ _Time.y * 3.0` 是波的相位，随时间推进，波就沿 x 方向传播。`uv.x * 20.0` 是空间频率——控制一屏里有几个波峰。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 波浪更剧烈 | 幅度 `0.05` 改成 `0.15` |
| 波浪更密 | `20.0` 改成 `40.0` |
| 波传播更快 | `3.0` 改成 `8.0` |
| 改成水波纹 | 幅度用 `sin(uv.x * 15.0 + _Time.y) + sin(uv.y * 15.0 + _Time.y)` 叠加两路 |

## 6. 练习

练习代码里 `uv = IN.uv`（没有扭曲）。补全用正弦波偏移 `uv.y` 的表达式。

### 答案解析

```hlsl
float waveHeight = sin(uv.x * 20.0 + _Time.y * 3.0) * 0.05;
uv.y += waveHeight;
```

`sin(uv.x * 20.0 + _Time.y * 3.0)` 生成沿 x 传播的正弦波，`* 0.05` 限制幅度，加进 `uv.y` 让采样坐标上下波动。之后画的条纹被坐标扭曲带成波浪，时间推进让波流动。

试着把 `uv.y += waveHeight` 改成 `uv.x += waveHeight`，看条纹往哪个方向扭曲。

## 7. 【小灶解析】专家补充

### ① 扭曲 = 给坐标加偏移

「扭曲」「变形」「水波」「热浪」这类效果，几乎都是**在采样坐标上加一个位移场**。位移场可以是 `sin`、噪声（noise）、或任意函数。**坐标先被掰弯，图案自然跟着弯**，这个顺序是扭曲类效果的灵魂。

### ② 幅度、频率、相位三件套再次登场

`sin(uv.x * 20.0 + time * 3.0) * 0.05` 拆开：`20.0` 空间频率（多密）、`3.0` 时间频率（多快）、`0.05` 幅度（多强）。三个数各管一件事，调扭曲手感就是调这三个。

### ③ 进阶：用噪声代替 sin

`sin` 是规则的波，做出来的波浪很「整齐」。真实的水面、火焰、热浪需要**不规则**的扭曲，那时就把 `sin` 换成噪声函数。但原理完全一样：算一个位移场，加进坐标。**本课是「程序化扭曲」的入门，噪声扭曲只是换了个位移场。**
