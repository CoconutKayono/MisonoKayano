# 第 89 课 · 环绕小点

> 学习目标：用 `cos`/`sin` 让一个点绕中心做圆周运动，做出「卫星绕轨」动画。

圆周运动 = 角度随时间增长，x、y 用 `cos`、`sin` 取分量。

---

## 1. 完整代码

```hlsl
Shader "Lesson/89_OrbitingDot"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;

                float angle = _Time.y * 1.5;
                float orbitRadius = 0.3;
                float2 orbitPosition = float2(cos(angle), sin(angle)) * orbitRadius;

                float distanceToDot = length(centeredUV - orbitPosition);
                float dotMask = 1.0 - smoothstep(0.04, 0.06, distanceToDot);

                float3 backgroundColor = float3(0.05, 0.05, 0.1);
                float3 dotColor = float3(1.0, 0.8, 0.3);
                float3 color = lerp(backgroundColor, dotColor, dotMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一个金黄色小点，绕屏幕中心匀速画圆。

---

## 2. 角度随时间增长

`angle = _Time.y * 1.5`：角度每秒增加 1.5 弧度。时间是「只会增」的，角度也就一直转，这就是圆周运动的驱动力。

---

## 3. 角度 → 位置

```hlsl
float2 orbitPosition = float2(cos(angle), sin(angle)) * orbitRadius;
```

`cos` 给 x 分量、`sin` 给 y 分量，两者合成一个方向，乘半径 `0.3` 就是圆上的点。**这是「极坐标 → 直角坐标」的标准转换**，和第 27 课的 `atan2` 正好是反方向。

---

## 4. 小点跟着位置走

算出 `orbitPosition` 后，和第 88 课一样：`length(centeredUV - orbitPosition)` 求距离，`smoothstep` 画柔和圆点。动态位置 + 静态画法，又一次复现。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 转得更快 | `1.5` 改成 `4.0` |
| 反向转（顺时针） | `angle` 前加负号：`-_Time.y * 1.5` |
| 轨道更大 | `0.3` 改成 `0.45` |
| 光晕更大 | `smoothstep(0.04, 0.06, ...)` 的第一参数改成 `0.0` |

## 6. 练习

练习代码里 `orbitPosition = float2(0.3, 0.0)`。补全用 cos/sin 把角度转成圆周位置的表达式。

### 答案解析

```hlsl
float angle = _Time.y * 1.5;
float2 orbitPosition = float2(cos(angle), sin(angle)) * orbitRadius;
```

`angle` 随时间线性增长；`cos(angle)`、`sin(angle)` 分别是单位圆上一点的 x、y 分量，乘半径 `orbitRadius` 得到圆周上的实际位置。角度不断增，点就绕圈转。

试着把 `float2(cos(angle), sin(angle))` 改成 `float2(cos(angle), sin(angle * 2.0))`，看轨迹变成什么形状。

## 7. 【小灶解析】专家补充

### ① 极坐标和直角坐标互转

`atan2(y, x)` 是「直角 → 极角」，`(cos(θ), sin(θ)) * r` 是「极角 → 直角」。这一对转换在圆形、环形、螺旋、扇区图案里反复出现，必须熟练掌握。

### ② 角速度 = 旋转快慢

`angle = _Time.y * 1.5` 里的 1.5 就是**角速度**（弧度/秒）。想要转一圈需要 2π/1.5 ≈ 4.19 秒。算旋转周期就用 `2π / 角速度`。TA 调旋转动画时，脑子里要有这个换算。

### ③ 圆形运动是无数动画的母体

卫星绕轨、指针转盘、loading 转圈、粒子漩涡……本质上都是「角度随时间转 + 半径定距离」。把这一个模式吃透，一大类动画都能随手写出来。
