# 第 92 课 · 旋转圆环

> 学习目标：画一个带缺口的圆环，让缺口沿环旋转，做出「加载转圈」动画。

圆环由「距离场」画，缺口由「极角」切，两者相乘后缺口绕圈转。

---

## 1. 完整代码

```hlsl
Shader "Lesson/92_RotatingRing"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;
                float distanceToCenter = length(centeredUV);

                // 圆环：距离场 + abs 对称检测
                float ringMask = 1.0 - smoothstep(0.02, 0.04, abs(distanceToCenter - 0.3));

                // 缺口：极角 + 时间旋转 + step 切掉一段
                float polarAngle = atan2(centeredUV.y, centeredUV.x);
                float normalizedAngle = (polarAngle + 3.14159265) / 6.2831853;
                float spinningAngle = frac(normalizedAngle + _Time.y * 0.2);
                float gapMask = step(0.08, spinningAngle);

                float finalMask = ringMask * gapMask;

                float3 backgroundColor = float3(0.05, 0.05, 0.1);
                float3 ringColor = float3(0.2, 0.9, 0.7);
                float3 color = lerp(backgroundColor, ringColor, finalMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一个青绿色圆环，上面有个缺口，缺口沿环匀速旋转，像 loading 转圈。

---

## 2. 圆环怎么画

`abs(distanceToCenter - 0.3)` 是「到圆周（半径 0.3）的距离」；`smoothstep(0.02, 0.04, ...)` 在靠近圆周处亮，`1.0 -` 翻转后得一圈细环。这和第 28 课的 SDF 圆环是同一招。

---

## 3. 缺口怎么切

```hlsl
float normalizedAngle = (polarAngle + 3.14159265) / 6.2831853;   // 角度 → 0~1
float spinningAngle = frac(normalizedAngle + _Time.y * 0.2);      // 时间让它转
float gapMask = step(0.08, spinningAngle);                         // 前 8% 是缺口
```

每个像素的极角归一化到 0~1，加时间偏移后 `frac` 折回。`step(0.08, ...)` 把每圈最前面 0.08 的部分（缺口）置 0，其余置 1。

---

## 4. 相乘 = 环上挖缺口

`finalMask = ringMask * gapMask`：圆环遮罩 × 缺口遮罩。环上 `gapMask=0` 的地方被切掉，只剩缺口。**「乘法做遮罩减法」**，第 30 课的布尔运算思想再次出现。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 缺口更大 | `0.08` 改成 `0.2` |
| 转得更快 | `_Time.y * 0.2` 改成 `_Time.y * 1.0` |
| 环更粗 | `smoothstep(0.02, 0.04, ...)` 改成 `smoothstep(0.02, 0.08, ...)` |
| 反向转 | `+ _Time.y * 0.2` 改成 `- _Time.y * 0.2` |

---

## 6. 练习

练习代码里 `ringMask = 0.0`、`gapMask = 0.0`。补全圆环遮罩和旋转缺口遮罩。

### 答案解析

```hlsl
float ringMask = 1.0 - smoothstep(0.02, 0.04, abs(distanceToCenter - 0.3));
float spinningAngle = frac(normalizedAngle + _Time.y * 0.2);
float gapMask = step(0.08, spinningAngle);
```

`abs(distanceToCenter - 0.3)` 检测「到圆周距离」，`smoothstep` 画出细环；极角归一化后加时间偏移再 `frac`，让角度分区随时间转，`step(0.08, ...)` 切出缺口。两者相乘，环上出现旋转缺口。

试着把 `step(0.08, spinningAngle)` 改成 `step(0.08, spinningAngle) * step(spinningAngle, 0.9)`，得到两个缺口。

---

## 7. 【小灶解析】专家补充

### ① 极角是「绕圈的一维坐标」

把圆环想象成一条拉直的数轴，`normalizedAngle` 就是这条数轴上的位置（0~1）。给这条数轴加时间偏移，就是让图案沿环流动。**「角度 → 0~1 → frac → step」是沿环形做动画的标准流水线。**

### ② 缺口 = 相乘切掉

遮罩相乘 = 逻辑 AND，任何「在图案上挖洞 / 切段」的需求，都是用一个 0/1 遮罩去乘。环挖缺口、砖墙挖窗、角色衣服破洞，原理一样。

### ③ 这是 loading 动画的 shader 原型

Unity 的 loading 转圈常用 UI 图片旋转实现，但用 shader 画的好处是：**无贴图、抗锯齿、任意分辨率都清晰**。理解了本课，你就掌握了「纯 shader 画 UI 元素」的一类思路，这在做程序化 UI 特效时很有用。
