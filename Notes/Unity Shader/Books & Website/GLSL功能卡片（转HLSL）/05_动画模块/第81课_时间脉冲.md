# 第 81 课 · 时间脉冲

> 学习目标：用 `_Time.y` 驱动一个 0~1 往返的脉冲，让颜色亮度随时间呼吸。

这是动画模块的第一课。动画的本质就是「把时间塞进某个参数里」。

---

## 1. 完整代码

```hlsl
Shader "Lesson/81_TimePulse"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float pulse = sin(_Time.y) * 0.5 + 0.5;   // 0~1 往返的脉冲
                float3 baseColor = float3(0.15, 0.25, 0.95);
                float3 color = baseColor * (0.2 + 0.8 * pulse);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是一块蓝色，亮度在 20%~100% 之间平滑往返，像呼吸一样。

---

## 2. _Time 是什么

`_Time` 是 Unity 内置的四维向量，`_Time.y` 是从游戏开始累计的秒数。它每秒增加 1，永不停止，所以是动画最常用的「时钟」。

另外还有 `_Time.x = t/20`、`_Time.z = t*2`、`_Time.w = t*3`，不同倍率方便取用。本课只用到 `_Time.y`。

---

## 3. sin 怎么变成脉冲

`sin(_Time.y)` 在 -1~+1 之间来回振荡，但它有负值，不能直接当亮度。两行变换：

```hlsl
float pulse = sin(_Time.y) * 0.5 + 0.5;
```

先把 -1~+1 缩放到 -0.5~+0.5，再加 0.5，得到 0~1。**「`sin(t) * 0.5 + 0.5`」是 shader 里把正弦波映射到 0~1 的标准写法**，之后所有动画课都会反复用到。

---

## 4. 脉冲驱动亮度

`baseColor * (0.2 + 0.8 * pulse)`：当 pulse=0 时乘 0.2（最暗），pulse=1 时乘 1.0（最亮）。`0.2` 是下限，`0.8` 是振幅——这样颜色不会全黑，始终保留一点蓝色。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 呼吸更快 | `sin(_Time.y)` 改成 `sin(_Time.y * 3.0)` |
| 呼吸更慢 | 改成 `sin(_Time.y * 0.4)` |
| 最暗时全黑 | `0.2` 改成 `0.0` |
| 换成红色呼吸 | `baseColor` 改成 `float3(0.95, 0.2, 0.15)` |

## 6. 练习

练习代码里 `pulse = 0.0`。用 `_Time.y` 和 `sin` 补全这个 0~1 脉冲，并让它驱动红色通道。

### 答案解析

```hlsl
float pulse = sin(_Time.y) * 0.5 + 0.5;
float3 color = float3(pulse, 0.0, 0.0);
```

`sin(_Time.y)` 是 -1~1 的正弦波，`* 0.5 + 0.5` 映射到 0~1。把 pulse 直接放进红色通道，画面就在黑和红之间呼吸。

试着把频率改成 `_Time.y * 5.0`，感受呼吸速度变化。

---

## 7. 【小灶解析】专家补充

### ① 时间是 shader 动画唯一的「输入」

shader 本身是无状态的——每一帧都从零开始算，记不住上一帧。想让画面动起来，唯一可靠的办法就是引入一个**每帧都在变的量**，而 `_Time` 就是 Unity 给你准备好的那个量。理解了这一点，你就理解了所有 shader 动画的根基。

### ② `sin(t) * 0.5 + 0.5` 要形成肌肉记忆

这个式子出现的频率极高：呼吸、闪烁、颜色循环、数值往返，全都靠它。记住它的三个要素——**正弦波（振荡）、乘 0.5（振幅减半）、加 0.5（抬到正区间）**。

### ③ 时间倍率 = 动画速度

`sin(_Time.y * 3.0)` 里的 `3.0` 是频率，频率越大变化越快。调动画速度的本质就是改这个倍率。你也可以把倍率抽成一个变量 `float speed = 2.0;`，让速度语义化。
