# 第 29 课 · 平滑边缘

> 学习目标：对比 `step` 与 `smoothstep`，理解平滑边缘（抗锯齿）的原理。

`step` 是硬边（0/1 跳变），`smoothstep` 是软边（0~1 平滑过渡）。本课专门对比它们。

---

## 1. 完整代码

```hlsl
Shader "Lesson/29_SmoothEdge"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float distanceToCenter = length(IN.uv - 0.5);

                float circleMask = 1.0 - smoothstep(0.2, 0.3, distanceToCenter);
                return half4(circleMask, circleMask, circleMask, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 29_SmoothEdge`。一个边缘柔和的圆。

---

## 2. step：硬边

```hlsl
float circleMask = 1.0 - step(0.3, distanceToCenter);
```

`step` 在阈值处**瞬间**从 0 跳到 1，边缘是一个像素宽的突变——放大看是锯齿。

---

## 3. smoothstep：平滑过渡

```hlsl
float circleMask = 1.0 - smoothstep(0.2, 0.3, distanceToCenter);
```

`smoothstep(edge0, edge1, x)` 在 `edge0 ~ edge1` 之间做一条 **S 形平滑曲线**，从 0 逐渐升到 1。`0.2 ~ 0.3` 就是过渡带，宽度 0.1。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 更硬的边缘 | 把 `smoothstep(0.2, 0.3, distanceToCenter)` 改成 `smoothstep(0.29, 0.3, distanceToCenter)` |
| 更软的边缘 | 把范围拉宽，如 `smoothstep(0.1, 0.35, distanceToCenter)` |
| 对比硬边 | 直接换成 `step(0.3, distanceToCenter)` |

---

## 5. 练习

练习代码里 `circleMask = 0.0`（全黑）。用 `1.0 - smoothstep(0.2, 0.3, distanceToCenter)` 计算平滑圆形遮罩。

### 答案解析

```hlsl
float circleMask = 1.0 - smoothstep(0.2, 0.3, distanceToCenter);
```

`smoothstep(0.2, 0.3, distanceToCenter)` 在距离从 0.2 到 0.3 之间平滑地从 0 升到 1。`1.0 -` 反转后，圆内（距离<0.2）为 1，边缘（0.2~0.3）渐变，圆外（距离>0.3）为 0。

过渡带越窄（如 0.29~0.3）边缘越硬越接近 step；越宽边缘越软。

---

## 6. 【小灶解析】专家补充

### ① 抗锯齿的本质

锯齿（aliasing）的根源是：一个像素要么完全在形状内、要么完全在形状外，没有中间值。smoothstep 在边缘给出了「部分覆盖」的中间值，让颜色平滑过渡，**视觉上把锯齿「揉」掉了**。这是软件抗锯齿（AA）的最朴素形式。

### ② smoothstep 的过渡带宽度有讲究

过渡带太宽 → 边缘发虚、形状「糊」；太窄 → 又变回锯齿。经验值是**过渡带取 1~2 个像素对应的 UV 宽度**。在全屏效果里，一个像素大约对应 `1.0 / 屏幕分辨率`，所以过渡带通常设得比 0.01 小。本课的 0.1 是为了让你看清楚效果，实际项目会小很多。

### ③ smoothstep 其实是个「缓动函数」

`smoothstep` 内部用的是 3t²−2t³ 这个三次曲线，在两端斜率为 0，所以过渡「起停都平缓」。这套「缓动（easing）」思想在动画里无处不在。**把 smoothstep 想成「数值版的缓动动画」，很多用法就通了**。
