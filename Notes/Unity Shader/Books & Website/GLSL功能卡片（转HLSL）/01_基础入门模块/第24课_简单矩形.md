# 第 24 课 · 简单矩形

> 学习目标：用两个 `step` 分别限定 x、y 的范围，构造一个简单矩形。

矩形是「x 在范围内 **且** y 在范围内」的区域。两个一维范围判断相乘即可。

---

## 1. 完整代码

```hlsl
Shader "Lesson/24_Rect"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float xInRange = step(0.2, IN.uv.x) * step(IN.uv.x, 0.8);
                float yInRange = step(0.3, IN.uv.y) * step(IN.uv.y, 0.7);

                float rectMask = xInRange * yInRange;
                return half4(rectMask, rectMask, rectMask, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 24_Rect`。画面中央偏下有一个白色矩形。

---

## 2. 限定 x 范围

`step(0.2, IN.uv.x)` 在 `x >= 0.2` 时是 1；`step(IN.uv.x, 0.8)` 在 `x <= 0.8` 时是 1。两者相乘：

```hlsl
float xInRange = step(0.2, IN.uv.x) * step(IN.uv.x, 0.8);
```

只有当 `x` 同时满足「>= 0.2」和「<= 0.8」时，`xInRange` 遮罩才为 1——这就是「在 0.2~0.8 范围内」。

---

## 3. 限定 y 范围，再相交

```hlsl
float yInRange = step(0.3, IN.uv.y) * step(IN.uv.y, 0.7);
float rectMask = xInRange * yInRange;
```

`xInRange * yInRange` 就是「x 在范围内 **且** y 在范围内」，两个一维遮罩相乘得到二维矩形。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 更宽的矩形 | 把 x 范围改成 `0.1` 和 `0.9` |
| 居中矩形 | 让 x、y 范围都关于 0.5 对称，如 `0.3`~`0.7` |
| 正方形 | 让 x、y 范围宽度相等 |

## 5. 练习

练习代码里 `xInRange = 0.0`、`yInRange = 0.0`（全黑）。分别计算 x、y 两个遮罩并相乘。

### 答案解析

```hlsl
float xInRange = step(0.2, IN.uv.x) * step(IN.uv.x, 0.8);
float yInRange = step(0.3, IN.uv.y) * step(IN.uv.y, 0.7);
float rectMask = xInRange * yInRange;
```

每个 `step(a, b)` 都是一个「大于等于」判断。两个 `step` 相乘 = 两个判断同时成立 = 区间。`xInRange * yInRange` 把两个一维区间相乘成二维矩形。

本课的矩形是「绝对位置」（相对左下角），第 19 课是「相对中心」（`abs(uv - 0.5)`）。两种写法都常用，注意体会区别。

---

## 6. 【小灶解析】专家补充

### ① 「范围判断」= 两个 step 相乘

`step(a, x) * step(x, b)` 是「判断 x 是否在 [a, b]」的经典写法。记不住没关系，你只要记住：**`step` 是「大于等于」的比较器，两个比较器相乘就是「区间」**。

### ② 相乘 = 逻辑 AND

遮罩相乘就是「逻辑与（AND）」：只有两个遮罩都为 1，结果才为 1。这是把二维图形拆成一维条件的核心工具。后面「矩形边框」「形状组合」都依赖这个「AND」思想。

### ③ 绝对坐标 vs 居中坐标

本课矩形是相对左下角定位的（直接写 0.2~0.8），第 19 课是相对中心定位的（`abs(uv - 0.5)`）。**居中定位更适合「对称图形」，绝对定位更适合「具体放在某个位置」**。两种都要会，实际使用时按需选。
