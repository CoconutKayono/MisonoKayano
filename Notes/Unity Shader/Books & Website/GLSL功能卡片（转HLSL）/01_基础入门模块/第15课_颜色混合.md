# 第 15 课 · 颜色混合

> 学习目标：学习使用 `lerp`（线性插值）进行颜色混合，理解线性插值的概念和应用。

想在两种颜色之间做渐变，不需要自己算，HLSL 有内置函数 **`lerp`**。

---

## 1. 完整代码

```hlsl
Shader "Lesson/15_ColorMix"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 redColor  = float3(1.0, 0.0, 0.0);   // 红
                float3 blueColor = float3(0.0, 0.0, 1.0);   // 蓝

                float3 finalColor = lerp(redColor, blueColor, IN.uv.x);
                return half4(finalColor, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 15_ColorMix`。左边红、右边蓝，中间紫色过渡。

---

## 2. lerp 是什么

`lerp(颜色A, 颜色B, 混合因子)` 在颜色 A 和颜色 B 之间按比例混合：

- 混合因子 = 0.0 → 完全是 A
- 混合因子 = 0.5 → A 和 B 各一半
- 混合因子 = 1.0 → 完全是 B

```hlsl
float3 finalColor = lerp(float3(1.0, 0.0, 0.0), float3(0.0, 0.0, 1.0), blendFactor);
//                       红色                     蓝色               混合因子
```

混合因子必须在 0.0 到 1.0 之间——正好是 UV 坐标的范围。

---

## 3. 用 uv.x 做水平渐变

把 `uv.x` 当作混合因子，左边 = 0（红色），右边 = 1（蓝色）：

```hlsl
float3 finalColor = lerp(redColor, blueColor, IN.uv.x);
```

---

## 4. 试着改一改

示例代码里颜色是红色和蓝色。把它们改成别的：

| 颜色组合 | 颜色 A | 颜色 B |
|----------|--------|--------|
| 橙→紫 | `float3(1.0, 0.5, 0.0)` | `float3(0.5, 0.0, 1.0)` |
| 白→黑 | `float3(1.0, 1.0, 1.0)` | `float3(0.0, 0.0, 0.0)` |
| 绿→黄 | `float3(0.0, 0.8, 0.3)` | `float3(1.0, 0.9, 0.0)` |

## 5. 练习

练习代码里 `lerp` 的因子是固定的 0.0，所以画面全是红色。把因子改成 `uv.x`，让它从左边红色渐变到右边蓝色。

初始状态：

```hlsl
half4 frag (Varyings IN) : SV_Target
{
    float3 redColor  = float3(1.0, 0.0, 0.0);
    float3 blueColor = float3(0.0, 0.0, 1.0);
    float3 finalColor = lerp(redColor, blueColor, 0.0);   // 全是红色
    return half4(finalColor, 1);
}
```

### 答案解析

把第三个参数从 0.0 改成 `IN.uv.x`：

```hlsl
float3 finalColor = lerp(redColor, blueColor, IN.uv.x);
```

`uv.x` 左边是 0（完全 redColor），右边是 1（完全 blueColor），中间是两者的混合。

进阶：改成 `IN.uv.y` 试试，渐变方向会变成从下到上。

---

## 6. 【小灶解析】专家补充

### ① lerp 的公式

`lerp(颜色A, 颜色B, 混合因子) = 颜色A * (1 - 混合因子) + 颜色B * 混合因子`。当混合因子=0 得到 A，=1 得到 B，中间是两者的加权平均。它是 HLSL 里使用频率最高的函数之一。

### ② 颜色混合 = 逐通道混合

`float3` 的 lerp 是每个通道各自独立插值：红对红、绿对绿、蓝对蓝。所以「混合颜色」本质上就是「分别混合三个分量」，这也是它能用于 float2/float3/float4 任意维度的原因。

### ③ 本课是第 07 课的「正式版」

第 07 课已经用过 lerp 做两色渐变；到这里你已经系统掌握了：`lerp` 是什么 → 怎么用 `uv.x/uv.y` 当混合因子 → 怎么换颜色。**lerp 是你目前最重要的颜色工具**，后面调材质、做后处理、混贴图都会反复用到。

### ④ 关于函数名

在 Unity 的 HLSL 里，线性插值函数统一叫 **`lerp`**。你在别的教程或引擎里可能会看到不同写法，但 Unity 里认准 `lerp` 就不会错。
