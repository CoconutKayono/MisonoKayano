# 第 16 课 · 绘制圆形

> 学习目标：用距离函数绘制基本图形，理解像素坐标系统和 `length()` 的应用。

圆形的本质是：**所有到中心距离相同的点**。用 `length()` 算距离，用 `step()` 判断在不在圆内。

---

## 1. 完整代码

```hlsl
Shader "Lesson/16_Circle"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;        // 原点移到中心
                float distanceToCenter = length(centeredUV);   // 到中心的距离

                float circleMask = 1.0 - step(0.3, distanceToCenter);
                return half4(circleMask, circleMask, circleMask, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 16_Circle`。画面中央出现一个白色圆，圆外是黑色。

---

## 2. 计算到中心的距离

先把坐标居中，再用 `length` 计算当前像素到中心的距离：

```hlsl
float2 centeredUV = IN.uv - 0.5;        // 原点移到中心
float distanceToCenter = length(centeredUV);   // 到中心的距离
```

`length(centeredUV)` = `sqrt(centeredUV.x * centeredUV.x + centeredUV.y * centeredUV.y)`，就是数学里的两点距离公式（这里第二个点是原点）。

---

## 3. 用 step 判断圆内外

`distanceToCenter < 半径` 表示在圆内，用 `step` 实现：

```hlsl
float circleMask = 1.0 - step(0.3, distanceToCenter);
```

- `distanceToCenter < 0.3`：`step(0.3, distanceToCenter)` = 0，`1.0 - 0` = 1（圆内，白色）
- `distanceToCenter >= 0.3`：`step(0.3, distanceToCenter)` = 1，`1.0 - 1` = 0（圆外，黑色）

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 更小的圆 | 把半径 `0.3` 改成 `0.15` |
| 更大的圆 | 把半径 `0.3` 改成 `0.45` |
| 黑底白圆反色 | `float circleMask = step(0.3, distanceToCenter);` |

---

## 5. 练习

练习代码里 `circleMask = 0.0`（全黑）。用 `1.0 - step(0.3, distanceToCenter)` 计算圆形遮罩，让画面中央出现一个白色圆。

### 答案解析

```hlsl
float circleMask = 1.0 - step(0.3, distanceToCenter);
```

`step(0.3, distanceToCenter)` 在 `distanceToCenter < 0.3` 时返回 0，在 `distanceToCenter >= 0.3` 时返回 1。用 `1.0 -` 反转：圆内为 1（白），圆外为 0（黑）。

半径 `0.3` 是相对于归一化坐标 0~1 的比例。改成 `0.15` 圆变小，改成 `0.45` 圆变大，接近填满画面。

---

## 6. 【小灶解析】专家补充

### ① 圆的定义就是「距离场」

`distanceToCenter = length(centeredUV)` 本质上在算一个**距离场（Distance Field）**——每个像素都存着「到中心的距离」。圆只是这个距离场的阈值化结果（`distanceToCenter < r`）。这个思路后面会升级成 SDF（有符号距离场），是程序化建模和字体渲染的核心技术。

### ② step 的硬边问题

`step` 让圆边缘是硬切的，放大看会有**锯齿**。第 09 课讲过，抗锯齿的标准做法是把 `step` 换成 `smoothstep`，让边缘有 1~2 像素的柔化。后面《平滑边缘》一课会专门讲。

### ③ 「先居中再算距离」是固定套路

第 10 课学过 `centeredUV = uv - 0.5`。这里又用了一遍：**先居中，再 length**，是画所有「以中心对称」图形的标准起手式。圆、圆环、光晕、暗角，全都从这个套路出发。
