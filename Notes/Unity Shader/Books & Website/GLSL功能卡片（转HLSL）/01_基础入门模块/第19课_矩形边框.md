# 第 19 课 · 矩形边框

> 学习目标：通过「外矩形 - 内矩形」构造矩形边框。

边框怎么做？思路是：**外矩形减去内矩形，剩下的就是边框区域**。

---

## 1. 完整代码

```hlsl
Shader "Lesson/19_RectBorder"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 distanceToCenter = abs(IN.uv - 0.5);   // 到中心的距离
                float2 halfSize = float2(0.28, 0.18);         // 半宽、半高
                float thickness = 0.03;                       // 边框厚度

                // 外矩形
                float outerRectMask = (1.0 - step(halfSize.x, distanceToCenter.x)) * (1.0 - step(halfSize.y, distanceToCenter.y));
                // 内矩形（内缩 thickness）
                float2 innerHalfSize = halfSize - thickness;
                float innerRectMask = (1.0 - step(innerHalfSize.x, distanceToCenter.x)) * (1.0 - step(innerHalfSize.y, distanceToCenter.y));

                float borderMask = clamp(outerRectMask - innerRectMask, 0.0, 1.0);
                return half4(borderMask, borderMask, borderMask, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 19_RectBorder`。画面中央出现一个白色矩形边框。

---

## 2. 遮罩相减

先构造外矩形遮罩（大矩形区域为 1）：

```hlsl
float2 distanceToCenter = abs(IN.uv - 0.5);   // 到中心的距离
float2 halfSize = float2(0.28, 0.18);         // 矩形的半宽和半高
float outerRectMask = (1.0 - step(halfSize.x, distanceToCenter.x)) * (1.0 - step(halfSize.y, distanceToCenter.y));
```

再构造内矩形遮罩（内缩 thickness 之后）：

```hlsl
float2 innerHalfSize = halfSize - thickness;
float innerRectMask = (1.0 - step(innerHalfSize.x, distanceToCenter.x)) * (1.0 - step(innerHalfSize.y, distanceToCenter.y));
```

两者相减就得到边框区域：

```hlsl
float borderMask = clamp(outerRectMask - innerRectMask, 0.0, 1.0);
```

## 3. 试着改一改

| 效果 | 写法 |
|------|------|
| 更粗的边框 | 把 `thickness` 改成 `0.06` |
| 更细的边框 | 把 `thickness` 改成 `0.015` |
| 正方形边框 | 把 `halfSize` 改成 `float2(0.25, 0.25)` |

## 4. 练习

练习代码里 `outerRectMask = 0.0`、`innerRectMask = 0.0`（全背景色）。分别计算这两个矩形遮罩，让边框显示出来。

### 答案解析

```hlsl
float outerRectMask = (1.0 - step(halfSize.x, distanceToCenter.x)) * (1.0 - step(halfSize.y, distanceToCenter.y));
float2 innerHalfSize = halfSize - thickness;
float innerRectMask = (1.0 - step(innerHalfSize.x, distanceToCenter.x)) * (1.0 - step(innerHalfSize.y, distanceToCenter.y));
float borderMask = clamp(outerRectMask - innerRectMask, 0.0, 1.0);
```

`outerRectMask` 是完整矩形（大），`innerRectMask` 是去掉 thickness 之后的矩形（小）。大减小，剩下一圈边框。

`clamp` 确保结果在 0~1，防止极少数精度问题导致负数。

---

## 5. 【小灶解析】专家补充

### ① 「大减小」是遮罩减法的通用套路

`outerRectMask - innerRectMask` 用减法做「差集」。这是构造空心图形（边框、圆环、中空区域）的通用思路：**两个遮罩相减 = 两个形状的差集**。后面第 30 课《形状组合》还会看到它的兄弟——`max`（并集）和 `min`（交集）。

### ② 矩形是「两个一维遮罩的乘积」

`(1 - step(halfSize.x, distanceToCenter.x))` 是「x 方向在范围内」，`(1 - step(halfSize.y, distanceToCenter.y))` 是「y 方向在范围内」，两者**相乘**（逻辑 AND）才是矩形。矩形 = 竖条 × 横条，这是把二维问题拆成一维的经典思路。

### ③ clamp 防御精度问题

`outerRectMask - innerRectMask` 理论上就是 0 或 1，但浮点运算可能产生极小的负值或 1.0001 之类的误差。`clamp(..., 0, 1)` 把这些误差抹平——「0/1 遮罩做完减法，顺手 clamp 一下」是个好习惯。
