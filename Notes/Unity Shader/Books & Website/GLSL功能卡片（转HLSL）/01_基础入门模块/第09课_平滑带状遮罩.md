# 第 09 课 · 平滑带状遮罩

> 学习目标：用 `smoothstep()` 创建一条平滑的水平亮带。

用 `abs` 测量到画布中线的距离，再用 `smoothstep` 把距离转成一条渐隐的亮带。

---

## 1. 完整代码

```hlsl
Shader "Lesson/09_Band"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float distanceToCenter = abs(IN.uv.y - 0.5);   // 到垂直中心的距离
                float bandMask = 1.0 - smoothstep(0.05, 0.07, distanceToCenter);
                return half4(bandMask, bandMask, bandMask, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 09_Band`。画面中央会出现一条**水平亮带**，向上下两边平滑渐隐到黑。

---

## 2. 构造带状遮罩

先计算当前像素到画面垂直中心的距离：

```hlsl
float distanceToCenter = abs(IN.uv.y - 0.5);
```

- 中心（`IN.uv.y = 0.5`）：`distanceToCenter = 0.0`（最亮）
- 边缘（`IN.uv.y = 0.0` 或 `1.0`）：`distanceToCenter = 0.5`（最暗）

再用 `smoothstep` 把距离转成遮罩：

```hlsl
float bandMask = 1.0 - smoothstep(0.05, 0.07, distanceToCenter);
```

`distanceToCenter < 0.05` 时遮罩为 1（亮带中心），`distanceToCenter > 0.07` 时遮罩为 0（背景），中间平滑过渡。

---

## 3. 试着改一改

| 效果 | 写法 |
|------|------|
| 更宽的带 | 把 `0.05, 0.07` 改成 `0.10, 0.12` |
| 更硬的边缘 | 把两个值改得很接近，如 `0.05, 0.051` |
| 竖直亮带 | 把 `IN.uv.y` 改成 `IN.uv.x` |

## 4. 练习

练习代码里 `bandMask = 0.0`（全背景色）。用 `1.0 - smoothstep(0.05, 0.07, distanceToCenter)` 计算遮罩，让画面中央出现一条水平亮带。

初始状态：

```hlsl
half4 frag (Varyings IN) : SV_Target
{
    float distanceToCenter = abs(IN.uv.y - 0.5);
    float bandMask = 0.0;               // 全黑
    return half4(bandMask, bandMask, bandMask, 1);
}
```

### 答案解析

```hlsl
float distanceToCenter = abs(IN.uv.y - 0.5);
float bandMask = 1.0 - smoothstep(0.05, 0.07, distanceToCenter);
```

- `abs(IN.uv.y - 0.5)` 把 y 轴「距中心的距离」折叠到 0~0.5，越靠近中心 `distanceToCenter` 越小。
- `smoothstep(0.05, 0.07, distanceToCenter)` 在 `distanceToCenter = 0.05` 到 `0.07` 之间从 0 渐变到 1，加上 `1.0 -`，带中心为 1，外侧为 0。

调整 `0.05` 和 `0.07` 可以改变带的宽度和边缘软硬度。两个值越接近，边缘越硬。

---

## 5. 【小灶解析】专家补充

### ① abs(uv.y - 0.5) 是「折叠」

`abs` 把上半（0.5~1）和下半（0~0.5）都「折」到 0~0.5，中心是 0。这是「居中 + 对称」的关键手法——下一课会正式讲居中坐标。想围绕某个中心做对称效果，先减中心再取绝对值/长度，是标准套路。

### ② smoothstep 是 step 的「软」版本

`step` 是硬切（0/1 跳变），`smoothstep(a, b, x)` 用一条 S 形曲线在 `[a, b]` 之间平滑过渡。当 `a == b` 时它退化成 step。所以你可以把 smoothstep 理解成「可以控制过渡宽度的 step」。

### ③ 1.0 - smoothstep(...) 就是第 08 课的反转

`smoothstep(0.05, 0.07, distanceToCenter)` 得到「外侧 1、内侧 0」，取反后变成「内侧 1 的亮带」。同一套反转技巧，在遮罩上反复使用。

### ④ 最重要的实际用途：抗锯齿（Anti-aliasing）

硬边界（step）会产生**锯齿（aliasing）**——这是移动端画圆、画线最常见的问题。smoothstep 让边界有 1~2 像素的柔化过渡，用极小的代价换来边缘平滑。**凡是画形状、画线、做遮罩，TA 的默认选择都是 smoothstep 而不是 step**，这是必须内化的习惯。
