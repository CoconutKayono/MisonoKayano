# 第 22 课 · 双色混合渐变

> 学习目标：用 `lerp` 完成一个简单的水平双色渐变（模块一综合练习）。

这是模块一的综合练习。用 `IN.uv.x` 作为渐变因子，在两种颜色之间插值。

---

## 1. 完整代码

```hlsl
Shader "Lesson/22_TwoColorMix"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 redColor   = float3(1.0, 0.2, 0.2);   // 红
                float3 greenColor = float3(0.2, 0.8, 0.2);   // 绿

                float3 blendedColor = lerp(redColor, greenColor, IN.uv.x);
                return half4(blendedColor, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 22_TwoColorMix`。左边红、右边绿，水平渐变。

---

## 2. 用 lerp 混合两种颜色

```hlsl
float3 blendedColor = lerp(redColor, greenColor, IN.uv.x);
```

`IN.uv.x` 从 0（左）到 1（右）。`lerp(颜色A, 颜色B, 混合因子)` 的数学含义：

```
blendedColor = redColor * (1 - 混合因子) + greenColor * 混合因子
```

- 左边缘（混合因子=0）：纯红
- 右边缘（混合因子=1）：纯绿
- 中间（混合因子=0.5）：红绿各半 = 黄色

---

## 3. 试着改一改

| 效果 | 写法 |
|------|------|
| 变成竖直渐变 | 把 `IN.uv.x` 改成 `IN.uv.y` |
| 反向（左绿右红） | 交换 redColor 和 greenColor |
| 三段颜色 | 加一个中间色，先 lerp 到中色、再 lerp 到第三色 |

## 4. 练习

练习代码里 `blendedColor = redColor`（全红）。用 `lerp(redColor, greenColor, IN.uv.x)` 完成渐变。

### 答案解析

```hlsl
float3 blendedColor = lerp(redColor, greenColor, IN.uv.x);
```

`IN.uv.x` 是天然的 0~1 渐变因子，不需要额外的 clamp（UV 本身就在 0~1 内）。这就是最简单、最常用的「颜色随位置变化」模式。

进阶：想加第三个颜色（比如蓝色）怎么办？思路是「分段插值」：

```hlsl
float3 left  = lerp(redColor, greenColor, saturate(IN.uv.x * 2.0));       // 左半段
float3 right = lerp(greenColor, blueColor, saturate(IN.uv.x * 2.0 - 1.0)); // 右半段
float3 blendedColor = lerp(left, right, step(0.5, IN.uv.x));
```

---

## 5. 【小灶解析】专家补充

### ① lerp 是颜色混和的「通用动词」

不管你是在渐变、还是在做颜色选择，`lerp` 都是把「0~1 的因子」变成「两个端点之间的颜色」的标准工具。本课和 07/15 课本质相同，但这里明确点出：**lerp 的因子不一定要是距离，可以是 UV 分量、噪声、时间……任何 0~1 的量**。

### ② 三色渐变 = 分段 lerp + step 切换

练习的进阶答案展示了「多段渐变」的标准做法：把范围拆成两段，各做一次 lerp，再用 `step` 选段。这是「色带（ramp）」的基础——美术里的渐变贴图、配色条，底层都是这个思路。

### ③ 别忘了 saturate

进阶答案里用了 `saturate(x)`，它是 `clamp(x, 0, 1)` 的简写。当 lerp 的因子可能超界时（比如 `uv.x * 2.0` 最大到 2），用 saturate 兜底是必备操作。**HLSL 里的 saturate 在 GPU 上是免费的，能加就加**。
