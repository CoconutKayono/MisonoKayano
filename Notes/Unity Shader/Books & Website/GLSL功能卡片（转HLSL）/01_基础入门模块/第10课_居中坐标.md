# 第 10 课 · 居中坐标

> 学习目标：把居中 UV（`uv - 0.5`）可视化成颜色，理解「以中心为原点」的重要性。

UV 坐标的原点在左下角。但画圆、做光晕、计算对称效果时，我们通常需要以画面中心为基准。

---

## 1. 完整代码

```hlsl
Shader "Lesson/10_CenteredUV"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 centeredUV = IN.uv - 0.5;   // 原点移到中心
                float3 color = float3(centeredUV + 0.5, 0.0);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

---

## 2. 减去 0.5，原点移到中心

一行代码就够：

```hlsl
float2 centeredUV = IN.uv - 0.5;
```

变换前后的对比：

| 位置 | IN.uv | centeredUV（变换后） |
|------|-------|------------|
| 左下角 | (0.0, 0.0) | (-0.5, -0.5) |
| 右上角 | (1.0, 1.0) | ( 0.5, 0.5) |
| 正中心 | (0.5, 0.5) | ( 0.0, 0.0) |

现在 `centeredUV` 的范围是 -0.5 到 0.5，中心是 (0, 0)。

---

## 3. 可视化 centeredUV

`centeredUV` 里有负数，直接当颜色会被截断（颜色不能为负，回忆第 03 课的 clipping）。加回 0.5 就能正常显示：

```hlsl
float3 color = float3(centeredUV + 0.5, 0.0);
```

这等价于原来的 UV 颜色图，只是思路变了——现在 `centeredUV` 描述的是「距中心的偏移」。

---

## 4. 为什么重要

画圆形时，需要计算像素到中心的距离：

```hlsl
float distanceToCenter = length(centeredUV);   // 到中心的距离
```

如果用原始 `IN.uv`，算出来是到左下角的距离，圆会偏到右上方。用 `centeredUV = IN.uv - 0.5`，圆才会在正中间。

---

## 5. 练习

用 `centeredUV = IN.uv - 0.5` 构造居中坐标，再用 `float3(centeredUV + 0.5, 0.0)` 输出颜色。

初始状态（全黑）：

```hlsl
half4 frag (Varyings IN) : SV_Target
{
    float2 centeredUV = IN.uv - 0.5;
    float3 color = float3(0.0, 0.0, 0.0);
    return half4(color, 1);
}
```

### 答案解析

```hlsl
float2 centeredUV = IN.uv - 0.5;
float3 color = float3(centeredUV + 0.5, 0.0);
```

- `centeredUV + 0.5` 把范围从 -0.5~0.5 移回 0~1，才能当颜色用。
- `centeredUV.x + 0.5` 给红色通道 → 左边红色为 0，右边为 1
- `centeredUV.y + 0.5` 给绿色通道 → 下边绿色为 0，上边为 1
- 蓝色固定为 0

视觉上和 UV 颜色图一样，但现在你的坐标是以中心为原点的，后续画任何圆形、光晕都可以直接用 `centeredUV`。

---

## 6. 【小灶解析】专家补充

### ① 为什么原点要在中心

对称效果（圆、光晕、旋转、缩放）都以中心为基准。原始 UV 原点在左下角，直接 `length(IN.uv)` 是「到左下角的距离」，做出来的圆会偏到右上角。**先居中（减 0.5），再算距离**，是画所有对称图形的第一步。

### ② 负数被截断

颜色通道不能为负，所以可视化 `centeredUV` 必须 `+0.5` 移回 0~1。这再次呼应第 03 课——**0~1 是颜色的「通用货币」**，超出区间的中间量需要先映射回来才能显示。

### ③ 坐标变换从「平移」开始

`centeredUV = IN.uv - 0.5` 是一次**平移变换**。后面你会继续学缩放（`centeredUV * scale`）和旋转（乘旋转矩阵），它们都是对 `centeredUV` 这个居中坐标做的。**平移 → 缩放 → 旋转**，是 Shader 里最常见的三种坐标变换，今天学的是第一种。

### ④ centeredUV 是后面所有「画形状」的起点

圆 = `length(centeredUV) < r`；圆角矩形、光晕、距离场（SDF）全都建立在 `centeredUV` 上。你已经为「用数学画形状」铺好了地基——下一课画圆就会直接用它。
