# 第 25 课 · 硬边遮罩

> 学习目标：用 `step` 制造一个硬边遮罩，把画面一刀切成两半。

`step` 的返回值是 0 或 1，没有任何中间值——这就是「硬边」。

---

## 1. 完整代码

```hlsl
Shader "Lesson/25_HardEdge"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 leftColor  = float3(0.15, 0.2, 0.9);   // 蓝
                float3 rightColor = float3(1.0, 0.5, 0.1);    // 橙

                float hardEdgeMask = step(0.5, IN.uv.x);
                float3 color = lerp(leftColor, rightColor, hardEdgeMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 25_HardEdge`。左半蓝、右半橙，中间一条笔直的分界线。

---

## 2. step 的硬边特性

```hlsl
float hardEdgeMask = step(0.5, IN.uv.x);
```

`IN.uv.x < 0.5` 时遮罩精确为 0，`IN.uv.x >= 0.5` 时精确为 1。中间**没有任何过渡**——这就是硬边。

---

## 3. 用遮罩切换颜色

```hlsl
float3 color = lerp(leftColor, rightColor, hardEdgeMask);
```

遮罩是 0/1，所以 lerp 只会取两个端点，中间不会出现混合色。分界线处是「跳变」。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 分界线右移 | 把阈值 `0.5` 改成 `0.7` |
| 水平切分 | 把 `IN.uv.x` 改成 `IN.uv.y` |
| 柔和过渡 | 把 `step` 换成 `smoothstep(0.45, 0.55, IN.uv.x)` |

---

## 5. 练习

练习代码里 `hardEdgeMask = 0.0`（全左色）。用 `step(0.5, IN.uv.x)` 计算硬边遮罩。

### 答案解析

```hlsl
float hardEdgeMask = step(0.5, IN.uv.x);
```

`step(0.5, IN.uv.x)` 是二值函数：`x < 0.5` 返回 0、`x >= 0.5` 返回 1。用它做 lerp 的因子，颜色在分界线处从蓝色瞬间跳到橙色。

把 `0.5` 改成 `0.7`，分界线右移；改成 `smoothstep(0.45, 0.55, ...)`，则出现柔和过渡。

---

## 6. 【小灶解析】专家补充

### ① 硬边 vs 软边：step 与 smoothstep 的分工

`step` 是「开关」，`smoothstep` 是「渐变」。硬边适合「UI 分块、形状轮廓、技术可视化」，软边适合「阴影、光晕、自然过渡」。**什么时候用哪个，取决于你希望边界是「一刀切」还是「有过渡」**。

### ② 硬边在真实渲染里的代价

硬边在低分辨率下会有明显**锯齿（aliasing）**，因为像素要么全蓝要么全橙，没有中间值来「欺骗眼睛」。真实项目的 UI 或图像处理里，纯硬边常常要配合 MSAA（多重采样抗锯齿）或换成 smoothstep。**硬边便宜但粗糙，软边贵一点但平滑**——这是渲染里永恒的权衡。

### ③ step 的阈值就是「分界线位置」

`step(0.5, x)` 里的 0.5 是分界线位置；`step(a, x)` 的 a 越大，分界线越靠右。这个阈值是「可调参数」——把 0.5 提出来做成一个可调节的材质属性，你就能在 Inspector 里拖条滑动分界线了。
