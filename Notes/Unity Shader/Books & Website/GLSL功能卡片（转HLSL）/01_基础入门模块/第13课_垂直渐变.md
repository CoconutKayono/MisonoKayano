# 第 13 课 · 垂直渐变

> 学习目标：使用 `uv.y` 创建从下到上的渐变。

上一节用 `uv.x` 做水平渐变，这一节换成 `uv.y`，方向变成从下到上。

---

## 1. 完整代码

```hlsl
Shader "Lesson/13_VerticalGradient"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 colorA = float3(0.1, 0.15, 0.25);   // 深夜蓝
                float3 colorB = float3(0.2, 0.85, 1.0);    // 天蓝色

                float blendFactor = IN.uv.y;
                float3 color = lerp(colorA, colorB, blendFactor);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

跑起来步骤同前，Shader 选 `Lesson → 13_VerticalGradient`。底部深色、顶部亮蓝，像天空。

---

## 2. uv.y 控制垂直方向

`uv.y` 在画面底部是 0.0，顶部是 1.0：

```hlsl
float blendFactor = IN.uv.y;
float3 color = lerp(colorA, colorB, blendFactor);
```

- 底部：`blendFactor = 0.0` → 完全是 colorA
- 顶部：`blendFactor = 1.0` → 完全是 colorB

---

## 3. 示例颜色

- `colorA = float3(0.1, 0.15, 0.25)` — 深夜蓝
- `colorB = float3(0.2, 0.85, 1.0)` — 天蓝色

底部深色，顶部亮蓝，像是天空渐变。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 反向（上深下亮） | `float blendFactor = 1.0 - IN.uv.y;` |
| 水平方向 | 把 `IN.uv.y` 改成 `IN.uv.x` |
| 黄昏配色 | `colorA = float3(0.2, 0.1, 0.3)`，`colorB = float3(1.0, 0.55, 0.2)` |

---

## 5. 练习

练习代码里因子 `blendFactor` 是 `0.0`（画面全是颜色 A）。把 `blendFactor` 改成 `IN.uv.y`，让颜色从下到上渐变。

初始状态：

```hlsl
half4 frag (Varyings IN) : SV_Target
{
    float3 colorA = float3(0.1, 0.15, 0.25);
    float3 colorB = float3(0.2, 0.85, 1.0);
    float blendFactor = 0.0;            // 全是颜色 A
    float3 color = lerp(colorA, colorB, blendFactor);
    return half4(color, 1);
}
```

### 答案解析

```hlsl
float blendFactor = IN.uv.y;
```

`uv.y` 底部为 0、顶部为 1，`lerp` 在两色间插值得到垂直渐变。

`uv.x` → 水平，`uv.y` → 垂直，就这一个字母的区别。

---

## 6. 【小灶解析】专家补充

### ① 一个字母控制方向

`uv.x` → 水平、`uv.y` → 垂直。这个「用哪个分量控制哪个方向」的直觉，是后面所有基于 UV 的图案（条纹方向、波的方向、扰动方向）的基础。

### ② 天空渐变的本质

本课是最朴素的天光感：底部深、顶部亮。真实的天空盒会考虑视角方向、太阳位置、大气散射，远复杂得多——但「底部深、顶部亮」的垂直渐变是它的第一近似。做风格化天空、卡通风背景时，这一课的效果直接就能用。

### ③ 分量可以各司其职

`uv.x` 和 `uv.y` 可以分别控制不同通道，做出双向渐变：第 05 课把两者相加做对角线，第 12 课把两者拆到红绿通道。`uv` 的两个分量是你可以自由组合的「两个独立信号」。

### ④ lerp 已经成了你的默认工具

从第 07 课到现在，`lerp` 反复出现：水平渐变、垂直渐变、天空渐变……它就是你目前最重要的「颜色工具」。下一课我们会用 `floor` 给这个连续的渐变加上「阶梯」。
