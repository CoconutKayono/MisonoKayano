# 第 45 课 · 高光控制

> 学习目标：用 shininess 参数控制高光的大小和锐利度，理解「光滑度」这个材质维度。

`shininess` 是传给 `pow` 的指数，决定高光大小和锐利程度。

---

## 1. 完整代码

```hlsl
Shader "Lesson/45_SpecularControl"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float3 normalOS : NORMAL;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float3 normalWS : TEXCOORD0;
                float3 positionWS : TEXCOORD1;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
                OUT.positionWS = TransformObjectToWorld(IN.positionOS.xyz);
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 normal = normalize(IN.normalWS);
                float3 viewDir = normalize(GetCameraPositionWS() - IN.positionWS);
                float3 lightDir = normalize(float3(-0.4, 0.6, 0.7));

                float shininess = 16.0;                             // 光滑度
                float3 halfVector = normalize(lightDir + viewDir);
                float specular = pow(max(dot(normal, halfVector), 0.0), shininess);

                float diffuse = max(dot(normal, lightDir), 0.0);
                float3 baseColor = float3(0.4, 0.7, 0.4);
                float3 color = baseColor * (0.1 + 0.9 * diffuse) + float3(1.0, 1.0, 1.0) * specular * 0.6;
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

场景准备同第 31 课。球体上有一个中等大小的白色高光。

---

## 2. shininess 是什么

`shininess` 是高光的「光滑度」参数，传给 `pow` 的指数，决定高光大小和锐利程度：

- `4` → 高光很大很柔，像哑光橡皮
- `16` → 中等，像塑料
- `64` → 小而亮，像金属漆
- `256` → 极小极亮，像镜面或玻璃

指数越大，只有非常接近「完美反射角」的像素才保留亮度，高光点变得又小又集中。

---

## 3. 半向量 hV 是什么

```hlsl
float3 halfVector = normalize(lightDir + viewDir);
float specular = pow(max(dot(normal, halfVector), 0.0), shininess);
```

这是 Blinn-Phong 改进版：把 `lightDir` 和 `viewDir` 相加归一化，得到「夹在中间」的方向，再看法线和它有多对齐。比 Phong 快，且掠射角更稳定。

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 高光很大、表面像橡皮 | `shininess` 从 `16.0` 改成 `4.0` |
| 高光变小、表面更光滑 | `shininess` 从 `16.0` 改成 `64.0` |
| 高光亮度增加（可能过曝） | `* specular * 0.6` 的 `0.6` 改成 `1.5` |

## 5. 练习

练习代码里 `specular = 0.0`，没有高光。补全 TODO，用 `halfVector` 和 `shininess` 计算正确的高光值。

### 答案解析

```hlsl
float specular = pow(max(dot(normal, halfVector), 0.0), shininess);
```

初始状态 `specular = 0.0`，球体只有漫反射。用 `dot(normal, halfVector)` 计算法线和半向量的对齐程度，再用 `pow(..., shininess)` 把它集中成一个高光点。`shininess = 16.0` 对应中等光滑的材质。

## 6. 【小灶解析】专家补充

### ① shininess 不是「越亮」，是「越集中」

很多人误以为 shininess 大 = 高光更亮。其实它控制的是**高光面积**：指数越大，高光总能量被压缩到更小的区域，所以「看起来更亮」——本质是更集中。理解这点，调整材质手感时就不会瞎试。

### ② 光滑度 → 粗糙度的映射

PBR 材质用「粗糙度 roughness」（0~1）替代 shininess。两者方向相反：roughness 小 = 光滑 = shininess 大。知道 shininess 后，理解 PBR 的 roughness 就是一层窗户纸。

### ③ 高光强度也要控

本课高光乘了 `0.6`。高光的「大小」（shininess）和「强度」（乘数）是**两个独立维度**：一个控形状、一个控亮度。真实材质里它们分别对应「粗糙度」和「反射率」。
