# 第 35 课 · 假阴影

> 学习目标：用一个偏移的椭圆模拟球体投射的阴影，不需要任何光线追踪。

真实阴影要追踪光线、计算遮挡，代价高。假阴影（fake shadow）的思路：阴影大致是球体在地面的投影，直接在球体下方画一个模糊的深色椭圆，视觉上就能以假乱真。

> 场景准备：本课是**纯 2D 场景**（球体也是算出来的），shader 贴在一个全屏四边形（Quad）或全屏 UI 上，不是真实 Sphere。

---

## 1. 完整代码

```hlsl
Shader "Lesson/35_FakeShadow"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float aspectRatio = _ScreenParams.x / _ScreenParams.y;
                float2 centeredUV = (IN.uv - 0.5) * 2.0;      // [-1, 1]
                centeredUV.x *= aspectRatio;                   // 修正宽高比

                float3 backgroundColor = float3(0.16, 0.17, 0.22);

                // —— 先画背景，把假阴影压进背景里 ——
                float shadowDistance = length(float2(centeredUV.x, centeredUV.y + 0.55)) - 0.32;
                float shadowMask = 1.0 - smoothstep(0.0, 0.08, shadowDistance);
                shadowMask *= 0.35;
                float3 background = lerp(backgroundColor, float3(0.0, 0.0, 0.0), shadowMask);

                float3 finalColor = background;

                // —— 与球体求交（球心在原点，半径 1），相机在 (0,0,-3) ——
                float3 rayOrigin = float3(0.0, 0.0, -3.0);
                float3 rayDirection = normalize(float3(centeredUV, 1.0));
                float centerProjection = dot(rayOrigin, rayDirection);              // 二次方程一次项系数
                float centerDistSqMinusRadiusSq = dot(rayOrigin, rayOrigin) - 1.0;  // 二次方程常数项
                float discriminant = centerProjection * centerProjection - centerDistSqMinusRadiusSq;

                if (discriminant >= 0.0)
                {
                    float hitDistance = -centerProjection - sqrt(discriminant);
                    float3 surfacePos = rayOrigin + rayDirection * hitDistance;
                    float3 normal = normalize(surfacePos);

                    float3 lightDir = normalize(float3(-0.4, 0.6, 0.7));
                    float diffuse = max(dot(normal, lightDir), 0.0);
                    finalColor = float3(0.35, 0.55, 0.9) * (0.2 + 0.8 * diffuse);
                }

                return half4(finalColor, 1.0);
            }
            ENDHLSL
        }
    }
}
```

画面中央是一个带漫反射的球，正下方有一块模糊的半透明阴影。

---

## 2. 用 SDF 画阴影椭圆

```hlsl
float shadowDistance = length(float2(centeredUV.x, centeredUV.y + 0.55)) - 0.32;
float shadowMask = 1.0 - smoothstep(0.0, 0.08, shadowDistance);
shadowMask *= 0.35;
```

`length(float2(x, y + 0.55)) - 0.32` 是一个圆形的有符号距离场（SDF）：`+ 0.55` 把圆心从球心移到球的下方，`- 0.32` 是半径。`smoothstep(0.0, 0.08, ...)` 把它变成从圆内（0）到圆外（1）的柔和遮罩，`1.0 -` 翻转后圆内为 1（有阴影）。

---

## 3. 控制阴影浓度

```hlsl
shadowMask *= 0.35;
```

原始遮罩最大是 1.0（100% 黑）。乘以 0.35 把最深阴影压到 35%，让阴影半透明、更自然。再用 `lerp(backgroundColor, 黑, shadowMask)` 把背景色按阴影强度压暗。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 阴影位置下移（球悬空更高） | 偏移量 `0.55` 改成 `0.75` |
| 阴影边缘更锐利 | 柔化范围 `0.08` 改成 `0.02` |
| 阴影更深更明显 | 浓度 `0.35` 改成 `0.7` |
| 阴影变小 | 半径 `0.32` 改成 `0.15` |

## 5. 练习

练习代码中球体已经画好，但 `shadowMask` 还没有计算。补全阴影的 SDF，并把阴影混进背景颜色里，让球体下方出现模糊的椭圆阴影。

### 答案解析

```hlsl
float shadowDistance = length(float2(centeredUV.x, centeredUV.y + 0.55)) - 0.32;
float shadowMask = 1.0 - smoothstep(0.0, 0.08, shadowDistance);
shadowMask *= 0.35;
float3 background = lerp(backgroundColor, float3(0.0, 0.0, 0.0), shadowMask);
```

`length(float2(x, y + 0.55)) - 0.32` 在球心正下方画了一个半径 0.32 的圆形 SDF；`smoothstep(0.0, 0.08, ...)` 把 0~0.08 的距离范围平滑映射成 0→1，`1.0 -` 翻转为圆内是 1；乘 0.35 控制透明度，最后 `lerp` 把深色叠到背景上。球体在阴影之后绘制，所以球体本身不会被压暗。

试着把偏移量 0.55 改成 `centeredUV.x * 0.2 + 0.55`，让阴影随 x 偏移，模拟光从斜上方照射。

## 6. 【小灶解析】专家补充

### ① 为什么这课又回到「全屏四边形」

前几课用的是真实 Sphere 网格，法线是现成的。但「球体 + 地面阴影」是一个**完整的小场景**，真实做法需要一个球 + 一个地面 + 一套阴影系统。为了单独讲清「假阴影」这个技巧，本课用一个全屏四边形 + 数学解析球体，把整场戏都塞进一个片元着色器里。这是 ShaderToy 式思路的保留，也是「程序化场景」的基础。

### ② 射线与球求交：这一小段是重点

`discriminant >= 0.0` 判断射线是否碰到球，`-centerProjection - sqrt(discriminant)` 求最近交点，`normalize(surfacePos)` 得到球面法线（球心在原点时，法线方向就是点的方向）。**这套「射线求交 → 算交点 → 算法线 → 着色」的流程，是后面学 Ray Marching、程序化 3D 的通用骨架**，值得反复看。

### ③ 假阴影 vs 真阴影

真阴影（Unity 的 Shadow Map）精确但代价高，还要配置光源、投影设置。假阴影就是一个「贴在地面上的深色椭圆」，常用于卡通风、UI、或低端设备的性能优化。缺点是它不会随几何正确变形——真正的椭圆应该横向拉长，本课为了简单用的是圆，你可以试试把 x 方向半径改大（如 `float2(centeredUV.x * 0.6, ...)`）让它更像真实投影。
