# 第 33 课 · 法线可视化

> 学习目标：把法线方向直接显示成颜色，理解「向量 → 颜色」的映射。

法线每个分量在 [-1, 1]，颜色只能在 [0, 1]，用 `* 0.5 + 0.5` 映射。

---

## 1. 完整代码

```hlsl
Shader "Lesson/33_NormalView"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float3 normalOS : NORMAL;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float3 normalWS : TEXCOORD0;
                float3 positionWS : TEXCOORD1;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
                OUT.positionWS = TransformObjectToWorld(IN.positionOS.xyz);
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 normal = normalize(IN.normalWS);
                return half4(normal * 0.5 + 0.5, 1.0);
            }
            ENDHLSL
        }
    }
}
```

场景准备同第 31 课。球体显示出红绿蓝的彩色渐变——每个轴对应一个颜色通道。

---

## 2. 什么是法线

法线是一个三维向量，表示表面上某个点「朝哪个方向看」，就像一根垂直插在表面上的箭头。球体上，中心点的法线朝正前方，边缘的法线朝向侧面。

每个分量（X、Y、Z）的范围是 -1.0 到 1.0：X 正方向朝右，Y 正方向朝上，Z 正方向朝向摄像机。

---

## 3. 为什么要 `* 0.5 + 0.5`

```hlsl
return half4(normal * 0.5 + 0.5, 1.0);
```

法线分量在 [-1, 1]，但颜色只能用 [0, 1]。`* 0.5 + 0.5` 把范围重新映射：

- 朝左（-1）→ 0%（黑）
- 正中（0）→ 50%（中灰）
- 朝右（+1）→ 100%（亮）

三个轴分别对应红（X）、绿（Y）、蓝（Z）通道，球体就显示出彩色渐变。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 取绝对值，颜色对称 | `normal * 0.5 + 0.5` 改成 `abs(normal)` |
| 只看 Z 轴（中心亮、边缘暗） | `normal * 0.5 + 0.5` 改成 `float3(normal.z * 0.5 + 0.5, normal.z * 0.5 + 0.5, normal.z * 0.5 + 0.5)` |
| 只看 X 轴（左暗右亮灰度） | 同上，用 `normal.x` |

## 5. 练习

练习代码里输出 `half4(0.0, 0.0, 0.0, 1.0)`，球体全黑。补全 TODO，输出法线可视化颜色。

### 答案解析

```hlsl
float3 color = normal * 0.5 + 0.5;
return half4(color, 1.0);
```

初始状态 `color` 固定为 0，球全黑。把法线 `normal` 乘以 0.5 再加 0.5，把范围从 [-1,1] 压缩到 [0,1]，才能作为颜色输出。每个轴对应一个通道（X→红，Y→绿，Z→蓝）。

试着把 `* 0.5 + 0.5` 改成 `* 0.5 + 0.3`，看整体颜色会变深还是变浅。

## 6. 【小灶解析】专家补充

### ① 法线可视化是调试「神器」

把法线显示成颜色，是 TA 排查光照问题的第一招：光不对的时候，先看法线对不对。如果法线颜色乱了（比如整体偏蓝、有接缝），那问题十有八九出在法线传递或坐标系转换上，而不是光照公式本身。

### ② 世界空间法线 vs 物体空间法线

本课输出的是**世界空间**法线。球体在世界空间里旋转时，法线方向跟着变，所以颜色会随之变化。如果你用物体空间法线（`IN.normalOS`）输出，颜色就不随旋转变化。这个区别在修光照 bug 时非常关键——**「法线在哪个空间」是 TA 每天都要问自己的问题**。

### ③ 为什么法线要重新归一化

法线从顶点 shader 传到片元 shader 会经过光栅化插值。三个顶点的单位法线平均后，长度通常会小于 1，所以片元里必须 `normalize(IN.normalWS)`。忘了这步，`dot` 的结果会整体偏小，光照变暗。
