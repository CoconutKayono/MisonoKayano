# 第 46 课 · 双光源

> 学习目标：对每盏灯分别计算漫反射再加权叠加，理解多光源的原理。

多光源原理很简单：每盏灯独立算一遍，加权相加。

---

## 1. 完整代码

```hlsl
Shader "Lesson/46_TwoLights"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float3 normalOS : NORMAL;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float3 normalWS : TEXCOORD0;
                float3 positionWS : TEXCOORD1;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
                OUT.positionWS = TransformObjectToWorld(IN.positionOS.xyz);
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float3 normal = normalize(IN.normalWS);

                float3 lightDir1 = normalize(float3(-0.4, 0.6, 0.7));   // 主光：左上偏前
                float3 lightDir2 = normalize(float3(0.6, 0.2, 0.6));     // 补光：右侧偏低

                float diffuse = max(dot(normal, lightDir1), 0.0) * 0.7
                              + max(dot(normal, lightDir2), 0.0) * 0.5;

                float3 baseColor = float3(0.85, 0.6, 0.35);
                float3 color = baseColor * (0.08 + diffuse);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

场景准备同第 31 课。球体正面中心两灯叠加最亮，两侧各受一盏灯，背面接近暗色。

---

## 2. 为什么要加权

现实中的光有强有弱：第一盏贡献 70%（0.7），第二盏贡献 50%（0.5）。权重让你设定**主光（key light）**和**补光（fill light）**的关系：主光强、照亮主要轮廓；补光弱、从另一侧补足暗部细节。

---

## 3. 两盏灯的方向

```hlsl
float3 lightDir1 = normalize(float3(-0.4, 0.6, 0.7));
float3 lightDir2 = normalize(float3(0.6, 0.2, 0.6));
```

两盏灯从不同角度照射，球面每块区域同时受到两个方向的光照贡献。`normalize` 保证方向长度为 1，漫反射结果才正确。

---

## 4. 叠加公式

```hlsl
float diffuse = max(dot(normal, lightDir1), 0.0) * 0.7
              + max(dot(normal, lightDir2), 0.0) * 0.5;
```

`max(..., 0.0)` 保证背光面贡献不会是负数。两项直接相加，得到来自两盏灯的总漫反射量。

---

## 5. 试着改一改

| 效果 | 写法 |
|------|------|
| 两盏灯亮度趋于均衡 | `0.7` 改成 `0.3` |
| 两盏灯来自同侧、背面无光 | `lightDir2` 改成 `normalize(float3(-0.6, 0.2, 0.6))` |
| 再加一盏灯、三点光 | 增加 `lightDir3` 从正下方照射并叠加 |
| 冷暖光对比 | 给两盏灯加不同颜色乘数 |

---

## 6. 练习

练习代码里两盏灯的方向已定义，但 `diffuse` 只用了第一盏。补全第二盏灯的漫反射项，两项加权叠加，让球体出现双光源受光效果。

### 答案解析

```hlsl
float diffuse = max(dot(normal, lightDir1), 0.0) * 0.7
              + max(dot(normal, lightDir2), 0.0) * 0.5;
```

起始代码只有 `max(dot(normal, lightDir1), 0.0) * 0.7`，球体只受一盏灯影响。加上第二项后，补光从右侧照亮暗部，正面中心两灯叠加最亮，两侧各受一盏灯，背面接近暗色。权重 0.7 和 0.5 让主光和补光有明显区别。

试着给第二项加一个颜色乘数，比如 `* float3(0.8, 0.6, 1.0)`，让补光带一点蓝紫色，制造冷暖对比。

---

## 6. 【小灶解析】专家补充

### ① 多光源 = 循环叠加

本课手动写了两盏灯。真实的 Unity shader 会**循环**遍历所有光源，把每盏灯的贡献累加进同一个变量。结构完全一样，只是用 `for` 循环代替手写两行。看到循环遍历光源时，你就知道它做的正是本课这件事。

### ② 主光 + 补光 = 三点布光

摄影里的「三点布光」：主光（key）定轮廓、补光（fill）填暗部、轮廓光（rim，第 34 课）分离背景。本课的主光/补光 + 第 34 课边缘光，合起来就是完整的三点布光——**TA 做角色打光的基本功**。

### ③ 多光源的性能代价

Unity 的前向渲染里，每多一盏真实光源，物体就可能多渲染一遍（多一个 pass）。所以手游通常限制光源数量，或用「假光」（烘焙、探针、本课这种手写方向）代替。理解本课，你就理解了「为什么美术要控制场景里灯的数量」。
