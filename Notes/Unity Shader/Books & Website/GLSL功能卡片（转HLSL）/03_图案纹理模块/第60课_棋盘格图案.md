# 第 60 课 · 棋盘格图案（8×8）

> 学习目标：把棋盘格的格子数量做成参数，并给格子边缘加抗锯齿。

第 49 课画过 10×10 棋盘格，本课把「数量」抽成变量，再加柔边。

---

## 1. 完整代码

```hlsl
Shader "Lesson/60_Checker8x8"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float tileCount = 8.0;
                float2 scaledUV = IN.uv * tileCount;

                float columnIndex = floor(scaledUV.x);
                float rowIndex = floor(scaledUV.y);
                float patternMask = fmod(columnIndex + rowIndex, 2.0);

                float3 darkColor = float3(0.15, 0.3, 0.25);
                float3 lightColor = float3(0.95, 0.9, 0.8);
                float3 color = lerp(darkColor, lightColor, patternMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是 8×8 的墨绿与米白棋盘格。

---

## 2. 编号 + 奇偶，和 10×10 一模一样

```hlsl
float columnIndex = floor(scaledUV.x);
float rowIndex = floor(scaledUV.y);
float patternMask = fmod(columnIndex + rowIndex, 2.0);
```

`floor(scaledUV.x)` 得列号、`floor(scaledUV.y)` 得行号，两者相加对 2 取余：和为偶数得 0、奇数得 1。相邻格子奇偶必相反，颜色自然交替。本课把「列号、行号」分开命名，逻辑比第 49 课更清晰。

---

## 3. 格子数量就是 tileCount

```hlsl
float tileCount = 8.0;
float2 scaledUV = IN.uv * tileCount;
```

格子的多少只由 `tileCount` 决定：8 就是 8×8，16 就是 16×16。改成变量后，想要多少格子改一个数字就行。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 格子变大（4×4） | `tileCount` 改成 `4.0` |
| 格子变小（16×16） | `tileCount` 改成 `16.0` |
| 加柔边（抗锯齿） | 把 `fmod` 那行替换成 `smoothstep(0.0, 0.05, frac(scaledUV.x)) * smoothstep(0.0, 0.05, frac(scaledUV.y))` 后再与奇偶相乘 |
| 换配色 | `darkColor`/`lightColor` 换成别的颜色 |

## 5. 练习

练习代码里 `patternMask = 0.0`。改成正确表达式，让画面出现 8×8 棋盘格。

### 答案解析

```hlsl
float patternMask = fmod(columnIndex + rowIndex, 2.0);
```

`columnIndex + rowIndex` 是格子的行列号之和，`fmod(..., 2.0)` 对 2 取余，相邻格子余数必相反，颜色交替。初始 `patternMask = 0.0` 让画面全深色。

试着把 `tileCount` 从 `8.0` 改成 `3.0`，再改成 `7.0`，观察奇偶数格数对图案对称性的影响。

## 6. 【小灶解析】专家补充

### ① 棋盘格 = 奇偶判断，跟格数无关

无论 8×8 还是 100×100，棋盘格的本质都是「行号 + 列号是奇数还是偶数」。**格数只是 `tileCount` 一个参数**，图案逻辑完全不变。这就是「参数化」：逻辑写死，数量可变。

### ② 硬边棋盘的锯齿问题

`fmod` 直接输出 0/1，格子边界处颜色突变，会产生锯齿。真实项目里常在边界加 `smoothstep` 做 1~2 像素的柔化。本课「试着改一改」里的柔边写法就是这种思路。

### ③ 命名让逻辑自解释

本课用 `columnIndex`、`rowIndex` 而不是 `x`、`y`，读代码时「列号、行号」一眼就懂。**变量名是写给自己三个月后的自己看的**，TA 项目里 shader 常要长期维护，命名尤其重要。
