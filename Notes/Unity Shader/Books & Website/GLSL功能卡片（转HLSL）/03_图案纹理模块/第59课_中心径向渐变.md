# 第 59 课 · 中心径向渐变

> 学习目标：用「到屏幕中心的距离」驱动颜色，做从中心向外扩散的渐变。

`distance(uv, 中心)` 得到距离场，直接当 `lerp` 的比例就是径向渐变。

---

## 1. 完整代码

```hlsl
Shader "Lesson/59_RadialGradient"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float2 center = float2(0.5, 0.5);
                float distanceToCenter = distance(IN.uv, center);

                float3 innerColor = float3(1.0, 0.95, 0.8);   // 中心暖白
                float3 outerColor = float3(0.05, 0.1, 0.25);  // 边缘深蓝

                float3 color = lerp(innerColor, outerColor, distanceToCenter);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面从中心的暖白平滑过渡到边缘的深蓝。

---

## 2. distance 算距离

```hlsl
float2 center = float2(0.5, 0.5);
float distanceToCenter = distance(IN.uv, center);
```

`distance(A, B)` 返回两点间的欧氏距离（等价于 `length(A - B)`）。`IN.uv` 是当前像素位置，`(0.5, 0.5)` 是屏幕中心，所以 `distanceToCenter` 就是「离中心多远」：中心 0，角落约 0.7。

---

## 3. 距离当混合比例

```hlsl
float3 color = lerp(innerColor, outerColor, distanceToCenter);
```

把 `distanceToCenter` 塞进 `lerp` 的第三个参数：中心（距离 0）完全取 `innerColor`，边缘（距离约 0.7）几乎取 `outerColor`，中间平滑过渡。这就是径向渐变。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 渐变中心移到左上角 | `center` 改成 `float2(0.2, 0.8)` |
| 中心颜色范围扩大 | `lerp(inner, outer, distanceToCenter)` 改成 `lerp(inner, outer, distanceToCenter * 0.5)` |
| 变环形（同心圆环） | `distanceToCenter` 改成 `frac(distanceToCenter * 12.0)` |
| 反色 | 交换 `innerColor` 和 `outerColor` |

---

## 5. 练习

练习代码里 `color = innerColor`。改成正确表达式，让画面从中心暖白渐变到边缘深蓝。

### 答案解析

```hlsl
float3 color = lerp(innerColor, outerColor, distanceToCenter);
```

`distanceToCenter` 是像素到中心的距离，作为 `lerp` 的混合比例：中心取暖白、边缘取深蓝、中间平滑过渡。初始 `color = innerColor` 恒定，没有渐变。

试着把 `distanceToCenter` 改成 `distanceToCenter * distanceToCenter`，渐变会更集中在中心，边缘变化更慢。

---

## 6. 【小灶解析】专家补充

### ① 渐变方向 = 你选的「距离场」

水平渐变用 `uv.x`、竖直渐变用 `uv.y`、径向渐变用 `length(uv-中心)`。**渐变的方向由「你选择哪个数值场」决定**，颜色本身永远只是 `lerp` 的产物。这是第 56、57、59 三课共通的本质。

### ② distance 和 length 是同一件事

`distance(A, B)` 就是 `length(A - B)`，前者更直白、后者更通用。TA 写代码时两者都常见，见到哪个都别慌。

### ③ 距离场是「万能的中间变量」

有了距离场，你可以做径向渐变（本课）、同心圆环（第 50 课）、光晕、冲击波扩散、暗角（vignette）等一大堆效果。**先把距离算出来，剩下就是怎么用这个数**。
