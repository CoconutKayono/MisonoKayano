# 第 53 课 · 水平条纹

> 学习目标：只用 y 坐标 + `frac` + `step` 生成水平条纹。

水平条纹只关心 y：`frac(uv.y * 数量)` 让条纹沿竖直方向重复。

---

## 1. 完整代码

```hlsl
Shader "Lesson/53_HorizontalStripes"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float stripeCount = 12.0;

                float stripePattern = frac(IN.uv.y * stripeCount);
                float stripeMask = step(0.5, stripePattern);

                float3 darkColor = float3(0.15, 0.2, 0.3);
                float3 lightColor = float3(0.9, 0.95, 1.0);
                float3 color = lerp(darkColor, lightColor, stripeMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是横向的深浅交替条纹。

---

## 2. 为什么只看 y

`IN.uv.y` 沿竖直方向从 0 增到 1，同一水平线上的所有像素 y 值相同。所以「按 y 值着色」得到的就是水平条纹——每条纹路沿水平方向延伸、沿竖直方向重复。

---

## 3. frac + step 制造重复

```hlsl
float stripePattern = frac(IN.uv.y * stripeCount);
float stripeMask = step(0.5, stripePattern);
```

`IN.uv.y * 12.0` 把 y 拉伸成 0~12，`frac` 折叠成 12 段 0~1 的锯齿波，每段是一条深 + 一条浅。`step(0.5, ...)` 把每段切成上下两半，形成硬边条纹。

---

## 4. 试着改一改

| 效果 | 写法 |
|------|------|
| 条纹变粗 | `stripeCount` 从 `12.0` 改成 `6.0` |
| 条纹变细 | `stripeCount` 从 `12.0` 改成 `24.0` |
| 深浅各占一半改成三七分 | `step(0.5, ...)` 改成 `step(0.3, ...)` |
| 变垂直条纹 | `IN.uv.y` 改成 `IN.uv.x` |

---

## 5. 练习

练习代码里 `stripePattern = 0.0`。改成正确表达式，让画面出现 12 条水平条纹。

### 答案解析

```hlsl
float stripePattern = frac(IN.uv.y * stripeCount);
```

`IN.uv.y * 12.0` 把竖直坐标拉伸成 0~12，`frac` 折叠成 12 段循环。初始 `stripePattern = 0.0` 让 `step` 恒为 0，画面全深色。

试着把 `frac(IN.uv.y * stripeCount)` 改成 `frac(IN.uv.y * stripeCount + _Time.y)`，条纹会向上滚动，这就是常见的动态条纹背景。

---

## 6. 【小灶解析】专家补充

### ① 一维条纹 = 只看一个坐标

水平条纹只依赖 y、垂直条纹只依赖 x、对角条纹依赖 x+y。**条纹就是「一维数值场的阈值切割」**，你选择的那个「维度」决定了条纹的方向。这是第 50、51、53、54 四课共通的本质。

### ② 加时间就是动画

`frac(uv.y * 数量 + _Time.y)` 里的 `_Time.y` 让锯齿波整体平移，条纹就滚动起来。**任何图案里加 `_Time.y` 都能动起来**，这是最廉价的动画技巧。

### ③ 条纹可用于 UV 调试

条纹（尤其等宽黑白条纹）是检查 UV 拉伸、贴图方向的标准手段。TA 经常给模型贴一张条纹图，一眼看出 UV 哪里被拉长了。
