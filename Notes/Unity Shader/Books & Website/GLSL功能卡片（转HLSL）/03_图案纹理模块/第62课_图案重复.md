# 第 62 课 · 图案重复（综合课）

> 学习目标：把「分格 + 随机旋转 + 多种图案选择」组合起来，做随机重复图案。

这是 2D 图案组的综合练习：分格、hash、旋转、形状切换全部用上。

---

## 1. 完整代码

```hlsl
Shader "Lesson/62_PatternRepeat"
{
    SubShader
    {
        Tags
        {
            "RenderType" = "Opaque"
            "RenderPipeline" = "UniversalPipeline"
        }

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct Attributes
            {
                float4 positionOS : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct Varyings
            {
                float4 positionHCS : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            // 把二维整数坐标映射成 0~1 的伪随机数
            float hash21(float2 coord)
            {
                float2 fractCoord = frac(float2(coord.x * 0.1031, coord.y * 0.1030));
                fractCoord += dot(fractCoord, float2(fractCoord.y + 19.19, fractCoord.x + 33.33));
                return frac(fractCoord.x * fractCoord.y);
            }

            Varyings vert (Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS.xyz);
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag (Varyings IN) : SV_Target
            {
                float tileCount = 8.0;
                float2 scaledUV = IN.uv * tileCount;
                float2 cellIndex = floor(scaledUV);      // 格子编号
                float2 cellUV = frac(scaledUV) - 0.5;    // 格内局部坐标，居中

                float randomValue = hash21(cellIndex);

                // 每个格子随机旋转一个角度
                float angle = randomValue * 6.28318;
                float cosAngle = cos(angle);
                float sinAngle = sin(angle);
                float2 rotatedUV = float2(
                    cellUV.x * cosAngle - cellUV.y * sinAngle,
                    cellUV.x * sinAngle + cellUV.y * cosAngle
                );

                // 三种基础形状
                float circleMask = 1.0 - step(0.35, length(rotatedUV));
                float squareMask = 1.0 - step(0.35, max(abs(rotatedUV.x), abs(rotatedUV.y)));
                float crossMask = max(1.0 - step(0.15, abs(rotatedUV.x)),
                                      1.0 - step(0.15, abs(rotatedUV.y)));

                // 用格子编号选形状：圆、方、十字循环
                float patternType = fmod(cellIndex.x + cellIndex.y, 3.0);
                float patternMask;
                if (patternType < 1.0)      patternMask = circleMask;
                else if (patternType < 2.0) patternMask = squareMask;
                else                        patternMask = crossMask;

                float3 darkColor = float3(0.1, 0.1, 0.12);
                float3 lightColor = float3(0.95, 0.9, 0.8);
                float3 color = lerp(darkColor, lightColor, patternMask);
                return half4(color, 1);
            }
            ENDHLSL
        }
    }
}
```

画面是 8×8 的格子，每个格子里随机旋转的圆、方或十字。

## 2. 分格 + 随机旋转

```hlsl
float2 cellIndex = floor(scaledUV);
float2 cellUV = frac(scaledUV) - 0.5;
float randomValue = hash21(cellIndex);
```

`floor` 得格子编号、`frac` 得格内坐标、`hash21` 给每个格子一个稳定随机值。然后用随机值算出角度，把 `cellUV` 旋转：

```hlsl
float angle = randomValue * 6.28318;
float cosAngle = cos(angle);
float sinAngle = sin(angle);
float2 rotatedUV = float2(
    cellUV.x * cosAngle - cellUV.y * sinAngle,
    cellUV.x * sinAngle + cellUV.y * cosAngle
);
```

这是标准的二维旋转公式：每个格子里的图案随机转一个方向。

## 3. 三种形状

```hlsl
float circleMask = 1.0 - step(0.35, length(rotatedUV));
float squareMask = 1.0 - step(0.35, max(abs(rotatedUV.x), abs(rotatedUV.y)));
float crossMask = max(1.0 - step(0.15, abs(rotatedUV.x)),
                      1.0 - step(0.15, abs(rotatedUV.y)));
```

圆用 `length`、方用 `max(abs)`（到中心的切比雪夫距离）、十字用「竖条 + 横条」。三种形状的遮罩都是 0/1。

---

## 4. 用编号选形状

```hlsl
float patternType = fmod(cellIndex.x + cellIndex.y, 3.0);
```

`cellIndex.x + cellIndex.y` 对 3 取余，得到 0、1、2 三个值，用 `if` 分别选圆、方、十字。因为取余的是整数编号，形状会按斜线规律分布。

## 7. 【小灶解析】专家补充

### ① 图案 = 分格 + 状态 + 随机

这是 2D 图案组的总结式：**先把画面分成格子，给每个格子一个「状态」（旋转角、形状类型），再在格子里画基础形状**。砖墙的「错位」、Truchet 的「翻转」、本课的「旋转 + 选形状」都是同一个套路。

### ② 二维旋转公式要背下来

`x' = x·cosθ - y·sinθ`，`y' = x·sinθ + y·cosθ`。这是图形学里最基础的公式之一，旋转 UI、旋转粒子、旋转贴图到处都用。死记也要记住。

### ③ 三种形状是三种「距离函数」

圆是欧氏距离 `length`、方是切比雪夫距离 `max(abs)`、菱形是曼哈顿距离 `abs 相加`。**换距离函数 = 换形状**，这是 SDF 的核心思想，也是你以后做程序化贴图、做体素渲染都会反复遇到的概念。
