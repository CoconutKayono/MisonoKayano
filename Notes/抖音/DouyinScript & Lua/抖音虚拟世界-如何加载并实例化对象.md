# 抖音虚拟世界：如何加载并实例化对象

> 一句话结论：**SDK 不支持 `Resources.Load`，也没有任何按路径加载资源的 API**。运行时实例化对象只有两种方式：
>
> 1. **本地对象**（纯模型、仅自己可见）：用 Unity 原生 `Instantiate` / `Destroy`，或场景常驻 `SetActive` 切换
> 2. **网络对象**（全端同步 / 带 SDK 逻辑）：必须用 `DouyinObjectService.NetSpawn` / `NetDestroy`

## 1. 为什么不能按 path 加载

官方说明：世界上传时云构建会生成 AssetBundle 资源包，创作者无法访问 Resources 目录，所以：
- `Resources.Load` ❌ 不可用
- 没有开放任何 AssetBundle 运行时加载 API ❌
- 资源更新只能重新发布世界，不能运行时热更

引用只能来自三种地方（都不是“按路径加载资源”）：
- **场景里已存在的对象** → 用 `transform:Find("名字")` 或 `GameObject.Find` 查找（这是找场景对象，不是加载资源）
- **Inspector 拖进槽位的引用** → `---@var prefab:UnityEngine.GameObject`
- **注册进配置表的 key** → `NetSpawn("key")`（网络对象专用）

（详见 [[抖音虚拟世界-如何动态加载资源]]）

## 2. 先决策：你要「本地对象」还是「网络对象」

| 需求 | 方式 | 说明 |
| --- | --- | --- |
| 创建角色预览、本地特效、纯模型展示 | 本地对象（方式一） | 仅单端可见；不能挂 SDK 组件 |
| 所有玩家都能看到、状态一致（道具、门、NPC） | 网络对象（方式二） | 全端同步 |
| 挂载了交互 / 拾取 / Douyin Script 的物体 | 只能网络对象 | `Instantiate` 后 SDK 网络接口、同步变量不执行 |

> ⚠️ 官方开发模式简介里明确：网络对象**不可使用** Unity 原生 `Instantiate` / `Destroy` 动态创建与销毁。

---

# 方式一：本地对象（纯模型，仅本地可见）

适合：创建角色试衣预览、本地特效、单机 UI 展示。**没有 path 加载**，只有下面两种做法。

## 1a. 场景常驻 + SetActive（最推荐，零加载零销毁）

把模型直接放在场景 `PreviewRoot` 子节点下（Male_1/2/3、Female_1/2/3），全部默认隐藏，运行时按名字切换显隐：

```lua
---@var previewRoot:UnityEngine.Transform
---@end

local function HideAll()
    for _, name in ipairs({ "Male_1", "Male_2", "Male_3", "Female_1", "Female_2", "Female_3" }) do
        local go = previewRoot:Find(name)
        if go ~= nil then go.gameObject:SetActive(false) end
    end
end

local function SwitchModel(sex, index)
    local key = sex and ("Male_" .. index) or ("Female_" .. index)
    HideAll()
    local child = previewRoot:Find(key)
    if child == nil then
        print("找不到模型：", key)
        return
    end
    child.gameObject:SetActive(true)
    print("显示：", key)
end
```

> `transform:Find` 可以找到未激活的子节点；`GameObject.Find` 只能找激活对象。

## 1b. 拖引用 + Instantiate / Destroy（本地动态生成）

预制体引用通过 `---@var` 在 Inspector 拖好，运行时生成 / 销毁：

```lua
---@var prefabMale_1:UnityEngine.GameObject
---@var prefabMale_2:UnityEngine.GameObject
---@var prefabMale_3:UnityEngine.GameObject
---@var prefabFemale_1:UnityEngine.GameObject
---@var prefabFemale_2:UnityEngine.GameObject
---@var prefabFemale_3:UnityEngine.GameObject
---@var previewRoot:UnityEngine.Transform
---@end

local prefabs = {
    male   = { prefabMale_1,   prefabMale_2,   prefabMale_3 },
    female = { prefabFemale_1, prefabFemale_2, prefabFemale_3 },
}
local currentModel = nil

local function IsValidRef(obj)
    return obj ~= nil and not obj:IsNull()
end

local function DestroyCurrent()
    if IsValidRef(currentModel) then
        UnityEngine.Object.Destroy(currentModel)
        currentModel = nil
    end
end

local function SwitchModel(sex, index)
    local prefab = prefabs[sex and "male" or "female"][index]
    if not IsValidRef(prefab) then
        print("预制体未绑定：", sex, index)
        return
    end
    DestroyCurrent()
    local model = UnityEngine.Object.Instantiate(prefab, previewRoot)
    model.transform.localPosition = UnityEngine.Vector3.zero
    currentModel = model
    print("已生成：", model.name)
end

function OnDestroy()
    DestroyCurrent()
end
```

### 方式一限制（重要）
- 预制体引用必须提前拖好，**没有“按路径加载”**
- 如果预制体挂了 Douyin Script / 交互 / 拾取 / 同步组件，`Instantiate` 生成后这些 SDK 逻辑**不会执行**

# 方式二：网络对象（NetSpawn / NetDestroy）

适合：所有玩家都能看到、或挂载了 SDK 组件的对象。这是 SDK 里**唯一能凭 key（名字）动态生成**的方式，但生成的是网络对象。

## 2.1 前置配置（必须做，否则报 no such prefab）

1. 给预制体挂 **Douyin Object Sync**（网络同步组件），让它成为网络对象
2. Assets 右键 → **Create → Douyin → Net Spawn Object Asset**，在资产里添加：
   - 主键 key（唯一，例如 `Male_1`）
   - 游戏对象：关联对应预制体
3. 把该 Asset 拖入场景 **Douyin World Root → 网络对象生成配置** 数组
4. **保存场景**；启动调试器时**勾选打包资源**（配置改动属于场景改动）

## 2.2 生成：DouyinObjectService.NetSpawn

常用重载：

```lua
-- 只给 key
DouyinObjectService.NetSpawn(key, callback)
-- 指定位置
DouyinObjectService.NetSpawn(key, position, callback)
-- 指定位置 + 旋转（Vector3 或 Quaternion）
DouyinObjectService.NetSpawn(key, position, rotation, callback)
```

完整示例（含销毁旧的、防乱序、回调）：

```lua
local modelKeys = {
    male   = { "Male_1", "Male_2", "Male_3" },
    female = { "Female_1", "Female_2", "Female_3" },
}
local currentModel = nil
local switchSeq = 0

local function DestroyCurrent()
    if currentModel ~= nil and not currentModel:IsNull() then
        DouyinObjectService.NetDestroy(currentModel)
        currentModel = nil
    end
end

local function SwitchModel(sex, index)
    local key = modelKeys[sex and "male" or "female"][index]
    if key == nil then return end

    DestroyCurrent()
    switchSeq = switchSeq + 1
    local seq = switchSeq

    local go = DouyinObjectService.NetSpawn(key, UnityEngine.Vector3(0, 0, 0), function(obj, netId)
        if seq ~= switchSeq then
            if obj ~= nil then DouyinObjectService.NetDestroy(obj) end
            return
        end
        if obj == nil then
            print("NetSpawn 失败：" .. key)
            return
        end
        currentModel = obj
        print("已生成：" .. key)
    end)

    if go == nil then
        print("NetSpawn 返回 nil，key 未注册：" .. key)
    end
end
```

## 2.3 销毁：DouyinObjectService.NetDestroy

```lua
DouyinObjectService.NetDestroy(go)   -- 只有主权方可以销毁；生成者即主权方
```

- 生成的对象**不会自动销毁**（房间网络对象），必须自己管理：**生成必销毁**
- 反复生成不销毁，会在房间里越堆越多（退出房间才清空）

## 2.4 玩家关联对象：DouyinActor.NetSpawn

如果对象要“跟着某个玩家/形象走，玩家退房自动销毁”，用 actor 的 NetSpawn：

```lua
actor:NetSpawn(key, function(go, id)
    -- 生成后处理
end)
```

这类对象随 Actor 销毁而销毁，不需要手动 NetDestroy（除非有特殊需求）。典型用途：头顶称号、血条。

## 3. 常见报错对照

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| `DouyinNetPrefabPool-Instantiate no such prefab, name : X` | key 没注册进网络对象生成配置，或 key 拼写不一致 | 按 2.1 配置，检查 key 大小写 |
| `NetSpawn Object(key) is invalid, Douyin Object Type is necessary` | 预制体没挂网络同步组件 | 给预制体挂 Douyin Object Sync |
| `资源X建议放入 assetbundle中加载,不要使用 Resource` | 预制体放在了 Resources 目录 | 移到 Assets 下普通目录 |
| NetSpawn 返回 nil | key 不存在 / 创建失败 | 检查配置与日志 |

## 4. 数量上限（心里有数）

- 房间动态网络对象：每角色最多 1000 个（`DouyinObjectService.NetSpawn`）
- 玩家关联网络对象：每玩家最多 100 个（`DouyinActor.NetSpawn`）
- 全部网络对象总量 ≤ 8000
- 销毁后 key 可复用（只统计同一时间存在的数量）
