# 内置渲染管线中的渲染路径简介

> 原文：[Introduction to rendering paths in the Built-In Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/RenderingPaths.html)

> **重要**：Built-In Render Pipeline 已弃用，并将在未来版本中废止。它在整个 Unity 6.7 LTS 生命周期内仍受支持，包括错误修复和维护。有关迁移信息，请参阅 [从 Built-In Render Pipeline 迁移到 Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrading-from-birp.html) 和 [Render pipeline feature comparison](https://docs.unity3d.com/6000.7/Documentation/Manual/render-pipelines-feature-comparison.html)。

Unity 的 Built-In Render Pipeline 支持不同的 rendering path。Rendering path 是一系列与 lighting 和 shading 相关的操作。不同 rendering path 具有不同的功能和性能特征。哪种 rendering path 最适合项目，取决于项目类型和目标硬件。

可以在 **Graphics** 窗口中选择项目使用的 rendering path，也可以为每个 **Camera** 覆盖该路径。

如果运行项目的设备上的 GPU 不支持所选 rendering path，Unity 会自动使用较低 fidelity 的 rendering path。例如，在无法处理 Deferred Shading 的 GPU 上，Unity 会使用 Forward Rendering。

- [[02-内置渲染管线中的前向渲染路径]]是 Built-In Render Pipeline 中默认的 rendering path，是一种通用 rendering path。
- [[03-内置渲染管线中的延迟渲染路径]]是 Built-In Render Pipeline 中 lighting 和 shadow fidelity 最高的 rendering path。
- [[04-内置渲染管线中的旧版顶点光照渲染路径]]的 lighting fidelity 最低，且不支持实时阴影。它是 Forward rendering path 的子集。

## Rendering Path 比较

|  | **Deferred** | **Forward** | **Vertex Lit** |
| --- | --- | --- | --- |
| **Features** |  |  |  |
| Per-pixel lighting（normal maps、light cookies） | 是 | 是 | - |
| Real-time shadows | 是 | 有限制 | - |
| Reflection Probes | 是 | 是 | - |
| Depth & Normal Buffers | 是 | Additional render passes | - |
| Soft Particles | 是 | - | - |
| Semi-transparent objects | - | 是 | 是 |
| Anti-Aliasing | - | 是 | 是 |
| Light Culling Masks | 有限 | 是 | 是 |
| Lighting Fidelity | 全部 per-pixel | 部分 per-pixel | 全部 per-vertex |
| **Performance** |  |  |  |
| Cost of a per-pixel Light | 被照亮的像素数量 | 被照亮的像素数量 × 被照亮的对象数量 | - |
| Number of times objects are normally rendered | 1 | per-pixel light 数量 | 1 |
| Overhead for simple Scenes | 高 | 无 | 无 |
| **Platform Support** |  |  |  |
| PC（Windows/Mac） | Shader Model 3.0+ 和 MRT | 全部 | 全部 |
| Mobile（iOS/Android） | OpenGL ES 3.0 和 MRT、Metal | 全部 | 全部 |
| Consoles | XB1、PS4 | 全部 | - |
