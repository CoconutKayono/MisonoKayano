# 内置渲染管线中的旧版顶点光照渲染路径

> 原文：[Legacy Vertex Lit rendering path in the Built-In Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/RenderTech-VertexLit.html)

> **重要**：Built-In Render Pipeline 已弃用，并将在未来版本中废止。它在整个 Unity 6.7 LTS 生命周期内仍受支持，包括错误修复和维护。有关迁移信息，请参阅 [从 Built-In Render Pipeline 迁移到 Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrading-from-birp.html) 和 [Render pipeline feature comparison](https://docs.unity3d.com/6000.7/Documentation/Manual/render-pipelines-feature-comparison.html)。

本页介绍 Unity Built-In Render Pipeline 中 Vertex Lit [[01-内置渲染管线中的渲染路径简介|rendering path]] 的细节。

Vertex Lit path 通常在一个 pass 中渲染每个对象，并为每个 vertex 计算所有光源的 lighting。

这是最快的 rendering path，并且具有最广泛的硬件支持。

由于所有 lighting 都在 vertex level 计算，该 rendering path 不支持大多数 per-pixel effects：不支持 shadows、normal mapping、light cookies 和高度细节化的 specular highlights。
