# 内置渲染管线中的渲染路径

> 原文：[Rendering paths in the Built-In Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/built-in-rendering-paths.html)

> **重要**：Built-In Render Pipeline 已弃用，并将在未来版本中废止。它在整个 Unity 6.7 LTS 生命周期内仍受支持，包括错误修复和维护。有关迁移信息，请参阅 [从 Built-In Render Pipeline 迁移到 Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrading-from-birp.html) 和 [Render pipeline feature comparison](https://docs.unity3d.com/6000.7/Documentation/Manual/render-pipelines-feature-comparison.html)。

用于在 Built-In Render Pipeline 中选择 Forward、Deferred 和 Legacy Vertex Lit rendering path 的资源。

| 页面 | 说明 |
| --- | --- |
| [[01-内置渲染管线中的渲染路径简介]] | 了解不同 rendering path 的功能和性能特征，以及 Forward、Deferred 和 Legacy Vertex Lit 之间的差异。 |
| [[02-内置渲染管线中的前向渲染路径]] | 了解 Forward rendering path：它根据影响 GameObject 的光源，在一个或多个 pass 中渲染每个 GameObject。 |
| [[03-内置渲染管线中的延迟渲染路径]] | 了解 Deferred rendering path：影响 GameObject 的光源数量没有限制。 |
| [[04-内置渲染管线中的旧版顶点光照渲染路径]] | 了解 Legacy Vertex Lit rendering path：它的 lighting fidelity 最低，且不支持实时阴影。 |
