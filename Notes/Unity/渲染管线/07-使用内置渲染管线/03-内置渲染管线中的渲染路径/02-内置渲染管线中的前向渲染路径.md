# 内置渲染管线中的前向渲染路径

> 原文：[Forward rendering path in the Built-In Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/RenderTech-ForwardRendering.html)

> **重要**：Built-In Render Pipeline 已弃用，并将在未来版本中废止。它在整个 Unity 6.7 LTS 生命周期内仍受支持，包括错误修复和维护。有关迁移信息，请参阅 [从 Built-In Render Pipeline 迁移到 Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrading-from-birp.html) 和 [Render pipeline feature comparison](https://docs.unity3d.com/6000.7/Documentation/Manual/render-pipelines-feature-comparison.html)。

Forward rendering path 根据影响对象的光源，在一个或多个 render pass 中渲染每个 GameObject。

Forward rendering path 也会根据光源的设置和强度，以不同方式处理光源本身。详情请参阅 [Per-pixel and per-vertex lights](https://docs.unity3d.com/6000.7/Documentation/Manual/PerPixelLights-BuiltIn.html)。

## Render pass

对于每个 GameObject，Unity 首先渲染 Base Pass，内容包括：

- 影响 GameObject 的一个 per-pixel light。
- 影响 GameObject 的所有 per-vertex 和 spherical harmonics（SH）光源。
- GameObject 的 lightmap 数据。
- Ambient lighting。
- Emissive lighting。
- Directional Light 产生的阴影。

**注意**：Lightmapped 对象不会从 SH 光源接收 lighting。

Unity 随后为影响 GameObject 的每个 per-pixel light 渲染一个 Additional Pass。Unity 不会为这些光源渲染阴影。
