# 内置渲染管线的硬件要求

> 原文：[Hardware requirements for the Built-in Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/RenderTech-HardwareRequirements.html)

**重要**：Built-In Render Pipeline 已弃用，并将在未来版本中废止。在整个 Unity 6.7 LTS 生命周期内，它仍会获得支持，包括 bug 修复和维护。有关迁移的信息，请参阅[从 Built-In Render Pipeline 迁移到 Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrading-from-birp.html)和[渲染管线功能比较](https://docs.unity3d.com/6000.7/Documentation/Manual/render-pipelines-feature-comparison.html)。

## 摘要

|  | Win/Mac/Linux | iOS/Android | Consoles |
| --- | --- | --- | --- |
| Forward rendering | Yes | Yes | Yes |
| Vertex Lit rendering | Yes | Yes | - |
| Realtime Shadows | GPU support | GPU support | Yes |
| Image Effects | Yes | Yes | Yes |
| Programmable Shaders | Yes | Yes | Yes |
| Fixed Function Shaders | Yes | Yes | - |

## 实时阴影

实时阴影适用于大多数 PC、console 和 mobile 平台。在 Windows（Direct3D）上，GPU 还需要支持 shadow mapping 功能；大多数 discrete GPU 自 2003 年起支持该功能，大多数 integrated GPU 自 2007 年起支持该功能。从技术上说，在 Direct3D 10 上，GPU 应支持 `D16/D24X8` 或 `DF16/DF24` texture format；在 OpenGL 上，GPU 应支持 `GL_ARB_depth_texture` extension。

## 后期处理效果

[Post-processing effects](https://docs.unity3d.com/6000.7/Documentation/Manual/PostProcessingOverview.html) 需要 render-to-texture 功能，该功能通常受到本千年以来生产的硬件支持。

## Shader

可以编写 programmable shader 或 fixed function shader。Programmable shader 在所有平台上都受支持，默认使用 Shader Model 2.0（desktop）和 OpenGL ES 3.0（mobile）。如果希望添加更多功能，可以定位更高版本的 shader model。Fixed function 在除 console 外的所有平台上都受支持。

**注意**：Shader Graph 在 Built-in Render Pipeline 中不支持 [XR](https://docs.unity3d.com/6000.7/Documentation/Manual/XR.html)。
