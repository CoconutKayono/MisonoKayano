# 优化渲染图

> 原文：[Optimize a render graph](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/render-graph-optimize.html)


要优化渲染图，请合并渲染通道或减少渲染通道的数量。渲染通道越多，CPU 和 GPU 需要从内存存取的数据就越多，从而降低渲染速度；在使用基于图块的延迟渲染（TBDR）的设备上尤其如此。

## 使用颜色或深度缓冲区的现有副本

如果需要颜色或深度缓冲区的副本，请尽可能避免自行复制。改用 URP 默认创建的副本，以免创建不必要的渲染通道。

使用 [ConfigureInput](https://docs.unity3d.com/Packages/com.unity.render-pipelines.universal@latest/index.html?subfolder=/api/UnityEngine.Rendering.Universal.ScriptableRenderPass.html#UnityEngine_Rendering_Universal_ScriptableRenderPass_ConfigureInput_UnityEngine_Rendering_Universal_ScriptableRenderPassInput_) API，确保 URP 在帧数据中生成所需的纹理。

要检查 URP 是否在帧中创建了可用副本，请在 [[08-在 URP 中分析渲染图]] 中查找以下通道：

- **Copy Color**：将颜色从 `_CameraTargetAttachment` 复制到 [[05-URP 中的渲染图系统中的帧数据/04-URP 的帧数据纹理参考]]中的 `cameraOpaqueTexture`。
- **Copy Depth**：将深度从 `_CameraDepthAttachment` 复制到 [[05-URP 中的渲染图系统中的帧数据/04-URP 的帧数据纹理参考]]中的 `cameraDepthTexture`。

## 合并渲染通道

使用 [[08-在 URP 中分析渲染图]] 检查 URP 无法合并渲染通道的原因，并尽可能修复问题。在使用基于图块的延迟渲染（TBDR）的设备上，合并通道有助于降低能耗并延长运行时间。

可以执行以下操作，确保 URP 合并渲染通道：

- 尽可能使用 `AddRasterRenderPass`，而不是其他类型的渲染通道。
- 如果渲染通道只需从帧缓冲区读取当前像素，而不需要读取相邻像素，请使用 `SetInputAttachment` API 和 `LOAD_FRAMEBUFFER_X_INPUT` 宏。更多信息请参阅[从 GPU 内存获取当前帧缓冲区](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/render-graph-framebuffer-fetch.html)。

## 减少渲染通道的数量

不要为了将代码组织成更小、更易管理的块而创建不必要的渲染通道。每个创建的渲染通道都会增加 CPU 处理时间。

要编写合并的渲染通道，可以使用 `AddUnsafePass` API 以及 `SetRenderTarget` 等兼容性模式 API，但由于 URP 无法优化该渲染通道，渲染速度可能会降低。更多信息请参阅 [[10-在渲染图渲染通道中使用兼容性模式 API]]。



## 避免向颜色缓冲区 Blit 以及从颜色缓冲区 Blit

为了避免创建两个从摄像机颜色纹理 Blit 以及向摄像机颜色纹理 Blit 的渲染通道，请使用 `ContextContainer` 对象直接读取和写入颜色缓冲区。

例如：

```cs
public override void RecordRenderGraph(RenderGraph renderGraph, ContextContainer frameData)
{

    // Fetch the frame data textures
    var resourceData = frameData.Get<UniversalResourceData>();

    // Set the source as the color texture the camera currently targets
    var source = resourceData.activeColorTexture;
    
    // Create a destination texture, with the same dimensions as the source
    var destinationDescriptor = renderGraph.GetTextureDesc(source);
    destinationDescriptor.name = "DestinationTexture";
    destinationDescriptor.clearBuffer = false;
    TextureHandle destination = renderGraph.CreateTexture(destinationDescriptor);

    // Use the AddBlitPass API to create a simple blit from the source to the destination
    RenderGraphUtils.BlitMaterialParameters parameters = new(source, destination, BlitMaterial, 0);
    renderGraph.AddBlitPass(parameters, passName: "MyRenderPass");

    // Set the main color texture for the camera as the destination texture
    resourceData.cameraColor = destination;
}
```
