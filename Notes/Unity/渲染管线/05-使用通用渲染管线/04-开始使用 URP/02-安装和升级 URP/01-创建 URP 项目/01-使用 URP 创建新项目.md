# 使用 URP 创建新项目

> 原文：[Create a new project that uses URP](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/creating-a-new-project-with-urp.html)

如果要从头开始一个新项目，这是最佳选择。执行此操作时，Unity 会自动安装并配置 URP。

Unity Hub 包含以下模板，可用于创建预配置的通用渲染管线 (URP) 项目。

| 模板 | 描述 |
| --- | --- |
| 通用 2D (Universal 2D) | 适用于 2D 应用程序的空项目。URP 已预配置 2D Renderer。 |
| 通用 3D (Universal 3D) | 适用于 3D 应用程序的空项目。URP 已预配置 3D Renderer。 |
| 通用 3D 示例 | 包含四个环境，展示 URP 的多样性、可扩展性和可自定义性。项目展示了不同的艺术风格、渲染路径和场景复杂度；每个场景都演示如何针对不同平台（从移动设备和无束缚设备到高端 PC 和主机）定制项目。 |

要使用 URP 模板创建新项目，请执行以下操作：

1. 打开 Unity Hub。
2. 选择**项目 (Projects)** 选项卡，然后选择**新项目 (New project)**。
3. 选择一个 URP 模板。
4. 填写**项目设置 (Project settings)** 字段并选择**创建项目 (Create project)**。Unity 会创建新的预配置 URP 项目。

使用 URP 创建的项目与高清渲染管线 (HDRP) 或内置渲染管线不兼容。在开始开发之前，必须决定在项目中使用哪个渲染管线。有关选择渲染管线的信息，请参阅 Unity Manual 的[渲染管线](https://docs.unity3d.com/6000.7/Documentation/Manual/render-pipelines.html)部分。
