# 可编程渲染管线基础知识

> 原文：[Scriptable Render Pipeline fundamentals](https://docs.unity3d.com/6000.7/Documentation/Manual/scriptable-render-pipeline-introduction.html)

本页面介绍 Unity 的可编程渲染管线（Scriptable Render Pipeline，SRP）如何工作，并介绍一些关键概念和术语。此页面中的信息适用于通用渲染管线（Universal Render Pipeline，URP）、高清渲染管线（High Definition Render Pipeline，HDRP）以及基于 SRP 的自定义渲染管线。

可编程渲染管线是一层轻量级 API，可让你使用 C# 脚本调度和配置渲染命令。Unity 会将这些命令传递给底层图形架构，底层图形架构随后向图形 API 发送指令。

URP 和 HDRP 都构建在 SRP 之上。你也可以在 SRP 之上创建自己的自定义渲染管线。

## Render Pipeline Instance 和 Render Pipeline Asset

每个基于 SRP 的渲染管线都有两个关键的可自定义元素：

- **Render Pipeline Instance**：定义渲染管线功能的类实例。其脚本继承自 [`RenderPipeline`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.RenderPipeline.html)，并重写其 `Render()` 方法。
- **Render Pipeline Asset**：Unity 项目中的一个资源，用于存储要使用的 Render Pipeline Instance，以及如何对其进行配置。其脚本继承自 [`RenderPipelineAsset`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.RenderPipelineAsset.html)，并重写其 `CreatePipeline()` 方法。

有关这些元素的更多信息，以及如何在自定义渲染管线中创建它们的说明，请参阅[创建 Render Pipeline Asset 和 Render Pipeline Instance](https://docs.unity3d.com/Packages/com.unity.render-pipelines.core@17.0/manual/index.html)。

## ScriptableRenderContext

`ScriptableRenderContext` 是一个类，充当渲染管线中的自定义 C# 代码与 Unity 底层图形代码之间的接口。

使用 [`ScriptableRenderContext`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.ScriptableRenderContext.html) API 调度和执行渲染命令。有关信息，请参阅[在可编程渲染管线中调度和执行渲染命令](https://docs.unity3d.com/Packages/com.unity.render-pipelines.core@17.0/manual/srp-using-scriptable-render-context.html)。
