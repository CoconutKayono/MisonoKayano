# 更改或检测激活的渲染管线

> 原文：[Change or detect the active render pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/srp-setting-render-pipeline-asset.html)

> **重要**：内置渲染管线已弃用，并将在未来版本中停止使用。
>
> 在整个 Unity 6.7 LTS 生命周期内，Unity 仍会支持内置渲染管线，包括错误修复和维护。
>
> 有关迁移的信息，请参阅 [[../05-使用通用渲染管线/04-开始使用 URP/02-安装和升级 URP/02-从内置渲染管线升级到 URP/00-从内置渲染管线升级到 URP]] 和 [[02-渲染管线功能比较参考]]。

本页面介绍如何获取、设置和配置 Unity 当前使用的渲染管线。Unity 当前使用的渲染管线称为激活的渲染管线。

## 概述

为了渲染内容，Unity 可以使用内置渲染管线，也可以使用基于[[../02-可编程渲染管线基础知识]]（Scriptable Render Pipeline，SRP）的渲染管线，其中包括通用渲染管线（URP）和高清渲染管线（HDRP）。

要指定 Unity 使用的 Scriptable Render Pipeline，请使用渲染管线资源（Render Pipeline Asset）。渲染管线资源会告知 Unity 要使用哪个 SRP，以及如何配置它。如果未指定渲染管线资源，Unity 会使用内置渲染管线。

可以创建多个使用相同渲染管线、但配置不同的渲染管线资源；例如，可以为不同的硬件质量级别使用不同的渲染管线资源。有关渲染管线资源的概述，请参阅[[../02-可编程渲染管线基础知识]]。有关 URP 资源的信息，请参阅[通用渲染管线资源](https://docs.unity3d.com/Packages/com.unity.render-pipelines.universal@17.0/manual/universalrp-asset.html)；有关 HDRP 资源的信息，请参阅[高清渲染管线资源](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.0/manual/HDRP-Asset.html)。

在 Unity Editor 中或运行时更改激活的渲染管线资源后，Unity 会立即使用新的激活渲染管线来渲染内容。在 Unity Editor 中，这包括 Game 视图、Scene 视图，以及 Project 面板和 Inspector 中的 Material 预览。

更改激活的渲染管线时，必须确保项目中的资源和代码与新的渲染管线兼容；否则可能遇到错误或非预期的视觉效果。

## 确定激活的渲染管线

**Graphics 设置**和**Quality 设置**中的设置共同决定激活的渲染管线。

对于 **Quality** 设置窗口中的每个质量级别，Unity 使用分配给 **Render Pipeline Asset** 的渲染管线资源。如果该属性未分配，Unity 会改用 **Graphics** 设置窗口中分配给 **Default Render Pipeline Asset** 的渲染管线资源。

如果 **Render Pipeline Asset** 和 **Default Render Pipeline** 都未设置，Unity 会使用内置渲染管线。

## 如何在 Editor UI 中设置激活的渲染管线

### 激活内置渲染管线

要将激活的渲染管线设置为内置渲染管线，请从 Graphics 设置和 Quality 设置中移除所有渲染管线资源。

操作步骤如下：

1. 选择 **Edit** > **Project Settings** > **Quality**。
2. 对于每个质量级别，如果已将渲染管线资源分配给 **Render Pipeline Asset**，请取消分配。
3. 选择 **Edit** > **Project Settings** > **Graphics**。
4. 如果已将渲染管线资源分配给 **Default Render Pipeline**，请取消分配。

### 激活基于 SRP 的 URP、HDRP 或自定义渲染管线

要将激活的渲染管线设置为基于 SRP 的渲染管线，请告知 Unity 要用作默认激活渲染管线的渲染管线资源，并可选地为每个质量级别指定要使用的渲染管线资源。

操作步骤如下：

1. 在 Project 文件夹中找到要使用的渲染管线资源。
2. 设置默认渲染管线。对于没有质量级别覆盖项的情况，Unity 会使用默认渲染管线。如果不设置默认值，且没有适用的覆盖项，Unity 会使用内置渲染管线。
   1. 选择 **Edit** > **Project Settings** > **Graphics**。
   2. 将要使用的渲染管线资源设置为 **Default Render Pipeline**。
3. **可选**：为不同质量级别设置覆盖用的渲染管线资源。
   1. 选择 **Edit** > **Project Settings** > **Quality**。
   2. 将要使用的渲染管线资源设置为 **Render Pipeline Asset**。

## 如何在 C# 脚本中获取和设置激活的渲染管线

在 C# 脚本中，可以获取和设置激活的渲染管线，并在激活的渲染管线发生变化时接收回调。你可以在 Unity Editor 的 Edit Mode 或 Play Mode 中执行这些操作，也可以在应用程序运行时执行。

要执行这些操作，请使用以下 API：

- 获取激活渲染管线的方法有多种：
  - 要获取定义激活渲染管线的渲染管线资源引用，请使用 [`GraphicsSettings.currentRenderPipeline`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.GraphicsSettings-currentRenderPipeline.html)。
  - 要获取定义激活渲染管线的渲染管线资源引用，并确定 Unity 使用的是默认值还是覆盖值，请获取 [`GraphicsSettings.defaultRenderPipeline`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.GraphicsSettings-defaultRenderPipeline.html) 和 [`QualitySettings.renderPipeline`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/QualitySettings-renderPipeline.html) 的值。有关如何使用这些值的信息，请参阅上面的“确定激活的渲染管线”或下面的代码示例。
  - 要获取激活渲染管线的 [`RenderPipeline`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.RenderPipeline.html) 实例，请使用 [`RenderPipelineManager.currentPipeline`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.RenderPipelineManager-currentPipeline.html)。**注意**：Unity 只有在使用激活渲染管线渲染至少一帧后，才会更新此属性。
- 要设置激活的渲染管线，请设置 [`GraphicsSettings.defaultRenderPipeline`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.GraphicsSettings-defaultRenderPipeline.html) 和 [`QualitySettings.renderPipeline`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/QualitySettings-renderPipeline.html) 的值。有关如何使用这些值的信息，请参阅上面的“确定激活的渲染管线”或下面的代码示例。
- 要在激活渲染管线的类型发生变化时检测变化并执行代码，请使用 [`RenderPipelineManager.activeRenderPipelineTypeChanged`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.RenderPipelineManager-activeRenderPipelineTypeChanged.html)。

以下示例代码展示了如何使用这些 API：

```csharp
using UnityEngine;
using UnityEngine.Rendering;

public class ActiveRenderPipelineExample : MonoBehaviour
{
    // In the Inspector, assign a render pipeline asset to each of these fields
    public RenderPipelineAsset defaultRenderPipelineAsset;
    public RenderPipelineAsset overrideRenderPipelineAsset;

    void Start()
    {
        GraphicsSettings.defaultRenderPipeline = defaultRenderPipelineAsset;
        QualitySettings.renderPipeline = overrideRenderPipelineAsset;

        DisplayCurrentRenderPipeline();
    }

    void Update()
    {
        // When the user presses the left shift key, switch the default render pipeline
        if (Input.GetKeyDown(KeyCode.LeftShift)) {
            SwitchDefaultRenderPipeline();
            DisplayCurrentRenderPipeline();
        }
        // When the user presses the right shift key, switch the override render pipeline
        else if (Input.GetKeyDown(KeyCode.RightShift)) {
            SwitchOverrideRenderPipeline();
            DisplayCurrentRenderPipeline();
        }
    }

    // Switch the default render pipeline between null,
    // and the render pipeline defined in defaultRenderPipelineAsset
    void SwitchDefaultRenderPipeline()
    {
        if (GraphicsSettings.defaultRenderPipeline == defaultRenderPipelineAsset)
        {
            GraphicsSettings.defaultRenderPipeline = null;
        }
        else
        {
            GraphicsSettings.defaultRenderPipeline = defaultRenderPipelineAsset;
        }
    }

    // Switch the override render pipeline between null,
    // and the render pipeline defined in overrideRenderPipelineAsset
    void SwitchOverrideRenderPipeline()
    {
        if (QualitySettings.renderPipeline == overrideRenderPipelineAsset)
        {
            QualitySettings.renderPipeline = null;
        }
        else
        {
           QualitySettings.renderPipeline = overrideRenderPipelineAsset;
        }
    }

    // Print the current render pipeline information to the console
    void DisplayCurrentRenderPipeline()
    {
        // GraphicsSettings.defaultRenderPipeline determines the default render pipeline
        // If it is null, the default is the Built-in Render Pipeline
        if (GraphicsSettings.defaultRenderPipeline != null)
        {
            Debug.Log("The default render pipeline is defined by " + GraphicsSettings.defaultRenderPipeline.name);
        }
        else
        {
            Debug.Log("The default render pipeline is the Built-in Render Pipeline");
        }

        // QualitySettings.renderPipeline determines the override render pipeline for the current quality level
        // If it is null, no override exists for the current quality level
        if (QualitySettings.renderPipeline != null)
        {
            Debug.Log("The override render pipeline for the current quality level is defined by " + QualitySettings.renderPipeline.name);
        }
        else
        {
            Debug.Log("No override render pipeline exists for the current quality level");
        }

        // If an override render pipeline is defined, Unity uses that
        // Otherwise, it falls back to the default value
        if (QualitySettings.renderPipeline != null)
        {
            Debug.Log("The active render pipeline is the override render pipeline");
        }
        else
        {
            Debug.Log("The active render pipeline is the default render pipeline");
        }

        // To get a reference to the render pipeline asset that defines the active render pipeline,
        // without knowing if it is the default or an override, use GraphicsSettings.currentRenderPipeline
        if (GraphicsSettings.currentRenderPipeline != null)
        {
            Debug.Log("The active render pipeline is defined by " +GraphicsSettings.currentRenderPipeline.name);
        }
        else
        {
            Debug.Log("The active render pipeline is the Built-in Render Pipeline");
        }
    }
}
```
