# 使用脚本创建组件

> 原文：[Create components with scripts](https://docs.unity3d.com/6000.7/Documentation/Manual/CreatingComponents.html)

Component 可以为 GameObject 增加功能。要在 Editor 中自定义和扩展 Component，可以编写自己的脚本。

要通过脚本创建 Component，需要编写脚本，然后将脚本附加到 GameObject。附加到 GameObject 的脚本会显示在该 GameObject 的 Inspector 窗口中，因为 Editor 会将脚本视为内置 Component。

有关如何创建脚本的信息，请参阅[创建和使用脚本](../../01-开始使用Unity编程/02-创建脚本.md)。
