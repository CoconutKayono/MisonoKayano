# 约束组件

> 原文：[Constraint components](https://docs.unity3d.com/6000.7/Documentation/Manual/constraint-components.html)

Constraint Component 可以让一个 GameObject 的位置、旋转或缩放受其他 GameObject 控制。它们适合制作摄像机跟随、武器挂点、动画辅助和对象之间的相对关系。

常见 Constraint 包括：

- `Position Constraint`
- `Rotation Constraint`
- `Scale Constraint`
- `Aim Constraint`
- `Parent Constraint`

通常需要设置 Source Transform、约束权重和轴向限制。Constraint 的执行顺序会影响最终结果，复杂层级中应避免循环依赖。
