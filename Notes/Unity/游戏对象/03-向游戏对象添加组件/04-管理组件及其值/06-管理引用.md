# 管理引用

> 原文：[Manage references](https://docs.unity3d.com/6000.7/Documentation/Manual/InspectorReferences.html)

Reference 是一种以 GameObject、Component 或 Asset 作为输入的属性。

例如，在 3D GameObject 上：

- [Mesh Filter](https://docs.unity3d.com/6000.7/Documentation/Manual/class-MeshFilter.html) Component 从项目资源中获取 Mesh，并将其传递给 Mesh Renderer，以便在屏幕上渲染。Mesh 为 GameObject 提供形状。
- Mesh Renderer Component 引用一个 Material。

Component 可能具有默认 Reference，也可能需要手动添加 Reference。例如：

- 创建新的 3D Cube GameObject 时，其 Mesh Filter 和 Mesh Renderer Component 默认引用 Cube Mesh 和项目的默认 Material。你可以替换这些 Reference，但不是必须替换。
- 创建空的 GameObject 并添加 Mesh Filter 和 Mesh Renderer Component 时，它们不会引用默认 Mesh 或 Material。你必须手动添加这些 Reference。

## 分配引用

要为属性分配 Reference，可以在 Inspector 窗口的属性字段中执行以下任一操作：

- 从 Hierarchy 或 Project 窗口将兼容的项目拖入字段。
- 选择 **Object Picker**（⊙）打开属性字段的搜索窗口。该搜索窗口会筛选出与属性类型匹配的 Reference。

Reference 搜索窗口有两种类型：经典搜索窗口和 Advanced Object Picker。Advanced Object Picker 显示内置筛选器，因此你可以覆盖默认筛选条件；经典搜索窗口不支持覆盖筛选条件。有关 Advanced Object Picker 以及如何启用或禁用它的更多信息，请参阅 [Search Object Picker](https://docs.unity3d.com/6000.7/Documentation/Manual/search-advanced-object-picker.html)。

## 依赖 Component 的引用

可以将 GameObject 分配给期望 Component Reference 的属性字段。分配 GameObject 后，Unity 会使用该 GameObject 上第一个符合要求类型的 Component。在 Inspector 窗口中，列表最上方的 Component 就是第一个 Component。

如果 GameObject 不包含正确的 Component 类型，则无法将该 GameObject 分配为 Reference。例如，如果 Reference 字段要求 Sphere Collider，而你尝试分配一个只包含 Box Collider 的 GameObject，Unity Editor 不会接受该分配。
