# 使用曲线

> 原文：[Use curves](https://docs.unity3d.com/6000.7/Documentation/Manual/InspectorCurves.html)

Curve 是一种线图：当输入发生变化时，使用 X 轴表示输入值，并使用 Y 轴表示响应值。Unity Editor 在许多 Component 中使用 Curve。有关使用 Curve 的更多信息，请参阅 [编辑 Animation Curve](https://docs.unity3d.com/6000.7/Documentation/Manual/EditingCurves.html)。

## 保存 Curve Preset 并创建 Library

可以将当前 Curve 保存为 Preset，并将 Preset 组织到 Library 中。

### 保存 Curve Preset

要将当前 Curve 保存为 Preset：

1. 在 **Curve Editor** 中单击 **Settings** 按钮，打开 **Presets** 面板。
2. 列表中的最后一条 Curve 代表当前编辑结果。单击它，将 Curve 保存为 Preset。

### 删除或替换 Curve Preset

要删除 Preset，请在 **Presets** 面板中右键单击该 Preset，然后选择 **Delete**。

要替换 Preset，请在 **Presets** 面板中右键单击该 Preset，然后选择 **Replace**。此操作会将当前 Curve 保存到该 Preset。

### 创建和管理 Curve Library

可以将 Curve Preset 保存到一个或多个 Library，并在自定义 Library 与默认 Library 之间切换。使用 **More**（⋮）菜单创建 Library，或在不同 Library 之间切换。

> **提示：** 要将内置 Curve 添加到 Library，请在 **Presets** 面板的 **More**（⋮）菜单中选择 **Add Factory Presets To Current Library**。
