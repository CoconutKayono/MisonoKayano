# Layer 的用途

> 原文：[Uses of layers in Unity](https://docs.unity3d.com/6000.7/Documentation/Manual/use-layers.html)

你可以使用 Layer 优化项目和工作流。Layer 的常见用途包括基于 Layer 的渲染和基于 Layer 的碰撞。

## 使用 Camera Culling Mask 和 Layer

使用 Camera 的 Culling Mask 时，可以只渲染特定 Layer 或多个选定 Layer 中的对象。要更改 Culling Mask，请选择要使用的 Camera，然后在 Inspector 窗口中选择 **Culling Mask** 下拉菜单。如果取消勾选某个 Layer，它就不会在 Scene 中渲染。

> **注意：** UI 元素和 Screen Space Canvas 的子对象是例外，它们无论 Layer 设置如何都会渲染。

## 使用 Layer 进行 Raycast

可以使用 Layer 指定 Raycast 能够相交的 GameObject。要让 Raycast 忽略某个 GameObject，可以将它分配到 **Ignore Raycast** Layer，或将 `LayerMask` 传递给 Raycast API 调用。

如果没有将 `LayerMask` 传递给 Raycast API 调用，Unity 会使用 `Physics.DefaultRaycastLayers`，它会匹配除 **Ignore Raycast** 之外的每个 Layer。

`Physics.Raycast` 函数使用 bitmask，每一位决定 Raycast 是否忽略对应的 Layer。如果 `layerMask` 的所有位都开启，Raycast 会与所有 Collider 发生碰撞；如果 `layerMask = 0`，则不会发生碰撞。

例如，如果希望对 Layer 8 发射 Raycast：

```csharp
int layerMask = 1 << 8;

// Ray 是否与处于 Layer 8 的对象相交？
if (Physics.Raycast(transform.position, Vector3.forward, Mathf.Infinity, layerMask))
{
    Debug.Log("Ray 命中了玩家");
}
```

也可以执行反向操作，使 Raycast 与除 Layer 8 以外的所有 Layer 发生碰撞：

```csharp
void Update ()
{
    // 对 Layer 8 的索引执行位移，以获取 bitmask
    int layerMask = 1 << 8;

    // 此 Raycast 只检测 Layer 8 中的 Collider。
    // 要与除 Layer 8 以外的所有对象碰撞，请使用 ~ 运算符，因为它会反转 bitmask。
    layerMask = ~layerMask;

    RaycastHit hit;

    // Ray 是否与排除 Layer 8 的对象相交？
    if (Physics.Raycast(transform.position, transform.TransformDirection (Vector3.forward), out hit, Mathf.Infinity, layerMask))
    {
        Debug.DrawRay(transform.position, transform.TransformDirection (Vector3.forward) * hit.distance, Color.yellow);
        Debug.Log("命中");
    }
    else
    {
        Debug.DrawRay(transform.position, transform.TransformDirection (Vector3.forward) * 1000, Color.white);
        Debug.Log("未命中");
    }
}
```

> **注意：** 如果没有将 `layerMask` 传递给 Raycast 函数，它仍然会忽略使用 **Ignore Raycast** Layer 的 Collider。
