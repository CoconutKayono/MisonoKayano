# 创建功能 Layer

> 原文：[Create functional layers in Unity](https://docs.unity3d.com/6000.7/Documentation/Manual/create-layers.html)

Layer 可以帮助你组织 Scene 中的 GameObject。创建 Layer 并将 GameObject 分配到该 Layer 后，可以根据 Layer 编辑 GameObject 与其他 GameObject 的交互方式。

## 添加新 Layer

可以通过以下两种方式创建新 Layer：

1. 打开 **Tags and Layers** 窗口：从主菜单中选择 **Edit > Project Settings > Tags and Layers > Layers**。
2. 选择 GameObject，在 Inspector 窗口中选择 **Layer** 下拉菜单，然后从菜单中选择 **Add Layer**。

为 Layer 起一个描述性名称，以便记住该 Layer 的预期用途。

> **警告：** Layer 31 由 Editor 的 Preview 窗口机制在内部使用。为避免冲突，请不要使用此 Layer。

## 内置 Layer

打开 Layer 菜单时，可以看到一些已经命名的 Layer。除了 **Default** 和 **Ignore Raycast** 之外，Unity 不再将这些内置 Layer 用于许多专门用途；它们主要是为了向后兼容而保留的：

| Layer 编号 | Layer 名称 | 说明 |
| --- | --- | --- |
| 0 | **Default** | 所有 Scene 元素的默认 Layer。 |
| 1 | **TransparentFX** | Unity 在 Flare System 中使用此 Layer。 |
| 2 | **Ignore Raycast** | Physics Raycast API 默认忽略此 Layer。 |
| 4 | **Water** | Unity 2018.4 的 Standard Assets 使用此 Layer。 |
| 5 | **UI** | Unity UI 将此 Layer 用作 UI 元素的默认 Layer。 |

仍然可以使用这些 Layer，但不能重命名或删除它们。

## 将 GameObject 添加到 Layer

要将 GameObject 分配到 Layer，请选择 GameObject，在 Inspector 窗口中选择 **Layer** 旁边的下拉菜单。此菜单显示已命名的 Layer，你可以选择最适合该 GameObject 的 Layer。

每个 GameObject 只能分配到一个 Layer，但一个 Layer 可以包含多个 GameObject。
