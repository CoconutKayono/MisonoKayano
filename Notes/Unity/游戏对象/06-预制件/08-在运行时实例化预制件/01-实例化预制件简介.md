# 实例化预制件简介

> 原文：[Introduction to instantiating prefabs](https://docs.unity3d.com/6000.7/Documentation/Manual/instantiating-prefabs-intro.html)

可以在运行时使用 [Prefab](https://docs.unity3d.com/6000.7/Documentation/Manual/prefabs-introduction.html) 实例化复杂的 GameObject 或 GameObject 集合。与使用代码从头创建 GameObject 相比，使用代码实例化 Prefab 有许多优势：

- 只需一行代码即可实例化 Prefab。从头创建等效的 GameObject 需要更多代码。
- 无需修改代码即可更换要实例化的 Prefab。例如，可以将普通火箭简单替换为超强火箭，而不需要进行任何代码修改。

## 常见场景

在运行时实例化 Prefab 适用于以下常见场景：

- 通过在不同位置多次复制单个 Prefab 来构建结构，例如网格或圆形排列。
- 从发射器发射投射物 Prefab。投射物 Prefab 可以是复杂配置，包含 Mesh、Rigidbody、Collider、Audio Source、动态 Light，以及一个带有独立 Trail Particle System 的子 GameObject。
- 车辆、建筑物或角色（例如机器人）解体成多个部件。在这种场景中，示例脚本会删除完整的可运行机器人 Prefab，并将其替换为损坏的机器人 Prefab。损坏的 Prefab 由机器人的独立破损部件组成，每个部件都配置了自己的 Rigidbody Component 和 Particle System。

这种技术只需一行代码，就能将机器人炸成多个部件：用损坏的 Prefab 替换原始 GameObject。

## 实例化 Prefab

要在运行时实例化 Prefab，代码需要引用该 Prefab。可以在代码中创建一个 `GameObject` 类型的 public 字段，然后在 Inspector 中将要使用的 Prefab 分配给该字段。

下面的脚本示例只有一个 public 变量 `myPrefab`，它引用一个 Prefab。脚本会在 `Start` 方法中创建该 Prefab 的实例。

```csharp
using UnityEngine;
public class InstantiationExample : MonoBehaviour
{
    // Prefab 的引用。将 Prefab 拖到 Inspector 中的此字段。
    public GameObject myPrefab;

    // 游戏开始时实例化 Prefab。
    void Start()
    {
        // 在位置 (0, 0, 0) 且无旋转的位置实例化。
        Instantiate(myPrefab, new Vector3(0, 0, 0), Quaternion.identity);
    }
}
```

使用此示例：

1. 在 Project 中创建一个新的 MonoBehaviour 脚本，并将其命名为 `InstantiationExample`。
2. 复制代码，将其粘贴到新脚本中，然后保存脚本。
3. 使用 **GameObject > Create Empty** 菜单创建一个空 GameObject。
4. 将脚本拖到新的 GameObject 上，把脚本作为 Component 添加到该 GameObject。
5. [创建任意 Prefab](https://docs.unity3d.com/6000.7/Documentation/Manual/CreatingPrefabs.html)，然后将它从 **Project** 窗口拖到脚本 Component 中的 **My Prefab** 字段。

进入 Play Mode 后，Prefab 会在 Scene 中的位置 `(0, 0, 0)` 实例化。

可以将不同的 Prefab 拖到 Inspector 窗口的 **My Prefab** 字段中，从而更改 Unity 实例化的 Prefab，而无需修改脚本。
