# ECS 创作与烘焙工作流（ECS authoring and baking workflow）

> 来源：[Unity Package 官方文档 · Authoring and baking workflow](https://docs.unity3d.com/Packages/com.unity.entities@6.6/manual/ecs-workflow-example-authoring-baking.html)

本节提供实体组件系统（ECS）中创作（authoring）与烘焙（baking）工作流的示例。

ECS 中的创作与烘焙工作流，将基于 GameObject 的编辑器体验与 ECS 的高性能运行时架构连接起来。在创作阶段，你可以在 Unity 编辑器中使用常规的 GameObject 和 MonoBehaviour 组件；烘焙过程会将这些 GameObject 转换为优化的 ECS 实体和组件。该工作流将内容创作体验与运行时性能关注点分离开来。

本节的每个主题都是工作流中的一个步骤，且依赖前面的步骤才能工作。如果你正在编辑器中跟着操作，请按顺序执行以下步骤：

- 为示例创建子场景
- 从 GameObject 创建实体
- 创建新的 ECS 组件
- 向实体添加新组件
- 创建旋转实体的系统

## 前提条件

本工作流需要一个已安装以下包的 Unity 6 项目：

- Entities
- Entities Graphics

## 为示例创建子场景

实体组件系统（ECS）工作流的第一步是创建子场景（subscene）。ECS 使用子场景而不是场景来管理应用内容，因为 Unity 的核心场景系统与 ECS 不兼容。

要在 Unity 中创建子场景：

1. 在编辑器中打开一个现有场景。
2. 在 Hierarchy 中右键单击，选择 **New Sub Scene > Empty Scene**。
3. 在出现的提示中输入新子场景的名称并保存。Unity 会将子场景添加到打开的场景中，现在你可以使用它了。

## 从 GameObject 创建实体

在这一步中，你创建一个示例 GameObject，并了解 ECS 框架如何自动将子场景中的 GameObject 转换为实体。ECS 将 GameObject 转换为实体的过程称为烘焙（baking）。

要从 GameObject 创建实体：

1. 在 Hierarchy 窗口中选择一个子场景。
2. 创建一个名为 Cube 的立方体 GameObject（菜单路径：**GameObject > 3D Object > Cube**）。
3. ECS 会自动将新的立方体 GameObject 转换为实体。

当你在子场景中创建 GameObject 时，ECS 会在烘焙过程中自动将其转换为实体。

4. 选择 Cube GameObject。Inspector 窗口会显示 **Entity Baking Preview**（实体烘焙预览）部分。该部分包含 ECS 从原始 GameObject 转换而来的实体组件。

> 图片说明：Inspector 窗口显示 Entity Baking Preview 部分，其中选中了 Unity.Transforms.LocalToWorld。

例如，`Unity.Transforms.LocalToWorld` 组件包含渲染系统用来绘制实体的变换矩阵。对于 Cube 实体，ECS 使用 Cube GameObject 的 Transform 组件中的信息创建该组件。更多信息，请参阅「实体中的变换」（Transforms in Entities）。

## 创建新的 ECS 组件

在 ECS 中，组件存储系统可以读取或写入的实体数据。

在本示例中，一个 ECS 组件包含立方体的旋转速度。

ECS 有多个组件类型，本示例使用最常见的一种：基于 `IComponentData` 接口的组件：

1. 创建一个名为 `RotationSpeed.cs` 的新 C# 脚本，并将文件内容替换为以下代码示例。

```csharp
using Unity.Entities;

// This component defines the rotation speed of an entity.
public struct RotationSpeed : IComponentData
{
    public float RadiansPerSecond;
}
```

现在项目有了一个可以添加到实体上的组件。

与 GameObject 工作流不同，你不能将 ECS 组件拖放到实体上。

在 ECS 中有两种向实体添加组件的方式：

- 使用烘焙过程：Unity 在将 GameObject 转换为实体时添加实体组件。
- 在运行时使用 `AddComponent` API。

下一步演示前一种添加组件的方式。

## 向实体添加新组件

此步骤演示如何使用烘焙过程向实体添加组件。在烘焙过程中，ECS 会获取 GameObject 的常规 MonoBehaviour 组件，并将其转换为实体组件。

你为将数据转换为实体组件而创建的 MonoBehaviour 组件称为创作组件（authoring component）。创作与烘焙过程提供了一种使用编辑器界面定义和编辑 GameObject 属性，并将其转换为相应 ECS 运行时组件的方法。

有关不通过创作与烘焙过程向实体添加组件的信息，请参阅「向实体添加组件」（Add components to an entity）一节。

### 创建创作组件

创作组件是一种 MonoBehaviour 组件，提供了一种将编辑器中 GameObject 字段的数据传入 ECS 组件的方法。

要创建创作组件：

1. 创建一个名为 `RotationSpeedAuthoring.cs` 的新 C# 脚本，并将文件内容替换为以下代码。

```csharp
using Unity.Entities;
using Unity.Mathematics;
using UnityEngine;

// The authoring component provides a way to define the rotation speed of
// a GameObject in the Editor. ECS does not use the authoring component at 
// runtime, but converts it into an entity component using the Baker class.    
public class RotationSpeedAuthoring : MonoBehaviour
{
    public float DegreesPerSecond = 360.0f;
}
```

2. 将该脚本添加到 Cube GameObject 上。

### 检查 GameObject 及其对应的实体

为了更好地理解 GameObject 与实体概念之间的差异，请检查子场景中的 Cube 和 Editor World 中的 Cube 实体：

> 图片说明：子场景中的 Cube GameObject 与 Editor World 中的 Cube 实体。

1. 在 Hierarchy 中选择 Cube GameObject。Inspector 会显示创作数据，包括 Rotation Speed Authoring 组件中的 Degrees Per Second 属性（由 `RotationSpeedAuthoring` 类定义）。
2. 要检查实体数据，请在 Hierarchy 的 Editor World 节点下选择对应的实体。Entity Inspector 会显示实体的运行时组件。此时，实体视图中不包含 Degrees Per Second 属性或 Rotation Speed 组件。这是因为还没有一个烘焙器（baker）将创作组件转换为实体组件。

下一步是创建一个烘焙器类，将 MonoBehaviour 组件转换为实体组件。

### 创建烘焙器类

在 ECS 中，`Baker` 类定义了将 GameObject 数据转换为实体数据的逻辑。

将烘焙器类添加到创作组件：

1. 在 `RotationSpeedAuthoring.cs` 脚本中，将文件内容替换为以下代码，其中添加了 `RotationSpeedBaker` 类定义：

```csharp
using Unity.Entities;
using Unity.Mathematics;
using UnityEngine;

// The authoring component provides a way to define the rotation speed of
// a GameObject in the Editor. ECS does not use the authoring component at 
// runtime, but converts it into an entity component using the Baker class.    
public class RotationSpeedAuthoring : MonoBehaviour
{
    public float DegreesPerSecond = 360.0f;
}

// In the baking process, this Baker runs once for every RotationSpeedAuthoring
// instance in a subscene.
class RotationSpeedBaker : Baker<RotationSpeedAuthoring>
{
    public override void Bake(RotationSpeedAuthoring authoring)
    {
        // GetEntity returns an entity that ECS creates from the GameObject using
        // pre-built ECS baker methods. TransformUsageFlags.Dynamic instructs the
        // Bake method to add the Transforms.LocalTransform component to the entity.
        var entity = GetEntity(authoring, TransformUsageFlags.Dynamic);

        var rotationSpeed = new RotationSpeed
        {
            // The math class is from the Unity.Mathematics namespace.
            // Unity.Mathematics is optimized for Burst-compiled code.
            RadiansPerSecond = math.radians(authoring.DegreesPerSecond)
        };

        AddComponent(entity, rotationSpeed);
    }
}
```

该类有以下主要功能：

- `Bake` 方法将 `RotationSpeedAuthoring` 实例作为参数。该参数引用 GameObject 上的创作组件。这是你定义自定义逻辑、将 GameObject 数据转换为 ECS 数据的地方。
- `GetEntity` 方法返回一个 ECS 使用预构建的 ECS 烘焙器方法从 GameObject 创建的实体。

```csharp
var entity = GetEntity(authoring, TransformUsageFlags.Dynamic);
```

参数 `TransformUsageFlags.Dynamic` 指示 `Bake` 方法向实体添加 `Transforms.LocalTransform` 组件。本示例在下一步中使用 `LocalTransform` 组件旋转立方体。更多信息，请参阅「变换使用标志」（Transform usage flags）。

以下代码行创建了一个新的 RotationSpeed 组件实例，并由 `AddComponent` 方法将该组件添加到实体上：

```csharp
var rotationSpeed = new RotationSpeed
{
    RadiansPerSecond = math.radians(authoring.DegreesPerSecond)
};

AddComponent(entity, rotationSpeed);
```

新的 RotationSpeed 组件是一个 ECS 组件，它使用了 MonoBehaviour 创作组件中的数据。

2. 保存脚本，并在 Hierarchy 的 World 节点下选择 Cube 实体，在 Entity Inspector 中查看它。现在实体具有 Rotation Speed 组件，包含 Radians Per Second 属性。

> 图片说明：Editor World 节点下带有 Rotation Speed 组件的立方体。

组件中的属性名称和单位与 MonoBehaviour 创作组件不同——创作组件中的名称是 Degrees Per Second，单位是度。这体现了一种常见做法：在将数据从 GameObject 转换为实体时，你可以进行额外的处理。

现在你有了以下设置：

- 一个带有 Rotation Speed Authoring 组件（Degrees Per Second 属性）的 GameObject，你可以从编辑器编辑它。
- 一个带有 Rotation Speed 组件（Radians Per Second 属性）的实体，ECS 框架会根据 GameObject 的更改动态更新它。

下一步演示如何创建旋转立方体实体的系统。

## 创建旋转实体的系统

此任务描述如何创建旋转实体的 ECS 系统。

与 GameObject 工作流不同，在 ECS 中你不会将脚本直接分配到特定实体。相反，系统会在世界中查询满足特定条件的实体，然后对所有这些实体执行操作。

### 创建旋转系统

要创建旋转系统：

1. 创建一个名为 `RotationSystem.cs` 的新 C# 脚本，并将文件内容替换为以下代码：

```csharp
using Unity.Burst;
using Unity.Entities;
using Unity.Transforms;

// This example defines an unmanaged system based on the ISystem interface.
// ECS uses code generation, which is why the struct must be declared as partial.
public partial struct RotationSystem : ISystem
{
    // The BurstCompile attribute indicates that the method should be compiled
    // with the Burst compiler into highly-optimized native CPU code.
    [BurstCompile]
    public void OnUpdate(ref SystemState state)
    {
        // In ECS, use the DeltaTime property from Entities.SystemAPI.Time.
        float deltaTime = SystemAPI.Time.DeltaTime;

        // Create a query that selects all entities that have a LocalTransform
        // component and a RotationSpeed component.
        // In each loop iteration, the transform variable is assigned 
        // a read-write reference to LocalTransform, and the speed variable is
        // assigned a read-only reference to the RotationSpeed component.
        foreach (var (transform, speed) in
                    SystemAPI.Query<RefRW<LocalTransform>, RefRO<RotationSpeed>>())
        {
            // ValueRW and ValueRO both return a reference to the actual component
            // value. The difference is that ValueRW does a safety check for 
            // read-write access while ValueRO does a safety check for read-only
            // access.
            transform.ValueRW = transform.ValueRO.RotateY(
                speed.ValueRO.RadiansPerSecond * deltaTime);
        }
    }
}
```

2. 进入 Play 模式。立方体应该在 Game 视图和 Scene 视图中旋转。

进入 Play 模式时，ECS 会自动实例化基于 `ISystem` 接口的系统。

要影响实体，系统在 `OnUpdate` 方法中实现一个查询。在每一帧中，系统选择所有同时具有 `LocalTransform` 和 `RotationSpeed` 组件的实体，并在它们上执行 foreach 循环中定义的代码。

系统中的以下代码绕 Y 轴旋转实体：

```csharp
transform.ValueRW = transform.ValueRO.RotateY(speed.ValueRO.RadiansPerSecond * deltaTime);
```

`ValueRW` 和 `ValueRO` 方法是特殊的 ECS 方法，它们返回组件的引用，并对读写（`ValueRW`）或只读（`ValueRO`）访问执行安全检查。

有关变换操作的更多信息，请参阅「变换操作」（Transform operations）一节。

`[BurstCompile]` 属性表示应使用 Burst 编译器将该方法编译为高度优化的原生 CPU 代码。更多信息，请参阅 Burst 编译器文档。

要实际查看查询功能：

1. 在子场景中再创建几个立方体 GameObject。
2. 为其中一些立方体（但不是全部）添加 Rotation Speed Authoring 组件。
3. 在带有 Rotation Speed Authoring 组件的立方体上，更改 Degrees Per Second 值。
4. 进入 Play 模式。
5. 只有带有 Rotation Speed Authoring 组件的立方体才会旋转。立方体按 Degrees Per Second 属性定义的速度旋转。
