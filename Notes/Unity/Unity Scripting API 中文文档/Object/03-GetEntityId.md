# Object.GetEntityId

```csharp
public EntityId GetEntityId();
```

## 返回值

`EntityId`：对象的 `EntityId`。

## 描述

获取对象的 `EntityId`。对象的 `EntityId` 类似于内存实例的句柄，始终唯一；对于有效对象，它永远不会是 `EntityId.None`。
