# [GameObject](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/GameObject.html).IsDestroying

## 声明

~~~csharp
public bool IsDestroying();
~~~

## 返回值

如果 GameObject 及其后代对象当前正在销毁过程中，则返回 true，否则返回 false。

## 描述

检查 GameObject 及其后代对象当前是否正在销毁过程中。
