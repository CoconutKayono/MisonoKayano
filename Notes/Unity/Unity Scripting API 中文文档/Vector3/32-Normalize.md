# [Vector3](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector3.html).Normalize

## 声明

~~~csharp
public void Normalize();
~~~

## 参数

| 参数 | 描述 |
| --- | --- |
| value | 要归一化的向量。 |

## 返回

Vector3 A new vector with the same direction as the original vector but with a magnitude of 1.0.

## 描述

在保持方向的同时将当前向量长度归一化为 1。
