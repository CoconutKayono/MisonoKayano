# [Vector2Int](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector2Int.html).Max

## 声明

~~~csharp
public static Vector2Int Max(Vector2Int lhs, Vector2Int rhs);
~~~

## 参数

| 参数 | 描述 |
| --- | --- |
| lhs | 要比较的第一个向量。 |
| rhs | 要比较的第二个向量。 |

## 返回

Vector2Int A vector that is made from the largest components of two vectors.

## 描述

返回由两个向量较大分量组成的向量。
