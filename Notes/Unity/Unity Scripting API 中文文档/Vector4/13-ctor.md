# [Vector4](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector4.html) 构造函数

## 声明

~~~csharp
public Vector4(float x, float y, float z, float w);
~~~

## 参数

| 参数 | 描述 |
| --- | --- |
| x | x 分量的值。 |
| y | y 分量的值。 |
| z | z 分量的值。 |
| w | w 分量的值。 |

## 描述

使用给定的 x、y、z、w 分量创建新向量。

## 声明

~~~csharp
public Vector4(float x, float y, float z);
~~~

## 参数

| 参数 | 描述 |
| --- | --- |
| x | x 分量的值。 |
| y | y 分量的值。 |
| z | z 分量的值。 |

## 描述

使用给定的 x、y、z 分量创建新向量，并将 w 设置为零。

## 声明

~~~csharp
public Vector4(float x, float y);
~~~

## 参数

| 参数 | 描述 |
| --- | --- |
| x | x 分量的值。 |
| y | y 分量的值。 |

## 描述

使用给定的 x、y 分量创建新向量，并将 z 和 w 设置为零。
