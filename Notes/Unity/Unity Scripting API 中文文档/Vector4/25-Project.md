# [Vector4](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector4.html).Project

## 声明

~~~csharp
public static Vector4 Project(Vector4 a, Vector4 b);
~~~

## 参数

| 参数 | 描述 |
| --- | --- |
| a | 要投影的向量。 |
| b | 要投影到的向量。 |

## 返回

`Vector4`：a 在 b 上的投影。

## 描述

将一个向量投影到另一个向量上。
