# [Vector4](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector4.html).Distance

## 声明

~~~csharp
public static float Distance(Vector4 a, Vector4 b);
~~~

## 描述

返回 a 和 b 之间的距离。

`Vector4.Distance(a,b)` 与 `(a-b).magnitude` 相同。
