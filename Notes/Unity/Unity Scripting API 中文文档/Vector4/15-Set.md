# [Vector4](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector4.html).Set

## 声明

~~~csharp
public void Set(float newX, float newY, float newZ, float newW);
~~~

## 参数

| 参数 | 描述 |
| --- | --- |
| newX | 新的 x 分量。 |
| newY | 新的 y 分量。 |
| newZ | 新的 z 分量。 |
| newW | 新的 w 分量。 |

## 描述

设置现有 Vector4 的 x、y、z 和 w 分量。
