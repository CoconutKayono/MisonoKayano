# [Vector3Int](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector3Int.html).Scale

## 声明

~~~csharp
public static Vector3Int Scale(Vector3Int a, Vector3Int b);
~~~

## 参数

| 参数 | 描述 |
| --- | --- |
| a | 要与 b 相乘的向量。 |
| b | 要与 a 相乘的向量。 |

## 返回

Vector3Int：a 的每个分量与 b 的相应分量相乘的结果。

## 描述

按分量相乘两个向量。

## 声明

~~~csharp
public void Scale(Vector3Int scale);
~~~

## 参数

| 参数 | 描述 |
| --- | --- |
| scale | 要与此向量相乘的向量。 |

## 描述

将此向量的每个分量与 scale 的相应分量相乘。
