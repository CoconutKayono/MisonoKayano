# [Vector3Int](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector3Int.html).Max

## 声明

~~~csharp
public static Vector3Int Max(Vector3Int lhs, Vector3Int rhs);
~~~

## 参数

| 参数 | 描述 |
| --- | --- |
| lhs | 要比较的第一个向量。 |
| rhs | 要比较的第二个向量。 |

## 返回

Vector3Int A vector that is made from the largest components of two vectors.

## 描述

返回由两个向量较大分量组成的向量。
