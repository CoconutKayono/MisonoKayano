# HideFlags.DontSaveInEditor

## 描述

对象不会在编辑器中保存到场景。

对于场景中的 Prefab 实例，可以在 Prefab 实例句柄对象上设置此 hide flag，从而为 Prefab 实例中的所有对象设置相同的 hide flag。另请参阅 `PrefabUtility.GetPrefabInstanceHandle`。
