# Behaviour

## 描述

Behaviour 是可以启用或禁用的 Component。

其他资源：[MonoBehaviour](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/MonoBehaviour.html) 和 [Component](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Component.html)。

## 成员

| 本地链接 | API名 | 中文说明 |
| --- | --- | --- |
| [[01-enabled]] | enabled | 启用 Behaviour 时，对应 GameObject、脚本和其他脚本回调会处于启用状态。 |
| [[02-isActiveAndEnabled]] | isActiveAndEnabled | 如果 Behaviour 当前处于活动状态并已启用，则返回 true。 |
