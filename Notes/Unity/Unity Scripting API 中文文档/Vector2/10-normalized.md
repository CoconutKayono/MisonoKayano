# [Vector2](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector2.html).normalized

## 声明

~~~csharp
public Vector2 normalized;
~~~

## 描述

返回基于当前向量的归一化向量。归一化向量长度为 1，方向与当前向量相同；如果当前向量太小而无法归一化，则返回零向量。
