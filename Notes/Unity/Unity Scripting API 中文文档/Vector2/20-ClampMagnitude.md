# [Vector2](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector2.html).ClampMagnitude

## 声明

~~~csharp
public static Vector2 ClampMagnitude(Vector2 vector, float maxLength);
~~~

## 参数

| 参数 | 中文说明 |
| --- | --- |
| vector | 要限制的向量。 |
| maxLength | 允许的最大长度。 |

## 返回值

返回操作结果。

## 描述

创建给定向量的副本，并将其长度限制为最大长度。
