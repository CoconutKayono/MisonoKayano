# [Vector2](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector2.html).Normalize

## 声明

~~~csharp
public void Normalize();
~~~

## 参数

| 参数 | 中文说明 |
| --- | --- |
| value | 要归一化的向量。 |

## 返回值

无返回值。

## 描述

使向量的长度为 1。如果向量太小而无法归一化，则将其设为零向量。
