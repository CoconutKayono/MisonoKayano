# [Vector2](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Vector2.html).Perpendicular

## 声明

~~~csharp
public static Vector2 Perpendicular(Vector2 inDirection);
~~~

## 参数

| 参数 | 中文说明 |
| --- | --- |
| inDirection | 输入方向。 |

## 返回值

返回操作结果。

## 描述

返回垂直于此 2D 向量的 2D 向量。在 Y 轴向上的 2D 坐标系中，结果始终沿逆时针方向旋转 90 度。
