# [CharacterController](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/CharacterController.html).enableOverlapRecovery

public bool enableOverlapRecovery;

### 描述

启用或禁用重叠恢复。当检测到重叠时，该功能用于将角色控制器从静态对象中推出。
