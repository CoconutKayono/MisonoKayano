# 控制补间（Controlling a tween）

有三种方式可以操控补间。它们使用相同的方法名，唯一的区别是：通过快捷方式对象调用时，方法名会多一个 `DO` 前缀。

## A. 通过静态方法与过滤器

`DOTween` 类包含许多用于控制补间的静态方法。

每个方法都有两种版本：

- **"All" 版本**：作用于所有现有补间，如 `DOTween.KillAll()`。
- **普通版本**：带一个参数，可按补间的 id 或 target 过滤操作，如 `DOTween.Kill(myTargetOrId)`。（id 通过 `SetId` 手动设置；target 通过快捷方式创建补间时自动设置。）

静态方法还会返回一个 `int`，表示实际成功执行了请求操作的补间数量。

```cs
// 暂停所有补间
DOTween.PauseAll();
// 暂停所有 id 为 "badoom" 的补间
DOTween.Pause("badoom");
// 暂停所有以 someTransform 为目标的补间
DOTween.Pause(someTransform);
```

## B. 直接从补间引用调用

不用静态方法，直接在你的补间引用上调用同样的方法：

```cs
myTween.Pause();
```

## C. 从快捷方式对象调用

同上，但可以从快捷方式增强的对象上调用。注意此时方法名多了 `DO` 前缀，以区别于对象的普通方法：

```cs
transform.DOPause();
```

## 控制方法（Control methods）

再次提醒：所有控制方法在三种方式中方法名一致，只有对象快捷方式多一个 `DO` 前缀。

> [!WARNING]
> 想在补间结束后继续对补间使用这些方法，需要先关闭它的 autoKill 行为（`SetAutoKill(false)`），否则补间会在完成时被自动杀死。

### Complete —— 直接完成

```cs
CompleteAll/Complete(bool withCallbacks = false)
```

将补间直接送到结束位置（对无限循环的补间无效）。

- **withCallbacks**：仅 Sequence 使用。`TRUE` 时触发序列内部回调；`FALSE` 时忽略。

### Flip —— 翻转方向

```cs
FlipAll/Flip()
```

翻转补间的方向（正向变反向，反向变正向）。

### Goto —— 跳转到指定时间

```cs
GotoAll/Goto(float to, bool andPlay = false)
```

将补间送到指定时间位置。

- **to**：要达到的时间位置（如果超过整个补间时长，补间会直接到达结尾）。
- **andPlay**：`TRUE` 时到达指定位置后继续播放；`FALSE` 时暂停。

### Kill —— 杀死补间

```cs
KillAll/Kill(bool complete = false, params object[] idsOrTargetsToExclude)
```

杀死补间。

补间在完成时会被自动杀死（除非你用 `SetAutoKill(false)` 阻止），但如果你不再需要它，可以用此方法提前杀死。

- **complete**：`TRUE` 时在杀死前立刻完成补间（把目标设为其最终值）。
- **idsOrTargetsToExclude**：仅 KillAll 使用。要从操作中排除的目标或 id。

### Pause / Play / PlayBackwards / PlayForward —— 暂停与播放

```cs
PauseAll/Pause()                // 暂停补间
PlayAll/Play()                  // 播放补间
PlayBackwardsAll/PlayBackwards() // 倒放补间
PlayForwardAll/PlayForward()     // 正放补间
```

### Restart —— 重新启动

```cs
RestartAll/Restart(bool includeDelay = true, float changeDelayTo = -1)
```

重新启动补间。

- **includeDelay**：`TRUE` 时包含延迟；`FALSE` 时跳过。
- **changeDelayTo**：将补间的延迟设为指定值。

### Rewind —— 倒回

```cs
RewindAll/Rewind(bool includeDelay = true)
```

倒回并暂停补间。

- **includeDelay**：`TRUE` 时包含延迟；`FALSE` 时跳过。

### SmoothRewind —— 平滑倒回

```cs
SmoothRewindAll/SmoothRewind()
```

平滑地倒回补间（不含延迟）。

"平滑倒回"会将补间动画回起始位置（而不是直接跳过去），跳过所有已完成的循环（`LoopType.Incremental` 除外），同时保持动画流畅。

- 如果补间仍在等待延迟，则只会把延迟设为 0 并暂停补间。
- 注意：平滑倒回后的补间，其播放方向会被翻转。

### TogglePause —— 切换暂停

```cs
TogglePauseAll/TogglePause()
```

暂停的补间恢复播放，播放中的补间暂停。

## 特殊控制方法

### ForceInit —— 所有补间通用

```cs
ForceInit()
```

适用于 `Tween`、`Tweener` 或 `Sequence` 实例。强制补间立即初始化其设置。当你想获取补间初始化后才可用的数据时（如 `PathLength`），这个方法很有用。

### GotoWaypoint —— 仅路径补间

```cs
GotoWaypoint(int waypointIndex, bool andPlay = false)
```

**仅适用于路径补间**，且只能从使用 **Linear 缓动** 的 `Tween` 或 `Tweener` 实例调用。将路径补间送到指定路径点索引。

> [!WARNING]
> 这是一个特殊工具方法：调用后 lookAt 方向可能出错，可能需要手动设置（因为它依赖平滑的路径移动，不适合包含大幅方向变化的跳跃）。

- **waypointIndex**：要达到的路径点索引（如果超过最大索引，补间会直接去最后一个）。
- **andPlay**：`TRUE` 时到达后继续播放；`FALSE` 时暂停。

```cs
myPathTween.GotoWaypoint(2);
```
