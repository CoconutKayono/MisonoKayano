# 相机渲染类型简介

> 原文：[Introduction to camera render types in URP](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/camera-types-and-render-type-introduction.html)

Universal Render Pipeline（URP）中有两种 Camera：

- **Base Camera** 是将内容渲染到 render target（屏幕或 Render Texture）的通用 Camera。
- **Overlay Camera** 将内容渲染到另一台 Camera 的输出之上。可以将 Base Camera 与一台或多台 Overlay Camera 的输出组合，这称为 [[01-Camera Stack原理|Camera Stacking]]。

## Base Camera

Base Camera 是 URP 中默认的 Camera 类型，是将内容渲染到指定 render target 的通用 Camera。

要在 URP 中渲染任何内容，Scene 中至少需要一台 Base Camera。Scene 中可以有多台 Base Camera。Base Camera 可以独立使用，也可以用于 Camera Stack。

![Base Camera 图标](camera-icon-base.png)

有关 Unity 在 Inspector 中为 Base Camera 暴露的属性，请参阅[[01-Camera Inspector窗口参考|Camera Component 参考]]。

## Overlay Camera

Overlay Camera 将视图渲染到另一台 Camera 的输出之上。可以使用 Overlay Camera 创建 2D UI 中的 3D 对象、车辆驾驶舱等效果。

Overlay Camera 必须与一台或多台 Base Camera 配合使用，并通过 Camera Stacking 系统组合。Overlay Camera 不能独立使用。不属于任何 Camera Stack 的 Overlay Camera 不会执行 Render Loop 的任何步骤，这种 Camera 称为 orphan Camera。

> [!NOTE]
> 在此版本的 URP 中，只有使用 Universal Renderer 时才支持 Overlay Camera 和 Camera Stacking。

![Overlay Camera 图标](camera-icon-overlay.png)

Camera Stack 中的 Base Camera 决定 Camera Stack 的大多数属性。由于 Overlay Camera 只能在 Camera Stack 中使用，URP 渲染 Scene 时只使用 Overlay Camera 的以下属性：

- Projection
- FOV Axis
- Field of View
- Physical Camera 属性
- Clipping Planes
- Renderer
- Clear Depth
- Render Shadows
- Culling Mask
- Occlusion Culling

Unity 会在 Inspector 中隐藏所有其他未使用的属性。可以通过脚本访问未使用的属性，但对这些属性所做的任何更改都不会影响使用该 Overlay Camera 的 Camera Stack 的视觉输出。

> [!NOTE]
> 虽然可以对 Camera Stack 中的单个 Overlay Camera 应用 post-processing，但 effect 也会应用于该 Overlay Camera 之前 Camera Stack 已经渲染的所有输出。这与对单个 Base Camera 应用 post-processing 不同，后者的 effect 只应用于 Base Camera。

有关 Unity 在 Inspector 中为 Overlay Camera 暴露的属性，请参阅[[01-Camera Inspector窗口参考|Camera Component 参考]]。
