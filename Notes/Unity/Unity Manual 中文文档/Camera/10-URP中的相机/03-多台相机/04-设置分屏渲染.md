# 设置分屏渲染

> 原文：[Set up split-screen rendering](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/rendering-to-the-same-render-target.html)

在 Universal Render Pipeline（URP）中，多台 Base Camera 或 Camera Stack 可以渲染到同一个 render target。这可以创建 split screen rendering 等效果。

如果多台 Base Camera 或 Camera Stack 渲染到 render target 的同一区域，Unity 会在重叠区域多次绘制每个像素。Unity 会最后绘制 Priority 最高的 Base Camera 或 Camera Stack，使其覆盖之前绘制的像素。有关 Camera render order optimization 的更多信息，请参阅[[04-相机渲染顺序|URP 中的相机渲染顺序]]。

使用 Base Camera 的 **Viewport Rect** 属性定义要渲染到 render target 的区域。有关 viewport 坐标的更多信息，请参阅 [Unity Manual](https://docs.unity3d.com/Manual/class-Camera.html) 和 [API 文档](https://docs.unity3d.com/ScriptReference/Camera-rect.html)。

## 设置分屏渲染

![在 URP 中设置分屏渲染](camera-split-screen-viewport.png)

1. 在 Scene 中创建 Camera。其 **Render Mode** 默认为 **Base**，因此它是 Base Camera。
2. 选择该 Camera。在 Inspector 中滚动到 **Output** 部分，将 **Viewport Rect** 的值更改为：
   - X：`0`
   - Y：`0`
   - W：`0.5`
   - H：`1`
3. 在 Scene 中创建另一台 Camera。其 **Render Mode** 默认为 **Base**，因此它是 Base Camera。
4. 选择该 Camera。在 Inspector 中滚动到 **Output** 部分，将 **Viewport Rect** 的值更改为：
   - X：`0.5`
   - Y：`0`
   - W：`0.5`
   - H：`1`

Unity 会将第一台 Camera 渲染到屏幕左侧，将第二台 Camera 渲染到屏幕右侧。

也可以在脚本中设置 Camera 的 `rect` 属性，更改 Camera 的 Viewport Rect：

```csharp
myUniversalAdditionalCameraData.rect = new Rect(0.5f, 0f, 0.5f, 0f);
```
