# 获取剔除结果

> 原文：[Get culling results](https://docs.unity3d.com/6000.7/Documentation/Manual/CullingGroupAPI-get-culling-results.html)

### 通过 onStateChanged callback 接收结果

响应 sphere 可见性或距离状态变化的最高效方式，是使用 `onStateChanged` callback 字段。将它设置为一个接收 `CullingGroupEvent` 结构体参数的函数；每次 culling 完成后，对于状态发生变化的每个 sphere，Unity 都会调用该函数。`CullingGroupEvent` 的成员会告诉你 sphere 的旧状态和新状态。

```csharp
group.onStateChanged = StateChangedMethod;

private void StateChangedMethod(CullingGroupEvent evt)
{
    if (evt.hasBecomeVisible)
        Debug.LogFormat("Sphere {0} has become visible!", evt.index);
    if (evt.hasBecomeInvisible)
        Debug.LogFormat("Sphere {0} has become invisible!", evt.index);
}
```

### 通过 CullingGroup Query API 接收结果

除了 `onStateChanged` delegate，CullingGroup 还提供 API，用于获取 bounding sphere 数组中任意 sphere 的最新可见性和距离结果。要检查单个 sphere 的状态，可以使用 `IsVisible` 和 `GetDistance`：

```csharp
bool sphereIsVisible = group.IsVisible(0);
int sphereDistanceBand = group.GetDistance(0);
```

要检查多个 sphere 的状态，可以使用 `QueryIndices`。此方法扫描连续的 sphere 范围，查找符合指定可见性或距离状态的 sphere：

```csharp
// 分配用于保存 sphere 索引的数组；数组大小决定每次调用最多检查的 sphere 数量。
int[] resultIndices = new int[1000];
// 设置 int，用于保存放入数组的实际结果数量。
int numResults = 0;

// 查找所有可见的 sphere。
numResults = group.QueryIndices(true, resultIndices, 0);
// 查找所有位于 distance band 1 的 sphere。
numResults = group.QueryIndices(1, resultIndices, 0);
// 查找 distance band 2 中隐藏的 sphere，跳过前 100 个 sphere。
numResults = group.QueryIndices(false, 2, resultIndices, 100);
```

请注意，Query API 获取的信息只有在 CullingGroup 使用的 Camera 实际执行 culling 后才会更新。
