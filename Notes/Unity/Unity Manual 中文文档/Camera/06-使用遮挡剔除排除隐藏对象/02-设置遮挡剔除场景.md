# 设置遮挡剔除场景

> 原文：[Set up a scene for occlusion culling](https://docs.unity3d.com/6000.7/Documentation/Manual/occlusion-culling-getting-started.html)

本文介绍如何设置用于 Occlusion Culling 的 Scene、烘焙 Occlusion Culling 数据并可视化结果。

## 设置 Scene

开始前，确定 Scene 中希望作为 Static Occluder 和 Static Occludee 的所有 GameObject。Static Occluder 是不会移动并会阻挡后方 GameObject 视线的对象；Static Occludee 是不会移动并会被 Static Occluder 遮挡的对象。一个 GameObject 可以同时作为 Static Occluder 和 Static Occludee。

墙壁或建筑物等中型到大型实体 GameObject 是 Static Occluder 的良好候选对象。GameObject 必须满足以下条件才能作为 Static Occluder：

- 具有 Terrain 或 Mesh Renderer 组件。
- 是不透明的。
- 运行时不会移动。

如果使用 LOD Group，Unity 会使用 Static Occluder 的基础级别 GameObject（LOD0）确定它能遮挡什么。如果 GameObject 的轮廓在 LOD0 与其他 LOD 级别之间变化很大，它可能不适合作为 Static Occluder。

任何可能在运行时被遮挡的 GameObject 都是 Static Occludee 的良好候选对象，包括小型或透明 GameObject。GameObject 必须具有任意类型的 Renderer 组件且运行时不会移动，才能作为 Static Occludee。

完成识别后：

1. 选择希望作为 Static Occluder 的所有 GameObject。
2. 在 Inspector 窗口中打开 **Static Editor Flags** 下拉菜单，选择 **Occluder Static**。
3. 选择希望作为 Static Occludee 的所有 GameObject。
4. 在 Inspector 窗口中打开 **Static Editor Flags** 下拉菜单，选择 **Occludee Static**。
5. 向 Scene 添加 Camera，或选择已有 Camera。
6. 在 Inspector 窗口中确保启用 Camera 的 **Occlusion Culling** 属性。

## 烘焙数据

1. 从主菜单选择 **Window > Rendering > Occlusion Culling**，打开 [[07-Occlusion Culling窗口参考|Occlusion Culling 窗口]]。
2. 选择 **Bake** 选项卡。
3. 在 Inspector 窗口右下角按下 **Bake** 按钮。Unity 会生成 Occlusion Culling 数据，将数据作为资源保存到项目中，并将资源与当前 Scene 关联。

## 查看结果

1. 确保 Occlusion Culling 窗口和 Scene view 都可见。Occlusion Culling 窗口可见时，Unity 会在 Scene view 中显示 Occlusion Culling 数据和 Occlusion Culling popup。
2. 在 Scene 中选择一个 Camera。
3. 移动 Camera 并观察 Scene view。当 Camera 因 Frustum Culling 或 Occlusion Culling 无法看到 GameObject 时，应能看到 GameObject 从视图中消失。
4. 使用 Scene view 中的 Occlusion Culling popup 配置可视化效果。
5. 如有需要，在 Occlusion Culling 窗口的 **Bake** 选项卡中调整烘焙设置，然后重复烘焙过程。
