# 创建高精度遮挡区域

> 原文：[Create high-precision occlusion areas](https://docs.unity3d.com/6000.7/Documentation/Manual/class-OcclusionArea.html)

使用 Occlusion Area Component 可以在 Occlusion Culling 系统中定义 View Volume。View Volume 是 Camera 运行时可能所在的 Scene 区域。烘焙时，Unity 会在 View Volume 内生成更高精度的数据；运行时，当 Camera 位于 View Volume 内时，Unity 会执行更高精度的计算。

如果没有在 Scene 中定义任何 View Volume，Unity 会在烘焙时创建一个包含所有标记为 Occluder Static 或 Occludee Static 的 Scene 几何体的 View Volume。在大型或复杂 Scene 中，这可能导致数据过大、烘焙时间过长，以及运行时计算消耗过多资源。为避免这种情况，可以在 Camera 可能所在的区域放置 Occlusion Area，定义 View Volume。

## 使用 Occlusion Area Component 定义 View Volume

1. 在 Scene 中向空 GameObject 添加 **Occlusion Area** Component。
2. 在 Inspector 窗口中配置 **Size** 属性，使包围体覆盖所需区域。
3. 在 Inspector 窗口中启用 **Is View Volume**。

## Occlusion Area Component 参考

| 属性 | 说明 |
| --- | --- |
| **Size** | 设置 Occlusion Area 的大小。 |
| **Center** | 设置 Occlusion Area 的中心。默认值为 `(0, 0, 0)`，位于盒体中心。 |
| **Is View Volume** | 启用时，Occlusion Area 定义一个 View Volume；禁用时不定义 View Volume。Occlusion Area 必须启用此属性才能生效。 |

调整区域，使其覆盖需要高精度遮挡数据的空间，然后重新烘焙 Occlusion Culling 数据。
