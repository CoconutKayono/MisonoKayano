# XR 项目中的分辨率控制

> 原文：[Resolution control in XR projects](https://docs.unity3d.com/6000.7/Documentation/Manual/xr-graphics-resolution-scaling.html)

可以通过分辨率缩放减少 GPU 工作量并优化 XR 项目的性能。其中一些 XR 设备的分辨率控制方法会实现动态分辨率；动态分辨率会自动调整分辨率，以维持稳定的帧率。

具体控制方式取决于项目使用的 Render Pipeline。

## 分辨率控制参考

下表列出了可用于缩放 XR 项目分辨率的方法，以及各方法兼容的 Render Pipeline：

| 方法 | 兼容的 Render Pipeline |
| --- | --- |
| 使用 `XRSettings.renderViewportScale` 控制分辨率 | URP |
| 更改 URP Asset 中的 Render Scale | URP |
| 启用自动 viewport 动态分辨率 | URP |
| 动态分辨率系统 | HDRP |
| 更改 `XRSettings.eyeTextureResolutionScale` | HDRP |

## 使用 URP 控制分辨率

如果项目使用 URP，Unity 推荐使用 `XRSettings.renderViewportScale` 控制分辨率。如果项目启用了 post-processing，可以按照下方说明进行额外设置。

### 使用 XRSettings.renderViewportScale 控制分辨率

在未启用 post-processing，或启用了 HDR 时，URP 会直接渲染到 eye texture。此时可以直接使用 `XRSettings.renderViewportScale`，控制 URP 使用已分配 eye texture 的比例，并在运行时动态调整 eye texture 的渲染分辨率。

例如将值设置为 `0.5` 时，URP 会渲染到纹理的四分之一区域（宽度和高度各为一半），然后由 XR 设备将该区域放大以填充最终显示区域。该属性与 fixed foveated rendering 兼容，但它只是提供给 XR runtime 的开发者提示；runtime 可能根据内部逻辑和性能状况采用或忽略该值。可以查询 `XRSettings.appliedRenderViewportScale` 了解设备实际使用的缩放比例。

### 启用 post-processing 时使用 XRSettings.renderViewportScale

启用 URP XR 项目的 post-processing 后，URP 会渲染到中间纹理，而不是直接渲染到 eye texture。要启用动态分辨率：

1. 在 **Inspector** 中打开 **Main Camera**，在 **Output** 下启用 **URP Dynamic Resolution**。
2. 使用 `XRSettings.renderViewportScale` 调整发送到设备的最终 viewport 区域。URP 会在内部使用 `ScalableBufferManager` 缩放中间纹理。

该方式不能与 fixed foveated rendering 或 Temporal Anti Aliasing 同时使用。

### 更改 URP Asset 中的 Render Scale

可以直接在 URP Asset 中更改 Render Scale，以直接缩放 eye texture。这是 `XRSettings.eyeTextureResolutionScale` 的替代方式；后者不受 URP 支持，但受 HDRP 支持。

更改 Render Scale 会重新分配 eye texture，是一项开销较高的操作，不应每帧执行。操作步骤如下：

1. 在 **Inspector** 窗口中打开 URP Asset。
2. 展开 **Quality** 部分。
3. 设置所需的 **Render Scale** 值。

也可以使用 `UniversalRenderPipelineAsset.renderScale` API 更改该值。

### 启用自动 viewport 动态分辨率（OpenXR）

在 Unity 6.3 或更高版本，以及 OpenXR 1.16 或更高版本中，可以使用 Automatic viewport dynamic resolution 功能，自动控制 OpenXR runtime 上的分辨率。

## 使用 HDRP 控制分辨率

如果项目使用 HDRP，可以使用动态分辨率系统，或使用 `XRSettings.eyeTextureResolutionScale`。`XRSettings.renderViewportScale` 不受 HDRP 支持。
