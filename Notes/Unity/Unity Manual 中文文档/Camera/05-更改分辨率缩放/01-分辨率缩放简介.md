# 分辨率缩放简介

> 原文：[Introduction to changing resolution scale](https://docs.unity3d.com/6000.7/Documentation/Manual/resolution-scale-introduction.html)

> [!IMPORTANT]
> Built-In Render Pipeline 已弃用，并将在未来版本中移除。它会在整个 Unity 6.7 LTS 生命周期内继续获得支持，包括 Bug Fix 和维护。迁移信息请参阅[从 Built-In Render Pipeline 迁移到 Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrading-from-birp.html)以及[Render Pipeline 功能对比](https://docs.unity3d.com/6000.7/Documentation/Manual/render-pipelines-feature-comparison.html)。

为了减少 GPU 的工作量并提高渲染速度，可以降低 Unity 实际渲染图像的分辨率。例如，当应用的 Frame Rate 降低时，可以使用更低的分辨率进行渲染。

更改 resolution scale 时，Unity 会：

1. 以更低的分辨率渲染。
2. 使用一种 Upscaling Technique 放大渲染结果，使其匹配最终图像的尺寸。

如果使用 Universal Render Pipeline（URP）或 Built-In Render Pipeline，只能在部分平台上使用 Dynamic Resolution。关于 Dynamic Resolution，请参阅 [[00-动态分辨率]]；关于 High Definition Render Pipeline（HDRP）中的 Dynamic Resolution，请参阅 [HDRP 中的动态分辨率](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.0/manual/Dynamic-Resolution.html)。

## Upscaling techniques

Upscaling Technique 取决于所选择的 Render Pipeline 和构建目标平台。Built-In Render Pipeline 始终使用 GPU 提供的 Filtering Technique。

| Feature | Upscaling 使用的数据或方法 | URP | HDRP |
| --- | --- | --- | --- |
| Bilinear | Graphics API 提供的 Bilinear 或 Linear Filtering。 | 支持，参考 URP Asset 的 Quality Settings。 | 不支持。 |
| Nearest-neighbor | Graphics API 提供的 Nearest-neighbor 或 Point Sampling Filtering。 | 支持，参考 URP Asset 的 Quality Settings。 | 不支持。 |
| Catmull-Rom | 四次 Bilinear Sampling。 | 不支持。 | 支持，参考 HDRP 中选择 Upscale Filter 的说明。 |
| AMD FidelityFX Contrast Adaptive Sharpen（CAS） | Contrast Level。 | 不支持。 | 支持，参考 HDRP 中选择 Upscale Filter 的说明。 |
| Temporal Anti-Aliasing Upscaling（TAAU） | 前几帧的数据。 | 不支持。 | 支持，参考 HDRP 中选择 Upscale Filter 的说明。 |
| Spatial-Temporal Post-processing（STP） | 多张输入 Texture。STP 会自动配置，在不同平台上平衡性能和质量。 | 支持，但不能与 Dynamic Resolution 同时使用。 | 支持，但不能与 Software Dynamic Resolution 同时使用。 |
| AMD FidelityFX Super Resolution（FSR）1 | Frame Buffer。 | 支持，参考 URP Asset 的 Quality Settings。 | 支持，参考 HDRP 中选择 Upscale Filter 的说明。 |
| AMD FidelityFX Super Resolution（FSR）2 | 多张输入 Texture。 | 不支持。 | 支持，参考 HDRP 中选择 Upscale Filter 的说明。 |
| NVIDIA Deep Learning Super Sampling（DLSS）4 Super Resolution | 多张输入 Texture。 | 不支持。 | 支持，参考 HDRP 中的 DLSS 说明。 |
