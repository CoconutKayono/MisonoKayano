# 动态分辨率简介

> 原文：[Introduction to Dynamic Resolution](https://docs.unity3d.com/6000.7/Documentation/Manual/DynamicResolution-introduction.html)

动态分辨率是 Camera 的一项设置，可以动态缩放指定的 Render Target，以减少 GPU 工作量。你可以逐步降低分辨率，使应用维持稳定的帧率；如果变化足够平滑，用户通常不会明显察觉。

## Render Pipeline 兼容性

> [!IMPORTANT]
> Built-In Render Pipeline 已弃用，并将在未来版本中移除。它会在整个 Unity 6.7 LTS 生命周期内继续获得支持，包括 Bug Fix 和维护。迁移信息请参阅[从 Built-In Render Pipeline 迁移到 Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrading-from-birp.html)以及[Render Pipeline 功能对比](https://docs.unity3d.com/6000.7/Documentation/Manual/render-pipelines-feature-comparison.html)。

Dynamic Resolution 的支持取决于项目使用的 Render Pipeline。

| 功能 | URP | HDRP | Built-In Render Pipeline |
| --- | --- | --- | --- |
| 动态分辨率 | 支持（1） | 支持（2） | 支持（1） |

注：Built-In Render Pipeline 与 Universal Render Pipeline（URP）都按本文所述方式支持 Dynamic Resolution。High Definition Render Pipeline（HDRP）也支持 Dynamic Resolution，但启用和使用方式不同；相关信息请参阅 [HDRP 中的动态分辨率](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@latest?subfolder=/manual/Dynamic-Resolution.html)。

## 支持的平台

Unity 支持以下平台：iOS、macOS 和 tvOS（仅 Metal）、Android（仅 Vulkan）、Windows Standalone（仅 DirectX 12）以及 UWP（仅 DirectX 12）。

## 对 Render Target 的影响

使用 Dynamic Resolution 时，Unity 不会重新分配 Render Target。概念上，Unity 会缩放 Render Target；但实际实现使用 aliasing，缩小后的 Render Target 只占用原始 Render Target 的一小部分。Unity 会以完整分辨率分配 Render Target，然后由 Dynamic Resolution 系统将其缩小并再次放大，使用原始 Target 的一部分，而不是重新分配新的 Target。
