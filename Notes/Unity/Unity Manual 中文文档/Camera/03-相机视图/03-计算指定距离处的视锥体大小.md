# 计算指定距离处的 Frustum 大小

> 原文：[Calculate the size of the frustum at a distance](https://docs.unity3d.com/6000.7/Documentation/Manual/FrustumSizeAtDistance.html)

View frustum 在某个距离处的 cross-section 会形成一个 world space 中的矩形，用来界定 Camera 的可见区域。

有时需要计算 Camera 在指定距离处的矩形大小，或者反过来计算得到指定矩形大小所需的距离。例如，移动 Camera 需要始终完整拍摄 Player，就必须避免距离过近而裁切 Player 的一部分。

## 根据距离计算 Frustum 高度

使用以下公式计算指定距离处的 frustum height，单位均为 world unit：

```csharp
var frustumHeight = 2.0f * distance
    * Mathf.Tan(camera.fieldOfView * 0.5f * Mathf.Deg2Rad);
```

## 根据 Frustum 高度计算距离

可以反向计算得到指定 frustum height 所需的距离：

```csharp
var distance = frustumHeight * 0.5f
    / Mathf.Tan(camera.fieldOfView * 0.5f * Mathf.Deg2Rad);
```

## 根据高度和距离计算 FOV

当已知 height 和 distance 时，可以计算 Camera 的 FOV：

```csharp
var cameraFieldOfView = 2.0f
    * Mathf.Atan(frustumHeight * 0.5f / distance)
    * Mathf.Rad2Deg;
```

## 在宽度和高度之间转换

这些计算使用 frustum height，但可以通过 Camera 的 `aspect` 很容易地得到 width，反之亦然：

```csharp
var frustumWidth = frustumHeight * camera.aspect;
var frustumHeight = frustumWidth / camera.aspect;
```
