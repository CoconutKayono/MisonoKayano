# 配置多台相机

> 原文：[Configure multiple cameras](https://docs.unity3d.com/6000.7/Documentation/Manual/MultipleCameras.html)

创建 Scene 时通常只有一台相机，这已经足够应付大多数情况。但一个 Scene 可以拥有任意多台相机，并以不同方式组合它们的视图。

## 切换相机视图

默认情况下，一台相机会覆盖整个屏幕，因此同一时间只能看到一台相机的视图。可见相机通常是 `depth` 值最高的相机。通过脚本禁用一台相机并启用另一台相机，可以在不同视图之间切换，例如在俯视地图和第一人称视图之间切换。

```csharp
using UnityEngine;

public class ExampleScript : MonoBehaviour
{
    public Camera firstPersonCamera;
    public Camera overheadCamera;

    // 调用此函数禁用第一人称相机并启用俯视相机。
    public void ShowOverheadView()
    {
        firstPersonCamera.enabled = false;
        overheadCamera.enabled = true;
    }

    // 调用此函数启用第一人称相机并禁用俯视相机。
    public void ShowFirstPersonView()
    {
        firstPersonCamera.enabled = true;
        overheadCamera.enabled = false;
    }
}
```

## 在较大的视图中显示小型视图

可以让一台相机覆盖整个屏幕，再让另一台相机只渲染屏幕的一小块区域，例如驾驶游戏的后视镜，或第一人称游戏角落里的小地图。

在小型视图相机的 **Viewport Rect** 中设置屏幕矩形。视口坐标相对于屏幕归一化：左边和底边为 `0.0`，右边和顶边为 `1.0`，`0.5` 表示中点。还要将小视图相机的 `depth` 设置为高于背景相机的值，使它绘制在背景相机之上。
