# 在多台显示器上显示相机视图

> 原文：[Display camera views on multiple monitors](https://docs.unity3d.com/6000.7/Documentation/Manual/MultiDisplay.html)

使用 **multi-display** 可以同时在最多八台显示器上显示应用的八个不同相机视图。这适用于 PC 游戏、街机设备和公共展示装置等场景。

Unity 在以下平台支持 multi-display：

- Desktop platform：Windows、macOS 和 Linux。
- Android：OpenGL ES 和 Vulkan。
- iOS。

部分功能只在部分平台可用，兼容性请参阅 `Display`、`Screen` 和 `FullScreenMode` API。

## 激活 multi-display

Unity 默认只使用一台显示器。应用运行时，必须使用 `Display.Activate()` 显式激活其他显示器。显示器激活后不能停用。

建议在应用创建新 Scene 时激活其他显示器。可以把 Script Component 添加到默认 Camera 上，并确保在启动期间只调用一次 `Display.Activate()`。

作为最佳实践，可以创建一个小型的初始 Scene 来测试这个脚本。

```csharp
using UnityEngine;
using System.Collections;

public class ActivateAllDisplays : MonoBehaviour
{
    void Start ()
    {
        Debug.Log ("displays connected: " + Display.displays.Length);

        // Display.displays[0] 是主显示器、默认显示器，并且始终处于开启状态，因此从 index 1 开始处理。
        // 检查是否存在其他显示器，并激活每一台。
        for (int i = 1; i < Display.displays.Length; i++)
        {
            Display.displays[i].Activate();
        }
    }

    void Update()
    {

    }
}
```

## 在 Project 中预览多台显示器

1. 在 Camera 的 Inspector 中，为相机选择 **Target Display**。

![Camera Inspector 中的 Target Display 选项](InspectorCamera35.png)

2. 确认当前处于 **Game view**。
3. 在左上角的 **Display** 菜单中选择要预览的 Display。

![Game view 左上角的 Display 预览菜单](TargetDisplay.png)

## API 支持

UnityEngine.Display 支持以下 `Activate` 方法：

| 方法                                                             | 说明                                                                                                    |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `public void Activate()`                                       | 使用当前显示器的 width、height 激活指定 Display。进入新 Scene 时必须调用一次，可以从 Camera 或新 Scene 中的空 GameObject 上的 Script 调用。 |
| `public void Activate(int width, int height, int refreshRate)` | 仅 Windows 支持。使用自定义 width、height 激活指定 Display；Linux 和 macOS 的辅助显示器使用其当前可用分辨率。                          |
