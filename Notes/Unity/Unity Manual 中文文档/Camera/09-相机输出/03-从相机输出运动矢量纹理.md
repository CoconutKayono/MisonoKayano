# 从相机输出运动矢量纹理

> 原文：[Output a motion vector texture from a camera](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-CameraDepthTexture-motionvectors.html)

`DepthTextureMode.MotionVectors` 会构建一个屏幕大小的 `RG16`（每通道 16 位浮点数）texture，其中 screen space pixel motion 编码在 R&G 通道中。像素运动使用 screen UV space 编码。
