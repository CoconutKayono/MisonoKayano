# 排查相机输出问题

> 原文：[Troubleshooting camera output](https://docs.unity3d.com/6000.7/Documentation/Manual/CameraOutput-troubleshoot.html)

Camera Component Inspector 窗口会显示 Camera 是否正在渲染 depth 或 depth+normals texture。

Camera 请求 depth texture 的方式可能导致这种情况：禁用需要该 Texture 的 effect 后，Camera 仍可能继续渲染它。如果 Camera 上存在多个 effect，且每个 effect 都需要 depth texture，那么禁用单个 effect 时没有可靠方式自动关闭 depth texture 渲染。

实现复杂 Shader 或 Image Effect 时，请注意[不同平台之间的渲染差异](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-PlatformDifferences.html)。尤其是，在 Direct3D + Anti-Aliasing 上的 Image Effect 中使用 depth texture 通常需要特殊处理。

在某些情况下，depth texture 可能直接来自原生 Z buffer。如果 depth texture 中出现 artefacts，请确保使用它的 Shader **不**写入 Z buffer（使用 [`ZWrite Off`](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-ZWrite.html)）。

当 DepthNormals texture 通过单独的 pass 渲染时，Unity 会使用 [Shader Replacement](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-ShaderReplacement.html)。因此，请确保 Shader 中包含正确的 **RenderType** tag。
