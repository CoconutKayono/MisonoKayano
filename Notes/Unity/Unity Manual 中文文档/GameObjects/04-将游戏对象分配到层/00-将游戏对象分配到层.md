# 将游戏对象分配到层

> 原文：[Assign GameObjects to layers](https://docs.unity3d.com/6000.7/Documentation/Manual/Layers.html)

Layer 是一种用于分离 Scene 中 GameObject 的工具。你可以通过 UI 和脚本使用 Layer，编辑 Scene 中 GameObject 之间的交互方式。

你可以从 **View Options** Overlay 中选择在 Scene 视图中显示哪些 Layer。
