# 使用组件

> 原文：[Use components](https://docs.unity3d.com/6000.7/Documentation/Manual/UsingComponents.html)

你可以使用不同的 Component 来改变或增加 GameObject 的功能。你可以在 Inspector 窗口中修改任意 Component 的属性，也可以使用脚本修改。

有关如何通过脚本使用 Component 的更多信息，请参阅 Component 脚本参考页面。

## 添加组件

你可以通过 **Component** 菜单向选中的 GameObject 添加 Component。要添加 Rigidbody Component，请选择 GameObject，然后选择 **Component > Physics > Rigidbody**。Inspector 会显示 Rigidbody 的属性。如果选中空 GameObject 时按下 **Play**，GameObject 的 Transform 的 Y 位置会下降，这是因为 Unity 的 Physics 系统使 GameObject 在重力作用下下落。

![带 Rigidbody 的 GameObject](RigidBodyGO1.png)

你也可以在 Component Browser 中添加 Component。要打开 Component Browser，请在 Inspector 中选择 **Add Component**。

![Component Browser](ComponentBrowser1.png)

你可以在 Browser 中按类别浏览 Component，或使用搜索框按名称查找 Component。

Component 必须与要附加它的 GameObject 位于同一个项目中。Component 可能专属于某个 Package，也可能由脚本创建。Unity Editor 无法搜索以下来源中的 Component：

- 其他项目。
- 尚未附加到该项目的脚本。
- 尚未添加到项目中的 Package。

你可以向一个 GameObject 附加任意数量或组合的 Component。某些 Component 组合使用效果更好。例如，Rigidbody 会与 Collider 配合使用。

有关特定 Component 的更多信息，请参阅对应的 Component 参考页面。如果在 Inspector 中选择 Component 标题栏上的帮助图标（**?**），也可以从 Unity 访问该 Component 的参考页面。

## 编辑组件

向 GameObject 附加 Component 时，Component 的属性包含默认值。你可以在制作游戏时于 Editor 中编辑这些值，也可以在运行游戏时通过脚本编辑。

属性主要分为两种类型：值和引用。

你可以在 Inspector 中编辑值属性。值有多种类型，包括文本、开关和下拉选项。

对于引用属性，你可以将 Project 视图中的文件拖到属性上，或者使用属性上的对象选择器（圆形图标）。引用属性可以引用其他类型的 Component、GameObject 或 Asset。

有关不同属性类型的更多信息，请参阅[编辑属性](https://docs.unity3d.com/6000.7/Documentation/Manual/EditingProperties.html)。

![Audio Component 引用](AudioReference1.png)

*Audio Source 的 Inspector 值展示了如何调整 Component 的各个方面，以满足项目需求。*

## Component 上下文菜单命令

右键点击 Component，可以打开包含多个实用命令的上下文菜单。

在 Inspector 窗口中 Component 面板右上角的三点菜单（⋮）中也可以使用相同的命令。

下表介绍可用于调整 Component 的命令：

| 命令 | 说明 |
| --- | --- |
| **Reset** | 将 Component 属性恢复为最近一次编辑会话之前的值。 |
| **Remove Component** | 从 GameObject 中移除 Component。如果 Component 之间存在依赖关系（例如 Hinge Joint 只有附加到 Rigidbody 后才能工作），尝试移除被其他 Component 依赖的 Component 时会显示警告。 |
| **Move Up** | 在 Inspector 中将 Component 向上移动。你也可以在 Inspector 中拖放 Component 来重新排序。 |
| **Move Down** | 在 Inspector 中将 Component 向下移动。 |
| **Copy Component** | 复制 Component 的类型和当前属性设置。 |
| **Paste Component As New** | 将复制的 Component 属性设置作为新的 Component 粘贴。 |
| **Paste Component Values** | 将复制的 Component 属性设置粘贴到另一个相同类型的 Component 中。 |

## 测试属性

在 **Play Mode** 中，你可以在 Inspector 中修改 Component 的属性，从而查看属性的不同值如何影响 Gameplay。例如，你可以尝试不同的跳跃高度。如果在脚本中创建 `Jump Height` 属性，就可以进入 Play Mode，修改该值并按下跳跃按钮查看结果。然后无需退出 Play Mode 即可再次修改它，并在几秒内查看结果。退出 Play Mode 时，属性会恢复为进入 Play Mode 之前的值。使用这种工作流，可以更快地试验、调整和完善 Gameplay。
