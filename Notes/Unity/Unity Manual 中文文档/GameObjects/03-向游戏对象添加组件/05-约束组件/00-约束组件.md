# 约束组件

> 原文：[Constraint components](https://docs.unity3d.com/6000.7/Documentation/Manual/constraint-components.html)

Constraint Component 可以根据场景中的其他对象，控制 GameObject 的位置、旋转和缩放。它提供了一种在不使用父子层级或编写自定义脚本的情况下创建对象关系的方法。

Constraint 适用于角色绑定、摄像机控制以及创建对象之间的关系。你可以在单个 GameObject 上使用多个 Constraint，也可以在多个 Source Object 之间进行混合，以实现复杂行为。
