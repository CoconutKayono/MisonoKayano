# 约束组件简介

> 原文：[Constraint components introduction](https://docs.unity3d.com/6000.7/Documentation/Manual/Constraints.html)

Constraint Component 会将一个 GameObject 的位置、旋转或缩放关联到另一个 GameObject。受到约束的 GameObject 会像与其关联的 GameObject 一样移动、旋转或缩放。

Unity 支持以下类型的 Constraint Component：

- [[02-Aim Constraint|Aim]]：旋转受到约束的 GameObject，使其朝向关联的 GameObject。
- [[03-Look At Constraint|Look At]]：旋转受到约束的 GameObject，使其朝向关联的 GameObject（简化版的 Aim Constraint）。
- [[04-Parent Constraint|Parent]]：使受到约束的 GameObject 随关联的 GameObject 移动和旋转。
- [[05-Position Constraint|Position]]：使受到约束的 GameObject 像关联的 GameObject 一样移动。
- [[06-Rotation Constraint|Rotation]]：使受到约束的 GameObject 像关联的 GameObject 一样旋转。
- [[07-Scale Constraint|Scale]]：使受到约束的 GameObject 像关联的 GameObject 一样缩放。

## 关联 GameObject

使用 Constraint Component 中的 **Sources** 列表指定要关联的 GameObject。

例如，在 2D 射击游戏中，如果希望准星跟随玩家的宇宙飞船，请为准星添加 **Position Constraint** Component。要将准星关联到宇宙飞船，请在 **Position Constraint** Component 中，将宇宙飞船 GameObject 添加到 **Sources** 列表。玩家移动宇宙飞船时，准星就会跟随移动。

![准星的 Position Constraint。准星跟随玩家的宇宙飞船（红色）。](ConstraintSourceLinking.png)

一个 Constraint 可以关联多个 Source GameObject。在这种情况下，Constraint 使用所有 Source GameObject 的平均位置、旋转或缩放。例如，要让一个 Light 朝向一组 GameObject，请为 Light GameObject 添加 **Aim Constraint** Component，然后将要照亮的 GameObject 添加到 **Sources** 列表。**Aim Constraint** 会让 Light 朝向所有 Source 的平均位置。

Unity 会按照 Source GameObject 在 **Sources** 列表中的顺序对其进行评估。顺序对 **Position Constraint** 和 **Scale Constraint** 没有影响，但会影响 **Parent Constraint**、**Rotation Constraint** 和 **Aim Constraint**。要得到预期结果，可以通过拖放重新排列 **Sources** 列表。

也可以串联一系列 GameObject 的 Constraint。例如，要让小鸭子排成一列跟随母鸭：为 `Duckling1` 添加 **Position Constraint** Component，并将 `MotherDuck` 设为 Source；然后为 `Duckling2` 添加 **Position Constraint**，并将 `Duckling1` 设为 Source。当 `MotherDuck` GameObject 在 Scene 中移动时，`Duckling1` 会跟随 `MotherDuck`，而 `Duckling2` 会跟随 `Duckling1`。

避免创建循环 Constraint，因为这会导致游戏运行期间的更新结果不可预测。

## 设置 Constraint 属性

使用 [Inspector 窗口](https://docs.unity3d.com/6000.7/Documentation/Manual/UsingTheInspector.html)修改 Constraint 的通用属性。

![Position Constraint 的 Weight 和 Constraint Settings。](ConstraintSettings.png)

- 使用 **Weight** 调整 Constraint 的影响程度。Weight 为 `1` 时，Constraint 会使 GameObject 以与其 Source GameObject 相同的速率更新；Weight 为 `0` 时，Constraint 完全不起作用。每个 Source GameObject 也有独立的 Weight。
- 在 **Constraint Settings** 中使用 **At Rest** 属性，指定当 **Weight** 为 `0`，或 **Freeze Axes** 中对应属性未勾选时使用的 X、Y 和 Z 值。
- 在 **Constraint Settings** 中使用 **Offset** 属性，指定约束 GameObject 时使用的 X、Y 和 Z 偏移值。
- 使用 **Freeze Axes** 设置切换 Constraint 实际可以修改的轴。

## 激活和锁定 Constraint

使用 Constraint 时需要区分激活和锁定。

激活 Constraint 后，它才会评估受到约束的 GameObject 的位置、旋转或缩放。Unity 不会评估未激活的 Constraint。

锁定 Constraint 后，它才会移动、旋转或缩放 GameObject。锁定的 Constraint 会接管 GameObject 的 [Transform](https://docs.unity3d.com/6000.7/Documentation/Manual/class-Transform.html) 的相关部分。你不能手动移动、旋转或缩放带有锁定 Constraint 的 GameObject，也不能编辑 **Constraint Settings**。

要手动编辑 GameObject 的位置、旋转或缩放，请先解锁 Constraint。如果 Constraint 处于激活且未锁定状态，当你移动、旋转或缩放受到约束的 GameObject 或其 Source GameObject 时，Constraint 会自动更新 **Constraint Settings**。

向 GameObject 添加 Constraint Component 时，Constraint 默认处于未激活且未锁定状态。这样可以先微调受到约束的 GameObject 和 Source GameObject 的位置、旋转和缩放，再激活并锁定 Constraint。

**Activate** 和 **Zero** 按钮可以方便地自动更新 **Constraint Settings**：

- **Activate**：保存当前相对于 Source GameObject 的偏移，然后激活并锁定受到约束的 GameObject。
- **Zero**：重置位置、旋转或缩放，使其匹配 Source GameObject，然后激活并锁定受到约束的 GameObject。

## 为 Constraint 制作动画并组合 Constraint

可以使用 Animation Clip 修改受到约束的 GameObject 所关联的 Source GameObject。Animation 修改 Source GameObject 时，Constraint 会相应修改受到约束的 GameObject。

也可以为 Constraint Component 的属性制作动画。例如，可以使用 **Parent Constraint** 让角色的剑从手中移动到背后。先为剑 GameObject 添加 **Parent Constraint**，然后在 **Sources** 列表中将 Constraint 关联到角色的手和脊柱。要制作剑的动画，请为每个 Source 的 Weight 添加关键帧。要制作剑从背后移动到手中的动画，请添加关键帧，将手部 Weight 从 `0` 变为 `1`，同时将脊柱 Weight 从 `1` 变为 `0`。

同一个 GameObject 可以添加多个类型的 Constraint Component。更新 GameObject 时，Unity 会按照 Constraint Component 在 [Inspector 窗口](https://docs.unity3d.com/6000.7/Documentation/Manual/UsingTheInspector.html)中从上到下的顺序依次评估它们。同一个 GameObject 不能包含多个相同类型的 Constraint Component。例如，不能添加多个 **Position Constraint**。

## 导入 Constraint

从 Autodesk® Maya® 或 MotionBuilder® 向 Unity Editor 导入 FBX 文件时，可以同时导入 Constraint。单击 Import Settings 窗口的 **Animation** Tab，然后勾选 **Import Constraints**。

![勾选了 Import Constraints 的 Import Settings。](ConstraintImport.png)

对于 FBX 文件中的每个 Constraint，Unity 会自动添加对应的 Constraint Component，并将其关联到正确的 GameObject。

## 添加和编辑 Constraint

### 添加 Constraint Component

1. 选择要施加约束的 GameObject。
2. 在 Inspector 窗口中单击 **Add Component**，搜索要添加的 Constraint 类型，然后单击该类型进行添加。
3. 要向新 Constraint 添加 Source GameObject，请将该 GameObject 从 Hierarchy 窗口或 Scene 视图拖到 **Sources** 列表中。
4. 移动、旋转或缩放受到约束的 GameObject 及其 Source GameObject。
5. 要激活 Constraint，请单击 **Activate** 或 **Zero**，或者勾选 **Is Active** 和 **Lock**。

### 编辑 Constraint Component

1. 在 Editor 中选择受到约束的 GameObject。
2. 要调整 **At Rest** 或 **Offset** 字段，请在 Inspector 窗口中展开 **Constraint Settings**，取消勾选 **Lock**，然后编辑这些值。
3. 要指定 Constraint 更新哪些轴，请展开 **Constraint Settings**，然后勾选 **Freeze Axes** 中对应的属性。
4. 要向 Constraint 添加 Source GameObject：
   - 如果 **Sources** 列表中没有空槽，请单击列表底部的加号（`+`）。
   - 将要用作 Constraint Source 的 GameObject 从场景拖到 **Sources** 列表中。
5. 要移除 Source GameObject，请在 **Sources** 列表中选中它，然后单击列表底部的减号（`-`）。
6. 要重新排列 **Sources** 列表中的 Source GameObject，请单击要移动的 GameObject 左侧的双横线图标，然后将它向上或向下拖动。

   > **注意：** **Sources** 列表的顺序对 Position、Rotation 和 Scale Constraint 没有影响，但会影响 Parent 和 Aim Constraint 移动或旋转 GameObject 的方式。

7. 勾选 **Is Active** 和 **Lock**。
