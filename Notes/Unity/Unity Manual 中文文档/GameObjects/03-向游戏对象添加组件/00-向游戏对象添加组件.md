# 向游戏对象添加组件

> 原文：[Add components to GameObjects](https://docs.unity3d.com/6000.7/Documentation/Manual/unity-components.html)

Components 定义 Unity 中 GameObject 的行为和功能。向 GameObject 添加 Component，可以赋予它播放音频、响应 Physics 或运行自定义脚本等功能。
