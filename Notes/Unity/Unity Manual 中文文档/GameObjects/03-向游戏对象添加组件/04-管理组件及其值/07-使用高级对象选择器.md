# 使用 Advanced Object Picker

> 原文：[Use the Advanced Object Picker](https://docs.unity3d.com/6000.7/Documentation/Manual/search-advanced-object-picker.html)

**Advanced Object Picker** 窗口与 [Search](https://docs.unity3d.com/6000.7/Documentation/Manual/search-overview.html) 窗口类似，具有以下特性：

- 支持 Visual Query。
- 将结果列在四个 Tab 中：**All**、**Project**、**Resources** 和 **Hierarchy**。有关这些 Tab 的更多信息，请参阅 [Search Providers](https://docs.unity3d.com/6000.7/Documentation/Manual/search-filter-by-provider.html)。
- 提供三种视图：Grid、List 和 Table。
- 可以为项目显示 **Inspector** Panel，让你在将对象选作 Reference 之前编辑对象的属性。

![Advanced Object Picker 窗口，显示包含两个参数的 Visual Query，以及所选项目的 Inspector Panel。](search-advanced-object-picker.png)

## 在所有 Reference Field 中使用 Advanced Object Picker

要在 Unity Editor 的所有 Reference Field 中使用 **Advanced Object Picker**：

1. 从主菜单中选择 **Edit > Preferences**（macOS：**Unity > Settings**）。
2. 在 **Preferences** 窗口中，进入 **Search** Tab。
3. 在 **Search Engines** 下，从 **Object Selector** 下拉菜单中选择 **Advanced**。

   要恢复默认的 Object Selector，请从下拉菜单中选择 **Classic**。

4. 关闭 **Preferences** 窗口。

## 为单个属性分配 Advanced Object Picker

要将 `SearchContextAttribute` 添加到特定的对象属性，请参阅 [SearchContextAttribute](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Search.SearchContextAttribute.html)。
