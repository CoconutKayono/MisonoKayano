# 管理组件及其值

> 原文：[Manage components and their values](https://docs.unity3d.com/6000.7/Documentation/Manual/InspectorManageComponents.html)

Inspector 窗口显示附加到 GameObject 的 Component。你可以添加、移除和重新排列 Component，并编辑它们的值。

本节介绍如何编辑和管理 Component 属性。有关如何在 GameObject 中使用 Component 的更多信息，请参阅[组件简介](../../01-组件简介.md)。

| [[02-使用数值字段表达式]] | 在数值字段中使用表达式快速计算值。 |
| [[03-使用条形滑块]] | 使用 Bar Slider 编辑范围内的数值。 |
| [[04-选择颜色和颜色渐变]] | 在 Inspector 中设置颜色和 Color Gradient。 |
| [[05-使用曲线]] | 使用 Animation Curve 表示随输入变化的数值。 |
| [[06-管理引用]] | 在 Inspector 中创建和维护对象、Asset 与 Component 引用。 |
