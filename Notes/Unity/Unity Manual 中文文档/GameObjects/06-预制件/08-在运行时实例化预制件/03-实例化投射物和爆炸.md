# 实例化投射物和爆炸

> 原文：[Instantiate projectiles and explosions](https://docs.unity3d.com/6000.7/Documentation/Manual/instantiating-prefabs-projectiles.html)

可以将 Prefab 实例化为投射物，并在应用程序中使用爆炸效果销毁投射物。

下面的示例会在用户按下开火按钮时实例化投射物 Prefab。可以将该脚本添加到充当 Prefab 发射器的 GameObject 上。

## 创建投射物 Prefab Asset

1. 在 Hierarchy 中右键单击，然后选择 **3D Object > Sphere**。
2. 选中 Sphere，在 Inspector 中选择 **Add Component > Rigidbody**。Sphere 需要 Rigidbody 才能在空中飞行并检测碰撞发生的时机。
3. 将 Sphere 重命名为 `Projectile`，然后将它拖到项目的 `Assets` 文件夹中，以[创建 Prefab Asset](https://docs.unity3d.com/6000.7/Documentation/Manual/CreatingPrefabs.html#create-a-prefab-asset)。
4. 从 Hierarchy 中删除 Sphere。

可以选择为 Prefab 添加 [Texture](https://docs.unity3d.com/6000.7/Documentation/Manual/Textures.html)、调整其尺寸，或者导入其他 [Model](https://docs.unity3d.com/6000.7/Documentation/Manual/models.html) 作为投射物。

## 为投射物 Prefab Asset 添加爆炸脚本

要为投射物 Prefab 添加爆炸效果，必须先准备一个代表爆炸效果的 Prefab Asset。可以使用 [Particle System](https://docs.unity3d.com/6000.7/Documentation/Manual/ParticleSystems.html) 创建 Prefab，也可以在 [Asset Store](https://assetstore.unity.com/vfx/particles/fire-explosions) 中找到爆炸效果，并将它添加到项目的 `Assets` 文件夹中。

然后创建名为 `Projectile` 的脚本：

```csharp
using UnityEngine;

public class Projectile : MonoBehaviour
{

    public GameObject explosion;
    void Start()
    {
         // 无论是否与其他物体发生碰撞，10 秒后删除投射物。
         // 这样可以防止实例无限期留在 Scene 中。
         Destroy(gameObject,10);
    }
    void OnCollisionEnter()
    {
        // 投射物撞到物体时创建爆炸并删除投射物。
        Instantiate(explosion,transform.position,transform.rotation);
        Destroy(gameObject);
    }
}
```

该脚本会在投射物的当前位置实例化爆炸，并在投射物与其他物体发生碰撞时删除投射物 GameObject。

要使用该脚本，将它添加到投射物 Prefab Asset：

1. 选中 `Projectile` Prefab Asset，并在 [Prefab 编辑模式](https://docs.unity3d.com/6000.7/Documentation/Manual/EditingInPrefabMode.html) 中打开它。
2. 在 Inspector 中，将 `Projectile` 脚本拖到 Prefab 上。
3. 将爆炸 Prefab Asset 拖到 **Explosion** 字段中。

## 创建发射投射物的脚本

要发射投射物，需要创建一个在按下开火键时实例化投射物的脚本，并将该脚本添加到 GameObject。

创建名为 `FireProjectile` 的脚本，并写入以下内容：

```csharp
using UnityEngine;
using UnityEngine.InputSystem;

public class FireProjectile : MonoBehaviour
{
    // 只有带有 Rigidbody 的 GameObject 才能分配给 projectile。
    public Rigidbody projectile;
    // 投射物发射时的速度。
    // 这是 public 变量，因此可以在 Unity Editor 中调整。
    public float speed = 4;
    // 每帧调用一次。
    // 此方法会检查输入；如果按下 Attack 操作，则发射投射物。
    void Update()
    {
        // 检查本帧是否按下了 Attack 操作。
        // 如果按下，则在玩家位置实例化投射物并设置其速度。
        if (InputSystem.actions.FindAction("Attack").WasPressedThisFrame())
        {
            Rigidbody p = Instantiate(projectile, transform.position, transform.rotation);
            p.linearVelocity = transform.forward * speed;
        }
    }
}

```

该脚本使用 `Instantiate` 发射投射物。声明 public Prefab 变量时，变量类型可以是 GameObject，也可以是任何有效的 Component 类型，包括 Unity 内置 Component 或自定义 MonoBehaviour 脚本。

对于 Component 类型变量（例如 Rigidbody、Collider 和 Light），只能将包含该 Component 类型的 GameObject 分配给变量；`Instantiate` 函数会返回新 GameObject Instance 上该特定 Component 的引用。

## 将发射脚本添加到 GameObject

必须将脚本添加到 GameObject 才能使用它。操作步骤如下：

1. 确保 Scene 中有一个用于与投射物碰撞的地面 GameObject。如果使用空项目，可以创建 Plane GameObject：在 Hierarchy 中右键单击，然后选择 **3D Object > Plane**。
2. 创建 Cube GameObject：在 Hierarchy 中右键单击，选择 **3D Object > Cube**，然后将 Cube 放置在 Plane 上方。
3. 选中 Cube，在 Inspector 中删除 **Box Collider** Component。如果不删除该 Component，投射物会在撞到地面前先与 Cube 碰撞。
4. 将 `FireProjectile` 脚本拖到 Cube 上。
5. 将 `Projectile` Prefab Asset 拖到 Fire Projectile 脚本的 **Projectile** 字段中。
6. 进入 Play Mode，然后单击鼠标按钮。

Cube 会发射 Sphere 投射物；投射物与地面碰撞时会发生爆炸。
