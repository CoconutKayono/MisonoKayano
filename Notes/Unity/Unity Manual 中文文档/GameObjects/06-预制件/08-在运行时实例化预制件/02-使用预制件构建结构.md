# 使用预制件构建结构

> 原文：[Build a structure with prefabs](https://docs.unity3d.com/6000.7/Documentation/Manual/instantiating-prefabs-structure.html)

可以使用代码，以特定配置程序化生成 Prefab 的副本。下面的示例会创建一个由 Block Prefab Instance 组成的墙。

## 创建 Block Prefab Asset

要创建方块墙，必须先准备一个用于构建墙体的 Block Prefab Asset。

1. 在 Hierarchy 中右键单击，然后选择 **3D Object > Cube**。
2. 将 Cube 拖入 Project 窗口中的 **Assets** 文件夹。Unity 会根据 Cube 创建 Prefab Asset。
3. 将 Prefab Asset 重命名为 `Block`。
4. 从 Hierarchy 中删除原始 Cube。

## 创建实例化方块的脚本

创建一个 MonoBehaviour 脚本，并将其命名为 `Wall`。在 `Wall` 脚本中添加以下代码：

```csharp
using UnityEngine;
public class Wall : MonoBehaviour
{
   public GameObject block;
   public int width = 10;
   public int height = 4;

   void Start()
   {
       for (int y=0; y<height; ++y)
       {
           for (int x=0; x<width; ++x)
           {
               Vector3 pos = transform.position + new Vector3(x, y, 0);
               Instantiate(block, pos, Quaternion.identity);
           }
       }
   }
}
```

## 将脚本添加到空 GameObject

1. 创建一个空 GameObject。在 Hierarchy 中右键单击，然后选择 **Create Empty**。
2. 将 `Wall` 脚本添加到空 GameObject。
3. 将 `Block` Prefab Asset 拖到 **Block** 字段中。
4. 进入 Play Mode，Unity 会使用 `Block` Prefab 生成一面墙。

![由 4 行、每行 10 个方块组成的墙。Inspector 中选中了空 GameObject，并且 Block Prefab Asset 已分配给 Block 字段。](prefab-instantiate-wall.png)

由 4 行、每行 10 个方块组成的墙。Inspector 中选中了空 GameObject，并且 Block Prefab Asset 已分配给 Block 字段。

也可以使用代码将 Prefab 放置在网格或其他配置中。下面的示例会将 Cube 排列成圆形：

```csharp
using UnityEngine;
public class CircleFormation : MonoBehaviour

{
    // 在圆形队形中实例化 Prefab

    public GameObject prefab;
    public int numberOfObjects = 20;
    public float radius = 5f;

    void Start()
    {
        for (int i = 0; i < numberOfObjects; i++)
        {
            float angle = i * Mathf.PI * 2 / numberOfObjects;
            float x = Mathf.Cos(angle) * radius;
            float z = Mathf.Sin(angle) * radius;
            Vector3 pos = transform.position + new Vector3(x, 0, z);
            float angleDegrees = -angle*Mathf.Rad2Deg;
            Quaternion rot = Quaternion.Euler(0, angleDegrees, 0);
            Instantiate(prefab, pos, rot);
        }
    }
}
```

将脚本添加到空 GameObject 并进入 Play Mode 后，Unity 会生成以下排列的 Cube：
