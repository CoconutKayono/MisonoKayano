# 将预制件实例还原为 GameObject

> 原文：[Revert a prefab instance to a GameObject](https://docs.unity3d.com/6000.7/Documentation/Manual/UnpackingPrefabInstances.html)

如果希望将 Prefab Instance 转换为普通 GameObject，可以使用 **Unpack** 命令。Unity 会将 Prefab Instance 解包为 GameObject，同时保留原始 Prefab Asset。

## 使用 Unpack 将 Prefab Instance 转换为 GameObject

1. 在 Hierarchy 中右键单击 Prefab Instance。
2. 选择 **Prefab > Unpack**。

Unity 会将 Prefab Instance 转换为不再与原始 Prefab Asset 保持任何连接的 GameObject。同时，Unity 会将 Prefab Instance 上的所有 Override 保存到该 GameObject。

**Unpack** 命令只会解包选中的 Prefab Instance，并产生以下效果：

- 如果解包包含 Nested Prefab 的 Prefab Instance，Nested Prefab 会作为 Prefab Instance 保留在新的 GameObject 中。
- 如果解包 Prefab Variant，根对象会变成该 Variant 的 Base Prefab Asset 的新 Prefab Instance。Unity 会将 Variant 与原始 Prefab Asset 不同的所有属性转换为 Override。

要完全解包 Prefab Instance 及其 Nested Prefab，或将 Variant 完全解包为其基础 GameObject 集合，请选择 **Prefab > Unpack Completely**。
