# 嵌套预制件

> 原文：[Nest prefab instances in other prefabs](https://docs.unity3d.com/6000.7/Documentation/Manual/NestedPrefabs.html)

可以将 Prefab Instance 包含在其他 Prefab 中。包含在其他 Prefab 中的 Prefab Instance 称为 Nested Prefab。Nested Prefab 会保留与自身 Prefab Asset 的连接，同时成为另一个 Prefab Asset 的一部分。

可以在 Prefab Editing Mode 中，或从 Hierarchy 视图中添加 Nested Prefab。

## 在 Prefab Editing Mode 中添加 Nested Prefab

1. 选择要编辑的 Prefab，并打开 Prefab Editing Mode。
2. 将另一个 Prefab 拖入 Hierarchy 或 Scene 视图。也可以为这些 Prefab Instance 添加 Override。

## 从 Hierarchy 添加 Nested Prefab

可以在 Hierarchy 视图中，将 Prefab Instance 添加为另一个 Prefab 的子对象：

1. 在 Hierarchy 中，选择要编辑的 Prefab 旁边的下拉箭头。
2. 将 Project 窗口中的 Prefab 拖入该 Prefab 的层级中。

![带有嵌套 Weapon Blaster Prefab 的 Enemy Bot Variant，以及最近添加的 Banana Prefab Override。](prefabs-nested-hierarchy.png)

Nested Prefab 会作为 Parent Prefab Asset 的 Override 应用，并以绿色加号图标表示。也可以选择将这些 Override 修改永久应用到 Parent Prefab Asset。有关更多信息，请参阅[将 Override 应用到 Prefab Asset](https://docs.unity3d.com/6000.7/Documentation/Manual/PrefabInstanceOverrides.html#apply-overrides-to-the-prefab-asset)。
