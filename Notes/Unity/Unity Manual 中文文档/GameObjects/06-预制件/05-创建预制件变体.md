# 创建预制件变体

> 原文：[Create variations of prefabs](https://docs.unity3d.com/6000.7/Documentation/Manual/PrefabVariants.html)

如果希望以不同设置和配置复用 Prefab，Unity 会将其保存为 Prefab Variant。例如，可以使用 Prefab Variant 创建不同类型的敌人角色：让这些角色基于同一个基础 Prefab，但修改速度、添加不同对象或调整音效。

Prefab Variant 会从 Base Prefab 继承属性。Variant 中的 Override 优先于 Base Prefab 的值。Variant 可以使用任意 Prefab 作为 Base，包括其他 Variant。

在 Unity Editor 中，Prefab Variant 使用带有一条斜线面的蓝色 Cube 图标表示，以区别于 Prefab Instance。

![Enemy HoverBot Prefab，以及在 Hierarchy 窗口中查看的该 Prefab Variant。](prefab-variant-icon.png)

## 创建 Prefab Variant

可以在 Project 窗口或 Hierarchy 视图中创建 Prefab Variant。

### 从 Project 窗口创建 Prefab Variant

1. 在 Project 窗口中找到 Prefab。
2. 右键单击 Prefab，选择 **Create > Prefab Variant**。

Unity 会在原始 Prefab 所在的同一文件夹中创建 Variant。之后可以编辑 Prefab Variant，调整并覆盖它的设置。

### 从 Hierarchy 视图创建 Prefab Variant

1. 选择要创建 Variant 的 Prefab Instance。
2. 将 Prefab Instance 拖入 Project 窗口中的文件夹。

Unity 会显示对话框，询问你要创建新的 Prefab，还是创建 Prefab Variant。选择 **Prefab Variant** 后，Unity 会根据该 Prefab Instance 创建 Prefab Variant，并将 Instance 上的所有 Override 应用到新 Prefab Variant。之后可以编辑 Prefab Variant，调整并覆盖它的设置。

## Prefab Variant 层级

选择 Prefab Variant 时，Inspector 会显示它的 Parent Prefab，让你找到 Prefab Variant 的来源。也可以选择菜单按钮查看更多 Variant 详细信息。该信息会显示 Variant 的根 Prefab Asset、继承自该 Variant 的所有子 Prefab Variant，以及该 Variant 包含的 Override 数量。

![选中的 Prefab Variant Inspector 窗口，其中包含指向 Variant Parent 的链接。菜单下拉列表显示继承自此 Variant 的 Prefab 详细信息，以及此 Variant 所继承的 Prefab 详细信息。](prefab-variant-family.png)

## 编辑 Prefab Variant

在 Prefab Editing Mode 中打开 Prefab Variant 时，Variant 的根对象会显示为一个 Prefab Instance，代表 Variant 所继承的 Base Prefab。对 Prefab Variant 所做的任何编辑都会覆盖此 Base Prefab。

也可以使用 Override 修改属性值、添加或移除 Component，以及添加或移除子 GameObject。

每次编辑 Prefab Variant 时，Unity 都会将修改作为 Override 应用。要查看应用到 Variant 的 Override：

1. 在 Prefab Editing Mode 中打开 Prefab Variant。
2. 选择根 Prefab Instance。
3. 在 Inspector 的 **Prefabs** 下，选择 **Overrides** 下拉菜单。

该菜单会显示应用到 Variant 的所有 Override。选择 **Revert All** 可重置对 Prefab Variant 所做的全部修改；选择 **Apply all to Prefab Variant parent** 可将修改应用到 Parent Prefab Asset。

![Prefab Variant Inspector，其中列出了已应用的 Override。](prefab-variant-overrides.png)
