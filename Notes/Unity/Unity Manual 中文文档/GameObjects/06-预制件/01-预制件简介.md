# 预制件简介

> 原文：[Introduction to prefabs](https://docs.unity3d.com/6000.7/Documentation/Manual/prefabs-introduction.html)

你可以使用 Prefab 在 Scene 中的多个位置，或项目中的不同 Scene 之间复用 GameObject 配置。Prefab 系统会让 GameObject 的所有副本保持同步，因此当你修改 Prefab Asset 时，Unity 会自动更新该 Prefab 的所有 Instance。这样无需逐个编辑副本，就可以同时更新多个 GameObject。

![Project 窗口中的一组 Prefab。](prefabs-overview.png)

Prefab 的常见用途包括：

- 环境 Asset：例如在关卡中多次使用的特定树木类型。
- Non-player Character（NPC）：例如出现在多个关卡中的机器人，并通过 Override 设置不同的移动速度或声音。
- 投射物：例如海盗船的大炮每次开火时实例化一个炮弹 Prefab。
- 主要可玩角色：可以将角色 Prefab 放置在游戏每个 Scene 的起始位置。

Prefab 还适用于在运行时实例化开始时不在 Scene 中的 GameObject。例如，可以在游戏过程中生成游戏物品、特殊效果、投射物或 NPC。

## 使用 Prefab

要使用 Prefab，请创建 Prefab Asset，然后在 Scene 中使用它创建 Prefab Instance。

可以将 Prefab 嵌套在其他 Prefab 中，以创建复杂的对象层级，并在多个层级中编辑这些对象。不过，并非所有 Prefab Instance 都需要完全相同。如果希望某些 Instance 与其他 Instance 不同，可以覆盖单个 Prefab Instance 的设置。也可以创建 Prefab Variant，将一组 Override 组织为 Prefab 的不同变体。

如果使用 Prefab Override，理解 Prefab 的 Source 与 Original Source 之间的区别会很有帮助，这样才能确定 Prefab 的哪些部分被覆盖：

- **Source**：继承链中定义该对象的最近 Prefab Asset。
- **Original Source**：最初引入该对象的根 Prefab Asset。

例如，如果创建名为 `Light` 的 Prefab Asset 并在 Scene 中使用它，其对应的 Source 如下：

| Prefab 类型 | Source | Original Source |
| --- | --- | --- |
| Prefab Instance | Original Light Prefab Asset。 | Original Light Prefab Asset。 |
| Prefab Variant | Light Prefab Asset 的 Variant。 | Original Light Prefab Asset。 |
| Nested Prefab | 嵌套的 Light Prefab Asset。 | 嵌套的 Light Prefab Asset。 |

可以使用 [`PrefabUtility.GetCorrespondingObjectFromSource`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/PrefabUtility.GetCorrespondingObjectFromSource.html) 方法获取 Prefab 的 Source，使用 [`GetCorrespondingObjectFromOriginalSource`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/PrefabUtility.GetCorrespondingObjectFromOriginalSource.html) 方法获取 Prefab 的 Original Source。

## Prefab Inspector 预览

选择 Prefab 时，其 Inspector 窗口包含 **Asset Preview** Panel，用于显示 Prefab 的预览。如果 Prefab 小于 8 MB，预览具有交互性，你可以在 Panel 中旋转 Prefab。

如果 Prefab 大于 8 MB，Asset Preview 默认显示静态图片。要查看较大 Prefab 的交互式预览，请单击 **Asset Preview** Panel 内的任意位置。
