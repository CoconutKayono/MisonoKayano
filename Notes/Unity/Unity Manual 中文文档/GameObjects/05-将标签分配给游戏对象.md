# 将标签分配给 GameObject

> 原文：[Assign tags to GameObjects](https://docs.unity3d.com/6000.7/Documentation/Manual/Tags.html)

Tag 是可以分配给一个或多个 GameObject 的引用名称。例如，可以为玩家控制的角色定义 `Player` Tag，为非玩家控制的角色定义 `Enemy` Tag，也可以使用 `Collectable` Tag 标记 Scene 中玩家可以收集的物品。Tag 可以使用任意单词，也可以使用短语；但如果名称较长，可能需要扩大 Inspector 才能看到 Tag 的完整名称。一个 GameObject 只能分配一个 Tag。

Tag 可以帮助你出于脚本目的识别 GameObject。使用 Tag 后，不必通过拖放将 GameObject 手动添加到脚本的暴露属性中，因此在多个 GameObject 中复用相同脚本代码时可以节省时间。

Tag 也适用于 Collider 控制脚本中的触发器逻辑。例如，脚本可以使用 Tag 判断玩家是否与敌人、道具或可收集物发生交互。

可以使用 [`GameObject.FindWithTag`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/GameObject.FindWithTag.html) 函数查找包含指定 Tag 的 GameObject。下面的示例使用 `GameObject.FindWithTag()`，将 `respawnPrefab` 实例化到带有 `Respawn` Tag 的 GameObject 的位置，并使用其旋转。

```csharp
using UnityEngine;
using System.Collections;

public class Example : MonoBehaviour
{
    public GameObject respawnPrefab;
    public GameObject respawn;

    void Start()
    {
        if (respawn == null)
            respawn = GameObject.FindWithTag("Respawn");

        Instantiate(respawnPrefab, respawn.transform.position, respawn.transform.rotation) as GameObject;
    }
}
```

## 创建新 Tag

Inspector 会在 GameObject 名称下方显示 **Tag** 和 **Layer** 下拉菜单。

要创建新 Tag，请选择 **Add Tag…**。这会在 Inspector 中打开 **Tag and Layer Manager**。Tag 命名后，之后不能重命名。

Layer 与 Tag 类似，但用于定义 Unity 如何在 Scene 中渲染 GameObject。有关更多信息，请参阅[层](https://docs.unity3d.com/6000.7/Documentation/Manual/Layers.html)文档。

## 应用 Tag

Inspector 会在 GameObject 名称下方显示 **Tag** 和 **Layer** 下拉菜单。要将已有 Tag 应用到 GameObject，请打开 **Tag** 下拉菜单并选择要应用的 Tag。此时 GameObject 就与该 Tag 关联。

## 了解内置 Tag

Editor 包含以下不会出现在 Tag Manager 中的内置 Tag：

- `Untagged`
- `Respawn`
- `Finish`
- `EditorOnly`
- `MainCamera`
- `Player`
- `GameController`

其中一些内置 Tag（例如 `MainCamera` 和 `EditorOnly`）具有特殊功能：

- Editor 会在内部缓存带有 `MainCamera` Tag 的 GameObject。当你访问 [`Camera.main`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Camera-main.html) 时，Editor 会从缓存中返回第一个有效结果。
- Scene 中带有 `EditorOnly` Tag 的 GameObject 会在构建游戏时销毁。带有 `EditorOnly` Tag 的 GameObject 的所有子 GameObject 也会在构建游戏时销毁。
