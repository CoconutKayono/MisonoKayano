# Unity 基础类型

> 原文：[Fundamental Unity types](https://docs.unity3d.com/6000.7/Documentation/Manual/fundamental-unity-types.html)

Unity 提供了一些对脚本特别重要的内置类。自定义类型可以继承这些类，从而接入 Editor 和 Engine 的功能。理解这些类型、它们的行为以及为什么应该继承或使用它们，对编写 Unity 脚本很有帮助。

完整的内置类和所有成员列表，请参阅 Unity Scripting API 参考。

| 页面 | 说明 |
| --- | --- |
| [[01-Object类]] | 了解 `UnityEngine.Object`，它是 Editor 可引用对象的基础类。 |
| [[02-MonoBehaviour类]] | 继承 `MonoBehaviour`，使脚本成为 GameObject Component。 |
| [[03-ScriptableObject类]] | 使用 `ScriptableObject` 保存独立于 GameObject 的数据。 |
| [[04-Unity属性]] | 使用 Unity 专用 C# Attribute 定义代码的特殊行为。 |
| [[05-从InstanceID迁移到EntityId]] | 将旧的 InstanceID 使用方式迁移到 EntityId。 |
