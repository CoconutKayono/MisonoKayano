# 模拟卡顿

> 原文：[Simulate hitches for testing](https://docs.unity3d.com/6000.7/Documentation/Manual/time-simulate-hitches.html)

主动引入卡顿是测试游戏如何处理性能问题的常用方法，例如延迟尖峰、帧率下降、画面卡顿或压力下 UI 响应性下降。

下面的简单 `MonoBehaviour` 脚本可以附加到 Scene 中的任意 GameObject。它会定期阻塞主线程，模拟卡顿或 Frame Time 尖峰。你可以调整卡顿的频率和持续时间：

```csharp
using UnityEngine;
using Unity.Profiling;

public class HitchSimulator : MonoBehaviour
{
    static readonly ProfilerMarker k_HitchSimulatorMarker =
        new ProfilerMarker("[HitchSimulator] CauseHitch() introducing artificial hitches");

    [Tooltip("How often (in seconds) to cause a hitch.")]
    public float hitchInterval = 5f;

    [Tooltip("How long (in milliseconds) each hitch should last.")]
    public int hitchDurationMs = 200;

    private float _nextHitchTime = 0f;

    void Update()
    {
        if (Time.time >= _nextHitchTime)
        {
            Debug.LogWarning(
                $"[HitchSimulator] Causing a hitch for {hitchDurationMs} ms at {Time.time:F2}s");

            CauseHitch(hitchDurationMs);
            _nextHitchTime = Time.time + hitchInterval;
        }
    }

    void CauseHitch(int durationMs)
    {
        // 添加明确的 Profiler Marker，避免把测试卡顿误认为实际问题。
        k_HitchSimulatorMarker.Auto();
        float start = Time.realtimeSinceStartup;

        // 忙等待指定时长。
        while ((Time.realtimeSinceStartup - start) < durationMs / 1000f)
        {
            // Just spin
        }
    }
}
```

## 使用脚本

1. 将脚本复制到名为 `HitchSimulator.cs` 的新 C# 文件中。
2. 将它附加到 Scene 中任意 Active 的 GameObject。
3. 在 Inspector 中设置参数：
   - `hitchInterval`：卡顿发生的间隔，默认 5 秒。
   - `hitchDurationMs`：每次卡顿的持续时间，默认 200 毫秒。
4. 进入 Play Mode，在 Profiler 中或通过画面卡顿观察人为制造的 Frame Hitch。

> [!NOTE]
> 此脚本会阻塞主线程，模拟繁重计算造成的真实 Lag Spike，而不只是人为降低速度。使用很大的值可能导致 Editor 无响应。也可以改为通过按键或随机时间触发卡顿，以进行更丰富的测试。
