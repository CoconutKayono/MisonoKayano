# 创建脚本

> 原文：[Creating scripts](https://docs.unity3d.com/6000.7/Documentation/Manual/creating-scripts.html)

脚本允许你使用 C# 代码自定义和扩展应用程序的功能。继承 Unity 内置 `MonoBehaviour` 类的脚本可以创建自定义 Component，从而控制 `GameObject` 的行为；继承 `ScriptableObject` 的脚本可以在应用程序中高效存储大量数据。你也可以从空白 C# 脚本开始，编写自己的非 Unity 类。

与大多数其他 Asset 不同，脚本通常直接在 Unity 中创建。

## 创建脚本

创建脚本的方式如下：

1. 在主菜单中选择 **Assets > Create > Scripting**，然后选择要创建的脚本类型。
2. 或者，在 Project 窗口工具栏中打开 Create 菜单（加号图标），选择 **Scripting**，再选择要创建的脚本类型。

新脚本会创建在 Project 窗口中当前选中的文件夹内。Unity 会选中脚本文件名，提示你修改名称。命名脚本时需要注意的事项，请参阅 [[03-命名脚本]]。
