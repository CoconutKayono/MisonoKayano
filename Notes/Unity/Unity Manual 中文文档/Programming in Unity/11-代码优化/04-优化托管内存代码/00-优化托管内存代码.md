# 优化托管内存代码

> 原文：[Optimizing your code for managed memory](https://docs.unity3d.com/6000.7/Documentation/Manual/performance-optimizing-code-managed-memory.html)

C# 的自动内存管理降低了内存泄漏和其他编程错误的风险。相比之下，在 C++ 等其他编程语言中，你必须手动跟踪并释放所分配的全部内存。

自动内存管理让你能够快速编写代码，并减少错误。不过，这种便利可能会影响性能。为了优化代码性能，你必须避免应用程序频繁触发[垃圾回收器](https://docs.unity3d.com/6000.7/Documentation/Manual/performance-garbage-collector.html)的情况。本节概述了一些会影响应用程序何时触发垃圾回收器的常见问题和工作流程。
