# 使用 Job System 编写多线程代码

> 原文：[Write multithreaded code with the job system](https://docs.unity3d.com/6000.7/Documentation/Manual/job-system.html)

Job System 让你能够编写简单且安全的多线程代码，使应用程序可以使用所有可用的 CPU Core 来执行代码。这有助于提升应用程序的性能。
