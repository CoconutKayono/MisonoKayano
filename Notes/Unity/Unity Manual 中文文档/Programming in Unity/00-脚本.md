# Unity 编程

> 原文：[Programming in Unity](https://docs.unity3d.com/6000.7/Documentation/Manual/scripting.html)

在 Unity 中进行编程，是指通过代码而不是单纯依靠 Unity Editor UI 来编写项目功能。直接使用公开的 Unity API，可以获得比 Editor UI 更细致的控制和更高的自定义能力。

本节不涉及具体编程语言的系统教学。要学习 Unity 编程，可以参考 Unity Learn，以及相关书籍、教程和其他学习资源。

本目录按 Unity Manual 的原文顺序整理 Unity 编程相关内容。具体 API 成员请结合 Unity Scripting API 参考阅读。
