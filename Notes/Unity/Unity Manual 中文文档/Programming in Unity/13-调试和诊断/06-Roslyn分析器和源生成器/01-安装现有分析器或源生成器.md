# 安装和使用现有分析器或源代码生成器

> 原文：[Install and use an existing analyzer or source generator](https://docs.unity3d.com/6000.7/Documentation/Manual/install-existing-analyzer.html)

下面的示例使用 [ErrorProne.NET.CoreAnalyzers](https://www.nuget.org/packages/ErrorProne.NET.CoreAnalyzers/) 库，演示如何从 NuGet 安装代码分析器或源代码生成器：

1. 单击 **Download package** 按钮，将该库下载为 `.zip` 文件。

2. 解压 `.zip` 文件的内容。

3. 在解压后的文件夹中，找到包含分析器的 `.dll` 文件。在本例中，进入 **`errorprone.net.coreanalyzers<version-number>\analyzers\dotnet\cs`**。所需文件应位于此文件夹中，名称分别为 `ErrorProne.NET.Core.dll`、`ErrorProne.Net.CoreAnalyzers.dll` 和 `RuntimeContracts.dll`。

4. 将这些文件移动到 Unity 项目中的 `Assets` 文件夹，或移动到 `Assets` 文件夹内的任意嵌套文件夹。你可以在 Unity 中选择 **Assets > Import New Asset**，分别选择这三个文件的 `.dll`；也可以通过设备的文件浏览器，将它们复制到项目的 `Assets` 文件夹中。

5. 在 Unity 的 **Asset Browser** 中单击 `.dll` 文件，打开 **[Plugin Inspector](https://docs.unity3d.com/6000.7/Documentation/Manual/plug-in-inspector.html)** 窗口。

6. 在 **Select platforms for plugin** 标题下，禁用 **Any Platform**。

7. 在 **Include Platforms** 标题下，禁用 **Editor** 和 **Standalone**。

8. 在 Plugin Inspector 窗口的 **Asset Labels** 标题下，单击蓝色标签图标，打开 **Asset Labels** 子菜单。

9. 创建并分配一个名为 `RoslynAnalyzer` 的新标签。具体来说，在 **Asset Labels** 子菜单的文本输入框中输入 `RoslynAnalyzer`，然后按 **Return**。该标签必须与示例完全一致，并且区分大小写。为第一个分析器创建标签后，它会出现在 **Asset Labels** 子菜单的可用标签列表中。你可以在菜单中单击该标签名称，将它分配给其他分析器。

Unity 会识别 `RoslynAnalyzer` 标签，并将带有该标签的资源视为 Roslyn analyzer 或 source generator。当你为分析器分配该标签时，Unity 会重新编译分析器作用范围内的脚本，并根据分析器中的规则分析这些脚本中的代码。

与分析器处于同一个程序集定义中的所有脚本，都属于该分析器的作用范围。对于位于 `Assets` 文件夹根目录的分析器，Unity 会将项目中的所有文件都视为作用范围内的文件。有关作用范围的更多信息，请参阅 [Analyzer scope and rule set files](https://docs.unity3d.com/6000.7/Documentation/Manual/analyzer-scope-and-diagnostics.html)。

要测试分析器是否正常工作，请按照下面的示例操作。如果分析器安装正确，ErrorProne.NET analyzer 会在分析示例代码时发出警告。

创建一个名为 `RethrowError.cs` 的新脚本文件。将以下代码复制到脚本中，然后保存文件：

```csharp
using System;
using UnityEngine;

public class RethrowError : MonoBehaviour
{
    void Update()
    {
        try
        {
            DoSomethingInteresting();
        }
        catch (Exception e)
        {
            Debug.Log(e.Message);
            throw e;
        }
    }

    private void DoSomethingInteresting()
    {
        throw new System.NotImplementedException();
    }
}
```

保存文件时，Unity 会重新编译脚本，并在脚本代码上运行所有适用的分析器。正确安装 ErrorProne.NET analyzer 后，它会在 Console 窗口中针对上述代码发出以下警告：

```text
Assets\RethrowError.cs(14,23): warning EPC12: Suspicious exception handling: only e.Message is observed in exception block.
```

```text
Assets\RethrowError.cs(15,19): warning ERP021: Incorrect exception propagation. Use throw; instead.
```
