# 使用数学编程

> 原文：[Programming with math](https://docs.unity3d.com/6000.7/Documentation/Manual/programming-math.html)

Unity 提供了多个游戏编程中常用的数学运算 API，包括常见数学函数、随机数，以及 Vector、Matrix 和 Quaternion 等系统。

| 页面 | 说明 |
| --- | --- |
| [[01-Unity数学编程简介]] | 了解 Unity 提供的不同数学 API，并比较它们之间的差异。 |
| [[00-Unity Engine数学API]] | 使用 `UnityEngine` Namespace 中的数学 API，访问常见数学运算，包括三角函数、对数函数、随机数生成，以及 Vector、Matrix 和 Quaternion 的操作。 |
| [[03-Unity Mathematics API]] | 使用 `Unity.Mathematics` Namespace 中支持 SIMD 且可由 Burst 编译的数学 API，访问常见数学运算，包括三角函数、对数函数、随机数生成，以及 Vector、Matrix 和 Quaternion 的操作。 |
