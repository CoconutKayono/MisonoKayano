# 使用 Coroutine 跨帧分配任务

> 原文：[Split tasks across frames with coroutines](https://docs.unity3d.com/6000.7/Documentation/Manual/coroutines-section.html)

Coroutine 是可以暂停执行并在之后恢复的方法。在 Unity 中，这意味着 Coroutine 可以在一帧开始运行，然后在另一帧恢复，从而将任务分摊到多个帧中执行。
