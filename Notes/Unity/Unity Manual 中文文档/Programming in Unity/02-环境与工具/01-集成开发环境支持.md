# 集成开发环境支持

> 原文：[Integrated development environment (IDE) support](https://docs.unity3d.com/6000.7/Documentation/Manual/scripting-ide-support.html)

集成开发环境（IDE）是集成软件开发工具的应用程序，通常包括代码编辑器、代码补全、代码分析与诊断、测试运行和调试功能。Unity 支持以下 C# IDE：

- Visual Studio
- Visual Studio Code
- JetBrains Rider

在 Windows 和 macOS 上新安装 Unity Editor 时，通常会默认安装该平台对应的 IDE。也可以为已有的 Unity 安装添加 IDE 模块。更多信息请参阅 Unity Editor 的模块安装说明。

## External Script Editor 设置

Preferences 窗口中的 **External Script Editor** 设置决定 Unity 使用哪个 IDE 打开 C# 脚本文件。Unity 会自动将安装时附带的 IDE 设置为默认 External Script Editor。要修改此设置，请选择 **Edit > Preferences**（macOS：**Unity > Settings**）> **External Tools** > **External Script Editor**。

如果只需要打开、查看或简单编辑 C# 源文件，这项设置就足够了。完整的 IDE 体验（包括代码分析和调试）通常还需要额外的 Plug-in 或 Extension。

## Visual Studio（Windows）

Visual Studio 是 Windows 上 Unity 的默认 IDE。条件允许时，建议始终使用最新版本。新安装的 Unity Editor 通常会默认包含 Visual Studio Community 以及本节所需的其他调试组件；如果使用已有的 Visual Studio 或 Unity Editor，可能需要手动安装或配置这些组件。

### Visual Studio 调试配置

要在 Visual Studio 中完整调试 Unity C# 代码，需要具备：

- Visual Studio IDE：**Visual Studio Tools for Unity**。
- Unity Editor：**Unity Visual Studio Editor** Package（Unity Editor 的 Engineering 功能集包含此 Package）。
- 将 Visual Studio 设置为 External Script Editor。

关于 Unity Editor 的调试功能，请参阅 [[01-在Unity中调试CSharp代码]]；关于使用 Visual Studio Tools for Unity，请参阅 Microsoft 的相关文档。

### Code Analyzer

Unity 使用 Visual Studio 的 C# Compiler 编译脚本。使用 Visual Studio Editor Package 配合 Visual Studio 时，Unity 和 Visual Studio 都会显示脚本错误的详细信息。

由于 Unity 与 Visual Studio 编译用户代码的方式不同，`Microsoft.Unity.Analyzers.dll` 不会自动配置到 Unity Editor。要配置它，请按照 [[01-安装现有分析器或源生成器]] 中的说明，从 Microsoft.Unity.Analyzers NuGet Repository 安装并使用 Analyzer。

### Project 与 Solution 文件

Unity 会自动创建并维护 Visual Studio 的 `.sln` 和 `.csproj` 文件。你可以控制 Unity 是否为项目中的额外 Package 生成 `.csproj` 文件。相关设置取决于 Visual Studio Editor Package。

## Visual Studio Code（Windows、macOS、Linux）

Visual Studio Code 是 macOS 上 Unity 项目的默认 IDE。条件允许时，建议始终使用最新版本。新安装的 Unity Editor 通常会默认包含 Visual Studio Code 以及本节所需的调试组件；如果使用已有的 VS Code 或 Unity Editor，可能需要手动安装或配置这些组件。

### VS Code 调试配置

要在 VS Code 中完整调试 Unity C# 代码，需要具备：

- Visual Studio Code IDE：**C# for Visual Studio Code** Extension、**C# Dev Kit for Visual Studio Code** Extension、**Unity for Visual Studio Code** Extension。
- Unity Editor：`Unity Visual Studio Editor` Package 2.0.20 或更高版本（Unity Editor 的 Engineering 功能集包含此 Package）。
- 将 Visual Studio Code 设置为 External Script Editor。

> [!NOTE]
> Unity Visual Studio Code Editor Package `com.unity.ide.vscode` 已不再受支持，不应继续使用。Visual Studio Editor Package `com.unity.ide.visualstudio` 现在同时支持 Visual Studio Code 和 Visual Studio。

关于 Unity Editor 的调试功能，请参阅 [[01-在Unity中调试CSharp代码]]；关于 VS Code 与 Unity 的使用方法，请参阅 VS Code 的 Unity 开发文档。

## JetBrains Rider（Windows、macOS、Linux）

JetBrains Rider 是一款提供完整 C# 语言和调试支持的 C# IDE。条件允许时，建议始终使用最新版本。

### Rider 调试配置

要在 Rider 中完整调试 Unity C# 代码，需要具备：

- Unity Editor：**Unity JetBrains Rider** Package（Unity Editor 的 Engineering 功能集包含此 Package）。
- 将 Rider 设置为 External Script Editor。

关于 Unity Editor 的调试功能，请参阅 [[01-在Unity中调试CSharp代码]]；关于 JetBrains Rider 与 Unity 的使用方法，请参阅 Rider for Unity 文档。
