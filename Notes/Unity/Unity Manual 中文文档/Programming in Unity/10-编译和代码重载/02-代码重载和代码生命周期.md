# 代码重载和代码生命周期

> 原文：[Code and scene reload on entering Play mode](https://docs.unity3d.com/6000.7/Documentation/Manual/code-reloading-editor.html)

在 Edit mode 中编写应用并切换到 Play mode 预览 Runtime 行为，是 Unity Editor 迭代开发的核心功能。默认情况下，Editor 会在从 Edit mode 切换到 Play mode 时重载 Scene，但进入 Play mode 时默认不会重载代码；可以配置 Editor 执行代码重载。

理解 Unity 会重载什么、为什么重载、何时重载，以及如何配置重载行为，有助于在开发迭代时间与 Play mode 对构建应用性能的还原程度之间做出取舍。
