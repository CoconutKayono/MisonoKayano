# 测试条件编译

> 原文：[Test conditional compilation](https://docs.unity3d.com/6000.7/Documentation/Manual/test-conditional-compilation.html)

以下示例展示了如何测试条件编译的代码。它还会根据为目标构建选择的平台打印消息。

<a name="Sample"></a>

## 示例代码

```csharp
  using UnityEngine;
  using System.Collections;
  public class PlatformDefines : MonoBehaviour {
  void Start () {

    #if UNITY_EDITOR
      Debug.Log("Unity Editor");
    #endif

    #if UNITY_IOS
      Debug.Log("Unity iOS");
    #endif

    #if UNITY_STANDALONE_OSX
        Debug.Log("Standalone OSX");
    #endif

    #if UNITY_STANDALONE_WIN
      Debug.Log("Standalone Windows");
    #endif

  }          
  } 
```

## 测试说明

1. 打开 **Build Profiles** 窗口（菜单：**File** > **Build Profiles**）。
2. 检查要测试代码的平台是否为活动平台配置文件。如果不是，请选择首选平台并点击 **Switch Profile**。
3. 创建一个[脚本](https://docs.unity3d.com/6000.7/Documentation/Manual/creating-scripts.html)，然后复制粘贴[示例代码](#示例代码)。
4. 在 [Game view](https://docs.unity3d.com/6000.7/Documentation/Manual/GameView.html) 工具栏中，点击 Play 按钮进入 Play 模式。检查 Unity Console 中是否出现与所选平台相关的消息，以确认代码正常工作。例如，如果选择 iOS，Console 中会出现 `Unity Editor` 和 `Unity iOS` 消息。
