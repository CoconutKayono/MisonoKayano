# 将整数值约束到范围内

> 原文：[Constrain integer values to a range](https://docs.unity3d.com/6000.7/Documentation/Manual/burst/optimization-assumerange.html)

使用 `AssumeRange` 属性告诉 Burst 某个标量整数位于指定的受限范围内。如果 Burst 获得了这个信息，就可以提高应用程序的性能。示例代码如下：

```csharp
[return:AssumeRange(0u, 13u)]
static uint WithConstrainedRange([AssumeRange(0, 26)] int x)
{
    return (uint)x / 2u;
}
```

此示例告诉 Burst：

- 变量 `x` 位于闭区间 `[0..26]`，更直白地说就是 `x >= 0 && x <= 26`。
- `WithConstrainedRange` 的返回值位于闭区间 `[0..13]`，更直白地说就是返回值 `>= 0 && <= 13`。

Burst 使用这些假设来生成更好的代码。不过存在以下限制：

- 只能将其放在标量整数（有符号或无符号）类型上。
- 范围参数的类型必须与被标注的类型匹配。

Burst 能推断 `NativeArray` 和 `NativeSlice` 的 `.Length` 属性始终返回非负整数：

```csharp
static bool IsLengthNegative(NativeArray<float> na)
{
    // Burst 总会将此表达式替换为常量 false
    return na.Length < 0;
}
```

例如，如果有如下容器：

```csharp
struct MyContainer
{
    public int Length;

    // 其他数据……
}
```

下面的示例说明如何告诉 Burst，`Length` 始终为正整数：

```csharp
struct MyContainer
{
    private int _length;

    [return: AssumeRange(0, int.MaxValue)]
    private int LengthGetter()
    {
        return _length;
    }

    public int Length
    {
        get => LengthGetter();
        set => _length = value;
    }

    // 其他数据……
}
```
