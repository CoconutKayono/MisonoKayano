# 检查编译时约束

> 原文：[Check for compile-time constraints](https://docs.unity3d.com/6000.7/Documentation/Manual/burst/optimization-constant.html)

使用 `IsConstantExpression` intrinsic 检查给定表达式是否为编译时常量：

```csharp
using static Unity.Burst.CompilerServices.Constant;

var somethingWhichWillBeConstantFolded = math.pow(42.0f, 42.0f);

if (IsConstantExpression(somethingWhichWillBeConstantFolded))
{
    // Burst 知道 somethingWhichWillBeConstantFolded 是编译时常量
}
```

这对于检查复杂表达式是否总会被常量折叠很有用，也可以针对已知常量值实现优化。例如，要为整数幂实现一个类似 `pow` 的函数：

```csharp
using static Unity.Burst.CompilerServices.Constant;

public static float MyAwesomePow(float f, int i)
{
    if (IsConstantExpression(i) && (2 == i))
    {
        return f * f;
    }
    else
    {
        return math.pow(f, (float)i);
    }
}
```

`IsConstantExpression` 检查意味着：如果 `i` 不是常量，Burst 总会移除该分支，因为 if 条件为假。因此，当 `i` 是常量且等于 2 时，可以使用更高效的简单乘法。

`IsConstantExpression` 的结果有意依赖于已执行的优化。因此，函数是否内联会改变结果。例如在前面的例子中，单独看 `IsConstantExpression(i)` 会得到假，因为 `i` 是函数参数而不是常量；但是，如果 `MyAwesomePow` 被内联，并且传入了常量 `i`，它就会计算为真。如果 `MyAwesomePow` 最终没有内联，`IsConstantExpression(i)` 仍为假。

**注意**：常量折叠只在执行优化时发生。如果禁用了优化，该 intrinsic 会返回 `false`。
