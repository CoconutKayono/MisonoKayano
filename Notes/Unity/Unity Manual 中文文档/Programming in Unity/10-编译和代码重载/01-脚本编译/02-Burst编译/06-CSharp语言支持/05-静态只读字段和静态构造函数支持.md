# 静态只读字段和静态构造函数支持

> 原文：[Static read-only fields and static constructor support](https://docs.unity3d.com/6000.7/Documentation/Manual/burst/csharp-static-read-only-support.html)

Burst 会在编译时计算所有静态字段和静态构造函数。对于给定结构体，它会一起计算该结构体的所有静态字段和静态构造函数。

Burst 只支持静态只读字段。在 Burst 编译的结构体中使用非只读静态字段会导致编译错误。

如果 Burst 无法计算某个静态字段或静态构造函数，则该结构体的所有字段和构造函数都会计算失败。

当编译时计算失败时，Burst 会退回到将所有静态初始化代码编译为一个初始化函数，并在运行时调用该函数一次。这意味着代码本身必须兼容 Burst；如果编译时计算失败且代码不兼容 Burst，最终仍会编译失败。

例外情况是，静态只读数组字段有有限的初始化支持，只要它们通过数组构造函数或静态数据初始化即可：

- `static readonly int[] MyArray0 = { 1, 2, 3, .. };`
- `static readonly int[] MyArray1 = new int[10];`

## 语言支持

Burst 不支持调用外部函数和函数指针。

它支持在静态只读字段和构造函数中使用以下基础语言功能：

- 托管数组。
- 字符串。
- 有限的 intrinsic 支持：
  - `Unity.Burst.BurstCompiler.IsEnabled`
  - `Unity.Burst.BurstRuntime.GetHashCode32`
  - `Unity.Burst.BurstRuntime.GetHashCode64`
  - 向量类型构造。
- 有限的 intrinsic 断言支持：
  - `UnityEngine.Debug.Assert`
  - `NUnit.Framework.Assert.AreEqual`
  - `NUnit.Framework.Assert.AreNotEqual`
- 简单的 throw 模式。计算期间抛出的任何异常都会变成编译器错误。
