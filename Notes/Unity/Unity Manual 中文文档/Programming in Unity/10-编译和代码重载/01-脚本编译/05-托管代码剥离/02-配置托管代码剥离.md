# 配置托管代码剥离

> 原文：[Configure managed code stripping](https://docs.unity3d.com/6000.7/Documentation/Manual/managed-code-stripping-configure.html)

**Managed Stripping Level** 属性决定 Unity Linker 分析和剥离应用程序代码时遵循哪些[[06-Unity Linker标记规则参考|规则]]。提高 Managed Stripping Level 会扩大 Linker 搜索未使用代码的范围，同时也会增加构建时间。

要更改 **Managed Stripping Level** 属性：

1. 转到 **Edit** > **Project Settings** > **Player**。
2. 在 **Other Settings** 中，找到 Optimization 标题。
3. 将 **Managed Stripping Level** 属性设置为所需值。

| 属性 | 功能 |
| --- | --- |
| **Disabled** | Unity 不会移除任何代码。<br><br>此设置仅适用于 [Mono scripting backend](https://docs.unity3d.com/6000.7/Documentation/Manual/scripting-backends-mono.html)，并且在该 backend 下为默认设置。 |
| **Minimal** | Unity 只在 `UnityEngine` 和 .NET class libraries 中搜索未使用的代码。Unity 不会移除用户编写的代码。此设置最不容易导致意外的运行时行为。<br><br>此设置适用于可用性优先级高于构建体积的项目。如果使用 [IL2CPP scripting backend](https://docs.unity3d.com/6000.7/Documentation/Manual/scripting-backends-il2cpp.html)，此设置为默认设置。 |
| **Low** | Unity 会在所有 `UnityEngine` 和 .NET class libraries 中搜索未使用的代码。它也会搜索用户编写的程序集，但只有当 Player 构建中包含的场景没有引用这些程序集中的任何类型时才会这样做。此设置应用一组会移除部分未使用代码的规则，同时尽量降低意外后果的可能性，例如改变使用 reflection 的运行时代码的行为。<br><br>**注意**：**Low** Managed Stripping Level 已标记为未来弃用，不建议使用。请改用 **Minimal** 或 **Medium**。 |
| **Medium** | Unity 会部分搜索所有程序集，以查找未使用的代码。此设置应用一组会剥离更多代码模式的规则，从而减小构建体积。虽然 Unity 不会剥离所有可能未使用的代码，但此设置确实会增加产生不良或意外行为变化的风险。 |
| **High** | Unity 会广泛搜索所有程序集，以查找未使用的代码。在此设置下，Unity 将减小体积置于代码稳定性之上，并尽可能多地移除代码。<br><br>此搜索可能比低剥离级别耗时长得多。仅在紧凑的构建体积极其重要的项目中使用此设置。彻底测试应用程序，并谨慎使用 `[Preserve]` Attribute 和 `link.xml` 文件，以确保 Unity Linker 不会剥离关键代码。 |
