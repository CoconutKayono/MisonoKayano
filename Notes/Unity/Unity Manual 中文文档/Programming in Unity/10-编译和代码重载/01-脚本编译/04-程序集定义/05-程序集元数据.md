# 程序集元数据和编译详细信息

> 原文：[Assembly metadata and compilation details](https://docs.unity3d.com/6000.7/Documentation/Manual/assembly-definition-metadata.html)

可以为程序集定义其他元数据，并检索包含在[项目构建](https://docs.unity3d.com/6000.7/Documentation/Manual/building-introduction.html)中的程序集信息。

<a name="set-assembly-attributes"></a>

## 设置程序集属性

可以使用程序集 Attribute 为程序集设置元数据属性。虽然不是必需的，但建议在 Assembly Definition 旁边的名为 `AssemblyInfo.cs` 的独立文件中定义这些 Attribute。

例如，以下程序集 Attribute 指定了几个 .NET 程序集元数据值，以及 Unity 定义的 `Preserve` Attribute。该 Attribute 会影响构建项目时如何从程序集中移除未使用的代码：

```csharp
[assembly: System.Reflection.AssemblyCompany("Bee Corp.")]
[assembly: System.Reflection.AssemblyTitle("Bee's Assembly")]
[assembly: System.Reflection.AssemblyCopyright("Copyright 2020.")]
[assembly: UnityEngine.Scripting.Preserve]
```

<a name="get-assembly-info"></a>

## 在构建脚本中获取程序集信息

使用 [`CompilationPipeline`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Compilation.CompilationPipeline.html) Class 检索 Unity 为项目构建的所有程序集的信息，包括根据 Assembly Definition 资源创建的程序集。

例如，以下脚本使用 `CompilationPipeline` Class 列出项目当前所有的 Player 程序集：

```csharp
using UnityEditor;
using UnityEditor.Compilation;
public static class AssemblyLister
{
    [MenuItem("Tools/List Player Assemblies in Console")]
    public static void PrintAssemblyNames()
    {
        UnityEngine.Debug.Log("== Player Assemblies ==");
        Assembly[] playerAssemblies =
            CompilationPipeline.GetAssemblies(AssembliesType.Player);

        foreach (var assembly in playerAssemblies)
        {
            UnityEngine.Debug.Log(assembly.name);
        }
    }
}
```
