# 集成第三方代码库

> 原文：[Integrating third-party code libraries (plug-ins)](https://docs.unity3d.com/6000.7/Documentation/Manual/plug-ins.html)

在 Unity 中，通常使用 Script 创建功能，但也可以通过 Plug-in 引入 Unity 外部创建的代码。

Unity 支持两种 Plug-in：

- **Managed Plug-in**：使用 Visual Studio 等工具创建的 Managed .NET Assembly，只包含 .NET 代码，因此不能访问 .NET Library 不支持的功能。
- **Native Plug-in**：平台专用的 Native Code Library，可以访问操作系统调用和第三方代码库等 Unity 原本无法访问的功能。

Managed Code 可由 Unity 用来编译 Script 的标准 .NET 工具访问。Managed Plug-in Code 与 Unity Script Code 的区别在于，Plug-in 在 Unity 外部编译，Unity 可能无法访问其源代码。对于 Managed Plug-in，如果忘记将文件添加到项目，通常会得到标准 Compiler Error；对于 Native Plug-in，通常要到运行项目时才会收到错误报告。
