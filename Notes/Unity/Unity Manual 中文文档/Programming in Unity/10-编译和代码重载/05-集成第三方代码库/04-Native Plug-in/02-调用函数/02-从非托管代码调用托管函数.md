# 从 Unmanaged Code 调用 Managed Function

> 原文：[Call managed functions from unmanaged code](https://docs.unity3d.com/6000.7/Documentation/Manual/plug-ins-native-invoke-managed.html)

要从 Unmanaged Code 调用 Managed Function，可以使用 Delegate 定义 Callback Function 的 Signature。Callback Function 本身必须是 Static，并带有表明匹配 Delegate Type 的 `AOT.MonoPInvokeCallbackAttribute`：

```csharp
using System;
using System.Runtime.InteropServices;
using UnityEngine;

public class PluginImport : MonoBehaviour
{
    delegate void MyFuncType();

    [AOT.MonoPInvokeCallback(typeof(MyFuncType))]
    static void MyFunction() {
        Debug.Log("Got a call back from native code.");
    }

    [DllImport("__Internal")]
    static extern void RegisterMyCallback(MyFuncType func);

    // Keep a reference to the delegate so it (and the native function pointer
    // that points back to it) isn't garbage collected while native code still
    // holds the function pointer.
    static MyFuncType s_callback;

    void Start()
    {
        s_callback = MyFunction;
        RegisterMyCallback(s_callback);
    }
}
```

**Notes:**

- 将 Method 传给 `RegisterMyCallback` 会创建一个 Delegate Instance。Marshaller 只在 P/Invoke 调用持续期间保持该 Delegate 存活，因此立即调用的 Callback 是安全的。如果 Native Code 保存 Function Pointer 以便稍后调用（如本例），必须在 Managed 侧自行保存对 Delegate 的引用——例如保存在 Static Field 中，并持续到 Native Code 不再可能调用它为止。否则 Garbage Collector 可能回收 Delegate，之后的 Callback 会解引用悬空 Function Pointer，从而导致程序崩溃或损坏。
- 如果使用预编译的动态链接 Library，请将 `DllImport` 改为使用 Library Name。对于 Source Code Plug-in 和静态链接 Library，请使用特殊字符串 `__Internal`。更多信息请参阅 [[04-DllImport属性]]。

必须将 Function Pointer 传给 Unmanaged Code，使其可以调用 Managed Function。在本例中，C# 的 `RegisterMyCallback` Function 会传递 Function Pointer。

Unmanaged Code 必须定义与 C# Delegate 对应的 Function Pointer Type。它还必须导出一个 Function，让你可以将 Pointer 传给 Delegate：

```c
// A C# delegate passed to native code defaults to the __stdcall calling convention
// on Windows, but C/C++ function pointers default to __cdecl. Define a macro so the
// function pointer type and the exported function use a matching convention on every
// platform. A mismatch crashes the 32-bit Windows player. Guard on the target
// platform (_WIN32), not the compiler: __stdcall applies to the 32-bit Windows ABI
// and is understood by every Windows compiler (MSVC, MinGW, and Clang).
#if defined(_WIN32)
#define STDCALL __stdcall
#else
#define STDCALL
#endif

typedef void (STDCALL *MyFuncType)();
MyFuncType registeredCallback;

extern "C"
{
    void STDCALL RegisterMyCallback(MyFuncType func) {
        registeredCallback = func;
    }
} // end of export C block
```

Unmanaged Code 可以立即调用 Callback，也可以保存 Function Pointer 以便稍后调用：

```c
if(registeredCallback)
{
    registeredCallback();
}
```
