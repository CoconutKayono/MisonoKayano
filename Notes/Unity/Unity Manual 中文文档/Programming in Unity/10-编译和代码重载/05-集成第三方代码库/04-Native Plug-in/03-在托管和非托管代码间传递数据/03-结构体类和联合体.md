# Struct、Class 和 Union

> 原文：[Structures, classes, and unions](https://docs.unity3d.com/6000.7/Documentation/Manual/plug-ins-native-pass-types.html)

要在 Structure、Class 或 Union 中交换数据，Unmanaged Code 与 Managed Code 必须声明兼容的 Data Structure。.NET Interop Services API 提供了一些 Attribute，可用于指定 C# Type 的 Field 如何排列在内存中，以及 Type 中的每个 Field 在 Managed Code 与 Unmanaged Code 之间传递时应如何进行 Marshalling。

[StructLayoutAttribute](https://learn.microsoft.com/en-us/dotnet/api/system.runtime.interopservices.structlayoutattribute) 让你可以使 Managed Type 的 Layout 与 Unmanaged Code 中对应 Struct 的 Layout 匹配。默认情况下，C# 根据每个 Field 的 Data Type 大小按顺序排列 Managed Struct（有时会为 Alignment 添加额外 Padding）。可以使用其他 `StructLayoutAttribute` Value 精确控制 Struct Field 的 Offset 和有效大小。还可以指定如何 Marshall Struct 中的 String。

在单个 Field 上使用 [MarshalAsAttribute](https://learn.microsoft.com/en-us/dotnet/api/system.runtime.interopservices.marshalasattribute)，控制该 Field 的 Marshalling 方式。

结合使用 `LayoutKind.Explicit` 和 [FieldOffsetAttribute](https://learn.microsoft.com/en-us/dotnet/api/system.runtime.interopservices.fieldoffsetattribute)，定义与 [C/C++ Union](https://learn.microsoft.com/en-us/dotnet/framework/interop/marshalling-classes-structures-and-unions#unions-sample) 对应的 Struct。

**Note**：当 Unmanaged Function 按 Value 向 Managed Code 返回 Structure 或 Class 时，该 Type 必须是 [Blittable](https://learn.microsoft.com/en-us/dotnet/framework/interop/blittable-and-non-blittable-types)。不过，像 `bool` 这样的 Non-blittable Scalar Value 仍然可以在指定 Marshalling 方式后返回，以下示例就是这样做的。

例如，以下 C-language Code 定义了一个表示 Axis-aligned Box 的 Struct，以及一个将该 Struct 和 Array Pointer 作为参数的 Unmanaged Function：

```cpp
#include <math.h> // for fabsf

typedef struct _Box {
    float Position[3];
    float Scale;
    float Size[3];
} CustomBox;

extern "C" {
    bool CheckInside(CustomBox box, float* point) {
        // Use fabsf so the float differences aren't truncated to integers.
        // (The integer abs() function would round each difference toward zero.)
        if( fabsf( box.Position[0] - point[0] ) < box.Size[0] * box.Scale &&
            fabsf( box.Position[1] - point[1] ) < box.Size[1] * box.Scale &&
            fabsf( box.Position[2] - point[2] ) < box.Size[2] * box.Scale
          )
                return true;

        return false;
    }
}
```

**Note**：关于将此类 Function 作为动态加载 Library 的一部分进行编译和调用时所需的 Annotation，请参阅 [[01-从托管代码调用非托管函数]]。

`CheckInside` Function 会计算 Point 是否位于 Box 内部，并返回 C `bool` Type。要从 Managed Code 调用此 Function，必须定义兼容的 C# Struct，并告诉 Scripting Runtime 如何处理参数和返回类型：

```csharp
using UnityEngine;
using System.Runtime.InteropServices;

// Sequential layout is the default and should be used in most cases
[StructLayout(LayoutKind.Sequential)]
public struct CustomBox
{
    // Marshall the array in place, with 3 elements
    [MarshalAs(UnmanagedType.ByValArray, SizeConst = 3)]
    float[] Position;
    float Scale;
    [MarshalAs(UnmanagedType.ByValArray, SizeConst = 3)]
    float[] Size;

    // Constructor (defining a constructor is not mandatory)
    public CustomBox (Vector3 center, float scale, Vector3 size)
    {
        Position = new float[3];
        Size = new float[3];
        for (var i = 0; i < 3; i++)
        {
            Position[i] = center[i];
            Size[i] = size[i];
        }
        Scale = scale;
    }
}

public class StructMarshalExamples
{
    // Import the native function
    [DllImport("__Internal")]
    [return: MarshalAs(UnmanagedType.I1)] // Marshal bool as a 1 byte signed integer
    static extern bool CheckInside(CustomBox box, [In] float[] point);

    // Run the example code
    public static void RunExamples()
    {
        // box1's half-extent in each axis is Size * Scale = 1 * 2.5 = 2.5
        var box1 = new CustomBox(Vector3.zero, 2.5f, Vector3.one);
        // box2's half-extent in each axis is Size * Scale = 1 * 4 = 4
        var box2 = new CustomBox(Vector3.zero, 4, Vector3.one);
        // The x distance (2.7) is just outside box1 (2.5) but inside box2 (4).
        // If the native code truncated 2.7 to 2, box1 would wrongly report "inside".
        float[] point = { 2.7f, 1.5f, -1.5f };

        var test1 = CheckInside(box1, point);
        var test2 = CheckInside(box2, point);

        Debug.Log($"Test point is {(test1 ? "inside" : "outside")} " +
                  $"the first box and {(test2 ? "inside" : "outside")} " +
                  $"the second");
    }
}
```

**Note**：如果使用预编译的动态链接 Library，请将 `DllImport` 改为使用 Library Name。对于 Source Code Plug-in 和静态链接 Library，请使用特殊字符串 `__Internal`。更多信息请参阅 [[04-DllImport属性]]。
