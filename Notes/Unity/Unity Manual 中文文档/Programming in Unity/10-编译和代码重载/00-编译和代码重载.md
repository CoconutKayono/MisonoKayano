# 编译和代码重载

> 原文：[Compilation and code reload](https://docs.unity3d.com/6000.7/Documentation/Manual/compilation-and-code-reload.html)

Compilation 会把代码转换为特定上下文和平台上运行的代码。Unity Editor 可能在打开项目、修改脚本、重新导入脚本 Asset 或进入 Play Mode 时重新编译和重载代码。

代码重载可以在上下文切换时保存或重置数据，并让相关修改生效；但频繁重载也会降低开发迭代速度。因此需要理解 Unity 何时、为什么以及如何编译和重载脚本与其他 Asset，同时理解 Unity 如何安排已编译代码的执行顺序。
