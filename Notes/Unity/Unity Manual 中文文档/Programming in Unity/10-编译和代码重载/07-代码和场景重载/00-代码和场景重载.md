# 代码重载和代码生命周期

> 原文：[Code reload and the code lifecycle](https://docs.unity3d.com/6000.7/Documentation/Manual/programming-code-lifecycle.html)

在 Unity Editor 中开发和迭代时，项目代码会根据你所做的修改自动加载和重载。

这个过程通常称为代码重载（code reload）；在 Mono 脚本后端的语境中称为 Domain Reload。代码重载包含以下关键阶段：

1. 重新编译脚本程序集。
2. 序列化托管对象以保存其状态。
3. 卸载或销毁现有脚本程序集。
4. 重新加载脚本程序集。
5. 反序列化托管对象以恢复其状态，并执行必要的初始化。

默认情况下，当 Unity 检测到脚本或其他 Asset 发生变化时，会在 Asset Database refresh 的一部分流程中自动重载代码。

你也可以选择[配置 Editor，使其在 Edit mode 与 Play mode 之间切换时重载代码](https://docs.unity3d.com/6000.7/Documentation/Manual/configurable-enter-play-mode.html)。

## 访问代码生命周期

在代码可用期间，它会经历加载、初始化、执行、停用以及卸载或销毁。这一系列代码经历的阶段称为代码生命周期（code lifecycle）。

有时需要在代码生命周期的特定阶段执行代码。例如，在脚本程序集加载或卸载之前或之后的关键时刻执行适当的设置或清理工作，或者在 Edit mode 与 Play mode 之间切换时执行代码。

Unity 通过提供公共生命周期 API，使你的代码能够在代码生命周期的特定时刻接收回调。

### 生命周期 API

一组主要位于 `Unity.Scripting.LifecycleManagement` 命名空间中的公共 Attribute，为旧版生命周期 API 提供了更连贯的替代方案。旧版 API 由 Attribute、事件和接口混合组成。

新 API 包含此前用户代码无法访问的代码生命周期阶段的回调。虽然部分旧 API 绑定到 Mono 和 Domain Reload，但新 API 保证能够与未来的任何脚本运行时和代码重载机制协同工作。

新 API 也具有对称性：对于每个加载代码或进入状态的回调，都有一个对应的卸载代码或退出状态的回调。新 API 也会在必要时同时提供给 Editor 和 Player。

以下各节中的表格列出了新的生命周期 API，以及在代码生命周期中具有等效功能和时机的旧 API。新代码建议采用较新的 API。

### 代码重载回调

以下 API 允许你在代码重载过程的关键阶段接收回调。新 API 位于 `Unity.Scripting.LifecycleManagement` 命名空间中，在 Editor 和 Player 构建中都可用。新版 API 具有以下主要优点：

- [`[OnCodeDeinitializing]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Scripting.LifecycleManagement.OnCodeDeinitializingAttribute.html) 和 [`[OnCodeUnloading]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Scripting.LifecycleManagement.OnCodeUnloadingAttribute.html) 可以直接访问此前无法访问的代码生命周期阶段。旧 API 中最接近的等效方案是使用 [`AssemblyReloadEvents.beforeAssemblyReload`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssemblyReloadEvents-beforeAssemblyReload.html) 并手动管理订阅。
- [`[OnCodeInitializing]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Scripting.LifecycleManagement.OnCodeInitializingAttribute.html) 会在 Asset 完全加载之前执行，因此比旧版的 [`[InitializeOnLoad]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/InitializeOnLoadAttribute.html)、[`[InitializeOnLoadMethod]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/InitializeOnLoadMethodAttribute.html) 和 [`[RuntimeInitializeOnLoadMethod]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/RuntimeInitializeOnLoadMethodAttribute.html) 更适合资源预分配；旧 API 会在之后执行。

| 生命周期阶段 | 新 API | 旧 API |
| --- | --- | --- |
| 代码重载期间序列化托管对象。 | `Unity.Scripting.LifecycleManagement`：[`[OnCodeDeinitializing]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Scripting.LifecycleManagement.OnCodeDeinitializingAttribute.html) | 没有既有等效 API。 |
| 代码重载前、代码被卸载之前。 | `Unity.Scripting.LifecycleManagement`：[`[OnCodeUnloading]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Scripting.LifecycleManagement.OnCodeUnloadingAttribute.html) | `UnityEditor`：[`AssemblyReloadEvents.beforeAssemblyReload`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssemblyReloadEvents-beforeAssemblyReload.html) |
| 程序集加载并初始化之后。发生在：<br><br>- 初始代码加载之后（Editor 和 Player）。<br>- 代码重载之后（仅 Editor）。 | `Unity.Scripting.LifecycleManagement`：[`[OnCodeLoaded]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Scripting.LifecycleManagement.OnCodeLoadedAttribute.html) | 没有既有等效 API。 |
| 代码重载后恢复（反序列化）托管对象之后。此时：<br><br>- 所有程序集都已加载。<br>- 已恢复序列化的 `MonoBehaviour` 和 `ScriptableObject` 数据。<br>- 对象已存在，但尚未收到 `Awake`/`OnEnable` 调用。 | `Unity.Scripting.LifecycleManagement`：[`[OnCodeInitializing]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Scripting.LifecycleManagement.OnCodeInitializingAttribute.html) | `UnityEditor`：[`[InitializeOnLoad]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/InitializeOnLoadAttribute.html)、[`[InitializeOnLoadMethod]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/InitializeOnLoadMethodAttribute.html)<br><br>`UnityEngine`：[`[RuntimeInitializeOnLoadMethod]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/RuntimeInitializeOnLoadMethodAttribute.html) 与 [`RuntimeInitializeLoadType.SubsystemRegistration`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/RuntimeInitializeLoadType.SubsystemRegistration.html) 配合使用。 |

更多信息和使用示例请参阅这些 Attribute 的 API 参考。

有关这些回调在代码重载上下文中的相对执行顺序，请参阅 [[02-Domain和Scene重载执行顺序参考]]。

### Play mode 和 Edit mode 转换回调

以下 API 允许你在进入和退出 Edit mode，以及进入和退出 Play mode 时接收回调。新版 API 分别位于 `UnityEditor.Scripting.LifecycleManagement` 和 `UnityEngine` 命名空间中。它们是两对对称的 Attribute，分别对应进入和退出 Edit mode，以及进入和退出 Play mode。与旧版 [`EditorApplication.playModeStateChange`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/EditorApplication-playModeStateChanged.html) 相比，它们有两个主要优点：

- 它们是 Attribute 而不是事件，因此避免了订阅事件、筛选枚举值和订阅泄漏所带来的开销与风险。
- 进入和退出 Play mode 的回调位于 `UnityEngine` 命名空间，因此不需要使用预处理器指令将它们从 Player 脚本的编译中排除。

| 生命周期阶段 | 新 API | 旧 API |
| --- | --- | --- |
| 初始化或重新初始化 Play mode，发生在：<br><br>- Editor 进入 Play mode 时。<br>- Editor 在 Play mode 中发生代码重载之后。<br>- 构建的 Player 应用启动时。<br><br>时机与 `InitializeOnEnterPlayMode` 等效，但 `[OnEnteringPlayMode]` 在对任何 Editor 对象调用 `OnDisable` 之后调用，而 `InitializeOnEnterPlayMode` 在此之前调用。 | `UnityEngine`：[`[OnEnteringPlayMode]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/OnEnteringPlayModeAttribute.html) | `UnityEditor`：[`PlayModeStateChange.EnteredPlayMode`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/PlayModeStateChange.EnteredPlayMode.html) |
| 关闭 Play mode，发生在：<br><br>- Editor 退出 Play mode 时。<br>- Play mode 中代码重载之前。<br>- 构建的 Player 应用退出时。 | `UnityEngine`：[`[OnExitingPlayMode]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/OnExitingPlayModeAttribute.html) | `UnityEditor`：[`PlayModeStateChange.ExitingPlayMode`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/PlayModeStateChange.ExitingPlayMode.html) |
| 初始化或重新初始化 Edit mode，发生在：<br><br>- 从 Play mode 返回 Edit mode 时。<br>- Edit mode 中发生代码重载之后。 | `UnityEditor`：[`[OnEnteringEditMode]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Scripting.LifecycleManagement.OnEnteringEditModeAttribute.html) | `UnityEditor`：[`PlayModeStateChange.EnteredEditMode`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/PlayModeStateChange.EnteredEditMode.html) |
| 关闭 Edit mode，发生在：<br><br>- 进入 Play mode 之前。<br>- Editor 中发生代码重载之前。 | `UnityEditor`：[`[OnExitingEditMode]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Scripting.LifecycleManagement.OnExitingEditModeAttribute.html) | `UnityEditor`：[`PlayModeStateChange.ExitingEditMode`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/PlayModeStateChange.ExitingEditMode.html) |

更多信息和使用示例请参阅这些 Attribute 的 API 参考。

有关使用这些 API 在进入和退出 Play mode 时重置静态状态的示例，请参阅[从代码重置状态](https://docs.unity3d.com/6000.7/Documentation/Manual/domain-reloading.html#reset-state)。
