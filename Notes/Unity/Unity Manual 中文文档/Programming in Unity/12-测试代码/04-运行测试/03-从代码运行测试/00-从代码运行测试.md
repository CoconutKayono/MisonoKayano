# 从代码运行测试

> 原文：[Running tests from code](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/running-tests-from-code.html)

可以使用 [TestRunnerAPI](https://docs.unity3d.com/Packages/com.unity.test-framework@latest/index.html?subfolder=/api/UnityEditor.TestTools.TestRunner.Api.TestRunnerApi.html) 类从代码调用 Unity Test Framework 的测试运行器，从而控制运行哪些测试，并获取测试数据和结果。

| 页面 | 说明 |
| --- | --- |
| [[01-指定要运行的测试]] | 组合 Filter 对象并传给 TestRunnerAPI，以确定测试运行中包含哪些测试。 |
| [[03-获取测试结果]] | 注册回调，在活动测试运行或单个测试开始或结束时接收通知。 |
| [[02-获取测试列表]] | 从测试运行器中获取指定测试模式（Edit Mode 或 Play Mode）的测试树。 |
