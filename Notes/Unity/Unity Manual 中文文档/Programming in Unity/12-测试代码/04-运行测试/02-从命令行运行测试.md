# 从命令行运行测试

> 原文：[Run tests from the command line](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/run-tests-from-command-line.html)

可以从 Unity Editor 命令行运行测试项目。下面的示例演示了如何在 Windows 上运行：

```bash
Unity.exe -runTests -batchmode -projectPath PATH_TO_YOUR_PROJECT -testResults C:\temp\results.xml -testPlatform PS4
```

> **注意：** 在命令行运行测试时，使用 **-batchmode** 选项可以避免手动输入。更多信息请参阅 [Unity Editor 命令行参数](https://docs.unity3d.com/6000.7/Documentation/Manual/EditorCommandLineArguments.html)。

有关 Unity Test Framework 提供的全部 Editor 命令行参数，请参阅[命令行参考](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/reference-command-line.html)。
