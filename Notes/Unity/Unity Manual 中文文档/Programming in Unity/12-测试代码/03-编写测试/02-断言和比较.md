# 断言和比较

> 原文：[Asserting and comparing](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/asserting-and-comparing.html)

Unity Test Framework 扩展了 NUnit，提供用于比较、断言以及为断言提供约束的 Unity 专用自定义 API。

## 断言

如果 Unity 记录的消息不是普通日志或警告消息，测试就会失败。你可以使用 [LogAssert](https://docs.unity3d.com/Packages/com.unity.test-framework@latest/index.html?subfolder=/api/UnityEngine.TestTools.LogAssert.html) 检查日志中是否包含预期消息，这样 Unity 记录该消息时测试就不会失败。

请在运行被测代码之前使用 `LogAssert.Expect`，因为预期日志的检查会在每一帧结束时运行。

如果预期消息没有出现，或者 Unity 没有记录任何普通日志或警告消息，测试同样会报告失败。

以下示例使用 `LogAssert.Expect`，预期 Editor 日志中同时出现普通日志消息和错误消息：

```csharp
[Test]
public void LogAssertExample()
{
    // Expect a regular log message
    LogAssert.Expect(LogType.Log, "Log message");
    
    // The test fails without the following expected log message     
    Debug.Log("Log message");
    
    // An error log
    Debug.LogError("Error message");
    
    // Without expecting an error log, the test would fail
    LogAssert.Expect(LogType.Error, "Error message");
}
```

### 使用约束进行断言

NUnit 允许使用 `Assert.That` 机制编写易读且描述性强的[断言](https://docs.nunit.org/articles/nunit/writing-tests/assertions/assertions.html)，其中第一个参数是被测对象，第二个参数描述该对象必须满足的条件。

Unity Test Framework 通过自定义约束类型扩展了这一机制，并声明了一个重叠的 [Is](https://docs.unity3d.com/Packages/com.unity.test-framework@latest/index.html?subfolder=/api/UnityEngine.TestTools.Constraints.Is.html) 类。为消除原始实现与自定义实现之间的歧义，必须使用 `using` 语句显式声明它，或通过完整类型名称 `UnityEngine.TestTools.Constraints.Is` 访问它。

## 比较

Unity Test Framework 提供自定义相等比较器和实用工具，使测试中自定义 Unity 类型值的验证更加容易。可比较的类型包括 `Color`、`Quaternion` 和 Vector。

你可以使用这些类，在给定容差范围内通过 [NUnit 约束](https://docs.nunit.org/articles/nunit/writing-tests/constraints/Constraints.html)或 [Unity 约束](https://docs.unity3d.com/Packages/com.unity.test-framework@latest/index.html?subfolder=/api/UnityEngine.TestTools.Constraints.Is.html)比较两个相同类型的对象是否相等。

调用 `Instance` 可将默认计算误差值应用于比较。若要设置特定误差值，请使用单参数构造函数 `ctor(float error)` 实例化新的比较器对象。

如需查看可用比较器的完整列表和用法示例，请参阅 [UnityEngine.TestTools.Utils](https://docs.unity3d.com/Packages/com.unity.test-framework@latest/index.html?subfolder=/api/UnityEngine.TestTools.Utils.html) API 参考。
