# 8. 性能测试

> 原文：[8. Performance Tests](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/LostCrypt/performance-tests.html)

## 学习目标

最后要探索的是一个使用 Performance Tests 扩展 Unity Test Framework 的 package。

## 练习

Performance Testing package 可以用来测量游戏性能。如果想跟踪项目中随时间发生的各种回归或改进，这是一个很好的工具。在本例中，你将学习如何创建一个测量游戏平均帧数的测试。

- LostCrypt 默认没有安装 Performance Testing package。请按照 [Performance Testing package 的安装说明](https://docs.unity3d.com/Packages/com.unity.test-framework.performance@2.8/manual/index.html) 安装它。
- 将 package 添加为项目 manifest 的依赖项。每个 Unity 项目都有一个 [project manifest](https://docs.unity3d.com/Manual/upm-manifestPrj.html)，它是 Package Manager 的入口文件。该文件必须位于 `<project>/Packages` 目录中。Package Manager 使用它配置许多内容，包括项目的依赖项列表，以及要查询的 package 仓库。更多信息请参阅 [project manifest 术语表条目](https://docs.unity3d.com/6000.7/Documentation/Manual/Glossary.html#projectmanifest)。
- 安装 package 后，在 `PlayModeTests` assembly definition 中添加对 `Unity.PerformanceTesting` 的引用，以访问性能测试 API。
- 在 `Assets/Tests/PlayModeTests` 下创建新的 C# 类 `PerformanceTests.cs`。

现在可以完成目标了。在 `PerformanceTests.cs` 中创建名为 `MainScene_MeasureAverageFrames()` 的新函数。在这个函数中，让角色移动到 Wand 位置，并等待 Wand 拾取效果结束。在整个过程中测量帧数。

## 加分练习

- 尝试测量 LostCrypt 中的平均 FPS。可能需要使用 `UnityEngine` API 的 `Time.deltaTime`，以及 Performance Testing package API 的 `Measure.Custom`。

## 提示

- 加载 Scene 后最初几帧通常不稳定。使用 `Measure.Frames().Scope()` API，在单独的 scope 中测量这些帧。
- 测试结束后，可以在 **Window > General > Performance Test Report** 下查看性能结果，也可以使用 [Callback API](https://docs.unity3d.com/Packages/com.unity.test-framework@1.1/manual/extension-get-test-results.html) 接收结果。

## 解决方案

`PerformanceTests.cs`

```csharp
using System.Collections;
using Unity.PerformanceTesting;
using UnityEngine;
using UnityEngine.TestTools;
using UnityEngine.SceneManagement;

public class PerformanceTests
{
    private Transform _characterTransform;
    private float _wandLocation = 21.080f;

    [UnityTest, Performance]
    public IEnumerator MainScene_MeasureAverageFrames()
    {
        SceneManager.LoadScene("Assets/Scenes/Main.unity", LoadSceneMode.Single);
        using (Measure.Frames().Scope("Frames.MainSceneOnLoad.Unstable"))
        {
            for (var i = 0; i < 25; i++)
            {
                yield return null;
            }
        }

        using (Measure.Frames().Scope("Frames.MainSceneGameplay"))
        {
            yield return GoRight();
            while (GetCurrentCharacterPosition() <= _wandLocation)
            {
                yield return null;
            }

            StopMoving();
            yield return new WaitForSeconds(15);
        }
    }

    private float GetCurrentCharacterPosition()
    {
        // Get Main character's Transform which is used to manipulate position.
        if (_characterTransform == null)
        {
            _characterTransform = GameObject.Find("Sara Variant").transform;
        }

        return _characterTransform.position.x;
    }

    private IEnumerator GoRight()
    {
        TestInputControl.MoveLeft = false;
        yield return null;
        TestInputControl.MoveRight = true;
    }

    private void StopMoving()
    {
        TestInputControl.MoveRight = false;
        TestInputControl.MoveLeft = false;
    }
}
```
