# 3. 移动角色

> 原文：[3. Moving character](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/LostCrypt/moving-character.html)

## 学习目标

了解如何使用 [InputSystem package](https://docs.unity3d.com/Packages/com.unity.inputsystem@latest)，在测试中以通用方式通过代码移动角色。

## 练习

请确保 Unity 项目中已经安装 InputSystem。你可以在 Package Manager 中确认这一点。

- 在 `Assets/Tests/PlayModeTests` 下创建名为 `MovementTest.cs` 的新类。
- 在 `PlayModeTests` 的 assembly definition 中添加对 `Unity.InputSystem` 和 `Unity.InputSystem.TestFramework` 的引用。
- 在 Tests 下创建新的 `InputControl` 目录：`Assets/Tests/InputControl`。
- 在 `InputControl` 目录中创建新的 assembly definition：`TestInputControl.asmdef`。
- 创建新的类 `TestInputControl.cs`，实现以下属性：

```csharp
public static bool MoveLeft { get; set; }
public static bool MoveRight { get; set; }
public static bool Jump { get; set; }
```

- 返回 `PlayModeTests` assembly definition，并添加对新创建的 `TestInputControl` 的引用。
- 最后，需要在实际的 LostCrypt 代码中使用 `TestInputControl`。当前 Unity 的 InputSystem 不支持更简单的代码化 mock 方式，请查看此 git diff，了解需要在 `CharacterController2D` 中进行的修改：

现在已经准备就绪！返回 `MovementTest.cs`，编写一个暂时不进行任何断言的测试，只移动 Sara 角色，并让她偶尔跳跃。

## 提示

- 可以在测试中使用 `WaitForSeconds`，有意延长测试运行时间，以便在屏幕上看到实际的动画。
- 如果出现编译问题，请确保遵循正确的文件夹结构：

```text
Tests
    InputControl
        TestInputControl.asmdef
        TestInputControl.cs
    PlayModeTests
        MovementTest.cs
        PlayModeTest.asmdef
```

## 解决方案

`PlayModeTests.asmdef`

```json
{
    "name": "PlayModeTests",
    "references": [
      "Unity.InputSystem",
      "Unity.InputSystem.TestFramework",
      "TestInputControl"
    ],
    "optionalUnityReferences": [
      "TestAssemblies"
    ]
}
```

`MovementTest.cs`

```csharp
using System.Collections;
using UnityEngine;
using UnityEngine.TestTools;
using UnityEngine.SceneManagement;

public class MovementTest
{
    [UnityTest]
    public IEnumerator MainScene_CharacterIsAbleToJump()
    {
      SceneManager.LoadScene("Assets/Scenes/Main.unity", LoadSceneMode.Single);
      yield return waitForSceneLoad();
      yield return GoRight();
      yield return new WaitForSeconds(2);
      yield return Jump();
      yield return new WaitForSeconds(3);
      yield return GoLeft();
      yield return Jump();
      yield return new WaitForSeconds(2);
    }

    private IEnumerator Jump()
    {
      TestInputControl.Jump = true;
      yield return null;
      TestInputControl.Jump = false;
    }

    private IEnumerator GoRight()
    {
      TestInputControl.MoveLeft = false;
      yield return null;
      TestInputControl.MoveRight = true;
    }

    private IEnumerator GoLeft()
    {
      TestInputControl.MoveRight = false;
      yield return null;
      TestInputControl.MoveLeft = true;
    }

    private IEnumerator waitForSceneLoad()
    {
        while (SceneManager.GetActiveScene().buildIndex > 0)
        {
            yield return null;
        }
    }
}
```
