# 5. 断言和预期日志

> 原文：[5. Asserting and expecting logs](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/asserting-logs.html)

## 学习目标

学习如何测试和验证会向 Console log 写入内容的代码。

## 简介与动机

在 Unity 中，许多 package 和 module 会通过 log message 和 exception 与用户沟通。这既适用于正常工作流，也适用于错误情况。

我们扩展了测试框架，使其能够识别 Console log。这意味着默认情况下，在运行 test 时记录的任何 error 或 exception 都会导致 test 失败。如果这种失败是预期的，可以使用 `LogAssert.Expect(logtype, message)` 确保指定 message 确实被记录。它既可以用于预期普通 message，也可以用于预期 warning。 `LogAssert.Expect` 可以放在 message 产生之前或之后。当 test 结束（或下一次 yield）时，如果预期 message 不存在，test 就会失败。

```csharp
[Test]
public void LogAssertExample()
{
    // Expect a regular log message
    LogAssert.Expect(LogType.Log, "Log message");

    // The test fails without the following expected log message
    Debug.Log("Log message");

    // An error log
    Debug.LogError("Error message");

    // Without expecting an error log, the test would fail
    LogAssert.Expect(LogType.Error, "Error message");
}
```

`LogAssert.Expect` 也接受 regex 作为参数，因为有时无法知道确切的字符串。例如，记录的 message 中包含持续时间时，就可以使用 regex 匹配变化的部分。

## 练习

在 sample `5_AssertingLogs` 中有一个名为 `MyLoggingClass` 的类。

这个类有两个具有以下行为的方法：

- `DoSomething();` 记录 message “Doing something”。
- `DoSomethingElse();` 记录 error “An error happened. Code: #”，其中 `#` 是一个从 0 到 9 的随机数字。

编写 test，使用 `LogAssert.Expect` 验证上述行为。你可以进行实验：观察不使用 expect 直接调用 `DoSomethingElse();` 时会发生什么，也可以观察预期一个 warning 类型的 message 时会发生什么。

## 提示

要预期 error message，需要将 regular expression 与 `LogAssert.Expect` 一起使用。

在 Unity 中，记录的 error 与记录的 exception 是不同的。

## 解决方案

完整解决方案位于 sample `5_AssertingLogs_Solution` 中。

下面是一种可能的 test 实现：

```csharp
[Test]
public void DoSomethingLogsMessage()
{
    var loggingClassUnderTest = new MyLoggingClass();

    loggingClassUnderTest.DoSomething();

    LogAssert.Expect(LogType.Log, "Doing something");
}

[Test]
public void DoSomethingElseLogsError()
{
    var loggingClassUnderTest = new MyLoggingClass();

    loggingClassUnderTest.DoSomethingElse();

    LogAssert.Expect(LogType.Error, new Regex("An error happened. Code: \\d"));
}
```
