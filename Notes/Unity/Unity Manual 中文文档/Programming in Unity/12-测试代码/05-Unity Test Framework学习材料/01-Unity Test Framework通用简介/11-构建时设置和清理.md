# 12. 在构建时设置和清理

> 原文：[12. Setup and cleanup at build time](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/build-setup-cleanup.html)

## 学习目标

本节将介绍 Test Framework 在 Player 构建前后提供的钩子。

## 简介与动机

有时需要在 Play Mode 测试构建前更改设置或准备资源。同样，也可能需要在构建后清理内容。为此，Test Framework 提供了两个钩子：[`PrebuildSetup` 和 `PostBuildCleanup`](https://docs.unity3d.com/Packages/com.unity.test-framework@1.1/manual/reference-setup-and-cleanup.html)。

在 Editor 中，`PrebuildSetup` 会在构建和测试运行前调用，`PostBuildCleanup` 会在测试全部完成后调用。Edit Mode 和 Play Mode 测试都会执行这两个阶段。在设备上运行 Play Mode 测试时，由于测试会与构建并行在设备上执行，Cleanup 会在构建完成后立即运行。

确保测试具有 `PrebuildSetup` 和 `PostBuildCleanup` 的最简单方式，是分别在测试类中实现 `IPrebuildSetup` 和 `IPostBuildCleanup`。

设置和清理通常会与 `UnityEditor` Assembly 中的代码交互。这些代码在设备上运行时不可用，但我们又希望将内置的设置和清理代码保留在测试类中。因此，建议使用 `#if UNITY_EDITOR` 宏包裹与 Editor 相关的代码行。例如：

```csharp
public class MyTestClass : IPrebuildSetup
{
    [Test]
    public void MyTest()
    {

    }

    public void Setup()
    {
    #if UNITY_EDITOR
        UnityEditor.EditorSettings.serializationMode = SerializationMode.ForceText;
    #endif
    }
}
```

> **注意**：如果没有包裹 Editor 代码，那么在 Editor 中运行时不会出现编译错误；但尝试在 Player 中运行测试时会出现编译错误。

## 练习

sample `12_BuildSetupCleanup` 包含一个用于验证 Scene 内容的 Play Mode 测试。它本质上是上一项练习中测试的 Play Mode 版本。

该测试会失败，因为找不到 Scene。可以通过将 Scene 添加到 Build Settings 来解决，但不建议把测试相关的 Scene 加入 Build Settings，因为在非测试用途的构建中也可能将它包含进去。

因此，任务是创建一个 `PrebuildSetup`，将 Scene 添加到 `EditorBuildSettings`；再创建一个 `PostBuildCleanup`，将其移除。

分别在 Editor 和独立 Player 中运行测试，以验证解决方案。你需要使用 `#if UNITY_EDITOR`，使代码能够为 Player 编译。

## 提示

- `IPrebuildSetup` 接口要求实现 `Setup` 方法，因此要注意不要让它与已经存在的 `[SetUp]` 方法混淆。

## 解决方案

完整解决方案位于 [sample](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/test-framework-general-introduction.html#import-samples) `12_BuildSetupCleanup_Solution` 中。

完整的测试解决方案可以如下实现：

```csharp
using System.Collections;
using System.Linq;
using NUnit.Framework;
#if UNITY_EDITOR
using UnityEditor;
#endif
using UnityEngine;
using UnityEngine.SceneManagement;
using UnityEngine.TestTools;

namespace Tests
{
    public class SceneTests : IPrebuildSetup, IPostBuildCleanup
    {
        private string originalScene;
        private const string k_SceneName = "Assets/MyGameScene.unity";

        public void Setup()
        {
        #if UNITY_EDITOR
            if (EditorBuildSettings.scenes.Any(scene => scene.path == k_SceneName))
            {
                return;
            }

            var includedScenes = EditorBuildSettings.scenes.ToList();
            includedScenes.Add(new EditorBuildSettingsScene(k_SceneName, true));
            EditorBuildSettings.scenes = includedScenes.ToArray();
        #endif
        }

        [UnitySetUp]
        public IEnumerator SetupBeforeTest()
        {
            originalScene = SceneManager.GetActiveScene().path;
            SceneManager.LoadScene(k_SceneName);
            yield return null; // 跳过一帧
        }

        [Test]
        public void VerifyScene()
        {
            var gameObject = GameObject.Find("GameObjectToTestFor");

            Assert.That(gameObject, Is.Not.Null, $"GameObjectToTestFor not found in {SceneManager.GetActiveScene().path}.");
        }

        [TearDown]
        public void TeardownAfterTest()
        {
            SceneManager.LoadScene(originalScene);
        }

        public void Cleanup()
        {
        #if UNITY_EDITOR
            EditorBuildSettings.scenes = EditorBuildSettings.scenes.Where(scene => scene.path != k_SceneName).ToArray();
        #endif
        }
    }
}
```

注意，`#if UNITY_EDITOR` 也用于 `using` 语句之间，从而允许引用 `UnityEditor`。
