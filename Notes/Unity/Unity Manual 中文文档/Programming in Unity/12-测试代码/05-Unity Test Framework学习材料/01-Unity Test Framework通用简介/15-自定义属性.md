# 16. 自定义属性

> 原文：[16. Custom attributes](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/custom-attributes.html)

## 学习目标

本节将介绍几种实现自定义 NUnit 属性的方法。自定义属性可以改变测试的执行方式。

## 简介与动机

NUnit 的一个强大之处在于它具有很好的扩展性。扩展方式之一就是使用自定义属性。例如，可以实现 [`IWrapTestMethod`](https://docs.nunit.org/articles/nunit/extending-nunit/ICommandWrapper-Interface.html) 接口的属性。该接口包含一个用于包装 `TestCommand` 的方法，而 `TestCommand` 实现了执行测试的方法。通常，这些测试命令会先执行一些操作，调用内部命令的 `Execute`，然后在内部命令完成后再执行一些操作。

下面 3 个类实现了 `IWrapTestMethod` 接口，并在测试中使用它：

```csharp
public class MyAttribute : NUnitAttribute, IWrapTestMethod
{
    public TestCommand Wrap(TestCommand command)
    {
        return new MyCommand(command);
    }
}

public class MyCommand : TestCommand
{
    private TestCommand innerCommand;

    public MyCommand(TestCommand command) : base(command.Test)
    {
        innerCommand = command;
    }

    public override TestResult Execute(ITestExecutionContext context)
    {
        Debug.Log("Before");
        var result = innerCommand.Execute(context);
        Debug.Log("After");

        return result;
    }
}

public class MyTests
{
    [Test]
    [MyAttribute]
    public void Test1()
    {
        Debug.Log("The test");
    }
}
```

运行 `MyTests.Test1` 时，会打印以下输出：

```text
Test1 (0,017s)
–-
Before
The test
After
```

自定义属性还可以实现其他接口，例如 `IWrapSetUpTearDown`、`IApplyToContext` 和 `IApplyToTest`。

## 练习

Unity 的目标是任何操作耗时都不应超过 500 ms。sample `16_CustomAttributes` 中有一个名为 `MyClass` 的类，其中包含两个方法。这两个方法都应该返回 `true`，但有人引入了回归问题，使其中一个方法的运行时间变得很长。

任务是创建一个新的自定义属性，检测测试运行是否超过 500 ms。如果超过，就使用描述性消息使测试失败。将该属性应用到现有的两个测试上。

## 提示

- 可以使用 `System.Diagnostics.Stopwatch` 类测量经过了多少毫秒。

## 解决方案

完整解决方案位于 `16_CustomAttributes_Solution` 中。

解决方案的核心是测试命令实现中的 `Execute` 方法：

```csharp
public override TestResult Execute(ITestExecutionContext context)
{
    var stopWatch = new Stopwatch();
    stopWatch.Start();
    var result = innerCommand.Execute(context);
    stopWatch.Stop();

    if (stopWatch.ElapsedMilliseconds > 500)
    {
        result.SetResult(ResultState.Failure, $"Test took {stopWatch.ElapsedMilliseconds} ms. That is longer than 500ms!");
    }

    return result;
}
```
