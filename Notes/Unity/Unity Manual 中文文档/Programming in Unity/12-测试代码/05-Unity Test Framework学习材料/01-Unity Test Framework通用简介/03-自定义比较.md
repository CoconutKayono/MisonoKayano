# 4. 自定义比较

> 原文：[4. Custom comparison](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/custom-comparison.html)

## 学习目标

本练习将介绍 Unity Test Framework 中提供的 custom equality comparer，例如 `Vector3EqualityComparer`。这些 comparer 可用于对 Vector 进行 assert。

## 简介与动机

我们扩展了 NUnit 的 assertion 能力，为 Unity 特有的对象提供了一些 custom comparison 功能。一个很好的例子是比较两个 `Vector3` 对象。

使用方式示例：

```csharp
actual = new Vector3(0.01f, 0.01f, 0f);
expected = new Vector3(0.01f, 0.01f, 0f);

Assert.That(actual, Is.EqualTo(expected).Using(Vector3EqualityComparer.Instance));
```

这可以验证两个 vectors 在给定 tolerance 范围内是否相同。默认 tolerance 是 `0.0001f`。你可以提供新的 `Vector3EqualityComparer` 来修改 tolerance，而不是使用默认的 `.Instance`。例如，以下代码将 tolerance 提高到 `0.01f`：

```csharp
Assert.That(actual, Is.EqualTo(expected).Using(new Vector3EqualityComparer(0.01f)));
```

有关所有可用 custom comparers 的列表，请参阅[自定义 equality comparers](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/extension-custom-equality-comparers.html)。

## 练习

与练习 3 的项目类似，sample `4_CustomComparison` 包含一个 `ValueOutputter` 类。

验证 `ValueOutputter` 的方法是否返回正确的值：

- `GetVector3()` 应返回一个大致等于 `(10.333, 3, 9.666)` 的 `Vector3`。
- `GetFloat()` 应返回一个大致等于 `19.333` 的 `float`。这与上一个练习相同，但你可以尝试使用 `FloatEqualityComparer` 解决。
- `GetQuaternion()` 应返回一个大致等于 `(10f, 0f, 7.33333f, 0f)` 的 `Quaternion`。Quaternion 是 Unity 用于将旋转表示为数据的标准方式。编写处理旋转的代码时，通常应该使用 `Quaternion` 类及其方法。

## 提示

某些练习可能需要为 comparer 提供自定义错误 tolerance。

如果比较失败，comparer 会像普通 assert 一样，给出实际值和期望值的消息。但是，由于 `Vector3.ToString` 在显示值之前会进行四舍五入，即使两个 `Vector3` 值并不相同，错误消息中的两个字符串也可能相同。

## 解决方案

完整解决方案位于 sample `4_CustomComparison_Solution` 中。

```csharp
[Test]
public void Vector3ReturnsCorrectValue()
{
    var valueOutputterUnderTest = new ValueOutputter();

    var vector3 = valueOutputterUnderTest.GetVector3();

    var expected = new Vector3(10.333f, 3f, 9.666f);
    Assert.That(vector3, Is.EqualTo(expected).Using(new Vector3EqualityComparer(0.001f)));
}

[Test]
public void FloatReturnsCorrectValue()
{
    var valueOutputterUnderTest = new ValueOutputter();

    var actualFloat = valueOutputterUnderTest.GetFloat();

    Assert.That(actualFloat, Is.EqualTo(19.333f).Using(new FloatEqualityComparer(0.001f)));
}

[Test]
public void QuaternionReturnsCorrectValue()
{
    var valueOutputterUnderTest = new ValueOutputter();

    var actualValue = valueOutputterUnderTest.GetQuaternion();

    var expectedValue = new Quaternion(10f, 0f, 7.33333f, 0f);
    Assert.That(actualValue, Is.EqualTo(expectedValue).Using(new QuaternionEqualityComparer(0.001f)));
}
```
