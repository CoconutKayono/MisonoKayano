# 8. 在 Player 中运行 Play Mode 测试

> 原文：[8. PlayMode tests in a Player](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/play-mode-tests-in-player.html)

## 学习目标

本节将教你如何在计算机上的 standalone Player 中运行 Play Mode tests。

## 简介与动机

自动化测试质量保证的重要领域之一，是能够在不同类型的平台上进行测试。这对 Unity 和 Unity 用户都很有用，可以让他们在从手机到主机的各种设备上验证应用程序。

在平台上运行 tests 的最简单设置，是在自己的计算机上以 standalone 方式运行。如果已经安装了适用于操作系统的 Unity standalone platform support，就可以点击 **Run all in player** 按钮运行 Play Mode tests。更详细的说明请参阅[在 standalone Player 中运行 Play Mode tests](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/run-playmode-tests-standalone.html)。

## 练习

导入 sample `8_PlayModeTests_InPlayer`。

这个项目包含上一个练习的解决方案，也就是一个简单的 Play Mode test。

在 Play Mode 选项卡中点击 **Run all in player** 按钮，在 standalone Player 中执行 test。
