# 创建测试

> 原文：[Create a test](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/workflow-create-test.html)

创建 Test Assembly 后，在 Test Runner 中选中它，点击 **Create a new Test Script in the active path**；也可以使用 **Assets > Create > Testing > C# Test Script**。Unity 会生成带有示例测试的 `.cs` 文件，修改文件名后在 IDE 中编辑并保存，Test Runner 会显示新的 Test Fixture 和 Test。

创建 Play Mode 测试的流程相同；如果测试要在 Standalone 或其他 Player 上运行，必须把脚本放在包含相应平台引用的 Test Assembly 中。每个测试应明确 Arrange（准备输入）、Act（执行代码）和 Assert（验证结果）阶段。
