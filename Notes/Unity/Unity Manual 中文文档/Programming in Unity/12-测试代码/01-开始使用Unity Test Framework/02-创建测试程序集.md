# 创建测试程序集

> 原文：[Create a test assembly](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/workflow-create-test-assembly.html)

Unity Test Framework 测试必须放在引用 NUnit 的 Test Assembly 中。在 Test Runner 中选中 Project 窗口的 Assets，打开 **Window > General > Test Runner**，选择 **Create a new Test Assembly Folder**；也可以使用 **Assets > Create > Testing > Test Assembly Folder**。

Unity 会创建 Tests 子目录和对应的 `.asmdef`，其中包含 `nunit.framework.dll`、`UnityEngine.TestRunner` 和 `UnityEditor.TestRunner` 引用。默认只面向 Editor；在 Inspector 的 Platforms 中选择 Any Platform 或指定平台后，程序集中的 Play Mode 测试才能在对应 Player 上运行。测试程序集还需要显式引用包含被测代码的 Assembly Definition。
