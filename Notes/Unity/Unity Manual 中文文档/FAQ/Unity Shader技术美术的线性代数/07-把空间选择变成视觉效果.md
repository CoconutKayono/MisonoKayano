# 07｜把空间选择变成视觉效果

## 先问：这个效果应该固定在哪里

在写公式前，把视觉意图说成一句可以观察的话。

| 视觉意图 | 优先考虑的坐标 | 移动物体后的预期 |
| --- | --- | --- |
| 图案印在雕像身上 | Object 或 UV | 图案跟着雕像走 |
| 扫描面保持世界水平 | World | 雕像穿过固定扫描面 |
| 图案像屏幕上的滤镜 | Screen | 图案相对屏幕固定 |
| 光照细节跟着曲面朝向 | Tangent 法线转 World | 偏转方向随曲面转动 |
| 一个独立盒子控制溶解区域 | 自定义 Effect 空间 | 盒子走到哪里，效果到哪里 |

“Object 或 UV”不表示它们等价：Object 按模型坐标生成纹样，UV 按网格展开参数取样。有 UV 接缝、不同面朝向时，结果很不一样。

## 同一行公式，换个输入空间就换种表现

水平条纹可以写成：

~~~hlsl
float stripe = step(0.5, frac(position.y * frequency));
~~~

frac 取小数部分，step 把每周期分为明暗两半：

- positionOS.y：高度按模型自己的尺子测量，条纹随模型旋转；模型放大时世界中的条纹间距也变大。
- positionWS.y：高度按世界尺子测量，旋转模型时条纹仍保持世界水平；世界中的间距保持约 $1/frequency$。
- screenUV.y：高度按画面测量，条纹像覆盖在画面上的透明胶片；其间距按视口比例定义。

这比“哪种空间高级”更重要：**空间的选择决定视觉效果依附的参照物。**

硬 step 在远处或细条纹上容易闪烁。第 08 篇使用带 fwidth 的平滑周期纹样减轻问题，便于观察空间关系。

## 世界扫描面

希望薄亮带始终停留在世界高度 h：

~~~hlsl
float d = abs(positionWS.y - h);
float mask = 1.0 - smoothstep(width, width + softness, d);
~~~

h、width、softness 在此按世界单位理解，softness 应大于 0。把 positionWS 换成 positionOS 后，亮带会随模型倾斜，并受模型缩放影响。

数学只是在算“到一个平面的距离”。一般平面可写为：

$$
d=n\cdot(p-c)
$$

n 是单位法线，c 是平面上的点；$|d|$ 是距离，正负号告诉你位于哪一侧。计算中的 n、p、c 必须同空间。

## 风向与位移长度不要弄丢

希望顶点始终沿世界 x 方向摆动：

~~~hlsl
float3 pWS = TransformObjectToWorld(positionOS);
pWS += float3(amplitude * sin(time + pWS.y * frequency), 0, 0);
float4 pCS = TransformWorldToHClip(pWS);
~~~

这里 amplitude 是世界空间的长度。若改成 positionOS.x += ...，物体旋转后摆动方向也会转，缩放后振幅也会变。

如果必须在 OS 中加一个世界位移，需把位移变回 OS，保留其长度关系：

~~~hlsl
float3 deltaOS = mul((float3x3)GetWorldToObjectMatrix(), deltaWS);
positionOS += deltaOS;
~~~

这个 deltaOS 不应该随手 normalize。URP 的方向帮助函数有的默认归一化，使用时检查参数。

以上只演示位置思路；真正的风动画还需要同步处理法线、阴影 Pass 和可能的运动向量。

## 为什么 UV 加偏移，纹样却向反方向走

最终颜色是 $C(u)=Texture(u)$。改成 $C(u)=Texture(u+a)$ 后，固定纹样特征原本在纹理地址 $u_0$，现在出现在满足：

$$
u+a=u_0\Rightarrow u=u_0-a
$$

的位置。因此采样坐标向右加 a，纹样在表面上向左移动。对旋转和缩放也有类似的“取样映射与可见图案”反向关系。

希望图案放大两倍时，常把采样坐标相对中心缩小一半：

~~~hlsl
float2 sampleUV = (uv - 0.5) / 2.0 + 0.5;
~~~

这与顶点坐标乘 2 让几何放大，是两种不同的使用场景。还要考虑 Wrap Mode：超出 0—1 后，Repeat 会重复，Clamp 会贴边延伸。

## 把需求翻译成操作的四步

1. 确定参照物：模型、世界、镜头或独立效果对象。
2. 选择要测量的量：位置、距离、方向夹角、表面法线。
3. 把参与运算的数据统一到所选空间。
4. 预测移动、旋转和缩放后的结果，再实际操作核对。

自测：希望两个不同大小的石头共用世界中连续的苔藓纹样，应先试 Object 还是 World？

答案：World 能提供跨物体连续的空间输入；但连续坐标不保证投影无拉伸，复杂曲面可能还需三平面映射等技术。
