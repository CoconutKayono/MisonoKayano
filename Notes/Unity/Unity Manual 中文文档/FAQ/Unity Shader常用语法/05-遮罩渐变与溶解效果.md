# 05｜遮罩、渐变与溶解效果

配套 [函数可视化实验室](../Unity%20Shader技术美术的线性代数/交互演示/空间与矩阵实验室.html)：可交互观察 Remap、Step、Smoothstep、分阶等操作。曲线显示实际数值；灰度预览在显示时把超出 0—1 的值截为黑或白，这不等于函数自动限幅。

## 场景：在两种颜色之间过渡

**可放在基础模板 frag 中，替换原返回逻辑：**

~~~c
half3 a = half3(0.05, 0.15, 0.4);
half3 b = half3(1.0, 0.4, 0.1);
float mask = saturate(IN.uv.x);
half3 color = lerp(a, b, mask);
return half4(color, 1);
~~~

lerp(a,b,t) 等于 a+(b-a)*t：t=0 得 a，t=1 得 b。它**不会自动把 t 限制在 0—1**，需要时使用 saturate。

表现：UV 左侧蓝、右侧橙；换成另一张贴图的 r 通道作 mask，就得到按图案混合两种颜色。

## 场景：硬边遮罩与柔边遮罩

~~~c
float hard = step(0.5, IN.uv.x);
float soft = smoothstep(0.4, 0.6, IN.uv.x);
~~~

step(edge,x) 在 x 小于 edge 时为 0，否则为 1。容易写反的不是函数名称，而是**阈值在前、被测量的数在后**。

smoothstep(low,high,x) 在两阈值间平滑过渡；保持 high>low。反向遮罩用 1-smoothstep(...)，不要靠交换上下界表达反向。

小例子：step(0.5,0.2)=0；step(0.5,0.8)=1；smoothstep(0.4,0.6,0.5)=0.5。[Microsoft smoothstep](https://learn.microsoft.com/en-us/windows/win32/direct3dhlsl/dx-graphics-hlsl-smoothstep)

## 场景：圆形光斑

**frag 示例，半径与柔边先写成常量：**

~~~c
float d = length(IN.uv - 0.5);
float mask = 1.0 - smoothstep(0.25, 0.30, d);
return half4(mask.xxx, 1);
~~~

length 把“到中心的二维位移”变成距离。半径不是像素，而是 UV 单位；UV 有拉伸时，圆在模型上可能变椭圆。

## 场景：重复条纹

~~~c
float phase = frac(IN.uv.y * 8.0);
float stripe = step(0.5, phase);
return half4(stripe.xxx, 1);
~~~

frac(x)=x-floor(x)，所以 frac(-0.2)=0.8。不要把它和所有语言中带符号的余数混为一谈。

想让条纹固定在世界水平面，改用 IN.positionWS.y，但需要先按第 03 篇传递这个字段。输入坐标决定纹样依附的空间。

## 场景：溶解与烧边

以下示例在基础模板上扩展，采用**镂空裁剪**，不是半透明。

**新增 Properties：**

~~~c
_NoiseMap("Dissolve Noise", 2D) = "white" {}
_Dissolve("Dissolve", Range(0,1)) = 0
_EdgeWidth("Edge Width", Range(0.001,0.2)) = 0.05
[HDR] _EdgeColor("Edge Color", Color) = (4,1,0,1)
~~~

**新增 HLSL 声明：**

~~~c
// 放在 CBUFFER 外
TEXTURE2D(_NoiseMap);
SAMPLER(sampler_NoiseMap);

// 以下三项加入原有 UnityPerMaterial，不要再创建第二个同名 CBUFFER
float _Dissolve;
float _EdgeWidth;
float4 _EdgeColor;
~~~

**替换 frag：**

~~~c
half4 frag(Varyings IN) : SV_Target
{
    half4 base = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, IN.uv) * _BaseColor;
    float noise = SAMPLE_TEXTURE2D(_NoiseMap, sampler_NoiseMap, IN.uv).r;
    float edge = 0.0;

    // 明确处理完全显示与完全消失两个端点
    if (_Dissolve >= 1.0)
        clip(-1.0);
    else if (_Dissolve > 0.0)
    {
        float d = noise - _Dissolve;
        clip(d);
        edge = 1.0 - smoothstep(0.0, max(_EdgeWidth, 0.0001), d);
    }

    return half4(base.rgb + edge * _EdgeColor.rgb, 1);
}
~~~

**SubShader 标签与 Pass 状态：** 使用第 07 篇的 Cutout 组合：Queue=AlphaTest、RenderType=TransparentCutout、ZWrite On、Blend Off。保留 UniversalPipeline 标签。

clip(x) 丢弃负值对应的片元；0 不丢弃。若直接 clip(noise-_Dissolve)，噪声为 1 的区域在 _Dissolve=1 时仍可能残留，因此上例显式处理端点。clip 丢弃片元，不会给模型生成封口面。

噪声贴图通常作为数据关闭 sRGB。高于 1 的边缘颜色只是在输出 HDR 亮度；可见光晕还依赖 HDR、Bloom 等配置。要让消失的部分不再投影，ShadowCaster 等相关 Pass 必须采用一致裁剪逻辑。

## 场景：让程序边缘随像素大小变柔和

**传统顶点/片元 Shader 中，以下用在 frag：**

~~~c
float d = length(IN.uv - 0.5) - 0.25;
float width = max(fwidth(d), 0.0001);
float circle = 1.0 - smoothstep(-width, width, d);
return half4(circle.xxx, 1);
~~~

fwidth 估计该量在邻近片元中的变化幅度，可用来给边缘设置与屏幕采样相关的过渡宽度。它不是“读取纹理宽度”。

ddx、ddy、fwidth 属于屏幕导数操作；不要原样搬到普通顶点阶段，也不要随意放进像素之间不一致的分支后再依赖其导数结果。

常用数值函数入口：[Microsoft HLSL 内置函数](https://learn.microsoft.com/en-us/windows/win32/direct3dhlsl/dx-graphics-hlsl-intrinsic-functions)。
