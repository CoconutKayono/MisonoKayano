# 04｜纹理采样与 UV 动画

## 场景：贴图乘染色

**前提：** 采用基础模板，已声明 _BaseMap、sampler_BaseMap、_BaseColor，vert 已传递 uv。

**放在 frag：**

~~~hlsl
half4 tex = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, IN.uv);
return tex * _BaseColor;
~~~

TEXTURE2D 声明纹理资源，SAMPLER 声明采样状态，SAMPLE_TEXTURE2D 执行采样。采样不是“读一个绝对像素编号”，过滤、寻址方式与 mip 都会影响结果。

## 场景：让材质的 Tiling/Offset 生效

**放在 vert：**

~~~hlsl
OUT.uv = TRANSFORM_TEX(IN.uv, _BaseMap);
~~~

可以理解为：

~~~hlsl
OUT.uv = IN.uv * _BaseMap_ST.xy + _BaseMap_ST.zw;
~~~

这两行是等价选择，不要连续执行两次。_BaseMap_ST 需声明在 UnityPerMaterial 中。[Unity URP 纹理示例](https://docs.unity3d.com/cn/6000.0/Manual/urp/writing-shaders-urp-unlit-texture.html)

## 场景：水流、能量流动

**新增属性与缓冲变量：**

~~~shaderlab
// Properties
_Scroll("UV Speed XY", Vector) = (0.1,0,0,0)
~~~

~~~hlsl
// UnityPerMaterial 中
float4 _Scroll;
~~~

**在 frag 中替换基础纹理采样：**

~~~hlsl
float2 uv = IN.uv + _Time.y * _Scroll.xy;
half4 tex = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, uv);
return tex * _BaseColor;
~~~

纹样的可见移动方向与采样偏移通常相反：u 增大表示去右边读内容，原来的纹样特征会向左出现。

希望循环流动，一般给纹理设置 Repeat。不要习惯性地先对 UV 做 frac：纹理采样器本身能重复寻址，而手工 frac 的跳变可能影响导数和 mip 选择，引出接缝。

## 场景：绕中心旋转纹样

**frag 片段，角度为演示常量：**

~~~hlsl
float angle = radians(30.0);
float s = sin(angle), c = cos(angle);
float2x2 R = float2x2(c, -s, s, c);
float2 uv = mul(R, IN.uv - 0.5) + 0.5;
half4 tex = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, uv);
return tex * _BaseColor;
~~~

这旋转的是已经经过 Tiling/Offset 的采样坐标。如果希望先旋转原始 UV、再做材质平铺，需要调整运算顺序。矩阵次序决定最终效果。

## 场景：用一张贴图的多个通道

假设一张自定义遮罩图约定：R=湿润、G=发光、B=溶解噪声、A=其他遮罩。

~~~hlsl
half4 masks = SAMPLE_TEXTURE2D(_MaskMap, sampler_MaskMap, IN.uv);
half wetness = masks.r;
half glow = masks.g;
half noise = masks.b;
~~~

需要另声明 _MaskMap 纹理及采样器。通道名字完全由你的资产约定决定；Unity 不会看见 .g 就自动知道它是发光。

遮罩这类数据纹理通常关闭 sRGB；颜色贴图则按颜色工作流设置，法线图使用 Normal Map 导入类型。错误的导入设置会改变取样数值，表现为阈值不对或颜色不对。

## 场景：顶点着色器采样高度图

**普通顶点阶段不能依赖片元隐式导数选 mip；使用显式 LOD：**

~~~hlsl
// 前提：已声明 _HeightMap 和 sampler_HeightMap，网格提供 uv、normalOS
float height = SAMPLE_TEXTURE2D_LOD(_HeightMap, sampler_HeightMap, IN.uv, 0).r;
float3 pOS = IN.positionOS.xyz + IN.normalOS * (height * 0.1);
~~~

最后参数 0 指最细 mip，并不意味着最适合性能和远景稳定性。还应满足目标平台与 Shader Model 的支持要求，可根据项目需要设置 #pragma target。

## 其他常见资源形式

| 使用场景 | 声明与取样 |
| --- | --- |
| 天空盒/立方体贴图 | TEXTURECUBE、SAMPLE_TEXTURECUBE；输入三维方向 |
| 纹理数组 | TEXTURE2D_ARRAY、SAMPLE_TEXTURE2D_ARRAY；还需数组层索引 |
| 明确控制 mip | SAMPLE_TEXTURE2D_LOD |
| 明确控制梯度 | SAMPLE_TEXTURE2D_GRAD；较进阶 |

这些是 Unity 封装宏，参数与可用性需要查看当前包的定义；不要按名称猜参数数量。
