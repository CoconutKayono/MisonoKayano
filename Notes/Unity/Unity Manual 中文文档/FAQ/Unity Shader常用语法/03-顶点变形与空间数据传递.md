# 03｜顶点变形与空间数据传递

## 场景：把网格数据送到片元阶段

下面是可替换基础模板中同名结构和 vert 的片段；增加了世界位置与法线。

~~~c
struct Attributes
{
    float4 positionOS : POSITION;
    float3 normalOS   : NORMAL;
    float4 tangentOS  : TANGENT;
    float2 uv        : TEXCOORD0;
    half4 color      : COLOR;
};

struct Varyings
{
    float4 positionCS : SV_POSITION;
    float2 uv         : TEXCOORD0;
    float3 positionWS : TEXCOORD1;
    float3 normalWS   : TEXCOORD2;
    half4 color       : TEXCOORD3;
};

Varyings vert(Attributes IN)
{
    Varyings OUT;
    OUT.positionCS = TransformObjectToHClip(IN.positionOS.xyz);
    OUT.uv = TRANSFORM_TEX(IN.uv, _BaseMap);
    OUT.positionWS = TransformObjectToWorld(IN.positionOS.xyz);
    OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
    OUT.color = IN.color;
    return OUT;
}
~~~

网格需要提供所用的 UV、法线、切线或顶点色。声明了输入字段，不会自动为缺失数据生成有意义的内容。

## 冒号后的语义是接口，不是注释

| 语义 | 常见位置 | 含义 |
| --- | --- | --- |
| POSITION | 顶点输入 | 网格顶点位置 |
| NORMAL | 顶点输入 | 网格法线 |
| TANGENT | 顶点输入 | xyz 切线及 w 方向性符号 |
| COLOR | 顶点输入 | 顶点色 |
| TEXCOORD0… | 顶点输入或阶段传递 | 输入 UV，或一般插值通道 |
| SV_POSITION | 顶点输出/片元输入 | 位置系统语义，含义随阶段变化 |
| SV_Target | 片元返回值 | 输出到颜色渲染目标 |

TEXCOORD1 不表示“必须是一张纹理的第二套 UV”。用于 Varyings 时，它可承载世界位置、法线、雾因子等，编号不能在同一接口里冲突。

传到片元的普通浮点数据通常会按光栅化规则做透视校正插值。因此顶点阶段的单位法线到片元后应重新归一化。需要禁止插值的整型标记，可使用 nointerpolation；这与普通颜色渐变的用途不同。

## 场景：世界风向下的摆动

**替换 vert 中的位置计算，其他 OUT 字段仍需赋值：**

~~~hlsl
float3 pWS = TransformObjectToWorld(IN.positionOS.xyz);
pWS.x += sin(_Time.y + pWS.y * 2.0) * 0.1;
OUT.positionWS = pWS;
OUT.positionCS = TransformWorldToHClip(pWS);
~~~

_Time.y 是 Unity 提供的随游戏时间推进的秒数，可用于连续动画，不应再当 deltaTime 积分一次。这段是每帧由原始顶点位置计算当前偏移。

- 在 WS 加 x：风始终沿世界 x。
- 在 OS 加 x：风随模型朝向变化。
- 只在 frag 改颜色：不会改变几何轮廓。
- 网格太稀：顶点波浪不能自动生成更多几何细节。

顶点形变后需要相应更新法线、阴影等 Pass；该片段只展示位置语法。扩大几何范围还可能需要调整 CPU 侧 Renderer bounds，避免提前剔除。

## 场景：沿法线膨胀

~~~hlsl
float3 pOS = IN.positionOS.xyz + IN.normalOS * 0.03;
OUT.positionCS = TransformObjectToHClip(pOS);
~~~

这是对象空间膨胀，厚度受模型缩放影响；硬边处的分裂法线可能导致裂缝或不连续。它也不是屏幕上固定像素宽度的描边。

## 场景：选对空间转换函数

| 需要转换的量 | URP 写法 |
| --- | --- |
| 模型位置 → 世界位置 | TransformObjectToWorld(positionOS) |
| 世界位置 → 模型位置 | TransformWorldToObject(positionWS) |
| 模型位置 → Clip | TransformObjectToHClip(positionOS) |
| 世界位置 → Clip | TransformWorldToHClip(positionWS) |
| 模型法线 → 世界法线 | TransformObjectToWorldNormal(normalOS) |
| 模型方向 → 世界方向 | TransformObjectToWorldDir(directionOS) |

方向函数可能默认归一化；要保留位移长度时检查其参数，或显式乘 3×3 线性部分。法线不能在非均匀缩放下当普通方向处理。

依据：[URP 坐标转换方法](https://docs.unity3d.com/6000.0/Documentation/Manual/urp/use-built-in-shader-methods-transformations.html)、[Unity 官方空间变换源码](https://github.com/Unity-Technologies/Graphics/blob/master/Packages/com.unity.render-pipelines.core/ShaderLibrary/SpaceTransforms.hlsl)。
