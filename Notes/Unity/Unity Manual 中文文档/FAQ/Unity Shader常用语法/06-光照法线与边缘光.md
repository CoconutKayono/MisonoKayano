# 06｜光照、法线与边缘光

## 场景：让模型根据主光方向出现明暗

**前提：**

- 已按第 03 篇将 normalWS、positionWS 传到片元阶段。
- 保留 Core.hlsl，再包含 Lighting.hlsl。
- 简单手写前向光照 Pass 可设置 LightMode=UniversalForwardOnly；标签负责调度，光照公式仍由你编写。
- 以下只是主光 Lambert 示例，不是完整 URP Lit/PBR。

**HLSLPROGRAM 函数外新增：**

~~~c
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"
~~~

**替换 frag：**

~~~c
half4 frag(Varyings IN) : SV_Target
{
    half3 albedo = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, IN.uv).rgb * _BaseColor.rgb;
    float3 N = normalize(IN.normalWS);
    Light light = GetMainLight();
    half ndotl = saturate(dot(N, light.direction));
    half3 diffuse = albedo * light.color * ndotl * light.distanceAttenuation;
    return half4(diffuse, 1);
}
~~~

dot 比较表面朝向与光源方向；saturate 去除背面负值。GetMainLight() 的 direction 可以用作指向光源的方向参与这里的点积；不要又随意取负。

这段没有加入环境光、额外灯光或实时阴影采样。背光全黑属于示例模型的预期，不代表 shader 编译坏了。[Unity URP 光照方法](https://docs.unity3d.com/cn/6000.0/Manual/urp/use-built-in-shader-methods-lighting.html)

## 场景：边缘光、能量护盾轮廓

**在有 normalWS、positionWS 的 frag 中计算：**

~~~c
float3 N = normalize(IN.normalWS);
float3 V = GetWorldSpaceNormalizeViewDir(IN.positionWS);
float rim = pow(1.0 - saturate(dot(N, V)), 4.0);
half3 rimColor = half3(0.1, 0.8, 1.0) * rim;
~~~

把 rimColor 加到已有颜色即可。正对镜头的表面 N·V 接近 1，边缘较小；接近侧面的表面 N·V 接近 0，边缘较亮。指数增大会使亮带更集中。

这是常见 Fresnel 风格遮罩，不是完整物理 Fresnel 方程。pow 的底数在这里经过 saturate 保证非负，避免对负数取非整数幂。

## 场景：把法线贴图变成世界朝向

**前提与新增声明：**

- Properties 添加 [Normal] _NormalMap("Normal Map", 2D)="bump" {}。
- HLSL 在 CBUFFER 外声明 TEXTURE2D(_NormalMap) 和 SAMPLER(sampler_NormalMap)。
- 包含 Lighting.hlsl，网格有 UV、法线和有效切线。
- 在 Varyings 中新增 float4 tangentWS : TEXCOORD4;，编号应与其他字段错开。

**vert 中新增：**

~~~c
OUT.tangentWS.xyz = TransformObjectToWorldDir(IN.tangentOS.xyz);
OUT.tangentWS.w = IN.tangentOS.w * GetOddNegativeScale();
~~~

**frag 中：**

~~~c
half4 packed = SAMPLE_TEXTURE2D(_NormalMap, sampler_NormalMap, IN.uv);
float3 nTS = UnpackNormal(packed);

float3 N = normalize(IN.normalWS);
float3 T = normalize(IN.tangentWS.xyz);
T = normalize(T - N * dot(T, N));
float3 B = cross(N, T) * IN.tangentWS.w;

float3 nWS = normalize(nTS.x * T + nTS.y * B + nTS.z * N);
~~~

这个教学版本显式建立局部正交框架，便于看懂每个分量；生产材质应与烘焙器及目标管线的切线框架约定保持一致。退化切线或异常网格数据也需单独处理。

UnpackNormal 处理 Unity 法线纹理编码；直接把采样 RGB 当世界法线会出错。nTS=(0,0,1) 表示沿模型表面 N，不是永远朝世界 +Z。

法线变换及 TBN 约定参见 [Unity SpaceTransforms.hlsl](https://github.com/Unity-Technologies/Graphics/blob/master/Packages/com.unity.render-pipelines.core/ShaderLibrary/SpaceTransforms.hlsl)，以及 [[../Unity Shader技术美术的线性代数/06-点积法线与切线空间|法线逆转置与切线空间]]。

## 场景：接收主光阴影

下面只讨论**主方向光阴影贴图路径，含级联，不含屏幕空间阴影与软阴影变体**。

**HLSLPROGRAM 顶部新增：**

~~~c
#pragma multi_compile _ _MAIN_LIGHT_SHADOWS _MAIN_LIGHT_SHADOWS_CASCADE
~~~

**frag 中替换 GetMainLight()：**

~~~c
float4 shadowCoord = TransformWorldToShadowCoord(IN.positionWS);
Light light = GetMainLight(shadowCoord);
~~~

再把 diffuse 乘以 light.shadowAttenuation。在片元位置求阴影坐标，可以避免把跨级联的大三角形只按顶点结果插值。

还需要 URP 资产与灯光启用阴影，场景中有真正绘制 ShadowCaster 的物体。若启用了屏幕空间阴影 Renderer Feature，应使用匹配该路径的关键字和坐标获取方式，不能只把 _MAIN_LIGHT_SHADOWS_SCREEN 填进 pragma 而保持上述采样坐标不变。[Unity URP 阴影方法](https://docs.unity3d.com/6000.0/Documentation/Manual/urp/use-built-in-shader-methods-shadows.html)

**接收阴影与投射阴影是两件事。** 此处只改变接收端。给 Pass 起名 ShadowCaster 不会自动生成正确阴影程序，还需对应 LightMode、顶点处理和必要的裁剪逻辑。

## 场景：额外灯光

常见接口是 GetAdditionalLightsCount 与 GetAdditionalLight，但 Forward、Forward+ 和不同 URP 包版本对循环与关键字的要求不同。本专题不提供一份假装通用的额外光循环；以目标包的官方光照示例为准。

需要完整金属度、粗糙度、探针、Lightmap 与阴影整合时，优先从管线 Lit 模板或 Shader Graph Lit 开始，比把这些教学片段继续堆叠更可靠。
