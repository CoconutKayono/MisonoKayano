# 09｜管线对照与官方参考

## 场景：旧教程的代码为什么在 URP 中报错

| 旧教程常见写法 | 本专题 URP 写法 | 说明 |
| --- | --- | --- |
| CGPROGRAM / ENDCG | HLSLPROGRAM / ENDHLSL | 旧块名称不代表里面完全是另一套算法，但库和框架需要匹配 |
| UnityCG.cginc | URP 的 Core.hlsl | 按需求再引入 Lighting.hlsl 等 |
| UnityObjectToClipPos(v.vertex) | TransformObjectToHClip(positionOS) | 都涉及模型位置到 Clip |
| sampler2D、tex2D | TEXTURE2D、SAMPLER、SAMPLE_TEXTURE2D | URP 的跨平台资源封装 |
| _WorldSpaceLightPos0 等 | GetMainLight 等管线接口 | 不是所有旧内置变量在 URP 都可直接用 |
| #pragma surface surf Standard | URP Lit Shader Graph 或手写顶点/片元 Shader | Built-in Surface Shader 不直接适用于 URP |
| GrabPass | URP 的相机颜色纹理或自定义渲染流程 | 不是把关键词重命名就能迁移 |
| ForwardBase / ForwardAdd | URP 的 LightMode 与光照接口 | 调度方式也不同 |

迁移时应先判断 **使用哪条渲染管线、哪套 Shader 模板**，再替换接口。仅把 tex2D 改成 SAMPLE_TEXTURE2D，不能保证整份旧 Shader 可用。[Unity 官方 URP 迁移指南](https://docs.unity3d.com/cn/6000.0/Manual/urp/urp-shaders/birp-urp-custom-shader-upgrade-guide.html)

HDRP 有自己的材质结构、Pass 约定、光照和相机相对坐标处理；本文 URP 模板不是 HDRP 模板。

## 场景：判断一个名字从哪里来

| 名字 | 来源 |
| --- | --- |
| float、struct、return、if | HLSL 语言 |
| dot、lerp、normalize、smoothstep | HLSL 内置函数 |
| Properties、Blend、ZWrite | ShaderLab |
| _Time | Unity 提供的 Shader 变量 |
| TEXTURE2D、CBUFFER_START | Unity 的宏封装 |
| TransformObjectToHClip、GetMainLight | Unity/URP 库函数 |
| _BaseColor、MakeBand、vert、frag | 本例选取的属性与函数名，并非全部是保留字 |

变量以下划线开头只是常见命名习惯；并不会因此获得自动绑定所有功能的能力。

## 推荐的实际查阅顺序

第一次写：01 的完整模板 → 04 的纹理与颜色 → 05 的遮罩。

做特效时：先用 05 写出灰度遮罩，再用 07 决定它是透明、加法还是镂空；最后用 08 添加必要开关和调试输出。

做空间与光照时：03 传递正确数据 → 06 计算朝向；遇到“为什么”再回到 [[../Unity Shader技术美术的线性代数/00-学习路线|线性代数专题]]。
