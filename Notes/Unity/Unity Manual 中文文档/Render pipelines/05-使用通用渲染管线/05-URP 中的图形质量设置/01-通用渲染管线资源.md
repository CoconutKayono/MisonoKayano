# 通用渲染管线资源

> 原文：[Universal Render Pipeline asset](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/urp-asset-and-renderer.html)

任何使用通用渲染管线（URP）的 Unity 项目都必须具有 URP 资源来配置设置。使用 URP 模板创建项目时，Unity 会在项目的 **Settings** 文件夹中创建 URP 资源，并在项目设置中分配这些资源。如果要将现有项目迁移到 URP，则需要创建 URP 资源并在图形设置中分配该资源，具体步骤参见 [[02-将 URP 安装到现有项目中]]。

URP 资源控制通用渲染管线的多项图形功能和质量设置。它是一个继承自 `RenderPipelineAsset` 的可编程对象。在图形设置中分配该资源后，Unity 会从内置渲染管线切换到 URP。随后，可以直接在 URP 中调整相应设置，而不必到其他位置查找。

可以拥有多个 URP 资源并在它们之间切换。例如，可以创建一个启用阴影的资源和一个禁用阴影的资源。通过切换资源来了解效果时，不必每次都手动切换相应的阴影设置。但是，不能在 HDRP/SRP 资源与 URP 资源之间切换，因为这些渲染管线彼此不兼容。
