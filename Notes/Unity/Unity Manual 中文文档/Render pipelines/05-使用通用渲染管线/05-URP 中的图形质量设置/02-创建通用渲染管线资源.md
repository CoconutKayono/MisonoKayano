# 创建通用渲染管线资源

> 原文：[Create a Universal Render Pipeline asset](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/urp-asset-create.html)

创建通用渲染管线资源，以配置全局渲染和质量设置，并为项目实例化 URP 管线。资源说明参见 [[01-URP 通用渲染管线资源参考]]。

创建 URP 资源的步骤如下：

1. 在 **Project** 窗口中选择目标文件夹。
2. 创建通用渲染管线资源（菜单：**Assets** > **Create** > **Rendering** > **URP Asset (with Universal Renderer)**）。

也可以在 **Project** 窗口中右键单击，然后选择 **Create** > **Rendering** > **URP Asset (with Universal Renderer)**。

Unity 会在所选文件夹中创建 URP 资源。
