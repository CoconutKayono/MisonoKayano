# 从 HDRP 迁移到 URP

> 原文：[Migrating from HDRP to URP](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/migrating-from-hdrp.html)

使用以下资源，将 High Definition Render Pipeline（HDRP）项目迁移到 Universal Render Pipeline（URP），并将项目设置转换为与 URP 兼容的形式。

从 HDRP 迁移到 URP 时，并非所有功能都相同或受到支持。有关功能支持情况，请参阅 [[01-选择渲染管线]] 和 [[02-渲染管线功能比较参考]]。

> [!NOTE]
> 要从 HDRP 迁移到 URP，必须重写项目的大部分内容。这是一个非常耗时的过程。
