# 升级到通用渲染管线版本 8.2.x

> 原文：[Upgrade to version 8.2.x of the Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrade-guide-8-2-0.html)


本页介绍如何从旧版本的通用渲染管线 (URP) 升级到 8.2.x 版。

## 从 URP 8.0.x–8.1.x 升级

1. 与 URP 8.0.x 相比，URP 8.2.x 没有重大更改。要将 URP 升级到 8.2.x 版本，请安装新版本的包。

## 从 URP 7.2.x 及更高的 7.x 版本升级

1. URP 8.x.x 不支持 Post-Processing Stack v2 包。如果项目使用 Post-Processing Stack v2 包，请先迁移使用这个包的效果。

## 从 URP 7.0.x–7.1.x 升级

1. 先升级到 URP 7.2.0。请参阅[[17-升级到通用渲染管线版本 7.2.0]]。
2. URP 8.x.x 不支持 Post-Processing Stack v2 包。如果项目使用 Post-Processing Stack v2 包，请先迁移使用这个包的效果。
