# 升级到通用渲染管线版本 7.3.0

> 原文：[Upgrade to version 7.3.0 of the Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrade-guide-7-3-0.html)


本页介绍如何从旧版本的通用渲染管线 (URP) 升级到 7.3.0 版。

## 从 URP 7.2.x 升级

1. 与 URP 7.2.x 相比，URP 7.3.0 没有重大更改。要将 URP 升级到版本 7.3.0，请安装新版本的包。

## 从 URP 7.0.x–7.1.x 升级

1. 先升级到 URP 7.2.0。请参阅[[17-升级到通用渲染管线版本 7.2.0]]。
2. 执行**从 URP 7.2.x 升级**的过程。
