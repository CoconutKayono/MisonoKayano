# 从内置渲染管线升级到 URP

> 原文：[Migrating from the Built-In Render Pipeline to URP](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrading-from-birp.html)


使用渲染管线转换器将项目升级到 URP 并匹配内置渲染管线中的质量设置的资源。

| **页面** | **描述** |
| --- | --- |
| [[06-使用渲染管线转换器转换资源]] | 可以将针对内置渲染管线项目制作的资源转换为与 URP 兼容的资源。 |
| [[05-将质量设置从内置渲染管线转换到 URP。]] | 匹配内置渲染管线中的**低 (Low)** 和**高 (High)** 默认质量预设的性能。 |
| [[08-使用渲染管线转换器将着色器转换为 URP]] | 将内置渲染管线的预构建着色器转换为 URP 着色器。 |
| [[09-查找 URP 中内置渲染管线质量设置]] | 在内置渲染管线的**质量 (Quality)** 窗口中（在**项目设置 (Project Settings)** 窗口中或 URP 中的 URP 资源中）查找设置。 |
