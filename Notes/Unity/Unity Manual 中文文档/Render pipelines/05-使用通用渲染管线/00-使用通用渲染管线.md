# 使用通用渲染管线

> 原文：[Using the Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/universal-render-pipeline.html)

![通用渲染管线跨平台渲染示例](urp-example.png)

通用渲染管线（Universal Render Pipeline，URP）是由 Unity 制作的预构建[[02-可编程渲染管线基础知识]]。URP 提供了对美术师友好的工作流程，可让您在移动设备、高端游戏主机和 PC 等多种平台上快速、轻松地创建经过优化的图形。
