# 在内置渲染管线中配置图形层

> 原文：[Configure graphics tiers in the Built-In Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/graphics-tiers-customize.html)

**重要**：Built-In Render Pipeline 已弃用，并将在未来版本中废止。在整个 Unity 6.7 LTS 生命周期内，它仍会获得支持，包括 bug 修复和维护。有关迁移的信息，请参阅[从 Built-In Render Pipeline 迁移到 Universal Render Pipeline](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrading-from-birp.html)和[渲染管线功能比较](https://docs.unity3d.com/6000.7/Documentation/Manual/render-pipelines-feature-comparison.html)。

## 配合 C# script 使用 graphics tier

Unity 将当前 graphics tier 的值存储在 `Graphics.activeTier` 中，并将其表示为 `GraphicsTier` enum。要根据当前 graphics tier 添加 custom behavior，可以测试此值。

要覆盖 `Graphics.activeTier` 的值，请直接设置它。注意，必须在 Unity 加载任何随 graphics tier 变化的 shader 之前执行此操作。适合设置此值的位置是 pre-loading Scene，即加载 main Scene 之前。

## Tier settings

可以在 Unity Editor 中配置 tier settings。Tier settings 允许为每个 tier 启用或禁用 graphics feature。

Tier settings 的工作方式是更改 Unity 内部 shader code 中的 `#define` preprocessor directive。这些更改会自动影响 Built-in Render Pipeline 的预构建 shader（例如 Standard Shader）以及 Surface Shader 的内部 shader library code。也可以在手动编写的 shader 中添加代码，根据 tier settings 改变其行为。详情请参阅 [[01-内置渲染管线中的图形层]]。

默认 tier settings 适用于大多数用例。仅当遇到性能问题，或者希望在默认未启用功能的低端设备上启用该功能时，才应更改这些设置。

可以为给定 build target 的每个 graphics tier 配置不同的 tier settings。更改 tier settings 的方式如下：

- 使用 [Graphics Settings 窗口](https://docs.unity3d.com/6000.7/Documentation/Manual/class-GraphicsSettings.html)中的 **Tier Settings** 区域；
- 在 Editor script 中使用以下 API：
  - [`EditorGraphicsSettings`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.EditorGraphicsSettings.html)；
  - [`TierSettings`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.TierSettings.html)。

可以在 Editor 中测试 tier settings。导航到 **Edit > Graphics Tier**，然后选择 Unity Editor 要使用的 tier。
