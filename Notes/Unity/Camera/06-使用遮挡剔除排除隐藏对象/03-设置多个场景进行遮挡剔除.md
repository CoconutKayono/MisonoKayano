# 设置多个场景进行遮挡剔除

> 原文：[Set up multiple scenes for occlusion culling](https://docs.unity3d.com/6000.7/Documentation/Manual/occlusion-culling-scene-loading.html)

## 一次加载一个 Scene

运行时无论打开多少个 Scene，Unity 一次只加载一个 Occlusion Culling 数据资源。因此，必须根据计划一次加载一个 Scene 还是多个 Scene，以不同方式准备数据。

如果使用 `LoadSceneMode.Single` 一次加载一个 Scene，必须为每个 Scene 单独烘焙数据：

1. 在 Unity Editor 中打开要烘焙 Occlusion Culling 数据的单个 Scene。
2. 为 Scene 烘焙数据。Unity 会生成数据，并将其保存为 `Assets/[Scene name]/OcclusionCullingData.asset`，然后将该资源的引用添加到打开的 Scene。
3. 保存 Scene。
4. 对每个 Scene 重复上述步骤。

运行时，将 Scene 作为项目的默认 Scene，或使用 `LoadSceneMode.Single` 加载。Unity 会卸载当前活动 Scene（如果存在）及其 Occlusion Culling 数据资源，然后连同自己的数据资源一起加载新 Scene。

## 同时加载多个 Scene

如果使用 `LoadSceneMode.Additive` 一次加载多个 Scene，必须将这些 Scene 一起烘焙：

1. 在 Unity Editor 中打开运行时要加载的 Scene 组中的第一个 Scene，使其成为活动 Scene。
2. Additively 打开组中的其他 Scene，使所有 Scene 同时处于打开状态。
3. 为所有 Scene 烘焙数据。Unity 会为所有打开的 Scene 生成数据，将其保存为 `Assets/[active Scene name]/OcclusionCullingData.asset`，并将该资源的引用添加到所有打开的 Scene。
4. 保存这些 Scene。

运行时，将组中的第一个 Scene 作为项目的默认 Scene，或使用 `LoadSceneMode.Single` 加载。Unity 会卸载当前活动 Scene（如果存在）及其 Occlusion Culling 数据资源，然后连同共享数据资源一起加载新 Scene。按需要使用 `LoadSceneMode.Additive` 加载其他 Scene；如果 Unity 发现 Additively 加载的 Scene 与活动 Scene 使用相同的 Occlusion Culling 数据，Occlusion Culling 就会按预期工作。

共享 Occlusion Culling 数据资源的文件大小更大，但使用更大的资源不会额外增加运行时 CPU 开销。有关在 Unity Editor 中处理多个 Scene 的更多信息，请参阅[多 Scene 编辑](https://docs.unity3d.com/6000.7/Documentation/Manual/MultiSceneEditing.html)。
