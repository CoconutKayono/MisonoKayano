# 使用 Occlusion Culling 排除隐藏对象

> 原文：[Excluding hidden objects with occlusion culling](https://docs.unity3d.com/6000.7/Documentation/Manual/OcclusionCulling-landing.html)

关于如何阻止 Unity 对隐藏 GameObject 执行渲染计算的资源。

> [!NOTE]
> 如果项目使用 Universal Render Pipeline（URP）或 High Definition Render Pipeline（HDRP），也可以使用 [[10-URP中的GPU遮挡剔除]]，或参考 [HDRP 中的 GPU Occlusion Culling](https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.4/manual/gpu-culling.html)。

Occlusion Culling 与 Frustum Culling 不同：Frustum Culling 排除位于相机 View Frustum 外的对象，而 Occlusion Culling 还会排除虽然位于 Frustum 内、但被其他对象挡住的对象。
