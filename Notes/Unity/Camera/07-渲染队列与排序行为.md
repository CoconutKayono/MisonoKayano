# Render Queue 与排序行为

> 原文：[Render queues and sorting behaviours](https://docs.unity3d.com/6000.7/Documentation/Manual/built-in-rendering-order.html)

Unity 渲染对象的顺序取决于两个因素：对象所在的 Render Queue，以及 Unity 如何在该 Render Queue 内对对象排序。

## Render Queue

Unity 会将对象分到称为 Render Queue 的组中。Unity 会先渲染一个 Render Queue 的内容，再渲染下一个 Render Queue 的内容，以此类推。

Unity 具有以下命名 Render Queue，并按以下顺序渲染：

| 名称 | 索引 | 说明 |
| --- | ---: | --- |
| **Background** | 1000 | 用于绘制 Scene 背景中的内容。 |
| **Geometry** | 2000 | 用于不透明几何体，是默认 Queue。 |
| **AlphaTest** | 2450 | 用于 alpha tested 几何体。它位于 **Geometry** Queue 之后，因为在所有实体对象绘制完成后渲染 alpha-tested 对象更加高效。 |
| **Transparent** | 3000 | 用于所有 alpha-blended 内容，即不写入 depth buffer 的 Shader，例如玻璃或粒子效果。 |
| **Overlay** | 4000 | 用于渲染在其他所有内容之上的效果，例如 lens flare。 |

请注意，Skybox 材质是特殊情况。Unity 会在所有不透明几何体之后（Queue 索引 2500 之后），但在所有透明几何体之前（Queue 索引 2501 之前）绘制 Skybox 材质。

## Render Queue 内的排序行为

在每个 Render Queue 内，Unity 会根据对象与 Camera 的距离对对象排序和绘制。排序行为取决于 Render Queue 的索引：

- 对于索引小于或等于 2500（Geometry + 500）的 Queue，Unity 默认使用 `OpaqueSortMode.FrontToBack` 定义的行为对 Renderer 排序。
- 对于索引为 2501 或更高的 Queue，Unity 默认使用 `TransparencySortMode.Default` 定义的行为对 Renderer 排序。

## 设置 Camera 如何对材质排序

更改 Render Queue 内排序行为的方式取决于 Render Queue 的索引：

- 对于索引小于或等于 2500（Geometry + 500）的 Queue，可以使用 [`Camera.opaqueSortMode`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Camera-opaqueSortMode.html) API 更改 Camera 的 opaque sort mode。
- 对于索引为 2501 或更高的 Queue，可以使用 [`Rendering.GraphicsSettings.transparencySortMode`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Rendering.GraphicsSettings-transparencySortMode.html) API 更改默认 transparent sort mode，也可以使用 [`Camera.transparencySortMode`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Camera-transparencySortMode.html) API 更改 Camera 的 transparent sort mode。
