# URP 中的运动矢量简介

> 原文：[Introduction to motion vectors in URP](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/features/motion-vectors.html)

URP 使用 motion vector render pass 计算表面片段在相邻帧之间的屏幕空间运动。URP 将运动数据存储在全屏纹理中，其中每个像素存储的运动数据称为 motion vector。

只有当当前帧中存在请求 motion vector render pass 的活动功能时，Unity 才会执行该 pass。例如，Temporal Anti-Aliasing 和 Motion Blur 等 URP 功能会请求 motion vector pass。有关自定义 pass 如何请求 motion vector pass 的信息，请参阅“在 Pass 中使用运动矢量纹理”。

错误或缺失的 motion vector 可能导致依赖该数据的效果出现视觉伪影。应按照本页的说明设置对象的 Renderer、Material 和 Shader，确保它们正确支持 motion vector。

URP 只支持不透明 Material 的 motion vector，包括 Alpha Clipping 材质。URP 不支持透明 Material 的 motion vector。

## 实现细节

本节介绍 URP 如何实现 motion vector。

### Motion vector 的定义

Motion vector 是一个二维向量，表示表面片段相对于 Camera、从上一帧到当前帧的运动，并且该运动被投影到 Camera 的 near clipping plane 上。

Motion vector texture 使用两个通道（`R` 和 `G`）。每个 texel 存储一个可见表面片段的 UV 偏移量。对于给定 texel，从它当前的 UV 坐标中减去 motion vector，就可以得到该 texel 在上一帧屏幕上的 UV 坐标。计算出的上一帧 UV 坐标可能超出屏幕边界。

### Object motion vector 与仅 Camera motion vector

Motion vector 分为两类：

- `Camera motion vector`：只由 Camera 自身的运动造成的 motion vector。
- `Object motion vector`：由 Camera 的运动与该片段所属对象的 world-space 运动共同造成的 motion vector。

只查看 motion vector texture，无法判断某个片段的屏幕运动究竟来自 Camera、对象，还是二者的组合。

计算 Camera motion vector 只需要执行一次全屏 Pass。该 Pass 每帧的计算量固定，不受场景复杂度影响；它只需要知道屏幕上所有像素当前的 3D 位置，以及 Camera 的运动情况。这些信息可以根据 depth buffer 和当前帧、上一帧的 Camera 矩阵推导出来。

Object motion vector 的计算量取决于场景中运动对象的数量和复杂程度，因为必须为每个对象执行一次绘制，才能计算该对象的运动。每次绘制也必须同时加入 Camera 的运动影响。

### Unity 何时渲染每对象的 Motion Vector

当以下条件满足时，Unity 会在一帧中为某个 Mesh 渲染 object motion vector：

1. 与 Mesh 关联的 Shader 在活动的 `SubShader` 区块中包含 `MotionVectors` Pass。
2. Mesh 通过以下某一种 Renderer 渲染：
   - `SkinnedMeshRenderer`。
   - `MeshRenderer`，并且它的 `Motion Vectors` 属性没有设置为 `Camera Motion Only`。
   - 使用 `Graphics.RenderMesh`、`Graphics.RenderMeshInstanced` 或 `Graphics.RenderMeshIndirect` API，并且 `RenderParams` 结构体的 `MotionVectorMode` 成员没有设置为 `Camera`。
3. 满足以下任一条件：
   - `MeshRenderer` 的 `MotionVectorGenerationMode` 属性，或 `Graphics.RenderMesh...` API 的 `RenderParams.MotionVectorMode` 成员设置为 `ForceNoMotion`。`ForceNoMotion` 要求每帧渲染每对象的 motion vector pass，这样才能用零值覆盖此类对象的 Camera motion vector。
   - Material 启用了 `MotionVectors` Pass，例如 Shader Graph 或 Alembic 动画包含顶点动画。
   - Material 没有启用 `MotionVectors` Pass，但当前帧和上一帧的 model matrix 不匹配，或者对象带有骨骼动画。如果 Renderer 静止且没有骨骼动画，即使其 Shader 包含 MotionVectors Pass，只要 Material 禁用了该 Pass，就不会为它渲染每对象的 motion vector pass。

### URP 预构建 Shader 中的 MotionVectors Pass

对于预构建 Shader，当 `MotionVectors` Pass 启用时，Unity 会为 Mesh Renderer 渲染 object motion vector，即使 Mesh Renderer 本身没有移动。

在以下条件满足时，Unity 会在 URP 预构建 Shader 中启用 `MotionVectors` Pass：

- 对于 URP ShaderLab Shader：在 Material 的 `Advanced Options` 区域启用 `Alembic Motion Vectors` 属性。
- 对于 URP Lit 和 Unlit Shader Graph Shader：在 `Graph Inspector` 中启用 `Alembic Motion Vectors`，或者将 `Additional Motion Vectors` 属性设置为 `TimeBased` 或 `Custom`。
