# 以第一人称控制相机

> 原文：[Control a camera in first person](https://docs.unity3d.com/6000.7/Documentation/Manual/control-camera.html)

可以在观察相机的同时浏览 Scene view。在第一人称视角下从相机镜头中工作，可以更好地完成镜头构图。

使用 **Cameras Overlay** 可以选择并控制附加了 `Camera` 或 `Cinemachine Camera` Component 的 GameObject。

控制相机时，可以像使用 Scene Camera 一样使用 Editor tools。例如，选择 GameObject 后按 `F`，可以让相机聚焦到该对象。也可以在观察相机画面的同时调整 GameObject 的 position、orientation 和 scale，从而改变镜头构图。

可以通过 Cameras Overlay 调整直接控制的相机的 overscan。overscan 可以让你有意看到比相机最终输出更多或更少的 Scene 内容。

Cameras Overlay 支持 Timeline 和 Animation 的相机路径制作，也支持 Animated Camera。以第一人称控制相机，可以为相机的 GameObject 制作动画并生成 keyframe。

## 操作步骤

1. 按 `` ` `` 打开 **Overlays** 菜单。
2. 在 Overlays 菜单中启用 **Cameras** Overlay。
3. 在 Cameras Overlay 的下拉列表中选择要控制的相机。
4. 选择 **Control selected camera in first person**。
5. 如需调整 overscan 的大小和不透明度，选择 **Configure overscan settings**：
   - 在 **Overscan** 中输入数值，或使用 mouse scroll wheel 设置 view guide 大小。默认值为 `1`；大于 `1` 可以看到超出 Camera Frustum 的区域，小于 `1` 可以放大查看更小区域。
   - 在 **Overscan Opacity** 中输入数值，调整 view guide 的不透明度。
6. 使用 Scene view navigation controls 在 Scene 中移动相机。
7. 要退出相机视图，在 Cameras Overlay 中选择 **Return to Scene Camera**。
