# 从相机发射 Ray

> 原文：[Cast a ray from a camera](https://docs.unity3d.com/6000.7/Documentation/Manual/CameraRays-cast.html)

从 Camera 发射 Ray 最常见的用途，是向 Scene 中执行 Raycast。Raycast 会从 Ray 的 origin 沿 Ray 前进，直到命中 Scene 中的 Collider，然后在 `RaycastHit` 对象中返回命中对象及命中点的信息。

这是一种根据对象屏幕图像定位对象的常用方法。例如，可以确定 mouse position 对应的对象：

```csharp
using UnityEngine;
using System.Collections;

public class ExampleScript : MonoBehaviour {
    public Camera camera;

    void Start(){
        RaycastHit hit;
        Ray ray = camera.ScreenPointToRay(Input.mousePosition);

        if (Physics.Raycast(ray, out hit)) {
            Transform objectHit = hit.transform;

            // 处理 Raycast 命中的对象。
        }
    }
}
```
