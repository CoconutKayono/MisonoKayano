# 相机输出简介

> 原文：[Introduction to camera output](https://docs.unity3d.com/6000.7/Documentation/Manual/CameraOutput-introduction.html)

Camera 可以生成 depth、depth+normals 或 motion vector texture。这是一种最小化的 G-buffer texture，可用于 post-processing effect 或实现 custom lighting model。

这些 texture 主要由 effect 使用，例如 post-processing effect 经常使用 depth 信息。

Depth Texture 的像素值范围为 `0` 到 `1`，并且采用非线性分布。根据配置和使用的平台，精度通常为 32 位或 16 位。从 Depth Texture 读取时，会返回范围在 `0` 到 `1` 之间的高精度值。如果需要获得距 Camera 的距离，或其他线性的 `0–1` 值，请使用 helper macro 手动计算。

Depth Texture 受大多数现代硬件和图形 API 支持。特殊要求包括：

- Direct3D 11+（Windows）、OpenGL 3+（Mac/Linux）、Metal（iOS）以及主流游戏主机支持 depth texture。

可以通过脚本中的 [`Camera.depthTextureMode`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Camera-depthTextureMode.html) 变量启用 Camera 的 depth Texture mode。也可以使用 [Shader Replacement](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-ShaderReplacement.html) 功能自行构建类似 texture。

共有三种 depth texture mode：

- `DepthTextureMode.Depth`：depth texture。
- `DepthTextureMode.DepthNormals`：将 depth 和 view space normals 打包到一个 texture 中。
- `DepthTextureMode.MotionVectors`：当前帧每个屏幕 texel 的 per-pixel screen space motion，打包为 `RG16` texture。

这些值是 flags，因此可以指定上述 texture 的任意组合。

## 内部实现

> [!IMPORTANT]
> Built-In Render Pipeline 已弃用，并将在未来版本中变为 obsolete。在整个 Unity 6.7 LTS 生命周期内，它仍受支持，包括 bug 修复和维护。有关迁移信息，请参阅[从 Built-In Render Pipeline 迁移到 URP](https://docs.unity3d.com/6000.7/Documentation/Manual/urp/upgrading-from-birp.html)和[Render Pipeline 功能比较](https://docs.unity3d.com/6000.7/Documentation/Manual/render-pipelines-feature-comparison.html)。

Depth texture 可以直接来自实际 depth buffer，也可以根据使用的 rendering path 和硬件，在单独的 pass 中渲染。通常在 Built-In Render Pipeline 使用 Deferred Shading rendering path 时，depth texture 几乎没有额外成本，因为它本来就是 G-buffer 渲染的产物。

启用后，MotionVectors texture 始终来自额外的 render pass。Unity 会将移动的 GameObject 渲染到该 buffer，并构造它们从上一帧到当前帧的运动。
