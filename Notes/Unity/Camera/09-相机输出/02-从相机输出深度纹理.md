# 从相机输出深度纹理

> 原文：[Output a depth texture from a camera](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-CameraDepthTexture.html)

使用 `DepthTextureMode` 可以从 Camera 输出 depth texture 或 depth-normals texture。

## DepthTextureMode.Depth texture

这会构建一个与屏幕大小相同的 depth texture。

Depth texture 使用与 shadow caster rendering 相同的 Shader pass（`ShadowCaster` pass type）进行渲染。因此，如果 Shader 不支持 shadow casting（Shader 或其任何 fallback 中没有 shadow caster pass），使用该 Shader 的对象不会出现在 depth texture 中。

- 让 Shader [fallback](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-Fallback.html) 到包含 shadow casting pass 的其他 Shader；或者
- 如果使用 [surface shader](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-SurfaceShaders.html)，添加 `addshadow` 指令，使其也生成 shadow pass。

请注意，只有“opaque”对象（材质和 Shader 设置为使用小于或等于 2500 的 [render queue](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-SubShaderTags.html)）会被渲染到 depth texture 中。

## DepthTextureMode.DepthNormals texture

这会构建一个屏幕大小的 32 位（每通道 8 位）texture，其中 view space normals 编码在 R&G 通道中，depth 编码在 B&A 通道中。Normals 使用 Stereographic projection 编码，depth 是打包到两个 8 位通道中的 16 位值。

[`UnityCG.cginc`](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-BuiltinIncludes.html) include file 提供 `DecodeDepthNormal` helper function，用于从编码后的像素值解码 depth 和 normal。返回的 depth 范围为 `0..1`。

有关如何使用 depth 和 normals texture 的示例，请参阅[运行时替换 Shader](https://docs.unity3d.com/6000.7/Documentation/Manual/SL-ShaderReplacement.html)，或[后处理和全屏效果](https://docs.unity3d.com/6000.7/Documentation/Manual/PostProcessingOverview.html)中的 Ambient Occlusion。
