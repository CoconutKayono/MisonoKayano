# 日志文件参考

> 原文：[Log files reference](https://docs.unity3d.com/6000.7/Documentation/Manual/log-files.html)

Unity 会为 Unity Editor、Package Manager、许可、Development Player 和 Unity Hub 生成日志文件。你可以使用这些日志文件了解应用程序中发生问题的位置。

Unity 会将 [Console 窗口](https://docs.unity3d.com/6000.7/Documentation/Manual/Console.html)中的所有消息、警告和错误添加到日志文件中。要向 Console 窗口和日志添加自定义消息，请使用 [[03-Debug类|Debug 类]]。

你可以在项目代码中使用 [`Application.consoleLogPath`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Application-consoleLogPath.html) 属性，获取当前正在运行的 Editor 或 Player 应用程序的日志位置。

> **注意：** 并非所有平台都支持此功能。有关更多信息，请参阅[平台开发](https://docs.unity3d.com/6000.7/Documentation/Manual/PlatformSpecific.html)。

<a id="log-locations"></a>

## Editor 相关日志位置

默认情况下，Editor 会将日志消息写入与打开的项目对应的日志文件。该文件位于项目文件夹中的 `ProjectName/Logs/Editor.log`。

如果希望 Editor 改为写入单个全局日志文件，可以在 [Preferences 窗口](https://docs.unity3d.com/6000.7/Documentation/Manual/preferences-general.html) 中启用 **Use Global Editor Log**，也可以使用 Editor [命令行参数](https://docs.unity3d.com/6000.7/Documentation/Manual/EditorCommandLineArguments.html) `-useGlobalLog`。该全局日志由系统上的所有 Unity 项目和所有 Editor 实例共享。各平台默认的全局 Editor 日志位置请参阅下面的 [Linux](#linux)、[macOS](#mac-os) 和 [Windows](#windows) 表格。

如果在 [Preferences](https://docs.unity3d.com/6000.7/Documentation/Manual/preferences-general.html) 中启用 **Enable logging framework**，还可以启用 **Enable JSON logging**，以 JSON Lines 格式存储日志。Logging framework 只支持相对于项目的日志记录，Editor 会将 JSON 日志写入 `ProjectName/Logs/Editor.jsonl`。但是，Editor 启动时 Unity 收集的日志会先写入全局日志位置；选择项目后，这些日志会被复制到相对于项目的日志位置。

> **提示：** 建议使用默认的项目专属 Editor 日志。如果多个项目或 Editor 实例向同一个文件写入内容，全局日志文件可能会变得混乱且难以调试。项目专属日志能提供更清晰的记录并简化调试，尤其是在你经常切换项目时。

每个操作系统都有自己的全局 Editor 日志默认位置，以及 Unity Hub 创建的项目位置。你可以在 [Hub](https://docs.unity.com/hub/projects) 的 **Projects** 部分更改 Unity Hub 创建新项目的位置。你还可以使用 `-logFile` 命令行参数指定日志位置。有关更多信息，请参阅 [Unity Editor 命令行参数](https://docs.unity3d.com/6000.7/Documentation/Manual/EditorCommandLineArguments.html)。

要直接从 Editor 访问 Editor 日志文件，请打开 Console 窗口（主菜单：**Window** > **General** > **Console**），然后从 More（⋮）菜单中选择 **Open Editor Log**。

当 Editor 能够解析项目路径时，Package Manager 日志默认写入 `[ProjectPath]/Logs/upm.log`。使用 `-useGlobalLog` 启动 Editor，或无法解析项目路径时，下面表格中列出的全局备用位置会生效。无论其他设置如何，都可以使用 `-upmLogFile <pathname>` 命令行参数将 Package Manager 日志指定到其他位置；该参数具有最高优先级。有关更多信息，请参阅 [Unity Editor 命令行参数](https://docs.unity3d.com/6000.7/Documentation/Manual/EditorCommandLineArguments.html)。

<a id="linux"></a>

### Linux

| 日志类型 | 日志位置 |
| --- | --- |
| **Editor** | [全局](#log-locations) Editor 日志：`~/.config/unity3d/Editor.log` |
| **Editor（JSON）** | [全局](#log-locations) JSON 日志：`~/.config/unity3d/Editor.jsonl` |
| **Package Manager** | `[ProjectPath]/Logs/upm.log`（默认）<br>全局备用位置：`~/.config/unity3d/upm.log` |
| **Licensing client** | `~/.config/unity3d/Unity/Unity.Licensing.Client.log` |
| **Licensing audits** | `~/.config/unity3d/Unity/Unity.Entitlements.Audit.log` |

<a id="mac-os"></a>

### macOS

在 macOS 上，你还可以通过 Console.app 实用工具访问 Unity 的日志。

| 日志类型 | 日志位置 |
| --- | --- |
| **Editor** | [全局](#log-locations) Editor 日志：`~/Library/Logs/Unity/Editor.log` |
| **Editor（JSON）** | [全局](#log-locations) JSON 日志：`~/Library/Logs/Unity/Editor.jsonl` |
| **Package Manager** | `[ProjectPath]/Logs/upm.log`（默认）<br>全局备用位置：`~/Library/Logs/Unity/upm.log` |
| **Licensing client** | `~/Library/Logs/Unity/Unity.Licensing.Client.log` |
| **Licensing audits** | `~/Library/Logs/Unity/Unity.Entitlements.Audit.log` |

<a id="windows"></a>

### Windows

在 Windows 上，全局 Editor 日志和 Package Manager 全局备用日志位于 Windows Explorer 默认不显示的文件夹中。要查看 `AppData` 文件夹，必须在 Windows 中启用 Hidden Items 设置。有关如何执行此操作的更多信息，请参阅 Microsoft 文档中的 [Windows 文件资源管理器](https://support.microsoft.com/en-us/windows/view-hidden-files-and-folders-in-windows-97fbc472-c603-9d90-91d0-1166d1d9f4b5)。

在 Windows 上，默认不存在 standard out 流，因此必须将 Editor 作为持续集成（CI）系统的子进程启动，并为其配置有效的 `stdout` 流。如果指定 `-` 将输出发送到 `stdout`，输出不会显示在 Console 窗口中。

| 日志类型 | 日志位置 |
| --- | --- |
| **Editor** | [全局](#log-locations) Editor 日志：`%LOCALAPPDATA%\Unity\Editor\Editor.log` |
| **Editor（JSON）** | [全局](#log-locations) JSON 日志：`%LOCALAPPDATA%\Unity\Editor\Editor.jsonl` |
| **Package Manager** | `[ProjectPath]\Logs\upm.log`（默认）<br>全局备用位置（User account）：`%LOCALAPPDATA%\Unity\Editor\upm.log`<br>全局备用位置（SYSTEM account）：`%ALLUSERSPROFILE%\Unity\Editor\upm.log` |
| **Licensing client** | `%LOCALAPPDATA%\Unity\Unity.Licensing.Client.log` |
| **Licensing audits** | `%LOCALAPPDATA%\Unity\Unity.Entitlements.Audit.log` |
| **Crash files** | `%TMP%\Unity\Editor\Crashes`<br><br>**注意：** 可以使用 `-crash-report-folder` 命令行参数覆盖文件夹位置。 |

<a id="player"></a>

## Player 相关日志位置

要查看 Player 日志，请打开 Console 窗口（主菜单：**Window** > **General** > **Console**），然后从 Console 窗口菜单中选择 **Open Player Log**。你也可以导航到以下文件夹：

| 操作系统 | Player 日志位置 |
| --- | --- |
| **Android** | 要访问 Android 应用程序的 Player 日志，请使用 [Android logcat](https://developer.android.com/studio/command-line/logcat)。有关更多信息，请参阅[查看 Android 日志](https://docs.unity3d.com/6000.7/Documentation/Manual/android-debugging-on-an-android-device.html#view-android-logs)。 |
| **iOS** | 使用 GDB Console，或通过 XCode 使用 Organizer Console，访问 iOS 设备日志。有关设备日志的更多信息，请参阅 [Apple 文档](https://developer.apple.com/documentation/xcode/acquiring-crash-reports-and-diagnostic-logs)。 |
| **Linux** | `~/.config/unity3d/CompanyName/ProductName/Player.log` |
| **macOS** | `~/Library/Logs/Company Name/Product Name/Player.log`<br><br>**注意：** 也可以使用 Console.app 实用工具查找日志文件。 |
| **Universal Windows Platform** | `%USERPROFILE%\AppData\Local\Packages\<productname>\TempState\UnityPlayer.log` |
| **Web** | Unity 会将日志输出写入[浏览器的 JavaScript Console](https://docs.unity3d.com/6000.7/Documentation/Manual/webgl-debugging.html)。 |
| **Windows** | `%USERPROFILE%\AppData\LocalLow\CompanyName\ProductName\Player.log` |

### Player 崩溃文件（仅限 Windows）

有关 Windows 上 Player 崩溃文件的位置，请参阅 [`CrashReporting.crashReportFolder`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Windows.CrashReporting-crashReportFolder.html)。

## Unity Hub 日志位置

你可以使用操作系统的文件管理器应用程序访问 Hub 日志，也可以从 Hub 内部访问这些日志。有关更多信息，请参阅 [Hub 文档](https://docs.unity3d.com/hub/manual/Help.html)。

| 操作系统 | Player 日志位置 |
| --- | --- |
| **Linux** | `~/.config/UnityHub/logs/info-log.json` |
| **macOS** | `~/Library/Application Support/UnityHub/logs/info-log.json` |
| **Windows** | `%UserProfile%\AppData\Roaming\UnityHub\logs\info-log.json` |
