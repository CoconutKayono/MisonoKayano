# 编写参数化测试

> 原文：[Parameterized tests](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/reference-tests-parameterized.html)

Unity Test Framework 支持参数化测试，这对于数据驱动测试很有用。

普通 NUnit 测试支持使用 [`[TestCase]`](https://docs.nunit.org/articles/nunit/writing-tests/attributes/testcase.html) 和 [`[ValueSource]`](https://docs.nunit.org/articles/nunit/writing-tests/attributes/valuesource.html) 特性进行参数化测试。Unity 测试只支持 `ValueSource`。

以下示例演示如何在 Unity 测试中使用 `ValueSource`：

```csharp
static int[] values = new int[] { 1, 5, 6 };

[UnityTest]
public IEnumerator MyTestWithMultipleValues([ValueSource("values")] int value)
{
    yield return null;
}
```

## 根据参数忽略测试

你可以使用 [ParameterizedIgnoreAttribute](https://docs.unity3d.com/Packages/com.unity.test-framework@latest/index.html?subfolder=/api/UnityEngine.TestTools.ParametrizedIgnoreAttribute.html)，根据传递给测试方法的参数选择性地忽略测试。
