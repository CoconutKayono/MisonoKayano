# 测试前后的操作

> 原文：[Performing actions before and after tests](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/before-and-after-tests.html)

通过执行适当的测试前设置和测试后清理工作，确保测试在正确的状态下运行，从而编写可靠的测试。Unity Test Framework 提供一系列 API，让你可以在测试运行前后定义的阶段执行工作。

| 主题 | 说明 |
| --- | --- |
| **[[03-UnitySetUp和UnityTearDown]]** | 使用 Unity Test Framework API 设置和清理测试。 |
| **[[04-测试前后执行操作]]** | 使用 [IOuterUnityTestAction](https://docs.unity3d.com/Packages/com.unity.test-framework@latest/index.html?subfolder=/api/UnityEngine.TestTools.IOuterUnityTestAction.html) API，在测试外部、设置之前以及清理之后执行工作。 |
| **[[02-构建时设置和清理]]** | 在构建测试之前修改 Unity 或文件系统，然后在测试运行后清理这些修改。 |
| **[[01-测试操作执行顺序]]** | 了解测试操作彼此执行的先后顺序。 |
