# 指定要运行的测试

> 原文：[Specify which tests to run](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/extension-run-tests.html)

要从代码运行测试，请在 TestRunnerApi 上调用 Execute，并使用 Filter 指定要运行的测试。

下面的示例运行项目中的所有 Play Mode 测试：

~~~csharp
var testRunnerApi = ScriptableObject.CreateInstance<TestRunnerApi>();
var filter = new Filter()
{
    testMode = TestMode.PlayMode
};
testRunnerApi.Execute(new ExecutionSettings(filter));
~~~

## 多个筛选值

可以在 Filter 类中设置其他字段，以创建更具体的筛选条件。

许多字段允许使用多个值。当为一个字段指定多个值时，测试运行器会运行至少匹配其中一个值的测试。

下面的示例运行完整名称匹配两个指定名称之一的测试：

~~~csharp
var api = ScriptableObject.CreateInstance<TestRunnerApi>();
api.Execute(new ExecutionSettings(new Filter()
{
    testNames = new[] {"MyTestClass.NameOfMyTest", "SpecificTestFixture.NameOfAnotherTest"}
}));
~~~

## 多个筛选字段

如果为一个筛选器设置多个字段，测试运行器只会运行同时匹配所有字段的测试。

下面的示例会运行指定程序集中的测试，并且测试名称必须匹配两个指定名称之一：

~~~csharp
var api = ScriptableObject.CreateInstance<TestRunnerApi>();
api.Execute(new ExecutionSettings(new Filter()
{
    assemblyNames = new [] {"MyTestAssembly"},
    testNames = new [] {"MyTestClass.NameOfMyTest", "MyTestClass.AnotherNameOfATest"}
}));
~~~

## 多个构造函数筛选器

ExecutionSettings 的构造函数可以接收一个或多个筛选器。如果没有提供筛选器，默认运行所有 Edit Mode 测试。如果提供多个筛选器，只要测试匹配其中任意一个筛选器，就会运行该测试。

下面的示例会运行名为 MyTestAssembly 的程序集中的所有测试，以及名称匹配两个指定名称之一的测试：

~~~csharp
var api = ScriptableObject.CreateInstance<TestRunnerApi>();
api.Execute(new ExecutionSettings(
    new Filter()
    {
        assemblyNames = new[] {"MyTestAssembly"},
    },
    new Filter()
    {
        testNames = new[] {"MyTestClass.NameOfMyTest", "MyTestClass.AnotherNameOfATest"}
    }
));
~~~

> **注意：** 目前不支持在每个 Filter 中指定不同的测试模式或平台。测试模式和平台取自第一个 Filter；如果未指定，则默认使用 Edit Mode。
