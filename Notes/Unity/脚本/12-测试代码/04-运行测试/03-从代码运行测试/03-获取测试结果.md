# 获取测试结果

> 原文：[Retrieve test results](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/extension-get-test-results.html)

可以在活动测试运行或单个测试开始和结束时接收回调。要注册回调，请在 [TestRunnerApi](https://docs.unity3d.com/Packages/com.unity.test-framework@latest/index.html?subfolder=/api/UnityEditor.TestTools.TestRunner.Api.TestRunnerApi.html) 上调用 RegisterCallbacks，并传入实现 [ICallbacks](https://docs.unity3d.com/Packages/com.unity.test-framework@latest/index.html?subfolder=/api/UnityEditor.TestTools.TestRunner.Api.ICallbacks.html) 的类实例。ICallbacks 包含四个方法，分别用于整个测试运行以及测试树各层级的开始和结束。

下面的示例展示了如何设置监听器：

> **注意：** Listener 会接收所有测试运行的回调，与注册该 Listener 的 TestRunnerApi 是否对应这些测试运行无关。

~~~csharp
public void SetupListeners()
{
   var api = ScriptableObject.CreateInstance<TestRunnerApi>();
   api.RegisterCallbacks(new MyCallbacks());
}

private class MyCallbacks : ICallbacks
{
    public void RunStarted(ITestAdaptor testsToRun)
    {
       
    }

    public void RunFinished(ITestResultAdaptor result)
    {
       
    }

    public void TestStarted(ITestAdaptor test)
    {
       
    }

    public void TestFinished(ITestResultAdaptor result)
    {
        if (!result.HasChildren && result.ResultState != "Passed")
        {
            Debug.Log(string.Format("Test {0} {1}", result.Test.Name, result.ResultState));
        }
    }
}
~~~

> **注意：** 注册的回调不会在 Domain Reload 后保留。因此，必须在 Domain Reload 后重新注册回调，通常可以使用 [InitializeOnLoad](https://docs.unity3d.com/6000.7/Documentation/Manual/RunningEditorCodeOnLaunch.html) 完成。

注册回调时，可以将整数作为第二个参数传入 RegisterCallbacks，以提供 priority。priority 会影响不同回调的调用顺序，默认值为 0。

还可以向 RegisterCallbacks 传入实现 [IErrorCallbacks](https://docs.unity3d.com/Packages/com.unity.test-framework@latest/index.html?subfolder=/api/UnityEditor.TestTools.TestRunner.Api.IErrorCallbacks.html) 的类实例。IErrorCallbacks 是 ICallbacks 的扩展版本，并增加了 OnError 回调。当测试运行无法启动时会调用 OnError，例如发生编译错误，或 [[../../03-编写测试/01-测试前后的操作/02-构建时设置和清理#prebuildsetup-and-postbuildcleanup|IPrebuildSetup]] 抛出异常时。
