# 测试 Lost Crypt

> 原文：[Testing Lost Crypt](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/LostCrypt/lost-crypt-introduction.html)

欢迎阅读 Unity Test Framework（UTF）培训材料。

本培训由一系列练习组成，从较基础的主题开始，再逐步扩展这些知识。每个章节都有“学习目标”部分，可以帮助你选择能够学习新内容的练习。练习按主题分组，难度各不相同。

> **本课程专注于测试一个实际游戏。选择的项目是 [LostCrypt](https://assetstore.unity.com/packages/essentials/tutorial-projects/lost-crypt-2d-sample-project-158673) 示例项目。**
