# 3. 语义测试断言

> 原文：[3. Semantic test assertion](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/semantic-test-assertion.html)

## 学习目标

本练习将介绍 `Assert.That` 及其相关类。

## 简介与动机

NUnit Test Framework 和 Unity Test Framework 都提供了一系列断言类，可以用更接近自然语言的方式断言对象。这使语句更容易阅读。

下面是语义断言类的使用示例：

```csharp
Assert.That(myValue, Is.GreaterThan(20));
Assert.That(str, Does.Contain("a string").And.Contain("something else"));
```

这里检查变量 `myValue` 是否大于 20，然后检查字符串 `str` 是否同时包含 `"a string"` 和 `"something else"`。

语义断言也称为 [Constraint Model](https://docs.nunit.org/articles/nunit/writing-tests/assertions/assertion-models/constraint.html)。除了 `Is` 和 `Does`，还有许多其他可以使用的关键字。

## 练习

在 `3_SemanticTestAssertion` [sample](https://docs.unity3d.com/6000.7/Documentation/Manual/test-framework/course/test-framework-general-introduction.html#import-samples) 中，有一个名为 `ValueOutputter` 的类，它会返回不同类型的值。

请编写测试，断言它输出的不同结果。需要验证：

- `GetInt()` 返回 11。
- `GetString()` 返回一个包含 `string` 和 `asserted` 这两个单词的字符串。
- `GetFloat()` 返回一个约为 19.33 的值。

## 提示

- 对浮点数进行断言时，可能需要检查值大于 19.33 且小于 19.34，因为输出结果不是有理数的精确表示。

## 解决方案

本练习的完整解决方案位于 sample `3_SemanticTestAssertion_Solution` 中。

```csharp
internal class ValueOutputterTests
{
    [Test]
    public void GivesExpectedInt()
    {
        var outputterUnderTest = new ValueOutputter();

        var number = outputterUnderTest.GetInt();

        Assert.That(number, Is.EqualTo(11));
    }

    [Test]
    public void GivesExpectedString()
    {
        var outputterUnderTest = new ValueOutputter();

        var str = outputterUnderTest.GetString();

        Assert.That(str, Does.Contain("string").And.Contain("asserted"));
    }

    [Test]
    public void GivesExpectedFloat()
    {
        var outputterUnderTest = new ValueOutputter();

        var number = outputterUnderTest.GetFloat();

        Assert.That(number, Is.GreaterThan(19.33f).And.LessThan(19.34f));
    }
}
```
