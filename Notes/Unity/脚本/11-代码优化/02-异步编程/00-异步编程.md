# 使用 Awaitable 类进行异步编程

> 原文：[Asynchronous programming with the Awaitable class](https://docs.unity3d.com/6000.7/Documentation/Manual/async-await-support.html)

异步编程允许代码执行长期运行的任务，而不会阻塞主线程。这样，应用程序在等待异步任务完成时仍能保持响应，并执行其他任务。

Unity 支持使用 .NET [`async`](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/async) 关键字和 [`await`](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/operators/await) 运算符的简化异步编程模型。

在阅读 Unity 中的异步编程之前，请确保理解 .NET 异步编程的基础元素。如需重要背景信息，请参阅[使用 async 和 await 进行异步编程](https://learn.microsoft.com/en-us/dotnet/csharp/asynchronous-programming/)和[Task 异步编程模型](https://learn.microsoft.com/en-us/dotnet/csharp/asynchronous-programming/task-asynchronous-programming-model)。
