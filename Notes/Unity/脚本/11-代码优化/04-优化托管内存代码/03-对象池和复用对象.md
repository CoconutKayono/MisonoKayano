# 对象池和复用对象

> 原文：[Pooling and reusing objects](https://docs.unity3d.com/6000.7/Documentation/Manual/performance-reusable-code.html)

对象池和复用是一种编程模式：将频繁使用的对象实例放回对象池，需要时再从池中取出并重新使用。对象池可以减少反复实例化和销毁新对象所产生的开销，并限制整体分配和释放的次数。这有助于最大限度地降低垃圾回收（GC）开销和 CPU 负载。

可以池化 `GameObject`，也可以池化其他频繁使用的类型，包括数组、列表和字典等集合类型。你可以编写自己的池化逻辑，但 Unity 为方便使用，在 `UnityEngine.Pool` 命名空间中提供了一组 API，用于实现 `GameObject` 和若干集合类型的池化。

> [!NOTE]
> 与许多其他 Unity 核心 API 一样，`UnityEngine.Pool` API 不是线程安全的，只能从主线程安全调用。

## 池化和复用 GameObject

游戏中的某些对象类型（例如投射物）可能会反复且频繁地出现，即使场景中同时只有少量此类对象。与其每次发射时都从预制件实例化一个新的投射物对象，不如在游戏开始时创建一个投射物对象池，然后按需重复使用对象。

### 创建对象池

Unity 的 [`ObjectPool<T>`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Pool.ObjectPool_1.html) 类实现了可复用对象池模式，是在应用程序中实现对象池最简单的方式。`ObjectPool<T>` 的实例管理一组类型为 `T` 的对象。通过 [`ObjectPool<T>` 构造函数](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Pool.ObjectPool_1-ctor.html)创建 `ObjectPool<T>` 时，需要提供参数来定义对象池的以下关键方面：

- 对象池的起始容量。
- 对象池可扩展到的最大容量。
- 是否执行集合安全检查，以防止将同一个对象实例重复释放回对象池。
- 一系列 C# [`Action<T>`](https://learn.microsoft.com/en-us/dotnet/api/system.action-1?view=net-10.0) 委托。Unity 在对象池执行以下关键操作时调用相应的回调：
  - 从对象池取出对象时调用的回调。
  - 将对象返回对象池时调用的回调。
  - 请求对象但对象池为空时，创建新对象实例时调用的回调。
  - 对象返回对象池但对象池已达到最大容量时，销毁对象实例时调用的回调。

### 从对象池取出对象

调用 [`ObjectPool<T>.Get`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Pool.ObjectPool_1.Get.html) 可以从对象池取出对象。此操作还会调用传递给 `ObjectPool` 构造函数的 `actionOnGet` 参数对应的方法，让你有机会准备并激活对象。

如果对象池为空时请求对象，则会创建一个新的对象实例。创建过程会调用传递给 `ObjectPool` 构造函数的 `createFunc` 参数对应的方法。

`ObjectPool<T>.Get` 有一个 `Get(out PooledObject<T> pooledObject)` 重载。当 `PooledObject` 被释放时，它会自动释放其中的实例。这对于短生命周期的作用域很有用。

更多信息和代码示例，请参阅 [`PooledObject<T>.Get` API 参考](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Pool.PooledObject_1.Get.html)。

### 将对象返回对象池

对象使用完毕后，调用 [`ObjectPool<T>.Release`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Pool.ObjectPool_1.Release.html)，并将要返回的对象作为参数传入，即可将对象返回对象池。此操作还会调用传递给 `ObjectPool` 构造函数的 `actionOnRelease` 参数对应的方法，让你有机会停用并重置返回对象的状态。

如果在对象池已满时返回对象，该对象会被销毁。销毁过程会调用传递给 `ObjectPool` 构造函数的 `actionOnDestroy` 参数对应的方法。

将 `true` 作为构造函数的 `collectionCheck` 参数，可以启用集合安全检查。如果启用了集合检查，而你尝试返回一个已经在池中的对象，Unity 会抛出异常。即使启用了该功能，集合检查也只在 Editor 中可用，在 Player 构建中不可用。启用集合检查会产生额外开销，但可以捕获重复释放错误，因此建议在开发期间启用。

### 重置使用过的对象

从对象池取出的对象在使用期间可能会改变状态。例如，池化的敌人 `GameObject` 在场景中处于活动状态时，可能会改变位置、生命值、动画状态和物理状态。对象返回对象池时，必须重置这些状态，以便对象之后再次取出时，能够从与首次使用时相同的状态开始。

根据要重置的状态，可以选择在对象池的 `actionOnGet` 委托中取出对象时重置，也可以在 `actionOnRelease` 委托中将对象释放回对象池时重置。另一种选择，是在池化对象本身上实现自定义停用方法，然后从对象池的取出或释放操作中调用这些方法。

需要重置的状态取决于池化对象的具体行为和组件。释放对象时，常见的重置任务包括停止协程、取消订阅事件、重置物理状态、清除动画和停止粒子系统。同样重要的是，在释放时停用 `GameObject`，以免对象处于对象池中时仍接收 [`Update`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/MonoBehaviour.Update.html) 调用。

### 示例：池化投射物

投射物的典型 `ObjectPool<T>` 实现包含以下关键阶段：

1. 在游戏开始时创建一个由非活动投射物对象组成的对象池。向构造函数提供所需委托，以便在创建新池化对象、从对象池取出对象、将对象返回对象池以及因对象池已满而销毁对象时调用相应回调。
2. 需要投射物时（例如用户开火时），使用 `ObjectPool<T>.Get` 从对象池取出一个非活动投射物。在对应的 `actionOnGet` 回调中，激活取出的对象，并初始化其位置和方向等相关属性。
3. 投射物不再需要时（例如命中目标或飞出边界时），使用 `ObjectPool<T>.Release` 将其返回对象池。通常可以让投射物持有自身对象池的引用，以便在完成任务时自行释放。在对应的 `actionOnRelease` 回调中，停用返回的对象，并重置其速度和动画状态等相关属性。

下面是一个在 `ObjectPool<T>` 中池化的投射物脚本组件代码。注意，投射物有一个公共属性，用于让它获得自身对象池的引用；投射物会在延迟一段时间后使用这个引用将自身返回对象池：

```csharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.Pool;
public class RevisedProjectile : MonoBehaviour
{
    // Deactivate after delay
    [SerializeField] private float timeoutDelay = 3f;

    private IObjectPool<RevisedProjectile> objectPool;

    // Public property to give the projectile a reference to its ObjectPool
    public IObjectPool<RevisedProjectile> ObjectPool { set => objectPool = value; }

    public void Deactivate()
    {
        StartCoroutine(DeactivateRoutine(timeoutDelay));
    }

    IEnumerator DeactivateRoutine(float delay)
    {
        yield return new WaitForSeconds(delay);

        // Reset the moving Rigidbody
        Rigidbody rBody = GetComponent<Rigidbody>();
        rBody.linearVelocity = new Vector3(0f, 0f, 0f);
        rBody.angularVelocity = new Vector3(0f, 0f, 0f);

        // Release the projectile back to the pool
        objectPool.Release(this);
    }
}
```

下面是附加到炮塔上的组件代码。它负责发射投射物并管理投射物对象池；用户射击时，炮塔调用对象池上的 `Get` 来取出池化投射物：

```csharp
using UnityEngine;
using UnityEngine.Pool;
using UnityEngine.Events;

public class RevisedGun : MonoBehaviour
{
    [Tooltip("Prefab to shoot")]
    [SerializeField] private RevisedProjectile projectilePrefab;
    [Tooltip("Projectile force")]
    [SerializeField] private float muzzleVelocity = 1500f;
    [Tooltip("End point of gun where shots appear")]
    [SerializeField] private Transform muzzlePosition;
    [Tooltip("Time between shots / smaller = higher rate of fire")]
    [SerializeField] private float cooldownWindow = 0.1f;

    [SerializeField] private UnityEvent m_GunFired;

    // Stack-based ObjectPool available with Unity 2021 and above
    private IObjectPool<RevisedProjectile> objectPool;

    // Throw an exception if we try to return an existing item, already in the pool
    [SerializeField] private bool collectionCheck = true;

    // Extra options to control the pool capacity and maximum size
    [SerializeField] private int defaultCapacity = 20;
    [SerializeField] private int maxSize = 100;

    private float nextTimeToShoot;

    private void Awake()
    {
        objectPool = new ObjectPool<RevisedProjectile>(CreateProjectile,
            OnGetFromPool, OnReleaseToPool, OnDestroyPooledObject,
            collectionCheck, defaultCapacity, maxSize);
    }

    // Invoked when creating an item to populate the object pool
    private RevisedProjectile CreateProjectile()
    {
        RevisedProjectile projectileInstance = Instantiate(projectilePrefab);
        projectileInstance.ObjectPool = objectPool;
        return projectileInstance;
    }

    // Invoked when returning an item to the object pool
    private void OnReleaseToPool(RevisedProjectile pooledObject)
    {
        pooledObject.gameObject.SetActive(false);
    }

    // Invoked when retrieving the next item from the object pool
    private void OnGetFromPool(RevisedProjectile pooledObject)
    {
        pooledObject.gameObject.SetActive(true);
    }

    // Invoked when the maximum number of pooled items is exceeded (i.e. destroy the pooled object)
    private void OnDestroyPooledObject(RevisedProjectile pooledObject)
    {
        Destroy(pooledObject.gameObject);
    }

    private void FixedUpdate()
    {
        // Invokes the Shoot method if the delay time is exceeded
        if (Input.GetButton("Fire1") && Time.time > nextTimeToShoot && objectPool != null)
        {
            Shoot();
        }
    }

    private void Shoot()
    {
        // Get a pooled object instead of instantiating
        RevisedProjectile bulletObject = objectPool.Get();

        if (bulletObject == null)
            return;

        // Align to gun barrel/muzzle position
        bulletObject.transform.SetPositionAndRotation(muzzlePosition.position, muzzlePosition.rotation);

        // Move projectile forward
        bulletObject.GetComponent<Rigidbody>().AddForce(bulletObject.transform.forward * muzzleVelocity, ForceMode.Acceleration);

        // Turn off after a few seconds
        bulletObject.Deactivate();

        // Set cooldown delay
        nextTimeToShoot = Time.time + cooldownWindow;

        m_GunFired.Invoke();
    }
}
```

包含所有必要预制件和可运行炮塔（炮塔会发射池化投射物）的完整示例项目，可作为免费包从 [Asset Store](https://assetstore.unity.com/packages/essentials/tutorial-projects/level-up-your-code-with-design-patterns-and-solid-289616)下载。更多信息，请参阅 [Unity 中使用对象池提升 C# 脚本性能](https://learn.unity.com/course/design-patterns-unity-6/tutorial/use-object-pooling-to-boost-performance-of-c-scripts-in-unity#67a0d722edbc2a14cfcb7400)。

### 处理池化对象的场景卸载

默认情况下，对象池与创建它的场景绑定。当该场景被卸载时，Unity 会销毁该场景中的所有 `GameObject`，包括对象池和所有池化实例。

可以将对象池管理器放在根 `GameObject` 下，并在该对象上调用 [`object.DontDestroyOnLoad`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Object.DontDestroyOnLoad.html)，使对象池在场景重新加载后继续存在。在释放时，可以调用 [`transform.SetParent`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Transform.SetParent.html) 将池化项目重新设置为对象池根节点的子对象，使其不会随场景一起销毁。

如果场景卸载时场景中可能仍有活动的池化实例，请确保它们在 [`OnDisable`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/MonoBehaviour.OnDisable.html) 和 [`OnDestroy`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/MonoBehaviour.OnDestroy.html) 中自行释放，或者注册 [`SceneManager.activeSceneChanged`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/SceneManagement.SceneManager-activeSceneChanged.html) 回调来召回或销毁对象。

避免在非活动状态下长期持有对池化实例的引用。可以使用 [`ObjectPool<T>.Clear`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Pool.ObjectPool_1.Clear.html) 销毁所有非活动实例，例如在关卡之间调用该方法。

## 池化和复用集合类型

也可以池化和复用 [`System.Collection`](https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic?view=net-6.0) 命名空间中的集合对象，例如 `List` 和 `Dictionary`。

集合类提供了 `Clear` 方法，该方法会移除集合中的值，但不会释放已为集合分配的内存。这对于为复杂计算分配临时辅助集合很有用。

下面的示例代码每帧分配一次 `nearestNeighbors` `List` 来收集一组数据点，这是低效的不良实践：

```csharp
// Bad C# script example. This Update method allocates a new `List` every frame.
void Update() {

    List<float> nearestNeighbors = new List<float>();

    findDistancesToNearestNeighbors(nearestNeighbors);

    nearestNeighbors.Sort();

    // … use the sorted list somehow …
}
```

相反，可以将这个 `List` 从方法中提升到所在类中，并在每次使用时清除和复用它，这样代码就不必每帧分配新的 `List`：

```csharp
// Good C# script example. This method re-uses the same List every frame.
List<float> m_NearestNeighbors = new List<float>();

void Update() {

    m_NearestNeighbors.Clear();

    findDistancesToNearestNeighbors(NearestNeighbors);

    m_NearestNeighbors.Sort();

    // … use the sorted list somehow …
}
```

这段示例代码会在多个帧之间保留并复用 `List` 实例的内存。只有在 `List` 需要扩容时，代码才会分配新的内存。

`UnityEngine.Pool` 命名空间还为多种集合类型提供了现成的池化实现，包括 `List<T>`、`HashSet<T>` 和 `Dictionary<TKey, TValue>`。这些实现遵循与 `ObjectPool<T>` 相同的原理，让你可以按需取出和释放池化集合对象实例。更多信息和示例，请参阅 [`CollectionPool<T>`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Pool.CollectionPool_1.html) API 参考，以及同一命名空间下其他按集合类型提供的对象池类。
