# 处理格式化错误

> 原文：[Handle formatting errors](https://docs.unity3d.com/6000.7/Documentation/Manual/smart-strings/handle-formatting-errors.html)

控制 Smart Strings 对无效格式字符串和无法格式化值的反应，并跟踪发生的失败。

Smart Strings 可能在两个阶段失败：Parser 读取格式字符串时，以及 SmartFormatter 求值 Placeholder 时。每个阶段都有独立的错误操作，用于决定失败时是抛出异常、将错误写入输出、跳过错误，还是保持 Placeholder 不变。

## 错误操作

Parser 的错误操作是 `ParserSettings.ErrorAction`，类型为 `ParseErrorAction`。

Formatter 的错误操作是 `FormatterSettings.ErrorAction`，类型为 `FormatErrorAction`。

两个枚举包含相同的四个值，顺序也相同，默认值均为 `ThrowError`。

| 值 | 作用 |
| --- | --- |
| `ThrowError` | 抛出异常。这是默认值。调试时建议使用此值，以便错误立即暴露。 |
| `OutputErrorInResult` | 将错误消息写入格式化结果，而不是抛出异常。 |
| `Ignore` | 跳过错误并继续处理；失败项目不会产生输出。 |
| `MaintainTokens` | 在输出中保持出错 Token 不变，从而保留原始 Placeholder 文本。 |

## 设置错误操作

可以在 Editor 中或代码中设置错误操作：

- 在 Editor 中，打开 **Edit > Project Settings > Smart Strings**，在 **Parser** 和 **Formatter** 部分使用 **Error Action** 下拉菜单。参阅[[03-Smart Strings设置参考]]。
- 在代码中，在当前 Formatter 的设置上进行配置：

```csharp
Smart.Default.Settings.Parser.ErrorAction = ParseErrorAction.OutputErrorInResult;
Smart.Default.Settings.Formatter.ErrorAction = FormatErrorAction.Ignore;
```

> [!NOTE]
> 设置应在初始化期间应用。请在 Formatter 和 Parser 处理任何 Smart String 之前修改错误操作。

## 跟踪失败

如果不想改变错误操作，可以订阅失败事件来观察失败。无论是否抛出异常，两个事件都会触发。

要跟踪 Formatter 中的失败，请订阅 `SmartFormatter.OnFormattingFailure` 事件。该事件会提供 `FormattingErrorEventArgs`，其中包含 Placeholder 文本、格式字符串中的 `ErrorIndex`，以及 `IgnoreError`。当错误操作不是 `ThrowError` 时，`IgnoreError` 为 `true`。

要跟踪 Parser 中的失败，请订阅 `Parser.OnParsingFailure` 事件。该事件会提供 `ParsingErrorEventArgs`，其中包含解析 `Errors` 和 `ThrowsException`。当 Parser 的错误操作为 `ThrowError` 时，`ThrowsException` 为 `true`。可以通过 `Smart.Default.Parser` 访问 Parser。

```csharp
Smart.Default.OnFormattingFailure += (sender, e) =>
    Debug.LogWarning($"Smart String failed at {e.ErrorIndex}: {e.Placeholder}");
```

当错误操作为 `ThrowError` 时，格式化失败会抛出 `FormattingException`。它公开以下成员：

| 成员 | 描述 |
| --- | --- |
| `Issue` | 错误描述。 |
| `Format` | 导致错误的基础格式字符串。 |
| `Index` | 格式字符串中发生错误的位置。 |
| `ErrorItem` | 导致错误的 `FormatItem`。 |
