# 管理更新和执行顺序

> 原文：[Managing update and execution order](https://docs.unity3d.com/6000.7/Documentation/Manual/managing-update-order.html)

Unity Runtime 会持续运行 Player Loop，依次处理输入、游戏状态更新和帧渲染。`MonoBehaviour` 可以通过 Event Function 接入这个循环。

了解执行顺序有助于自定义和优化项目。例如，某些初始化工作必须始终在第一帧更新前完成；控制车辆 Engine 的脚本也可能必须先于控制转向的脚本执行。
