# 每帧更新

> 原文：[Per-frame updates](https://docs.unity3d.com/6000.7/Documentation/Manual/time-per-frame-updates.html)

Unity 会执行一些每帧更新。你的 `MonoBehaviour` 脚本可以通过 [MonoBehaviour.Update](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/MonoBehaviour.Update.html) 方法接入这个更新循环。例如，游戏角色可以在自己的 `Update` 方法中读取手柄输入，并向前移动一定距离。处理这类基于时间的操作时，必须记住游戏的 Frame Rate 可能变化，因此两次 `Update` 调用之间的时间间隔也会变化。

游戏的可变 Frame Rate 通常用 Frames Per Second（FPS）表示。Frame Rate 会受到主机设备能力，以及绘制每一帧所需的图形和计算复杂度影响。例如，屏幕上有 100 个 Active 角色时，游戏可能比只有一个角色时运行得慢。

除非 [Quality Settings](https://docs.unity3d.com/6000.7/Documentation/Manual/class-QualitySettings.html) 或 [Adaptive Performance](https://docs.unity3d.com/6000.7/Documentation/Manual/adaptive-performance/adaptive-performance.html) 对其进行限制，Unity 会尽量以最高可能的 Frame Rate 运行游戏。每帧发生的更多内容，请参阅[执行顺序图](https://docs.unity3d.com/6000.7/Documentation/Manual/execution-order.html)中的 **Game Logic** 部分。

**使用 `Time.deltaTime` 进行与帧率无关的移动**

假设需要让对象逐帧向前移动。最初可能会想到每帧移动固定距离：

```csharp
//C# script example
using UnityEngine;
using System.Collections;

public class ExampleScript : MonoBehaviour {
    public float distancePerFrame;
    
    void Update() {
        transform.Translate(0, 0, distancePerFrame); // this is incorrect
    }
}
```

但是，Frame Rate 变化时，这段代码会使对象的表观速度发生变化。游戏以 100 FPS 运行时，对象每秒移动 `distancePerFrame` 的 100 倍；如果由于 CPU 负载等原因降到 60 FPS，对象每秒只前进 60 次，因此在相同时间内移动的距离更短。

这通常不是期望的结果，尤其是在游戏和 Animation 中。更常见的需求是让对象无论 Frame Rate 如何变化，都以稳定、可预测的速度移动。解决方法是用每帧经过的时间缩放每帧的移动量，该时间可以通过 [Time.deltaTime](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Time-deltaTime.html) 属性读取：

```csharp
//C# script example
using UnityEngine;
using System.Collections;

public class ExampleScript : MonoBehaviour {
    public float distancePerSecond;
    
    void Update() {
        transform.Translate(0, 0, distancePerSecond * Time.deltaTime);
    }
}
```

现在移动量使用 `distancePerSecond` 而不是 `distancePerFrame` 表示。Frame Rate 变化时，每一步移动的大小也会相应变化，因此对象速度保持不变。

根据目标平台，可以使用 [Application.targetFrameRate](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Application-targetFrameRate.html) 或 [QualitySettings.vSyncCount](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/QualitySettings-vSyncCount.html) 设置应用程序的 Frame Rate。更多信息请参阅 [Application.targetFrameRate API 文档](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Application-targetFrameRate.html)。
