# 捕获帧率

> 原文：[Capturing frame rate](https://docs.unity3d.com/6000.7/Documentation/Manual/time-capture-frame-rate.html)

时间管理的一种特殊情况是希望将 Gameplay 录制为视频。保存屏幕图像需要相当多的时间，这会降低游戏正常的 Frame Rate，导致视频不能反映游戏的真实性能。

要改善视频效果，可以使用 `Time.captureFramerate` 属性。默认值为 `0`，表示未录制 Gameplay。当设置为非零值时，游戏时间会变慢，帧更新会以精确的固定间隔发出，以便录制。帧间隔等于 `1 / Time.captureFramerate`；例如设置为 `5.0` 时，每五分之一秒更新一次。

由于实际降低了对 Frame Rate 的要求，你可以在 `Update` 或 `LateUpdate` 函数中保存 Screenshot 或执行其他操作。下面的 C# 示例将帧捕获为 Screenshot 序列。这些图像会以 PNG 文件存储在文件夹中，之后可以使用图像处理软件（例如 QuickTime Pro）将它们合成为影片：

```csharp
//C# script example
using UnityEngine;
using System.Collections;

public class ExampleScript : MonoBehaviour {
    // Capture frames as a screenshot sequence. Images are
    // stored as PNG files in a folder - these can be combined into
    // a movie using image utility software (eg, QuickTime Pro).
    
    // The folder to contain our screenshots.
    // If the folder exists we will append numbers to create an empty folder.
    string folder = "ScreenshotFolder";
    int frameRate = 25;

    void Start () {
        // Set the playback frame rate (real time will not relate to game time after this).
        Time.captureFramerate = frameRate;
        // Create the folder
        System.IO.Directory.CreateDirectory(folder);
    }

    // Use LateUpdate to capture the screen after all other updates have been processed.
    void LateUpdate() {
        // Append filename to folder name (format is '0005 shot.png"')
        string name = string.Format(
            "{0}/{1:D04} shot.png",
            folder,
            Time.frameCount);
        // Capture the screenshot to the specified file.
        ScreenCapture.CaptureScreenshot(name);
    }
}
```

通过这种方式可以改善视频质量，但会让游戏更难操作。可以尝试不同的 `Time.captureFramerate` 值，找到合适的平衡。
