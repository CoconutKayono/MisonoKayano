# 管理时间和帧率

> 原文：[Managing time and frame rate](https://docs.unity3d.com/6000.7/Documentation/Manual/managing-time-and-frame-rate.html)

理解 Unity 如何处理时间非常重要，这样才能确保 Gameplay 保持稳定。Unity 会按照规律的时间间隔执行更新，以捕获角色位置、生命值、分数等内容的变化。如果代码在错误的更新循环中进行修改，或者没有考虑时间变化，移动等效果可能会过快、过慢，或者出现跳动而不是平滑移动。

`Time` 类包含了一些属性，你可以通过这些属性获取各种与时间相关的测量值和设置；其中一些属性也可以设置。完整的属性列表及其含义，请参阅 Scripting API 参考中的 [Time](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Time.html)。
