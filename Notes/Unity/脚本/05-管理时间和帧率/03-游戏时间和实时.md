# 游戏时间和实时

> 原文：[In-game time and real time](https://docs.unity3d.com/6000.7/Documentation/Manual/time-scale.html)

[`Time.timeScale`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Time-timeScale.html) 属性定义游戏世界中的时间相对于真实时间流逝的速率：

- `1.0` 表示游戏时间与真实时间一致。
- `2.0` 表示游戏时间以真实世界两倍的速度流逝，游戏动作会加速。
- `0.5` 表示游戏速度减半。
- `0` 表示游戏时间完全停止。

`Time.timeScale` 并不会真正减慢代码执行，而是改变传递给 `Update` 和 `FixedUpdate` 函数的时间步，也就是 [`Time.deltaTime`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Time-deltaTime.html) 和 [`Time.fixedDeltaTime`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Time-fixedDeltaTime.html) 的值。

降低时间缩放时，`Update` 可能仍然以相同频率调用，但每帧的 `Time.deltaTime` 会变小。其他脚本函数不受时间缩放影响，因此在游戏暂停时，仍然可以显示具有正常交互速度的 GUI。

慢动作等特殊时间效果通常需要减慢游戏时间，让 Animation 和代码中的基于时间的计算以更慢速度发生。游戏暂停时，也可能需要完全冻结游戏时间。

可以在 [Time](https://docs.unity3d.com/6000.7/Documentation/Manual/class-TimeManager.html) 窗口中全局设置 Time Scale，但通常更适合通过脚本使用 [`Time.timeScale`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Time-timeScale.html) 属性设置该值：

```csharp
//C# script example
using UnityEngine;
using System.Collections;

public class ExampleScript : MonoBehaviour {
    void Pause() {
        Time.timeScale = 0;
    }
    
    void Resume() {
        Time.timeScale = 1;
    }
}
```
