# 自定义序列化

> 原文：[Custom serialization](https://docs.unity3d.com/6000.7/Documentation/Manual/script-serialization-custom-serialization.html)

当想要序列化 Unity serializer 不支持的内容（例如 C# `Stack<T>`）时，可以在类中实现 `ISerializationCallbackReceiver` 接口。这样就能实现 Unity 在序列化和反序列化的关键时刻调用的回调。

可以使用序列化回调，让难以序列化的数据在运行时采用不同于序列化时的表示形式。在 Unity 序列化数据之前，将数据转换为 Unity 能理解的形式；Unity 将数据写入字段后，再将序列化数据转换回运行时所需的形式。

1. 对象即将被序列化时，Unity 调用 `OnBeforeSerialize()` 回调。在此回调中，可以将数据转换为 Unity 能理解的形式。例如，要序列化 C# `Stack<T>`，可将 `Stack<T>` 中的元素复制到 `List<T>` 字段。
2. `OnBeforeSerialize()` 回调完成后，Unity 序列化该 List。
3. 之后对象被反序列化时，Unity 调用 `OnAfterDeserialize()` 回调。在此回调中，可以将数据转换为便于对象在内存中使用的形式。例如，使用 `List<T>` 重建 C# `Stack<T>`。

## Unity 默认序列化的性能问题

如果想使用树数据结构并让 Unity 直接序列化该数据结构，缺少 null 支持会导致数据流变大，从而在许多系统中造成性能下降：

```csharp
using UnityEngine;
using System.Collections.Generic;
using System;

// This example demonstrates why directly serializing a tree
// can lead to performance issues due to Unity's serializer limitations (e.g., no null support, deep copying).
// It's provided to illustrate a problematic pattern, not a recommended one.
public class ProblematicTreeSerialization : MonoBehaviour
{
    [Serializable]
    public class Node
    {
        public string interestingValue = "value";
        // This field creates a class cycle (Node -> List<Node> -> Node),
        // which can make serialization data very large and inefficient for Unity's default serializer.
        public List<Node> children = new List<Node>();
    }

    // This root node will be serialized by Unity.
    public Node root = new Node();

}
```

要解决此问题，可以告诉 Unity 不要直接序列化这棵树，并创建 Unity serializer 能理解的、独立的可序列化树表示。然后使用 `ISerializationCallbackReceiver` 在运行时树和此可序列化格式之间转换。

```csharp
using UnityEngine;
using System.Collections.Generic;
using System;

// This example demonstrates how to use ISerializationCallbackReceiver to custom serialize
// a tree structure, avoiding the performance issues of direct serialization shown in ProblematicTreeSerialization.
public class CustomTreeSerialization : MonoBehaviour, ISerializationCallbackReceiver
{
    // Node class used at runtime. This is not directly serialized by Unity.
    public class Node
    {
        public string interestingValue = "value";
        public List<Node> children = new List<Node>();
    }

    // Serializable struct that represents a node for Unity's serializer.
    [Serializable]
    public struct SerializableNode
    {
        public string interestingValue;
        public int childCount;
        public int indexOfFirstChild;
    }

    // The root node used for runtime tree representation. Not directly serialized by Unity.
    private Node root = new Node();

    // This list is the only data Unity will serialize for the tree.
    // It's marked [SerializeField] so Unity's serializer can access it.
    [SerializeField] private List<SerializableNode> serializedNodes = new List<SerializableNode>();

    // Called just before Unity serializes the object.
    public void OnBeforeSerialize()
    {
        // Ensure root exists for serialization.
        if (root == null)
        {
            root = new Node();
        }

        serializedNodes.Clear();
        AddNodeToSerializedNodes(root);
    }

    // Recursively adds nodes to the 'serializedNodes' list in depth-first order.
    private void AddNodeToSerializedNodes(Node n)
    {
        var serializedNode = new SerializableNode
        {
            interestingValue = n.interestingValue,
            childCount = n.children.Count,
            // The index of the first child will be the current size of 'serializedNodes' + 1
            // (since the current node is added next, and then its children).
            indexOfFirstChild = serializedNodes.Count + 1
        };

        serializedNodes.Add(serializedNode);

        foreach (var child in n.children)
        {
            AddNodeToSerializedNodes(child);
        }
    }

    // Called just after Unity deserializes the object.
    public void OnAfterDeserialize()
    {
        // If there's serialized data, reconstruct the runtime tree.
        if (serializedNodes != null && serializedNodes.Count > 0)
        {
            // Start reconstruction from the first serialized node (index 0).
            ReadNodeFromSerializedNodes(0, out root);
        }
        else
        {
            root = new Node();
        }
    }

    // Recursively reads nodes from 'serializedNodes' and reconstructs the runtime tree.
    // Returns the next index to read from.
    private int ReadNodeFromSerializedNodes(int index, out Node node)
    {
        var serializedNode = serializedNodes[index];

        // Create a new runtime node and transfer data.
        Node newNode = new Node()
        {
            interestingValue = serializedNode.interestingValue,
            children = new List<Node>()
        };

        // The children were serialized immediately after their parent (depth-first).
        // Increment the index and recursively read children.
        int currentIndex = index + 1;
        for (int i = 0; i < serializedNode.childCount; i++)
        {
            Node childNode;
            currentIndex = ReadNodeFromSerializedNodes(currentIndex, out childNode);
            newNode.children.Add(childNode);
        }

        node = newNode;
        return currentIndex;
    }

}
```

## 直接序列化 Dictionary

**注意**：对于大多数项目，优先使用内置的 Dictionary serialization。给 `Dictionary<TKey, TValue>` 字段应用 `[SerializeField]`，然后直接在 Inspector 中编辑。参阅 [[04-Dictionary序列化]]。只有在需要 sorted dictionary（`SortedDictionary<TKey, TValue>`）、Dictionary 子类、分析器拒绝的键或值类型，或 Unity 不直接序列化的其他集合类型（例如 `HashSet<T>`）时，才使用下面基于回调的模式。

通过实现 `ISerializationCallbackReceiver`，可以在序列化前将 Dictionary 转换为两个 `List` 实例（一个保存 keys，一个保存 values），并在反序列化后从这两个 List 重建 Dictionary。

```csharp
using UnityEngine;
using System;
using System.Collections.Generic;

public class SerializationCallbackScript : MonoBehaviour, ISerializationCallbackReceiver
{
    public List<int> keys = new List<int> { 3, 4, 5 };
    public List<string> values = new List<string> { "I", "Love", "Unity" };

    // The dictionary is rebuilt from the keys and values lists in OnAfterDeserialize.
    public Dictionary<int, string>  myDictionary = new Dictionary<int, string>();

    public void OnBeforeSerialize()
    {
        keys.Clear();
        values.Clear();
        // For each key/value pair in the dictionary, add the key to the keys list and the value to the values list
        foreach (var kvp in myDictionary)
        {
            keys.Add(kvp.Key);
            values.Add(kvp.Value);
        }
    }

    public void OnAfterDeserialize()
    {
        myDictionary = new Dictionary<int, string>();
        // Loop through the list of keys and values and add each key/value pair to the dictionary
        for (int i = 0; i != Math.Min(keys.Count, values.Count); i++)
            myDictionary.Add(keys[i], values[i]);
    }

    void OnGUI()
    {
        // This callback displays the following output on three separate labels in the GameView:
        // "Key: 3 value: I"
        // "Key: 4 value: Love"
        // "Key: 5 value: Unity"
        foreach (var kvp in myDictionary)
            GUILayout.Label("Key: " + kvp.Key + " value: " + kvp.Value);
    }
}
```

## 可复用的可序列化集合

对于经常使用的类型（如 `HashSet<T>` 或 `Dictionary<TKey, TValue>`），创建自包含、可复用的包装类更实用。这些包装类封装序列化逻辑，可以插入任何脚本。

**注意**：序列化规则分析器的 [[07-序列化规则分析器参考#uac1009|UAC1009]] 会标记使用不支持集合类型的字段。使用这些包装类是解决该警告的一种方式。

### 可复用的可序列化 HashSet 包装类

```csharp
using UnityEngine;
using System.Collections.Generic;

[System.Serializable]
public class SerializableHashSet<T> : ISerializationCallbackReceiver
{
    [SerializeField] private List<T> items = new List<T>();

    private HashSet<T> hashSet;

    public void OnBeforeSerialize()
    {
        EnsureInitialized();
        items.Clear();
        items.AddRange(hashSet);
    }

    public void OnAfterDeserialize()
    {
        hashSet = new HashSet<T>(items);
    }

    private void EnsureInitialized()
    {
        if (hashSet == null)
            hashSet = new HashSet<T>(items);
    }

    public bool Add(T item)
    {
        EnsureInitialized();
        return hashSet.Add(item);
    }

    public bool Contains(T item)
    {
        EnsureInitialized();
        return hashSet.Contains(item);
    }

    public bool Remove(T item)
    {
        EnsureInitialized();
        return hashSet.Remove(item);
    }

    public int Count
    {
        get
        {
            EnsureInitialized();
            return hashSet.Count;
        }
    }
}
```

用法：

```csharp
public class AchievementManager : MonoBehaviour
{
    public SerializableHashSet<string> unlockedAchievements; // Serializes as a List<string>
}
```

### 可复用的可序列化 Dictionary 包装类

```csharp
using UnityEngine;
using System.Collections.Generic;

[System.Serializable]
public class SerializableDictionary<TKey, TValue> : ISerializationCallbackReceiver
{
    [SerializeField] private List<TKey> keys = new List<TKey>();
    [SerializeField] private List<TValue> values = new List<TValue>();

    private Dictionary<TKey, TValue> dictionary;

    public void OnBeforeSerialize()
    {
        EnsureInitialized();
        keys.Clear();
        values.Clear();

        foreach (var kvp in dictionary)
        {
            keys.Add(kvp.Key);
            values.Add(kvp.Value);
        }
    }

    public void OnAfterDeserialize()
    {
        dictionary = new Dictionary<TKey, TValue>();

        for (int i = 0; i < keys.Count && i < values.Count; i++)
        {
            dictionary[keys[i]] = values[i];
        }
    }

    private void EnsureInitialized()
    {
        if (dictionary == null)
            dictionary = new Dictionary<TKey, TValue>();
    }

    public TValue this[TKey key]
    {
        get
        {
            EnsureInitialized();
            return dictionary[key];
        }
        set
        {
            EnsureInitialized();
            dictionary[key] = value;
        }
    }

    public bool TryGetValue(TKey key, out TValue value)
    {
        EnsureInitialized();
        return dictionary.TryGetValue(key, out value);
    }

    public bool ContainsKey(TKey key)
    {
        EnsureInitialized();
        return dictionary.ContainsKey(key);
    }

    public void Add(TKey key, TValue value)
    {
        EnsureInitialized();
        dictionary.Add(key, value);
    }

    public bool Remove(TKey key)
    {
        EnsureInitialized();
        return dictionary.Remove(key);
    }

    public int Count
    {
        get
        {
            EnsureInitialized();
            return dictionary.Count;
        }
    }
}
```

用法：

```csharp
public class ItemDatabase : MonoBehaviour
{
    public SerializableDictionary<string, int> itemPrices; // Serializes as parallel key/value lists
}
```

## 多态反序列化

Unity 默认 serializer 对普通 C# 类的多态支持有限。要序列化一组继承自同一基类的对象，通常需要手动存储类型信息和每个派生类型的具体数据。下面的示例演示如何使用 `ISerializationCallbackReceiver` 实现这一点。

```csharp
using UnityEngine;
using System.Collections.Generic;
using System;

// Base class for polymorphic objects. Not directly serializable by Unity.
public abstract class Animal
{
    public string Name { get; set; }
    public abstract string GetSound();
}

// Derived class
public class Dog : Animal
{
    public int BarkVolume { get; set; }
    public Dog(string name, int barkVolume)
    {
        Name = name;
        BarkVolume = barkVolume;
    }
    public override string GetSound() => $"Woof! (Volume: {BarkVolume})";
}

// Derived class
public class Cat : Animal
{
    public bool IsCute { get; set; }
    public Cat(string name, bool isCute)
    {
        Name = name;
        IsCute = isCute;
    }
    public override string GetSound() => $"Meow! (Cute: {IsCute})";
}

// Serializable wrapper struct for Dog's data.
// Marked [Serializable] for Unity.
[Serializable]
public struct SerializableDog
{
    public string name;
    public int barkVolume;
}

// Serializable wrapper struct for Cat's data.
// Marked [Serializable] for Unity.
[Serializable]
public struct SerializableCat
{
    public string name;
    public bool isCute;
}

// Enum to identify the type of animal for deserialization.
public enum AnimalType
{
    Dog,
    Cat
}

// Example demonstrating polymorphic deserialization using ISerializationCallbackReceiver.
// This approach requires manual management of type information during serialization.
public class PolymorphicAnimalSerialization : MonoBehaviour, ISerializationCallbackReceiver
{
    // The runtime list of polymorphic Animal objects. Not directly serialized by Unity.
    public List<Animal> animals = new List<Animal>();

    // These lists store the serializable data for each derived type,
    // along with a list of types to reconstruct the original order.
    // Marked [SerializeField] to be saved by Unity.
    [SerializeField] private List<AnimalType> _animalTypes = new List<AnimalType>();
    [SerializeField] private List<SerializableDog> _dogs = new List<SerializableDog>();
    [SerializeField] private List<SerializableCat> _cats = new List<SerializableCat>();

    // Called just before Unity serializes the object.
    public void OnBeforeSerialize()
    {
        _animalTypes.Clear();
        _dogs.Clear();
        _cats.Clear();

        foreach (var animal in animals)
        {
            if (animal is Dog dog)
            {
                _animalTypes.Add(AnimalType.Dog);
                _dogs.Add(new SerializableDog { name = dog.Name, barkVolume = dog.BarkVolume });
            }
            else if (animal is Cat cat)
            {
                _animalTypes.Add(AnimalType.Cat);
                _cats.Add(new SerializableCat { name = cat.Name, isCute = cat.IsCute });
            }
        }
    }

    // Called just after Unity deserializes the object.
    public void OnAfterDeserialize()
    {
        animals.Clear();

        // Keep track of which serialized item to read next from each list.
        int dogIndex = 0;
        int catIndex = 0;

        // Iterate through the type list to reconstruct the animals in the correct order.
        foreach (var type in _animalTypes)
        {
            switch (type)
            {
                case AnimalType.Dog:
                    if (dogIndex < _dogs.Count)
                    {
                        var sDog = _dogs[dogIndex];
                        animals.Add(new Dog(sDog.name, sDog.barkVolume));
                        dogIndex++;
                    }
                    else
                    {
                        Debug.LogError("Mismatch in serialized Dog data during deserialization.");
                    }
                    break;
                case AnimalType.Cat:
                    if (catIndex < _cats.Count)
                    {
                        var sCat = _cats[catIndex];
                        animals.Add(new Cat(sCat.name, sCat.isCute));
                        catIndex++;
                    }
                    else
                    {
                        Debug.LogError("Mismatch in serialized Cat data during deserialization.");
                    }
                    break;
            }
        }
    }
}
```

> 原文：[Custom serialization](https://docs.unity3d.com/6000.7/Documentation/Manual/script-serialization-custom-serialization.html)

当你希望序列化 Unity serializer 不支持的内容（例如 C# `Stack<T>`）时，可以在 class 中实现 [`ISerializationCallbackReceiver`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/ISerializationCallbackReceiver.html) interface。这样，你可以实现 Unity 在 serialization 和 deserialization 的关键时间点调用的 callbacks。

你可以使用 serialization callbacks，让难以序列化的 data 在 runtime 使用一种 representation，而在 serialization 时使用另一种 representation。可以在 Unity 序列化 data 前，将其转换为 Unity 理解的形式；Unity 将 data 写入 fields 后，再将 serialized data 转换回你希望 runtime 使用的形式。

1. Object 即将被序列化时，Unity 调用 `OnBeforeSerialize()` callback。在此 callback 中，可以将 data 转换为 Unity 理解的形式。例如，要序列化 C# `Stack<T>`，可以将 `Stack<T>` 中的 elements 复制到 `List<T>` field。
2. `OnBeforeSerialize()` callback 完成后，Unity 序列化该 list。
3. 之后 object 被反序列化时，Unity 调用 `OnAfterDeserialize()` callback。在此 callback 中，可以将 data 转换回适合 object 在 memory 中使用的形式。例如，使用 `List<T>` 重建 C# `Stack<T>`。

## Unity default serialization 的 performance issues

如果希望使用 tree data structure，并让 Unity 直接序列化该 data structure，那么对 null 的支持缺失会使 data stream 变大。这会导致许多 systems 的 performance degradation：

```csharp
using UnityEngine;
using System.Collections.Generic;
using System;

// This example demonstrates why directly serializing a tree
// can lead to performance issues due to Unity's serializer limitations (e.g., no null support, deep copying).
// It's provided to illustrate a problematic pattern, not a recommended one.
public class ProblematicTreeSerialization : MonoBehaviour
{
    [Serializable]
    public class Node
    {
        public string interestingValue = "value";
        // This field creates a class cycle (Node -> List<Node> -> Node),
        // which can make serialization data very large and inefficient for Unity's default serializer.
        public List<Node> children = new List<Node>();
    }

    // This root node will be serialized by Unity.
    public Node root = new Node();

}
```

要解决此问题，可以告诉 Unity 不要直接序列化 tree，并创建一个 Unity 理解的、独立的 serializable representation。然后可以使用 `ISerializationCallbackReceiver` interface，在 runtime tree 与此 serializable format 之间进行转换。

```csharp
using UnityEngine;
using System.Collections.Generic;
using System;

// This example demonstrates how to use ISerializationCallbackReceiver to custom serialize
// a tree structure, avoiding the performance issues of direct serialization shown in ProblematicTreeSerialization.
public class CustomTreeSerialization : MonoBehaviour, ISerializationCallbackReceiver
{
    // Node class used at runtime. This is not directly serialized by Unity.
    public class Node
    {
        public string interestingValue = "value";
        public List<Node> children = new List<Node>();
    }

    // Serializable struct that represents a node for Unity's serializer.
    [Serializable]
    public struct SerializableNode
    {
        public string interestingValue;
        public int childCount;
        public int indexOfFirstChild;
    }

    // The root node used for runtime tree representation. Not directly serialized by Unity.
    private Node root = new Node();

    // This list is the only data Unity will serialize for the tree.
    // It's marked [SerializeField] so Unity's serializer can access it.
    [SerializeField] private List<SerializableNode> serializedNodes = new List<SerializableNode>();

    // Called just before Unity serializes the object.
    public void OnBeforeSerialize()
    {
        // Ensure root exists for serialization.
        if (root == null)
        {
            root = new Node();
        }

        serializedNodes.Clear(); 
        AddNodeToSerializedNodes(root); 
    }

    // Recursively adds nodes to the 'serializedNodes' list in depth-first order.
    private void AddNodeToSerializedNodes(Node n)
    {
        var serializedNode = new SerializableNode
        {
            interestingValue = n.interestingValue,
            childCount = n.children.Count,
            // The index of the first child will be the current size of 'serializedNodes' + 1
            // (since the current node is added next, and then its children).
            indexOfFirstChild = serializedNodes.Count + 1
        };

        serializedNodes.Add(serializedNode);

        foreach (var child in n.children)
        {
            AddNodeToSerializedNodes(child);
        }
    }

    // Called just after Unity deserializes the object.
    public void OnAfterDeserialize()
    {
        // If there's serialized data, reconstruct the runtime tree.
        if (serializedNodes != null && serializedNodes.Count > 0)
        {
            // Start reconstruction from the first serialized node (index 0).
            ReadNodeFromSerializedNodes(0, out root);
        }
        else
        {
            root = new Node();
        }
    }

    // Recursively reads nodes from 'serializedNodes' and reconstructs the runtime tree.
    // Returns the next index to read from.
    private int ReadNodeFromSerializedNodes(int index, out Node node)
    {
        var serializedNode = serializedNodes[index];

        // Create a new runtime node and transfer data.
        Node newNode = new Node()
        {
            interestingValue = serializedNode.interestingValue,
            children = new List<Node>()
        };

        // The children were serialized immediately after their parent (depth-first).
        // Increment the index and recursively read children.
        int currentIndex = index + 1; 
        for (int i = 0; i < serializedNode.childCount; i++)
        {
            Node childNode;
            currentIndex = ReadNodeFromSerializedNodes(currentIndex, out childNode);
            newNode.children.Add(childNode);
        }

        node = newNode;
        return currentIndex;
    }

}
```

## 直接序列化 Dictionary

**注意**：对于大多数 projects，应优先使用 built-in dictionary serialization。将 [`[SerializeField]`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/SerializeField.html) 应用到 `Dictionary<TKey, TValue>` field，并直接在 Inspector 中编辑它。参阅 [[04-Dictionary序列化]]。只有在需要 sorted dictionary（`SortedDictionary<TKey, TValue>`）、dictionary subclass、analyzer 拒绝的 key 或 value type，或 Unity 不直接序列化的其他 collection type（例如 `HashSet<T>`）时，才使用下面的 callback-based pattern。

通过实现 [`ISerializationCallbackReceiver`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/ISerializationCallbackReceiver.html)，可以在 serialization 前将 dictionary 转换为两个 `List` instances（一个用于 keys，一个用于 values），然后在 deserialization 后从 lists 重建 dictionary。

```csharp
using UnityEngine;
using System;
using System.Collections.Generic;

public class SerializationCallbackScript : MonoBehaviour, ISerializationCallbackReceiver
{
    public List<int> keys = new List<int> { 3, 4, 5 };
    public List<string> values = new List<string> { "I", "Love", "Unity" };

    // The dictionary is rebuilt from the keys and values lists in OnAfterDeserialize.
    public Dictionary<int, string>  myDictionary = new Dictionary<int, string>();

    public void OnBeforeSerialize()
    {
        keys.Clear();
        values.Clear();
        // For each key/value pair in the dictionary, add the key to the keys list and the value to the values list
        foreach (var kvp in myDictionary)
        {
            keys.Add(kvp.Key);
            values.Add(kvp.Value);
        }
    }

    public void OnAfterDeserialize()
    {
        myDictionary = new Dictionary<int, string>();
        // Loop through the list of keys and values and add each key/value pair to the dictionary
        for (int i = 0; i != Math.Min(keys.Count, values.Count); i++)
            myDictionary.Add(keys[i], values[i]);
    }

    void OnGUI()
    {
        // This callback displays the following output on three separate labels in the GameView:
        // "Key: 3 value: I"
        // "Key: 4 value: Love"
        // "Key: 5 value: Unity"
        foreach (var kvp in myDictionary)
            GUILayout.Label("Key: " + kvp.Key + " value: " + kvp.Value);
    }
}
```

## 可复用的 serializable collections

对于经常使用的 types，例如 `HashSet<T>` 或 `Dictionary<TKey, TValue>`，创建 self-contained、reusable wrapper classes 更实用。这些 wrappers 封装 serialization logic，因此可以将它们插入任意 script。

**注意**：Serialization rules analyzer 的 rule [[07-序列化规则分析器参考#UAC1009|UAC1009]] 会标记使用 unsupported collection types 的 fields。使用这些 wrappers 是解决该 warning 的一种方式。

### 可复用的 serializable HashSet wrapper

```csharp
using UnityEngine;
using System.Collections.Generic;

[System.Serializable]
public class SerializableHashSet<T> : ISerializationCallbackReceiver
{
    [SerializeField] private List<T> items = new List<T>();

    private HashSet<T> hashSet;

    public void OnBeforeSerialize()
    {
        EnsureInitialized();
        items.Clear();
        items.AddRange(hashSet);
    }

    public void OnAfterDeserialize()
    {
        hashSet = new HashSet<T>(items);
    }

    private void EnsureInitialized()
    {
        if (hashSet == null)
            hashSet = new HashSet<T>(items);
    }

    public bool Add(T item)
    {
        EnsureInitialized();
        return hashSet.Add(item);
    }

    public bool Contains(T item)
    {
        EnsureInitialized();
        return hashSet.Contains(item);
    }

    public bool Remove(T item)
    {
        EnsureInitialized();
```

### 可复用的 serializable Dictionary wrapper

```csharp
using UnityEngine;
using System.Collections.Generic;

[System.Serializable]
public class SerializableDictionary<TKey, TValue> : ISerializationCallbackReceiver
{
    [SerializeField] private List<TKey> keys = new List<TKey>();
    [SerializeField] private List<TValue> values = new List<TValue>();

    private Dictionary<TKey, TValue> dictionary;

    public void OnBeforeSerialize()
    {
        EnsureInitialized();
        keys.Clear();
        values.Clear();

        foreach (var kvp in dictionary)
        {
            keys.Add(kvp.Key);
            values.Add(kvp.Value);
        }
    }

    public void OnAfterDeserialize()
    {
        dictionary = new Dictionary<TKey, TValue>();

        for (int i = 0; i < keys.Count && i < values.Count; i++)
        {
            dictionary[keys[i]] = values[i];
        }
    }

    private void EnsureInitialized()
    {
        if (dictionary == null)
            dictionary = new Dictionary<TKey, TValue>();
    }

    public TValue this[TKey key]
    {
        get
        {
            EnsureInitialized();
            return dictionary[key];
        }
        set
        {
            EnsureInitialized();
            dictionary[key] = value;
        }
    }

    public bool TryGetValue(TKey key, out TValue value)
    {
        EnsureInitialized();
        return dictionary.TryGetValue(key, out value);
    }

    public bool ContainsKey(TKey key)
    {
        EnsureInitialized();
        return dictionary.ContainsKey(key);
    }

    public void Add(TKey key, TValue value)
    {
        EnsureInitialized();
        dictionary.Add(key, value);
    }

    public bool Remove(TKey key)
    {
        EnsureInitialized();
        return dictionary.Remove(key);
    }

    public int Count
    {
        get
        {
            EnsureInitialized();
            return dictionary.Count;
        }
    }
}
```

## Polymorphic deserialization

Unity default serializer 对 plain C# classes 的 polymorphism 支持有限。要序列化继承自同一个 base class 的 object list，通常需要手动存储 type information 以及每个 derived type 的具体 data。以下示例展示如何使用 `ISerializationCallbackReceiver` 实现这一点。

```csharp
using UnityEngine;
using System.Collections.Generic;
using System;

// Base class for polymorphic objects. Not directly serializable by Unity.
public abstract class Animal
{
    public string Name { get; set; }
    public abstract string GetSound();
}

// Derived class
public class Dog : Animal
{
    public int BarkVolume { get; set; }
    public Dog(string name, int barkVolume)
    {
        Name = name;
        BarkVolume = barkVolume;
    }
    public override string GetSound() => $"Woof! (Volume: {BarkVolume})";
}

// Derived class
public class Cat : Animal
{
    public bool IsCute { get; set; }
    public Cat(string name, bool isCute)
    {
        Name = name;
        IsCute = isCute;
    }
    public override string GetSound() => $"Meow! (Cute: {IsCute})";
}

// Serializable wrapper struct for Dog's data.
// Marked [Serializable] for Unity.
[Serializable]
public struct SerializableDog
{
    public string name;
    public int barkVolume;
}

// Serializable wrapper struct for Cat's data.
// Marked [Serializable] for Unity.
[Serializable]
public struct SerializableCat
{
    public string name;
    public bool isCute;
}

// Enum to identify the type of animal for deserialization.
public enum AnimalType
{
    Dog,
    Cat
}

// Example demonstrating polymorphic deserialization using ISerializationCallbackReceiver.
// This approach requires manual management of type information during serialization.
public class PolymorphicAnimalSerialization : MonoBehaviour, ISerializationCallbackReceiver
{
    // The runtime list of polymorphic Animal objects. Not directly serialized by Unity.
    public List<Animal> animals = new List<Animal>();

    // These lists store the serializable data for each derived type,
    // along with a list of types to reconstruct the original order.
    // Marked [SerializeField] to be saved by Unity.
    [SerializeField] private List<AnimalType> _animalTypes = new List<AnimalType>();
    [SerializeField] private List<SerializableDog> _dogs = new List<SerializableDog>();
    [SerializeField] private List<SerializableCat> _cats = new List<SerializableCat>();

    // Called just before Unity serializes the object.
    public void OnBeforeSerialize()
    {
        _animalTypes.Clear();
        _dogs.Clear();
        _cats.Clear();

        foreach (var animal in animals)
        {
            if (animal is Dog dog)
            {
                _animalTypes.Add(AnimalType.Dog);
                _dogs.Add(new SerializableDog { name = dog.Name, barkVolume = dog.BarkVolume });
            }
            else if (animal is Cat cat)
            {
                _animalTypes.Add(AnimalType.Cat);
                _cats.Add(new SerializableCat { name = cat.Name, isCute = cat.IsCute });
            }
        }
    }

    // Called just after Unity deserializes the object.
    public void OnAfterDeserialize()
    {
        animals.Clear();
        
        // Keep track of which serialized item to read next from each list.
        int dogIndex = 0;
        int catIndex = 0;

        // Iterate through the type list to reconstruct the animals in the correct order.
        foreach (var type in _animalTypes)
        {
            switch (type)
            {
                case AnimalType.Dog:
                    if (dogIndex < _dogs.Count)
                    {
                        var sDog = _dogs[dogIndex];
                        animals.Add(new Dog(sDog.name, sDog.barkVolume));
                        dogIndex++;
                    }
                    else
                    {
                        Debug.LogError("Mismatch in serialized Dog data during deserialization.");
                    }
                    break;
                case AnimalType.Cat:
                    if (catIndex < _cats.Count)
                    {
                        var sCat = _cats[catIndex];
                        animals.Add(new Cat(sCat.name, sCat.isCute));
                        catIndex++;
                    }
                    else
                    {
                        Debug.LogError("Mismatch in serialized Cat data during deserialization.");
                    }
                    break;
            }
        }
    }
}
```
