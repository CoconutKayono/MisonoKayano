# Assembly Definition 文件格式参考

> 原文：[Assembly Definition file format reference](https://docs.unity3d.com/6000.7/Documentation/Manual/assembly-definition-file-format.html)

Assembly Definition 和 Assembly Definition Reference 资源是 JSON 文件。可以在 Unity Editor 中使用 **Inspector** 窗口编辑资源文件，也可以使用外部工具直接修改 JSON 内容。

## Assembly Definition JSON

Assembly Definition 是包含以下字段的 JSON 对象：

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `allowUnsafeCode` | bool | Optional | 默认为 `false`。有关此选项含义的信息，请参阅 Assembly Definition Inspector 参考中的 **General Options** 下的 **Allow ‘unsafe’ Code**。 |
| `autoReferenced` | bool | Optional | 默认为 `true`。有关此选项含义的信息，请参阅 Assembly Definition Inspector 参考中的 **General Options** 下的 **Auto Referenced**。 |
| `defineConstraints` | string[] | Optional | 可以为空。更多信息请参阅 Assembly Definition Inspector 参考中的 **Define Constraints**。 |
| `excludePlatforms` | string[] | Optional | 要排除的平台名称字符串，或者空数组。如果 `includePlatforms` 包含值，`excludePlatforms` 数组必须为空。有效的平台名称字符串是 `Compilation.AssemblyDefinitionPlatform` 对象数组的 `AssemblyDefinitionPlatform.Name` 属性值，该对象数组由 [`CompilationPipeline.GetAssemblyDefinitionPlatforms`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/CompilationPipeline.GetAssemblyDefinitionPlatforms.html) 返回。只有当前 Editor 安装了构建支持的平台才有效。更多信息请参阅 Assembly Definition Inspector 参考中的 **Platforms**。 |
| `includePlatforms` | string[] | Optional | 要包含的平台名称字符串，或者空数组。如果 `excludePlatforms` 包含值，`includePlatforms` 数组必须为空。有效的平台名称字符串是 `Compilation.AssemblyDefinitionPlatform` 对象数组的 `AssemblyDefinitionPlatform.Name` 属性值，该对象数组由 [`CompilationPipeline.GetAssemblyDefinitionPlatforms`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/CompilationPipeline.GetAssemblyDefinitionPlatforms.html) 返回。只有当前 Editor 安装了构建支持的平台才有效。更多信息请参阅 Assembly Definition Inspector 参考中的 **Platforms**。 |
| `name` | string | Required | 更多信息请参阅 Assembly Definition Inspector 参考中的 **Name**。 |
| `noEngineReferences` | bool | Optional | 默认为 `false`。有关此选项含义的信息，请参阅 Assembly Definition Inspector 参考中的 **General Options** 下的 **No Engine References**。 |
| `overrideReferences` | bool | Optional | 默认为 `false`。如果 `precompiledReferences` 包含值，则设置为 `true`。有关此选项含义的信息，请参阅 Assembly Definition Inspector 参考中的 **General Options** 下的 **Override References**。 |
| `precompiledReferences` | string[] | Optional | 被引用 DLL 库的文件名，包括扩展名但不含其他路径元素。可以为空。除非将 `overrideReferences` 设为 `true`，否则会忽略此数组。更多信息请参阅 [[03-引用程序集]]。 |
| `references` | string[] | Optional | 对其他 Assembly Definition 资源创建的程序集的引用。可以使用 Assembly Definition 资源文件的 GUID，或使用 Assembly Definition 的 `name` 字段定义的程序集名称。列表中的所有引用必须使用同一种形式。可以为空。可以使用 [`AssetDatabase.AssetPathToGUID`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssetDatabase.AssetPathToGUID.html) 函数检索资源 GUID。每个资源的关联元数据中也包含 GUID。Assembly Definition Inspector 中显示 **Use GUIDs** 选项，但该选项不会序列化到关联 JSON 文件中；Editor 会根据文件中引用的形式推断此选项。更多信息请参阅 [[03-引用程序集]]。 |
| `versionDefines` | object[] | Optional | 包含每个版本定义对应的一个对象。该对象有三个字段：`name`:string——资源名称；`expression`:string——定义资源版本或版本范围的表达式；`define`:string——要定义的符号。更多信息请参阅 Assembly Definition Inspector 参考中的 **Version Defines**。 |

### 使用程序集名称和包含平台的示例

下面的 Assembly Definition JSON 示例使用程序集名称引用其他 Assembly Definition，并使用 `includePlatforms` Key 指定包含的平台数组：

```json
{
    "name": "BeeAssembly",
    "references": [
        "Unity.CollabProxy.Editor",
        "AssemblyB",
        "UnityEngine.UI",
        "UnityEngine.TestRunner",
        "UnityEditor.TestRunner"
    ],
    "includePlatforms": [
        "Android",
        "LinuxStandalone64",
        "WebGL"
    ],
    "excludePlatforms": [],
    "overrideReferences": true,
    "precompiledReferences": [
        "Newtonsoft.Json.dll",
        "nunit.framework.dll"
    ],
    "autoReferenced": false,
    "defineConstraints": [
        "UNITY_2019",
        "UNITY_INCLUDE_TESTS"
    ],
    "versionDefines": [
        {
            "name": "com.unity.ide.vscode",
            "expression": "[1.7,2.4.1]",
            "define": "MY_SYMBOL"
        },
        {
            "name": "com.unity.test-framework",
            "expression": "[2.7.2-preview.8]",
            "define": "TESTS"
        }
    ],
    "noEngineReferences": false
}
```

### 使用 GUID 和排除平台的示例

下面的 Assembly Definition JSON 示例使用 Assembly Definition 的 GUID 进行引用，并使用 `excludePlatforms` Key 指定排除的平台数组：

```json
{
    "name": "BeeAssembly",
    "references": [
        "GUID:17b36165d09634a48bf5a0e4bb27f4bd",
        "GUID:b470eee7144904e59a1064b70fa1b086",
        "GUID:2bafac87e7f4b9b418d9448d219b01ab",
        "GUID:27619889b8ba8c24980f49ee34dbb44a",
        "GUID:0acc523941302664db1f4e527237feb3"
    ],
    "includePlatforms": [],
    "excludePlatforms": [
        "iOS",
        "macOSStandalone",
        "tvOS"
    ],
    "allowUnsafeCode": false,
    "overrideReferences": true,
    "precompiledReferences": [
        "Newtonsoft.Json.dll",
        "nunit.framework.dll"
    ],
    "autoReferenced": false,
    "defineConstraints": [
        "UNITY_2019",
        "UNITY_INCLUDE_TESTS"
    ],
    "versionDefines": [
        {
            "name": "com.unity.ide.vscode",
            "expression": "[1.7,2.4.1]",
            "define": "MY_SYMBOL"
        },
        {
            "name": "com.unity.test-framework",
            "expression": "[2.7.2-preview.8]",
            "define": "TESTS"
        }
    ],
    "noEngineReferences": false
}
```

## Assembly Definition Reference JSON

Assembly Definition Reference 是只有一个必需字段的 JSON 对象，该字段是名为 `reference` 的字符串。它指定要引用的程序集，可以使用程序集名称或 Assembly Definition 资源 GUID。可以使用 [`AssetDatabase.AssetPathToGUID`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/AssetDatabase.AssetPathToGUID.html) 函数检索资源 GUID。每个资源的关联元数据中也包含 GUID。

下面的 Assembly Definition Reference 示例通过名称引用另一个资源：

```json
{
    "reference": "AssemblyA"
}
```

下面的 Assembly Definition Reference 示例通过资源 GUID 引用另一个资源：

```json
{
    "reference": "GUID:f4de40948f4904ecb94b59dd38aab8a1"
}
```
