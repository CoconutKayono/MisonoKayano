# 编译警告参考

> 原文：[Compilation warnings reference](https://docs.unity3d.com/6000.7/Documentation/Manual/burst/compilation-warnings.html)

本页介绍常见的编译警告及其修复方法。

## IgnoreWarning Attribute

[`Unity.Burst.CompilerServices.IgnoreWarningAttribute`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Burst.CompilerServices.IgnoreWarningAttribute.html) 可以抑制特定 Burst 编译函数的警告。Burst 生成的警告值得重视，因此应谨慎使用此 Attribute，并且只在必要时使用。下面的各个部分介绍适合抑制警告的具体情况。

## BC1370

BC1370 警告会生成以下消息：

```
An exception was thrown from a function without the correct `[Conditional("ENABLE_UNITY_COLLECTIONS_CHECKS")]` guard...
```

如果 Unity 遇到未由 `[Conditional("ENABLE_UNITY_COLLECTIONS_CHECKS")]` 保护的 `throw`，就会产生此警告。在 Editor 中，抛出的异常会被捕获并记录到 Console；但在 Player 构建中，`throw` 会变成 abort，从而导致应用崩溃。

Burst 会针对这些异常发出警告，并建议将它们放入由 `[Conditional("ENABLE_UNITY_COLLECTIONS_CHECKS")]` 保护的函数中，因为这些函数不会包含在 Player 构建中。但是，如果确实希望通过抛出异常使应用崩溃，可以在 `throw` 上使用 `IgnoreWarningAttribute`，抑制 Burst 发出的警告：

```csharp
[IgnoreWarning(1370)]
int DoSomethingMaybe(int x)
{
    if (x < 0) throw new Exception("Dang - sorry I crashed your game!");

    return x * x;
}
```

> 注意：此警告只针对会保留到 Player 构建中的异常。不会编译进 Player 构建的仅 Editor 或仅调试异常不会触发此警告。

## BC1371

BC1371 警告会生成以下消息：

```
A call to the method 'xxx' has been discarded, due to its use as an argument to a discarded method...
```

要理解此警告，请考虑以下示例：

```csharp
[BurstDiscard]
static void DoSomeManagedStuff(int x)
{
    // 仅在禁用 Burst 编译时运行
}

// 计算出需要传递给 Managed 代码的结果的函数
int BurstCompiledCode(int x,int y)
{
    return y+2*x;
}

[BurstCompile]
void BurstedMethod()
{
    var myValue = BurstCompiledCode(1,3);
    DoSomeManagedStuff(myValue);
}
```

Unity 以 Release 模式编译 C# 代码时，会优化并移除局部变量 `myValue`。这意味着 Burst 接收到的代码类似于以下内容：

```csharp
[BurstCompile]
void BurstedMethod()
{
    DoSomeManagedStuff(BurstCompiledCode(1,3));
}
```

这会使 Burst 生成警告，因为 Burst 会将 `DoSomeManagedStuff` 与 `BurstCompiledCode` 参数一起丢弃。这意味着不再执行 `BurstCompiledCode` 函数，从而产生警告。

如果这不是预期行为，请确保变量有多个用途。例如：

```csharp
void IsUsed(ref int x)
{
    // 防止移除的占位函数
}

[BurstCompile]
void BurstedMethod()
{
    var myValue = BurstCompiledCode(1,3);
    DoSomeManagedStuff(myValue);
    IsUsed(ref myValue);
}
```

或者，如果确定代码被正确丢弃，可以像下面这样在 `BurstedMethod` 上忽略警告：

```csharp
[IgnoreWarning(1371)]
[BurstCompile]
void BurstedMethod()
{
    var myValue = BurstCompiledCode(1,3);
    DoSomeManagedStuff(myValue);
}
```

如果同一个被丢弃的方法在多个位置被调用，可以将 `[IgnoreWarning(1371)]` 放在 `[BurstDiscard]` 方法本身上，在所有调用点抑制警告，而不必为每个调用方添加 Attribute：

```csharp
[BurstDiscard]
[IgnoreWarning(1371)]
static void DoSomeManagedStuff(int x)
{
    // 仅在禁用 Burst 编译时运行
}
```
