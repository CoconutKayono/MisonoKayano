# 字符串支持

> 原文：[String support](https://docs.unity3d.com/6000.7/Documentation/Manual/burst/csharp-string-support.html)

Burst 在以下场景支持使用字符串：

- [`Debug.Log`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Debug.Log.html)。
- 为 `Unity.Collections` 提供的 `FixedString` 结构体赋值，例如 [`FixedString128Bytes`](https://docs.unity3d.com/Packages/com.unity.collections@2.2/api/Unity.Collections.FixedString128Bytes.html)。
- 在 Burst 函数的参数上使用 `System.Runtime.CompilerServices` 属性 `[CallerLineNumber]`、`[CallerMemberName]` 和 `[CallerFilePath]`。但是，只能将这些字符串直接传递给 `Debug.Log` 调用。

字符串可以是以下两种形式之一：

- 字符串字面量，例如 `"This is a string literal"`。
- 插值字符串，例如 `$"This is an integer {value}`，或者使用 `string.Format`，其中待格式化字符串也是字符串字面量。

例如，Burst 支持以下构造：

- 使用字符串字面量记录日志：

  ```csharp
  Debug.Log("This a string literal");
  ```

- 使用字符串插值记录日志：

  ```csharp
  int value = 256;
  Debug.Log($"This is an integer value {value}");
  ```

  这与直接使用 `string.Format` 相同：

  ```csharp
  int value = 256;
  Debug.Log(string.Format("This is an integer value {0}", value));
  ```

## 支持的 Debug 方法

Burst 支持以下 [`Debug`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Debug.html) 方法：

- `Debug.Log(object)`
- `Debug.LogWarning(object)`
- `Debug.LogError(object)`

## 字符串插值支持

字符串插值有以下限制：

- 字符串必须是字符串字面量。
- Burst 支持以下 `string.Format` 方法：
  - `string.Format(string, object)`
  - `string.Format(string, object, object)`
  - `string.Format(string, object, object, object)`
  - `string.Format(string, object[])`。当字符串插值包含多于三个参数时使用此形式，例如 `$"{arg1} {arg2} {arg3} {arg4} {arg5}"`。此时 `object[]` 数组必须是固定大小，并且任何参数都不能涉及控制流，例如 `$"This is a {(cond ? arg1 : arg2)}"`。
- 字符串只能使用值类型。
- 字符串只能使用内置类型参数：
  - `char`
  - `boolean`
  - `byte` / `sbyte`
  - `double`
  - `float`
  - `short` / `ushort`
  - `int` / `uint`
  - `long` / `ulong`
- Burst 支持所有向量类型（例如 `int2`、`float3`），但不支持 `half` 向量类型。例如：

  ```csharp
  var value = new float3(1.0f, 2.0f, 3.0f);
  // 记录 “This value float3(1f, 2f, 3f)”
  Debug.Log($"This value `{value}`");
  ```

- Burst 不支持结构体的 `ToString()`，而是显示结构体的完整名称。

更多信息请参阅 .NET 文档中的[字符串插值](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/tokens/interpolated)和[标准数字格式字符串](https://docs.microsoft.com/en-us/dotnet/standard/base-types/standard-numeric-format-strings)。

## 托管字符串

可以将托管 `string` 字面量或插值字符串直接传递给 `Debug.Log`，但不能将字符串传递给用户方法，也不能将字符串作为结构体字段。要传递或存储字符串，请使用 `Unity.Collections` 包中的 [`FixedString`](https://docs.unity3d.com/Packages/com.unity.collections@1.2/api/Unity.Collections.FixedString.html) 结构体之一：

```csharp
int value = 256;
FixedString128Bytes text = $"This is an integer value {value} used with FixedString128Bytes";
MyCustomLog(text);

// 可以使用 FixedString 将字符串作为参数传递，
// 但不能直接使用托管 string：
public static void MyCustomLog(in FixedString128Bytes log)
{
    Debug.Log(log);
}
```

## 参数和格式说明符

Burst 对字符串格式参数和格式说明符的支持有限：

```csharp
int value = 256;

// 左对齐填充：“This value `  256`”
Debug.Log($"This value `{value,5}`");

// 右对齐填充：“This value `256  `”
Debug.Log($"This value `{value,-5}`");

// 大写十六进制：“This value `00FF`”
Debug.Log($"This value `{value:X4}`");

// 小写十六进制：“This value `00ff`”
Debug.Log($"This value `{value:x4}`");

// 带前导零的十进制：“This value `0256`”
Debug.Log($"This value `{value:D4}`");
```
