# 避免不必要的零初始化

> 原文：[Prevent unnecessary zero initialization](https://docs.unity3d.com/6000.7/Documentation/Manual/burst/optimization-skiplocalsinit.html)

使用 `SkipLocalsInitAttribute` 告诉 Burst，方法内的任何栈分配都不必初始化为零。

在 C# 中，所有局部变量默认初始化为零，这可以避免与未定义数据相关的一类错误。但初始化数据会产生运行时开销：

```csharp
static unsafe int DoSomethingWithLUT(int* data);

static unsafe int DoSomething(int size)
{
    int* data = stackalloc int[size];

    // 将 data 的每个字段初始化为递增的一组值。
    for (int i = 0; i < size; i++)
    {
        data[i] = i;
    }

    // 在其他位置使用这些数据。
    return DoSomethingWithLUT(data);
}
```

这段代码的 X86 汇编如下：

其中的 `movabs  rax, offset burst.memset.inline.X64_SSE4.i32@@32` 表示必须注入 memset 来将数据清零。在此示例中，你知道下面的循环会完整初始化数组，但 Burst 无法知道这一点。

要解决这个问题，使用 `Unity.Burst.CompilerServices.SkipLocalsInitAttribute`，告诉 Burst 方法中的栈分配不必初始化为零。

**注意**：只有在确定不会遇到未定义行为错误时，才使用此属性。

例如：

```csharp
using Unity.Burst.CompilerServices;

static unsafe int DoSomethingWithLUT(int* data);

[SkipLocalsInit]
static unsafe int DoSomething(int size)
{
    int* data = stackalloc int[size];

    // 将 data 的每个字段初始化为递增的一组值。
    for (int i = 0; i < size; i++)
    {
        data[i] = i;
    }

    // 在其他位置使用这些数据。
    return DoSomethingWithLUT(data);
}
```
