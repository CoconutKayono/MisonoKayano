# 向代码添加优化提示

> 原文：[Add optimization hints to your code](https://docs.unity3d.com/6000.7/Documentation/Manual/burst/optimization-hint.html)

使用 `Hint` intrinsics 向代码中添加帮助 Burst 优化的信息。它提供以下方法：

- `Unity.Burst.CompilerServices.Hint.Likely`：表示布尔条件很可能为真。
- `Unity.Burst.CompilerServices.Hint.Unlikely`：表示布尔条件不太可能为真。
- `Unity.Burst.CompilerServices.Hint.Assume`：表示可以假设布尔条件为真。

## Likely intrinsic

`Likely` intrinsic 表示某个分支条件为真的概率很高，因此 Burst 可以针对该分支进行重点优化：

```csharp
if (Unity.Burst.CompilerServices.Hint.Likely(b))
{
    // Burst 会假设我们很可能执行到这里，并据此优化代码！
}
else
{
    // 这部分代码会避开优化器的重点处理。
}
```

## Unlikely intrinsic

`Unlikely` intrinsic 与 `Likely` 相反：该条件不太可能为真，因此 Burst 可以针对条件为假的情况进行优化：

```csharp
if (Unity.Burst.CompilerServices.Hint.Unlikely(b))
{
    // 这部分代码会避开优化器的重点处理。
}
else
{
    // Burst 会假设我们很可能执行到这里，并据此优化代码！
}
```

`Likely` 和 `Unlikely` intrinsics 会确保 Burst 在二进制文件中把最可能执行的代码放在分支条件之后。这意味着该代码很可能位于指令缓存中。Burst 还可以将代码从 likely 分支中提升出来，并花费更多时间进行优化，同时减少对 unlikely 代码的优化时间。

检查分配结果是否有效就是一个 unlikely 分支的例子。分配大多数时候都有效，因此希望这条路径很快，同时还需要保留错误情况的回退路径。

## Assume intrinsic

`Assume` intrinsic 表示 Burst 可以假设某个条件始终为真。请谨慎使用。

使用 `Assume` 可以任意告诉 Burst 某件事为真。例如，可以告诉 Burst 循环结束值始终是 16 的倍数，使该循环能够完美向量化而不需要标量收尾。也可以用它告诉 Burst 某个值不是 `NaN`，或者该值为负数。

```csharp
Unity.Burst.CompilerServices.Hint.Assume(b);

if (b)
{
    // 已告诉 Burst b 始终为真，因此总会执行此分支。
}
else
{
    // 因为 b 始终为真，这部分代码会从程序中移除！
}
```
