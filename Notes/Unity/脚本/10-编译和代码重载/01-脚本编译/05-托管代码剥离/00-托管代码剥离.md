# 托管代码剥离

> 原文：[Managed code stripping](https://docs.unity3d.com/6000.7/Documentation/Manual/managed-code-stripping.html)

在构建过程中，Unity 会通过称为 Managed Code Stripping 的过程移除未使用或不可达的代码，从而显著减小应用程序的最终体积。Managed Code Stripping 会从托管程序集（managed assemblies）中移除代码，包括由项目中的 C# 脚本构建的程序集、属于 packages 和 plug-ins 的程序集，以及 .NET Framework 中的程序集。

Unity 使用名为 Unity Linker 的工具对项目程序集中的代码执行静态分析。静态分析会识别执行期间无法到达的类、类的一部分、函数或函数的一部分。此分析只包含构建时已经存在的代码，因为 Unity 执行静态分析时，运行时生成的代码尚不存在。

你可以在 Unity Editor 中配置项目所执行的代码剥离级别。也可以通过 Attribute 或特殊的 XML 配置文件提供注释，指示 Unity Linker 应保留代码库中的哪些部分。
