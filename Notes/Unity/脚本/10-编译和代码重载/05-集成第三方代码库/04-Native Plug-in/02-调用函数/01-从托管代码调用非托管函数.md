# 从 Managed Code 调用 Unmanaged Function

> 原文：[Call unmanaged functions from managed code](https://docs.unity3d.com/6000.7/Documentation/Manual/plug-ins-native-invoke-unmanaged.html)

要从 Managed Code 调用 Unmanaged Function，必须在 C# 中声明一个 Function Prototype，并满足以下特征：

- 与 Unmanaged Function 具有相同的名称。
- 具有兼容的参数和返回类型。
- 声明为 `static`。
- 声明为 `extern`。
- 具有用于标识 Native Library 位置的 `DllImportAttribute`。

此外，Unmanaged Function 必须使用 C Linkage 导出。C Linkage 可以避免 C++ 风格 Linkage 产生的 Name Mangling 以及其他 Application Binary Interface（ABI）问题。

可以将这些 Managed Declaration 放在 C# Code 中方便的位置。例如，可以将它们全部声明在一个 Class 中，也可以在使用它们的不同 Class 中分别声明各个 Function。

**Note**：Unmanaged Function 只能向 Managed Code 返回 Blittable Type。Blittable Type 包括 Primitive Value，以及只包含 Blittable Type 的 Struct 和 Array。

例如，Native Plug-in 可以定义以下 Function。按当前写法，可以直接将它复制到 Unity Project 中的 C++ Source Code File，Unity 会对其进行静态编译和链接：

```cpp
extern "C" {
    void SendString(const char* message) {
        printf("%s\n", message); // Shown in Player.log
        fflush(stdout);
    }
}
```

要将相同的 Code 构建为预编译 Dynamic Library，还必须导出每个 Function，让 Dynamic Loader 可以找到它们。定义一个 Export Macro，并在每个导出的 Function 前加上它（例如 `EXPORT_API void SendString(...)`）。静态链接的 Source Code Plug-in 不需要此 Annotation：

```c
// Select the annotation by target platform, not by compiler: every Windows
// compiler (MSVC, MinGW, and Clang) needs __declspec(dllexport) to export from a
// DLL, while GCC and Clang use the visibility attribute on other platforms.
#if defined(_WIN32)
#define EXPORT_API __declspec(dllexport)
#elif defined(__GNUC__) || defined(__clang__)
#define EXPORT_API __attribute__((visibility("default")))
#else
#define EXPORT_API
#endif
```

**Note**：预编译 Dynamic Library 还要求 Managed 与 Unmanaged 两侧在 32-bit Windows 上使用相同的 Calling Convention。关于与 Unity 默认使用的 Convention 相匹配的 `STDCALL` Macro，请参阅 [[02-从非托管代码调用托管函数]]，并以相同方式应用它（例如 `EXPORT_API void STDCALL SendString(...)`）。

你的 C# Class 可以按以下方式为 `SendString()` Function 声明 Managed Function Prototype：

```csharp
[DllImport("__Internal")]
private static extern void SendString(string message);
```

关于如何确定要加载的 Native Plug-in Library，详见 [[../04-DllImport属性]]。
