# 与 Web Server 交互

> 原文：[Interacting with web servers](https://docs.unity3d.com/6000.7/Documentation/Manual/web-request.html)

[`UnityWebRequest`](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Networking.UnityWebRequest.html) 类及相关 API 提供了构造 HTTP Request 和处理 HTTP Response 的系统。Unity Web Request 系统允许 Unity 游戏与 Web 后端交互，同时支持分块 HTTP 请求、流式 `POST`/`PUT` 操作，以及对 HTTP Header 和 Method 的完全控制。
