矩形变换（Rect Transform）

本页内容属性（Properties）详细说明（Details）

Rect Transform 是 Transform 在二维布局中的对应组件。Transform 表示一个点，Rect Transform 表示可放置 UI 元素的矩形。如果父级也是 Rect Transform，子级还可以定义相对于父矩形的位置和尺寸。

属性（Properties）

属性 功能说明
Pos (X, Y, Z) 矩形轴心点（Pivot）相对于锚点的位置；矩形围绕此轴心旋转。
Width/Height 矩形的宽度和高度。
Left, Top, Right, Bottom 矩形边缘相对于各自锚点的位置，可理解为锚点定义矩形内的 Padding。锚点分离时，这些值会替代 Pos 和 Width/Height。单击 RectTransform 左上方的 Anchor Presets 方框可访问这些选项。
Anchors 矩形左下角和右上角的锚点。
        Min 左下角锚点的位置，以父矩形尺寸的比例表示。0,0 对应父级左下角，1,1 对应父级右上角。
        Max 右上角锚点的位置，以父矩形尺寸的比例表示。0,0 对应父级左下角，1,1 对应父级右上角。
轴心（Pivot） 矩形围绕其旋转的轴心位置，以自身尺寸的比例表示。0,0 是左下角，1,1 是右上角。
旋转（Rotation） 对象围绕轴心沿 X、Y、Z 轴旋转的角度，单位为度。
缩放（Scale） 对象在 X、Y、Z 方向上的缩放系数。
蓝图模式（Blueprint Mode） 按未旋转、未缩放的方式编辑 RectTransform，也会启用吸附（Snapping）。
原始编辑模式（Raw Edit Mode） 启用后，编辑 Pivot 和 Anchor 不会通过反向调整位置和尺寸来保持矩形原位。

详细说明（Details）

部分 RectTransform 计算在帧末、计算 UI 顶点之前执行，以纳入本帧中的最新变化。这意味着第一次 Start 和第一次 Update 回调时，这些值可能尚未完成首次计算。

可在 Start() 中调用 Canvas.ForceUpdateCanvases()，强制 Canvas 在调用时更新，而非等待帧末。

完整入门和概述参阅 Basic Layout。
