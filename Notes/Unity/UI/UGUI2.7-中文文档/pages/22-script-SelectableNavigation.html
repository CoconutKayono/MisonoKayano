导航选项（Navigation Options）

离线英文原文Unity 在线原文 ↗

上一页可选择组件基类（Selectable Base Class）下一页按钮（Button）

属性 功能说明
导航（Navigation） Navigation 决定 Play Mode 中如何在 UI 元素之间导航。
无（None） 不使用键盘导航，也不会因鼠标单击或触摸而获得焦点。
水平（Horizontal） 沿水平方向导航。
垂直（Vertical） 沿垂直方向导航。
自动（Automatic） 自动导航。
显式（Explicit） 可为不同方向键明确指定下一导航目标。
可视化（Visualize） 选中 Visualize 后，Scene 窗口会显示已配置的导航关系，见下图。

图中的箭头表示这组控件的焦点切换关系：某控件有焦点时，按方向键会将焦点移到哪个控件。示例中，Button 获得焦点后按右键，会选中左侧的第一个垂直 Slider。垂直 Slider 的上下键用于调整值，不能用来移出焦点；水平 Slider 的左右键也有相同限制。
