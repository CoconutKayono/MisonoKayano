属性分为以下各组：

组（Group） 说明
字体字面信息（Face Info） 管理字体的行度量。
生成设置（Generation Settings） 查看字体资源生成的值。
图集与材质（Atlas & Material） 查看此字体资源生成的子资源。
字体子集化（Font Subsetting） 对源字体进行子集化，使构建只包含选定字符。
字体粗细（Font Weights） 控制粗体和斜体文本的外观。
后备字体资源（Fallback Font Assets） 管理用于补充缺失字符的后备字体资源列表。
字符表（Character Table） 管理在字体资源中包含的字符。
字形表（Glyph Table） 导入字体数据出现问题时，可调整单个字形的属性进行修正。
字形调整表（Glyph Adjustment Table） 控制特定字符对之间的间距。
连字表（Ligature Table） 管理将多个字形替换为单个连字字形的替换规则。
标记与基字形调整表（Mark To Base Adjustment Table） 管理基字形与标记字形之间的位置调整。
标记与标记调整表（Mark To Mark Adjustment Table） 管理成对标记字形之间的位置调整。

字体字面信息（Face Info）

Face Info 属性用于控制字体的行度量，也包含由以下工具生成的只读属性： 字体资源创建器（Font Asset Creator） 在创建此资源时生成的属性。

属性（Property） 说明
更新纹理图集（Update Texture Atlas） 打开 字体资源创建器（Font Asset Creator） ，并预先配置为修改及重新生成此字体资源。
字体族名称（Family Name） 创建字体资源的字体名称。

TextMesh Pro 在生成字体资源时设置此值，无法手动更改。
样式名称（Style Name） 用于创建此字体资源的字体样式。例如， 常规（Regular）、 粗体（Bold）或是 斜体（Italic）.

TextMesh Pro 在生成字体资源时设置此值，无法手动更改。
点数大小（Point Size） 字号，以磅为单位。

生成字体资源时，TextMesh Pro 将此值烘焙到图集纹理中，不能手动修改。
缩放 按此值缩放字体。例如，值为 1.5 时，字形会缩放至正常大小的 150%。
行高（Line Height） 控制相邻文本行顶部之间的距离。

如果行高大于以下两个值之和： 上升线（Ascent Line） 和 下降线（Descent Line） ，则行间会出现间隙。

如果行高小于以下两个值之和： 上升线（Ascent Line） 和 下降线（Descent Line） ，则不同行的字符可能重叠。
上升线（Ascent Line） 控制字形可延伸到基线上方的最大距离，对应文本行的顶部。
大写字母线（Cap Line） 控制基线到大写字形顶部之间的距离。
中线（Mean Line） 控制不带上伸部的小写字形的最大高度（例如， a 和 c，但不包括 b 和 d，因为这些字符具有上伸部）。

圆形字形的顶部有时会略高于中线。
基线（Baseline） 控制了基线的高度。

基线是字符排列所依据的水平线。
下降线（Descent Line） 控制字形可以在基线以下延伸的最大距离。
下划线偏移（Underline Offset） 控制下划线相对于基线的位置。
下划线厚度（Underline Thickness） 控制下划线的厚度。
删除线偏移（Strikethrough Offset） 控制删除线相对于基线的位置。
上标偏移（Superscript Offset） 设置上标文本相对于基线的偏移。
上标大小（Superscript Size） 相对于正常字号缩放上标文本。
下标偏移（Subscript Offset） 设置下标文本相对于基线的偏移。
下标大小（Subscript Size） 相对于正常字号缩放下标文本。
制表符宽度（Tab Width） 指定 TAB 制表符的宽度。

生成设置（Generation Settings）

字体资源创建器（Font Asset Creator） 当你生成字体资源时会产生这些值。

注意

当 图集填充模式（Atlas Population Mode） 是 动态（Dynamic）时，可以更改图集尺寸而无需重新生成图集。

属性（Property） 说明
源字体文件（Source Font File） 指定作为源文件使用的字体文件位置。
字体字面（Font Face） 选择要使用的字面，例如常规或粗体。
图集填充模式（Atlas Population Mode） 确定字体资源类型：Static（静态）、Dynamic（动态）或 Dynamic OS（动态系统字体）。
渲染模式（Render Mode） 定义 Font Engine 渲染字形时使用的渲染模式。参阅 图集渲染模式设置（Atlas Render Mode settings） 了解支持的取值。
采样点数大小（Sampling Point Size） 确定字体纹理中的字符大小，以磅为单位。
内边距 定义字体图集纹理中字符之间的内边距大小。

此值由字体资源创建器在生成字体资源时设置，不可编辑。
图集宽度／高度（Atlas Width/Height） 确定字体图集纹理的宽度和高度。

对于每个维度，从下拉菜单中选择可用的值之一。
多图集纹理（Multi Atlas Textures） 确定字体资源是否需要创建额外的图集纹理。
构建时清除动态数据（Clear Dynamic Data On Build） 确定新建动态字体资源时，Clear Dynamic Data on Build 属性应设为 true 还是 false。
获取字体特性（Get Font Features） 确定动态添加字符和字形到字体资源时，是否从源字体文件获取 OpenType 字体特性。

图集渲染模式设置（Atlas Render Mode settings）

以下属性的有效值： 渲染模式（Render Mode） 属性：

设置（Setting） 说明
SMOOTH 将图集渲染为经过抗锯齿处理的位图。
RASTER 将图集渲染为未经过抗锯齿处理的位图。
SMOOTH_HINTED 将图集渲染为抗锯齿位图，并将字符像素与纹理像素对齐，获得更清晰的结果。
RASTER_HINTED 将图集渲染为非抗锯齿位图，并将字符像素与纹理像素对齐，获得更清晰的结果。
SDF 使用较慢但更准确的 SDF 生成模式渲染图集，不进行过采样。
SDFAA 使用较快但精度稍低的 SDF 生成模式渲染图集。生成的字体图集足以满足多数情况。
SDFAA_HINTED 使用较快但精度稍低的 SDF 生成模式渲染图集，并将字符像素与纹理像素对齐，使结果更清晰。生成的字体图集足以满足多数情况。
SDF8 使用较慢但更准确的 SDF 生成模式渲染图集，采用 8 倍过采样。
SDF16 使用较慢但更准确的 SDF 生成模式渲染图集，采用 16 倍过采样。
SDF32 使用较慢但更准确的 SDF 生成模式渲染图集，采用 32 倍过采样。适用于字符复杂或较小的字体。

字体子集化（Font Subsetting）

对源字体进行子集化，使构建只包含选定字符。此区域只对源字体为项目内字体文件的动态字体资源显示。更多信息参阅 通过字体子集化优化字体文件.

属性（Property） 说明
当前子集（Active Subset） 当前子集中码点的数量，仅在子集启用时显示。
预设（Preset） 用于填充 字符（Characters） 字段的预定义字符集。预设与 字体资源创建器（Font Asset Creator） 字符集。可选择 ASCII、 扩展 ASCII（Extended ASCII）、 ASCII 小写字符（ASCII Lowercase）、 ASCII 大写字符（ASCII Uppercase）、 数字与符号（Numbers + Symbols）、 来自已烘焙图集（From Baked Atlas） （已烘焙到图集中的字符快照），或 自定义（Custom） （自行输入的字符）。
字符（Characters） 子集中要保留的字符。构建包含的字体数据会移除其他所有字形。仅在以下选项启用时显示： 预设（Preset） 设为 来自已烘焙图集（From Baked Atlas） 或 自定义（Custom）.
缺失字符（Missing Characters） 源字体不包含的码点，会从子集中排除。格式字符和控制字符没有可见字形，因此只以码点列出。
字体文件大小（Font File Size） 原始字体文件大小与子集字体数据大小。编辑字符集时，子集大小是以下内容的预览： 更新子集（Update Subset） 生成的结果。
更新子集（Update Subset） 将 字符（Characters） 字段中的字符作为子集。
移除子集（Remove Subset） 删除应用的子集，以便构建包含完整的字体文件。

字体粗细（Font Weights）

使用以下选项之一控制粗体和斜体文本的外观：

  • 设置字体资源粗体与斜体变体的引用。使用此方式时，必须自行为以下粗细范围创建对应的字体资源变体：

    • 100 - 细体（100 - Thin）
    • 200 - 特细（200 - Extra-Light）
    • 300 - 轻体（300 - Light）
    • 400 - 常规（400 - Regular） （仅斜体）
    • 500 - 中等（500 - Medium） （当前字体资源，不可编辑）
    • 600 - 半粗（600 - Semi-Bold）
    • 700 - 粗体（700 - Bold）
    • 800 - 特粗（800 - Heavy）
    • 900 - 黑体（900 - Black）

  • 设置字重、间距、倾斜和制表符数值，控制 TextMesh Pro 如何模拟字体资源的变体：

    设置（Setting） 说明
    常规粗细（Normal Weight） 设置没有对应字体资源时使用的常规字重。
    粗体粗细（Bold Weight） 设置没有对应字体资源时使用的粗体字重。
    间距偏移（Spacing Offset） 使用常规文本样式时，在字符之间添加间距。
    粗体间距（Bold Spacing） 使用模拟粗体样式时（即未指定粗体字体资源），在字符之间添加间距。
    斜体样式（Italic Style） 设置应用于 Normal Style 字体资源的倾斜程度，用于模拟斜体。
    制表符倍数（Tab Multiple） 设置制表符大小。TextMesh Pro 将此值乘以字体中空格字符的宽度，得到实际使用的制表符宽度。

若未指定字体资源，TextMesh Pro 会根据设置的数值模拟粗体和斜体。模拟字重只支持常规与粗体文本及它们的斜体版本，分别相当于字重 400 和 700。

后备字体资源（Fallback Font Assets）

每个字体资源只包含有限数量的字符。使用当前字体资源中没有的字符时，TextMesh Pro 会搜索后备字体列表，直到找到包含该字符的字体资源，再用它渲染该字符。

可用此功能将字体分布到多个纹理中，或为特定字符使用不同字体。搜索列表以寻找缺失字符需要额外计算资源，使用额外字体也会增加绘制调用。

关于后备字体的工作原理，参阅 后备字体资源（Fallback font assets）.

属性（Property） 说明
后备字体资源列表（Fallback Font Asset list） 管理此字体资源的后备字体。

选择（Select） + 和 - 增加和删除字体插槽。

选择字体旁的圆形图标，打开 Object Picker 并选择字体资源。

拖动各字体资源左侧的手柄，调整列表顺序。

字形属性（Glyph properties）

显示单个字形的属性，每个字形各有一个条目。

选择条目，使其成为活动项。随后可以：

  • 在文本字段中输入未使用的 Unicode 十六进制 ID，再选择 复制到（Copy to） ，以复制此字形。

  • 选择（Select） 移除（Remove） 以从列表中移除此字形。

  • 编辑这些设置中的任何一个:

    设置（Setting） 说明
    X、 Y、 W、 H (字形矩形（Glyph Rect）) 在字体图集中定义一个字符的位置。

    缩放 更改此缩放因子以调整字符大小。
    图集索引（Atlas Index） 设置包含此字符的图集纹理索引。
    类别类型（Class Type） 选择 类别定义类型（class definition type） ，用于此字形。

  • 选中记录，使其成为活动项并启用相关控件。
  • 选择（Select） 上移（Up） 或 向下（Down） 在列表中移动记录上或下。
  • 输入以下字形的数量： 组成字形（Component Glyphs） 数量。随后会显示相同数量的文本框，可在其中输入各个待替换字形的索引。
  • 在以下字段输入用于替换它们的字形索引： 连字字形（Ligature Glyph）.
  • 选择（Select） + 在列表中添加字形副本。
  • 选择（Select） - 或 移除（Remove） 将字形从列表中删除。

字形调整表（Glyph Adjustment Table）

字形调整表控制特定字符对之间的间距。有些字体包含字偶距信息，TextMesh Pro 会自动导入。对于未提供字偶距的字体，可自行添加字偶距对。

调整对搜索（Adjustment Pair Search）

按字符或 ASCII 值搜索调整表。只要左侧或右侧字符匹配搜索字符串，条目就会出现在结果中。

搜索结果以左字符的ASCII值的上升顺序显示。

上一项与下一项（Previous and Next）

较长的调整表会分为多页，可以使用 上一页（Previous Page） 和 下一页（Next Page） 按钮。

进行翻页；这些按钮也出现在表格底部。

字形属性（Glyph properties）

显示单个字形的属性，每个字形各有一个条目。

选择条目，使其成为活动项。字偶距对的左右两个字符会显示出来。

可以调整以下设置：

设置（Setting） 说明
OX、 OY 为字偶距对中的每个字符设置水平（X）和垂直（Y）偏移，相对于字符的初始位置。
AX 对于字偶距对中的每个字符，在放置下一个字符之前，请指定在基线沿线前进的距离。

左侧 AX 值控制了字偶距对中的字符之间的距离，而右边的 AX 值控制了字偶距对与下一个字符之间的距离。
选项（Options） 选择 TextMesh Pro 应如何应用此字形对调整，例如忽略间距调整或连字。

添加字偶距对（Add New Kerning Pair）

向字形调整表添加新条目。

你不能复制现有条目。

标记与基字形调整表（Mark To Base Adjustment Table）

标记与基字形调整表提供一组记录，用于定义基字形与标记字形之间的位置调整。

标记到基字形搜索（Mark To Base Search）

按基字形或标记字形的索引搜索表格。

上一项与下一项（Previous and Next）

较长的标记与基字形调整表会分为多页，可以使用 上一页（Previous Page） 和 下一页（Next Page） 按钮。

进行翻页；这些按钮也出现在表格底部。

标记与基字形调整记录

显示标记与基字形调整记录列表，每条记录都有独立条目。

  • 选中记录，使其成为活动项并启用相关控件。
  • 选择（Select） + 在列表中添加字形副本。
  • 选择（Select） - 或 移除（Remove） 将字形从列表中删除。

条目处于活动状态时，可以执行以下操作：

  • 标记字形和基字形各有一个 ID和 X 和 Y 数值。这些成对数值会并排显示在每条记录中。

  • 编辑这些设置中的任何一个:

    设置（Setting） 说明
    X、 Y 对于基字形，设置其锚点位置。
    对于标记字形，设置其相对于基字形锚点的位置调整。
    ID 指定基字形或标记字形的索引。

标记与标记调整表（Mark To Mark Adjustment Table）

标记与标记调整表提供一组记录，用于定义两个标记字形之间的位置调整。

标记到标记搜索（Mark To Mark Search）

按任一标记字形的索引搜索表格。

上一项与下一项（Previous and Next）

较长的标记与标记调整表会分为多页，可以使用 上一页（Previous Page） 和 下一页（Next Page） 按钮。

进行翻页；这些按钮也出现在表格底部。

标记与标记调整记录

显示标记与标记字形调整记录列表，每条记录都有独立条目。

  • 选中记录，使其成为活动项并启用相关控件。
  • 选择（Select） + 在列表中添加字形副本。
  • 选择（Select） - 或 移除（Remove） 将字形从列表中删除。

条目处于活动状态时，可以执行以下操作：

  • 两个标记字形各有一个 ID和 X 和 Y 数值。这些成对数值会并排显示在每条记录中。

  • 编辑这些设置中的任何一个:

    设置（Setting） 说明
    X、 Y 对于用作基准的标记字形，设置其锚点位置。
    对于需要调整的标记字形，设置其相对于基准标记字形锚点的位置调整。
    ID 指定两个标记字形的索引。
