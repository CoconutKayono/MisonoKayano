滚动矩形（Scroll Rect）

本页内容属性事件详细说明滚动条设置提示

需要在较小区域中显示占用较大空间的内容时，可以使用 Scroll Rect。它提供滚动浏览这些内容的功能。

通常将 Scroll Rect 与一个 遮罩（Mask） 来创建滚动视图，使用户只能看到 Scroll Rect 范围内的可滚动内容。此外还可结合一到两个 滚动条（Scrollbars） 组合使用；拖动滚动条即可水平或垂直滚动。

属性

属性： 功能：
内容 要滚动的 UI 元素（例如大图像）的 Rect Transform 引用。
水平 启用水平滚动
垂直 启用垂直滚动
移动类型（Movement Type） Unrestricted（不限制）、Elastic（弹性）或 Clamped（钳制）。Elastic 和 Clamped 会使内容保持在 Scroll Rect 边界内；Elastic 在内容到达边缘时产生回弹。
        弹性（Elasticity） 弹性模式下使用的回弹程度。
惯性（Inertia） 启用 Inertia 后，拖动并松开指针时，内容会继续移动。未启用时，内容仅在拖动过程中移动。
        减速率 启用 Inertia 时，减速率决定内容停止移动的速度。设为 0 会立即停止移动；设为 1 则永远不会减速。
滚动灵敏度 对鼠标滚轮和触控板滚动事件的灵敏度。
视口（Viewport） 视口的 Rect Transform 引用；视口是内容 Rect Transform 的父对象。
水平滚动条（Horizontal Scrollbar） 可选的水平滚动条元素引用。
        可见性 是否在不需要时自动隐藏滚动条，并可同时扩展视口。
        间距（Spacing） 滚动条与视口之间的间距。
垂直滚动条（Vertical Scrollbar） 可选的垂直滚动条元素引用。
        可见性 是否在不需要时自动隐藏滚动条，并可同时扩展视口。
        间距（Spacing） 滚动条与视口之间的间距。

事件

属性： 功能：
值变化事件（On Value Changed） UnityEvent 事件在 Scroll Rect 的滚动位置改变时触发，可将当前滚动位置作为 Vector2 类型的动态参数传递。

详细说明

滚动视图中的重要元素包括 视口、可滚动的 内容，以及可选的一到两个 滚动条.

  • 根GameObject具有Scroll Rect组件。
  • 视口具有一个 遮罩（Mask） 组件。视口可以是根 GameObject，也可以是根对象的独立子 GameObject。若使用自动隐藏滚动条，则必须使用子对象。视口的 Rect Transform 必须引用到 视口（Viewport） 属性。
  • 所有可滚动内容必须属于同一个 Content GameObject，且 Content 是视口的子对象。Content 的 Rect Transform 必须引用到 内容 属性。
  • 若使用滚动条，它们应是根 GameObject 的子对象。关于滚动条的设置，参阅 滚动条 页面；关于滚动视图与滚动条的组合设置，参阅下面的 滚动条设置 部分。

此图展示了视口作为滚动视图根对象的子对象时的设置。这也是使用 GameObject > UI (Canvas) > Scroll View 菜单创建滚动视图时的默认结构。

要滚动内容，必须从 ScrollRect 的边界内接收输入，而不是直接在内容对象上接收输入。

使用 Unrestricted 滚动模式时要谨慎，内容可能滚出到无法再控制的位置。使用 Elastic 或受约束的移动模式时，最好让内容初始位置处于 ScrollRect 边界内；否则 RectTransform 尝试将内容移回边界时，可能产生意外行为。

滚动条设置

Scroll Rect 还可以选择连接水平和／或垂直 滚动条。它们通常在层级中与视口互为同级对象。使用时，应将它们拖入对应的 水平滚动条（Horizontal Scrollbar） 和 垂直滚动条（Vertical Scrollbar） 属性。注意，水平滚动条的 方向（Direction） 属性应设为 Left To Right（从左到右），而垂直滚动条应设为 Bottom To Top（从下到上）.

滚动条可设置为自动隐藏：内容不大于视口、无需滚动时，隐藏滚动条。自动隐藏只在 Play Mode 生效，Edit Mode 中始终显示滚动条，避免不必要地将场景标记为已修改，也便于按滚动条显示时仍有足够空间的比例制作内容。

如果一个或两个滚动条的可见性行为设为 自动隐藏并扩展视口（Auto Hide And Expand View），隐藏滚动条时，视口会自动扩展，利用滚动条原本占据的空间。此时，以下对象的位置与大小： 视口 由 Scroll Rect 驱动， 水平滚动条 的宽度，以及 垂直滚动条 的高度，也会被驱动。采用这种设置时，视口和滚动条都必须是 Scroll Rect 根 GameObject 的子对象。

提示

  • 当内容增大或缩小时，Content RectTransform 的轴心和锚点决定内容在滚动视图内的对齐方式。若内容应始终与顶部对齐，将锚点设在父对象顶部，并将轴心设在顶部。
  • 参阅 让 UI 元素适应内容大小 页面，了解如何让内容的 Rect Transform 自动调整尺寸以适应内容。
