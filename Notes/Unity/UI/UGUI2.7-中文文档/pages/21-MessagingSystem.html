消息系统（Messaging System）

本页内容定义自定义消息（Defining A Custom Message）

新的 UI 系统使用纯 C# 的 Messaging System 来替代 SendMessage，并解决其部分问题。通过在 MonoBehaviour 上实现自定义接口，组件可声明自己能够接收消息系统回调。调用时指定目标 GameObject，系统会对该对象上所有实现指定接口的组件执行回调。消息可携带自定义用户数据，还可控制在 GameObject 层级中的传播范围：只在目标对象执行，或传播到子级、父级。此外，框架提供辅助函数，用于查找实现指定消息接口的 GameObject。

Messaging System 是通用框架，既可用于 UI，也可用于一般游戏代码。添加自定义消息事件很简单，并可复用 UI 事件处理所使用的同一套框架。

定义自定义消息（Defining A Custom Message）

UnityEngine.EventSystems 命名空间中提供基础接口 IEventSystemHandler。继承它的接口都可作为通过消息系统接收事件的目标。

public interface ICustomMessageTarget : IEventSystemHandler
{
    // functions that can be called via the messaging system
    void Message1();
    void Message2();
}

定义接口后，由 MonoBehaviour 实现它。向该 MonoBehaviour 所在的 GameObject 发送对应消息时，就会执行这些函数。

public class CustomMessageTarget : MonoBehaviour, ICustomMessageTarget
{
    public void Message1()
    {
        Debug.Log ("Message 1 received");
    }

    public void Message2()
    {
        Debug.Log ("Message 2 received");
    }
}

有了接收消息的脚本，接下来需要发送消息。通常消息响应某个松耦合事件，例如 UI 系统根据用户输入发送 PointerEnter、PointerExit 等事件。

发送消息时使用静态辅助类，参数包括目标对象、用户数据，以及映射到消息接口中具体函数的委托（Functor）。

ExecuteEvents.Execute<ICustomMessageTarget>(target, null, (x,y)=>x.Message1());

此代码会在目标 GameObject 上所有实现 ICustomMessageTarget 的组件中调用 Message1。ExecuteEvents 脚本文档还介绍了在子级或父级执行等其他调用形式。
