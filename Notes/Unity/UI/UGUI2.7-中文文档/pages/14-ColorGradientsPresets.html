渐变预设（Gradient Presets）

本页内容创建渐变预设（Creating gradient presets）应用渐变预设（Applying gradient presets）移除渐变预设（Removing gradient presets）

Gradient Preset 用于在多个文本对象之间复用相同的颜色渐变。预设会覆盖文本本地的渐变类型和颜色。

预设必须存放在指定文件夹中，TextMesh Pro 才能找到并将其加入构建。该文件夹可在 TextMesh Pro 设置中修改。参考：TextMesh Pro settings

创建渐变预设（Creating gradient presets）

选择 Assets > Create > TextMesh Pro > Color Gradient。

这会创建新的 TextMesh Pro Color Gradient 资源，并在 Inspector 中打开。

在 Color Mode 下拉菜单中选择渐变类型，再设置 Colors。参考：gradient type

应用渐变预设（Applying gradient presets）

通过 TextMesh Pro Inspector 将渐变预设应用于文本。

应用步骤：

  1. 启用 Main Settings > Color Gradient。
  2. 打开 Main Settings > Color Preset 的 Object Picker（圆圈图标），选择预设。

应用后，Inspector 将用预设的值覆盖文本原来的渐变类型和颜色。

注意（Caution）

应用预设后，在 TextMesh Pro Inspector 中修改渐变设置，会修改预设本身，所有使用同一预设的对象都会受到影响。

移除渐变预设（Removing gradient presets）

打开 Main Settings > Color Preset 的 Object Picker，选择 None。

移除后，文本恢复使用本地渐变属性。
