补间动画（Tweening）

Tweening（UnityEngine.UI.Tweening）是 uGUI 内部使用的动画工具，用于平滑地过渡属性值，例如 Graphic 和 Selectable 响应交互时触发的颜色淡变和 Alpha 动画。它不面向游戏代码直接使用；原文建议通用补间需求使用 Animator 或 DOTween / LeanTween。

概述（Overview）

系统包含以下类型：

类型（Type） 作用
ColorTween 对 Color 插值，并通过回调传出结果。
FloatTween 对 float 插值，并通过回调传出结果。
TweenRunner<T> 为一个所有者对象管理单个活动 Tween 的生命周期。
TweenManager 单例，每个渲染帧驱动全部活动 TweenRunner 实例一次。

ColorTween

ColorTween 在两个 Color 之间插值，ColorTweenMode 决定哪些通道参与动画：

模式（Mode） 行为
All 对 R、G、B、A 四个通道进行线性插值（Lerp）。
RGB 只对 R、G、B 插值，Alpha 保持起始值。
不透明度（Alpha） 只对 Alpha 插值，R、G、B 保持起始值。

属性（Properties）

属性 类型（Type） 说明
startColor 颜色（Color） 进度为 0 时的颜色。
targetColor 颜色（Color） 进度为 1 时的颜色。
tweenMode ColorTweenMode 需要动画化的通道，默认为 All。
duration float 持续时间，单位为秒。
ignoreTimeScale bool 为 true 时使用 Time.unscaledDeltaTime。

方法（Methods）

方法（Method） 说明
SetChangedCallback(Action<Color>) 注册每次 Tick 调用的回调，并替换此前注册的回调。
TweenValue(float) 根据给定进度计算插值颜色，并调用回调。
ValidTarget() 已注册回调时返回 true。

FloatTween

FloatTween 在 startValue 与 targetValue 之间对单个 float 插值。

属性（Properties）

属性 类型（Type） 说明
startValue float 进度为 0 时的值。
targetValue float 进度为 1 时的值。
duration float 持续时间，单位为秒。
ignoreTimeScale bool 为 true 时使用 Time.unscaledDeltaTime。

方法（Methods）

方法（Method） 说明
SetChangedCallback(Action<float>) 注册每次 Tick 调用的回调，并替换此前注册的回调。
TweenValue(float) 根据给定进度计算插值 float，并调用回调。
ValidTarget() 已注册回调时返回 true。

TweenRunner<T>

TweenRunner<T> 为指定 MonoBehaviour 所有者同时管理一个 Tween。开始新 Tween 会自动停止正在运行的 Tween。

var runner = new TweenRunner<ColorTween>();
runner.Init(this);          // call once, typically in OnEnable

var tween = new ColorTween
{
    startColor  = Color.white,
    targetColor = Color.red,
    duration    = 0.15f,
    ignoreTimeScale = true
};
tween.SetChangedCallback(c => image.color = c);
runner.StartTween(tween);

方法（Methods）

方法（Method） 说明
Init(MonoBehaviour) 将 Runner 与 MonoBehaviour 关联，必须在 StartTween 之前调用。
StartTween(T) 停止正在运行的 Tween 并开始新的。如果所有者 GameObject 未激活，立即调用 TweenValue(1f)，且不注册 Tick 更新。
StopTween() 取消活动 Tween；没有 Tween 运行时调用也安全。
说明（Note）

未调用 Init 时，StartTween 会记录警告并直接返回，不启动 Tween。

TweenManager

TweenManager 是内部单例，在每帧 Canvas 渲染前（Canvas.willRenderCanvases）更新全部已注册 TweenRunner。不需直接操作它，TweenRunner 会代为调用 Register 和 Unregister。

Tick 调度（Tick scheduling）

Tick 由 Canvas.willRenderCanvases 驱动，该事件在本帧脚本执行完毕后、构建 Canvas Batch 之前触发，让本帧的颜色和 Alpha 变化进入同一次 Canvas 重建。

回调期间的安全修改（Safe mutation）

遍历期间发生的注册与注销会被延后处理，例如某 Tween 回调启动或停止另一个 Tween。更新循环结束后立即执行延后操作，使所有副作用仍在同一帧内完成。

完成（Completion）

经过时间达到或超过 duration 时，Tween 完成。在该 Tick 中仅调用一次 TweenValue(1f)，然后注销 Runner。无论帧时间如何变化，最终值都精确等于 targetColor 或 targetValue。
