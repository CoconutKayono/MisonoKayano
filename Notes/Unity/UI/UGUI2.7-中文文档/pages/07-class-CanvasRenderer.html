画布渲染器（Canvas Renderer）

离线英文原文Unity 在线原文 ↗

本页内容属性（Properties）详细说明（Details）

Canvas Renderer 负责渲染 Canvas 内的图形 UI 对象。

属性（Properties）

下表说明 Canvas Renderer 组件的属性：

属性 功能说明
剔除透明网格（Cull Transparent Mesh） 网格透明时是否忽略此渲染器。设为 true 时，透明网格对应的几何数据不会参与渲染。

详细说明（Details）

通过 GameObject > Create UI 菜单创建的标准 UI 对象，会在需要时自动带有 Canvas Renderer；自定义 UI 对象可能需要手动添加。原文同时提到 Inspector 不公开属性，但部分属性和方法可通过脚本访问；完整信息见 Script Reference 中的 CanvasRenderer 页面。
