射线检测器（Raycasters）

离线英文原文Unity 在线原文 ↗

上一页输入模块（Input Modules）下一页支持的事件（Supported Events）

Raycaster 用于确定特定屏幕位置（如鼠标单击或触摸位置）下有哪些对象。它从屏幕向场景投射射线，检测与射线相交的对象，用于识别 UI、二维或三维对象上的用户交互。

不同类型的对象使用不同的 Raycaster：

  • Graphic Raycaster：检测 Canvas 上的 UI 元素。
  • Physics 2D Raycaster：检测二维物理对象。
  • Physics Raycaster：检测三维物理对象。

Event System 使用 Raycaster 决定输入事件的接收目标。场景中存在并启用 Raycaster 时，系统会确定给定屏幕位置上最近的对象；多个 Raycaster 同时启用时，会对所有检测器执行检测，并按距离对结果排序。
