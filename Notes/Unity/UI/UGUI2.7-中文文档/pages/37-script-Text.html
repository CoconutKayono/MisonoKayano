Text 向用户显示不带交互的文本，可作为其他 GUI 控件的标题或标签，也可显示说明和其他文字。

属性（Properties）

属性 功能说明
文本（Text） 控件显示的文本。
字符（Character）
字体（Font） 显示文本使用的 Font。
字体样式（Font Style） 文本样式：Normal、Bold、Italic 或 Bold And Italic。
字号（Font Size） 显示文本的字号。
行距（Line Spacing） 各行之间的垂直间距。
富文本（Rich Text） 是否将文本中的标记解析为 Rich Text 样式？
段落（Paragraph）
对齐（Alignment） 文本的水平和垂直对齐方式。
按几何对齐（Align by Geometry） 使用字形几何边界而非字形度量（Glyph Metrics）进行水平对齐。
水平溢出（Horizontal Overflow） 文本宽度超过矩形时的处理方式：Wrap 或 Overflow。
垂直溢出（Vertical Overflow） 换行后的文本高度超过矩形时的处理方式：Truncate 或 Overflow。
自动适配（Best Fit） 是否忽略字号属性，自动尝试让文本适合控件矩形？
颜色（Color） 渲染文本的颜色。
材质（Material） 渲染文本的 Material。

详细说明（Details）

Button、Toggle 等控件内置文字说明；Slider 等没有内置文字的控件，可用 Text 标签解释用途。Text 也适合操作说明、故事文字、对话和法律声明。参考：Buttons Toggles Sliders

Text 提供字号、字体样式、对齐等常见参数。启用 Rich Text 后，文本中的标记会被解释为样式信息，可将单个词或短段落加粗、改色等；语法参阅 Rich Text。

提示（Hints）

  • 简单阴影或轮廓效果的用法参阅 Effects。
