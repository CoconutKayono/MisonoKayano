下拉列表（Dropdown） 让用户从选项列表中选择一个选项。

控件显示当前选择的选项。单击后会展开列表，供用户选择新选项。选择完成后列表关闭，控件显示新选项。单击控件本身或 Canvas 内的其他任意位置也会关闭列表。

属性

属性： 功能：
可交互（Interactable） 组件是否接受输入？参阅 可交互（Interactable）.
过渡（Transition） 决定控件如何在视觉上响应用户操作的属性。参阅 过渡选项.
导航（Navigation） 决定控件导航顺序的属性。参阅 导航选项.
模板（Template） 下拉列表模板的 Rect Transform。详见下文。
标题文本（Caption Text） 显示当前选中项文本的 Text 组件。（可选）
标题图像（Caption Image） 显示当前选中项图像的 Image 组件。（可选）
选项文本（Item Text） 显示选项文本的 Text 组件。（可选）
选项图像（Item Image） 显示选项图像的 Image 组件。（可选）
值（Value） 当前选中项的索引：0 表示第一项，1 表示第二项，依此类推。
选项（Options） 可选项列表。每项都可指定文本字符串和图像。

事件

属性： 功能：
值变化事件（On Value Changed） UnityEvent 事件，在用户单击下拉列表中的某个选项时调用。

详细说明

选项列表可以在 Inspector 中指定，也可从代码赋值。每个选项可以指定文本字符串；如果 Dropdown 的设置支持图像，还可指定图像。

按钮只有一个事件，名为 值变化事件（On Value Changed） ，在用户完成对列表中某个选项的单击时触发。它支持传递选中项索引，类型为整数；0 表示第一项，1 表示第二项，依此类推。

模板系统

Dropdown 的一个子 GameObject 用作下拉列表模板。单击控件时，使用该模板显示列表。模板对象默认不激活，但编辑时可将其激活以方便观察。必须在 Dropdown 组件的 Template 属性中指定模板对象的引用。

模板必须包含一个挂有 Toggle 组件的选项。单击控件创建实际下拉列表时，会复制该选项，为每个可选项生成一个副本。选项的父对象会自动调整大小，以容纳全部选项。

模板可以采用不同设置。通过 GameObject > UI (Canvas) > Dropdown 创建的默认模板包含滚动视图；选项过多、无法同时显示时，会出现滚动条，供用户滚动浏览。这并不是模板的强制要求。

（关于滚动视图的设置，参阅 ScrollRect 页面。）

设置文本与图像支持

下拉列表的每个选项支持一段文本和一张图像，两者都可选。只有 Dropdown 配置了相应支持时，才可使用这些内容。

同时设置 Caption Text 和 Item Text 后，每个选项即可显示文本。通过 GameObject > UI (Canvas) > Dropdown 创建时，默认已经设置这两个属性。

  • Caption Text 是显示当前选中项文本的 Text 组件，通常是 Dropdown GameObject 的子对象。
  • Item Text 是显示每个选项文本的 Text 组件，通常是 Item GameObject 的子对象。

同时设置 Caption Image 和 Item Image 后，每个选项即可显示图像。默认不会设置这两个属性。

  • Caption Image 是显示当前选中项图像的 Image 组件，通常是 Dropdown GameObject 的子对象。
  • Item Image 是显示每个选项图像的 Image 组件，通常是 Item GameObject 的子对象。

下拉列表实际使用的文本与图像在 Dropdown 组件的 Options 属性中指定，也可以从代码设置。

下拉列表的位置

下拉列表相对于控件的位置，由 Template 的 Rect Transform 的锚点与轴心决定。

默认情况下，列表显示在控件下方：模板锚定在控件底部，模板轴心位于顶部。这样，当模板扩大以容纳不同数量的选项时，只会向下扩展。

Dropdown 用简单的逻辑避免列表出现在 Canvas 边界之外，否则某些选项将无法选中。如果列表在默认位置无法完全容纳于 Canvas 矩形内，就会反转它相对于控件的位置。例如默认显示在控件下方的列表，会改到上方。

这种逻辑很简单，也有一定限制。模板尺寸不能大于 Canvas 尺寸的一半再减去控件尺寸，否则控件位于 Canvas 中间时，上下两个位置都可能没有足够空间容纳列表。
