字体资源（Font Assets）

要在 TextMesh Pro 中使用不同字体，需要创建 Font Asset。TMP 有独立的字体资源格式，它与 Unity 常规字体资源格式不同，但由后者生成。参考：Unity's regular font Asset format

每个 TextMesh Pro Font Asset 包含两个子资源：

  • 字体图集（Font Atlas）：包含资源内所有字符的黑白或灰度纹理文件。下图为图集示例。
  • 字体材质（Font Material）：使用某种 TextMesh Pro Shader 控制文本外观的材质。参考：TextMesh Pro shaders

Font Asset 必须存放在指定文件夹中，TextMesh Pro 才能找到并将其打包进构建。可在 TextMesh Pro 设置中修改 Default Font Asset > Path。参考：TextMesh Pro settings

创建字体资源（Creating Font Assets）

使用 TextMesh Pro Font Asset Creator 创建字体资源。

也可以通过 Unity 主菜单创建空的 TMP Font Asset。空资源默认不含字符，需要后续添加。选中 Unity 字体资源，然后选择 Asset > Create > TextMeshPro > Font Asset。

字体图集类型（Types of font atlas）

Font Asset 可以使用以下图集类型：

  • Distance Field：包含有符号距离场（Signed Distance Field，SDF）信息。推荐大多数应用使用，因为 SDF 文本经过变换后仍能保持平滑。参考：signed distance field (SDF)
  • Smooth / Hinted Smooth：带抗锯齿的位图纹理。Hinted Smooth 将字形像素与纹理像素对齐，得到更平滑的结果。适用于正面观察的静态文本，且纹理像素与屏幕像素较好对应；对文本进行变换会使边缘模糊。
  • Raster / Raster Hinted：不作平滑处理的位图纹理，文本边缘通常呈锯齿或像素状。Raster Hinted 将字形像素与纹理像素对齐以改善平滑度。

获取字体特性（Get Font Features）

决定在向字体资源添加新字符和字形时，是否从源字体文件提取 OpenType Font Features。禁用后将不提取这些特性。

修改 FontAsset 的 Get Font Features：

  1. 选中 FontAsset。
  2. 在 FontAsset Inspector 中找到 Generation Settings。
  3. 切换 Get Font Features。

重置（Reset）

右键菜单的 Reset 会清空所有表，包括 Character、Glyph，以及 Ligature、Glyph Adjustment、Mark to Base、Mark to Mark 等字体特性表。它也会清空字体图集纹理，并将尺寸重置为 0。

重置 FontAsset：

  1. 选中 FontAsset。
  2. 打开 FontAsset Inspector 右上角菜单。
  3. 选择 Reset。

清除动态数据（Clear Dynamic Data）

Clear Dynamic Data 会清空 Character、Glyph 表和图集纹理，并将图集尺寸重置为 0，但保留 Ligatures、Glyph Adjustment、Mark to Base、Mark to Mark 等字体特性表数据。

清除 FontAsset 的动态数据：

  1. 选中 FontAsset。
  2. 打开 FontAsset Inspector 右上角菜单。
  3. 选择 Clear Dynamic Data。

这样，在清空图集的同时，仍能保留手动添加的连字、字偶距和附加符号数据。

构建时清除动态数据（Clear Dynamic Data on Build）

该选项与 Clear Dynamic Data 类似，但还会在构建项目或关闭 Editor 时清除数据。

启用后，构建过程中会将纹理尺寸调整为 0（空）。

对于动态 FontAsset，它会将 Glyph Atlas、Character Table 和 Glyph Table 恢复初始状态，减少资源数据占用，从而减小构建体积。

修改 Clear Dynamic Data on Build：

  1. 选中 FontAsset。
  2. 在 FontAsset Inspector 中找到 Generation Settings。
  3. 切换 Clear Dynamic Data on Build。
