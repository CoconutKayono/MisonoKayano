支持的事件（Supported Events）

离线英文原文Unity 在线原文 ↗

上一页射线检测器（Raycasters）下一页事件触发器（Event Trigger）

Event System 支持多种事件，还可以通过自定义 Input Module 进一步定制。

Standalone Input Module 和 Touch Input Module 支持的事件以接口形式提供。MonoBehaviour 实现对应接口后，只要 Event System 配置有效，就会在适当时机收到回调。

  • IPointerEnterHandler → OnPointerEnter：指针进入对象时调用。参考：IPointerEnterHandler
  • IPointerExitHandler → OnPointerExit：指针离开对象时调用。参考：IPointerExitHandler
  • IPointerDownHandler → OnPointerDown：指针在对象上按下时调用。参考：IPointerDownHandler
  • IPointerUpHandler → OnPointerUp：指针释放时调用，接收者为此前被按下的 GameObject。参考：IPointerUpHandler
  • IPointerClickHandler → OnPointerClick：指针在同一个对象上按下并释放时调用。参考：IPointerClickHandler
  • IInitializePotentialDragHandler → OnInitializePotentialDrag：找到潜在拖动目标时调用，可初始化相关值。参考：IInitializePotentialDragHandler
  • IBeginDragHandler → OnBeginDrag：即将开始拖动时，在被拖动对象上调用。参考：IBeginDragHandler
  • IDragHandler → OnDrag：拖动过程中，在被拖动对象上调用。参考：IDragHandler
  • IEndDragHandler → OnEndDrag：拖动结束时，在被拖动对象上调用。参考：IEndDragHandler
  • IDropHandler → OnDrop：在拖动结束所在的目标对象上调用。参考：IDropHandler
  • IScrollHandler → OnScroll：鼠标滚轮滚动时调用。参考：IScrollHandler
  • IUpdateSelectedHandler → OnUpdateSelected：每个更新 Tick 在当前选中对象上调用。参考：IUpdateSelectedHandler
  • ISelectHandler → OnSelect：对象成为选中对象时调用。参考：ISelectHandler
  • IDeselectHandler → OnDeselect：对象取消选中时调用。参考：IDeselectHandler
  • IMoveHandler → OnMove：发生左、右、上、下移动事件时调用。参考：IMoveHandler
  • ISubmitHandler → OnSubmit：按下提交按钮时调用。参考：ISubmitHandler
  • ICancelHandler → OnCancel：按下取消按钮时调用。参考：ICancelHandler
