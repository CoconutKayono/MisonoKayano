本页内容SDF 着色器（SDF Shaders）
整理说明：源目录的两个 Shaders HTML 正文相同，已合并为本篇。文件名含 Bitmap - MobileBitmapMobile 的副本仍是着色器概述，不是独立的 Bitmap Mobile 正文。

TextMesh Pro 围绕有符号距离场（Signed Distance Field，SDF）渲染设计，并附带一组相应 Shader。如果不使用 SDF，也可选择纯位图 Shader。

所有 Shader 都有桌面版和移动版。移动版开销较低、适合移动设备，但效果更少。可在 Shader 菜单 TextMeshPro 和 TextMeshPro / Mobile 中找到。

SDF 着色器（SDF Shaders）

SDF Shader 分为 Distance Field、Distance Field (Surface)、Distance Field Overlay 三种。常规版和 Overlay 版是 Unlit，不受 Scene 灯光影响，但可支持局部模拟光照效果。

Surface 版会与 Scene 灯光交互，使用 Unity Surface Shader 框架，灵活性较高但 GPU 开销也更大。它们不是基于物理的 Shader（Physically Based Shader）。

SDF Shader 可利用距离数据生成 Outline、Underlay、Bevel 等效果，通常会扩大文本的视觉范围。参数过大时，字符 Sprite 边缘可能出现伪影，应降低效果强度，例如减小偏移很大的柔化、膨胀 Underlay。

伪影源于图集中相邻字符的数据渗入当前字符。导入字体时增加 Padding，可为这些效果留出更多空间。
