画布组（Canvas Group）

离线英文原文Unity 在线原文 ↗

上一页画布缩放器（Canvas Scaler）下一页画布渲染器（Canvas Renderer）
本页内容属性（Properties）

Canvas Group 可以控制 Canvas 内 UI 元素的可见性、交互能力和 Alpha 透明度，便于统一管理多个 UI 元素的属性。

Canvas Group 的典型用途：

  • UI 淡入淡出：给窗口的 GameObject 添加 Canvas Group，改变 Alpha，让整个窗口淡入或淡出。
  • 禁用交互：给一组 UI 控件的父 GameObject 添加 Canvas Group，将 Interactable 设为 false，使这一组控件不可交互。
  • 忽略射线检测：给元素或其父级添加 Canvas Group，将 Block Raycasts 设为 false，避免这些 UI 元素阻挡鼠标事件。

属性（Properties）

下表说明 Canvas Group 组件的属性：

属性 功能说明
不透明度（Alpha） 组内 UI 元素的不透明度，范围为 0～1：0 完全透明，1 完全不透明。每个元素自身的透明度仍然有效，最终 Alpha 是 Canvas Group Alpha 与元素 Alpha 的乘积。
可交互（Interactable） 决定组件是否接受输入。设为 false 时禁用交互。
阻挡 UI 射线（Block Raycasts） 决定该组件是否阻挡 UI Raycast。需要调用 Canvas 上 Graphic Raycaster 的 RayCast 函数；此设置不影响 Physics.Raycast。
忽略父画布组（Ignore Parent Groups） 决定此组是否受 GameObject 层级中上级 Canvas Group 设置影响，还是忽略上级并以自身设置覆盖。
