传统富文本（Rich Text）

本页内容标记格式（Markup format）嵌套元素（Nested elements）标签参数（Tag parameters）支持的标签（Supported tags）支持的颜色（Supported colors）编辑器 GUI（Editor GUI）

UI 元素和 Text Mesh 的文本可包含多种字体样式与字号。UI 系统和旧版 GUI 系统都支持 Rich Text。Text、GUIStyle、GUIText、TextMesh 的 Rich Text 设置会让 Unity 解析文本中的标记标签。Debug.Log 也可使用这些标签增强代码日志；标签本身不显示，只控制文本样式。

标记格式（Markup format）

该标记系统借鉴 HTML，但不要求与标准 HTML 严格兼容。基本形式是用一对匹配的标签包围一段文本：

We are <b>not</b> amused.

如例所示，标签是放在尖括号 < 和 > 内的文本。

在段落开头放置开始标签，内部文本是标签名，此例为 b。

在段落末尾放置结束标签，名称相同但前面加 /。每个开始标签都必须有对应的结束标签，否则开始标签会作为普通文本显示。

标签不会直接显示给用户，而是控制其包围文本的样式。上例的 b 标签让 not 显示为粗体，屏幕效果如下：

We are not amused

包含包围标签的一段标记文本称为元素（Element）。

嵌套元素（Nested elements）

将一个元素嵌套在另一个内部，可以为一段文本应用多个样式。

We are <b><i>definitely not</i></b> amused

<i> 表示斜体，屏幕显示效果如下：

We are definitely not amused

结束标签的顺序与开始标签相反。内层标签无需覆盖外层元素的全部文本，因此嵌套时要注意关闭顺序。

We are <b>absolutely <i>definitely</i> not</b> amused

显示效果如下：

We are absolutely definitely not amused

标签参数（Tag parameters）

一些标签只是启用或禁用某种样式，另一些可以设置具体值。例如 color 必须指定颜色，这种信息通过标签参数传入：

We are <color=green>green</color> with envy

显示结果如下：

结束标签不包含参数值。参数值可用引号包围，但不是必需的。

标签参数不能包含空格，例如：

We are <color = green>green</color> with envy

此写法无效，因为 = 两侧包含空格。

支持的标签（Supported tags）

下表描述 Unity 支持的全部样式标签。

标签（Tag） 说明 示例 备注
b 以粗体显示文本。 We are <b>not</b> amused.
i 以斜体显示文本。 We are <i>usually</i> not amused.
size 根据参数设置字号，单位为像素。 We are <size=50>largely</size> unaffected. Debug.Log 也支持此标签，但字号过大时，窗口栏和 Console 的行距可能显示异常。
color 根据参数设置文本颜色。可以使用传统 HTML 十六进制格式 #rrggbbaa，分别表示红、绿、蓝和 Alpha。完全不透明的青色为 color=#00ffffff。十六进制大小写均可，#FF0000 与 #ff0000 等价。 We are <color=#ff0000ff>colorfully</color> amused 也可以直接使用颜色名，写法易读，但可选颜色有限，且始终采用完全不透明值。例如 <color=cyan>some text</color>。可用颜色名见下表。参考：table below
material 仅适用于 Text Mesh，使用参数指定的材质渲染某段文本。参数值是 Inspector 中 Text Mesh 材质数组的索引。 We are <material=2>texturally</material> amused
quad 仅适用于 Text Mesh，在文本行内渲染图像。参数指定材质、像素高度，以及要显示的图像矩形区域。quad 不包围文本，因此无需结束标签；原文说明它以标签末尾的 / 表示自闭合。 <quad material=1 size=20 x=0.1 y=0.1 width=0.5 height=0.5> 示例选择渲染器材质数组中对应的材质，将图像高度设为 20 像素。x、y、width、height 定义显示区域，均以纹理未缩放宽高的比例表示。

编辑器 GUI（Editor GUI）

编辑器 GUI 默认禁用富文本，可通过自定义 GUIStyle 显式启用。将 richText 设为 true，然后将该样式传给对应 GUI 函数：

GUIStyle style = new GUIStyle ();
style.richText = true;
GUILayout.Label("<size=30>Some <color=yellow>RICH</color> text</size>",style);
