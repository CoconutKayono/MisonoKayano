TextMesh Pro 设置（Settings）

TextMesh Pro 将项目级设置存储在专用 TMP Settings 资源中。该资源必须位于 Resources 文件夹，默认在 Assets/TextMesh Pro 目录下。

在 Project 窗口中选中该资源，或打开 Project Settings 并选择 TextMesh Pro 分类，即可编辑。

设置分为以下组：

组（Group） 说明
默认字体资源（Default Font Asset） 设置文本对象的默认字体。
备用字体资源（Fallback Font Assets） 主字体资源缺少字符时，指定要搜索的备用字体资源。
备用材质设置（Fallback Material Settings） 设置从备用字体获得的字符的样式选项。
动态字体系统设置（Dynamic Font System Settings） 设置缺失字符的处理方式。
文本容器默认设置（Text Container Default Settings） 控制新文本对象的文本容器尺寸。
文本组件默认设置（Text Component Default Settings） 设置新文本对象的基本格式。
默认精灵资源（Default Sprite Asset） 为未指定资源的 Rich Text sprite 标签设置默认 Sprite Asset，并配置其他精灵选项。
备用 Emoji 文本资源（Fallback Emoji Text Assets） 管理查找 Emoji 字符所使用的文本资源列表。
默认样式表（Default Style Sheet） 选择默认样式表。
颜色渐变预设（Color Gradient Presets） 选择颜色渐变预设的存放位置。
亚洲语言换行（Line Breaking for Asian Languages） 定义 Leading 和 Following Characters，让亚洲语言字体正确换行。
韩文选项（Korean Language Options） 决定韩文使用 Modern 还是 Traditional 换行规则。

默认字体资源（Default Font Asset）

属性 说明
默认字体资源（Default Font Asset） 创建新文本对象时采用的默认字体。
路径（Path） 字体资源的存储路径，必须指向 Resources 的子文件夹。

备用字体资源（Fallback Font Assets）

主字体中缺少某字符时，TextMesh Pro 会到这些资源中查找字形。如果主字体有本地 Fallback 列表，则先搜索本地列表。

属性 说明
备用字体资源列表（Fallback Font Assets List） 管理全局备用字体列表。单击 + / - 添加或删除槽位；单击字体旁的圆圈，用 Object Picker 选择 Font Asset；拖动左侧手柄可重新排序。

备用材质设置（Fallback Material Settings）

属性 说明
匹配材质预设（Match Material Presets） 启用后，让备用字体的字形匹配主字体样式。TMP 会为备用字形创建与主字体材质设置一致的材质。主字体与备用字体相似时效果最佳。
隐藏子文本对象（Hide Sub Text Objects） 决定是否在 Scene Hierarchy 中隐藏子文本对象。

动态字体系统设置（Dynamic Font System Settings）

以下是处理缺失字形的项目级设置。

属性 说明
缺失字符替代码点（Missing Character Unicode） 所有备用字体都找不到字形时，用此字符 ID 代替。默认值 0 显示一个方框轮廓。
禁用警告（Disable warnings） 启用后，不再为每个缺失字形记录警告。
运行时获取字体特性（Get Font Features at Runtime） 决定运行时是否从源字体文件提取 OpenType Font Features。
构建时清除动态数据（Clear Dynamic Data On Build） 决定新建动态 Font Asset 的 Clear Dynamic Data on Build 默认值为 true 还是 false。

文本容器默认设置（Text Container Default Settings）

以下设置定义新文本对象的文本容器默认尺寸。

属性 说明
TextMeshPro 新建 TextMesh Pro 三维对象的容器默认尺寸，单位为 Unity Unit。
TextMeshPro UI 新建 TextMesh Pro UI 对象的容器默认尺寸，单位为 Unity Unit。
启用射线目标（Enable Raycast Target） 启用后，新 TMP 对象默认成为 Raycast 目标；禁用后，UI 判断光标交互对象时默认忽略 TMP 对象。
自动调整文本容器（Auto Size Text Container） 新建 TextMesh Pro UI 对象时，自动调整容器尺寸以适应文本。
对象缩放是否静态（Is Object Scale Static） 禁用内部更新；文本对象的 Scale 不变化时可提升性能。

文本组件默认设置（Text Component Default Settings）

以下设置定义新文本对象的默认值。添加到 Scene 后，仍可在对象的 TextMesh Pro Inspector 中修改。

属性 说明
默认字号（Default Font Size） 默认字号，单位为 Point。
自动字号比例（Text Auto Size Ratios） 自动设置字号时使用的默认 Min / Max 尺寸比例。参考：sets font size automatically
文本换行模式（Text Wrapping Mode） 为所有新文本对象启用自动换行。
字体特性（Font Features） 定义新文本对象默认启用哪些 Font Features。
额外内边距（Extra Padding） 为字符 Sprite 增加额外留白。TMP 生成的 Sprite 通常贴合可见文字，但结果未必完全准确；额外留白可降低字形在 Sprite 边界被裁切的风险。
给全部精灵着色（Tint All Sprites） 默认情况下，Sprite 不受文本顶点颜色影响；启用 Tint All Sprites 后会受影响。
解析转义序列（Parse Escape Sequence） 启用后，将反斜杠转义解释为特殊字符，例如 \n 为换行，\t 为制表符。此选项作用于渲染文本；代码中的转义字符已由编译器解析。

默认精灵资源（Default Sprite Asset）

属性 说明
默认精灵资源（Default Sprite Asset） 为 TextMesh Pro GameObject 选择默认 Sprite Asset。参考：Sprite asset
缺失精灵替代码点（Missing Sprite Unicode） 请求的 Sprite 在主资源及备用资源中都缺失时，指定替代 Sprite 的 Unicode 值。
iOS Emoji 支持（iOS Emoji Support） 开启或关闭 iOS Emoji 支持。
路径（Path） Sprite Asset 的存储路径，必须指向 Resources 子文件夹。

备用 Emoji 文本资源（Fallback Emoji Text Assets）

文本包含 Emoji 时，TMP 会搜索此列表中的 Font Asset 和 Sprite Asset，以找到对应 Emoji 字符。

属性 说明
文本资源列表（Text Asset List） 管理备用 Emoji 文本资源列表。单击 + / - 添加或删除槽位，单击圆圈通过 Object Picker 选择资源，拖动左侧手柄重新排序。

默认样式表（Default Style Sheet）

属性 说明
默认样式表（Default Style Sheet） 选择一个样式表资源，供项目中所有文本对象使用。参考：style sheet
路径（Path） 样式表存储路径，必须指向 Resources 子文件夹。

颜色渐变预设（Color Gradient Presets）

属性 说明
路径（Path） 设置资源存储路径，必须指向 Resources 子文件夹。译注：原文此行写作 Sprite assets，但本节标题为 Color Gradient Presets，存在用词不一致。

亚洲语言换行（Line Breaking for Asian Languages）

要让亚洲语言正确换行，需指定 Leading 和 Following Characters：

属性 说明
Leading 字符（Leading Characters） 包含 Leading Characters 列表的文本文件。
Following 字符（Following Characters） 包含 Following Characters 列表的文本文件。

韩文选项（Korean Language Options）

属性 说明
使用现代换行规则（Use Modern Line Breaking） 启用时使用韩文 Modern 换行规则；禁用时使用 Traditional 规则。
