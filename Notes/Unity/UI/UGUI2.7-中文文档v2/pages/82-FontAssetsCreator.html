字体资源创建器（Font Asset Creator）

Font Asset Creator 将 Unity 字体资源 转换为 TextMesh Pro 字体资源。可创建有符号 距离场（SDF） 字体和位图字体。

创建新的 TextMesh Pro 字体资源时，会生成字体资源本身，以及字体的图集纹理和材质。

创建 TextMesh Pro 字体资源后，可以删除作为源文件的 Unity 字体资源。不过，为以后重新生成 TextMesh Pro 字体资源，可能需要将源字体保留在场景中。

创建字体资源

开始前，先将要使用的字体（通常为 TrueType .ttf 文件）导入项目。关于在 Unity 中导入字体，参阅 字体（Fonts） ，位于 Unity 手册中。

为了创建TextMesh Pro字体资源:

  1. 从菜单选择： Window > TextMesh Pro > Font Asset Creator 以打开字体资源创建器。

  2. 为 TextMesh Pro GameObject 选择 源字体文件（Source Font File）。这是要转换为 TextMesh Pro 字体资源的 Unity 字体资源。

  3. 调整 字体设置（Font Settings） ，然后按需要单击 生成字体图集（Generate Font Atlas） 创建图集纹理

    图集和字体资源的信息会显示在纹理预览区域。

    IMAGE

  4. 继续调整设置并重新生成图集，直到对结果满意。

  5. 单击 保存（Save） 或 另存为…（Save as...） 将字体资源保存到你的项目中。

    必须将资源保存在一个 Resources 文件夹，使 TextMesh Pro 能够访问它。

字体资源创建器设置：

属性： 功能：
源字体文件（Source Font File） 选择从中生成Text Mesh Pro字体资源的字体。

除非在项目其他位置使用该字体，或将其放入 Resources 文件夹，否则它不会包含在项目构建中。

你可以使用一个默认的TextMesh Pro 字体资源或 导入自己的.
采样点数大小（Sampling Point Size） 设置用于生成字体纹理的字号，以磅为单位。
自动大小（Auto Sizing） 在所有字符仍可放入纹理的前提下，采用尽可能大的字号。

这就是SDF字体的常规设置。
自定义大小（Custom Size） 使用自定义字号，在文本框中输入所需大小。

仅位图字体可通过此设置实现像素级精确控制。
内边距 指定字体纹理中字符之间的间距，以像素为单位。

内边距为字符分别渲染及生成 SDF 渐变提供空间。参阅 字体资源（Font Assets） 了解详情）。

内边距越大，过渡越平滑，能支持更高的渲染质量和更大的效果，例如较粗的描边。

对于 512 × 512 纹理，内边距设为 5 通常就足够。
装箱方法（Packing Method） 指定如何将字符纳入字体纹理。
最优（Optimum） 自动找到仍能容纳所有字符的最大字号。

使用此设置生成最终字体纹理。
快速（Fast） 更快地计算字符打包，但采用的字号可能比 Optimum 模式更小。

使用此设置测试字体资源创建设置。
图集分辨率（Atlas Resolution） 设置字体纹理的宽度和高度，以像素为单位。

仅包含 ASCII 字符时，512 × 512 的分辨率适用于多数字体。字符更多时，可能需要更高分辨率或多个图集。

对于 SDF 字体，更高的分辨率会产生更细腻的渐变，从而提高文本质量。
字符集（Character Set） 字体文件中的字符不会自动加入字体资源，必须指定所需字符。可选择预定义字符集、提供字符列表，或包含现有字体资源或文本资源中的全部字符。
ASCII 包含ASCII字符集中的可见字符。
扩展 ASCII（Extended ASCII） 包含扩展的ASCII字符集中的可见字符。
ASCII 小写字符（ASCII Lowercase） 只包含 ASCII 字符集中的可见小写字符。
ASCII 大写字符（ASCII Uppercase） 只包含 ASCII 字符集中的可见大写字符。
数字与符号（Numbers + Symbols） 只包含 ASCII 字符集中的可见数字和符号。
自定义范围（Custom Range） 包括你定义的一系列字符。

输入一系列十进制数值或数值范围，指定要包含的字符。

用连字符分隔范围的首尾数值，用逗号分隔不同数值与范围（例如， 32-126,160,8230）。

也可选择现有字体资源，以包含该资源中的字符。
Unicode 范围（十六进制）（Unicode Range (Hex)） 包括你定义的一系列字符。

输入一系列 Unicode 十六进制数值或数值范围，指定要包含的字符。

用连字符分隔范围的首尾数值，用逗号分隔不同数值与范围（例如， 20-7E,A0,2026）。

也可选择现有字体资源，以包含该资源中的字符。
自定义字符（Custom Characters） 包括你定义的一系列字符。

输入一个字符序列，指定包括哪些字符。

依次输入字符，不在字符之间添加空格或分隔符（例如， abc123*#%）。

也可选择现有字体资源，以包含该资源中的字符。
从文件读取字符（Characters from File） 包含指定文本资源中的所有字符。

如果你想保存你的字符集，请使用此选项。
字体样式（Font Style） 创建仅位图字体资源时，应用基本字体样式。

对于 SDF 字体，样式在着色器中配置，而不是在字体资源中配置。
常规（Normal） 生成不带样式的字符。
粗体、斜体、粗斜体（Bold, Italic, Bold_Italic） 生成具有粗体、斜体或粗斜体字符的字体资源。

可设置作用于加粗和倾斜的强度值。
描边（Outline） 生成带描边字符的字体资源。
Bold_Sim 生成使用模拟粗体的字体资源。
渲染模式（Render Mode） 指定在输出字体图集时使用的渲染模式。
SMOOTH 将图集渲染为抗锯齿位图。
RASTER 将图集渲染为不抗锯齿的位图。
SMOOTH_HINTED 将图集渲染为抗锯齿位图，并将字符像素与纹理像素对齐，以获得更清晰的结果。
RASTER_HINTED 将图集渲染为不抗锯齿的位图，并使字符像素与纹理像素对齐，让结果更清晰。
SDF 使用较慢但更准确的 SDF 生成模式渲染图集，不进行过采样。
SDFAA 使用较快但精度稍低的 SDF 生成模式渲染图集。生成的字体图集足以满足多数情况。
SDFAA_HINTED 使用较快但精度稍低的 SDF 生成模式渲染图集，并将字符像素与纹理像素对齐，让结果更清晰。生成的字体图集足以满足多数情况。
SDF8 使用较慢但更准确的 SDF 生成模式渲染图集，采用 8 倍过采样。
SDF16 使用较慢但更准确的 SDF 生成模式渲染图集，采用 16 倍过采样。
SDF32 使用较慢但更准确的 SDF 生成模式渲染图集，采用 32 倍过采样。适用于字符复杂或较小的字体。
获取字偶距对（Get Kerning Pairs） 启用此选项将字偶距数据从字体中复制。

字偶距数据用于调整特定字符对之间的间距，使视觉效果更协调。

注意： 并非所有字体都能导入字偶距数据。某些字体将字偶距对保存在字形定位（GPOS）表中，原文称 TextMesh Pro 使用的 FreeType 字体引擎不支持此方式；还有些字体完全没有保存字偶距对。
生成字体图集（Generate Font Atlas） 创建字体图集纹理。
保存（Save） 保存当前的字体图集。
另存为（Save As） 保存当前字体图集作为一个新的字体资源。

创建字体资源的技巧

字体纹理中的字符之间需要以像素为单位的内边距，以便分别渲染。内边距也为 SDF 渐变留出空间；数值越大，过渡越平滑，支持的渲染质量和效果范围也越大，例如更粗的描边。512 × 512 纹理通常使用 5 像素内边距即可。

包含全部 ASCII 字符时，512 × 512 纹理通常适用于多数字体。若要支持数千个字符，则需要较大纹理；即使使用最高分辨率，也可能无法容纳全部字符。此时可创建多个字体资源，将常用字符放入主字体资源，其他字符放入后备字体资源。
