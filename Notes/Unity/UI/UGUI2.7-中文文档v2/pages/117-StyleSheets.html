本页内容默认样式表（The default style sheet）每个对象的样式表（Per-object style sheets）创建自定义样式表（Creating custom style sheets）

使用样式表创建自定义文本样式，并通过以下标签应用到文本： <style> 富文本标签.

自定义样式可包含开始与结束富文本标签，以及前置和后置文本。

例如，希望文本中的标题使用大字号、红色和粗体，两侧各有一个星号，并在末尾换行。

无需为每个标题重复输入以下内容：

<font-weight=700><size=2em><color=#FF0000>*Heading*</color></size></font-weight><br>

而是创建一个名为 H1 的样式，包含上述全部格式：

随后，使用一个 <style> 标签：

<style="H1">Heading</style>

默认样式表（The default style sheet）

默认样式表是以下范围内每个 TextMesh Pro 对象使用的样式表：

TextMesh Pro 自带的默认样式表存储在 TextMesh Pro > Resources > Style Sheets 文件夹中，不过也可将任意样式表设为默认。

要更改默认的样式表，设置 Default Style Sheet > Default Style Sheet 选项，位置在 TextMesh Pro 设置.

每个对象的样式表（Per-object style sheets）

要覆盖默认样式表，在以下位置指定样式表资源： 额外设置（Extra settings） 在 UI 文本组件（UI text component） 或 三维文本组件（3D text component）.

创建自定义样式表（Creating custom style sheets）

要创建新的样式表，选择 Assets > Create > TextMesh Pro > Style Sheet ，通过菜单创建。

项目中会新增一个 TextMesh Pro 样式表。在 Inspector 中打开它，即可添加自定义样式。
