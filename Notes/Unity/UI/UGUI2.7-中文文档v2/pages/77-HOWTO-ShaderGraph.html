使用 Shader Graph 创建自定义 UI 效果（Create Custom UI Effects With Shader Graph）

离线英文原文Unity 在线原文 ↗

本页内容基本知识创建动画背景将着色器应用于Canvas元素向着色器传入自定义数据

Shader Graph 可用于制作动画背景和独特 UI 元素等自定义效果，使 Image 从静态变为动态，并定义按钮各状态的外观。它还提供更细致的外观控制，有助于优化性能和纹理内存。

以下是在 uGUI（Unity UI）中使用 Shader Graph 可以实现的效果示例：

  • 为用户界面创建缓缓旋转、流动或漂移的自定义背景。
  • 仅使用一张灰度图像，即可定义鼠标悬停、按下、失去焦点等按钮视觉状态。
  • 设计动画的HUD元素，显示时间的流逝。

基本知识

要为 Canvas UI 元素创建 Shader Graph 着色器，可使用以下任一方法：

  • 修改现有的Shader Graph:
    1. 在 Shader Editor 中打开 Shader Graph。
    2. 在 图设置（Graph Settings）选择 HDRP 目标。如果尚无该目标，转到 活动目标（Active Targets） > 加号（Plus）选择 HDRP.
    3. 在 Material 下拉菜单中选择 Canvas.
  • 创建新的 Shader Graph。转到 Assets > Create > Shader Graph > HDRP选择 Canvas Shader Graph.

创建动画背景

按以下步骤为用户界面创建一个简单的动画背景。

  1. 在图中添加两个 Sample Texture 2D 节点，设置为使用可平铺的云纹理。接下来让它们以不同方向和速度滚动。

  2. 为每个 Sample Texture 2D 添加一个 Tiling and Offset 节点，将其连接到 Sample Texture 2D 的 UV 输入端口。通过 Offset 输入端口实现滚动。

  3. 为每个 Tiling and Offset 节点创建一个 Multiply 节点，并连接到 Offset 输入端口。

  4. 为第一个 Multiply 节点创建一个 Vector 2 节点，连接到 A 输入端口，将其设为 0.2 和 0.13。为第二个 Multiply 节点创建一个 Vector 2 节点，连接到 B 输入端口，将其设为 -0.1 和 0.23这些值控制了滚动方向。

  5. 创建 Time 节点，将 Time 输出值乘以 0.3。此值用于调整效果的速度。

  6. 将 Time 的 Multiply 节点输出端口连接到另外两个 Multiply 节点。此时纹理就会滚动。

  7. 创建 Blend 节点，用它混合两个 Sample Texture 2D 节点的输出，将两张纹理的效果合并。

  8. 添加 Lerp 节点，将 Blend 的输出连接到 Lerp 的 T 输入，以纹理的贡献值作为混合遮罩。

  9. 要使用动画遮罩混合两种颜色，创建两个 Color 节点，分别连接到 Lerp 的 A 和 B 输入。按喜好设置颜色。

  10. 最后，将 Lerp 输出连接到 Fragment Context Block 的 Base Color 输入。

至此已创建动画背景着色器。可通过更换颜色、纹理或控制速度进行自定义。

将着色器应用于Canvas元素

按照下面的步骤将你创建的着色器应用到Canvas UI元素中。

  1. 在 Project 窗口中右键单击 Shader Graph 资源，选择 Create > Material。为材质命名。

  2. 确保场景中有 Canvas。如果没有，在 Hierarchy 面板中右键单击，选择 UI (Canvas) > Canvas。

  3. 在 Canvas 中添加 Image 元素。右键单击 Canvas，选择 UI > Image.

  4. 在 Hierarchy 面板中选中 Image。在 Inspector 窗口的 Material 槽位上选择 浏览 。

  5. 选择步骤 1 中创建的材质资源。

现在你的Canvas元素正在使用你创建的着色器。

向着色器传入自定义数据

可以在 Shader Graph 着色器中获取自定义数据，例如 Canvas Image 元素的宽度和高度。按以下步骤通过脚本即可实现：

  1. 按照 将着色器应用于 Canvas 元素 一节的步骤创建材质，并将其应用到 Canvas Image 元素。

  2. 打开 Shader Graph 资源，并在右上角选择 Blackboard ，即可打开 Blackboard 窗口。

  3. 在 Blackboard 窗口右上角单击 + ，添加新的 Blackboard 参数。

  4. 选择与需要传入的数据相匹配的数据类型。本例添加 Vector 2 参数。

  5. 将新参数命名为 Size。随后可将 Size 参数拖入图中，并按需使用。

  6. 创建以下脚本，将 Canvas Image 的 Width 和 Height 传入着色器的 Size 参数：

using UnityEngine;
using UnityEngine.UI;

[RequireComponent(typeof(Graphic))]
[ExecuteAlways]
public class ImageSize : MonoBehaviour
{
    private Image m_myCanvasImage;
    private void Start() 
    {
        m_myCanvasImage = GetComponent<Image>();
    }

#if UNITY_EDITOR
    void OnValidate() { UpdateMaterial(); }
#endif 

    private void FixedUpdate()
    {
        UpdateMaterial();
    }

    void UpdateMaterial()
    {
        if (m_myCanvasImage != null && m_myCanvasImage.material != null)
        {
            var imageRect = m_myCanvasImage.rectTransform.rect;
            var widthHeight = new Vector2(x: imageRect.width, y: imageRect.height);
            m_myCanvasImage.material.SetVector(name: "_Size", widthHeight);
        }
    }
}
  1. 保存脚本为 ImageSize.cs 然后把它添加到你的项目中。
  2. 在场景的 Hierarchy 面板中选中 Image 元素。
  3. 在Inspector窗口中，选择 添加组件 然后选择 Scripts > Image Size.

Image 元素的 Rect Transform 的 Width 和 Height 会传入材质的 Size 参数，随后即可在着色器中使用它们。
