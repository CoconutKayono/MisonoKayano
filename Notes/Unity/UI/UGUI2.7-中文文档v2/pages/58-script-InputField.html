输入框（Input Field） 可以让以下控件的文本变为可编辑内容： Text 控件 。与其他交互控件一样，它本身不是可见的 UI 元素，必须结合一个或多个视觉 UI 元素才能显示。

属性

属性： 功能：
可交互（Interactable） 决定 Input Field 是否可交互的布尔值。
过渡（Transition） 过渡（Transitions） 用于设置输入框在以下状态中的过渡方式： 法线（Normal）、 高亮（Highlighted）、 按下（Pressed） 或 禁用（Disabled）.
导航（Navigation） 决定控件导航顺序的属性。参阅 导航选项.
TextComponent 引用 Text 元素，用作以下控件的内容： 输入框（Input Field）
Text 初始值。开始编辑前，输入框中显示的文本。
字符限制（Character Limit） 允许输入到输入框的最大字符数。
内容类型（Content Type） 定义输入框接受的字符类型。
标准（Standard） 允许输入任意字符。
自动更正（Autocorrected） 自动更正用于跟踪未知单词，并向用户建议更合适的替代候选词。除非用户明确取消，否则会自动替换输入的文本。
整数（Integer Number） 只允许输入整数。
小数（Decimal Number） 只允许输入数字和一个小数点。
字母与数字（Alphanumeric） 允许输入字母和数字，不允许输入符号。
姓名（Name） 自动将每个单词的首字母转为大写。注意，用户可以通过以下按键绕过大写规则： Delete 。
电子邮件地址（Email Address） 允许输入最多包含一个 @ 符号的字母数字字符串，句点不能连续输入。
密码（Password）* 用星号隐藏输入的字符，允许输入符号。
PIN 码（Pin） 用星号隐藏输入的字符，只允许输入整数。
自定义（Custom） 允许自定义 Line Type、Input Type、Keyboard Type 和 Character Validation。
行类型（Line Type） 定义输入框内部文本的排版方式。
单行（Single Line） 只允许单行文本。
多行提交（Multi Line Submit） 允许多行文本，仅在需要时换行。
多行换行（Multi Line Newline） 允许多行文本，用户可按回车键插入换行。
占位内容（Placeholder） 可选的“空内容” 图形（Graphic） ，用于表示 输入框（Input Field） 中没有文本。注意，即使 输入框（Input Field） 被选中（获得焦点），占位图形仍然会显示，例如“Enter text...”。
插入光标闪烁频率（Caret Blink Rate） 用于指示文本插入位置的光标的闪烁频率。
选区颜色（Selection Color） 选中文本的背景颜色。
隐藏移动端输入框（Hide Mobile Input） 隐藏移动设备屏幕键盘附带的原生输入框。仅适用于 iOS 和 Android。

事件

属性： 功能：
值变化事件（On Value Change） UnityEvent 事件，在 Input Field 的文本内容发生变化时调用，可以将当前文本作为 string 类型的动态参数传递。
结束编辑（End Edit） UnityEvent 事件，在用户提交文本或单击其他位置使输入框失去焦点、从而结束编辑时调用。可以将当前文本作为 string 类型的动态参数传递。

详细说明

可以通过菜单将 Input Field 脚本添加到现有 Text 控件对象上：Component > UI > Input Field。随后，还应将对象拖到 Input Field 的 Text 属性中，以启用编辑。

Text 属性会随用户输入而改变，编辑后可通过脚本获取该值。可编辑 Text 控件刻意不支持富文本：输入富文本标记后会立即应用样式，但标记实际上会“消失”，之后无法再更改或删除样式。

提示

  • 要获取 Input Field 的文本，应读取 InputField 组件自身的 text 属性，而不是显示文本的 Text 组件的 text 属性。后者可能已经被裁切，或者在密码输入时只包含星号。

限制

  • iOS 连接外接键盘时，操作系统会隐藏屏幕键盘，但 InputField 中不会出现插入光标。这是因为 iOS 13 及更早版本缺少外接键盘支持。
