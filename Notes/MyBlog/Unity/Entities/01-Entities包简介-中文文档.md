# Entities 包（Entities package）

> 来源：[Unity Package 官方文档 · Entities package](https://docs.unity3d.com/Packages/com.unity.entities@6.6/manual/index.html)

Entities 包是 Unity 数据导向技术栈（Data-Oriented Technology Stack，DOTS）的一部分。它提供了实体组件系统（Entity Component System，ECS）架构的数据导向实现。

有关 ECS 相关包的完整列表，请参阅 [ECS 包](https://docs.unity3d.com/Packages/com.unity.entities@6.6/manual/ecs-packages.html)。通常不会单独使用 Entities 包；一般会组合使用 Entities Graphics、Unity Physics 和/或 Netcode for Entities。

请参阅 [ECS Samples](https://github.com/Unity-Technologies/EntityComponentSystemSamples) 获取入门资料，包括教程、示例和视频。
