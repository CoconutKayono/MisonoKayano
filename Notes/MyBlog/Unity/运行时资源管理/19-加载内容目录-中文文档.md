# 加载内容目录（Load content directories）

> 来源：[Unity 6000.7 官方手册 · Load content directories](https://docs.unity3d.com/6000.7/Documentation/Manual/content-directories-load.html)

每次调用 [BuildPipeline.BuildContentDirectory](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/BuildPipeline.BuildContentDirectory.html) 都会用来自一个或多个根资源的已构建内容填充指定的输出目录。

在运行时，脚本必须为每个内容目录调用一次 [ContentLoadManager.RegisterContentDirectory](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Loading.ContentLoadManager.RegisterContentDirectory.html)，以使其内容可用：

```csharp
ContentDirectoryHandle handle = ContentLoadManager.RegisterContentDirectory(localPath);
```

这会加载内容目录的构建清单（build manifest），以填充内存中的数据结构。来自已注册内容目录的根资源可通过 [ContentLoadManager](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Loading.ContentLoadManager.html) API 使用。

注册内容目录后，你可以调用 [ContentLoadManager.GetRootAssets](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Loading.ContentLoadManager.GetRootAssets.html) 发现其中可用的根资源。

当尝试加载资源或场景时，Unity 会按注册的相反顺序搜索已加载的内容目录，即最后注册的最先被搜索，就像栈一样。

## 卸载内容目录

要清理资源，请在对每个已加载资源调用 `Loadable.Release` 之后，以及在每个场景卸载之后（例如通过 `SceneManager.UnloadSceneAsync`），为每个内容目录调用一次 [ContentLoadManager.UnregisterContentDirectory](https://docs.unity3d.com/6000.7/Documentation/ScriptReference/Unity.Loading.ContentLoadManager.UnregisterContentDirectory.html)。如果仍有任何文件打开时调用 `UnregisterContentDirectory`，Unity 会记录错误。
