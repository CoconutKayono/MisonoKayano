# 其他方法（Additional methods）

## 静态方法（DOTween）

### DOTween.Clear

```cs
static DOTween.Clear(bool destroy = false)
```

杀死所有补间、清空所有对象池，并将最大 Tweener / Sequence 容量重置为默认值。

> [!WARNING]
> 此方法只应出于调试目的使用，或当你确定项目中不再需要创建/运行任何补间时使用，因为它会完全反初始化 DOTween 及其内部插件。**如果只是想杀死所有补间，请改用静态方法 `DOTween.KillAll()`。**

- **destroy**：若为 `TRUE`，还会销毁 DOTween 的 gameObject，并重置其初始化、默认设置及其他一切（下次使用 DOTween 时需要重新初始化）。

### DOTween.ClearCachedTweens

```cs
static DOTween.ClearCachedTweens()
```

清空所有缓存的补间对象池。

### DOTween.Validate

```cs
static DOTween.Validate()
```

验证所有活跃补间，并移除其中已失效的（通常是因为其目标已被销毁）。这是一个开销略大的操作，请谨慎使用。另外，特别是在安全模式开启时，基本不需要使用它。

### DOTween.ManualUpdate

```cs
static DOTween.ManualUpdate(float deltaTime, float unscaledDeltaTime)
```

更新所有设置为 `UpdateType.Manual` 的补间。

## 实例方法（Tween/Tweener/Sequence）

### Tween（Tweener + Sequence 通用）

#### Done

```cs
Tween Done()
```

可选：标记补间创建已结束。可以（可选地）作为补间链式创建的最后一项。

此方法通常不做任何事，**唯一的例外是时长为 0 的补间**：此时它会立即完成补间，而不是等待下一次内部更新（除非补间嵌套在 Sequence 中——这种情况下仍由 Sequence 控制，此方法会被忽略）。

#### ManualUpdate

```cs
ManualUpdate(float deltaTime, float unscaledDeltaTime)
```

强制此补间手动更新，无论通过 `SetUpdate` 设置的 `UpdateType` 是什么。

- 注意：补间仍受普通补间规则约束，例如补间被暂停时此方法无效。
- 注意：如果只想手动更新这一个补间实例，仍然需要把它设为 `UpdateType.Manual`，这样它才不会自动更新。
- **deltaTime**：手动传入的 deltaTime。
- **unscaledDeltaTime**：非缩放 delta 时间（用于设置为 `timeScaleIndependent` 的补间）。

### Tweener

以下三个 `Change*` 方法有共同的注意点：

- 对 Sequence 内部的 Tweener 无效。
- 只适用于普通补间，不适用于"不止是把一个值从一点动画到另一点"的补间（如 `DOLookAt`）。
- 对于接受单轴的快捷方式（`DOMoveX/Y/Z`、`DOScaleX/Y/Z` 等），即使补间只使用其中某个轴，也必须传入完整的 `Vector2/3/4` 值。

#### ChangeEndValue

```cs
ChangeEndValue(newEndValue, float duration = -1, bool snapStartValue = false)
```

更改 Tweener 的结束值，并倒回补间（不暂停）。

- **newEndValue**：新的结束值。
- **duration**：大于 0 时同时更改补间时长。
- **snapStartValue**：`TRUE` 时起始值变为目标当前值；`FALSE` 时保持原样。

#### ChangeStartValue

```cs
ChangeStartValue(newStartValue, float duration = -1)
```

更改 Tweener 的起始值，并倒回补间（不暂停）。

- **newStartValue**：新的起始值。
- **duration**：大于 0 时同时更改补间时长。

#### ChangeValues

```cs
ChangeValues(newStartValue, newEndValue, float duration = -1)
```

同时更改 Tweener 的起始值和结束值，并倒回补间（不暂停）。

- **newStartValue**：新的起始值。
- **newEndValue**：新的结束值。
- **duration**：大于 0 时同时更改补间时长。
