Function Icons — 64x64 PNG
============================

- Icon_Book_64.png: 64 x 64 pixels, RGBA PNG
- Icon_Moon_64.png: 64 x 64 pixels, RGBA PNG

Both are ordinary raster PNG images, not SVG.
Transparent canvas; icon content is centered and aspect ratio preserved.
The original icon artwork and colors are retained. Edges are resampled with
high-quality Lanczos filtering and a very light alpha-edge cleanup.

Unity import:
Texture Type: Sprite (2D and UI)
Sprite Mode: Single
Alpha Is Transparency: On
Mesh Type: Tight or Full Rect
Compression: None
